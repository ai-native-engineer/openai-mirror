Algorithms are hard to visualize, and
for me, it's literally impossible. I
have aphantasia, which means that I
can't form mental images at all. But
today, I'm going to walk you through how
I use Codex, OpenAI's agentic coding
tool, to build my very own algorithms
visualizer website so I can finally see
what my brain is unable to generate by
itself. Step one, tell Codex what to
build. I asked Codex to come up with a
list of common algorithms and create a
website with their visualizations.
That's it. No need to specify languages
or frameworks unless you have a
preference. Step two, debug. When I ran
the first version, some just weren't
quite right, like merge sort. So then I
fed Codex a rough sketch of what I
actually wanted it to look like, and it
implemented exactly that. Step three,
personalize. [music] I then asked Codex
to style my website, tweak the
animations, and make the UI feel like
something I'd be excited to use to study
or teach. Step four, document. This is,
of course, the part that most software
engineers absolutely dread. Luckily,
Codex can do this for us. I asked it to
organize my files, add meaningful
comments, and generate maintainable docs
so I can continue adding to it without
making a mess.
