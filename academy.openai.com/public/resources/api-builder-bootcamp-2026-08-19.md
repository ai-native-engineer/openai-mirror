## Series Overview

Join OpenAI Academy for a five-part live series covering API Foundations, Agents, Realtime, RAG, and Production & Optimization. Register for individual sessions or attend all five to earn a shareable completion certificate.

## Agenda / Sessions

Join us each week for a new topic, with all sessions running live from 10:00–11:00 AM PT.

#### August 19 | Builder Bootcamp: API Foundations

* Explore core API building blocks, model selection, prompting, structured outputs, and patterns for moving from idea to working prototype.

* ﻿ [Register for API Foundations](https://academy.openai.com/public/clubs/builders-etkn1/events/builder-bootcamp-api-foundations-w2r1db8i27?autoRsvp=true)﻿

#### August 26 | Builder Bootcamp: Agents

* Build reliable agentic workflows with tools, handoffs, orchestration, guardrails, and multi-step application patterns.

* ﻿ [Register for Agents](https://academy.openai.com/public/clubs/builders-etkn1/events/builder-bootcamp-agents-dnn3r6iuhf?autoRsvp=true)﻿

#### September 2 | Builder Bootcamp: Realtime

* Build responsive voice agents with speech-to-speech and chained architectures, turn-taking, interruption handling, tool calling, and guardrails.

* ﻿ [Register for Realtime](https://academy.openai.com/public/clubs/builders-etkn1/events/builder-bootcamp-realtime-yckmdr6h4y?autoRsvp=true)

#### September 10 | Builder Bootcamp: RAG

* Build grounded AI applications with retrieval and file search, covering knowledge ingestion, vector stores, ranking, metadata, knowledge freshness, and retrieval-quality evaluation.

* ﻿ [Register for RAG](https://academy.openai.com/public/clubs/builders-etkn1/events/builder-bootcamp-rag-7sdtlmnqff?autoRsvp=true)﻿

#### September 16 | Builder Bootcamp: Production & Optimization

* Take API applications from prototype to production with evals, model selection, latency and cost optimization, observability, guardrails, and reliability.

* ﻿ [Register for Production and Optimization](https://academy.openai.com/public/clubs/builders-etkn1/events/builder-bootcamp-production-and-optimization-jczbahx95z?autoRsvp=true)
