# Portfolio Company Dev & IT

In this session, you’ll build a practical foundation for developing with the OpenAI API. We’ll cover core building blocks, model selection, prompting, structured outputs, and the key concepts that help teams move from an initial use case to a working prototype.

You’ll also learn how to frame technical requirements, evaluate implementation options, and identify the considerations that matter as an application moves toward production. This session is designed for builders who want a shared baseline for developing reliable AI applications with OpenAI.
