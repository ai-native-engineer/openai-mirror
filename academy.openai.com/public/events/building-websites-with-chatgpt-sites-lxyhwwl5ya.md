# Building Websites with ChatGPT Sites

[Replay](https://academy.openai.com/home/videos/building-websites-with-chatgpt-sites-2026-07-17)

Have an idea you'd like to share online? Join us to learn how ChatGPT Sites can help you create a website for a personal project, small business, community group, portfolio, or anything else you're passionate about.

This session is open to everyone and does not require any previous experience with coding or web design. We'll walk through the process together and show how AI can help make building and publishing a website more accessible than ever. Download the ChatGPT desktop app before the session to follow along: <https://chatgpt.com/download/>
