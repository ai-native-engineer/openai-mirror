# Skill Labs

Project plans often start as scattered notes, meeting takeaways, loose goals, and open questions. In this hands-on lab, you will practice turning that messy starting point into an operating plan your team can actually use.

We will use AI to clarify the project goal, identify milestones, assign responsibilities, surface dependencies, name risks, and define the decisions that need owner input. You will also learn how to ask for a plan that stays reviewable, with assumptions, unresolved questions, and next steps clearly separated from confirmed information.

You will leave with a project planning prompt pattern and a reusable structure for turning early-stage work into a clear plan of action.
