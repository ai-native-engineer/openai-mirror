# Get the Most From the K-12 Educator Plugin

![Get the Most From the K-12 Educator Plugin](https://cdn.gradual.com/images/https://d2xo500swnpgl1.cloudfront.net/uploads/oaiacademy/k12-admin-61e4f7f9-7bb3-48a7-8e66-56194930723c-1785520011334.jpeg?fit=scale-down&width=1200)

## Prepare ChatGPT Work, model access, plugin settings, and credit limits so educators can create reviewable instructional materials for their classrooms.

![Get the Most From the K-12 Educator Plugin](https://cdn.gradual.com/images/https://d2xo500swnpgl1.cloudfront.net/uploads/oaiacademy/k12-admin-61e4f7f9-7bb3-48a7-8e66-56194930723c-1785520011334.jpeg?fit=scale-down&width=1200)

The K-12 Educator plugin is available in ChatGPT Edu workspaces, and admins can install it by default for approved educator RBAC groups. It helps educators create classroom-ready instructional materials, analyze classroom patterns, and draft family updates. Educators choose the classroom context, local standards, and approved sources, then review the results before using them in class. The plugin is available in ChatGPT Work and Codex; ChatGPT Work is the recommended place to begin. Admins should install the plugin for the appropriate educator groups, confirm Work access and plugin settings, set credit limits, test the experience, and encourage approved connected apps.

## Install the K-12 Educator Plugin for the Right Groups

Install the K-12 Educator plugin by default for approved teacher and instructional roles, such as classroom teachers, instructional coaches, curriculum leaders, library and media specialists, and educator-facing district staff.

Use existing role-based access control (RBAC) groups to install the K-12 Educator plugin for approved educator roles. Document any additional access restrictions required by district policy.

## Prepare ChatGPT Work and Plugin Access

### Confirm ChatGPT Work Access and Install the Plugins

* Confirm ChatGPT Work has not been disabled for the intended educator groups. Check that educators can open Work on desktop or web, use district-approved models, and have credit limits aligned with expected usage and district policy.

* Turn on “Allow members to use plugins & apps” for the workspace, then install the K-12 Educator plugin by default for approved educator RBAC groups.

### Confirm Plugin Availability and Installation

* Installed — an admin has installed K-12 Educator by default for an approved educator role or group, so its members can start using it immediately.

* Available — the plugin appears in the directory for the roles or groups your district selects, and each educator can choose to install it.

* For the smoothest launch, install K-12 Educator for approved educator groups; leave it available when educators should decide whether to install it themselves.

### Understand connected apps

* No connected apps are required to use K-12 Educator. Recommendation to educators to connect district-approved apps when doing so will help the plugin access relevant classroom materials or other approved context.

* When an educator chooses to connect an app, they may need to sign in and satisfy domain restrictions, OAuth scopes, provider-admin approval, and source-system permissions.

* App access is separate from plugin access: educators can retrieve only content they are already permitted to access in the connected school or work account.

## Test the Experience Before Launch

Before announcing the K-12 Educator plugin broadly, install it for the appropriate educator RBAC roles and groups:

* Confirm ChatGPT Work has not been disabled for the intended groups, approved models are available under your organization’s policies, and credit limits fit the launch scope.

* Confirm “Allow members to use plugins & apps” is enabled, then verify K-12 Educator is installed by default for the appropriate educator RBAC groups.

* Install the plugin by default for the appropriate RBAC groups; use Available when users should decide whether to install it themselves.

* Test in ChatGPT Work with an educator account from each intended role group. Have each account @mention the K-12 Educator plugin and create a small set of classroom-ready instructional materials.

* Encourage educators to connect approved apps when useful, and confirm they can still open and use the plugin without a connected app.

* Document any separate app-authentication, domain, or provider-admin steps users may encounter.

## If an Educator Cannot Get Started

First confirm ChatGPT Work has not been disabled, approved models and credits are available, and “Allow members to use plugins & apps” is enabled. Next, verify K-12 Educator is installed for the educator's RBAC group or available for self-installation. If a connected app does not open, review its authentication and source-system permissions.

## Pair Access With a First Classroom Use Case

Give educators one small, classroom-centered starting task: use a learning objective, grade level, local standards, educator notes, and one student-facing source to draft a lesson plan, slide outline, classroom activity, student handout, and formative check for educator review. Reinforce district policy, data minimization, and the separation of educator-only guidance from student-facing materials. Remind educators that source grounding improves relevance and traceability but does not guarantee accuracy, and that supported external actions require their approval.

## Recommended Admin Actions

* Prepare ChatGPT Work. Confirm Work access, approved model access, and credit limits appropriate to expected use and district policy.

* Enable and install the plugin. Turn on “Allow members to use plugins & apps,” then install K-12 Educator by default for the appropriate educator RBAC groups.

* Test the end-to-end experience. Use an educator account in ChatGPT Work to confirm @mention, launch, model access, credits, and optional-app behavior.

* Launch with a concrete classroom-materials use case and support guidance. Give educators one first instructional-materials task, the correct @mention, district policy reminders, and a support contact.
