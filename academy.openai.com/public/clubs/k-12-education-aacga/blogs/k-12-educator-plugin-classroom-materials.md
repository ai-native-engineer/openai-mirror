# Use the K-12 Educator Plugin to Create Classroom-Ready Instructional Materials

![Use the K-12 Educator Plugin to Create Classroom-Ready Instructional Materials](https://cdn.gradual.com/images/https://d2xo500swnpgl1.cloudfront.net/uploads/oaiacademy/k12-educator-v2-d9b5f005-64c9-41cc-b9a2-1c2e96250e70-1785796830595.jpeg?fit=scale-down&width=1200)

## Use the K-12 Educator plugin in ChatGPT Work or Codex, add your classroom context, and create instructional materials your students can use in class.

![Use the K-12 Educator Plugin to Create Classroom-Ready Instructional Materials](https://cdn.gradual.com/images/https://d2xo500swnpgl1.cloudfront.net/uploads/oaiacademy/k12-educator-v2-d9b5f005-64c9-41cc-b9a2-1c2e96250e70-1785796830595.jpeg?fit=scale-down&width=1200)

The K-12 Educator plugin helps educators create, adapt, and review classroom-ready instructional materials, including lesson plans, slides, handouts, activities, assignments, and formative checks. Educators provide the classroom context—such as grade level, learning objectives, local standards, and approved source materials—and review every instructional decision before using the materials with students. Use the plugin in ChatGPT Work or Codex.

## Best for

* Turning a learning objective, local standards, educator notes, and a student reading into a lesson plan, slide outline, in-class activity, and handout

* Turning a learning objective into an aligned assignment and rubric

* Adapting directions for clarity or learner access through differentiation without lowering expectations

* Building an interactive website or learning activity that helps students understand a complex topic

* Reviewing each school day's exit tickets to draft tomorrow's reteach, practice, and extensions for educator review

## Get Started

### 1. Open the K-12 Educator plugin from the plugin directory

Open the K-12 Educator plugin in the plugin directory. If your admin has made it available, install it before getting started; if your admin has already installed it for your role, open it directly in ChatGPT Work or Codex. Type @K-12 Educator to explore suggested classroom use cases.

### 2. Add your classroom context and optional connected apps

Select only the classroom sources that are relevant to your immediate task, and follow school or district guidance when adding student information.Add a useful source set: a learning objective, grade level, local standard, educator notes, student reading, assignment, or rubric.

You can also connect an appapplication through the plugin when one is available in your workspace. Open the plugin's available connected apps, choose the one that contains the classroom context you need, and follow the sign-in and permission steps. Availability depends on school or district workspace settings, your role, and account permissions.

A connected app is optional for these launch plugins. If one is not available or useful, continue with uploaded files, pasted text, or other approved classroom context. Connect only what you need and follow school or district policy.

### 3. Ask the plugin to support a concrete instructional task

Each prompt should name the classroom sources and local standards, the task you want help with—such as differentiated materials, an interactive activity, class analysis, or a family update—and any decisions you need to review.

## Starter prompts

### Prompt 1: Create instructional materials for an upcoming lesson

```
@K-12 Educator Use this Grade 7 learning objective, local standard, educator notes, and student reading to create a 50-minute lesson plan, a concise slide outline, an in-class activity, and a student handout for the ecosystem investigation. Keep the language age appropriate. Flag factual claims, accessibility decisions, and teaching choices I should review. Show me a preview before creating final files.
```

﻿

### Prompt 2: Review exit tickets and plan tomorrow’s instruction

```
@K-12 Educator Each school day, review the exit tickets in this approved folder and identify the concepts students understood, the misconceptions that need attention, and the students who may need more challenge. Draft tomorrow's reteach, practice, and extensions for my review, and do not share or publish anything without my approval.
```

﻿

## Use It Responsibly

* Follow school and district policies for AI use and protected information.

* Use the minimum student information needed for the task.

* Remove or avoid student-identifiable information whenever possible.

* Check content accuracy, age appropriateness, accessibility, and alignment.

* Review adaptations to make sure expectations and academic meaning are preserved.

* Make final decisions about instruction, feedback, assessment, and family communication yourself; source grounding improves relevance and traceability but does not guarantee accuracy.
