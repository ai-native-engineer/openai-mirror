# ChatGPT Edu: The Admin Plugin in Practice with a University Admin

Join Austin Blackwell, a ChatGPT Edu administrator at the University of South Carolina, for a conversation with fellow workspace admins. Through practical examples and live Q&A, Austin will share how his team uses the Admin Plugin for credit management and usage reporting, and the Admin API to automate approved requests.
