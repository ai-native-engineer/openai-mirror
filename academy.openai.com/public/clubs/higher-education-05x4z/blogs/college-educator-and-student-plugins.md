# Get the Most From the College Educator and College Student Plugins

## The College Educator and College Student plugins are available in ChatGPT Edu workspaces for higher education institutions; admins can install them by default for the appropriate RBAC groups.

![Get the Most From the College Educator and College Student Plugins](https://cdn.gradual.com/images/https://d2xo500swnpgl1.cloudfront.net/uploads/oaiacademy/higher-ed-admin-f8c50666-6ee3-43a1-aa01-381acfaed3ac-1785519991517.jpeg?fit=scale-down&width=1200)

The College Educator and College Student plugins are available in ChatGPT Edu workspaces for higher education institutions; admins can install them by default for the appropriate RBAC groups. The College Educator plugin helps faculty and other educators create instructional materials they can use in class, including lesson plans, slide outlines, handouts, and activities. The College Student plugin helps students create interactive study materials tailored to their courses, such as practice quizzes, flashcards, guided tutoring, and study plans. Users choose the relevant course context and remain in control. The plugins are available in ChatGPT Work and Codex; ChatGPT Work is the recommended place to begin.

The plugins are available by default. Admins should install College Educator and College Student for the appropriate RBAC groups, confirm ChatGPT Work and plugin access, set credit limits, test the experience, and encourage approved connected apps.

Start by confirming ChatGPT Work has not been disabled, turning on the workspace plugin setting, and installing each plugin for the appropriate RBAC roles and groups. Confirm that available models and credit limits align with institutional policy and expected use.

## Install the College Educator and College Student Plugins for the Right Groups

The College Educator and College Student plugins are available by default. Install each plugin for the RBAC groups that need it:

* College Educator plugin: faculty, educators, instructional designers, and other approved teaching-support roles

* College Student plugin: enrolled students and other approved learner roles

Use existing role-based access control (RBAC) groups to install College Educator for approved educator roles and College Student for approved student roles. Document any additional access restrictions required by institutional policy.

## Prepare ChatGPT Work and Plugin Access

### Confirm ChatGPT Work Access and Install the Plugins

* Confirm ChatGPT Work has not been disabled for the intended groups. Check that users can open Work on desktop or web, use institution-approved models, and have credit limits aligned with expected usage and institutional policy.

* Turn on “Allow members to use plugins & apps” for the workspace, then install each plugin by default for its intended educator or student RBAC groups.

### Confirm Plugin Availability and Installation

* Installed — an admin has installed the plugin by default for a designated role or group, so its members can start using it immediately.

* Available — the plugin appears in the directory for the roles or groups you select, and each user can choose to install it.

* For the smoothest launch, install College Educator for educator groups and College Student for student groups; leave a plugin available when users should decide whether to install it themselves.

### Understand connected apps

* No connected apps are required to use College Educator or College Student.

* We recommendEncourage users to connect approved apps, such as Google Drive, Gmail, or Calendar, when doing so will help the plugin access relevant course context.

* When a user chooses to connect an app, they may need to sign in and satisfy domain restrictions, OAuth scopes, provider-admin approval, and source-system permissions.

* App access is separate from plugin access: users can retrieve only content they are already permitted to access in the connected school or work account.

## Test the Experience Before Launch

Before announcing the plugins broadly, install each plugin for the appropriate RBAC roles and groups:

* Confirm ChatGPT Work has not been disabled for the intended groups, approved models are available under your organization’s policies, and credit limits fit the launch scope.

* Confirm “Allow members to use plugins & apps” is enabled, then verify College Educator and College Student are installed by default for their intended RBAC groups.

* Install the plugin by default for the appropriate RBAC groups; use Available when users should decide whether to install it themselves.

* Test in ChatGPT Work with one faculty account and one student account from the intended groups. Have each account @mention its plugin and create a small set of instructional materials or interactive study materials.

* Encourage users to connect approved apps when useful, and confirm they can still open and use each plugin without a connected app.

* Document any separate app-authentication or provider-admin steps users may encounter.

## Recommended Admin Actions

* Prepare ChatGPT Work. Confirm Work remains enabled, institution-approved models are available, and credit limits match expected use and institutional policy.

* Enable and install the plugins. Turn on “Allow members to use plugins & apps,” then install each plugin by default for the appropriate educator or student RBAC groups.

* Test the end-to-end experience. Use one faculty account and one student account in ChatGPT Work to confirm @mention, launch, model access, credits, and optional-app behavior.

* Launch with classroom-ready and interactive study use cases. Give educators a first instructional-materials task and students a first interactive-study task, along with the correct @mention, policy reminders, and a support contact.
