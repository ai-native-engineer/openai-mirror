# Use the College Educator Plugin to Create Instructional Materials for Your Classes

![Use the College Educator Plugin to Create Instructional Materials for Your Classes](https://cdn.gradual.com/images/https://d2xo500swnpgl1.cloudfront.net/uploads/oaiacademy/college-educator-v2-7b76c4cf-e6b5-41af-8e99-ceb0150fbd57-1785796632879.jpeg?fit=scale-down&width=1200)

## Use the College Educator plugin in ChatGPT Work or Codex, add the course context you choose, and create instructional materials you can review and use in class.

![Use the College Educator Plugin to Create Instructional Materials for Your Classes](https://cdn.gradual.com/images/https://d2xo500swnpgl1.cloudfront.net/uploads/oaiacademy/college-educator-v2-7b76c4cf-e6b5-41af-8e99-ceb0150fbd57-1785796632879.jpeg?fit=scale-down&width=1200)

The College Educator plugin helps faculty and other educators create classroom-ready instructional materials, including lesson plans, slide outlines, classroom activities, assignments, and student handouts. Educators choose the learning outcomes and course materials that should shape the result, then review and revise each draft before using it in class. The plugin is separate from College Student and does not transfer assignments or share course context with learners. Use it in ChatGPT Work or Codex.

A useful rule of thumb: start with the lesson, classroom activity, or set of instructional materials you need for an upcoming class. Choose the relevant course sources, ask for a reviewable draft, and make the academic decisions yourself.

## Best for

* Turning a syllabus, learning outcomes, and lecture notes into classroom-ready lesson plans, slide outlines, activities, and handouts

* Building an interactive website or learning activity that helps students understand a complex topic

* Adapting materials for learner access, mastery stage, language, localization, or engagement

* Analyzing course documents, slides, and student results to identify class strengths, common pitfalls, and improvements for the next class

* Updating class materials for a new term and carrying approved course context into the next instructional task

## Get Started in Three Steps

### 1. Open the College Educator plugin in ChatGPT Work or Codex

Open the College Educator plugin in the plugin directory. If your admin has made it available, select Install and start from the plugin page; if your admin has already installed it for your role, open it directly in ChatGPT Work or Codex. Type @College Educator to explore suggested use cases.

Choose one set of instructional materials you need for an upcoming class, such as a slide outline, classroom activity, assignment, or student handout.

### 2. Add your course context and optional connected apps

Add the smallest useful source set: a learning outcome, notes, assignment, rubric, reading, or results summary.

You can also connect an app (Google Drive, Outlook, Gmail, Calendar, etc.) through the plugin when one is available in your workspace. Open the plugin's available connected apps, choose the one that contains the context you need, and follow the sign-in and permission steps. Availability depends on your workspace settings, role, and account permissions.

A connected app is optional for these plugins. If one is not available or useful, continue with uploaded files, pasted text, or other approved course context. Connect only the sources needed for the task and follow institutional policy.

### 3. Ask the plugin to support a concrete instructional task

Each prompt should name your course sources, the instructional materials you want to use in class, relevant learning outcomes, important constraints, and any decisions you need to review.

## Starter prompts

### Prompt 1: Create a 50-minute class plan

```
@College Educator Use this syllabus, these learning outcomes, and my lecture notes to create a 50-minute class plan, a concise slide outline, an in-class activity, and a student handout. Explain how each material supports the learning outcomes, flag teaching choices and assumptions I should review, and show me a preview before creating final files.
```

﻿

### Prompt 2: Analyze class strengths and improve the class plan

```
@College Educator Use my course documents, slides, and student results to identify class strengths and common pitfalls. Recommend concrete improvements to the 50-minute class plan and materials for my next class, flag assumptions and student-data concerns, and wait for my approval before creating or sharing final files.
```

﻿

### Prompt 3: Build an interactive website for a complex topic

```
@College Educator Use this learning outcome, assigned reading, and course materials to build an interactive website that helps students understand [complex topic]. Include a short explanation, an interactive activity, checks for understanding, and accessible design. Show me a preview and wait for my approval before creating or sharing final files.
```

﻿

## Start Small and Build From What Works

Keep the first set of instructional materials small enough to review in one pass. Check that the result:

* Connects clearly to the course context you supplied

* Distinguishes source material from generated suggestions

* Makes assumptions and review points visible

* Preserves disciplinary accuracy and intended learning outcomes

* Is easy to revise before it becomes student-facing

Use your course documents, slides, and student results to identify class strengths and common pitfalls, then draft improvements to the next class. Review the analysis yourself; do not hand over final grading, exception, or publication decisions.

## Use It Responsibly

* Follow institutional policy for student work and protected information.

* Use the minimum student data needed for the task.

* Remove or avoid student-identifiable information when possible.

* Check disciplinary accuracy, accessibility, workload, and alignment.

* Keep answer keys and educator-only guidance separate from student-facing materials.

* Review and revise generated outputs, make final decisions about teaching, feedback, grades, and publication yourself, and approve any supported external action before it happens.
