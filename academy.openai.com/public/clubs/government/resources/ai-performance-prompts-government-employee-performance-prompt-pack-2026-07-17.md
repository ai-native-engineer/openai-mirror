# Government Employee Prompt Pack

*Self reviews, feedback, 1:1s, career planning, goal setting, development, and internal mobility.*

Use ChatGPT Work as a reflection partner. Bring your notes, feedback, goals, and artifacts. Ask it to organize evidence, find gaps, and draft language you can edit in your own voice.

# Writing self reviews

USE WHEN

Turn notes, projects, and wins into a clear narrative.

PROMPT

Help me write a self review from these notes. Group my work into impact themes, convert key

examples into STAR format, identify outcomes versus activity, and draft concise language that

sounds like me. Flag claims that need stronger evidence.

# Asking for feedback

USE WHEN

Request feedback that is specific and easy to answer.

PROMPT

Draft a feedback request to [manager/peer/stakeholder] about [project or behavior]. Ask for one

strength, one improvement area, one example they noticed, and one suggestion for my next level of

growth.

# Preparing for 1:1s

USE WHEN

Make a useful agenda instead of a status update.

PROMPT

Turn these notes into a 1:1 agenda. Include decisions I need, blockers, progress since last meeting,

feedback to ask for, career topics to raise, and one clear ask. Put the highest-priority items first.

# Career planning

USE WHEN

Think beyond the next review cycle.

PROMPT

Use my interests, strengths, feedback, and recent projects to suggest three possible career

directions. For each path, list why it fits, skills to build, evidence I need, and the manager

conversation to have.

# Goal setting

USE WHEN

Connect your work to measurable outcomes.

PROMPT

Convert these priorities into SMART goals for the next quarter. For each goal, include success

metrics, stakeholders, risks, first milestones, and a weekly reflection question to track progress.

# Development plans

USE WHEN

Build a concrete path for one skill or behavior.

PROMPT

Create a 30-60-90 day development plan for [skill or behavior]. Include practice opportunities,

resources, feedback loops, manager support to request, and evidence I can collect to show progress.

# Internal mobility prompts

USE WHEN

Explore a new role, team, or function.

PROMPT

Compare my experience to this internal role description. Identify transferable strengths, gaps,

examples to highlight, questions for the hiring manager, and a short internal mobility pitch that is honest and specific.
