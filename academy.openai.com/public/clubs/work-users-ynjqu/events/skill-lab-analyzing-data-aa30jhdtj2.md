# ChatGPT for Work

# Portfolio Company Knowledge Work

Data is most useful when it helps someone make a decision. In this hands-on Skill Lab, you’ll use ChatGPT to inspect a spreadsheet, frame a focused business question, explore meaningful patterns and comparisons, and turn the findings into a clear, shareable readout.

We’ll practice spotting data-quality issues, choosing charts that support the question, separating evidence from interpretation, and checking calculations, assumptions, and caveats before acting. You’ll also see how the same workflow can support inventory reviews, budget variance, campaign analysis, customer feedback, and other common workplace decisions.

Bring a spreadsheet tied to a real decision, or follow along with a sample. You’ll leave with a reusable structure for a concise analysis that includes key findings, charts, caveats, recommended actions, and next checks.
