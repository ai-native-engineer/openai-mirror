# Get started with ChatGPT Work: webinar resource guide

Use this guide to remember the core ideas from the webinar and recreate the two demos. Access to Work, Plugins, connected apps, Scheduled Tasks, Projects, and Skills can vary by plan and workspace settings. If you cannot use one of the tools shown, use an equivalent tool approved by your organization or upload a file with the same kind of information.

Practice with the synthetic files in this guide or in a ChatGPT workspace approved by your organization. Do not connect company email, calendars, messages, or files to a personal account unless your organization permits it.

## The ideas to keep

| Use | When you need |
| --- | --- |
| **Chat** | A quick answer, a brainstorm, a rewrite, or help with one part of a task |
| **Work** | ChatGPT to gather context, complete several steps, and create a finished result you can review |
| **Codex** | Software development or technical work involving code, repositories, testing, or debugging |

* Describe the result you want. Give Work the goal, trusted sources, constraints, output format, and review standard. You do not need to prescribe every step.

* Choose based on the job, not the file type or length. One focused question about a long report can still be a Chat task.

* A longer task may take longer to finish. You can follow its progress, answer questions, or change direction while it works.

* When the format matters, provide a template, example, brand guide, or other concrete standard.

* Finished work still needs human review. Check the facts, calculations, sources, judgment, and final format before you share or rely on it.

* Test a workflow before you repeat it. Once the result works, schedule recurring jobs or save the approach as a Skill.

## Demo 1: Build a daily work brief

### What to remember

This workflow turns scattered information from your calendar, email, and team messages into one prioritized plan. It also shows the difference between asking Chat for a quick answer and giving Work a complete assignment.

### Before you start

Connect the tools that hold your work:

* Google Workspace + Slack: Google Calendar, Gmail, Google Drive, and Slack

* Microsoft tools: Outlook Calendar, Outlook Email, SharePoint, and Microsoft Teams

Your organization may use a different combination. Workspace administrators control which Plugins, apps, data, and actions are available.

### Recreate it

1. Start in **Chat** and ask:

```
What meetings do I have today, and what should I prioritize?
```

Chat should return a useful answer quickly. This is a good fit when you want one focused answer.

2. Start a new chat, choose **Work**, and paste:

```
Review my calendar, email, and Slack. Identify anything that needs my attention today, including conflicts, deadlines, decisions, and follow-ups.

﻿

Create a Google Doc with a prioritized plan for my day, with the most important items first. For each item, include a direct link to the relevant calendar event, email thread, or Slack conversation.

﻿

Then send me a short summary in Slack with a link to the document.
```

If you use Microsoft tools, replace the app and output names in the prompt.

In this example, “send me” means a Slack direct message to yourself. Review the summary, choose the right destination if you change it, and approve the send when prompted.

3. While Work is running, add:

```
List my top three priorities at the top of the document.
```

4. Review the completed brief. Open a few source links and confirm that the priorities, deadlines, and conflicts are accurate.

5. After you are happy with one run, make it recurring:

```
Schedule this task to run every weekday at 7:30 a.m.
```

You can view, edit, pause, or delete recurring work from **Scheduled** in the sidebar.

## Demo 2: Turn quarterly results into a leadership presentation

### What to remember

Projects keep related Chat and Work chats, files, and instructions together. A template shows Work what the finished file should look like. Your review and corrections capture the unwritten rules that a formal brand guide may miss.

### Sample inputs

Use your own materials or download these example files:

﻿ <https://docsend.com/view/s/tg6ev96bqfasddd8>﻿

For the presentation template, use your organization’s slide template. If you do not have one, choose a suitable business review template from the **Default templates** Plugin.

### Recreate it

1. Create a Project called **Q2 Performance**.

2. Add the four sample files above, plus a presentation template if you have one.

3. Start a **Chat** conversation inside the Project and ask:

```
Review the quarterly goals and results in this Project. What were our biggest wins and misses, and what should I emphasize in a leadership presentation?
```

Use this when you need a quick summary.

4. Start a new chat inside the same Project, choose **Work**, and paste:

```
Create a Q2 performance lookback presentation for our leadership team.

﻿

Review the Q2 goals, Q2 performance results, and Q2 team updates in this Project. Compare our goals with our actual results. Identify the biggest wins and misses, and explain what drove them.

﻿

Build the presentation in Google Slides using our corporate presentation template and brand guide. If no company template is available, use a suitable business review template. Make the story clear, use charts where they help, and include the decisions or actions leadership should take next.

﻿

Only make claims supported by the source material. Cite every number and flag anything that needs verification.
```

If your Slack app is connected, you can replace the uploaded team updates with: “the relevant messages in the  `#q2-performance-updates`  Slack channel.”

5. Check a prominent number or conclusion:

```
Where did the [number or claim] on slide [slide number] come from? Show me the exact source. If you calculated it, show me the calculation. Link me directly to the source.
```

Open the source and verify it yourself.

6. Give Work your organization’s unwritten preferences. For the sample deck, use:

```
Please revise the presentation with these additional company preferences:

﻿

- Remove the table of contents slide.

- Put the main recommendation near the beginning.

- Show percentages with one decimal place and headcount as whole numbers.

- Put citations in footnotes.

- Use red only when something is genuinely off track.

- Use “customers” instead of “accounts.”

﻿

Keep following the corporate presentation template and brand guide.
```

7. Review the revised deck. Check the sources, numbers, story, recommendations, branding, and slide legibility.

8. Once the workflow produces a result you trust, save it as a Skill:

```
Create a Skill called company-presentation-builder based on the workflow we just completed.

﻿

Include our corporate presentation template and brand guide as reusable resources. Save the additional preferences I gave you about structure, number formatting, citations, color, and terminology.

﻿

Use this Skill whenever I ask ChatGPT to create or revise a company presentation. Only use information supported by the source material, and flag anything that needs verification.
```

Review the generated Skill, answer any follow-up questions, and install it when prompted. Test it on a new presentation before you share or rely on it.

Skills can be found under **Plugins > Skills**. Depending on your workspace settings, you may also be able to edit or share them.

## Find your first Work task

If you are not sure where to begin, ask Work to suggest a useful starting point:

```
Look at my recent work across my connected tools. Suggest three specific tasks that would be good fits for ChatGPT Work, tell me what you could create for each one, and recommend where I should start. Don’t begin until I choose.
```

Choose one task you already understand and need to finish. Start small enough that you can check the result carefully.
