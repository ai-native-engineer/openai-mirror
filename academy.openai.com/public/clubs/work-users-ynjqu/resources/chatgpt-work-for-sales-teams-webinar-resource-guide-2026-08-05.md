## Follow along with our webinar: ChatGPT Work for sales teams

Sales work rarely lives in one place. Opportunity data may sit in a CRM or spreadsheet, recent activity in call notes and email, and account strategy in a presentation. This webinar shows how Chat and Work complement each other across that work.

You’ll see Chat answer focused questions quickly, then see Work gather context, apply a repeatable sales process, and create finished files you can review: a prioritized deal brief and a strategic account plan presentation.

> **Note:** Some exercises require sample files and access to ChatGPT Work, Plugins, Google Workspace, and Slack. Availability depends on your plan and workspace settings. Use only data your organization allows, and review every output before acting on it, sharing it, contacting customers, or updating a CRM.

## Learn: When to use Chat and when to use Work

### Key ideas

* Use Chat when you need a fast answer, want to talk through an idea, or need help with one focused piece of work.

* Use Work when ChatGPT needs to gather context, work through several steps, and create a finished result.

* Choose based on the job—not the size or type of the file.

* Work can take longer because it is doing more. You can follow along, steer it while it works, or come back when the result is ready.

* You are still responsible for reviewing the facts, recommendations, and any action that affects a customer or system of record.

## Learn: Find and use the Sales plugin

The Sales plugin can use available context to help prepare account plans, meeting briefs, outreach, follow-ups, and pipeline summaries. Its connectors bring in context from approved tools such as a CRM, while its skills provide reusable instructions and resources for common sales tasks.

### Follow along

1. Open **Plugins** from the left sidebar.

2. Search for **Sales** and open the plugin. If it is available in your workspace, install or connect it as directed.

3. Review its connectors and skills, then find **Prioritize accounts**.

4. Return to the conversation, switch to Work, type  `@Sales` , and select the Sales plugin.

## Demo 1: Get a quick pipeline answer in Chat

Chat is useful when you need one focused answer from a spreadsheet and want it quickly. A quick answer can help you orient, but it is different from a complete prioritization workflow that weighs multiple sources and creates a finished brief.

### Follow along

Download the sample pipeline spreadsheet:  <https://docsend.com/view/s/kdjharyvscw2x54k>﻿

Start a new Chat, attach the sample spreadsheet, and use this prompt:

```
Looking at my open opportunities, which deals need my attention today? Give me the key details.
```

## Demo 1: Create and schedule a prioritized deal brief in Work

Work can compare opportunity details, recent activity, forecast notes, and stage criteria; rank the deals; create a Google Doc; and send a Slack summary. The task stays bounded: the prompt explicitly says not to contact customers or update the CRM.

### Follow along

Start a new Work task, invoke  `@Sales` , and use this prompt:

```
@Sales Review my open opportunities and decide where I should focus today.

﻿

Create a Google Doc. Rank the opportunities and include why each one needs attention, the supporting evidence, and the recommended next action. Use only information supported by the source.

﻿

Then send me a short summary in Slack with a link to the document. Do not contact customers or update the CRM.
```

While Work is running, steer the task without restarting it:

```
Include a section for each opportunity called “What I need to validate”.
```

After you review the result, schedule the same workflow:

```
Schedule this task to run every weekday at 7:30 a.m.
```

### What to review

* Does the ranking explain why each opportunity needs attention now?

* Can you trace each recommendation to supporting evidence?

* Are missing, stale, or inconsistent details called out instead of invented?

* Does the scheduled task create a fresh brief and deliver the summary where you expect it?

## Demo 2: Create a Project for a strategic account plan

A Project gives Chat and Work the same durable set of account materials, so you can ask a quick question or hand off the full presentation without uploading the sources again.

### Follow along

Download the Acme strategic account plan sample pack:  <https://docsend.com/view/s/kdjharyvscw2x54k>﻿

1. Create a Project called **Acme Strategic Account Plan**.

2. Add the account context spreadsheet, source packet, and presentation template.

3. Start a new Chat inside the Project and use this prompt:

```
What should I know about Acme before the account strategy review? What are the biggest opportunities and risks?
```

## Demo 2: Build a strategic account plan presentation in Work

Describe the finished result instead of scripting every research question, slide, and intermediate step. Give Work the same source materials and starting template you would use yourself, and ask it to ground claims in the source material.

### Follow along

Start a new Work task inside the Acme Project and use this prompt:

```
Create a strategic account plan presentation for an internal account review of Acme.

﻿

Explain what we know about the account, where the opportunities stand, what’s at risk, and how we should move forward. Use only information supported by the source material, and flag anything that still needs validation.

﻿

Build the presentation using the Acme Strategic Account Plan Template. Make the story clear, use charts or tables where they help, and include the actions we should take next.
```

When the presentation is ready, verify a material claim. Replace the bracketed text with a claim from your deck:

```
Where did the claim that [PASTE A CLAIM FROM THE PRESENTATION] come from? Show me the exact source and link me directly to it.
```

Then revise the deck with the company-specific preferences from the webinar—or replace these with your own:

```
Please revise the presentation with these company preferences:

﻿

- Remove the table of contents slide.

- Put the main recommendation right up front.

- Use the exact CRM stage names for open opportunities.

- Clearly label assumptions and missing information.

- Put citations in footnotes.

- Use red only for genuine deal risks or blockers.

- Use “customers” instead of “accounts” in leadership presentations.

﻿

Keep following the Acme account plan presentation template.
```

### What to review

* Does the deck use the template’s typography, colors, layouts, and chart styles?

* Are the opportunities, risks, stakeholders, and next actions consistent with the source materials?

* Are assumptions and missing information clearly labeled?

* Can you open the exact source behind a material claim and confirm that it supports the conclusion?

## Demo 2: Turn the account-plan workflow into a reusable skill

Test and refine the workflow first. Then save the version that actually works. A skill can preserve the template, company preferences, grounding rules, and review expectations for future account plans.

After you approve the revised deck, use this prompt:

```
Create a skill called strategic-account-plan-builder from this workflow. Include the Acme account plan presentation template and the preferences I gave you. Use it for future strategic account plan presentations, ground every claim in the source material, and flag anything that needs verification.
```

## Learn: Chat or Work?

* **Customer annual-report takeaways needed in five minutes → Chat.** One focused question; one fast answer.

* **Reconcile a pipeline report with CRM notes and build a clean forecast workbook → Work.** Several steps, careful checking, and a finished workbook.

* **Use CRM data, call notes, and account research to create an account strategy brief → Work.** Multiple sources, judgment, and a polished artifact.

* **Improve one customer follow-up email → Chat.** One small task with quick back-and-forth.

## Try it: Find your first Work task

You do not need to invent the perfect workflow before you begin. Ask Work to look at the work you are already doing, suggest a few good candidates, and wait for your choice.

```
Look at my recent work across my connected tools. Suggest three sales tasks that would be good fits for ChatGPT Work, tell me what you could create for each one, and recommend where I should start. Don’t begin until I choose.
```

## Before you use the output

* Use only approved data and connected sources.

* Check customer, opportunity, and pipeline facts against the appropriate system of record.

* Verify material claims, recommendations, calculations, and citations before sharing.

* Keep customer outreach, CRM updates, and other external actions as drafts until a person reviews and approves them.

* Follow your organization’s AI, privacy, security, and records-management policies.

## What to try next

Choose one sales task that is already on your plate. Start with a clear goal, give Work the sources and constraints it needs, ask for a reviewable artifact, and refine the result. If the workflow proves useful, schedule it or save it as a skill so the next run starts from what you learned.
