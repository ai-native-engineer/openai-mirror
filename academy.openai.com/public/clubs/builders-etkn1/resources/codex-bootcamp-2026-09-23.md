## **Series overview**

Join OpenAI Academy for a three-part live series designed for developers and technical teams using Codex. Register for individual sessions or follow the full progression from agentic coding fundamentals to advanced automation.

## **Agenda / Sessions**

Join us each week for a new topic, with all sessions running live from 10:00–11:00 AM PT.

#### **September 23 | Codex bootcamp 101: Agentic coding**

* Learn how to scope tasks, provide effective context, steer work, and review code changes using Codex.

#### **September 30 | Codex bootcamp 201: Team workflows**

* Set up Codex for shared context, approvals, reusable skills, tool connections, and repeatable team workflows.

#### **October 7 | Codex bootcamp 301: Advanced automation**

* Scale Codex with sub-agents, permissions, the Codex SDK, and production-ready automation patterns.
