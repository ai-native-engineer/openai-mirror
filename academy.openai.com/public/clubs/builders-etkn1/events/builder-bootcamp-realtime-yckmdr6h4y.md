# Portfolio Company SDLC

In this session, you’ll learn how to design and build realtime voice agents using the OpenAI Realtime API. We’ll cover when voice is the right fit, how to choose between speech-to-speech and chained architectures, and how to handle interruption, turn-taking, and tool calling.

You’ll also explore a practical customer support workflow, including identity verification, guardrails, action confirmation, tracing, and evaluation. This session is geared toward builders creating responsive, reliable voice experiences with OpenAI.
