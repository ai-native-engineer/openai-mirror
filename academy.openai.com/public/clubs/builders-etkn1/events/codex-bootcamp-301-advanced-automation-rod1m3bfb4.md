# Codex bootcamp 301: Advanced automation

# Developers & Builders

# Codex

# OpenAI API

# Advanced & Builder Skills

Learn how to scale Codex for advanced automation and production development workflows. We’ll cover permissions and sandboxing, sub-agents, plan mode, memory, writable roots and execution rules, the Codex SDK, and Codex exec.

This advanced session is designed for experienced builders ready to integrate Codex into CI, security, and code-review workflows. You’ll leave with practical patterns for building reliable automation, engineering effective harnesses, and establishing scalable Codex architecture.
