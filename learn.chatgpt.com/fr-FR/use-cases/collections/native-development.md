# Développement natif

Codex donne d’excellents résultats sur les projets pour les plateformes Apple lorsque chaque itération comprend un cycle de compilation, d’exécution ou de test dans le simulateur.
Ces cas d’utilisation vous seront utiles pour développer des applications iOS et macOS, nouvelles ou existantes, lorsque vous devez faire évoluer l’interface utilisateur et résoudre des problèmes.

## Créez la structure de base de l’application

Demandez à Codex de générer la structure initiale d’applications iOS et macOS, avec des cycles de compilation reproductibles. Le cas d’utilisation consacré à la structure de base d’une application Mac approfondit les dispositions avec barre latérale, vue détaillée et inspecteur, ainsi que les commandes, les paramètres et d’autres structures propres aux applications de bureau.

## Refactorisez les écrans SwiftUI sous iOS

Utilisez Codex pour scinder les vues SwiftUI volumineuses sans modifier leur comportement, puis migrez certains parcours iOS vers Liquid Glass lorsque l’application est prête.

## Exposez les actions iOS au système

Utilisez Codex pour déterminer les actions et les entités que votre application doit exposer via App Intents, afin que les utilisateurs puissent accéder aux fonctionnalités de l’application depuis les interfaces du système.

## Déboguez votre application

Demandez à Codex de reproduire les bugs dans Simulator ou d’ajouter de la télémétrie à votre application macOS pour vous aider à diagnostiquer et à corriger les problèmes.
