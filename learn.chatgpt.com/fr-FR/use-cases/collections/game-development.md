# Développement de jeux vidéo

Associé à la génération d’images, Codex est particulièrement efficace pour créer des jeux dans le navigateur ainsi que d’autres types de jeux.
Ces cas d’utilisation vous aideront à transformer vos idées en jeux fonctionnels.

## Créez une première boucle de gameplay jouable

Demandez à Codex de transformer le brief d’un jeu en une version jouable dans le navigateur, avec ses ressources, ses commandes et une boucle de gameplay que vous pouvez tester.

## Peaufinez l’interface et les commandes

Une fois le jeu opérationnel, utilisez Codex pour ajuster les détails du HUD, les menus et les commandes, et corriger les problèmes d’interaction mineurs.

## Traitez les aspects complexes de la logique du jeu

Utilisez Codex pour améliorer de manière itérative des algorithmes de jeu complexes à l’aide d’une boucle d’auto-évaluation.

## Priorisez les bugs à partir de signaux réels

Utilisez Codex pour regrouper les rapports de bugs, les vérifications ayant échoué, les logs et les notes de reproduction dans une liste classée par priorité avant qu’il ne corrige le jeu.

## Révision avant la fusion

Utilisez Codex dans GitHub pour réviser automatiquement les PRs et détecter les régressions ainsi que les tests manquants afin d’accélérer le déploiement.
