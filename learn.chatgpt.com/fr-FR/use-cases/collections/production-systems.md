# Systèmes en production

Les cas d’utilisation de cette collection sont utiles lorsque Codex travaille dans un dépôt qui possède déjà un historique, des tests, des responsables et des contraintes de production.
Codex est particulièrement efficace pour parcourir les bases de code complexes, notamment les vastes monorepos comprenant de nombreux services et dépendances.
Si vous travaillez sur un système en production, familiarisez-vous avec ces cas d’utilisation pour comprendre comment Codex peut vous aider.

## Commencez par faire le tour de la base de code

Utilisez Codex pour vous familiariser avec une base de code complexe, ce qui est particulièrement utile quand vous prenez en main le dépôt d’un logiciel en production.

## Modernisez la base de code

Appuyez-vous sur Codex pour planifier les migrations de votre stack technique, mettre à niveau votre intégration afin d’utiliser les modèles les plus récents le cas échéant, et refactoriser la base de code pour en améliorer la lisibilité et la facilité de maintenance.

## Formalisez les processus récurrents

Demandez à Codex de transformer les flux de travail ou les listes de contrôle propres au dépôt en un skill, afin que toutes les personnes contribuant au dépôt puissent bénéficier d’un processus standardisé.

## Tenez la documentation à jour

Demandez à Codex de comparer les modifications du code source à la documentation existante, d’apporter à celle-ci le minimum de mises à jour utiles, puis de vérifier les changements.

## Veillez au bon fonctionnement du système

Utilisez Codex depuis Slack et connectez-le à vos systèmes d’alerte et de suivi des tickets, ainsi qu’à vos revues quotidiennes des bugs, pour qu’il prenne automatiquement en charge les demandes de fonctionnalités et les corrections de bugs.

## Évitez que les revues de code ne deviennent un point de blocage

Utilisez Codex pour automatiser la revue de code des PRs et mener des contrôles qualité ciblés sur les parcours critiques, afin de repérer rapidement les problèmes et de déployer vos mises à jour en toute confiance.
