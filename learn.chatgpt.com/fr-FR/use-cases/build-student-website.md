## Définissez le périmètre d’une première version utile

Prenez comme point de départ le public cible, la tâche principale que le site doit permettre d’accomplir et les contenus dont vous disposez déjà. Ajoutez des exemples, des préférences en matière de design, des exigences d’accessibilité et des critères de réussite clairs.

Veillez à ce que le périmètre initial soit suffisamment restreint pour pouvoir créer et tester le site en une seule itération.

## Créez et examinez le site

Dans Sites, utilisez le prompt de démarrage pour :

- organiser le contenu fourni
- définir une architecture de l’information simple
- créer les pages et les interactions essentielles
- utiliser des mises en page adaptatives
- vérifier la navigation au clavier, les libellés et le contraste
- tester le parcours principal avec du contenu représentatif

Examinez l’aperçu local avant de publier le site. Vérifiez que les textes, les images, les liens, les formulaires et les données proviennent de sources approuvées.

## Préparez le partage

Demandez à ChatGPT une liste de contrôle avant publication couvrant les contenus manquants, les autorisations, la confidentialité, l’accessibilité et les tests finaux. Si le site recueille des soumissions, vérifiez où les données sont envoyées et qui peut y accéder.

Ne publiez la version révisée qu’après avoir obtenu l’approbation de la personne responsable du projet ou de l’enseignant concerné.
