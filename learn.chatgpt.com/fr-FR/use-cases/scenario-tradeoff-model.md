## Établissez une base commune pour comparer les options

Il est plus facile d’examiner les scénarios lorsque toutes les options reposent sur les mêmes hypothèses et critères de décision. Avant que ChatGPT n’établisse la comparaison, fournissez-lui le modèle, le contexte des KPI, les documents de planification, les données opérationnelles et les contraintes des parties prenantes.

1. Précisez la décision, les options, l’horizon temporel et les critères.
2. Joignez les modèles, les tableaux de bord, les documents de planification, le contexte du marché et les données opérationnelles.
3. Demandez à ChatGPT d’identifier les hypothèses communes, spécifiques à chaque option ou manquantes.
4. Exécutez le prompt initial, puis examinez les coûts, les délais, les risques, les responsables et l’impact sur les clients.
5. Modifiez explicitement les hypothèses et comparez la recommandation d’un scénario à l’autre.

Conservez le modèle source intact et enregistrez séparément les résultats de chaque scénario. Le résultat le plus utile ne se limite pas à une recommandation : il explique aussi clairement quelles hypothèses, si elles changeaient, modifieraient cette recommandation.

## Testez la sensibilité

Demandez à ChatGPT de faire varier les hypothèses les plus déterminantes et d’indiquer dans quelles conditions une autre option devient préférable.
