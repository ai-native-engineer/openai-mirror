## Introduction

ChatGPT est très efficace pour nettoyer méthodiquement des données tabulaires.
Lorsqu’un fichier CSV ou une feuille de calcul contient des dates dans plusieurs formats, des lignes en double, des valeurs monétaires au format texte, des cellules vides, des alias ou des lignes récapitulatives copiées-collées, demandez à ChatGPT d’en nettoyer une copie sans modifier le fichier d’origine.

## Utilisation

1. Faites glisser le fichier dans ChatGPT ou mentionnez-le dans votre prompt, par exemple `@customer-export.csv`.
2. Décrivez les problèmes que vous avez déjà repérés.
3. Indiquez à ChatGPT le format souhaité pour la version nettoyée : fichier CSV, onglet de feuille de calcul ou fichier prêt à être importé.
4. Vérifiez la copie nettoyée avant de l’utiliser.

Utilisez le prompt de démarrage de cette page pour effectuer un premier nettoyage. Remplacez le nom du fichier et le contenu des puces par vos propres informations. Les informations utiles sont les problèmes que vous avez déjà repérés et le type de fichier dont vous aurez ensuite besoin : un fichier CSV nettoyé, un onglet de feuille de calcul nettoyé ou un fichier prêt à être importé. Une fois que ChatGPT a généré la copie nettoyée, ouvrez dans la discussion le fichier nettoyé et la note sur la qualité des données avant d’utiliser ces données dans les étapes de traitement suivantes.
