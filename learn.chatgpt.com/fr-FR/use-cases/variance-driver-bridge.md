## Introduction

Un tableau d’analyse des écarts relie une variation constatée aux facteurs opérationnels qui l’expliquent. ChatGPT peut rapprocher le réalisé, le budget, les prévisions, les données des KPI et les notes des responsables, puis classer les facteurs et distinguer les explications étayées des questions auxquelles un responsable doit encore répondre.

## Choisissez la comparaison

Définissez les périodes et les versions à comparer, par exemple les prévisions par rapport au réalisé, le budget par rapport au réalisé ou les prévisions actuelles par rapport aux précédentes. Indiquez le seuil de matérialité, les conventions de signe et les postes financiers pertinents pour cette révision.

1. Joignez les données du réalisé, le budget, les prévisions, les données des KPI et les notes des responsables.
2. Définissez la comparaison, le seuil de matérialité et les postes financiers requis.
3. Lancez le prompt de départ et demandez un classeur modifiable contenant le tableau d’analyse des écarts.
4. Vérifiez les écarts entre les sources, les conventions de signe et le classement des facteurs.
5. Poursuivez dans la même discussion pour traiter les questions à adresser aux responsables et préparer les commentaires.

## Mettez les explications à l’épreuve

Les commentaires sur les facteurs explicatifs doivent s’appuyer sur ce que montrent les sources. Lorsque les fichiers sources révèlent une variation sans en établir la cause, demandez à ChatGPT d’indiquer clairement que l’explication proposée n’est qu’une hypothèse.
