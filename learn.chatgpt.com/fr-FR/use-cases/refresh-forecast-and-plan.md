## Introduction

Une mise à jour des prévisions doit indiquer les hypothèses qui ont changé et les effets de ces changements sur le plan. ChatGPT peut mettre à jour un modèle modifiable, élaborer des scénarios comparables et synthétiser les analyses de sensibilité et les seuils de déclenchement que la direction doit examiner.

## Préparez les données de planification

Joignez le modèle opérationnel, les derniers résultats réels, les hypothèses approuvées, les contributions des responsables et les prévisions précédentes. Ajoutez le calendrier de planification et les règles relatives aux scénarios, puis indiquez les hypothèses que ChatGPT ne peut mettre à jour qu’après approbation.

1. Joignez le modèle opérationnel et les fichiers complémentaires contenant les facteurs clés.
2. Ajoutez les derniers résultats réels, les hypothèses approuvées, les contributions des responsables et les prévisions précédentes.
3. Définissez les règles des scénarios de référence, favorable et défavorable, ainsi que les hypothèses protégées.
4. Exécutez le prompt de démarrage et demandez un classeur de prévisions modifiable.
5. Examinez les modifications apportées aux hypothèses, les liens entre les formules, les analyses de sensibilité et les éléments soumis à approbation.
6. Poursuivez dans la même discussion pour ajuster un facteur à la fois.

## Comparez les scénarios

Une bonne planification de scénarios permet de vérifier facilement les écarts. Laissez le scénario de référence visible et montrez que chaque scénario découle d’un petit nombre de modifications explicites apportées aux facteurs clés.
