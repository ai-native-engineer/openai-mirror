## Comment l’utiliser

1. Installez l’application Slack, connectez les dépôts et environnements appropriés, puis ajoutez `@Codex` au canal.
2. Mentionnez `@Codex` dans un fil de discussion en indiquant clairement votre demande, les contraintes et le résultat souhaité.
3. Ouvrez le lien vers la discussion, examinez le résultat, puis poursuivez les échanges dans Slack si la tâche nécessite une nouvelle itération.

Pour en savoir plus sur l’utilisation de Codex dans Slack, consultez le [guide dédié](/fr-FR/codex/third-party/slack).

## Conseils

- Si le fil ne fournit pas encore assez de contexte ou ne propose pas de correctif, ajoutez des indications dans votre prompt
- Assurez-vous que l’association entre le dépôt et l’environnement est correcte en mentionnant le nom du projet ou de l’environnement dans votre prompt
- Délimitez la demande afin que Codex puisse la mener à bien sans second cycle de planification
- Si le code source de votre projet est volumineux, guidez Codex en indiquant les fichiers ou dossiers pertinents pour la tâche
