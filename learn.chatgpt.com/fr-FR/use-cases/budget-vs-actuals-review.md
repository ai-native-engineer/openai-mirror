## Introduction

Si vous travaillez sur un budget et souhaitez examiner les écarts ou détecter d’éventuels problèmes, ChatGPT peut vous aider à créer un classeur de révision pleinement fonctionnel que vous pourrez exploiter.

Joignez le budget prévisionnel, l’export des données réelles et les notes de clôture, puis demandez à ChatGPT de créer un classeur de révision modifiable. ChatGPT peut conserver les données brutes, affecter les données réelles aux postes budgétaires, calculer les écarts et créer une vue de synthèse que vous pourrez examiner dans la discussion.

## Créez le classeur de révision

1. Joignez le budget prévisionnel, l’export des données réelles et les notes de clôture, ou fournissez les références exactes des fichiers ainsi que leur source.
2. Exécutez le prompt de départ et demandez un classeur `.xlsx` modifiable.
3. Ouvrez le classeur dans ChatGPT. Affichez-le en plein écran pour examiner les données brutes, les correspondances, les formules de calcul des écarts et l’onglet de synthèse.
4. Poursuivez dans la même discussion pour corriger l’affectation des catégories, ajouter des ventilations par département ou rédiger la synthèse financière.

Si les fichiers sources se trouvent dans un plugin connecté, indiquez précisément les fichiers ou le dossier à utiliser. Évitez de demander à ChatGPT d’effectuer une recherche dans l’ensemble d’un Drive ou d’un espace de travail lorsque la révision doit s’appuyer sur des sources financières précises. Lorsque le classeur apparaît dans la discussion, ouvrez-le et affichez-le en plein écran pour examiner les données brutes, les correspondances, les formules de calcul des écarts et l’onglet de synthèse avant de demander des modifications.

## Vérifiez les écarts

Avant de partager le classeur, demandez à ChatGPT d’auditer les catégories, les formules et les explications des écarts.
