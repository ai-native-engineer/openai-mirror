# Fonctionnalités

Découvrez les flux de travail, les capacités, les commandes et les paramètres de ChatGPT

Découvrez les flux de travail, les capacités, les commandes et les paramètres pour travailler dans ChatGPT.

ChatGPT réunit au même endroit les projets, les discussions de longue durée, la navigation web, les fichiers, les images et les plugins. La documentation sur les commandes, les paramètres et le dépannage complète ces flux de travail : elle vous aide à choisir le flux de travail adapté et à fournir à chaque discussion le contexte et les outils dont elle a besoin.
