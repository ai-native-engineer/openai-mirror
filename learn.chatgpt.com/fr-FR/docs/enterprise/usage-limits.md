Les limites d’utilisation et les contrôles des dépenses de l’espace de travail ChatGPT s’appliquent aux activités admissibles dans le cadre de l’offre de cet espace de travail. Selon l’offre, cela peut inclure certaines activités dans Codex. Ces contrôles ne constituent pas un système de limitation universel pour Codex et ne régissent pas la facturation de la Plateforme API.

Pour connaître le modèle d’administration complet, consultez
[Rôles et autorisations de l’espace de travail](/fr-FR/codex/enterprise/roles-and-workspace-permissions).

## Déterminez dans quels cas ces contrôles s’appliquent

Examinez les contrôles d’utilisation de l’espace de travail ChatGPT dans les cas suivants :

- L’accord de l’organisation prévoit l’utilisation de crédits partagés ou achetés pour l’espace de travail ChatGPT.
- Les activités admissibles dans Codex peuvent consommer ces crédits.
- Les administrateurs ont besoin de garde-fous pour les utilisateurs, de contrôles des dépenses à l’échelle de l’espace de travail ou de notifications d’utilisation disponibles avec l’offre actuelle.

Les contrôles d’utilisation ne définissent ni les droits d’accès aux fonctionnalités ni les autorisations, même si l’accès aux fonctionnalités admissibles peut être suspendu lorsque les limites sont atteintes. Ils n’ont aucune incidence sur les autorisations du système source et ne régissent ni l’utilisation de la Plateforme API ni sa facturation.
