Dans l’application de bureau ChatGPT, ouvrez le menu déroulant ChatGPT et sélectionnez **Codex**.
Lorsque vous démarrez une discussion Codex, choisissez où l’exécuter :

- **Local** : travaillez directement dans le répertoire de votre projet actuel.
- **Worktree** : isolez les modifications dans un arbre de travail Git. [En savoir plus](/fr-FR/codex/environments/git-worktrees).
- **Cloud** : exécutez-la à distance dans un environnement cloud configuré.

Les discussions **Local** et **Worktree** s’exécutent toutes deux sur votre ordinateur.

Pour consulter le glossaire complet et découvrir les concepts, explorez la [section Concepts](/fr-FR/codex/prompting).
