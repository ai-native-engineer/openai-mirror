# Configuration

Configurez ChatGPT, les outils de développement Codex, les workflows réutilisables et les outils externes

Définissez les valeurs par défaut, ajoutez du contexte persistant et personnalisez le fonctionnement de ChatGPT et des outils de développement Codex.

La configuration définit le comportement de ChatGPT et des outils de développement Codex dans les discussions et les dépôts, ainsi que sur différentes machines. Le contexte persistant, les fichiers de configuration, les consignes relatives aux dépôts, les sous-agents, les connexions externes et la configuration pour Linux et Windows assurent ensemble la cohérence de ces workflows, aussi bien pour les utilisateurs individuels que pour les équipes.
