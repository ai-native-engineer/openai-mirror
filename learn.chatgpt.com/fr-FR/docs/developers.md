# Développeurs

Configurez les flux de travail de développement, les environnements, les extensions et les intégrations

Utilisez Codex avec des bases de code, des environnements de développement, des automatisations et les outils de votre équipe.

Codex prend en charge aussi bien les tâches de programmation courantes que les intégrations plus poussées dans les environnements locaux et cloud. Ses flux de travail de développement couvrent la revue de code, le terminal intégré, les skills et plugins réutilisables, l’automatisation avec le SDK et App Server, les outils d’équipe et les ressources de référence propres à chaque interface.
