Créez un flux de travail dans le terminal avec Codex

Découvrez les fonctionnalités de la CLI qui vous permettent de reprendre des sessions, d’ajouter du contexte visuel et web, de décomposer les tâches complexes et de connecter Codex à vos outils de développement.

Reprenez une discussion enregistrée

Rouvrez une discussion récente du dépôt actuel, ou recherchez parmi les discussions locales lorsque vous devez reprendre un travail plus ancien.

Ajoutez du contexte visuel au prompt

Joignez une capture d’écran d’erreur, un diagramme d’architecture ou une référence de design dès le premier prompt, ou collez une image dans la zone de saisie interactive.

Décomposez une analyse de grande ampleur

Demandez à Codex de déléguer des tâches ciblées à des agents spécialisés, puis de réintégrer leurs conclusions dans la session principale du terminal.

Recherchez des informations à jour

Activez la recherche web en direct lorsqu’une tâche nécessite des informations à jour sur les versions, la documentation ou le comportement de systèmes externes. L’activité de recherche reste visible dans la transcription.

Transférez le travail vers Codex Cloud

Parcourez les discussions en cours et terminées, soumettez une tâche à un environnement configuré et appliquez le résultat à votre dépôt local depuis le terminal.

Connectez des outils externes avec MCP

Ajoutez des serveurs MCP locaux ou distants, authentifiez-vous si nécessaire et examinez les outils disponibles pour la session en cours avant que Codex ne les utilise.

Définissez les limites de chaque exécution

Choisissez dans quels cas Codex peut modifier des fichiers ou exécuter des commandes sans vous le demander, puis examinez le bac à sable actif et les répertoires racines accessibles en écriture avant de continuer.

Adaptez Codex à votre terminal
