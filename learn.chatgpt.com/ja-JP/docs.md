# ChatGPT

意欲的な仕事やソフトウェア開発に ChatGPT を活用

概要

目標、アイデア、タスクのいずれかから始めましょう。ChatGPT はコンテキストを収集し、アクションを実行して、役立つものを生み出せます。

2026年7月13日～17日

デスクトップで Work の会話とプロジェクトを一元管理

クラウド上の Work の会話をデバイス間で利用し、ローカルの会話はコンピューターに保存したまま、ChatGPT のプロジェクトをデスクトップアプリで開けます。

Codex Micro で Codex の並行作業を制御

Codex Micro の Agent Keys、Command Keys、アナログスティック、ダイヤルを使って、デスク上の物理デバイスから最大 6 件のチャットを操作できます。

Amazon Bedrock 経由で GPT-5.6 を利用

ChatGPT Work と Codex のローカル利用環境を、Amazon Bedrock 経由で GPT-5.6 Sol、Terra、Luna に接続できます。

2026年7月6日～10日

ChatGPT で意欲的な仕事に挑戦

ChatGPT Work は、ファイルやプラグインからコンテキストを収集し、アクションを実行して、レビュー可能な成果物を作成できます。

用途に合う GPT-5.6 モデルを選択

フラッグシップモデル級の性能を持つ Sol、日常業務に適したバランス型の Terra、高速かつ低コストな Luna を比較できます。

ChatGPT デスクトップアプリで Codex を利用

ChatGPT デスクトップアプリに Codex が加わり、インラインの差分編集、サイドパネルでの Pull Request レビュー、高速化されたコンピューターの使用、複数リポジトリ対応のプロジェクトが利用できるようになりました。

2026年6月15日～19日

実演したワークフローを再利用可能なスキルに変換

Record & Replay では、macOS 上でワークフローを ChatGPT または Codex に実演し、その実演を再利用可能なスキルに変換できます。

別のホストでチャットを継続

チャットの引き継ぎにより、チャットとその Git の状態を、ローカルコンピューターと接続済みのリモートホストとの間で移動できます。

iOS からのワークスペース閲覧とレビュー

iOS 版リモートに、ワークスペースのファイル閲覧、ディレクトリ選択、差分および MCP 承認向けのより充実したコントロールが追加されました。

2026年6月8日～12日

ブラウザの開発者モードによる Web アプリのデバッグ

開発者モードにより、Codex は制御された範囲でブラウザの診断機能にアクセスし、Web アプリのプロファイリングやデバッグを行えます。

セットアップを Codex に引き継ぐ

オンボーディング時に、対応しているセットアップを他のコーディングエージェントからインポートするか、/init でプロジェクト用の指示を作成できます。

iOS から Codex のチャットをセットアップ

iOS 版リモートでは、ブランチの選択、Worktree の作成、セットアップスクリプトの実行、目標の管理、レビューコメントの追加ができます。
