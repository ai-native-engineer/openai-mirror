## 概要

プラグインは、ChatGPT と Codex で使う機能を再利用可能なワークフローにまとめたものです。スキル、コネクタ、またはその両方を含めることができます。両製品で共通のプラグインディレクトリを使用するため、それぞれの対応環境から同じ公開プラグインを探せます。

プラグインは、Web 版、デスクトップ版、モバイル版の ChatGPT のチャットと Work、および ChatGPT デスクトップアプリ内の Codex で利用できます。Codex CLI にも Codex 環境向けのプラグインブラウザがあります。IDE 拡張機能はプラグインに対応していません。

モバイルでは、アカウントで利用可能なプラグインをチャットまたは Work で使用できます。

**プラグイン** タブを開き、プラグインを探してインストールします。
インストール後は、ChatGPT のチャットや Work、または Codex でプラグインを使用できます。
インストールしたプラグインにより、新しいチャットにスキル、コネクタ、MCP ツールを追加できます。

**プラグイン** タブを開き、プラグインを探してインストールします。
インストール後は、チャットまたは Work でプラグインを使用できます。
プラグインによっては、ツールを利用できるようになる前に外部サービスへの接続を求められることがあります。

Codex CLI で `/plugins` を入力し、プラグインブラウザを開きます。
設定済みのマーケットプレイスからプラグインをインストールしたら、
同梱のスキルやツールを使用する前に新しいセッションを開始します。

<a id="plugin-directory-in-the-ide-extension"></a>

### 対応環境でのプラグインの使用

IDE 拡張機能ではプラグインを利用できません。Codex 向けのプラグインを探してインストールするには、ChatGPT デスクトップアプリまたは Codex CLI を使用します。

たとえば、次の方法で ChatGPT と Codex の機能を拡張できます。

- Codex Security プラグインをインストールして、許可された範囲のコードをスキャンし、脆弱性が疑われる検出結果を検証します。
- Gmail プラグインをインストールして、Gmail を操作します。
- Google Drive プラグインをインストールして、Drive、Docs、Sheets、Slides を横断して作業します。
- Slack プラグインをインストールして、チャンネルを要約したり、返信の下書きを作成したりします。

プラグインには、次の構成要素を 1 つ以上含めることができます。

- **スキル：** 特定の種類の作業向けに再利用できる指示です。
  ChatGPT と Codex は必要に応じてスキルを読み込み、適切な手順に従いながら、
  タスクに合った参考資料や補助スクリプトを使用できます。
- **コネクタ：** GitHub、Slack、Google Drive などのツールに接続する機能です。
  ChatGPT と Codex はそれらのツールから情報を読み取り、ツール内で操作を実行できます。
  コネクタはツールを提供し、必要に応じてカスタム UI も含められます。
- **MCP サーバー：** ChatGPT と Codex が追加のツールや共有情報にアクセスできるようにするサービスです。
  多くの場合、そうしたツールや情報はローカルプロジェクト外のシステムから提供されます。
  コネクタを支えるサービスでもあり、ツールを定義し、認証・認可を適用して、
  構造化データを返したり、外部システムに対する操作を実行したりします。
- **ブラウザ拡張機能：** プラグインのワークフローに必要な
  ブラウザ機能
- **フック：** ライフサイクル内の設定されたタイミングで実行されるコマンドです。
  プラグインのフックを有効にする前に、内容をレビューして信頼できることを確認してください。
- **スケジュール済みタスクのテンプレート：** スケジュール済みタスクを利用できる環境で、
  繰り返し実行するタスクの作成に再利用できるひな型

プロジェクトやチーム向けのリポジトリマーケットプレイスなど、
マーケットプレイスのソースを通じてプラグインを公開し、共有できます。[プラグインを作成する](https://developers.openai.com/plugins/build/plugins)では、
マーケットプレイスのセットアップ、パッケージ化、配布について説明しています。

インテグレーションを構築する場合は、まず
[MCP サーバーの構築](https://developers.openai.com/plugins/build/mcp-server)を参照してください。
プラグインにカスタム UI が必要な場合は、
[オプションの UI ガイド](https://developers.openai.com/plugins/build/chatgpt-ui)を参照してください。

## プラグインの使用とインストール

<a id="plugin-directory-in-the-codex-app"></a>

### 共通プラグインディレクトリ

ChatGPT と Codex は同じ公開プラグインカタログを使用します。
Web 版または ChatGPT デスクトップアプリで **プラグイン** タブを開き、プラグインを探してインストールします。

  
    
  

プラグインディレクトリでは、プラグインが次のタブに分類されています。

- **OpenAI：** OpenAI が開発したプラグイン
- **ワークスペース名：** ワークスペースが提供するプラグイン
- **個人：** 個人用マーケットプレイスのプラグイン（該当するプラグインがある場合は、 **自分が作成したもの** と
**自分に共有されたもの** のセクションを含む）

別に設けられている **インストール済み** の欄で、すでにインストールしたプラグインを確認できます。

ワークスペースの管理者は、チーム向けに GitHub マーケットプレイスをインポートして同期できます。
セットアップとアクセスの要件については、[プラグインの管理](/ja-JP/codex/enterprise/plugin-management)を
参照してください。

### プラグインのインストールと使用

プラグインディレクトリを開いたら、次の手順に従います。

1. プラグインを検索するか一覧から探し、詳細を開きます。
2. プラスボタンを選択して、プラグインをインストールします。
3. プラグインにコネクタが必要な場合は、接続を求められたら接続します。インストール時に認証を求められるプラグインもあれば、初めて使用するときに認証を求められるプラグインもあります。
4. インストール後に新しいチャットを開始し、ChatGPT または Codex にプラグインを使用するよう依頼します。

### 「ChatGPT でサインイン」による対応パートナーとの連携

**ChatGPT でサインイン** は、対応するプラグインと、
Airtable、GitLab、HubSpot、Notion、Supabase、Vercel などのパートナーサイト向けに、ベータ版として順次提供されています。
この選択肢が表示される場合は、プラグインの接続時に **ChatGPT でサインイン** を選択し、
そのサービスのアカウントを作成または連携します。

サインイン時にパートナーと共有されるのは、名前、メールアドレス、および設定されている場合はプロフィール画像のみです。サインインによってプラグインにデータへのアクセス権が付与されたり、操作が自動的に承認されたりすることはありません。接続を利用する前に、別途プラグインが要求する権限を確認し、承認してください。

プラグインをインストールすると、プロンプト入力欄から直接使用できます。

### Codex からの Apple Messages の使用

Apple Messages プラグインは、macOS 向け ChatGPT デスクトップアプリのすべてのプランで利用できます。Codex と ChatGPT Work では、Mac 上の iMessage、SMS、RCS のチャットを読み取ったり検索したり、Messages アプリを通じてあなたに代わってメッセージを送信したりできます。Messages を通じて ChatGPT とリモートでやり取りすることはできず、ChatGPT の通常のチャットでも使用できません。

今回のリリースでは、Messages プラグインは ChatGPT デスクトップアプリの Apple Silicon (arm64) 向けビルドにのみ含まれています。

1. **プラグイン**を開き、Apple Messages プラグインを探してインストールします。
2. Codex または ChatGPT Work で新しいチャットを開始し、メッセージの検索、要約、下書きの作成、送信を依頼します。
3. ChatGPT が Messages の内容を読み取る前に、要求された macOS の権限を付与します。
4. 送信を許可する前に、メッセージと宛先を確認します。

デフォルトでは、メッセージと宛先を承認した後にのみ、ChatGPT がメッセージを送信します。
 **1 回だけ許可** を選択すると、その送信だけを承認できます。
**このチャットへの送信を常に許可**を選択すると、
ChatGPT は今後、Messages の対象チャットに追加の送信承認なしでメッセージを送信できます。

信頼できない指示や誤解を招く指示が含まれる可能性のあるチャットでは、送信ごとの承認を維持してください。送信を常時許可すると、ChatGPT があなたの名義でメッセージを送信する前に内容を確認する最後の機会が失われます。この設定は、そのリスクを許容できる場合にのみ使用してください。

送信ごとの承認を再び有効にするには、 **設定** \> **コンピューターの使用** を開き、
 **Messages** の横にある**管理** を選択します。 **常に送信を許可**で、
対象のチャットの横にあるごみ箱アイコンを選択し、 **削除**を選択して確定します。
以後、そのチャットへの送信前に ChatGPT が再び承認を求めます。

**既知の問題：** タスクが **フルアクセス** に設定されている場合や、その他の設定で承認プロンプトが無効になっている場合、
Apple Messages で送信に必要な確認画面を表示できないことがあります。
 **承認を求める** または **承認を任せる** に切り替えて、もう一度お試しください。

Apple Messages はお使いの Mac 上で動作します。Web 版やモバイル版の ChatGPT、Codex CLI、IDE 拡張機能では直接利用できません。

管理対象のワークスペースでは、管理者は既存の「コンピューターの使用」設定から Apple Messages を無効にできます。

```text

CLI のプラグインブラウザでは、プラグインがマーケットプレイス別に分類されています。
マーケットプレイスのタブで配布元を切り替え、プラグインを開いて詳細を確認したり、

<a id="api-key-availability"></a>

### API キーでの利用可否

[OpenAI API キーで
Codex にサインイン](/ja-JP/codex/auth#sign-in-with-an-api-key)すると、
Codex CLI と ChatGPT デスクトップアプリ内の Codex で、OpenAI が選定した対応プラグインを閲覧、インストール、管理できます。
一部のプラグインは、接続フローで未対応の OAuth 機能を必要とするため、
API キー認証では利用できません。プラグインの使用状況は、
[Platform の使用状況ページ](https://platform.openai.com/usage)で確認してください。

### 権限とデータ共有の仕組み

Web 版 ChatGPT では、チャットと Work のどちらでも、そのチャットで利用できるワークスペースの権限とツールが使用されます。コネクタには、引き続き個別のサインインとアクセス権が必要です。

プラグインの機能が Codex ホストを通じて実行される場合は、そのホストの[サンドボックスと
承認ポリシー](/ja-JP/codex/agent-approvals-security)が適用されます。
外部サービスへの接続には、そのサービス独自の認証と
アクセス制御が適用されます。

- 同梱のスキルは、インストール後に新しいチャットまたは CLI セッションを開始すると利用できるようになります。
- プラグインにコネクタが含まれている場合は、セットアップ時または初回利用時に、利用中のプロダクトからコネクタのインストールまたはサインインを求められることがあります。
- プラグインに MCP サーバーが含まれている場合は、利用前に追加のセットアップや認証が必要になることがあります。
- ChatGPT が同梱のコネクタを通じてデータを送信する場合は、そのサービスの利用規約とプライバシーポリシーが適用されます。

### プラグインの削除

プラグインを削除するには、対応するプラグインブラウザで対象のプラグインを開き、利用できる場合は
**プラグインをアンインストール** を選択します。ワークスペースにインストールされたプラグインや
デフォルトのプラグインでは、この操作を利用できない場合があります。
こうしたプラグインはワークスペース管理者が管理します。

プラグインをアンインストールすると、その ChatGPT または Codex 環境からプラグインバンドルは削除されますが、同梱のコネクタの接続は、ChatGPT で管理操作を行うまで維持されます。

## 独自プラグインの作成

独自のプラグインを作成、テスト、配布する場合は、
[プラグインを作成する](https://developers.openai.com/plugins/build/plugins)をご覧ください。このページでは、ローカル環境でのひな形作成、
マーケットプレイスの手動セットアップ、ワークスペースでの共有、プラグインマニフェスト、
パッケージ化の指針について説明しています。

プラグインにサーバーを利用する機能が含まれている場合は、
[MCP サーバーの構築](https://developers.openai.com/plugins/build/mcp-server)をご覧ください。
MCP ツールはカスタム UI なしでも動作し、画面表示がワークフローに役立つ場合は
UI を返すこともできます。

プラグインをレビューに提出する準備ができたら、
[プラグインの提出](https://developers.openai.com/plugins/deploy/submission)をご覧ください。OpenAI Platform での提出フロー、
必要な権限、レビュー資料、MCP のチェック、
テストケースの要件を確認できます。
