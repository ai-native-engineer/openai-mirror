# ChatGPT デスクトップアプリ

ChatGPT デスクトップアプリを使えば、プロジェクトやファイルを扱い、長時間にわたる作業を進められます。

複雑な作業の司令塔

1 つのデスクトップワークスペースで、複数のプロジェクトを並行して進め、ファイルを扱い、コンピューターを操作し、長時間にわたる作業を継続できます。

メリット

すべてのチャットをひと目で確認

コンテキストを失うことなく、プロジェクトや長時間にわたる作業を切り替えられます。

実際に使える成果物の作成と確認

同じワークスペースで、ドキュメント、スプレッドシート、画像などのファイルを開けます。

ツールをまたいだ作業

ブラウザ、デスクトップアプリ、プラグインを使用したり、チャット内でタスクをスケジュールしたりできます。

ChatGPT デスクトップアプリのインストール

macOS、Windows、または Linux 用の ChatGPT をダウンロードします。

ChatGPT を開いてサインイン

アプリを開き、ChatGPT アカウントでサインインします。

作業場所の選択

チャットを開始するか、プロジェクトを作成するか、フォルダーを開きます。ChatGPT は選択した場所にあるファイルとコンテキストを使用できます。

チャットとプロジェクトについて学ぶ

最初のメッセージを送信

ChatGPT または Codex を選択します。ChatGPT では、コンポーザーの上にある切り替えボタンを使って「チャット」または「Work」を選択します。Codex では、まず「新しいチャット」を選択します。簡単な質問をする場合は、「新しいチャット」にカーソルを合わせ、右側のクイックチャットアイコンを選択します。その後、求める結果を説明し、ChatGPT に必要なファイルやコンテキストを追加します。

ChatGPT の使い方を学ぶ

アプリでできること

日々の作業を、確認、改善、共有できる成果物に仕上げます。

ユースケースを見る

要点を絞った業務概要で一日をスタート

カレンダー、メッセージ、メール、プロジェクトのコンテキストを横断して、優先事項を確認します。

ファイル分析とインタラクティブな可視化の作成

エクスポートしたデータから、確認して共有できる知見を導き出します。

散在するコンテキストから完成版の PRD を作成

複数の情報源を集約・統合し、そのまま作業に使えるドキュメントを作成します。

未整理データのクリーニングと準備

元のファイルを変更せずに、未整理の CSV やスプレッドシートから整理済みのコピーを作成します。

フィードバックをアクションに変換

複数の情報源からのフィードバックを統合し、確認できる成果物にまとめます。

お使いのブラウザは video タグをサポートしていません。

ChatGPT デスクトップアプリの活用場面…

複数のプロジェクトを並行管理

並行中の作業を一覧で確認し、チャットをすばやく切り替えられます。

ファイルの作成とレビュー

ChatGPT を離れることなく、成果物を完成させて確認できます。

タスクに必要なツールへのアクセスを ChatGPT に許可します。

定期的な作業のスケジュール設定

独立したスケジュール済みタスクを作成するか、既存のチャット内でタスクをスケジュールします。

ChatGPT と Codex のその他の利用環境

ChatGPT と Codex の利用環境

ChatGPT Web

ブラウザから調査、分析、作成を行えます。

Codex CLI

ターミナルから内容を確認・編集し、作業を自動化できます。

IDE 拡張機能

エディター内でコードと並べて Codex を利用できます。

Codex Cloud

複数のクラウド環境でコーディングタスクを並行して実行できます。
