ChatGPT Work は、トピックの調査、情報の分析、ドキュメントやプレゼンテーションの仕上げなど、複数のステップからなるタスクを従業員が完了できるよう支援します。これらのタスクには追加の推論、ツール、処理が必要になることがあり、それに伴ってクレジットを消費する場合があります。こうした利用が請求額に影響するかどうかは、クレジット残高、契約上の単価、ワークスペースの超過利用設定によって決まります。

このガイドでは、Work が使用量に与える影響を把握し、従業員への導入を計画して、組織で利用できる支出管理機能を適用する方法を説明します。

## 使用量とコストの概要

- 対象となるクレジット制の契約では、Work の利用に応じて、ワークスペースで共有するクレジットを消費します。
- 契約済みクレジットを消費することと、新たに請求される料金が発生することは異なります。
- 従業員はチャットと Work の両方を使えます。導入に伴う使用量を見積もる際は、両方の対象使用量を合算して評価してください。
- 職種別の見積もりは計画に役立ちますが、ユーザーあたりの固定料金ではなく、請求額を保証するものでもありません。
- ユーザーの使用量上限とワークスペースの超過利用上限は、別々の管理機能です。アラートは通知を行いますが、支出を止めるものではありません。
- 組織の利用実績と、測定可能なワークフローの成果をもとに、導入を評価してください。

## Work がクレジットを使う理由

クレジット制の契約を結んでいる組織では、対象となる Work の利用に応じて、ワークスペースに割り当てられた共有クレジットを消費します。対象となる他の ChatGPT 機能も同じ割り当て枠から消費することがあるため、Work に必ずしも専用の残高があるわけではありません。

消費量は次の要素によって変わります。

- モデル、実行環境、適用される推論や速度の設定
- タスクの複雑さと、使用する対象ツールや機能（たとえば、従業員がアクセス権を持つ承認済みのアプリやシステムから、CRM レコード、ドキュメント、メッセージを使って四半期ビジネスレビューを作成する場合など）
- 従業員がタスクを実行する頻度

Work を使い始めても、従業員がチャットの利用をやめる必要はありません。消費量の合計がどう変わったかを把握するには、同じ従業員について、従来のチャットの使用量と、チャットと Work を合わせた使用量を、比較可能な期間で比べてください。

対象となる各アクティビティで消費するクレジットは、契約と適用される料金表によって決まります。既存のサブスクリプション料金やシート料金は、クレジット消費量の見積もりとは別です。

### トークンとクレジットの基礎

**トークン** は、入力、キャッシュされた入力、出力など、モデルが読み書きする情報量を測る単位です。
クレジット制の契約では、対象となる利用の支払いに、
ワークスペースの共有割り当て枠から **クレジット** が使われます。クレジット料金については、
[トークン単価](/ja-JP/codex/pricing#token-rates)をご覧ください。

Enterprise 契約でクレジット制ではなく USD 建ての従量課金が定められている場合は、<a href="https://help.openai.com/en/articles/20001415-chatgpt-rate-card-enterprise-token-based-pricing" target="_blank" rel="noopener noreferrer">Enterprise の USD 建て料金表</a>と契約を参照してください。USD 建てで請求されるワークスペースにクレジットの計算方法を適用したり、消費したクレジットを追加の請求額として扱ったりしないでください。

## 利用が請求額に影響する条件

対象となる Work の利用で追加料金が発生するかどうかは、契約、クレジット残高、適用される請求設定によって決まります。契約済みクレジットを使うと利用可能な残高は減りますが、それ自体で新たに請求される料金が発生するわけではありません。

- **契約済みクレジットが残っている場合：** 対象の利用に応じて、
  利用可能なクレジット枠が減ります。これらのクレジットを使うこと自体で、
  既存の契約に含まれない新たな料金が発生するわけではありません。
- **クレジットが残っておらず、アカウントで超過利用が許可されている場合：** 対象の利用は、
  ワークスペースに設定された超過利用上限の範囲内で継続でき、
  契約上の超過利用単価に基づく料金が発生する場合があります。
- **クレジットが残っておらず、アカウントで超過利用が許可されていない場合：** 対象機能は、
  クレジットが利用可能になるか、適用される上限が変更されるまで、
  一時停止することがあります。

超過利用時の動作は、アカウントが超過利用の対象かどうかと、ワークスペースに設定された上限の両方によって決まります。
契約で超過利用が許可されていない場合、
利用可能なクレジットがなくなると対象の利用は停止します。アカウントで超過利用が許可されている場合、
上限が未設定だと、クレジット残高を超えて対象の利用を継続できることがあります。
対応している場合は、超過利用上限を 0 に設定すると、ワークスペースで超過利用が発生するのを防げます。
一方、 **制限なし** は支出を 0 に抑える設定ではありません。

使用量レポートやドル建ての見積もりは、計画や利用状況の把握に使うもので、発行済みの請求書ではありません。表示される見積もりの中には、契約上の超過利用単価を使うものがあり、この単価は契約済みクレジットの単価と異なる場合があります。実際の請求額は、請求書、請求対象期間、組織の契約条件に照らして確認してください。

## 職種別・チーム別の使用量の見積もり

財務、マーケティング、営業など、同じような業務を担当する従業員への導入を計画する際は、職種別の見積もりが役立ちます。まず、組織が支援を予定している従業員とワークフローを確認してください。

次の手順で見積もりを作成します。

1. 導入対象のユーザーグループと、比較に使える既存のチャット利用期間を特定します。
2. 試験導入時の利用実績、または承認済みで対象職種に適したベンチマークを使い、チャットと Work を合わせた消費量を見積もります。
3. 契約済みクレジットの残高を確認します。契約済みクレジットと超過利用を分けて、それぞれに適切な契約単価を適用します。
4. 予測される使用量が利用可能なクレジットの範囲内に収まるか、契約上の超過利用条件が適用される可能性があるかを判断します。
5. 実際の導入状況、タスクの内訳、消費実績を使って見積もりを更新します。

承認済みのベンチマークには、エンタープライズ顧客の利用実績と、実際に使用されたモデルの構成比が反映されている場合があります。その有用性は、比較期間、職種の分類、ワークフロー、アカウントに関する前提条件によって異なります。大まかな職種別の見積もりを、業界やタスクに固有のベンチマークとみなすことはできません。

**年間換算のクレジット消費額の見積もり** は、実際の利用額を
1 年間に換算したものです。これは Work 単独のライセンス料金や、標準的なユーザーあたりの料金、
OpenAI のインフラコストを示すものではなく、
請求額が同額だけ増えるという予測でもありません。実際の追加料金は、
契約済みクレジットの残高、契約上の料金、許可されている超過利用、請求対象期間によって決まります。

### マーケティング部門の導入計画の参考例

Work を初めて導入したエンタープライズ顧客のマーケティング担当者の利用実績を分析したところ、年間換算のクレジット消費額に次の変化が見られました。

- **中央値：** 約 **従業員 1 人あたり年間 $53**
- **90 パーセンタイル値：** 約 **従業員 1 人あたり年間 $1,154**
- **平均値：** 約 **従業員 1 人あたり年間 $309**

中央値は、実測した個人別使用量の中央に位置する値です。少数の従業員が多くのクレジットを消費するため、平均値は中央値より高くなります。90 パーセンタイル値は、実測した使用量の上位層との境界を示す値であり、支出上限や最大値ではありません。

利用状況の内訳が似た **従業員 100 人** のグループに、 **従業員 1 人あたりの平均
$309** を適用すると、約 **年間 $30,900**となり、
**計画上の月額換算では $2,575**に相当します。

これらの参考見積もりは、エンタープライズ顧客の利用実績と実際のモデル構成比を反映し、導入期間中の 1 週間の使用量を年間換算したものです。削減額を保証するものでも、ユーザーあたりの固定料金でも、そのまま請求される金額でも、請求額の確実な増加を示すものでもありません。実際の請求額は、契約済みクレジットの残高、契約上の単価、許可されている超過利用によって決まります。

担当アカウントチームが、組織の契約に照らして承認済みの見積もりを理解するお手伝いをします。

## 管理者向けの設定とレポート

ワークスペースのオーナーと管理者は、対応している次の設定を使って、アクセスとクレジット消費の対象となる利用を管理できます。

- **Work へのアクセス：** ワークスペースで利用できる権限設定を使い、
  Work にアクセスできるユーザーやグループを選びます。
- **モデルと速度の設定：** 対応している場合は、「ワークスペース設定 \> モデル」で、
  Work & Codex の初期モデル、推論レベル、速度、Fast モードの利用可否を設定します。
  対応モデルで Fast モードを使うと、クレジット消費量が増えることがあります。
- **ユーザーの使用量上限：** 各ユーザーの対象使用量を管理するため、
  対応している月間上限の設定で、ワークスペースの既定値、グループ別の上限、個別の上書き値を指定します。
- **ワークスペースの超過利用上限：** 共有クレジット枠を使い切った後に、
  対象の利用をどの程度まで続けられるかを制御します。
- **使用量アラート：** 「請求」で、対応している使用量のしきい値と通知先を設定します。
  アラートは通知を行うだけで、支出を止めるものではありません。
- **クレジット残高とレポート：** 「請求」でクレジット残高を確認し、
  自分のロールで利用できる使用量レポートをダウンロードします。契約に契約済みクレジットが含まれている場合は、
  利用実績を契約上の割り当て枠と請求対象期間に照らし合わせ、
  消費ペースを評価します。
- **請求書：** ワークスペースでのロールに請求書へのアクセス権がある場合は、
  発行済みの請求書と対応する請求対象期間を確認します。

ユーザーごとの上書き設定は、グループやワークスペースの既定値より優先されます。複数のグループに所属している場合は、適用対象となるグループ上限のうち、最も高い値が適用されます。グループの上限が未設定でも、上限が 0 クレジットになるわけではありません。試験導入の参加者ごとに、実際に適用される上限を確認してください。

使用量上限を設定しても、クレジットが追加されるわけではなく、Work にアクセスできる人が決まるわけでもありません。モデルの既定値や従業員へのガイダンスは消費量に影響を与えることがありますが、どちらも強制適用される使用量上限や、ワークスペースの超過利用設定の代わりにはなりません。

利用できる管理機能、レポートの詳細度、請求書へのアクセス、請求の仕組みは、
プラン、ワークスペースの構成、契約によって異なります。
レポートに利用状況がすぐに反映されない場合があるため、
使用量を請求書と照合する前に、レポートのタイムスタンプと請求対象期間を比較してください。
各プロダクトへの適用範囲と最新の設定手順については、
[ChatGPT の使用量上限と支出管理](/ja-JP/codex/enterprise/usage-limits)をご覧ください。

## 使用量と成果の測定

顧客調査、会議の準備、財務レポートの作成など、現状の基準値が明確で、繰り返し行うワークフローを選びます。どのタスクにも最も高度な選択肢が必要だと考えるのではなく、業務に適したアクセス権、ツール、モデルの機能を使ってください。

試験導入では、Work の導入前後で同じワークフローを比較します。タスクに応じた測定項目には、次のようなものがあります。

- 業務の完了に必要な時間
- 成果物の品質、完成度、一貫性
- 手戻り、手作業による調整、エラー率
- チームが意図した成果物を完成させたかどうか

お客様が測定したこれらの成果を、実際のクレジット消費量や請求額への実際の影響とあわせて確認します。利用量だけではコスト削減を裏付けることはできず、見込まれる時間短縮も金銭的な利益を保証するものではありません。

## 範囲を限定した導入から開始

アクセス対象を拡大する前に、次のことを行います。

1. 契約内容、クレジット残高、適用料金、超過利用の設定を確認します。
2. 対象とするグループを絞り、組織で評価できるワークフローを選びます。
3. 利用可能なアクセス権限、ユーザーの利用上限、アラート、ワークスペースの超過利用上限を設定します。
4. チャットと Work を合わせたクレジット消費量を、そのグループの既存の基準値と比較します。
5. 導入範囲を拡大する前に、測定した成果と請求額への実際の影響を確認します。

アクセス、データ、ガバナンス、導入に関する詳しい説明は、
[ChatGPT Work 管理者向けのよくある質問](/ja-JP/codex/enterprise/work-admin-faq)をご覧ください。
契約ごとの料金、利用可能なクレジット、請求に関するご質問は、
担当のアカウントチームにお問い合わせください。
