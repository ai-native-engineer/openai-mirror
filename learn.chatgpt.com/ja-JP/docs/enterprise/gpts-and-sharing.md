## 共有

GPT を作成できるユーザーと、特定のユーザー、グループ、またはワークスペース全体への共有を許可するかどうかを管理します。

  GPT 作成者は接続済みアプリまたはカスタムアクションのいずれかを使用できますが、同じ GPT で両方を併用することはできません。

## 接続済みアプリとアクション

GPT 作成者が承認済みのワークスペースアプリを使用したり、許可されたサードパーティの API と連携するアクションを設定したりできるようにします。アクセスには引き続き、ワークスペースのポリシー、ユーザーの権限、承認済みドメインの制約が適用されます。

## ドメイン

GPT アクションのアクセス先を承認済みの外部ドメインに制限し、ワークスペース内で作成された GPT がアクセスできるサードパーティの API を管理します。許可されたドメインがない場合、カスタム GPT アクションは実行できません。

  ドメインの承認は、API 認証やユーザーによる認可の代わりにはなりません。

## GPT の管理

ワークスペース内で作成された GPT をレビューし、共有設定と所有権を管理して、必要に応じて GPT を削除します。管理画面では、所有者が割り当てられた GPT と未割り当ての GPT に分類し、次の情報を表示します。

- 名前
- 作成者
- カスタムアクション
- アクセス可能なユーザー
- チャット
- 作成日時
- 更新日時
