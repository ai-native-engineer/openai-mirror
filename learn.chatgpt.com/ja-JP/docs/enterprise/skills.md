スキルは、指示と補助リソースで構成される再利用可能なワークフローです。
ChatGPT ワークスペースのスキル、ChatGPT デスクトップ App、Codex CLI、IDE 拡張機能の
対象となるローカル機能で使用されるファイルシステムのスキル、およびスキルを
パッケージ化するプラグインには、それぞれ個別のライフサイクル管理とアクセス制御があります。

完全な管理モデルについては、
[ロールとワークスペースの権限](/ja-JP/codex/enterprise/roles-and-workspace-permissions)を参照してください。

<a id="distinguish-the-distribution-models"></a>

## スキルの配布と管理

| 配布モデル      | 用途                                                                                           | 管理範囲                                                                       |
| ----------------------- | ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| ChatGPT ワークスペースのスキル | サポート対象の ChatGPT ワークスペース機能を通じた、承認済みワークフローの共有またはインストール              | ChatGPT ワークスペースのスキルに対する権限とライフサイクル管理                                    |
| ローカルファイルシステムのスキル  | リポジトリ用、ユーザー用、管理者用、またはシステム同梱の配置場所から、インストール済みワークフローを読み込む     | ファイルシステムでの配布、ローカルクライアントの構成、実行時の権限                  |
| プラグイン                  | 1 つ以上のスキルを、任意のコネクタ、MCP サーバー、フック、表示用メタデータとともにパッケージ化 | プラグインの利用可否とインストール、およびバンドルされた各機能に対する個別の管理 |

ChatGPT ワークスペースでのスキル配布、ローカルファイルシステムへのスキルのインストール、
利用環境ごとのプラグインのインストールは、それぞれ別の経路です。スキルを移動しても、
ChatGPT ワークスペースの所有権、共有設定、ロールの割り当て、プラグインの
インストール状態、コネクタの認可は引き継がれません。

プラグインは、Web 版、デスクトップ版、モバイル版 ChatGPT のチャットと Work、
ChatGPT デスクトップ App 内の Codex、および Codex CLI のプラグインブラウザーで利用できます。
IDE 拡張機能では利用できません。
これらの対応環境では、ChatGPT と Codex で共有されている 1 つの共通ディレクトリから
公開プラグインを取得します。

## 機能ごとの管理元

詳しくは [スキルを作成する](/ja-JP/codex/build-skills) でファイルシステム上の配置場所と作成方法を、
[ChatGPT のスキル](https://help.openai.com/en/articles/20001066-skills-in-chatgpt)
で現在のワークスペースでの手順を、 [プラグインを作成する](https://developers.openai.com/plugins/build/plugins) で
プラグインのパッケージ化方法を確認してください。

ChatGPT ワークスペースの管理機能から、ローカルファイルシステムのスキルやプラグインをインストールすることはできません。
ファイルシステムで配布しても、ChatGPT ワークスペースの所有権やロールは割り当てられません。
プラグインをインストールしても、コネクタ、MCP サーバー、または
接続済みサービスへのアクセス権は付与されません。各機能は、その機能を
管理するインターフェースから構成してください。
