対応地域では、macOS および Windows の ChatGPT デスクトップアプリで、ChatGPT Work と Codex からコンピューターの使用を利用できます。コンピューターの使用プラグインをインストールしてください。macOS では、求められたら画面収録とアクセシビリティの権限を許可してください。

コンピューターの使用により、ChatGPT は macOS または Windows のグラフィカルユーザーインターフェースを確認して操作できます。デスクトップアプリの動作確認、ブラウザの利用、アプリ設定の変更、プラグインとして利用できないデータソースの操作、グラフィカルユーザーインターフェースでのみ発生するバグの再現など、コマンドラインツールや構造化された連携だけでは対応できないタスクに使用してください。

コンピューターの使用は、プロジェクトのワークスペース外にあるアプリやシステムの状態に影響を与える可能性があります。対象を限定したタスクに使用し、続行する前に権限リクエストを確認してください。

## コンピューターの使用のセットアップ

ChatGPT デスクトップアプリで ChatGPT を選択し、切り替えメニューから Work に切り替えるか、
Codex を選択します。 **プラグイン \>
コンピューターの使用** を開き、求められたら **プラグインをインストール** を選択します。ChatGPT に「 **有効にする**」と表示された場合は、それを選択します。
コンピューターの使用のサーバーとスキルのトグルをオンにし、 **今すぐ
試す** を選択して開始します。

  

続いて、 **設定 \> コンピューターの使用** を開き、アプリへのアクセス権を確認します。
接続済みブラウザの操作項目には **管理** アクションが表示されます。
今後のタスクでの使用を承認したアプリは、 **常に許可するアプリ** セクションに表示されます。

  

Windows では、タスクの実行中、対象アプリをアクティブなデスクトップに表示したままにしてください。macOS では、求められたら画面収録とアクセシビリティの権限を許可し、ChatGPT が対象アプリを確認して操作できるようにしてください。

macOS では、次の権限を許可してください。

- ChatGPT が対象アプリを確認するための**画面収録** の権限
- ChatGPT がクリック、文字入力、画面移動を行うための**アクセシビリティ** の権限

## コンピューターの使用が適した場面

スクリーンショットや視覚的な判断を必要とする難しいタスクでは、
モデル選択メニューで利用可能であれば [GPT-6 Astra](/ja-JP/codex/models#gpt-6-astra) を選択してください。
プラグインのセットアップ、OS の権限、アプリへのアクセス制御は、
ほかのモデルと同じです。

ファイルやコマンド出力だけでは確認が難しいグラフィカルユーザーインターフェースを扱うタスクには、コンピューターの使用を選択してください。

適した用途には、次のようなものがあります。

- ChatGPT が開発している macOS アプリ、Windows アプリ、iOS シミュレーターの操作フロー、その他のデスクトップアプリのテスト
- ウェブブラウザが必要なタスクの実行
- グラフィカルインターフェースでのみ発生するバグの再現
- UI のクリック操作が必要なアプリ設定の変更
- プラグインからアクセスできないアプリやデータソース内の情報の確認
- macOS で別の作業を続けながら、対象を限定したタスクをバックグラウンドで実行
- 複数のアプリにまたがるワークフローの実行

ローカルで開発しているウェブアプリには、
まず[内蔵ブラウザ](/ja-JP/codex/browser?surface=app)を使用してください。

### Windows でのフォアグラウンド利用

Windows では、コンピューターの使用はアクティブなデスクトップで動作します。同じ Windows セッションを使い続けながらバックグラウンドで動作させることはできません。そのため、タスクの実行中は ChatGPT がポインターを動かして文字を入力し、フォアグラウンドの操作を引き継ぐ点に注意してください。

離席中も Windows のタスクを続行するには、
Windows デバイスのロックを解除したまま、インターネットに接続しておきます。
スマートフォンから[リモート操作](/ja-JP/codex/remote-connections)を利用して進捗を確認したり、
追加の指示を送ったりできます。あるいは、ChatGPT デスクトップアプリを Windows の仮想マシン内で実行すれば、
コンピューターの使用がメインのデスクトップではなく VM を操作します。

ChatGPT に操作させるアプリ、ウィンドウ、操作フローを具体的に指定します。

```text
Open the app with Computer Use, reproduce the onboarding bug, and fix the
smallest code path that causes it. After each change, run the same UI flow
again.

```text
Open @Chrome and verify the checkout page still works after the latest changes.

対象アプリに専用のプラグインや MCP サーバーがある場合は、データへのアクセスや繰り返し実行する操作には、その構造化された連携機能を優先してください。ChatGPT がアプリを視覚的に確認または操作する必要がある場合は、コンピューターの使用を選択してください。

## 権限と承認

ワークスペース管理者は、コンピューターの使用でアクセスできるアプリや、
承認を保存できるかどうかを制限できます。
[管理者によるブラウザとコンピューターの使用の制御](/ja-JP/codex/enterprise/managed-configuration#control-browser-and-computer-use)を参照してください。

コンピューターの使用に対するシステム権限は、ChatGPT でのアプリの承認とは別です。macOS では、画面収録とアクセシビリティの権限により、ChatGPT がアプリを確認して操作できるようになります。アプリの承認によって、ChatGPT にどのアプリの使用を許可するかが決まります。ファイルの読み取りと編集、シェルコマンドには、引き続きタスクのサンドボックス設定と承認設定が適用されます。

コンピューターの使用で ChatGPT が確認して操作できるのは、許可したアプリだけです。
タスクの実行中、ChatGPT はコンピューター上のアプリを使用する前に許可を求めます。
 **常に許可** を選択すると、そのアプリを今後使用する際に、
ChatGPT が再度許可を求めることはありません。 **常に許可** リストからアプリを削除するには、
ChatGPT デスクトップアプリの設定にある**コンピューターの使用** セクションを開きます。

  
    
  

ChatGPT は、慎重な対応が必要な操作や、作業を中断させる可能性のある操作を実行する前にも、許可を求める場合があります。

ChatGPT がアプリを確認または操作できない場合、macOS では **システム設定 \>
プライバシーとセキュリティ** を開き、 **画面収録** と **アクセシビリティ** の設定で、 **Codex
コンピューターの使用** が許可されていることを確認してください。Windows では、
対象アプリがアクティブなデスクトップセッションに表示されていることを確認してください。

Windows では、コンピューターの使用に関するアプリの利用可否の設定を、
`$CODEX_HOME/config.toml` に永続的に保存します。
コンピューターの使用が確認を求めずに開けるアプリを一覧に記載してください。

```toml
[computer_use.windows]
always_allowed_app_ids = ["mspaint.exe"]

Windows のコンピューターの使用が報告するアプリ識別子を使用してください。
たとえば、デスクトップアプリの実行可能ファイル名や、パッケージアプリのアプリユーザーモデル ID が該当します。
ChatGPT はリストにないアプリについて確認を求めます。保存済みの設定を取り消すには、
 **設定 \> コンピューターの使用 \> 常に許可**から対象アプリを削除してください。

このテーブルには、コンピューターの使用に関するローカルの利用可否の設定が保存されます。
これは管理者が強制適用する `requirements.toml` とは別です。
管理者は、そのファイルで `[features].computer_use = false` を設定することでコンピューターの使用を無効にできます。
以前の `$CODEX_HOME/computer-use/config.toml` にある許可リストの項目は、現在の設定へ移行されます。
ただし、その `denied` リストは現在のポリシースキーマには含まれません。

## ロック中の使用

  ロック中の使用は macOS 専用です。Windows では、コンピューターの使用はフォアグラウンドで動作します。

ロック中の使用を有効にした場合に限り、Mac がロックされた後も ChatGPT はコンピューターの使用を利用できます。Mac のロック後、ChatGPT のタスクが接続済みデバイスからデスクトップアプリを使用する必要がある場合に利用してください。

ロック中の使用を有効にすると、ChatGPT は Apple の
[認可プラグイン](https://developer.apple.com/documentation/security/authorization-plug-ins)をインストールします。
このプラグインは macOS のロック解除処理に組み込まれます。

ロック中の使用の機能は、意図的に限定されています。Mac のロックをリモートで解除するための汎用的な手段ではなく、ほかのアプリやローカルプロセスがコンピューターのロックを解除できるようにするものでもありません。

ロック中の使用を利用する手順は次のとおりです。

1. アプリで **設定 \> コンピューターの使用** を開きます。
2. ロック中の使用を有効にします。
3. Mac の画面がロックされた後、接続済みデバイスからコンピューターの使用を伴うタスクを開始します。

Mac のロック後に ChatGPT のタスクがコンピューターの使用を介してアプリにアクセスすると、ChatGPT はローカルでの操作をブロックし、ロック画面の保護を維持したまま、Mac のロックを一時的に解除します。ロックを解除する前に、ChatGPT はその試行が、実行中で信頼済みのコンピューターの使用ターンに対するものかを確認します。その短い有効期間外では、ChatGPT はロック解除を拒否し、必要に応じて手動で解除するよう求めます。

ロック中の使用には、次の安全対策があります。

- 認可の有効期間は短く、対象は現在のロック解除の試行に限定されます。
- コンピューターの使用ターンが実行中の場合に限り、ChatGPT だけが自動ロック解除を利用できます。
- デスクトップのロックが一時的に解除されている間、ChatGPT がすべてのディスプレイを覆います。
- ChatGPT がローカルのキーボードまたはポインターからの入力を検出すると、Mac を再度ロックし、ユーザーが手動でロックを解除するまで自動ロック解除を一時停止します。

## 安全に利用するためのガイドライン

コンピューターの使用では、ChatGPT は画面の内容を確認し、スクリーンショットを撮影できるほか、対象アプリのウィンドウ、メニュー、キーボード入力、クリップボードの状態を操作できます。アプリに表示される内容、ブラウザのページ、スクリーンショット、対象アプリで開いたファイルは、タスクの実行中に ChatGPT が処理する可能性があるコンテキストとして扱ってください。

タスクの範囲を限定し、慎重な対応が必要な操作中はその場を離れないでください。

- ChatGPT には、一度に 1 つの対象アプリや操作の流れを明確に指定してください。
- いつでもタスクを停止したり、コンピューターの操作を自分で引き継いだりできます。
- 機密情報を扱うアプリは、タスクに必要な場合を除き、閉じておいてください。
- Windows では、ChatGPT の作業中はフォアグラウンドの入力操作を ChatGPT が占有することを想定してください。別のデバイスや VM を使用するか、自分でそのデスクトップを使用する前にタスクを停止してください。
- 機密情報を必要とするタスクは、その場にいて各手順を承認できる場合を除き、避けてください。
- ChatGPT にアプリの使用を許可する前に、アプリの使用許可を求めるプロンプトを確認してください。
- 今後のタスクで ChatGPT に自動的に使用させてもよいと判断したアプリに限り、
   **常に許可** を選択してください。
- アカウント、セキュリティ、プライバシー、ネットワーク、支払い、または認証情報に関する設定を扱う場合は、その場を離れないでください。
- ChatGPT が誤ったウィンドウを操作し始めた場合は、タスクをキャンセルしてください。

ChatGPT がブラウザを使用する場合、すでにサインインしているページも操作できます。ウェブサイト上の操作は、自分で行う場合と同じように確認してください。ウェブページには悪意のあるコンテンツや誤解を招くコンテンツが含まれる可能性があります。また、サイトによっては、承認したクリック操作、フォーム送信、サインイン状態での操作が、自分のアカウントから行われたものとして扱われる場合があります。ChatGPT の作業中もブラウザを使い続けるには、ChatGPT に別のブラウザを使用するよう依頼してください。

この機能では、ターミナルアプリや ChatGPT 自体を自動操作できません。これらを自動操作すると、ChatGPT のセキュリティポリシーを回避できてしまうおそれがあるためです。また、管理者として認証したり、コンピューター上でセキュリティやプライバシーに関する権限を求めるプロンプトを承認したりすることもできません。

ファイルの編集とシェルコマンドには、該当する場合、引き続き ChatGPT の承認設定とサンドボックスの設定が適用されます。デスクトップアプリで行った変更は、ディスクに保存され、プロジェクトで追跡されるまで、レビューペインに表示されない場合があります。コンピューターの使用で取得したスクリーンショットを含め、ChatGPT を通じて処理されるコンテンツには、ChatGPT のデータコントロールが適用されます。
