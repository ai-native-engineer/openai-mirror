## ChatGPT Work の概要

ChatGPT Work では、実務を ChatGPT に任せられます。

回答、説明、アイデア出し、短い下書きが必要な場合は、チャットを使用します。
概要資料、プレゼンテーション、分析、定期更新、ワークフロー、レビューして活用できるファイルなど、
明確な成果を伴うタスクを ChatGPT に完了してもらう場合は、ChatGPT Work を使用します。
[チャットと ChatGPT Work の併用](/ja-JP/codex/use-chatgpt)について詳しくご覧ください。

ChatGPT Work は、ファイル、プラグイン、承認済みのツールを使って情報を取得し、完成したファイルを作成し、ワークフローを実行して、レビューできる状態まで作業を仕上げられます。進捗の確認、質問への回答、方針の変更、重要なアクションの承認も可能です。

[デスクトップアプリ](/ja-JP/codex/app)では、該当するツールが利用可能な場合、
ChatGPT Work はローカルファイル、アプリ、ブラウザも使用できます。

コーディング以外の作業に Codex を使用してきた場合は、そのまま Codex を使うことも、代わりに ChatGPT Work を使うこともできます。ChatGPT Work では、日常業務向けに設計された操作環境で、同じ主要機能を利用できます。

## 最初に試すこと

まず、 **Work** に切り替えて、最初のタスクを選びます。
求める成果が明確で、参考資料がいくつかあり、
成果物をレビューできるタスクが適しています。

### ローカルまたはクラウドの選択

デスクトップアプリで、コンポーザーの「 **ローカルで作業**」を開きます。
選択肢に「**クラウド** 」が表示される場合は、アプリを閉じたりコンピューターの電源を切ったりした後も
ChatGPT Work に実行を続けてもらいたいときや、
Web 版やモバイルアプリからチャットを続けたいときに選択します。
タスクにコンピューター上のファイルやアプリが必要な場合は、「 **ローカルで作業** 」を選択したままにします。

クラウドは、ウェブサイトを継続的に調査または確認するスケジュール済みタスクにも便利です。コンピューターがスリープ状態でも実行できるためです。

まず試せる代表的なユースケースは、次の 3 つです。

### プレゼンテーションの作成

ChatGPT Work を使うと、メモ、ドキュメント、調査資料、会議資料を、構成の整ったプレゼンテーションにまとめられます。

  
    
  

### 比較用スプレッドシートの作成

ChatGPT Work を使うと、メモ、ファイル、調査資料を基に、選択肢の比較や意思決定に役立つスプレッドシートを作成できます。

  
    
  

### 定期更新の設定

ChatGPT Work に作業の繰り返し、監視、更新を継続して行ってもらう場合は、スケジュール済みタスクを使用します。

  
    
  

[スケジュール済みタスク](/ja-JP/codex/automations?surface=app)について詳しくご覧ください。

## ChatGPT Work のベストプラクティス

ChatGPT にタスクの完了、ファイルの作成、作業の継続的な管理を任せる場合は、ChatGPT Work を使用します。次のようなタスクに適しています。

- 複数の情報源、プラグイン、ツール、手順を使用するタスク
- 手作業で完了するには相応の時間がかかるタスク
- レビュー、編集、再利用する成果物を作成するタスク
- 継続的な繰り返し、監視、更新が必要なタスク

より良い結果を得るには、必要な成果、使用する情報源やプラグイン、守るべき制約、望ましい成果の基準、レビューや承認のために停止するタイミングを ChatGPT に伝えてください。

**改善前：** 私たちの顧客調査についてのプレゼンテーションを作成してください。

[ChatGPT Work のプロンプト](/ja-JP/codex/prompting#prompting-for-work)について詳しくご覧ください。

## プラグインの追加によるコンテキストの充実と出力の改善

  
    
  

プラグインを使うと、ChatGPT Work を Slack、Google Drive、SharePoint、メール、カレンダー、顧客関係管理システム、プロジェクト管理ツールなど、チームが使うツールと連携できます。

- プラグインライブラリを表示するには、左側のサイドバーで「 **プラグイン** 」を選択します。
- 業務に最も適したプラグインをインストールします。
- ChatGPT に特定のツールを指定するには、プロンプトで `@` に続けてプラグイン名を入力します。

[プラグイン](/ja-JP/codex/plugins)について詳しくご覧ください。

## ChatGPT Work の効率的な活用

慎重な推論、視覚的な判断、完成度の高い最終ファイルが求められる高度な作業には、
[GPT-6 Astra](/ja-JP/codex/models#gpt-6-astra) を選択します。より単純なタスクには、
Sol、Terra、Luna を検討してください。
モデルセレクターで利用可能なモデルから選択し、
大規模なタスクを始める前に[プランの使用状況](/ja-JP/codex/pricing)を確認してください。

ChatGPT Work は、複数の手順、情報源、ツールを伴う本格的なタスクや、完成した成果物が必要なタスクに最適です。長時間かかるタスクや複雑なタスクでは、ChatGPT が代わりに行う作業が増えるため、より多くのクレジットを消費する場合があります。プロンプトの数ではなく、完成した成果の価値に注目してください。

適切な制約を設けて、タスクの対象を絞ります。たとえば、「これらの情報源だけを使用する」「上位 5 つの選択肢を比較する」「何かを送信する前に停止する」などです。

簡単な質問、短い文章の書き換え、助言だけが必要な意思決定には、代わりにチャットを使用します。

[効率的な作業方法](/ja-JP/codex/prompting#prompting-for-work)について詳しくご覧ください。

安全性レビューのためにタスクが一時停止した場合は、通知に従い、
提示された確認結果があれば、その内容を確認してから続行してください。[安全性の監視と一時停止されたタスク](/ja-JP/codex/agent-approvals-security#safety-monitoring-and-paused-tasks)をご覧ください。
