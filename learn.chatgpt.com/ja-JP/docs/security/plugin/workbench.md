セキュリティワークベンチでは、Codex デスクトップアプリでスキャン、検出結果、リポジトリを
まとめて管理できます。Codex は通常のタスクとしてスキャンを分析し、
ワークベンチにはスキャンと結果が保存されるため、後から確認できます。

ChatGPT デスクトップアプリで ChatGPT のドロップダウンメニューを開き、 **Codex** を選択します。
[Codex Security プラグイン](/ja-JP/codex/security/plugin)をインストールして有効にしてから、
サイドバーで **セキュリティ** を選択します。

  **セキュリティ** が表示されない場合は、 **Codex** が選択され、プラグインが
  インストールされて有効になっていることを確認します。必要に応じてデスクトップアプリとプラグインを更新し、
  ワークスペース管理者がプラグインの使用を許可しているか確認します。

## スキャンの開始

スキャンの品質を最大限に高めるには、<code>{RECOMMENDED_MODEL_REFERENCES.latestSecurityScanModel.slug}</code> を使用し、
推論強度を `xhigh` に設定します。

1. **スキャン** を開き、 **+ スキャン**を選択します。
2. 既存のリポジトリまたは別のフォルダーを選択します。
3. **コードベース** を選択してリポジトリをスキャンするか、 **変更** を選択して
   Git で管理されている変更をレビューします。
4. 標準のコードベーススキャンでは、リポジトリ全体またはフォルダーを選択します。
5. ディープスキャンを実行するには、まずリポジトリまたはフォルダーをコードベースとして選択し、
    **ディープスキャン**をオンにします。ディープスキャンでは、選択したコードベース全体をレビューします。
6. 変更スキャンでは、未コミットの変更、コミット、または
   リビジョンの範囲を選択します。変更スキャンでは **ディープスキャン** を利用できません。
7. モデルと推論強度を選択します。 **追加のコンテキスト** を開き、
   関連する攻撃ベクトル、重点領域、その他のセキュリティコンテキストを記述します。
8. **スキャンを開始**を選択します。

## スキャンの進捗確認

スキャンページには、現在のフェーズと、プラグインが報告するスキャンの進捗状況が表示されます。
標準スキャンのフェーズには、脅威モデリング、探索、検証、
影響とパスの分析、レポート作成、最終処理が含まれます。

**アクティビティを表示** を選択すると、スキャンを実行する Codex タスクが開きます。
ワークベンチを離れても、保存済みのスキャンを失うことなく **スキャン** に戻れます。
作業を意図的に停止するには、スキャンを開き、 **スキャンを停止**を選択します。

スキャンが完了したら、結果を開いて対象、リビジョン、
検出結果、カバレッジ、利用可能なレポートアーティファクトをレビューします。

## 複数のスキャンにまたがる検出結果のレビュー

**検出結果** を開き、リポジトリやスキャンを横断して保存済みの検出結果を確認します。
一覧を検索または絞り込み、検出結果を選択して、概要、
ソースコード上の根拠、検証内容、影響をレビューします。

検出結果の詳細は **概要** で確認します。 **パッチ** では、対象を絞った修正の生成、
レビュー、適用、検証を行えます。修復ワークフローについては、[セキュリティ検出結果の
修正と検証](/ja-JP/codex/security/plugin/fix-findings)を参照してください。

  **検出結果** タブには、保存済みの Codex Security スキャンによる検出結果が表示されます。
  インポート済みのチケットやその他の既存のセキュリティ上の問題は、別の
[バックログのトリアージワークフロー](/ja-JP/codex/security/plugin/triage-backlog)で引き続き扱われます。

## リポジトリ履歴の確認

**リポジトリ** を開いて、利用可能なリポジトリとフォルダーを参照します。
リポジトリを選択すると、スキャン履歴、最後にスキャンされたリビジョン、
未解決の検出結果を確認できます。リポジトリの詳細画面から以前のスキャンを開くか、
そのリポジトリに関連付けられた検出結果を表示できます。

リポジトリにスキャンがない場合は、詳細画面からスキャンを開始するか、ワークベンチで **+ スキャン**を選択して
開始します。

## 会話からのスキャン開始

通常の会話で、インストール済みの Codex Security プラグインを実行するよう
Codex に依頼することもできます。共有のプラグインワークベンチを使用するスキャンは **スキャン**に表示されるため、
セキュリティワークベンチから進捗や結果を再度確認できます。

ターミナルでのスキャンと自動化については、[Codex Security CLI
クイックスタート](/ja-JP/codex/security/cli)を参照してください。
