ローカル環境では、Worktree のセットアップ手順だけでなく、プロジェクトでよく使うアクションも構成できます。

  ローカル環境は、ChatGPT デスクトップアプリの Codex でのみ利用できます。
  ローカル環境を構成または使用する前に、 **Codex** を選択してください。

ローカル環境は、[ChatGPT デスクトップアプリの設定](codex://settings) 画面で構成します。生成されたファイルをプロジェクトの Git リポジトリにコミットすると、ほかのユーザーと共有できます。

Codex は、この構成をプロジェクトのルートにある `.codex` フォルダーに保存します。
リポジトリに複数のプロジェクトが含まれている場合は、
共有の `.codex` フォルダーを含むプロジェクトディレクトリを開いてください。

## セットアップスクリプト

Worktree はローカルチャットとは別のディレクトリを使用するため、プロジェクトのセットアップが完了していない場合があり、依存関係や、リポジトリにコミットされていないファイルが不足している可能性があります。新しいチャットの開始時に Codex が新しい Worktree を作成すると、セットアップスクリプトが自動的に実行されます。

このスクリプトを使用して、依存関係のインストールやビルドプロセスの実行など、環境の構成に必要なコマンドを実行してください。

たとえば、TypeScript プロジェクトでは、セットアップスクリプトを使用して依存関係をインストールし、初回ビルドを実行できます：

```bash
npm install
npm run build

セットアップがプラットフォーム固有の場合は、macOS、Windows、Linux のいずれかに対応するセットアップスクリプトを定義し、デフォルトのスクリプトを上書きしてください。

## アクション

<div>
アクションを使用して、アプリの開発サーバーの起動やテストスイートの実行など、よく使うタスクを定義します。これらのアクションは ChatGPT デスクトップアプリのトップバーに表示され、すばやくアクセスできます。アクションは、アプリの [統合ターミナル](/ja-JP/codex/integrated-terminal) 内で実行されます。

アクションを使うと、プロジェクトのビルドや開発サーバーの起動など、よく使う操作を毎回入力せずに済みます。一度だけ簡単にデバッグしたい場合は、統合ターミナルを直接使用できます。

たとえば、Node.js プロジェクトでは、次のスクリプトを含む「実行」アクションを作成できます：

```bash
npm start

アクションのコマンドがプラットフォームごとに異なる場合は、macOS、Windows、Linux それぞれに対応するスクリプトを定義してください。

アクションを区別できるように、それぞれのアクションに対応するアイコンを選択してください。

## 組み込みの Git ツールの使用

<div class="my-8 grid gap-6 md:grid-cols-[minmax(0,1fr)_minmax(16rem,42%)] md:items-center">

<div>

ChatGPT デスクトップアプリの Codex では、ローカルプロジェクトと Worktree ごとに、よく使う Git 操作機能が用意されています。差分ペインには、現在のチェックアウトの変更内容が表示され、Codex に対応を依頼するインラインコメントを追加できます。アプリ内で、個々の変更箇所やファイル全体をステージまたは元に戻したり、変更をコミットしたり、ブランチをプッシュしたり、Pull Request を作成したりできます。

アプリに用意されていない Git 操作には、[統合ターミナル](/ja-JP/codex/integrated-terminal) を使用してください。
並行作業による変更をローカルのチェックアウトから分離するには、
[Worktree](/ja-JP/codex/environments/git-worktrees) でタスクを開始してください。

</div>
