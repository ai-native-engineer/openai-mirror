ChatGPT デスクトップアプリで、ChatGPT のドロップダウンを開き、 **Codex** を選択します。
Codex チャットを開始する際は、実行場所を選択します：

- **ローカル**：現在のプロジェクトディレクトリで直接作業します。
- **Worktree**：Git の Worktree で変更を分離します。[詳しく見る](/ja-JP/codex/environments/git-worktrees)。
- **クラウド**：設定済みのクラウド環境でリモート実行します。

**ローカル** と **Worktree** のチャットは、どちらもお使いのコンピューターで実行されます。

用語集とコンセプトの詳細については、[コンセプトのセクション](/ja-JP/codex/prompting)をご覧ください。
