# Codex リモート

接続済みのコンピューター上の Codex タスクをスマートフォンから開始し、指示を送り、承認・レビューできます。

リモート

スマートフォンからコーディングタスクを開始・進行管理・レビュー

スマートフォンから進捗を確認し、アクションを承認して、指示を送信できます。Codex は各タスクを接続済みのコンピューターで実行します。

リモートをセットアップ

リモート接続ガイド

ChatGPT モバイルアプリは、接続済みの Mac または Windows PC と組み合わせて使用します。利用可否は、ロールアウト状況とワークスペースの設定によって異なります。

Codex リモートのインタラクティブプレビュー

接続済みのコンピューター、タスク、会話、承認、変更されたファイルを表示する、Codex リモートのインタラクティブなモバイルアプリ

Codex リモートの利点

スマートフォンからタスクを開始

接続済みのコンピューターとプロジェクトを選択し、タスクの内容を説明して、Codex に作業を任せます。

作業の進行に合わせて指示

タスクを開いて進捗を確認し、デスクに戻ることなく新しい指示を送信できます。

要求されたアクションを承認

接続済みのコンピューターで Codex が作業を続ける前に、要求されたコマンドとアクションを確認します。

結果をレビュー

応答、変更されたファイル、差分、テスト結果を確認し、次の対応を決めます。

リモートの利用開始

コンピューターを接続し、アクセスを承認して、最初のタスクを開始します。
