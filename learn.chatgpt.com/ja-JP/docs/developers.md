# 開発者向け

開発ワークフロー、環境、拡張機能、連携の設定

Codex をコードベース、開発環境、自動化、チームのツールと組み合わせて活用できます。

Codex は、ローカル環境とクラウド環境の両方で、日々のコーディング作業から高度な連携まで対応します。開発ワークフローには、コードレビュー、統合ターミナル、再利用可能なスキルとプラグイン、SDK と App Server による自動化、チーム向けツール、各インターフェースのリファレンス資料が含まれます。

エンジニア向け Codex 新着情報

ワークフローを詳しく見る

Web アプリケーション向けの Codex の出力、統合ターミナル、コードレビュー

開発ワークフロー

ChatGPT で変更内容をレビューし、開発ツールを使用します。

コードレビュー

リリース前に変更内容をレビューし、フィードバックに対応します。

統合ターミナル

ChatGPT デスクトップアプリ内でコマンドを実行し、出力を確認します。

拡張と自動化

開発ワークフローをパッケージ化し、決定論的な自動化を実行します。

スキルの構築

ChatGPT と Codex で繰り返し実行するタスク向けに、指示とリソースをパッケージ化します。

プラグインを作成する

ChatGPT と Codex 向けに、スキルと MCP サーバーをパッケージ化します。

サイトツール（WebMCP）

WebMCP を使って、AI エージェントがウェブサイトを直接操作できるようにします。

フック

Codex がライフサイクルイベントを発行した際に、カスタムコマンドを実行します。

環境

開発作業の実行場所と分離方法を選択します。

タスクの実行方法について、ローカル、クラウド、その他の選択肢を比較します。

ローカル環境

プロジェクトと Worktree 向けに、セットアップスクリプトとアクションを設定します。

クラウド環境

設定済みのクラウド環境に作業を委任します。

Git Worktree

並行して進める変更を、別々の作業ツリーに分離します。

Codex を使った開発

プロダクト、システム、自動化されたワークフローに Codex を組み込みます。

Codex SDK

アプリケーションから Codex をプログラムで制御します。

App Server

Codex クライアントを支えるプロトコルと連携します。

MCP サーバー

Model Context Protocol を通じて Codex の機能を公開します。

GitHub Action

GitHub Actions のワークフローから Codex を実行します。

非対話モード

スクリプトやその他の自動化システムから Codex を実行します。

サードパーティ連携

チームがすでに使用しているツールから作業を委任し、進捗を追跡します。

GitHub

作業を割り当て、変更内容をレビューし、Pull Request の作成に向けて進めます。

GitLab（ベータ版）

プロジェクトを接続し、作業を委任して、マージリクエストをレビューします。

Slack

外部でのやり取りから Codex のチャットを開始し、結果を返します。

Linear

イシューを Codex に割り当て、作業の完了まで進捗を追跡します。

リファレンス

開発者向けの各インターフェースについて、コマンド、設定、プラグイン申請エラーを確認できます。

CLI のカスタマイズ

シンタックスハイライト、テーマ、シェルの動作を調整します。

開発者向けコマンド

デスクトップアプリ、Codex CLI、IDE 拡張機能で、コマンドとスラッシュコマンドを使用します。

開発者向け設定

デスクトップアプリ、Codex CLI、IDE 拡張機能を開発用に設定します。
