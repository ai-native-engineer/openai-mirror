ChatGPT に画像の生成や編集を依頼します。コードと並行して、または ChatGPT のチャット内で作成したい UI アセット、
バナー、背景、イラスト、スプライトシート、プレースホルダーには
画像生成を利用できます。

App のコンポーザーから画像を依頼します。ChatGPT で既存のアセットを変換する場合や、
視覚的な参考資料として使う場合は、参照画像を追加します。

### 生成画像のレビューと編集

生成された画像を選択して、拡大ビューアーを開きます。1 枚の画像を確認する
**フォーカス表示** と、同じチャットで生成された画像をまとめて確認する **キャンバス表示** を
切り替えられます。

**キャンバス表示**では、 **コメント** を使って 1 枚以上の画像に具体的なフィードバックを
追加できます。 **複数選択** で対象の画像を選んだ後、同じチャットで
コメントと追加の編集指示を送信します。変更する点と維持する点を
説明してください。

ChatGPT の Web チャットから画像を依頼します。ChatGPT で画像を編集する場合や、
視覚的な参考資料として使用する場合は、コンポーザーに参照画像を添付します。

インタラクティブセッションで画像を説明するか、`$imagegen` を含めて
画像生成スキルを明示的に呼び出します。既存の画像を結果の参考にする場合は、`-i` または
`--image` で添付します。

拡張機能のチャットから画像を依頼します。参照画像を
<kbd>Shift</kbd> キーを押しながらコンポーザーにドラッグすると、Codex に既存のアセットの
編集や、それを基にした作成を依頼できます。

## 画像の生成または編集

画像を自然言語で説明します。ChatGPT で既存のアセットを変換または拡張する場合は、
参照画像を追加します。

プロンプトに `$imagegen` を含めて、画像生成スキルを
明示的に呼び出します。

組み込みの画像生成では `gpt-image-2` が使われ、通常の
Codex 利用上限にカウントされます。画像生成では、画像の品質とサイズに応じて、
画像生成を行わない同等のターンよりも、プランに含まれる利用枠を平均で 3～5 倍速く
消費します。より大規模なバッチでは、環境に `OPENAI_API_KEY` を設定し、
ChatGPT に API 経由で画像を生成するよう依頼してください。この場合は API の料金が適用されます。

ChatGPT の Web 版で画像を利用できるかどうかと利用上限は、プランと
ワークスペースの設定によって異なります。プログラムから画像を生成する場合は、[画像生成
API](/api/docs/guides/image-generation) を使用してください。

## 効果的な画像プロンプトの作成

有用な画像プロンプトは、多くの場合、明確な 1～3 文だけで十分です。結果の成否を左右する
次の詳細を明記します：

- 画像の目的や想定する対象者を説明します。
- 主な被写体と、何が起きているかを説明します。
- 背景、構図、ビジュアルスタイルを説明します。
- 重要な場合は、フレーミング、寸法、照明、色、素材を追加します。
- 画像に含めてはいけないものも含め、制約を明記します。

漠然とした印象ではなく、具体的な視覚表現を使います。たとえば「美しい照明」と依頼する代わりに、
光がどこから差すかを説明します。必ず固定しておく必要がある
要件は繰り返し伝えます。

## 結果の調整

まず核となるアイデアから始め、その後は対象を絞って少しずつ修正します。構図や
その他の重要なディテールが意図せず変わらないよう、一度に 1 つの要素だけを調整してください。
画像内の特定の範囲を選択し、その範囲に加える変更を説明することも
できます。

既存の画像を編集する場合は、変更する点と、そのまま維持する点を
正確に指定します。

より広範に修正する場合は、変更内容が明確に伝わる、端的なフィードバックにします。画像を
明るくする、彩度を下げる、背景を簡素化する、または構図を維持したまま
スタイルを変更する、といった指示です。

## 複数の参照画像の使用

一方の画像で内容を指定し、もう一方でスタイル、レイアウト、その他の視覚的な方向性を
指定する場合は、少数の参照画像を使用します。各画像を順番で示し、
画像同士の関係を説明してください。要素を組み合わせるときは、前景、背景、
左、右など、位置関係を表す語を使用します。

## 画像へのテキスト追加

画像内のテキストは短くし、内容を正確に指定します。表示する文言をそのまま
かぎ括弧で囲み、希望する大文字・小文字表記を維持したうえで、フォントの
スタイル、サイズ、色、配置を説明します。一般的でない名前は、正確さが
重要な場合に 1 文字ずつ指定します。他のテキストを許可するかどうかも明記します。

## インフォグラフィックと情報量の多いレイアウトの作成

画像生成は、解説図、ポスター、ラベル付き図表、
タイムラインなど、情報量の多いビジュアルの下書きに役立ちます。情報の
階層とレイアウトを説明し、ラベルは簡潔にして、文字を鮮明に描画するよう依頼してください。
文章量が多い場合や、本番用途で品質が重要なタイポグラフィでは、すべての文言を確認し、
必要に応じてデザインツールで仕上げてください。

## その他の注意事項

- **肖像の使用には注意してください。** 実在の人物を描写する場合は、必要に応じて
  参照写真を提供し、その人物の肖像を使用する許可を得ていることを
  確認してください。
- **独自の表現を依頼してください。** 特定のブランド、製品、アーティスト、作品を模倣せず、汎用的または独自のデザインを
  依頼してください。
- **クレジット表記は任意です。** 生成画像に OpenAI のクレジットを表記する必要はありませんが、
  経緯を示すことが有用な場合は、アセットの作成方法を説明できます。
- **適用されるポリシーに従ってください。** 組織のガイドラインと
  [OpenAI の利用
  ポリシー](https://openai.com/policies/usage-policies/)に従って画像を使用してください。
