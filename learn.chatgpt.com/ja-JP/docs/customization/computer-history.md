macOS の ChatGPT デスクトップアプリでは、ChatGPT Pro、Business、Enterprise のユーザーは、コンピューターの使用履歴が **デフォルトでオフ** になっています。
  Pro ユーザーは、
  この機能をオンにするかどうかを選択できます。Business と Enterprise のワークスペースでは、
  管理者が明示的にアクセスを許可して初めて、各メンバーがオンにするかどうかを選択できます。
  コンピューターの使用履歴には[メモリ](/ja-JP/codex/customization/memories)も必要で、
  API キーや Amazon Bedrock では利用できません。
  欧州経済領域（EEA）、スイス、
  英国などの対応地域で利用できます。

コンピューターの使用履歴は、アプリやウェブサイトでのアクティビティを、ChatGPT と Codex が参照できるメモリとタイムラインに変換します。最近の作業について自然な言葉で質問したり、中断したところから作業を再開したり、作業パターンを把握したり、繰り返すワークフローをスキルやオートメーションに変換したりできます。

履歴の記録は、自分で機能をオンにして初めて始まります。対象となるアプリやウェブサイトを選択でき、macOS のメニューバーから収集状況を確認して一時停止することも、履歴をいつでも確認または削除することもできます。

コンピューターの使用履歴は、以前の Chronicle リサーチプレビューに代わる機能ですが、単に名称を変更したものではなく、システムを再構築しています。操作イベントと、macOS のアクセシビリティ機能を通じて利用できるテキストやその他のコンテキストを活用し、確認や削除が可能な要約を作成します。履歴にスクリーンショットが含まれることや、音声が録音されることはなく、プライベートモードでのウェブ閲覧に関するアクティビティも一切含まれません。

  

## コンピューターの使用履歴の活用方法

コンピューターの使用履歴は、最近のアクティビティをコンテキストとして提供します。ファイル、Slack での会話、Google Doc など別の情報源の方がタスクに適している場合、ChatGPT と Codex は履歴からその情報源を特定し、直接読み取ることができます。

## コンピューターの使用履歴の仕組み

コンピューターの使用履歴は、許可されたアプリやウェブサイトから操作イベントのストリームを作成します。イベントには、クリック、文字入力、キーボードショートカット、アプリの切り替え、macOS のアクセシビリティ機能を通じて取得できるコンテキストなどが含まれます。これらのイベントは、テキストによる要約とローカルのメモリファイルに定期的に変換されます。

コンピューターの使用履歴にスクリーンショットは含まれず、マイク入力やシステム音声も記録されません。プライベートモードでのウェブ閲覧は一切含まれません。

**設定 \> コンピューターの使用履歴 \> 履歴**では、タイムライン上の要約が
日付と時刻ごとに整理されます。各項目には次の情報が表示される場合があります：

- アクティビティのタイトルとテキストによる要約
- 要約の作成に使用されたアプリ
- ChatGPT が繰り返し行える作業を特定した場合に提案されるスキルまたは自動化
- メモリファイルを Finder で表示する、または項目を削除する操作

**履歴について質問** を選択すると、コンピューターの使用履歴を使ったチャットを開始できます。
次のようなプロンプトも使用できます：

- 「最後に休憩する前は何の作業をしていましたか？」
- 「今日、少し前に探していた提案書はどこにありますか？」
- 「今日取り組んだタスクとその進捗状況を一覧にしてください」
- 「スタンドアップミーティング用に、昨日行った作業を要約してください」

## 権限とアクセス

コンピューターの使用履歴では、ワークスペースでのアクセス権、個人ごとのオプトイン、メモリ、履歴に含めるアプリやウェブサイトを個別に管理します：

- **ワークスペースでのアクセス権：** コンピューターの使用履歴は、Business および
  エンタープライズのワークスペースではデフォルトでオフになっており、管理者がアクセス権を
  明示的に付与するまで利用できません。エンタープライズ管理者は、 **コンピューターの使用履歴を
  有効にする** を[**ワークスペース設定 \> 権限とロール**](https://chatgpt.com/admin/settings)で選択して、
  適切なワークスペースのロールにアクセス権を付与できます。
- **個人ごとのオプトイン：** ワークスペースでアクセス権が付与されても、メンバーが
  コンピューターの使用履歴をオンにするかどうかを選べるようになるだけです。この機能が自動的にオンになることはありません。
  ChatGPT Pro のユーザーも含め、各自が個別にオプトインする必要があります。
- **メモリ：** コンピューターの使用履歴を利用するには、[メモリ](/ja-JP/codex/customization/memories)も必要です。
  `/memories` を使用すると、個々のチャットでローカルのメモリを利用できるか、
  そのチャットを今後のメモリの作成に反映するかを管理できます。
- **アプリとウェブサイト：** 操作イベントの収集対象となる
  情報源は、アプリやウェブサイトの権限によって決まります。特定の情報源だけを許可したり、
  履歴に含めたくないアプリやウェブサイトの URL を除外したりできます。

ワークスペースのロールにアクセス権がない場合は、ローカル設定を変更してもコンピューターの使用履歴を有効にできません。

## コンピューターの使用履歴の有効化

コンピューターの使用履歴はデフォルトでオフになっています。Business またはエンタープライズのワークスペースを利用している場合は、オンにする前に管理者にアクセス権の付与を依頼してください。管理者の承認だけではオプトインしたことにはなりません。

1. macOS で ChatGPT デスクトップアプリを開きます。
2. 設定の **連携**から、 **コンピューターの使用履歴**を選択します。
3. **オンにする** を選択し、プライバシー、権限、
   ローカルストレージに関する情報を確認します。
4. 求められた場合は、 **メモリ**をオンにします。コンピューターの使用履歴で
   チャットやタスクをまたいでアクティビティのコンテキストを利用するには、メモリが必要です。
5. 履歴に含めるアプリやウェブサイトを選択し、macOS で権限の許可を求められた場合は、その指示に従います。

コンピューターの使用履歴では、画面収録の権限は必要ありません。設定項目が表示されない場合は、ご利用のプランがコンピューターの使用履歴に対応していることと、該当する場合はワークスペース管理者がこの機能を有効にしていることを確認してください。

## 履歴に含める内容の管理

今後の履歴に含めるアプリやウェブサイトと、コンピューターの使用履歴による操作イベントの収集を有効にするかどうかを管理できます。

### アプリとウェブサイトの選択

**設定 \> コンピューターの使用履歴 \> 権限**で、コンピューターの使用履歴に含める
アプリやウェブサイトを選択します：

- **次のアプリを除外** と **次のウェブサイトを除外** では、指定したアプリや URL を
  ブロックし、それ以外の対応する情報源は許可します。
- **次のアプリのみを含める** と **次のウェブサイトのみを含める** では、
  明示的に選択した情報源のみを許可します。

履歴のタイムラインの項目でアプリのアイコンを選択すると、そのアプリを今後の履歴から除外することもできます。あとから再び対象に含めることもできます。

プライベートモードでのウェブ閲覧は一切含まれません。アプリやウェブサイトの権限の変更は、今後の履歴にのみ反映されます。既存の項目を消すには、項目を削除するか履歴を消去してください。

### 収集の一時停止、再開、停止

コンピューターの使用履歴の設定画面または macOS のメニューバーで、アクティビティを収集するタイミングを管理できます：

- macOS のメニューバーで ChatGPT アイコンを選択し、コンピューターの使用履歴のメニューを展開すると、記録対象のアクティビティを確認し、各種設定にアクセスできます。
- **一時停止** を選択すると、新しい操作イベントの収集が停止します。
再び収集する場合は、**再開** を選択します。
- 今後のアクティビティの収集を停止するには、コンピューターの使用履歴をオフにします。

コンピューターの使用履歴には、コミュニケーションアプリやウェブサイトの操作イベントが含まれる場合があります。相手から事前に明示的な同意を得ていない場合は、他の人とやり取りしている間、この機能をオフにしてください。健康、金融、個人に関する機密性の高い情報を扱うアプリについては、機能を一時停止するか、そのアプリを対象から除外することを検討してください。

## 履歴の確認と消去

**設定 \> コンピューターの使用履歴 \> 履歴** を開くと、コンピューターの使用履歴が
要約した内容を確認できます。要約に対応するローカルのメモリファイルを Finder で表示したり、
タイムラインの項目を個別に削除したり、直近 10 分、直近 1 時間、直近 1 日分、
またはすべての履歴を消去したりできます。macOS のメニューバーからは、
最近使用したアプリの直近のセッションも消去できます。

履歴を消去すると、関連する操作イベントと、それらのイベントから生成されたメモリが削除されます。この操作は元に戻せません。

## プライバシーとローカルストレージ

コンピューターの使用履歴は、操作イベントのストリームを Mac に一時保存し、ChatGPT と Codex がメモリを生成して、おすすめのワークフローを作成できるようにします。このストリームには、クリックや文字入力などのアクティビティのほか、macOS のアクセシビリティ機能を通じて取得できるテキストやその他のコンテキストが含まれる場合があります。履歴にスクリーンショットが含まれることはなく、マイク入力やシステム音声も記録されません。プライベートモードでのウェブ閲覧は一切含まれません。

一時イベントファイルは最長 48 時間保持されます。生成されたメモリファイルは、削除または消去するまでファイルシステムに残り、履歴のタイムラインから表示できます。

### コンピューターの使用履歴のデータ保存場所

コンピューターの使用履歴は、操作イベントを Mac に一時保存します。
イベントファイルは ChatGPT の
[App Group](https://developer.apple.com/documentation/xcode/protecting-local-app-data-using-containers) 内に隔離されるため、
明示的な許可がない限り、ほかのアプリからアクセスすることはできません。
ChatGPT と Codex は、これらのイベントファイルを 48 時間後に削除します。

コンピューターの使用履歴は、Codex と同じ種類のローカルメモリを生成します。これは、閲覧や編集が可能な
プレーンテキスト形式の Markdown ファイルです。これらのファイルは
`$CODEX_HOME/memories/extensions/skysight/` 配下に保存され、このパスは通常
`~/.codex/memories/extensions/skysight/` に展開されます。

### OpenAI と共有されるデータ

コンピューターの使用履歴は操作イベントをローカルで記録した後、操作イベントのストリームにアクセスできる一時的な Codex セッションを定期的に開始して、アクティビティを要約し、メモリを作成します。

OpenAI は一時イベントファイルを自社サーバー上で処理してメモリを生成し、生成されたメモリは Mac にローカル保存されます。OpenAI は、法令で義務付けられている場合を除き、処理後にこれらのイベントファイルを保持しません。また、学習にも使用しません。

ChatGPT または Codex が今後のチャットでメモリを使用する場合、関連するメモリの内容や
操作イベントがコンテキストに含まれることがあります。このチャットの内容は、
OpenAI のモデルの改善に使用される場合があります。ただし、
[ChatGPT のデータ管理設定](https://help.openai.com/en/articles/7730893-data-controls-faq)で許可されている場合に限ります。
また、メモリには
[ほかの Codex のメモリと同じチャット単位の管理設定](/ja-JP/codex/customization/memories#control-memories-per-chat)が適用されます。

### プロンプトインジェクションのリスク

コンピューターの使用履歴を利用すると、アプリやウェブサイトのコンテンツを通じてプロンプトインジェクションが発生するリスクが高まります。たとえば、悪意のある指示を含むウェブサイトを閲覧した場合、ChatGPT や Codex がその指示に従ってしまう可能性があります。

## トークン使用量

コンピューターの使用履歴は、アクティビティを要約してメモリを作成する際にトークンを使用します。

## トラブルシューティング

コンピューターの使用履歴を利用できるにもかかわらず、開始されない場合：

1. **メモリ** がオンになっていることを確認します。
2. **設定 \> コンピューターの使用履歴** を開き、表示されている状態に応じて **セットアップを完了**、 **再開**、
   または **再試行**を選択します。
3. それでも設定を利用できない場合は、ChatGPT デスクトップアプリを終了して再度開きます。
