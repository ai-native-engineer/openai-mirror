# 機能

ChatGPT のワークフローやできること、コマンド、設定を詳しく見る

ChatGPT での作業に役立つワークフローやできること、コマンド、設定をご覧ください。

ChatGPT では、プロジェクトや長時間にわたるチャットを、ウェブ閲覧、ファイル、画像、プラグインと組み合わせて活用できます。適切なワークフローの選択から、各チャットに必要なコンテキストとツールの用意まで、コマンド、設定、トラブルシューティングのリファレンスが一連の作業を支えます。

プロジェクトとチャットを詳しく見る

チャット、プラグイン、コンテンツツール用の Codex サイドバーと「追加」メニュー

ワークフロー

作業を整理し、委任し、レビューする方法です。

プロジェクトとチャット

関連するチャット、コンテキスト、作業をひとまとめにできます。

Codex リモート

スマートフォンからタスクを開始し、アクションを承認して、作業をレビューできます。

Sites

ChatGPT でインタラクティブなウェブサイトやアプリを作成、保存、公開できます。

可視化

アイデアや情報をインタラクティブな図解に変換します。

スケジュール済みタスク

定期的な作業をスケジュールし、完了後に結果をレビューします。

長時間にわたる作業

席を外している間も、ChatGPT に作業を続けてもらえます。

通知

作業への対応が必要になったときの ChatGPT の通知方法を選べます。

ペット

アニメーションで動く相棒を選び、チャットの進行を見守れます。

Codex Micro

Work Louder のキーボードから ChatGPT のチャットの状況を確認し、操作できます。

できること

ChatGPT が内容を理解し、コンテンツを作成し、アクションを実行するためのツールです。

ブラウザ

主導権を保ったまま、ChatGPT にウェブサイトの閲覧や操作を任せられます。

コンピューターの使用

画面上のインターフェースを通じて、ChatGPT にアプリを操作してもらえます。

ChatGPT 音声モード

ChatGPT デスクトップアプリのチャット、Work、Codex で音声機能を試せます。

プラグイン

再利用可能なワークフロー、連携ツール、共有コンテキストをインストールします。

ウェブ検索

最新の情報を見つけ、情報源をタスクに取り込めます。

画像生成

作業の一環として画像を作成、編集できます。

画像入力

スクリーンショットや画像を ChatGPT のコンテキストとして使用します。

Appshots

視覚的な確認やデバッグのために、アプリの状態をキャプチャします。

ブラウザ拡張機能

Chrome、Edge、Brave、Opera、Vivaldi のいずれかを ChatGPT と組み合わせて使えます。

ファイルの操作

ドキュメントなどのファイルを作成し、プレビューしながら調整します。

リファレンス

ChatGPT デスクトップアプリのコマンドと設定を確認できます。

コマンド

アプリのコマンド、キーボードショートカット、ディープリンクを使用します。

スラッシュコマンド

対話中によく使う操作をショートカットで実行します。

設定

ChatGPT デスクトップアプリの環境設定をカスタマイズします。

トラブルシューティング

ChatGPT デスクトップアプリでよくある問題を解決します。
