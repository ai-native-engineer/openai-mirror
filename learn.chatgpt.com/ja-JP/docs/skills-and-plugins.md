スキルとプラグインを使うと、適切な手順、リソース、ツールを活用して、ChatGPT と Codex で
繰り返し作業を完了できます。チャットのたびに同じプロンプト、テンプレート、要件、プロセスを
貼り付ける手間も減らせます。

- **スキル**には、特定の
  タスクやワークフロー向けの手順と補助リソースがまとめられています。
- **プラグイン**は、スキルやコネクタ、または
  その両方を含められるインストール可能なバンドルです。コネクタは Model Context Protocol（MCP）サーバーを基盤としており、
  必要に応じて ChatGPT のカスタム UI も組み込めます。

## 繰り返し作業へのスキル活用

スキルは、ChatGPT や Codex にタスク固有のガイダンスを提供する、再利用可能な
ワークフローです。繰り返し作業で普段使っている進め方を取り込めるため、どちらの
製品でも、そのタスクが発生するたびに同じプロセスに従えます。

スキルでは、次の要素を組み合わせられます：

- スキルを適用できる場面を ChatGPT と Codex が判断するのに役立つ、
名前と説明。
- プロセスと期待される結果を定義するワークフローの手順。
- テンプレート、例、ブランドガイドライン、スキーマ、連携ツールなどの
補助リソース。

一定の進め方を繰り返すことが良い結果につながる作業では、スキルが特に役立ちます。
たとえば、スキルを使って、日次ブリーフの作成、ドキュメントのレビュー、プレゼンテーションの作成、
チームの文章作成基準の適用、または同じ連携ツールから毎週情報を収集する
ことができます。

スキルを使用すると、一貫性を高め、チームのベストプラクティスを
ワークフロー内で活用できるようになります。また、文書化されていない
知識に頼らず、標準プロセスを共有できます。

リクエストがスキルの目的に合っていれば、ChatGPT と Codex はそのスキルを選択できます。
明示的に選択することもできます。ChatGPT では `@` メンション、Codex
では `$` メンションを使用できます。

## スキルの作成

まず、すでに繰り返しているタスクを、ChatGPT と Codex 向けの専用手順書に
まとめます。最初に作るスキルには、週次報告、キャンペーン概要、
会議後のフォローアップなど、手順と形式を一貫させたい
タスクが適しています。

実用的なスキルの作成手順：

1. **目的を絞ったタスクを 1 つ選びます。** ファイル、リンク、メモなど、通常は何を材料に
   作業を始めるか、完成した成果物がどのようなものかを整理します。
2. **ワークフローを説明します。** ChatGPT では `@skill-creator` から始め、Codex では
   `$skill-creator` を使用します。目標、実行する手順、期待する
   形式、スキルに必ず含めるものと避けるものを説明します。テンプレートや
   良い例があれば追加します。
3. **ドラフトをレビューして試します。** 手順を確認し、実際にありそうな
   リクエストでスキルをテストします。手順が抜けたり、結果が希望する
   形式から外れたりした場合は、スキルを調整します。
4. **インストールして再利用します。** スキルを有効にすると、ChatGPT または Codex が関連する
   リクエストでそのスキルを使用できるほか、明示的に選択することもできます。また、
   ワークスペースの設定で許可されていれば、チームメンバーと共有できます。

## ツールと共有ワークフローへのプラグイン活用

プラグインを使うと、再利用可能な機能のインストールと共有が簡単になります。プラグインでは、
スキルと、GitHub、Google Drive、Slack などのサービス向けコネクタを
組み合わせられます。さらに、追加のツールやコンテキストを提供する MCP サーバーも含められます。

ChatGPT と Codex は、1 つの共通プラグインディレクトリを共有しています。ワークフローを自分で
作成せず、既存のものを追加したい場合は、このディレクトリを参照してください。プラグインを
インストールした後は、タスクを直接記述するか、利用する環境の呼び出し構文を使ってプラグインまたは
同梱のスキルを明示的に選択します。

[プラグインのインストール方法と使用方法を学ぶ](/ja-JP/codex/plugins)。

## スキルとプラグインの使い分け

特定のタスク向けに再利用可能な手順が必要な場合は、スキルを使用します。
手順と連携サービスやその他のツールを組み合わせた、インストール可能なパッケージが
必要な場合は、プラグインを使用します。

また、
「[Record & Replay](/ja-JP/codex/extend/record-and-replay)」を使ってワークフローを実演することもできます。録画は再利用可能な
スキルに変換されます。独自のバンドルをパッケージ化して配布するには、
「[プラグインを作成する](https://developers.openai.com/plugins/build/plugins)」をご覧ください。

プラグインをサービスに接続したり、MCP ツールを公開したりする必要がある場合は、
「[MCP サーバーを作成する](https://developers.openai.com/plugins/build/mcp-server)」をご覧ください。プラグインを一般公開向けのレビューに提出する準備ができたら、
「[プラグインを提出する](https://developers.openai.com/plugins/deploy/submission)」をご覧ください。

再利用可能なワークフローのその他の例については、「[OpenAI
Academy でのスキル活用](https://openai.com/academy/skills/)」をご覧ください。
