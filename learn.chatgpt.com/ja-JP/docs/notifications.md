通知は、作業への対応が必要になったことを知らせます。通知の設定項目と
配信チャネルは、利用環境によって異なります。

## デスクトップ通知の設定

[**設定**](codex://settings) を開き、ターン完了アラートを表示しないか、
ChatGPT がバックグラウンドにある間のみ表示するか、常に表示するかを選択します。
権限および質問の通知は、個別の設定項目でオンまたはオフにできます。
オペレーティングシステムから、ChatGPT
デスクトップアプリへの通知権限の付与を求められる場合があります。

### アクティビティビューでチャットを確認

**アクティビティ** が利用できる場合は、サイドバーのベルを選択すると、未読、実行中、または応答待ちのチャットを
確認できます。アクティビティビューは、
macOS では <kbd>Cmd</kbd>+<kbd>Option</kbd>+<kbd>U</kbd>、
Windows では <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>U</kbd> で開閉することもできます。

ビューのオプションで、表示するチャットを選択します。現在の
利用環境によっては、**Work**、**チャット**、**ピン留め済み**、
**スケジュール済み** などが表示されます。未読項目をまとめて既読にするには、**すべて既読にする** を選択することもできます。

<a id="follow-task-activity-with-a-pet"></a>

### ペットでチャットの状況を確認

ChatGPT デスクトップアプリのフローティングペットは、他のアプリで作業しながらチャットの
状況を確認するもう一つの方法です。ペットに表示されるチャットの状態は、**実行中**、
**入力が必要**、**準備完了**、**ブロック中** のいずれかです。

[ペット](/ja-JP/codex/pets?surface=app) を参照して、ペットの選択方法やステータスの意味、
独自のペットの作成方法を確認してください。

## Web 通知の設定

**設定 \> 通知** を開き、アカウントで利用できる通知カテゴリと
チャネルを管理します。利用できるチャネルはカテゴリやアカウントによって異なり、
プッシュ通知、メール、SMS などがあります。タスクの通知設定にある **タスクを管理** を選択して、
**スケジュール済み** を開きます。

## CLI 通知の設定

ターミナル通知と外部通知については、
[通知](/ja-JP/codex/config-file/config-advanced#notifications)（
高度な設定ガイド）を参照してください。TUI が通知を送信するタイミングと、
ターン完了時に Codex が外部プログラムを実行するかどうかを選択できます。

<a id="follow-task-activity-in-the-ide"></a>

## IDE でチャットの状況を確認

IDE 拡張機能には個別の通知設定項目がありません。チャットを
開いたままにして、その状況を確認してください。ターン完了時に外部プログラムを
実行するには、接続先の Codex ホストで `notify` を設定します。詳しくは、
[通知](/ja-JP/codex/config-file/config-advanced#notifications)（
高度な設定ガイド）を参照してください。
