リモート接続を利用すると、別のデバイスやマシンで実行中の作業にアクセスできます。
ChatGPT モバイルアプリで「 **リモート** 」を開くと、
接続済みの Mac または Windows デバイス上の ChatGPT や Codex のチャットで作業できます。
ChatGPT デスクトップアプリを実行している別の対応デバイスから作業を続けたり、
アプリを SSH ホスト上のプロジェクトに接続したりすることもできます。

リモートアクセスでは、接続先ホストのプロジェクト、チャット、ファイル、認証情報、権限、プラグイン、コンピューターの使用、ブラウザ設定、ローカルツールを使用します。

## リモートでできること

- ホスト上のプロジェクトで新しいチャットを開始したり、既存のチャットを続けたりできます。
- 追加の指示を送り、質問に回答し、進行中の作業の方向性を調整できます。
- コマンドやその他の操作を承認できます。
- 出力、差分、テスト結果、ターミナル出力、スクリーンショットをレビューできます。
- ChatGPT がタスクを完了したときや、対応が必要になったときに通知を受け取れます。
- 接続済みのホストやチャットを切り替えられます。

以降では、ChatGPT モバイルアプリで「 **リモート** 」を開き、
デスクトップホストにアクセスする方法を説明します。Codex を SSH ホスト上のプロジェクトに接続する方法は、
[SSH ホストへの接続](#connect-to-an-ssh-host)を参照してください。

## リモートのセットアップ前

  リモートは、macOS および Windows で ChatGPT デスクトップアプリを実行しているホストに対応しています。
  iOS または Android 版の ChatGPT からホストを操作できます。
  別の Mac または Windows デバイスで「 **他のデバイスを操作** 」を利用できる場合は、そのデバイスからも操作できます。
  提供状況はロールアウトにより異なる場合があります。

次の要件を満たしていることを確認してください。

- 使用する ChatGPT アカウントとワークスペースでの Codex へのアクセス権
- iOS または Android デバイスにインストールされた最新の ChatGPT モバイルアプリ。「 **リモート**」がアプリに表示されない場合は、
  先に ChatGPT を更新してください。
- スリープ状態ではなく、オンラインで、同じアカウントとワークスペースにサインインしているホスト上で動作する、macOS または Windows 向けの最新の ChatGPT デスクトップアプリ。モバイルのセットアップはアプリから開始します。Codex CLI や IDE 拡張機能からはセットアップできません。
- そのアカウントまたはワークスペースで必要な多要素認証、SSO、またはパスキーの設定

ChatGPT ワークスペースを通じて Codex を利用する場合、スマートフォンから接続する前に、管理者がリモートコントロールへのアクセスを有効にする必要がある場合があります。

<a id="set-up-mobile-access"></a>

## リモートのセットアップ

まず、接続するホストで ChatGPT デスクトップアプリを開きます。セットアップフローでそのホストへのリモートアクセスを有効にすると、スマートフォンでスキャンできる QR コードが表示されます。この QR コードにより、そのスマートフォンとホストがペアリングされます。スマートフォンまたは対応するデスクトップアプリを実行するデバイスごとに、操作するすべてのホストとペアリングしてください。

  2026 年 6 月 8 日以降に使用した既存の接続は、ペアリングされたままです。2026 年 6 月 8 日以降に既存の接続を使用していない場合は、両方のアプリを更新し、デバイスをもう一度ペアリングしてください。

1. リモートのセットアップを開始します。

   ホストで ChatGPT デスクトップアプリを開き、「 **設定** \>
**接続** \> **この Mac または PC を操作**」に移動します。「 **セットアップ** 」または
「**追加**」を選択します。リモートアクセスを承認し、求められた確認を完了してください。

2. QR コードをスキャンします。

   スマートフォンでアプリに表示された QR コードをスキャンします。コードをスキャンすると ChatGPT が開き、モバイルアプリとホストの接続を完了できます。

3. ChatGPT でセットアップを完了します。

   ChatGPT でリモートのセットアップフローが開きます。同じ ChatGPT アカウントとワークスペースであることを確認し、必要な多要素認証、SSO、またはパスキーの手順を完了します。セットアップに成功すると、スマートフォンの「リモート」にホストが表示されます。

4. ホストの設定を確認します。

   ホスト上のアプリで「 **設定** \> **接続** 」を開き、
   接続済みのデバイスを管理します。また、コンピューターをスリープさせないように設定したり、
   コンピューターの使用を有効にしたり、Chrome 拡張機能をインストールしたりできます。

  

## 接続対象の選択

まず、普段 ChatGPT を使用しているノート PC またはデスクトップ PC を接続します。継続的なアクセスや別の環境が必要な場合は、常時稼働のコンピューターまたは SSH ホストを追加します。

### <span class="not-prose inline-flex items-center gap-3 align-middle"><span class="inline-flex h-7 w-7 shrink-0 items-center justify-center rounded-md bg-surface-secondary text-secondary"></span><span>ノート PC またはデスクトップ PC</span></span>

デスクトップアプリがすでにインストールされている Mac または Windows PC に接続します。これにより、普段使用しているものと同じプロジェクト、チャット、認証情報、プラグイン、ローカル設定にリモートでアクセスできます。

コンピューターがスリープ状態になる、ネットワーク接続が切断される、またはアプリが終了すると、再び利用可能になるまでリモートアクセスは停止します。そのコンピューターをホストデバイスとして使用する場合は、電源に接続したままにし、可能な場合はホストの接続設定でスリープを防止してください。

Mac のノート PC では、画面を開いた状態で電源に接続しておけば、リモートアクセスを利用し続けられます。
画面を閉じる場合は、外部ディスプレイも接続してください。
ただし、「**スリープ** 」を選択すると、リモートアクセスは停止します。

Windows ホストでは、セッションのロックを解除した状態を保ち、
[コンピューターの使用](/ja-JP/codex/computer-use)を利用するタスクを実行できるようにしてください。
Windows ではコンピューターの使用がフォアグラウンドで実行されるため、
ホストのデスクトップをそのタスク専用にしている間、リモート操作は作業の開始や確認に最適です。

### <span class="not-prose inline-flex items-center gap-3 align-middle"><span class="inline-flex h-7 w-7 shrink-0 items-center justify-center rounded-md bg-surface-secondary text-secondary"></span><span>常時稼働の専用コンピューター</span></span>

長時間続く作業でも ChatGPT にアクセスできる状態を保ちたい場合は、常時稼働する専用の Mac または Windows PC を使用します。

そのマシンに、ChatGPT または Codex が使用するプロジェクト、認証情報、MCP サーバー、スキル、ツールをセットアップします。

### <span class="not-prose inline-flex items-center gap-3 align-middle"><span class="inline-flex h-7 w-7 shrink-0 items-center justify-center rounded-md bg-surface-secondary text-secondary"></span><span>リモート開発環境</span></span>

プロジェクトがすでにリモート環境にある場合は、SSH ホストまたはマネージド型のリモート開発環境を使用します。まず、デスクトップアプリを実行しているホストをその環境に接続します。スマートフォンは引き続き同じホストに接続し、ChatGPT はリモート環境で、その環境の依存関係、セキュリティポリシー、コンピューティングリソースを使用して作業します。

SSH のセットアップについて詳しくは、[SSH ホストへの接続](#connect-to-an-ssh-host)を参照してください。

  常時稼働のコンピューターまたはリモートホストでブラウザやデスクトップのタスクを実行するには、そのホストでコンピューターの使用を有効にし、Chrome 拡張機能をインストールします。

## 接続先ホストが提供するもの

スマートフォンから ChatGPT にプロンプト、承認、追加のメッセージを送信します。ChatGPT が使用する環境は、接続先ホストが提供します。

つまり、次のようになります。

- リポジトリのファイルとローカルドキュメントは、接続先ホストから提供されます。
- シェルコマンドは、そのホストまたはリモート環境で実行されます。
- MCP サーバー、スキル、ブラウザアクセス、コンピューターの使用は、そのホストの構成に基づきます。
- サインイン済みのウェブサイトやデスクトップアプリを利用できるのは、ホストからアクセスできる場合に限られます。
- サンドボックスの設定、セキュリティ制御、操作の承認は、接続したセッションにも引き続き適用されます。

安全な中継レイヤーにより、信頼できるマシンを公開インターネットに直接さらすことなく、許可済みの ChatGPT デバイスからアクセスできる状態を維持します。

## 別のデバイスでの作業の継続

サインイン済みで、ChatGPT デスクトップアプリを実行し、リモート操作に対応している別のデバイスから作業を続けられます。たとえば、ノート PC を使用できない場合は、スマートフォンから常時稼働のホスト上でチャットを開始し、後からノート PC のアプリを開いて同じチャットを続けられます。

この機能を利用できる Mac または Windows デバイスでは、「 **設定 \>
接続 \> 他のデバイスを操作** 」を開き、別のホストを追加します。同じデバイスで
リモートアクセスの許可と別のデバイスの操作を同時に行えます。

  

## SSH ホストへの接続

ChatGPT デスクトップアプリでは、SSH ホストからリモートプロジェクトを追加し、リモートのファイルシステムやシェルを使ってチャットを実行できます。リモートプロジェクトのチャットでは、リモートホスト上でコマンドの実行、ファイルの読み取り、変更の書き込みを行います。

リモートホストは、通常の SSH アクセスと同じセキュリティ基準で構成してください。信頼できる鍵と最小権限のアカウントを使用し、認証なしでアクセスできる公開リスナーは設けないでください。

1. Codex が自動検出できるように、ホストを SSH 設定に追加します。

   ```text
   Host devbox
     HostName devbox.example.com
     User you
     IdentityFile ~/.ssh/id_ed25519

   Codex は `~/.ssh/config` から個別のホストエイリアスを読み取り、
   OpenSSH で解決します。パターンだけで指定されたホストは無視されます。

2. アプリを実行しているマシンからホストに SSH 接続できることを確認します。

   ```bash
   ssh devbox

3. リモートホストに Codex をインストールし、認証を行います。

   アプリは、SSH 経由でリモートの Codex App Server を起動する際に、
   リモートユーザーのログインシェルを使用します。そのシェルで `codex` コマンドが
   リモートホストの `PATH` 上で利用できることを確認してください。

4. アプリで **設定 \> 接続** を開き、SSH ホストを追加または有効にしてから、
   リモートプロジェクトのフォルダーを選択します。

## ホスト間でのチャットの引き継ぎ

引き継ぎにより、既存のチャットとその Git の状態を、ローカルコンピューターと接続済みのリモートホストの間で移動できます。ローカルで作業を開始し、リモートコンピューターの Worktree で続けて、後でチャットを戻せます。

チャットを引き継ぐ前に、引き継ぎ先ホストに接続し、そのホストで同じ Git リポジトリを対象とするプロジェクトを保存します。プロジェクトがリポジトリのサブディレクトリの場合は、両方のホストで同じサブディレクトリを保存します。保存済みプロジェクトが一致する引き継ぎ先だけが Codex に表示されます。

チャットを引き継ぐには、次の手順に従います：

1. デスクトップアプリでチャットを開きます。
2. チャットのフッターで現在の実行場所を選択してから、
   引き継ぎ先のホストを選択します。リモートチャットをローカルコンピューターに戻す場合は、 **このコンピューター** を
   選択します。
3. 引き継ぎ先とブランチを確認し、 **引き継ぐ** を選択します。

Codex は引き継ぎ先ホストで Worktree を作成または再利用し、チャットと Git の状態を転送して、チャットの実行先をそのホストに切り替えます。チャットが実行中の場合は、転送前に引き継ぎによって現在の応答が中断されます。

別のチャットから Codex に、名前を指定したチャットを接続済みのホストへ引き継ぐよう依頼することもできます。Codex は依頼元のチャット自体を引き継ぐことはできません。また、Codex Cloud 環境への引き継ぎはサポートされていません。

## 認証とネットワークへの公開

リモート接続では、SSH を使用してリモートの Codex App Server を起動して管理します。App Server のトランスポートを、共有ネットワークやパブリックネットワークに直接公開しないでください。

現在接続しているネットワークの外部にあるリモートマシンへアクセスする必要がある場合は、App Server をインターネットに直接公開する代わりに、VPN またはメッシュネットワークツールを使用してください。

## トラブルシューティング

### スマートフォンにホストが表示されない場合

ホストでデスクトップアプリが実行中で、 **他のデバイスからの
接続を許可** を有効にしており、両方のデバイスで同じ ChatGPT アカウントと
ワークスペースを使用していることを確認します。2026 年 6 月 8 日以降にこの接続を使用していない場合は、両方の
アプリを更新し、デバイスをもう一度ペアリングしてください。

### 再サインイン後もオフのままのリモートコントロール

ChatGPT からサインアウトすると、 **リモートコントロール** はオフになりますが、
既存のデバイスのペアリングは解除されません。再びサインインした後、 **リモートコントロール** をオンにすると、
以前の接続状態が復元されます。

**リモートコントロール** をオンにして **追加** を選択した後にエラーが表示された場合は、
ホストの ChatGPT デスクトップアプリを再起動してから、もう一度お試しください。

### 承認リクエストが表示されない場合

ChatGPT モバイルアプリで **リモート** を開きます。スマートフォンとホストで
同じ ChatGPT アカウントとワークスペースを使用していることを確認してから、QR コードをもう一度スキャンするか、ホストから
セットアップをやり直します。ChatGPT ワークスペースを使用している場合は、管理者に
リモートコントロールへのアクセスが有効になっていることを確認してもらってください。

### リモートセッションが切断される場合

ホストがスリープ状態になっていないか、ネットワーク接続が切れていないか、アプリが終了していないかを確認します。ChatGPT の作業中は、ホストをスリープさせず、ネットワークに接続した状態を維持してください。

### 認証が原因でセットアップできない場合

セットアップ中に表示されるアカウントまたはワークスペースの認証プロンプトに従って手続きを完了します。組織で SSO、多要素認証、またはパスキーが必須の場合は、もう一度試す前にその認証フローを完了してください。それでもセットアップに失敗する場合は、ワークスペースの管理者に、リモートコントロールへのアクセスが有効になっていることを確認してもらってください。
