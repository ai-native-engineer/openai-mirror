タスクでファイルを生成する場合は、ソースデータ、希望するファイル形式、構成、そのタスクで重要なレビュー基準を ChatGPT に伝えます。利用できるプレビュー機能やレビューツールは、使用する環境によって異なります。

ChatGPT デスクトップアプリでは、生成されたドキュメント、プレゼンテーション、スプレッドシート、PDF ファイルをチャットの横に表示してプレビューできます。自動プレビューが有効な場合、アプリはタスクの完了後に生成されたファイルを開くことができます。

HTML プレビューを利用できる場合、生成された `.html` ファイルと `.htm` ファイルも
インタラクティブなプレビューとして開くことができます。レンダリングされたプレビューと
ソースビューを切り替えて、出力やその基になっている HTML を確認します。

アノテーションに対応したプレビューの特定の箇所を指定し、その部分に絞った修正を依頼します。

Web 版の ChatGPT Work では、ソースファイルを添付するか、ドキュメント、プレゼンテーション、スプレッドシート、PDF の作成を ChatGPT に依頼します。生成されたファイルをチャットでレビューし、必要に応じてダウンロードして、次のバージョンに向けた具体的なフィードバックを伝えます。

Codex CLI では、作業ディレクトリ内のファイルを作成、編集できますが、ファイルの視覚的なプレビュー機能やアノテーション用のインターフェースは備えていません。各出力パスと実行したチェックを報告するよう Codex に依頼します。

IDE 拡張機能では、ワークスペース内のファイルを作成、編集できます。テキストファイルとコードファイルはエディターでレビューし、ドキュメント、プレゼンテーション、スプレッドシート、PDF ファイルは対応するビューアーで開きます。

  
    
  

## レビュー用ファイルの作成

スプレッドシートやプレゼンテーションの場合は、必要なシート、列、グラフ、スライドのセクション、確認項目を具体的に伝えます。出力の保存場所と結果の確認方法を説明するよう ChatGPT に依頼します。

## アノテーションによるファイルの改善

アノテーションを使うと、ファイル内の特定の箇所を指定し、変更内容を ChatGPT に伝えられます。コード、Markdown ファイル、ウェブサイトで利用できるアノテーションのワークフローは、ドキュメント、スプレッドシート、プレゼンテーションにも使用できます。

たとえば、次のような操作ができます。

- ウェブサイトのナビゲーションバーを選択し、フォントを変更するよう ChatGPT に依頼します。
- 投資仮説に含まれる主張をハイライトし、その出典を尋ねます。
- スライド上のグラフに印を付け、ラベルをよりわかりやすくするよう依頼します。

ChatGPT は選択した領域をリクエストのコンテキストとして使用するため、最初からやり直したり、すでに気に入っている部分を変更したりせずにファイルを改善できます。アノテーションは、初稿の完成後にレビューと改善を繰り返す際に特に役立ちます。

## Web でのファイルのレビューと改善

生成されたファイルを開くかダウンロードし、対応するビューアーでレビューします。修正を依頼する際は、対応が必要なページ、スライド、シート、表、文章の一節を具体的に示し、変更しない部分も明確に伝えます。次のバージョンをダウンロードする前に、新しいファイル名と実施したチェックを報告するよう ChatGPT に依頼します。

## ファイルのレビューと改善

タスクの実行中はチャットのサイドバーを使用します。エージェントの計画、情報源、生成されたファイル、チャットの要約を表示できるため、作業の方向性を調整し、生成されたファイルを確認して、再度の見直しを依頼できます。

各ファイルの保存場所と結果の検証方法を説明するよう ChatGPT に依頼します。プレビューで出力を確認し、構成、データ、レイアウト、検証内容のうち、再度見直す必要がある点に絞ってフィードバックを伝えます。
