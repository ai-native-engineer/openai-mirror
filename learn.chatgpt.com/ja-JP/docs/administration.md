# 管理

ChatGPT、Codex の開発者ツール、API、プラグイン、接続先システムに対するアクセスとポリシーの適用範囲を設定

ChatGPT、Codex の開発者ツール、API、プラグイン、接続先システムに対するアクセスとポリシーの適用範囲を設定します。

管理では、相互に関連する 6 つの領域を扱います。ChatGPT ワークスペースへのアクセス、ChatGPT デスクトップアプリ、Codex CLI、IDE 拡張機能の対象機能に適用されるローカルランタイムポリシー、Codex Cloud の利用資格、Platform API へのアクセス、プラグインの利用可否とコネクタの権限、そして接続先システムの権限です。まずワークスペースの ID とアクセスを整備し、次に各導入環境に必要なランタイムとソースシステムの制御を適用します。

認証について詳しく見る

ChatGPT ワークスペースのメンバー、グループ、アクセストークン、ロールによる制御

はじめに

まずロールアウトガイドを参照し、次に各制御領域のリファレンスページをご覧ください。

管理者向けロールアウトガイド

アクセス方針を立て、責任者を割り当て、制御を設定して、ロールアウトを検証します。

ChatGPT Work

ChatGPT Work の概要と管理リファレンスを確認します。

ChatGPT Work の概要

ホスト環境での実行、ネットワーク制御、データの取り扱い範囲、監査で把握できる範囲を理解します。

ChatGPT Work のクラウドセキュリティ

ホスト環境での実行、接続済みアカウント、アクセス制御、データ保持、監査で把握できる範囲を確認します。

ChatGPT Work のローカルセキュリティ

ローカル環境での実行、デバイスやブラウザへのアクセス、管理対象のポリシー、データの取り扱い、監査上の制約を確認します。

ChatGPT Work 管理者向けのよくある質問

ChatGPT Work のアクセス、データ、ガバナンス、利用状況、インシデントに関する制御を確認します。

ChatGPT Work の使用量とコスト

共有クレジット、請求への影響、支出の制御、導入計画について理解します。

ID と認証

ユーザーのサインイン方法を選択し、プログラムで実行するワークフロー用の認証情報を発行します。

認証の概要

サインイン方法、認証情報の保存方法、強制適用の仕組みを比較します。

ワークロード ID

信頼済みのワークロードが、長期間有効な認証情報を使わずに Codex を利用できるようにします。

個人アクセストークン

プログラムによるアクセスに使用するトークンを作成し、管理します。

サービスアカウント

自動化されたワークフロー用の ID をワークスペース内で作成し、管理します。

ワークスペースのアクセス、ポリシー、モデル

ChatGPT ワークスペースへのアクセス権を割り当て、ローカルランタイムポリシー、Codex Cloud へのアクセス、Platform API へのアクセスとは分けて管理します。

グループとプロビジョニング

手動で管理するグループと SCIM グループ、プロビジョニング、ロールアウト対象のユーザー群を管理します。

ユーザーライフサイクル管理

従業員のアカウントをプロビジョニングし、グループのアクセス権を更新し、退職するユーザーの認証情報を失効させます。

ロールとワークスペースの権限

ワークスペース、ランタイム、API、プラグイン、ソースシステムの各制御をまとめた正式な対応表を使用します。

GPT と共有

ワークスペース全体で、GPT の共有、所有権、接続済みアプリ、サードパーティのアクションを管理します。

管理対象の設定

対応環境で管理対象の設定を配布し、ChatGPT デスクトップアプリ、Codex CLI、IDE 拡張機能の対象機能にランタイム要件を強制適用します。

Prisma AIRS

Codex のプロンプトにワークスペース全体のセキュリティポリシーを適用します。

HIPAA 構成

保護対象保健情報を扱う可能性のあるワークフロー向けに、ローカルランタイムの保護措置を設定します。

ワークスペースでのモデルの利用可否

ChatGPT、ChatGPT デスクトップアプリ内の Codex、Codex CLI、IDE 拡張機能、Codex Cloud、Platform API ごとに、モデルへのアクセスを分けて管理します。

プラグインとコネクタの制御

プラグインのインストール、同梱されたスキル、コネクタ経由の機能、接続先サービスへのアクセスを制御します。

プラグインの制御

プラグインの利用可否、コネクタへのアクセスとアクション、ソースシステムの権限を管理します。

プラグイン管理

GitHub からワークスペースのプラグインをインポートし、同期します。

スキルの制御

ChatGPT ワークスペース、ローカルファイルシステム、プラグインにおけるスキルの制御を比較します。

利用状況、ガバナンス、コンプライアンス

導入状況を測定し、レポートデータや監査データをそれぞれの管理元システムに振り分けます。

ガバナンス

調べたい内容に応じて、分析、支出、監査に適した確認手段を選択します。

管理者用プラグイン

権限、承認、およびサポートされている管理ワークフローには、管理者用プラグインを使用します。

ワークスペースの分析

ワークスペース単位で ChatGPT の導入状況と Codex の利用状況を確認します。

分析 API

Codex 分析 API を使用して、開発者のアクティビティとコードレビューに関するレポート作成を自動化します。

Compliance API と監査イベント

監査と調査のワークフローで使用するアクティビティ記録をエクスポートします。

展開とモデルプロバイダー

デスクトップアプリの展開と更新、管理対象ホストへの接続、または対応する外部モデルプロバイダーの設定を行います。

アプリの更新管理

デスクトップアプリの更新を管理し、デバイス管理プラットフォームを通じて承認済みのバージョンを展開します。

Windows アプリの展開

管理対象の Windows デバイス向けに、インストール方法と更新方法を選択します。

リモート接続

接続先のコンピューターで作業を開始し、管理します。

Amazon Bedrock

対応するローカルクライアントで、Bedrock を通じて提供されるモデルを使用できるように設定します。
