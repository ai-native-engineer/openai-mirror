# 構成

ChatGPT と Codex の開発者ツール、再利用可能なワークフロー、外部ツールを構成します

デフォルトを設定し、永続的なコンテキストを追加して、ChatGPT と Codex の開発者ツールの動作をカスタマイズします。

構成によって、チャット、リポジトリ、マシンをまたいで ChatGPT と Codex の開発者ツールがどのように動作するかが決まります。永続的なコンテキスト、設定ファイル、リポジトリ向けのガイダンス、サブエージェント、外部接続、Linux と Windows のセットアップを組み合わせることで、個人やチームのワークフローの一貫性を保てます。

カスタマイズを詳しく見る

ChatGPT の設定メニュー、設定ファイルのオプション、パーソナリティ設定

カスタマイズ

利用体験を自分に合わせ、役立つコンテキストをチャット間で引き継ぎます。

カスタマイズの概要

ガイダンス、スキル、MCP、サブエージェントを使って、ChatGPT と Codex をカスタマイズします。

メモリ

ChatGPT が役立つコンテキストをチャット間で保持できるようにします。

コンピューターの使用履歴

最近のコンピューター操作をコンテキストとして使用し、含める内容を管理します。

設定ファイル

設定ファイルと変数を使用して、モデル、ツール、環境、デフォルト設定を制御します。

設定の基本

設定の階層を理解し、設定ファイルを作成します。

高度な設定

プロファイル、プロバイダー、ポリシー、高度なオプションを使用します。

設定リファレンス

サポートされているすべての設定キーを参照します。

環境変数

システムやセッションによって異なる値を設定します。

設定例

注釈付きの完全な設定例から始めます。

エージェントの構成

エージェントの連携方法や、プロジェクトのガイダンスに従う方法を設定します。

AGENTS.md

Codex にリポジトリ向けの永続的な指示を与えます。

サブエージェント

範囲を絞ったタスクを専門のエージェントに委任します。

速度

Codex の処理速度と推論の深さを調整します。

ルール

Codex が自動的に実行できるコマンドを定義します。

ChatGPT と Codex の機能拡張

知識をパッケージ化し、サービスと連携して機能を追加します。

記録と再生

ChatGPT または Codex にワークフローを実演し、再利用可能なスキルに変換します。

MCP

Codex の開発者ツールを外部ツールやコンテキストに接続します。

Linux

対応する Linux デスクトップに ChatGPT をインストールし、更新します。

ChatGPT デスクトップアプリ

Ubuntu、Debian、Fedora のいずれかに Linux プレビュー版をインストールします。

Windows

Codex を Windows 上でネイティブに実行するか、WSL 内で実行します。

PowerShell または WSL のワークフローで ChatGPT デスクトップアプリを使用します。

Windows サンドボックス

ネイティブのファイルシステム分離とコマンド分離を使用して Codex を実行します。

WSL

Windows が管理する Linux 環境で Codex を使用します。
