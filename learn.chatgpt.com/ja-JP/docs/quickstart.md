## ChatGPT の利用環境

ChatGPT は、
[ChatGPT デスクトップアプリ](/ja-JP/codex/app)や [Web 版 ChatGPT](/ja-JP/codex/web) など、さまざまな環境で利用できます。
作業に合う方を選んでください。

  

  ターミナルやコードエディターで Codex を使いたい開発者の方は、
  [Codex CLI](/ja-JP/codex/cli) または [Codex IDE 拡張機能](/ja-JP/codex/ide)をお試しください。

## セットアップ

  <div slot="app">
ChatGPT デスクトップアプリは macOS、Windows、Linux で利用できます。
プロジェクト、ローカルファイル、時間のかかるタスク、クイックチャットに使用できます。
対応している Linux ディストリビューションとパッケージのインストールについては、
[Linux デスクトップアプリガイド](/ja-JP/codex/linux/linux-app)をご覧ください。

1. <h3 id="setup-app-install">ChatGPT デスクトップアプリのインストール</h3>

    お使いの OS に合ったバージョンを選択してください。

    

2.  <h3 id="setup-app-sign-in">ChatGPT デスクトップアプリの起動とサインイン</h3>

    アプリを開き、ChatGPT アカウントでサインインします。

    Codex は API キーでも利用できます。[一部の機能は利用できない場合があります](/ja-JP/codex/pricing#feature-availability)。

3.  <h3 id="setup-app-select-workspace">ChatGPT の作業先の選択</h3>

    チャットを開始するか、プロジェクトを作成するか、フォルダーを開きます。
    ChatGPT は、選択したフォルダー内のファイルを読み取り、変更できます。詳しくは、[チャットとプロジェクト](/ja-JP/codex/projects)をご覧ください。

4.  <h3 id="setup-app-start-task">チャットの開始</h3>

            <div class="grid gap-5 md:grid-cols-[minmax(0,1fr)_minmax(17rem,20rem)] md:items-start">

          <div>

                - 調査や分析を行ったり、ドキュメント、プレゼンテーション、
                  スプレッドシート、Sites などの成果物を作成したりするには、 **ChatGPT** を選択してから **Work** に切り替えます。
                  切り替えメニューは、新しいチャットページの上部、コンポーザーの上にあります。
                - コードベースのコンテキストと開発ツールを使ってソフトウェアを開発するには、
ChatGPT のドロップダウンから **Codex** を選択します。
                - 簡単な質問やチャットには、 **ChatGPT** を選択してから、 **チャット**を選択します。
                  切り替えメニューは、新しいチャットページの上部、コンポーザーの上にあります。
                  Codex では、 **新しいチャット**にポインターを合わせ、その右側の **クイックチャット** アイコンを選択します。

                詳しくは、[ChatGPT の使い方](/ja-JP/codex/use-chatgpt)をご覧ください。
