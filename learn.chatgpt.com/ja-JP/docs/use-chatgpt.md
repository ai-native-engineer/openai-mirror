## アイデアから役立つ成果へ

ChatGPT は、自然言語でやり取りできる AI エージェントです。

1. 質問、アイデア、大まかなメモ、ファイル、取り組むべきタスクなどから始めます。

2. ChatGPT に、情報の解説、アイデアの具体化、コンテンツの下書き、テーマの調査、資料の分析、新しいものの作成を依頼します。

3. ファイル、ウェブ検索、プロジェクト、プラグインなど、必要なコンテキストとツールを追加します。

4. 結果を確認し、方向性を修正して、変更を依頼します。最初から完璧なプロンプトを書く必要も、特別なコマンドを使う必要もありません。

## 自分に合った進め方の選択

質問や対話にはチャットを使います。規模の大きいタスクを ChatGPT に任せ、レビューできる成果物に仕上げてほしい場合は、切り替えメニューで Work をオンにします。特にソフトウェア開発で、開発者向けの画面や詳しい技術情報が必要な場合は、Codex を選択します。

| 選択肢       | 目的                              | 例                                                                     |
| ------------ | --------------------------------------------- | ---------------------------------------------------------------------------- |
| チャット         | ChatGPT と対話しながら作業を進める           | 質問、ウェブ検索、アイデア出し、メッセージの下書き、選択肢の比較 |
| ChatGPT Work | 目指す成果を明確にし、レビューできる成果物を得る | スライド資料の作成、ファイルの分析、レポートの下書き、プロジェクト計画の策定           |
| Codex        | 開発ツールを使い、技術的な詳細を確認する | コードのデバッグ、テストの実行、PR のレビュー、機能の実装                      |

チャットでは、質問、アイデア出し、文章の作成や修正、ファイルの要約、
選択肢の比較、大きなタスクの内容の整理などができます。Codex では、 **新しいチャット**にカーソルを合わせ、
 **クイックチャット** が表示された場合は選択します。

レビューできる完成した成果物が必要な場合は、 **Work** に切り替え、
含めるべき内容を伝えます。タスクやプロンプトの例、ベストプラクティスについては、
[ChatGPT Work
入門](/ja-JP/codex/get-started-with-work)をご覧ください。

### ChatGPT Work でできること

ChatGPT Work は、タスクを計画してコンテキストを集め、ツールを使いながら、レビューできる成果物が完成するまで作業を進められます。

  

次のような作業を依頼できます。

- **情報の調査・分析：** ウェブ検索、ウェブサイトの閲覧、
  情報源の比較、ファイルの読み取り、データの分析、調査結果の要約を行います。
- **ファイルやツールの活用：** アップロードしたファイル、
[プロジェクト](/ja-JP/codex/projects)、メモリ、ChatGPT Library、インストール済みの
[プラグイン](/ja-JP/codex/plugins)を取り込みます。プラグインを通じて、連携先の情報や再利用可能なワークフロー、
  対応するアクションを利用できます。
- **ファイルの作成と仕上げ：** [ドキュメント、プレゼンテーション、
  スプレッドシート、PDF ファイル](/ja-JP/codex/artifacts-viewer)の下書きを作成し、仕上げます。結果をレビューし、
  必要な修正を具体的に依頼して、完成したファイルをダウンロードします。
- **視覚的でインタラクティブな成果物の作成：** 
[画像](/ja-JP/codex/image-generation)を生成・編集したり、
インタラクティブな[可視化](/ja-JP/codex/visualizations)を行ったりできます。
  [Sites](/ja-JP/codex/sites) でウェブサイトやアプリを構築・共有することもできます。
- **ウェブサイトやアプリをまたぐ作業：** [ブラウザ](/ja-JP/codex/browser)を使って、
  ウェブサイトを調査・操作します。デスクトップアプリでは、
[ブラウザ拡張機能](/ja-JP/codex/chrome-extension)、
[コンピューターの使用](/ja-JP/codex/computer-use)、[Appshots](/ja-JP/codex/appshots) が利用可能な場合に、
  これらの機能を使えます。
- **コードの実行と技術的な作業のレビュー：** コードやシェルコマンドの実行、
  データの分析、ファイルの確認、[コードのレビュー](/ja-JP/codex/code-review)を行います。また、
  選択した環境からアクセスできるリポジトリで作業します。
- **時間のかかるタスクの委任と継続：** 独立した作業を
[サブエージェント](/ja-JP/codex/agent-configuration/subagents)に分担させ、進捗を確認しながら、
  [長時間にわたる作業](/ja-JP/codex/long-running-work)を継続します。
- **役立つワークフローの反復実行：** 定期的な作業には[スケジュール済みタスク
  ](/codex/automations)を設定し、
[スキル](/ja-JP/codex/skills-and-plugins)を使ってワークフローを再利用します。
- **音声でのタスク進行：** 対応するプランのデスクトップアプリでは、
[ChatGPT 音声モード](/ja-JP/codex/features/voice)を使って作業を開始したり、進捗を確認したり、
  方向性を変更したりできます。

  利用できる機能は、プラン、プラットフォーム、地域、提供状況、
  ワークスペースの設定によって異なります。ワークスペース管理者は、ChatGPT Work、
  プラグイン、ブラウザの使用、ネットワークアクセスの利用可否を管理できます。ChatGPT Work と Codex の[利用制限
  ](/codex/pricing)は共通です。

### クラウドとローカルの選択

ウェブ版では、ChatGPT Work は管理されたクラウド環境で実行されます。デスクトップアプリでは、タスクの実行場所も選択できる場合があります。

- **クラウド：** 分離されたホスト型環境で作業します。タスクはデスクトップアプリを閉じた後も継続でき、
  ウェブ版やモバイルアプリで続きを進められます。
  クラウドでの作業では、アップロードしたファイル、接続済みのツール、承認済みのウェブサイトを利用できます。
- **ローカルでの作業：** コンピューター上のファイル、アプリ、ブラウザを使います。
  ローカルでの作業は、アカウントまたはワークスペースで有効になっている場合に、
  デスクトップアプリで利用できます。

ChatGPT は進捗を表示し、情報や承認が必要になると一時停止します。影響の大きい操作は承認前に内容を確認し、最終的な結果も使用または共有する前に確認してください。

### デスクトップでの ChatGPT Work と Codex の比較

ChatGPT Work と Codex には共通する機能があります。Codex が好みであれば、リサーチやドキュメント、プレゼンテーションの作成などの知識労働に引き続き使えます。両方を利用できる場合、デスクトップアプリでは、選択に応じてインターフェースとエージェントによる作業の提示方法が変わります。

| 違い          | デスクトップアプリの ChatGPT                                                 | デスクトップアプリの Codex                                              |
| ------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 開始方法      | **ChatGPT** を選択し、 **Work** に切り替える                            | プロダクト選択メニューで **Codex** を選択する                          |
| 表示されるチャット       | ウェブ版やモバイル版のチャットで開始した会話と、ChatGPT Work のチャットを表示 | Codex のチャットと開発プロジェクトを中心に表示                     |
| クイックチャット          | 利用不可                                                          | 利用できる場合は、ウェブ版やモバイル版の ChatGPT チャットに Codex からアクセス |
| 技術的な詳細    | Git やシェルコマンドなどの技術的な詳細を非表示                      | 差分画面やレビュー画面など、開発者向けの詳細情報を表示            |
| エージェントの説明方法 | 技術的な専門用語を避けた説明と完成した成果物を重視                     | 技術面や実装の詳細も説明可能                  |
| Pull Request ペイン  | ChatGPT Work の使用中は利用不可                                  | 有効になっている場合は利用可能                                            |

### ChatGPT との自然な対話

頼りになる同僚に依頼内容を説明するつもりで書いてください。達成したいことを伝え、回答に影響する詳細を加えて、必要な形式を指定してください。最初のプロンプトは出発点にすぎません。続けてメッセージを送り、コンテキストを追加したり、結果を改善したりできます。

次のような簡単な指示で、やり取りを続けられます。

- 「これをもっと短くしてください。」
- 「3 つの異なるアプローチを示してください。」
- 「どのような前提を置いていますか？」
- 「続ける前に、私に質問してください。」

詳しくは[プロンプト](/ja-JP/codex/prompting)をご覧ください。
[AI 基礎コース](https://academy.openai.com/home/courses/ai-foundations-juzjs)を受講して、
ガイドに沿って実践することもできます。

## ChatGPT に適切なコンテキストを提供

タスクに必要な情報、ツール、指示を ChatGPT に提供してください。すべてを伝える必要はありません。結果の良し悪しを左右するコンテキストを含めてください。

### 関連する作業をプロジェクトに集約

プロジェクトを使うと、ChatGPT での作業をトピックや目標、継続中の取り組みごとに整理できます。
継続する作業や同じコンテキストを使う作業では、
関連するチャット、ファイル、指示を 1 つのプロジェクトにまとめてください。[プロジェクトについて
詳しくご覧ください。](/ja-JP/codex/projects)

### ファイルの添付

ドキュメント、プレゼンテーション、スプレッドシート、PDF ファイル、画像、エクスポートしたデータをアップロードまたは添付できます。ChatGPT に次の作業を依頼する際に活用してください。

- 内容の要約や比較
- パターンや不整合の検出
- 情報の抽出、クリーニング、再整理
- 新しいファイルの元資料としての利用

ChatGPT がファイルを作成したら、プレビューを開いて内容を確認してください。
その後、最初からやり直さずに変更を依頼できます。
[ファイルの操作](/ja-JP/codex/artifacts-viewer)について詳しくご覧ください。

### プラグインによるツールの接続

プラグインを使うと、Google Drive、SharePoint、Salesforce、Gong など、業務で使用するツールや情報に ChatGPT を接続できます。チャット外の情報、別のシステムでの操作、繰り返し実行できるワークフローがタスクに必要な場合に活用してください。

  

プラグインの利用可否は、ご利用のプラン、ワークスペースの設定、各プラグインによって異なります。
[スキルとプラグイン](/ja-JP/codex/skills-and-plugins)について詳しくご覧ください。

## Codex スレッドの読み取り専用スナップショットの共有

すべての Codex プランで、macOS 版 ChatGPT デスクトップアプリを使い、ローカルの Codex スレッドの読み取り専用スナップショットを作成できます。スナップショットを共有しても、他のユーザーにプロジェクトやコンピューターへのアクセス権が付与されることはありません。

共有する前に、リンクを開けるユーザーを確認してください。

- **個人アカウント：** リンクを持っている人なら誰でもスナップショットを開けます。
- **ワークスペースアカウント：** スナップショットを作成したワークスペースの認証済みメンバーのみが開けます。
  そのワークスペースの全員にアクセスを許可するか、
  招待したユーザーとグループに制限できます。
  ワークスペース管理者は、ワークスペースの共有リンクを無効にできます。

1. スレッドを開き、 **共有**を選択します。
   スラッシュコマンドを利用できる場合は `/share` も使用できます。
2. ワークスペースアカウントの場合は、 **アクセスできるユーザー** で、ワークスペースの全員か、
    **招待されたユーザーとグループのみ**を選択します。
   招待した相手のみにアクセスを許可する場合は、既存のワークスペースメンバーをメールアドレスで追加するか、ワークスペースのグループを選択します。
3. スナップショットのアップロードが完了するまで待ち、 **リンクをコピー**を選択します。
   ダイアログを開くとアップロードが始まりますが、
    **リンクをコピー**を選択したときにのみ、指定した共有範囲と共有相手に対して Codex がスナップショットを公開します。
4. コピーしたリンクを開き、他の人に送信する前に共有画面の内容を確認してください。

スナップショットに記録されるのは、共有時点のスレッドの内容のうち、共有に対応しているものです。後から追加されたメッセージや変更は、既存のスナップショットに反映されません。

共有スナップショットには、ユーザーに表示されるメッセージ、推論の要約、添付画像、エージェントが閲覧または生成した画像、ファイルの変更内容（パスや差分を含む）が含まれる場合があります。元のスレッドでのツール呼び出し、シェルコマンド、ツールの入力や出力は含まれません。

Codex は、スナップショットをアップロードする前に、既知のシークレットのパターンに一致する情報をマスクします。ファイルパスなどの機密情報がメッセージ、画像、差分に残っている場合があるため、リンクを送信する前に共有画面を確認してください。

共有スナップショットから元のスレッドをフォークすることはできません。スナップショットを添付ファイルとしてインポートし、新しいスレッドで参照できます。

共有リンクを確認または無効化するには、[ChatGPT の
データコントロール](https://chatgpt.com/#settings/DataControls)を開き、 **共有リンク**を選択します。

## すぐに使える結果への仕上げ

最初の結果は、内容を確認し、批判的に検討し、改善できる下書きとして扱ってください。完成度が高く見える回答でも、不完全だったり誤っていたりする場合があります。使用または共有する前に、重要な詳細を確認してください。

**作業内容の確認：**

- 重要な数値、名称、日付、引用、主張を検証してください。
- 生成されたファイルを開き、すべてのセクション、タブ、スライド、ページを確認します。
- ChatGPT が適切かつ最新の資料を使用したことを確認します。
- 情報の抜け漏れや、根拠のない前提がないか確認します。
- 結果が目的に沿っていない場合は、修正すべき点を絞って依頼します。

次に、ChatGPT に結果を厳しく検証するよう依頼します。

- 「この結果には、どの情報源を使いましたか？」
- 「主な主張それぞれの出典を示してください。」
- 「どのような前提を置きましたか？」
- 「アクセスできなかった情報は何ですか？」
- 「推奨内容が変わるのは、どのような場合ですか？」
- 「この結果を元のファイルと照合してください。」

ChatGPT が情報源にアクセスできなかった場合や、タスクの一部を完了できなかった場合は、その事実を明確に伝えるよう求めます。自信ありげな推測よりも、不足している情報や未完了の作業が明示されているほうが対処しやすくなります。

  法律、金融、医療、セキュリティなど、重大な影響を伴う意思決定には、適切な専門家によるレビューが必要です。ChatGPT は、十分な情報に基づく判断を支えるために使い、判断そのものの代わりにはしないでください。
