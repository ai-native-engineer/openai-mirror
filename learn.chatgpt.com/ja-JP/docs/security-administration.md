# セキュリティ

ChatGPT と Codex 開発者ツールの権限と、セキュリティおよび安全性に関する制御を管理します

ChatGPT と Codex 開発者ツールのアクセス対象を制御し、作業が分離される仕組みを理解して、セキュリティ上慎重な扱いが必要なタスクには安全策を講じます。

セキュリティ管理機能では、ChatGPT と Codex 開発者ツールのアクセス対象と、慎重な扱いが必要な操作のレビュー方法を定めます。権限、サンドボックス、承認、ネットワークアクセスによって信頼境界を確立します。Codex Security は脆弱性の検出と修正を支援し、サイバーセーフティのガイダンスでは、セキュリティ上慎重な扱いが必要な作業への対応方法を説明します。

権限を確認

デフォルト、自動、フル、カスタムの各アクセスレベルに対応する ChatGPT の承認オプション

権限

ファイルシステム、ネットワーク、コマンド、承認、レビューに関する動作を制御します。

ファイルシステム、コマンド、ネットワークへのアクセスに使用するプロファイルを選択します。

サンドボックス

Codex によるコマンドとファイル変更の分離方法を確認します。

自動レビュー

設定したポリシーに照らして操作を自動的にレビューします。

エージェントの承認とセキュリティ

Codex が操作前に承認を求めなければならない条件を設定します。

インターネットアクセス

クラウド上のチャットがアクセスできるドメインを制御します。

Codex Security

脆弱性を検出して把握し、修正します。

Codex Security の概要

コードを評価し、レビュー済みの検出結果に基づいて、対象を絞った修正を行います。

Codex Security プラグイン

ChatGPT デスクトップアプリと Codex CLI からセキュリティワークフローを実行します。

Codex Security CLI

ローカルでセキュリティスキャンを実行し、リポジトリのレビューを自動化します。

Codex Security TypeScript SDK

セキュリティスキャンと進捗レポート機能を開発者ツールに統合します。

Codex Security クラウドのセットアップ

リポジトリを接続し、クラウドでのセキュリティスキャンを構成します。

セキュリティレビュー

GitHub の Pull Request に対して詳細なセキュリティレビューを実行します。

脅威モデル

コードベースの脅威モデルをレビューし、改善します。

Codex Security クラウドに関するよくある質問

クラウドスキャン、検出結果、プライバシー、アクセスに関する質問への回答を確認します。

サイバーセーフティ

承認済みのモデルを選択し、セキュリティ業務を安全に進められるよう設定します。

モデルと Trusted Access

サイバーセキュリティモデルを選択し、Trusted Access を申請します。

推奨構成

環境を分離し、作業を対象範囲内に制限して、慎重な扱いが必要な操作をレビューします。
