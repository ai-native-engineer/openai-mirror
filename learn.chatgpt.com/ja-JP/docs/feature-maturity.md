ChatGPT と Codex の一部の機能は、成熟度ラベル付きでリリースされます。このラベルにより、各機能の信頼性、変更される可能性がある点、期待できるサポートの水準を把握できます。

| 成熟度          | 意味                                                                                                 | 利用の目安                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 開発中 | まだ利用できる段階ではありません。                                                                                            | 利用しないでください。                                                                    |
| 実験的      | 不安定であり、OpenAI が削除または変更する可能性があります。                                                                  | 自己責任で利用してください。                                                         |
| ベータ版              | 広くテストできる段階です。大部分は完成していますが、ユーザーからのフィードバックに基づき、一部が変更される可能性があります。       | ほとんどの評価や試験導入に利用できますが、軽微な変更は想定してください。                      |
| 安定版            | 全面的にサポートされ、ドキュメントも整備されており、広く利用できる段階です。動作と構成は長期にわたって一貫性が保たれます。 | 本番環境でも安心して利用できます。削除される場合は、通常、非推奨化のプロセスを経ます。 |
| 非推奨        | 互換性を維持するために引き続き提供されていますが、利用は非推奨です。OpenAI が今後のリリースで削除する可能性があります。       | 新規の利用は避け、移行を計画してください。                                            |
