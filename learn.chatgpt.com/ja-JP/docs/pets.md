ペットは、作業状況を確認するために任意で利用できるアニメーション付きの相棒です。ペットの表示場所と
表示内容は、使用するインターフェースによって異なります。ペットを選ぶと変わるのは
見た目だけで、ChatGPT がタスクを完了する方法は変わりません。

## フローティングペットの使用

ChatGPT デスクトップアプリでは、ペットをほかのアプリのウィンドウより手前にフローティング表示し、
複数のチャットのアクティビティを確認できます。

### ペットの選択と起動

1. アプリ画面下部のプロフィールメニューを開き、**ペット**を選択します。また、
   [**設定**](codex://settings)を開いて、**ペット**に移動することもできます。
2. 組み込みペットまたはカスタムペットを選択します。
3. `/pet` を入力するか、コマンドメニューを開いて**ペットを起こす**を選択します。

**ペットをしまう**を、**設定 \> ペット**またはコマンドメニューで選択するか、
`/pet` をもう一度入力すると、ペットを非表示にできます。選択したペットとその位置は
アプリを再度開いても保持されます。

カスタムペットを選択すると、**プロフィール**画面にも表示されます。

### ペットのステータス

| ステータス          | 意味                                                  |
| --------------- | -------------------------------------------------------- |
| **実行中**     | チャットで処理が進行中です。                              |
| **入力が必要** | チャットには、承認、回答、またはその他の判断が必要です。 |
| **準備完了**       | チャットが完了し、未読のアクティビティがあります。            |
| **ブロック中**     | チャットが失敗したか、システムエラーが発生しました。             |

複数のチャットでアクティビティがある場合、ペットは入力が必要なチャットを最優先し、
次にブロック中、準備完了、実行中の順で優先します。アクティビティトレイを開いて
チャットを選択します。

ペットを選択すると ChatGPT に戻り、アクティビティを選択すると該当するチャットが開きます。
アクティビティトレイは[システム
通知](/ja-JP/codex/notifications?surface=app)とは別です。

### コンピューターの使用状況の確認

macOS では、[コンピューターの使用](/ja-JP/codex/computer-use)のピクチャ・イン・ピクチャウィンドウを
起きているペットに連結できます。ペットを動かすと、ウィンドウも追従します。

### カスタムペットの作成

1. **設定 \> ペット**を開き、**自分のペットを作成**を選択します。
2. アプリは、同梱の `hatch-pet` スキルをインストールしてスキルを再読み込みし、
   新しいチャットを開きます。
3. 希望するペットについて記述し、プロンプトを送信します。
4. タスクが完了したら、**設定 \> ペット**に戻って**更新**を選択し、
   新しいペットを選びます。

デスクトップアプリで作成したカスタムペットは、コンピューターにローカル保存されます。
ChatGPT Web には自動的に同期されません。

### アニメーションの低減

ペットは、オペレーティングシステムのモーション軽減設定に従います。モーション軽減を
有効にすると、ペットではスプライトアニメーションの代わりに静止フレームが使用されます。

## Web でのペットの選択

アカウントとワークスペースでペットを利用できる場合は、**設定 \>
パーソナライズ \> ペット \> ペットを選択**を開きます。組み込みペットを選ぶか、ペットなしで ChatGPT を使用するには
**デフォルト**を選択します。

Web 上のペットは、対応している ChatGPT Work のチャット内に表示されます。デスクトップアプリの
フローティングオーバーレイやアクティビティトレイ、`/pet` コマンドは利用できません。

### カスタムペットのアップロード

**ペットをアップロード**を選択して、カスタムスプライトシートを追加します。ファイルは
背景が透明な PNG または WebP で、サイズが 1536 × 1872 ピクセルちょうど、容量が 20 MiB 以下である必要があります。
アップロードしたペットは、同じ設定から編集、ダウンロード、更新、削除できます。

## ターミナルペットの選択

対話型の Codex CLI セッションでは、次の操作を行います：

- `/pets` または `/pet` を入力して、ペットピッカーを開きます。
- `/pets <name>` を入力すると、ペットを直接選択できます。
- `/pets off` を入力して、ターミナルペットを無効にします。

ピッカーには、組み込みペットと、お使いの
コンピューターにインストールされている互換性のあるカスタムペットが表示されます。ターミナルペットは、現在の CLI セッションのアクティビティを示します。ステータスには
**実行中**、**入力が必要**、**準備完了**、**ブロック中**を使用しますが、デスクトップアプリにある複数チャットのアクティビティトレイは
利用できません。

ターミナルペットを使用するには、iTerm2 3.6 以降、または Kitty graphics か
Sixel をサポートするターミナルが必要です。tmux 内および Zellij 内では利用できません。

## IDE 拡張機能のペット

Codex IDE 拡張機能には、ペットピッカーやフローティングペットのオーバーレイはありません。
自分のペットを使用する場合は、ChatGPT デスクトップアプリまたは Codex CLI を使用してください。
