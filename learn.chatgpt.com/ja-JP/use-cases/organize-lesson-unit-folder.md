## 再編成前のファイル棚卸し

まず、既存の授業または単元フォルダーから始めます。どのファイルが正式版で、どれが作業中の下書きか、また、どのファイルを移動してはならないかを ChatGPT に伝えます。

想定される用途ごとにファイルを分類し、重複ファイル、分かりにくいファイル名、古いバージョンを示す一覧を作成するよう依頼します。

## 提案された構成のレビュー

実用的なフォルダー構成では、たとえば次のように分けられます：

- 原資料と参考資料
- 授業計画
- プレゼンテーション資料
- 生徒向け配布資料
- 評価資料と解答集
- アクセシビリティ対応版または多言語版
- アーカイブした下書き

具体的なフォルダー構成には、教師やチームの実際の作業方法を反映させる必要があります。変更を承認する前に、フォルダー名と移動案をレビューしてください。

## 結果の検証

整理後、リンクが引き続き機能すること、現在使用中のファイルを簡単に見つけられること、何も削除されていないことを確認します。ChatGPT に、名前を変更したファイル、移動したファイル、アーカイブしたファイルが分かる README と変更概要の作成を依頼します。

単元の内容が大幅に変わったら、棚卸しをやり直します。これにより、重複ファイルがさらに積み重なるのを防ぎ、フォルダーを使いやすい状態に保てます。
