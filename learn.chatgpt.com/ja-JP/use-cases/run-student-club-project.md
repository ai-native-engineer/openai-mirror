## プロジェクトハブの構築

プロジェクト概要、現在のフォルダー、会議メモ、予算、メンバーが参加できる日時、キャンパスの要件、期限を集めます。日程、承認、支出ルールについて、基準となる情報源を特定します。

ファイルを再整理したり作業を割り当てたりする前に、現状を棚卸しするよう ChatGPT に依頼します。

## 作業計画

運営ハブでは、以下を相互に関連付ける必要があります：

- マイルストーンと期限
- 担当者の候補と依存関係
- 予算項目と承認
- 意思決定事項と未解決の論点
- リスクと不測の事態への対応策
- 会議の議題とフォローアップ
- 連絡文案

非公開の計画メモは、メンバー、パートナー、参加者向けのメッセージとは分けて管理します。

## チームでのレビュー

チーム会議で、担当者、日程、予算上の前提を確認します。ChatGPT は推奨事項の草案を作成できますが、承認なしに担当者を割り当てたり、メッセージを送信したり、資金の支出を決めたりしてはいけません。

各会議後にメモを追加し、確認済みの意思決定を反映してハブを更新するよう ChatGPT に依頼します。将来の運営担当者が変更内容を把握できるよう、意思決定ログを残します。
