## 承認済み資料に基づく単元計画

学習基準、カリキュラムガイドまたは進度ガイド、学校カレンダー、過去の授業、評価指針、関連する学習者のニーズを収集します。どの資料が現行版で、どれが参考例にすぎないのかを確認します。

計画上の重要な判断ごとに、根拠となる承認済み資料を対応付けるよう ChatGPT に依頼します。

## 授業の流れの下書き

スタータープロンプトを使用し、次の項目を含む計画を作成します：

1. 学習目標と学習基準。
2. 利用可能な日程に合った授業の流れ。
3. 必要な教材と資料ファイルへのリンク。
4. 形成的な理解度確認と各評価との関連。
5. 想定される誤概念や前提知識の不足。
6. 教員がレビューすべき判断事項と指針の不足箇所。

下書きには、活動を列挙するだけでなく、各授業をその流れに組み込む理由も示す必要があります。

## 指導上の判断のレビュー

学習基準との整合性、進度、評価の負担、アクセシビリティ、対象年齢への適合性を確認します。ChatGPT が学区の要件や学習者に関する情報を根拠なく作り出していないことも確認します。

同じチャットで計画を修正し、どれが承認済み版かを明確に示してから、スライド資料や授業用教材の作成に使用します。
