## 試験範囲の明確化

まず、公式の学習目標、教員からの案内、講義ノート、指定文献、演習問題、過去の小テストを用意します。学習に使える時間と、すでに重点的な学習が必要だとわかっているトピックも追加します。

予定している各トピックを、根拠となる授業資料に対応付けるよう ChatGPT に依頼します。試験範囲かどうか不明な内容は、試験内容として扱わず、確認事項として残します。

## 複数の学習形式の作成

スタータープロンプトを使って、相互に補完する次の学習資料を作成します：

1. 関係性を示すコンセプトマップ。
2. 復習用の簡潔な学習ガイド。
3. 間隔を空けて反復練習するためのカレンダー。
4. 想起、説明、応用を幅広く扱う問題バンク。
5. 授業資料に基づく解答解説。
6. トピックと演習結果を記録する進捗トラッカー。

同じ要約を何度も読み返すより、複数の形式を組み合わせるほうが、理解の抜けを見つけやすくなります。

## 見直しと調整

問題と解答解説を公式資料と照合します。公式資料にないトピック、曖昧な解答、根拠のない主張を削除します。

学習セッションが終わるたびにトラッカーを更新し、明らかになった理解の抜けに合わせて、以降のセッションを調整するよう ChatGPT に依頼します。採点対象となる課題や利用が制限されている授業資料は、教員が定めたルールの範囲内で扱ってください。
