## はじめに

新しい製品や機能に取りかかる前に、スコープと要件について認識を合わせるため、製品要件ドキュメント（PRD）の下書きを作成するのが一般的です。多くの場合、その PRD の作成に必要なコンテキストは、Linear のチケット、Slack での議論、Notion や Google Drive の下書きなど、チームの社内システムにすでにあります。ChatGPT はこのコンテキストを収集し、出典をたどれる状態に保ちながら、レビューと改善を重ねられる PRD の下書きを作成できます。

## 情報源の選択

まず、ChatGPT に使用させる情報源を指定します。PRD で引用する Linear のプロジェクト、Slack の計画用チャンネルまたはスレッド、Drive のドキュメント、Notion のページ、会議メモ、ローカルファイルなどです。
また、問題、ユーザー、要件、UX、技術面、ローンチ計画、タイムライン、決定事項など、PRD に含めるセクションを明確に示す必要があります。

1. 出力を実際の DOCX ファイルにする場合は、`$documents` から始めます。
2. 情報源を直接指定します。Linear のプロジェクトまたはマイルストーン、Slack のチャンネルまたはスレッド、ChatGPT が引用するドキュメントやメモを指定してください。
3. PRD に含めるセクションの要件を ChatGPT に伝えます。
4. まず出典をまとめた付録をレビューし、次に要件と未解決の質問を確認します。
5. 同じチャットで不足を補い、スコープを明確にし、引き継ぎの準備をします。

## 同じチャットでの改善

最初の下書きには、このページのスタータープロンプトを使用します。必要な情報が不足している場合は、最初からやり直さず、その情報を補える情報源を ChatGPT に指定してください。

## 出典情報の確認

PRD を共有する前に、出典による裏付けが弱いか、まったくない主張、未解決の質問、確定済みとして扱った決定事項を一覧にするよう ChatGPT に依頼します。出典をまとめた付録を見てもそれらを簡単に監査できない場合は、何かをエクスポートまたは投稿する前に、同じチャットで改善を続けてください。
