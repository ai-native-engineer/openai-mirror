# 財務

ChatGPT Work または Codex を使用して、承認済みのワークブック、ダッシュボード、モデル、
担当者が提供する背景情報を、レビュー可能な分析結果やレポート資料にまとめます。ChatGPT では、
数式、出典、前提条件、未解決の問題を明示できるため、
財務責任者は、内容を共有する前に判断を下せます。

## 業績の説明

決算データから経営層向けの説明を組み立て、実績を計画と比較し、
重要な変動の要因を影響度順に整理します。

## モデルと計画のレビュー

財務モデルを構築または検証し、予測を更新して、前提条件やソースの不足を隠さずに
シナリオを比較します。

## 経営層向けレポートの作成

承認済みの進捗トラッカー、指標、コメント、各担当者からの情報を基に、
全社、経営層、CFO、または取締役会向けの定例報告資料を作成します。
