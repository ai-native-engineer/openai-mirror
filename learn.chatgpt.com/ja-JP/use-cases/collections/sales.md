# 営業

ChatGPT Work または Codex で、アカウント記録、顧客との
会話、パイプラインのシグナル、未解決のリスクをまとめます。ChatGPT は承認済みの
コンテキストから、概要資料、フォローアップ文案、売上予測レビュー、アカウントプランを作成し、
出典に基づく事実と、推定した商機やリスクを区別して扱えます。

## パイプラインの優先順位付けと売上予測の見直し

対応が必要なアカウントに優先順位を付けてから、どの商談をコミットに残すか、
アップサイドに移すか、売上予測から外すかをレビューします。

## ミーティングの準備とフォローアップ

顧客とのミーティングに必要なコンテキストを収集し、承認済みのメモや
文字起こしから、フォローアップ文案、社内向けの要約、レビュー可能な次のステップを作成します。

## アカウント戦略の策定と商談の停滞解消

最近の顧客シグナルに基づいてアカウント戦略を更新するか、停滞している商談について、
障害となっている要因とエスカレーション経路を特定します。
