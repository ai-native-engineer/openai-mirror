# ゲーム開発

Codex は画像生成と組み合わせることで、ブラウザベースをはじめとするさまざまなゲームの制作に特に威力を発揮します。
これらのユースケースは、アイデアを実際に動くゲームへと形にするのに役立ちます。

## 最初のプレイ可能なゲームループの構築

ゲーム概要を、アセット、操作系、テスト可能なゲームループを備えたブラウザ向けビルドに仕上げるよう Codex に依頼します。

## UI と操作系の調整

ゲームが動作するようになったら、Codex を使って HUD の細部やメニュー、操作系を調整し、操作時の細かな問題を修正します。

## 複雑なゲームロジックへの対応

自己評価ループを実行しながら、Codex を活用して複雑なゲームアルゴリズムを反復的に改善します。

## 実際のシグナルに基づくバグのトリアージ

Codex でゲームにパッチを適用する前に、バグレポート、失敗したチェック、ログ、再現手順のメモを収集し、優先順位付きのリストにまとめます。

## マージ前のレビュー

GitHub 上の Codex に PR を自動レビューさせ、リグレッションや不足しているテストを検出することで、デプロイを迅速化します。
