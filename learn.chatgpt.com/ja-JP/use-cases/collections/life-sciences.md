# ライフサイエンス

当社のフロンティアリーズニングモデルである GPT-Rosalind は、
生物学、創薬、トランスレーショナル医療にわたる研究を支援するために構築されています。このライフサイエンス向けモデルシリーズは、
科学研究のワークフローに最適化され、ツールをより効果的に活用する能力と、
化学、タンパク質工学、ゲノミクスに関するより深い理解を兼ね備えています。現在、
GPT-Rosalind は、当社のトラステッドアクセスプログラムを通じて、利用資格のあるユーザー向けの
[研究プレビュー](https://openai.com/form/life-sciences-access/) として ChatGPT、
Codex、API で利用できます。

科学研究や分析には、ChatGPT Work または Codex を使用します。ChatGPT では、
共有の研究ワークフローで GPT-Rosalind と科学研究向けプラグインを活用できます。一方、
コード、リポジトリ、ベンチマーク、反復的なソフトウェア実験のいずれかが必要な場合は、
Codex を使用します。

## ライフサイエンスの研究と分析

ChatGPT を使用すると、シーケンシングデータから、研究に活用できる生物学的知見を導き出せます。
bulk RNA-seq と single-cell RNA-seq の解析から、
複数の情報源を用いた標的の優先順位付けまで対応します。

## タンパク質フォールディングの研究とアーキテクチャ探索

Codex を使用して、タンパク質フォールディングに関する仮説をレビュー可能な実験サイクルに落とし込みます。
明示的なベンチマークと永続的な成果物を用意し、エビデンスの範囲を明確にします。
