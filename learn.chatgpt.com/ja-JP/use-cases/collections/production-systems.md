# 本番システム

このコレクションのユースケースは、履歴、テスト、オーナー、本番運用上の制約がすでにあるリポジトリで Codex を使用する場合に役立ちます。
Codex は、多数のサービスや依存関係を抱える大規模なモノレポをはじめ、複雑なコードベースの探索を特に得意としています。
本番システムに携わっている場合は、これらのユースケースに目を通し、Codex がどのように役立つかを確認してください。

## コードベースツアーから開始

Codex を使えば、複雑なコードベースを把握できます。特に、本番ソフトウェアのリポジトリへのオンボーディング時に役立ちます。

## コードベースのモダナイズ

Codex を活用して、技術スタックの移行を計画し、必要に応じて既存の統合を最新モデル対応にアップグレードし、コードベースをリファクタリングして可読性と保守性を高めます。

## 反復作業の標準化

リポジトリの全コントリビューターが標準化されたプロセスを活用できるように、リポジトリ固有のワークフローやチェックリストをスキルに変換するよう Codex に依頼します。

## ドキュメントを最新に維持

ソースの変更を既存のドキュメントと比較し、実用上必要な最小限の範囲でドキュメントを更新して、変更内容を検証するよう Codex に依頼します。

## システムの健全性維持

Slack から Codex を使用し、アラートシステム、イシュー管理、日次のバグチェックと連携させることで、機能リクエストやバグ修正に自動で対応できるようにします。

## レビューのボトルネックを回避

Codex を使って PR を自動でレビューし、重要なフローに絞って QA を実施すれば、問題をすばやく発見し、安心してアップデートをリリースできます。
