# Web 開発

Codex は既存のデザインシステムとの相性がよく、制約や視覚的な入力を考慮してレスポンシブ UI を生成します。
これらのユースケースは、Web アプリを構築し、フロントエンドのデザインを反復改善する場合に役立ちます。

## アイデアからプロトタイプへ

Codex を使って、大まかなアイデアからビジュアルの方向性を定め、最初のプロトタイプを実装します。

## Figma を基に実装

Codex を使って Figma からデザインのコンテキストを取得し、リポジトリのコンポーネント、スタイリング、デザインシステムに沿ったコードに変換します。

## UI の反復改善

Codex を活用すれば、視覚的な入力やプロンプトに基づいて必要な箇所だけを変更し、その結果をブラウザで検証できます。

## Slack 上のスコープが明確なタスクへの対応

機能リクエストや問題の報告があったら、Slack で Codex をタグ付けしてください。Codex がそのタスクを引き受け、バックグラウンドで作業します。

## プレビューのデプロイ

Codex を使って Web アプリを構築または更新し、Vercel でデプロイして、共有可能なライブ URL を受け取ります。
