# 教育

ChatGPT Work または Codex を使って、各所に分散した授業資料、学業上の
要件、スケジュール、フィードバック、プロジェクトのコンテキストを、編集可能で
すぐにレビューできる成果物にまとめます。ChatGPT は、出典に基づく根拠を保持し、不確実性を
明示しながら、大学教員、教師、学生、学校チームが引き続き責任を持って
学術面と指導面での意思決定を行えるようにします。

## 高等教育機関の教員

授業内容を更新し、評価基準を調整し、複数クラスを比較し、参加状況を確認し、
研究のエビデンスを統合して、教員委員会での意思決定に備えます。

## 高等教育機関の学生

学期の予定を整理し、試験に備え、学生プロジェクトの進行を調整し、時間とお金をバランスよく
配分し、ウェブサイトを構築し、求人やインターンシップへの応募を管理します。

## K–12 の教員

授業用ファイルを整理し、単元計画を立て、授業用スライドと、それに付随する
教材を作成し、フィードバックを一貫して反映し、インタラクティブな授業リソースを構築します。
