## 依頼から分析要件への落とし込み

ステークホルダーからの依頼には、ビジネス上の問い、希望するグラフ、前提とされている指標定義が混在しがちです。元の依頼と関連する背景情報を ChatGPT に渡し、分析を始める前に、問い、定義、データソース、結合、判断事項を特定するよう依頼します。

1. 依頼に関するスレッド、指標用語集、ダッシュボード、エクスポートファイル、関連する背景情報を添付します。
2. 把握できている事項、曖昧な点、不足している情報、スコープ外の事項を ChatGPT に列挙してもらいます。
3. 指標定義、結合ロジック、対象期間、想定読者を確認します。
4. スタータープロンプトを使って、一次分析を実行し、ステークホルダーに提示できる回答を作成します。
5. 計算、グラフ、注意事項、未解決の質問をアナリストにレビューしてもらいます。

断定的な回答によって、未定義の指標や未検証の結合が見過ごされないようにしてください。分析計画も成果物の一部です。これにより、次のイテレーションをより迅速にレビューできます。

## 依頼者への最終確認

分析のレビュー後、未解決の質問を短い確認メモにまとめ、送信せずに下書きだけ作成するよう ChatGPT に依頼します。
