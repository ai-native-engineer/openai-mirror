## Convierte la solicitud en un acuerdo de análisis

Las solicitudes de las partes interesadas suelen mezclar la pregunta de negocio, un gráfico preferido y una definición de métricas que se da por sentada. Dale a ChatGPT la solicitud original y el contexto relacionado; luego, pídele que identifique la pregunta, las definiciones, las fuentes, las uniones y las decisiones antes de iniciar el análisis.

1. Adjunta el hilo de la solicitud, el glosario de métricas, los paneles, las exportaciones de datos y el contexto pertinente.
2. Pídele a ChatGPT que enumere qué se sabe, qué es ambiguo, qué falta y qué queda fuera del alcance.
3. Confirma las definiciones de las métricas, la lógica de unión, la ventana temporal y el público destinatario.
4. Ejecuta el prompt inicial para obtener un análisis preliminar y una respuesta lista para presentar a las partes interesadas.
5. Pídele a un analista que revise los cálculos, los gráficos, las salvedades y las preguntas pendientes.

No dejes que el tono seguro de una respuesta oculte una métrica sin definir o una unión sin verificar. El plan de análisis forma parte del entregable porque agiliza la revisión de la siguiente iteración.

## Cierra el ciclo con el solicitante

Una vez revisado el análisis, pídele a ChatGPT que convierta las preguntas pendientes en una breve nota de confirmación, sin enviarla.
