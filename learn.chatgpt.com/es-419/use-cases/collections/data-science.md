# Ciencia de datos

Usa ChatGPT Work o Codex para convertir dashboards, definiciones de métricas, exportaciones,
notas de experimentos y contexto de las partes interesadas en análisis que otros puedan revisar
y usar como base para actuar. ChatGPT puede mantener visibles los cálculos, las fuentes, las salvedades y las preguntas pendientes
para que los analistas puedan validar la evidencia antes de compartirla.

## Definir el alcance de las preguntas e investigarlas

Convierte una solicitud ambigua en un plan de análisis claro o investiga una
variación inesperada de un KPI en los segmentos y el contexto relevantes.

## Medir y explicar el desempeño

Evalúa el impacto de un experimento o lanzamiento y convierte los KPI recurrentes y
los datos del negocio en una explicación del desempeño respaldada por fuentes.

## Diseñar dashboards y sistemas de monitoreo

Define la jerarquía de KPI, las especificaciones de los gráficos, las verificaciones de calidad, los responsables y
el plan de monitoreo que sustentan un dashboard listo para la toma de decisiones.
