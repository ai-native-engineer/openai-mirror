# Desarrollo nativo

Codex funciona muy bien en proyectos para plataformas de Apple cuando cada iteración incluye un ciclo de compilación, ejecución o simulación.
Estos casos de uso resultan útiles cuando desarrollas apps nuevas o existentes para iOS y macOS y necesitas iterar en la interfaz de usuario y depurar problemas.

## Crear la estructura base de la app

Pídele a Codex que cree la estructura inicial de apps para iOS y macOS con ciclos de compilación repetibles. El caso de uso de la estructura base para Mac profundiza en diseños con barra lateral, vista detallada e inspector, así como en comandos, configuración y otros elementos estructurales propios de las apps de escritorio.

## Refactorizar pantallas de SwiftUI para iOS

Usa Codex para dividir vistas grandes de SwiftUI sin cambiar su comportamiento y, cuando la app esté lista, migra ciertos flujos de iOS a Liquid Glass.

## Exponer acciones de iOS al sistema

Aprovecha Codex para identificar las acciones y entidades que tu app debería exponer mediante App Intents, de modo que los usuarios puedan acceder a sus funciones desde las interfaces del sistema.

## Depurar tu app

Pídele a Codex que reproduzca errores en Simulator o agregue telemetría a tu app para macOS a fin de ayudarte a depurar y corregir problemas.
