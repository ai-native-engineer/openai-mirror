# Sistemas de producción

Los casos de uso de esta colección son útiles cuando Codex trabaja en un repositorio que ya tiene historial, pruebas, responsables y restricciones de producción.
Codex es especialmente eficaz para navegar por bases de código complejas, incluidos los monorepos extensos con muchos servicios y dependencias diferentes.
Si trabajas en un sistema de producción, familiarízate con estos casos de uso para comprender cómo puede ayudarte Codex.

## Comienza con un recorrido por la base de código

Usa Codex para familiarizarte con una base de código compleja, lo que resulta especialmente útil al incorporarte a un repositorio de software de producción.

## Moderniza la base de código

Aprovecha Codex para planificar migraciones de la pila tecnológica, actualizar tu integración a los modelos más recientes si corresponde y refactorizar la base de código para mejorar su legibilidad y facilidad de mantenimiento.

## Formaliza el trabajo repetible

Pídele a Codex que convierta los flujos de trabajo o las listas de verificación propios del repositorio en una habilidad, para que todos los colaboradores del repositorio puedan beneficiarse de un proceso estandarizado.

## Mantén actualizada la documentación

Pídele a Codex que compare los cambios en el código fuente con la documentación existente, actualice el conjunto mínimo de documentación necesario y verifique los cambios.

## Mantén el sistema en buen estado

Haz que Codex se encargue automáticamente de las solicitudes de funcionalidades y las correcciones de errores usándolo desde Slack y conectándolo con tus sistemas de alertas, seguimiento de incidencias y rondas diarias de detección de errores.

## Evita el cuello de botella en la revisión

Usa Codex para revisar automáticamente los Pull requests y realizar revisiones específicas de control de calidad en los flujos críticos, para que puedas detectar problemas rápidamente y lanzar actualizaciones con confianza.
