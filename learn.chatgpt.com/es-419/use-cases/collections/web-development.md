# Desarrollo web

Codex funciona muy bien con los sistemas de diseño existentes, ya que tiene en cuenta las restricciones y las referencias visuales para generar una interfaz de usuario responsiva.
Estos casos de uso son útiles cuando desarrollas aplicaciones web y necesitas iterar en los diseños de frontend.

## Pasa de la idea al prototipo

Usa Codex para convertir una idea preliminar en una dirección visual e implementar un primer prototipo.

## Desarrolla a partir de Figma

Usa Codex para obtener el contexto de diseño de Figma y convertirlo en código que respete los componentes, los estilos y el sistema de diseño del repositorio.

## Itera en la interfaz de usuario

Usa Codex para hacer cambios específicos a partir de referencias visuales o prompts, y pídele que verifique su trabajo en el navegador.

## Atiende tareas específicas desde Slack

Etiqueta a Codex en Slack cuando alguien solicite una funcionalidad o reporte un problema, para que pueda encargarse de la tarea y trabajar en ella en segundo plano.

## Despliega una vista previa

Usa Codex para crear o actualizar una aplicación web, desplegarla con Vercel y obtener una URL activa que puedas compartir.

## Publica cambios más rápido

Usa Codex en GitHub para verificar que los cambios se puedan integrar de forma segura y así agilizar el ciclo de desarrollo.
