## Definir el alcance de una primera versión útil

Comienza por el público, la tarea principal que el sitio debe facilitar y el material de referencia que ya tienes. Agrega ejemplos, preferencias de diseño, requisitos de accesibilidad y criterios de éxito claros.

Mantén el alcance inicial lo suficientemente acotado como para desarrollar y probar el sitio en una sola iteración.

## Crear e inspeccionar el sitio

Usa el prompt inicial de Sites para:

- organizar el contenido proporcionado
- establecer una estructura de información sencilla
- crear las páginas y las interacciones principales
- usar diseños responsivos
- verificar el acceso mediante teclado, las etiquetas y el contraste
- probar el recorrido principal con contenido representativo

Revisa la vista previa local antes de publicar el sitio. Verifica que el texto, las imágenes, los enlaces, los formularios y los datos provengan de fuentes aprobadas.

## Preparar el sitio para compartirlo

Pídele a ChatGPT una lista de verificación para la publicación que abarque el contenido faltante, los permisos, la privacidad, la accesibilidad y las pruebas finales. Si el sitio permite enviar información, confirma adónde se dirigen los datos y quién puede acceder a ellos.

Publica solo después de que la persona responsable del proyecto o el docente correspondiente apruebe la versión revisada.
