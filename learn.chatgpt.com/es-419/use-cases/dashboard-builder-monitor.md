## Diseña en función de las decisiones, no de los gráficos

Antes de especificar un panel, define las decisiones que debe respaldar y quiénes serán los responsables de actuar en respuesta a las señales. Proporciona a ChatGPT las definiciones de métricas, las exportaciones de datos de origen, los ejemplos existentes, el contexto del flujo de trabajo y los comentarios de las partes interesadas para que la especificación se mantenga basada en datos reales.

1. Especifica el flujo de trabajo, la audiencia, las decisiones y la frecuencia de revisión.
2. Adjunta el glosario de métricas, las exportaciones de datos de origen, los ejemplos de paneles y los comentarios de las partes interesadas.
3. Pídele a ChatGPT que identifique los vacíos en las fuentes de datos, las verificaciones de calidad y las necesidades de asignación de responsables.
4. Ejecuta el prompt inicial para generar un borrador que incluya la jerarquía de KPI, las especificaciones de gráficos, los filtros y el monitoreo.
5. Revisa los riesgos de publicación y contrasta las métricas propuestas con los datos de origen.

Considera que la especificación del panel es un contrato entre analistas, responsables de los datos y usuarios. Define qué significa cada gráfico, cuándo se puede confiar en él y qué acción debe desencadenar.

## Haz que el monitoreo lleve a la acción

Una vez revisada la especificación, pídele a ChatGPT que convierta las verificaciones de mayor valor en una lista de verificación para el monitoreo con criterios claros sobre cuándo escalar.
