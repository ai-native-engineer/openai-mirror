## Partir del contenido didáctico aprobado

Usa el paquete didáctico revisado, las preguntas de práctica, las reglas de retroalimentación, los requisitos de accesibilidad y las preferencias de diseño. Identifica el objetivo de aprendizaje y la evidencia que demuestre que un estudiante completó la práctica prevista.

No inventes lineamientos pedagógicos ni datos de estudiantes que no se hayan proporcionado.

## Crear el flujo de aprendizaje

Una primera versión bien delimitada debería incluir:

- una introducción clara
- un ejemplo guiado
- un conjunto reducido de interacciones de práctica
- retroalimentación conforme a las reglas proporcionadas
- una autoevaluación final
- notas para docentes

Usa Sites para crear y previsualizar el recurso. Mantén el modelo de interacción lo bastante sencillo como para probarlo a fondo.

## Probar antes de compartir

Comprueba los flujos principales, el uso del teclado, las etiquetas, el contraste, el comportamiento responsivo, la lógica de retroalimentación y la exactitud del contenido. Prueba tanto las respuestas incorrectas como las correctas.

Pídele a ChatGPT que documente las limitaciones y las cuestiones pendientes sobre accesibilidad o aspectos pedagógicos. Un educador debería aprobar el recurso revisado antes de que se publique o se comparta con los estudiantes.
