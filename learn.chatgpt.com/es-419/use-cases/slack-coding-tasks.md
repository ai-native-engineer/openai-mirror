## Cómo usarlo

1. Instala la app de Slack, conecta los repositorios y entornos correctos, y agrega `@Codex` al canal.
2. Menciona a `@Codex` en un hilo con una solicitud clara, las restricciones y el resultado que deseas.
3. Abre el enlace del chat, revisa el resultado y continúa el seguimiento en Slack si la tarea necesita otra iteración.

Puedes obtener más información sobre cómo usar Codex en Slack en la [guía específica](/es-419/codex/third-party/slack).

## Consejos

- Si el hilo aún no incluye suficiente contexto ni una corrección sugerida, incluye algunas indicaciones en tu prompt
- Asegúrate de que la asignación del repositorio y del entorno sea correcta: menciona el nombre del proyecto o del entorno en tu prompt
- Define el alcance de la solicitud para que Codex pueda completarla sin una segunda ronda de planificación
- Si tu proyecto tiene una base de código extensa, orienta a Codex mencionando qué archivos o carpetas son relevantes para la tarea
