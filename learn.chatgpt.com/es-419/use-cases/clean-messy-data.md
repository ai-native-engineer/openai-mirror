## Introducción

ChatGPT es excelente para limpiar datos tabulares de manera sistemática.
Cuando un archivo CSV o una hoja de cálculo contiene fechas en distintos formatos, filas duplicadas, valores monetarios en forma de cadenas de texto, celdas en blanco, alias o filas de resumen pegadas, pídele a ChatGPT que limpie una copia y deje el archivo original sin cambios.

## Cómo usarlo

1. Arrastra el archivo a ChatGPT o menciónalo en tu prompt, por ejemplo, `@customer-export.csv`.
2. Describe los problemas que ya detectaste.
3. Indícale a ChatGPT qué formato debe tener la versión limpia: un archivo CSV, una pestaña de una hoja de cálculo o un archivo listo para cargar.
4. Revisa la copia limpia antes de usarla.

Usa el prompt inicial de esta página para la primera pasada de limpieza. Reemplaza el nombre del archivo y las viñetas por los de tu caso. Lo más útil es indicar qué problemas ya detectaste y qué archivo necesitas a continuación: un archivo CSV limpio, una pestaña limpia de una hoja de cálculo o un archivo listo para cargar. Después de que ChatGPT genere la copia limpia, abre desde el chat el archivo limpio y la nota sobre la calidad de los datos antes de usar los datos en procesos posteriores.
