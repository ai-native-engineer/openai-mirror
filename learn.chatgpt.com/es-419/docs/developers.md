# Desarrolladores

Configura flujos de trabajo de desarrollo, entornos, extensiones e integraciones

Usa Codex con bases de código, entornos de desarrollo, automatización y las herramientas de tu equipo.

Codex facilita las tareas cotidianas de programación y las integraciones más avanzadas en entornos locales y en la nube. Sus flujos de trabajo para desarrolladores abarcan la revisión de código, la terminal integrada, las habilidades y los complementos reutilizables, la automatización con el SDK y App Server, las herramientas para equipos y el material de referencia para cada interfaz.
