  ### Activa tareas programadas a partir de eventos de Gmail, Slack y GitHub

  Las tareas programadas de ChatGPT ahora pueden ejecutarse cuando ocurren eventos compatibles en Gmail, Slack
  o GitHub. Filtra los mensajes de Gmail por remitente o asunto, monitorea los canales de Slack
  seleccionados o responde a la actividad de los Pull Requests, como revisiones, comentarios, actualizaciones de commits
  y fusiones.

  Las tareas activadas por eventos están disponibles en ChatGPT en la web y en dispositivos móviles para
  los planes elegibles. Conecta la app correspondiente y aprueba el acceso que solicita antes de
  crear una tarea.
  La app de ChatGPT para Slack debe ser miembro de cada canal monitoreado, y la
  app de GitHub conectada debe tener acceso a cada repositorio monitoreado.

  Una tarea activada por eventos no puede tener también un horario de ejecución. Cuando llegan eventos que cumplen los criterios
  con poco tiempo de diferencia, ChatGPT puede combinarlos en una sola ejecución.
  Abre **Programadas** para revisar los eventos pendientes o elige **Ejecutar ahora**.

  [Aprende a activar tareas programadas a partir de eventos
  de apps](/codex/automations?surface=web#web-trigger-tasks-from-app-events).

  sitios web en memorias y una cronología que ChatGPT y Codex pueden usar. Elige
  qué apps y sitios web se incluyen, pausa la recopilación y revisa o elimina
  tu historial en cualquier momento.

  El Historial de la computadora está disponible para usuarios de ChatGPT Pro, Business y Empresas.
  Los administradores de Business y Empresas deben habilitar el acceso antes de que los miembros del espacio de trabajo
  puedan activarlo. La disponibilidad inicial excluye el Espacio Económico Europeo (EEE),
  Suiza y el Reino Unido.

  ### Presentamos Daybreak Blue y Daybreak Red

  Daybreak ahora ofrece dos niveles de acceso para defensores autorizados: Daybreak Blue y
  Daybreak Red. Úsalos para pasar de los hallazgos de seguridad a correcciones validadas en
  actividades expresamente autorizadas.

  Comienza con Daybreak Blue para la mayoría de las tareas de seguridad defensiva. Ofrece acceso
  a modelos de uso general, como GPT-5.6 Sol, para el descubrimiento de vulnerabilidades,
  la revisión de seguridad del código, la ingeniería de detección, la respuesta a incidentes, el análisis de malware
  y la validación de parches.

  Daybreak Red ofrece acceso, previa aprobación independiente, a modelos entrenados para fines específicos, como
  GPT-5.6 Cyber, para la reproducción autorizada de vulnerabilidades, la validación de exploits,
  las pruebas de penetración, el red teaming y el análisis de sistemas complejos.

  El acceso requiere aprobación mediante
  [Trusted Access for Cyber](/codex/cyber-safety#trusted-access-for-cyber) y
  solo se aplica a lo aprobado: la identidad, el espacio de trabajo o la organización y el proyecto de la API,
  el modelo y la interfaz del producto. Daybreak Red requiere aprobación
  y aprovisionamiento por separado; el acceso a Daybreak Blue no otorga acceso a Daybreak Red.

  Trabaja en un entorno aislado, define el alcance de la actividad, usa
  [perfiles de permisos](/codex/permissions) con privilegios mínimos y configura
  la [Revisión automática](/codex/sandboxing/auto-review) para las acciones elegibles antes de que
  crucen el límite del sandbox.

  Obtén más información sobre [Seguridad cibernética](/codex/cyber-safety),
  [las tarifas de créditos de Codex](/codex/pricing#credits-overview) y
  [los precios de los tokens de la API](/api/docs/pricing).

  ### La búsqueda web ahora está habilitada de forma predeterminada

  Codex ahora habilita la búsqueda web para las tareas locales en la CLI y la Extensión para IDE de Codex.
  De forma predeterminada, Codex usa una caché de búsqueda web, que es un índice de resultados web mantenido por OpenAI. El modo en caché devuelve resultados preindexados en lugar de obtener páginas en vivo, mientras que el modo en vivo obtiene los datos más recientes de la web. Si usas `--yolo` u otra [configuración de sandbox con acceso completo](/codex/agent-approvals-security), la búsqueda web usa resultados en vivo de forma predeterminada. Para deshabilitar este comportamiento o cambiar de modo, usa la opción de configuración `web_search`:

  + `web_search = "cached"` (valor predeterminado; proporciona resultados de la caché de búsqueda web)
  + `web_search = "live"` (obtiene los datos más recientes de la web; equivale a `--search`)
  + `web_search = "disabled"` para quitar la herramienta

  Para obtener más información, consulta la [documentación de configuración](/codex/config-file/config-basic).
