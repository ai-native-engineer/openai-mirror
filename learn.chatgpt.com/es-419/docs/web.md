Elige Chat o Work

Usa Chat para explorar una pregunta o dar forma a una idea. Cambia a Work cuando tengas un resultado claro en mente y quieras que ChatGPT planifique, recopile contexto y lleve una tarea más amplia hasta obtener un resultado que puedas revisar.

Elige el modelo y el nivel de razonamiento adecuados

Selecciona un modelo y un nivel de razonamiento en el editor. Comienza con el esfuerzo predeterminado y auméntalo cuando la tarea requiera una planificación más profunda, un análisis más exhaustivo o una ejecución de mayor escala con varios agentes.

Incorpora herramientas y flujos de trabajo repetibles

Instala complementos para conectar servicios como Google Drive, GitHub o Slack. Agrega habilidades cuando ChatGPT deba seguir un flujo de trabajo específico, usar las directrices del equipo o generar resultados de manera coherente.
