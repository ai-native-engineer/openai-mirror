## Dónde usar ChatGPT

ChatGPT está disponible en distintas plataformas, como la
[aplicación de escritorio de ChatGPT](/es-419/codex/app) y [ChatGPT en la web](/es-419/codex/web). Elige
la opción que se adapte a tu trabajo.

  

  Si desarrollas software y quieres usar Codex en tu terminal o editor de código,
  prueba [Codex CLI](/es-419/codex/cli) o la [extensión de Codex para IDE](/es-419/codex/ide).
