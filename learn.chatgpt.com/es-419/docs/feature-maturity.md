Algunas funciones de ChatGPT y Codex se lanzan con una etiqueta de madurez para que puedas saber qué tan confiable es cada una, qué podría cambiar y qué nivel de soporte puedes esperar.

| Madurez          | Qué significa                                                                                                 | Recomendaciones                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| En desarrollo | No está lista para usarse.                                                                                            | No la uses.                                                                    |
| Experimental      | Es inestable y OpenAI puede eliminarla o modificarla.                                                                  | Úsala bajo tu propia responsabilidad.                                                         |
| Beta              | Lista para pruebas con un público amplio; está completa en casi todos sus aspectos, pero algunos podrían cambiar según los comentarios de los usuarios.       | Apta para la mayoría de las evaluaciones y pruebas piloto; es de esperar que haya cambios menores.                      |
| Estable            | Cuenta con soporte completo, está documentada y lista para un uso generalizado; el comportamiento y la configuración se mantienen constantes con el tiempo. | Se puede usar de forma segura en producción; su eliminación suele ir precedida de un proceso de deprecación. |
| En desuso        | Sigue disponible por compatibilidad, pero ya no se recomienda; OpenAI puede eliminarla en una versión futura.       | Evita nuevos usos y planifica la migración.                                            |
