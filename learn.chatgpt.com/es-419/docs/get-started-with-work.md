## Introducción a ChatGPT Work

ChatGPT Work es una forma de delegar trabajo real a ChatGPT.

Usa Chat cuando quieras una respuesta, una explicación, una lluvia de ideas o un borrador breve.
Usa ChatGPT Work cuando quieras que ChatGPT complete una tarea con un resultado claro, como un
informe breve, una presentación, un análisis, una actualización periódica, un flujo de trabajo o un archivo que puedas revisar y
usar. Obtén más información sobre [cómo usar Chat y ChatGPT Work en conjunto](/es-419/codex/use-chatgpt).

ChatGPT Work puede usar tus archivos, complementos y herramientas aprobadas para obtener información,
crear archivos terminados, ejecutar flujos de trabajo y completar tareas listas para que las
revises. Puedes seguir el progreso, responder preguntas, cambiar de rumbo y
aprobar acciones importantes.

En la [App de escritorio](/es-419/codex/app), ChatGPT Work también puede usar archivos locales, apps y el
navegador cuando estas herramientas estén disponibles.

Si has usado Codex para tareas que no implican programación, puedes seguir en Codex o usar
ChatGPT Work en su lugar. ChatGPT Work ofrece las mismas capacidades principales con
una experiencia diseñada para el trabajo cotidiano.

## Qué probar primero

Primero, cambia a **Work**. Luego, elige tu primera tarea.
Las tareas adecuadas tienen un objetivo claro, algunos materiales de referencia y un resultado que puedas
revisar.

### Elige entre trabajar localmente o en la nube

En la App de escritorio, abre el control del editor con la etiqueta **Trabajar localmente**. Si
**Nube** aparece como opción, selecciónala cuando quieras que ChatGPT Work siga
ejecutándose después de cerrar la app o apagar la computadora, o cuando quieras
continuar el chat desde la web o la app móvil. Mantén seleccionada la opción **Trabajar localmente** cuando
la tarea necesite archivos o apps de tu computadora.

La opción Nube también es útil para las tareas programadas que investigan o revisan sitios web a lo largo
del tiempo, ya que su ejecución no depende de que tu computadora esté activa.

Estos son tres casos de uso comunes para comenzar:

### Crea una presentación

Usa ChatGPT Work para convertir notas, documentos, investigaciones o materiales de reuniones en una
presentación estructurada.

  
    
  

### Crea una hoja de cálculo comparativa

Usa ChatGPT Work para convertir notas, archivos o investigaciones en una hoja de cálculo que compare
opciones y te ayude a tomar una decisión.

  
    
  

### Configura una actualización periódica

Usa las tareas programadas cuando quieras que ChatGPT Work repita, supervise o actualice algo
con el paso del tiempo.

  
    
  

Obtén más información sobre las [tareas programadas](/es-419/codex/automations?surface=app).

## Prácticas recomendadas para usar ChatGPT Work

Usa ChatGPT Work cuando quieras que ChatGPT complete una tarea, cree un archivo o gestione el trabajo
a lo largo del tiempo. Es una buena opción para las tareas que:

- Implican varias fuentes, complementos, herramientas o pasos.
- Requerirían bastante tiempo para completarse manualmente.
- Producen un resultado que revisarás, editarás o reutilizarás.
- Deben repetirse, supervisarse o actualizarse con el paso del tiempo.

Para obtener un mejor resultado, indícale a ChatGPT qué necesitas lograr, las fuentes o complementos
que debe usar, las restricciones que debe respetar, los criterios que debe cumplir un buen resultado y cuándo debe detenerse para
una revisión o aprobación.

**En lugar de:** hazme una presentación sobre nuestra investigación sobre clientes.

Obtén más información sobre el [diseño de prompts para ChatGPT Work](/es-419/codex/prompting#prompting-for-work).

## Agrega complementos para obtener más contexto y mejores resultados

  
    
  

Los complementos conectan ChatGPT Work con herramientas que usa tu equipo, como Slack, Google Drive,
SharePoint, el correo electrónico, los calendarios, los sistemas de gestión de relaciones con clientes y los
sistemas de seguimiento de proyectos.

- Selecciona **Complementos** en la barra lateral izquierda para ver la biblioteca de complementos.
- Instala los complementos más relevantes para tu trabajo.
- Para indicarle a ChatGPT que use una herramienta específica, escribe `@` y el nombre del complemento en tu prompt.

Obtén más información sobre los [complementos](/es-419/codex/plugins).

## Usa ChatGPT Work de forma eficiente

Elige [GPT-6 Astra](/es-419/codex/models#gpt-6-astra) para trabajos exigentes que requieran
razonamiento cuidadoso, criterio visual o un archivo final bien elaborado. Para tareas más sencillas,
considera Sol, Terra o Luna. Elige entre los modelos
disponibles en tu selector de modelos y consulta el [uso de tu plan](/es-419/codex/pricing)
antes de iniciar una tarea de gran alcance.

ChatGPT Work es ideal para tareas de gran alcance que implican varios pasos, fuentes o
herramientas, o que requieren un entregable terminado. Las tareas más largas o complejas pueden consumir
más créditos porque ChatGPT hace más trabajo por ti. Enfócate en el valor
del resultado final, en lugar de la cantidad de prompts.

Mantén la tarea enfocada estableciendo límites útiles. Por ejemplo: “Usa solo
estas fuentes”, “compara las cinco mejores opciones” o “detente antes de enviar
cualquier cosa”.

Usa Chat en su lugar para preguntas rápidas, reescrituras breves y decisiones en las que
solo necesitas asesoramiento.

Obtén más información sobre [cómo trabajar de forma eficiente](/es-419/codex/prompting#prompting-for-work).

Si una tarea se pausa para una revisión de seguridad, sigue las indicaciones del aviso y revisa los hallazgos
disponibles antes de continuar. Consulta [monitoreo de seguridad y tareas pausadas](/es-419/codex/agent-approvals-security#safety-monitoring-and-paused-tasks).
