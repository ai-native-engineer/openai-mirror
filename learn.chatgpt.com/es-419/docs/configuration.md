# Configuración

Configura ChatGPT, las herramientas para desarrolladores de Codex, los flujos de trabajo reutilizables y las herramientas externas

Establece valores predeterminados, agrega contexto persistente y personaliza el funcionamiento de ChatGPT y de las herramientas para desarrolladores de Codex.

La configuración determina cómo se comportan ChatGPT y las herramientas para desarrolladores de Codex en chats, repositorios y computadoras. El contexto persistente, los archivos de configuración, las directrices del repositorio, los subagentes, las conexiones externas y la configuración de Linux y Windows funcionan en conjunto para mantener la coherencia de esos flujos de trabajo para usuarios individuales y equipos.
