OpenAI desarrolla de forma abierta partes clave de Codex. Ese trabajo se encuentra en GitHub para que puedas seguir el progreso, informar problemas y contribuir con mejoras.

Si mantienes un proyecto de código abierto de uso generalizado o quieres nominar a responsables del mantenimiento de proyectos importantes, también puedes [presentar una solicitud al programa Codex for OSS](/community/codex-for-oss) para obtener créditos para la API, ChatGPT Pro con Codex y acceso selectivo a Codex Security.

## Componentes de código abierto

| Componente                     | Dónde encontrarlo                                                                                             | Notas                                                   |
| ----------------------------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| CLI de Codex                     | [openai/codex](https://github.com/openai/codex)                                                           | El repositorio principal para el desarrollo de código abierto de Codex      |
| SDK de Codex                     | [openai/codex/codex-sdk](https://github.com/openai/codex/tree/main/sdk)                                   | El código fuente del SDK se encuentra en el repositorio de Codex                      |
| CLI de Codex Security            | [openai/codex-security](https://github.com/openai/codex-security)                                         | CLI para detectar y validar vulnerabilidades de seguridad |
| SDK de TypeScript de Codex Security | [openai/codex-security/sdk/typescript](https://github.com/openai/codex-security/tree/main/sdk/typescript) | SDK de TypeScript para ejecutar análisis de Codex Security         |
| App Server de Codex              | [openai/codex/codex-rs/app-server](https://github.com/openai/codex/tree/main/codex-rs/app-server)         | El código fuente de App Server se encuentra en el repositorio de Codex               |
| Habilidades                        | [openai/skills](https://github.com/openai/skills)                                                         | Habilidades reutilizables que amplían las capacidades de ChatGPT y Codex           |
| Complementos                       | [openai/plugins](https://github.com/openai/plugins)                                                       | Complementos reutilizables para ChatGPT y Codex                  |
| Extensión para IDE                 | -                                                                                                         | No es de código abierto                                         |
| Codex Cloud                   | -                                                                                                         | No es de código abierto                                         |
| Entorno universal en la nube   | [openai/codex-universal](https://github.com/openai/codex-universal)                                       | Entorno base que utiliza Codex Cloud                    |

## Dónde informar problemas y solicitar funciones

Usa el repositorio de GitHub correspondiente para enviar informes de errores y solicitudes de funciones:

- Informes de errores y solicitudes de funciones de Codex: [openai/codex/issues](https://github.com/openai/codex/issues)
- Informes de errores y solicitudes de funciones para la CLI y el SDK de TypeScript de Codex Security: [openai/codex-security/issues](https://github.com/openai/codex-security/issues)
- Foro de discusión: [openai/codex/discussions](https://github.com/openai/codex/discussions)

Cuando informes un problema, indica qué componente usas (CLI, SDK, extensión para IDE, Codex Cloud o Codex Security) y, si es posible, la versión.
