## Pasa de una idea a un resultado útil

ChatGPT es un agente de IA con el que te comunicas en lenguaje natural:

1. Empieza con una pregunta, una idea, notas preliminares, un archivo o una tarea que necesites
completar.

2. Pídele a ChatGPT que explique información, desarrolle ideas, redacte contenido, investigue un
tema, analice materiales o cree algo nuevo.

3. Agrega el contexto y las herramientas que necesita, como archivos, búsqueda web, proyectos o
complementos.

4. Revisa el resultado, corrige el rumbo y pide cambios. No necesitas
un primer prompt perfecto ni comandos especiales.

## Elige cómo quieres trabajar

Usa Chat para hacer una pregunta o conversar. Activa Work en el selector cuando
quieras que ChatGPT se encargue de una tarea más amplia hasta obtener un resultado que puedas revisar. Selecciona Codex
cuando quieras usar vistas para desarrolladores o ver más detalles técnicos, en especial para el desarrollo
de software.

| Elige       | Cuando quieras                              | Ejemplos                                                                     |
| ------------ | --------------------------------------------- | ---------------------------------------------------------------------------- |
| Chat         | Trabajar en algo con ChatGPT           | Hacer una pregunta, buscar en la web, generar ideas, redactar un mensaje, comparar opciones |
| ChatGPT Work | Definir un objetivo y obtener un resultado que puedas revisar | Crear una presentación, analizar archivos, redactar un informe, elaborar un plan de proyecto           |
| Codex        | Usar herramientas para desarrolladores y ver detalles técnicos | Depurar código, ejecutar pruebas, revisar un PR, implementar una función                      |

Usa Chat para hacer preguntas, generar ideas, redactar o revisar texto, resumir archivos,
comparar opciones o aclarar una tarea más amplia. En Codex, coloca el cursor sobre **Chat nuevo** y luego
selecciona **Chat rápido** cuando esa opción esté disponible.

Cuando necesites un resultado final que puedas revisar, cambia a **Work** y describe
qué debe incluir. Consulta [Primeros pasos con ChatGPT
Work](/es-419/codex/get-started-with-work) para ver ejemplos de tareas, prompts y prácticas
recomendadas.

### Qué puede hacer ChatGPT Work

ChatGPT Work puede planificar una tarea, recopilar contexto, usar herramientas y completar el trabajo
con un resultado que puedas revisar.

  

Pídele lo siguiente:

- **Investiga y analiza información.** Busca en la web, explora sitios web,
  compara fuentes, lee archivos, analiza datos y resume los hallazgos.
- **Usa tus archivos y herramientas.** Incorpora archivos subidos,
[proyectos](/es-419/codex/projects), memorias, ChatGPT Library y
[complementos](/es-419/codex/plugins) instalados. Los complementos pueden proporcionar información vinculada, flujos de
  trabajo reutilizables y acciones compatibles.
- **Crea archivos listos para usar.** Prepara y mejora [documentos, presentaciones,
  hojas de cálculo y archivos PDF](/es-419/codex/artifacts-viewer). Revisa el resultado, solicita
  cambios específicos y descarga el archivo final.
- **Crea contenido visual e interactivo.** Genera o edita
[imágenes](/es-419/codex/image-generation), crea
[visualizaciones](/es-419/codex/visualizations) interactivas y desarrolla o comparte sitios web y apps
  con [Sites](/es-419/codex/sites).
- **Trabaja en sitios web y apps.** Usa el [navegador](/es-419/codex/browser) para
  investigar e interactuar con sitios web. En la app de escritorio, usa la
[extensión del navegador](/es-419/codex/chrome-extension),
[Uso de la computadora](/es-419/codex/computer-use) y las [capturas de la aplicación](/es-419/codex/appshots) cuando
  esas funciones estén disponibles.
- **Ejecuta código y revisa el trabajo técnico.** Ejecuta código y comandos de shell, analiza
  datos, inspecciona archivos, [revisa código](/es-419/codex/code-review) y trabaja con
  repositorios a los que tenga acceso el entorno que seleccionaste.
- **Delega y continúa con tareas de mayor duración.** Distribuye el trabajo independiente entre
[subagentes](/es-419/codex/agent-configuration/subagents), sigue su progreso y
  mantén activo el [trabajo de larga duración](/es-419/codex/long-running-work).
- **Repite flujos de trabajo útiles.** Configura [tareas
  programadas](/es-419/codex/automations) para el trabajo recurrente y usa
[habilidades](/es-419/codex/skills-and-plugins) para reutilizar un flujo de trabajo.
- **Aborda una tarea por voz.** Si tienes un plan compatible, usa
[ChatGPT Voz](/es-419/codex/features/voice) en la app de escritorio para iniciar el trabajo, consultar el progreso o
  cambiar de rumbo.

  Las funciones dependen de tu plan, plataforma, región, fase de despliegue y configuración del espacio de
  trabajo. El administrador de tu espacio de trabajo puede controlar el acceso a ChatGPT Work y a los
  complementos, así como el uso del navegador y el acceso a la red. ChatGPT Work y Codex comparten [límites
  de uso](/es-419/codex/pricing).

### Elige si quieres trabajar en la nube o de forma local

En la web, ChatGPT Work se ejecuta en un entorno administrado en la nube. En la app de
escritorio, es posible que también puedas elegir dónde se ejecuta una tarea:

- **Nube:** ejecuta el trabajo en un entorno alojado y aislado. Una tarea puede seguir ejecutándose
  después de que cierres la app de escritorio y puedes continuarla desde la web o la app móvil. El trabajo en la nube
  puede usar archivos subidos, herramientas conectadas y sitios web aprobados.
- **Trabaja de forma local:** usa archivos, apps o el navegador de tu computadora. El trabajo
  local está disponible en la app de escritorio cuando está habilitado para tu cuenta o
  espacio de trabajo.

ChatGPT muestra su progreso y hace una pausa cuando necesita información o aprobación.
Revisa las acciones que puedan tener consecuencias importantes antes de aprobarlas y verifica el resultado final
antes de usarlo o compartirlo.

### Compara ChatGPT Work y Codex en la app de escritorio

ChatGPT Work y Codex tienen capacidades en común. Si
prefieres Codex, puedes seguir usándolo para investigar, trabajar con documentos y presentaciones y
realizar otras tareas de trabajo del conocimiento. Cuando ambos están disponibles para ti, la app de escritorio cambia
la interfaz y la forma en que el agente presenta su trabajo.

| Diferencia          | ChatGPT en la App de escritorio                                                 | Codex en la App de escritorio                                              |
| ------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Por dónde empezar      | Selecciona **ChatGPT** y luego cambia a **Work**                            | Selecciona **Codex** en el selector de productos                          |
| Chats que ves       | Consulta los chats iniciados con Chat en la web y en dispositivos móviles, además de los chats de ChatGPT Work | Concéntrate en los chats de Codex y en los proyectos de desarrollo                     |
| Chat rápido          | No disponible                                                          | Cuando la función esté disponible, accede en Codex a los chats de ChatGPT de la web y de dispositivos móviles |
| Detalles técnicos    | Oculta detalles técnicos, como Git o los comandos de shell                      | Consulta detalles para desarrolladores, incluidas las vistas de diferencias y de revisión            |
| Comunicación del agente | Prefiere un lenguaje no técnico y resultados listos para usar                     | Puede incluir detalles técnicos y de implementación                  |
| Panel de Pull requests  | No disponible al usar ChatGPT Work                                  | Disponible cuando está habilitado                                            |

### Habla con ChatGPT de forma natural

Escribe como si le explicaras la solicitud a un colega dispuesto a ayudarte. Indica qué
quieres lograr, agrega los detalles que cambian la respuesta y describe el
formato que necesitas. Tu primer prompt es solo un punto de partida: puedes agregar contexto
o perfeccionar el resultado con mensajes de seguimiento.

Puedes continuar con instrucciones sencillas como estas:

- “Hazlo más breve”.
- “Dame tres enfoques diferentes”.
- “¿Qué suposiciones estás haciendo?”
- “Hazme preguntas antes de continuar”.

Obtén más información sobre el [diseño de prompts](/es-419/codex/prompting) o toma el
[curso Fundamentos de IA](https://academy.openai.com/home/courses/ai-foundations-juzjs)
para practicar de forma guiada.

## Proporciona a ChatGPT el contexto adecuado

Proporciona a ChatGPT la información, las herramientas y las instrucciones relevantes para la tarea.
No necesitas proporcionarlo todo: incluye el contexto que determine cómo debe ser un
buen resultado.

### Agrupa el trabajo relacionado en un proyecto

Los proyectos te ayudan a organizar tu trabajo en ChatGPT en torno a un tema, un objetivo o una línea de
trabajo en curso. Mantén los chats, archivos e instrucciones relacionados en un mismo proyecto
cuando el trabajo se prolongue en el tiempo o dependa del mismo contexto. [Obtén más información
sobre los proyectos.](/es-419/codex/projects)

### Adjunta archivos

Puedes subir o adjuntar documentos, presentaciones, hojas de cálculo, archivos PDF, imágenes
y exportaciones de datos. Úsalos cuando quieras que ChatGPT:

- Los resuma o compare.
- Encuentre patrones o inconsistencias.
- Extraiga, limpie o reorganice información.
- Los use como material de referencia para un archivo nuevo.

Cuando ChatGPT cree un archivo, abre la vista previa y revisa su contenido. Luego puedes
pedir cambios sin empezar de cero. Obtén más información sobre
[cómo trabajar con archivos](/es-419/codex/artifacts-viewer).

### Conecta herramientas mediante complementos

Los complementos pueden conectar ChatGPT con las herramientas y la información que usas para trabajar, como
Google Drive, SharePoint, Salesforce o Gong. Úsalos cuando una tarea dependa
de información externa al chat, de acciones en otro sistema o de un
flujo de trabajo repetible.

  

La disponibilidad de un complemento depende de tu plan, de la configuración del espacio de trabajo y del
propio complemento. Obtén más información sobre [habilidades y complementos](/es-419/codex/skills-and-plugins).

## Comparte una instantánea de solo lectura de un hilo de Codex

En todos los planes de Codex, puedes crear una instantánea de solo lectura de un hilo local de Codex
en la aplicación de escritorio de ChatGPT para macOS. La instantánea no permite que otras personas
accedan a tu proyecto o computadora.

Antes de compartir la instantánea, verifica quién puede abrir el enlace:

- **Cuenta personal:** cualquier persona que tenga el enlace puede abrir la instantánea.
- **Cuenta de un espacio de trabajo:** solo pueden abrirla los miembros autenticados del espacio de trabajo donde
  se creó la instantánea. Puedes permitir el acceso a todos los miembros de ese espacio de trabajo
  o restringirlo a las personas y los grupos invitados. Un administrador del espacio de trabajo
  puede desactivar los enlaces compartidos de ese espacio.

1. Abre el hilo y selecciona **Compartir**. También puedes usar `/share` cuando los comandos
   slash estén disponibles.
2. Para una cuenta de un espacio de trabajo, usa **Quién tiene acceso** para elegir a todos los miembros de tu
   espacio de trabajo o **Solo personas y grupos invitados**. Para limitar el acceso a invitados,
   agrega por correo electrónico a miembros existentes del espacio de trabajo o elige grupos de ese espacio.
3. Espera a que termine de cargarse la instantánea y luego selecciona **Copiar enlace**.
   Al abrir el cuadro de diálogo, se inicia la carga, pero Codex publica la instantánea solo
   cuando seleccionas **Copiar enlace**, con la audiencia y los destinatarios que elegiste.
4. Abre el enlace copiado y revisa la vista compartida antes de enviarlo a alguien.

Una instantánea captura el contenido compatible del hilo que está disponible al momento de compartirla.
Los mensajes y cambios posteriores no actualizan la instantánea existente.

Las instantáneas compartidas pueden incluir mensajes visibles para el usuario, resúmenes de razonamiento, imágenes
adjuntas, imágenes vistas o generadas por el agente y cambios en archivos,
incluidas rutas y diffs. No incluyen las llamadas a herramientas del hilo original,
los comandos de shell ni los datos de entrada o salida de las herramientas.

Codex oculta los secretos que coinciden con patrones conocidos antes de cargar una instantánea. Revisa la
vista compartida antes de enviar el enlace, ya que puede quedar contenido sensible, incluidas rutas de
archivos, en mensajes, imágenes o diffs.

No puedes hacer un fork del hilo original a partir de una instantánea compartida. Puedes importar la
instantánea como archivo adjunto y hacer referencia a ella en un hilo nuevo.

Para ver o revocar un enlace compartido, abre los [controles de
datos de ChatGPT](https://chatgpt.com/#settings/DataControls) y selecciona **Enlaces compartidos**.

## Deja el resultado listo para usar

Trata el primer resultado como un borrador que puedes revisar, cuestionar y mejorar. Una
respuesta bien elaborada todavía puede estar incompleta o ser incorrecta, así que revisa los detalles
importantes antes de usarla o compartirla.

**Revisa el trabajo:**

- Verifica los números, nombres, fechas, citas y afirmaciones importantes.
- Abre los archivos generados y revisa cada sección, pestaña, diapositiva o página.
- Confirma que ChatGPT haya usado el material de origen correcto y más actualizado.
- Identifica la información faltante y las suposiciones sin fundamento.
- Pide cambios específicos cuando el resultado no cumpla con el objetivo.

Luego, pídele a ChatGPT que ponga a prueba el resultado:

- “¿Qué fuentes usaste para esto?”
- “Cita la fuente de cada afirmación importante”.
- “¿Qué suposiciones hiciste?”
- “¿A qué información no pudiste acceder?”
- “¿Qué te haría cambiar tu recomendación?”
- “Contrasta este resultado con los archivos originales”.

Si ChatGPT no pudo acceder a una fuente o completar parte de la tarea, pídele que lo diga
con claridad. Es más fácil abordar una carencia reconocida que una conjetura presentada con seguridad.

  Las decisiones legales, financieras, médicas, de seguridad y otras decisiones de alto impacto requieren
una revisión adecuada por parte de especialistas. Usa ChatGPT para respaldar un criterio informado, no para
reemplazarlo.
