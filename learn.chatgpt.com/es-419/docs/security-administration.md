# Seguridad

Administra los permisos y los controles de seguridad y protección de las herramientas para desarrolladores de ChatGPT y Codex

Controla a qué pueden acceder las herramientas para desarrolladores de ChatGPT y Codex, comprende cómo se aísla el trabajo y aplica medidas de protección para las tareas sensibles en materia de seguridad.

Los controles de seguridad definen a qué pueden acceder las herramientas para desarrolladores de ChatGPT y Codex y cómo se revisan las acciones sensibles. Los permisos, el entorno aislado, las aprobaciones y el acceso a la red establecen límites de confianza. Codex Security ayuda a detectar y corregir vulnerabilidades, y la guía de seguridad cibernética explica cómo se gestionan los trabajos sensibles en materia de seguridad.
