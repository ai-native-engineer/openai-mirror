## Comece pelo conteúdo didático aprovado

Use o pacote didático revisado, as questões para praticar, as regras de feedback, os requisitos de acessibilidade e as preferências de design. Identifique o objetivo de aprendizagem e as evidências de que um estudante concluiu a atividade prática prevista.

Não invente diretrizes pedagógicas nem dados de estudantes que não tenham sido fornecidos.

## Crie o fluxo de aprendizagem

Uma primeira versão com foco no essencial deve incluir:

- uma introdução clara
- um exemplo orientado
- um pequeno conjunto de exercícios interativos
- feedback que siga as regras fornecidas
- uma autoavaliação final
- observações para o professor

Use Sites para criar o recurso e conferir uma prévia dele. Mantenha o modelo de interação simples o bastante para testá-lo por completo.

## Teste antes de compartilhar

Verifique os fluxos principais, a navegação por teclado, os rótulos, o contraste, o comportamento responsivo, a lógica de feedback e a precisão do conteúdo. Teste tanto as respostas incorretas quanto as corretas.

Peça ao ChatGPT que documente as limitações e as questões pedagógicas ou de acessibilidade ainda não resolvidas. Um educador deve aprovar o recurso revisado antes que ele seja publicado ou compartilhado com os estudantes.
