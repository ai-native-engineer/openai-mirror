## Introdução

Ao criar uma projeção de fluxo de caixa, é importante garantir que ela seja precisa e reflita a realidade da sua empresa. Você pode usar o ChatGPT para criar uma pasta de trabalho de projeção que possa inspecionar e revisar no próprio ChatGPT. Anexe os dados de fluxo de caixa, as premissas operacionais e as restrições do modelo. Você também pode usar referências a arquivos quando os dados estiverem no Google Drive ou em outra fonte conectada.

## Crie a projeção

1. Anexe os dados de fluxo de caixa, as premissas operacionais e as restrições do modelo.
2. Execute o prompt inicial e peça uma pasta de trabalho editável no formato `.xlsx`.
3. Abra a pasta de trabalho no ChatGPT. Expanda-a para tela cheia a fim de inspecionar as premissas, fórmulas, cenários e a aba de resumo.
4. Continue no mesmo chat para alterar as premissas de recebimentos, folha de pagamento, pagamentos a fornecedores, crescimento ou saldo de segurança.

Quando a pasta de trabalho aparecer no chat, abra-a e expanda-a para tela cheia. Analise as premissas de prazo, fórmulas, cenários e a aba de resumo. Depois, peça ao ChatGPT que atualize a mesma pasta de trabalho ali mesmo.

## Analise a pressão sobre o caixa

Antes de usar a projeção, peça ao ChatGPT que identifique o ponto mínimo de liquidez, concilie a pasta de trabalho com os dados de origem e liste as premissas que precisam ser revisadas.

## Simule um cenário

Depois de analisar a pasta de trabalho no ChatGPT, use prompts de acompanhamento para alterar uma variável do cenário por vez.
