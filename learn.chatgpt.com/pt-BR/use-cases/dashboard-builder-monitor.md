## Projete pensando nas decisões, não nos gráficos

Antes de especificar um painel, defina as decisões que ele deve ajudar a tomar e os responsáveis por agir com base nos sinais. Forneça ao ChatGPT definições de métricas, exportações de dados de origem, exemplos existentes, contexto do fluxo de trabalho e feedback das partes interessadas para manter a especificação fundamentada em dados reais.

1. Informe o fluxo de trabalho, o público, as decisões e a frequência de revisão.
2. Anexe o glossário de métricas, as exportações de dados de origem, os exemplos de painéis e o feedback das partes interessadas.
3. Peça ao ChatGPT que identifique lacunas nas fontes de dados, verificações de qualidade e necessidades de definição de responsáveis.
4. Use o prompt inicial para elaborar a hierarquia de KPIs, as especificações dos gráficos, os filtros e o monitoramento.
5. Revise os riscos de publicação e teste as métricas propostas com base nos dados de origem.

Trate a especificação do painel como um contrato entre analistas, responsáveis pelos dados e usuários. Defina o que cada gráfico significa, quando é possível confiar nele e qual ação ele deve desencadear.

## Faça o monitoramento orientar ações

Depois que a especificação for revisada, peça ao ChatGPT que transforme as verificações que trazem mais valor em uma lista de verificação de monitoramento com critérios claros para escalonamento.
