## Torne as opções comparáveis

A análise de cenários é mais fácil de revisar quando todas as opções partem das mesmas premissas e usam os mesmos critérios de decisão. Antes de criar a comparação, forneça ao ChatGPT o modelo, o contexto dos KPIs, os documentos de planejamento, os dados operacionais e as restrições das partes interessadas.

1. Especifique a decisão, as opções, o horizonte temporal e os critérios.
2. Anexe modelos, painéis, documentos de planejamento, contexto de mercado e dados operacionais.
3. Peça ao ChatGPT para identificar premissas compartilhadas, específicas de cada opção ou ausentes.
4. Execute o prompt inicial e revise os custos, os prazos, os riscos, os responsáveis e o impacto sobre os clientes.
5. Altere as premissas de forma explícita e compare a recomendação entre os cenários.

Mantenha o modelo original intacto e salve os resultados dos cenários separadamente. O resultado mais útil não é apenas uma recomendação, mas também uma explicação clara de quais premissas poderiam mudá-la.

## Teste a sensibilidade

Peça ao ChatGPT que varie as premissas mais relevantes e mostre em que condições a opção preferida muda.
