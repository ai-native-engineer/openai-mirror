## Defina o escopo de uma primeira versão útil

Comece pelo público, pela principal tarefa que o site deve permitir realizar e pelos materiais que você já tem. Inclua exemplos, preferências de design, requisitos de acessibilidade e critérios claros de sucesso.

Mantenha o escopo inicial pequeno o suficiente para criar e testar o site de uma só vez.

## Crie e inspecione o site

Use o prompt inicial no Sites para:

- organizar o conteúdo fornecido
- definir uma estrutura simples para as informações
- criar as páginas e interações principais
- usar layouts responsivos
- verificar o acesso pelo teclado, os rótulos e o contraste
- testar o fluxo principal com conteúdo representativo

Revise a prévia local antes de publicar. Verifique se os textos, as imagens, os links, os formulários e os dados vêm de fontes aprovadas.

## Prepare-se para compartilhar

Peça ao ChatGPT uma lista de verificação para publicação que aborde o conteúdo pendente, as permissões, a privacidade, a acessibilidade e os testes finais. Se o site coletar informações enviadas pelos usuários, confirme para onde vão os dados e quem pode acessá-los.

Publique somente depois que o responsável pelo projeto ou o professor que o acompanha aprovar a versão revisada.
