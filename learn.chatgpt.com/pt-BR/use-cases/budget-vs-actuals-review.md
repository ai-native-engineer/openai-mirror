## Introdução

Se você estiver trabalhando com um orçamento e quiser revisar as variações ou investigar problemas, o ChatGPT poderá ajudar a criar uma pasta de trabalho de revisão totalmente funcional que você poderá usar.

Anexe o plano orçamentário, a exportação dos valores realizados e as notas de fechamento. Depois, peça ao ChatGPT uma pasta de trabalho de revisão editável. O ChatGPT pode preservar os dados brutos, mapear os valores realizados para o planejado, calcular as variações e criar uma visualização de resumo que você pode examinar no chat.

## Criar a pasta de trabalho de revisão

1. Anexe o plano orçamentário, a exportação dos valores realizados e as notas de fechamento ou forneça as referências exatas dos arquivos junto com a fonte.
2. Execute o prompt inicial e peça uma pasta de trabalho editável no formato `.xlsx`.
3. Abra a pasta de trabalho no ChatGPT. Coloque-a em tela cheia para examinar os dados brutos, os mapeamentos, as fórmulas de variação e a aba de resumo.
4. Continue no mesmo chat para corrigir os mapeamentos de categorias, adicionar detalhamentos por departamento ou redigir o resumo financeiro.

Se os arquivos de origem estiverem em um plug-in conectado, mencione os arquivos exatos ou a pasta exata. Evite pedir ao ChatGPT que pesquise de forma ampla no Drive ou no workspace quando a revisão precisar usar fontes financeiras específicas. Quando a pasta de trabalho aparecer no chat, abra-a e coloque-a em tela cheia para revisar os dados brutos, os mapeamentos, as fórmulas de variação e a aba de resumo antes de pedir alterações.

## Verificar as variações

Antes de compartilhar a pasta de trabalho, peça que o ChatGPT audite as categorias, as fórmulas e as explicações das variações.
