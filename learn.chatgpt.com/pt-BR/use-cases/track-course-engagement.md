## Defina o painel antes de combinar os dados

Forneça somente exportações aprovadas e desidentificadas. Inclua as definições das métricas, o período de análise, o calendário do curso e os identificadores necessários para alinhar os arquivos.

Antes de criar os gráficos, peça ao ChatGPT que mostre como os dados do LMS, de frequência, do diário de notas e das atividades serão relacionados. Primeiro, resolva registros duplicados, identificadores ausentes e definições conflitantes.

## Crie uma visualização para revisão

Use o prompt inicial para criar um painel com:

- tendências ao longo do tempo
- padrões de conclusão de atividades e de avaliação
- filtros que correspondam à estrutura do curso
- avisos sobre dados ausentes e sobre a qualidade dos dados
- uma fila de perguntas para revisão pelo corpo docente

Mantenha os padrões observados separados das explicações. Uma mudança na atividade é um sinal a ser investigado, não um diagnóstico.

## Valide e use com responsabilidade

Compare os cálculos com os totais dos dados de origem e verifique por amostragem registros individuais desidentificados. Confirme se os intervalos de datas, os filtros de turma e os agrupamentos de avaliações estão corretos.

Use o painel para orientar as perguntas do corpo docente. Não o use para automatizar a atribuição de notas, o contato com estudantes, a alocação ou classificações de alto impacto.
