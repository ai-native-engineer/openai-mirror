## Introdução

O ChatGPT é ótimo para limpar dados tabulares de forma sistemática.
Quando um CSV ou uma planilha contém datas em formatos diferentes, linhas duplicadas, strings de moeda, células em branco, aliases ou linhas de resumo coladas, peça ao ChatGPT que limpe uma cópia sem alterar o arquivo original.

## Como usar

1. Arraste o arquivo para o ChatGPT ou mencione-o no seu prompt, por exemplo, `@customer-export.csv`.
2. Descreva os problemas que você já identificou.
3. Diga ao ChatGPT qual deve ser o formato da versão limpa: CSV, aba de planilha ou arquivo pronto para upload.
4. Revise a cópia limpa antes de usá-la.

Use o prompt inicial desta página na primeira rodada de limpeza. Substitua o nome do arquivo e os itens da lista pelos seus. As informações relevantes são os problemas que você já identificou e o arquivo de que precisará em seguida: um CSV limpo, uma aba de planilha limpa ou um arquivo pronto para upload. Depois que o ChatGPT gerar a cópia limpa, abra o arquivo limpo e a observação sobre a qualidade dos dados no Chat antes de usar esses dados em etapas posteriores.
