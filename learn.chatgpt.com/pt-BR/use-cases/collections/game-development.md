# Desenvolvimento de jogos

O Codex, combinado com a geração de imagens, é especialmente poderoso para criar jogos para navegador e de outros tipos.
Esses casos de uso ajudarão você a transformar ideias em jogos prontos para jogar.

## Crie o primeiro ciclo jogável

Peça ao Codex para transformar um briefing de jogo em uma versão para navegador com recursos, controles e um ciclo que você possa testar.

## Ajuste a interface e os controles

Use o Codex para ajustar detalhes do HUD, menus, controles e pequenos problemas de interação quando o jogo já estiver funcionando.

## Lide com a lógica complexa do jogo

Use o Codex para aprimorar algoritmos de jogo complexos por meio de um ciclo de autoavaliação.

## Faça a triagem de bugs com base em sinais reais

Use o Codex para reunir relatórios de bugs, verificações com falha, logs e passos para reprodução em uma lista priorizada antes que ele aplique correções ao jogo.

## Revisão antes da mesclagem

Use o Codex no GitHub para revisar PRs automaticamente, detectar regressões e identificar testes ausentes, acelerando a implantação.
