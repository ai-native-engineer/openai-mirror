# Produtividade e colaboração

Use o ChatGPT Work ou o Codex para coordenar o trabalho envolvendo plug-ins, arquivos e equipes.
O ChatGPT pode reunir contexto de arquivos, mensagens, documentos e planilhas e transformá-lo em artefatos que possam ser compartilhados.
Para projetos de dados que dependem de um repositório, de scripts reproduzíveis ou de árvores de trabalho, use o Codex.

## Aprender um novo conceito

Peça ao ChatGPT para transformar um material complexo, como um artigo, uma especificação ou um guia técnico, em definições, exemplos e perguntas para revisão.

## Delegar fluxos de trabalho com várias etapas

Peça ao ChatGPT para reunir informações aprovadas de vários plug-ins a fim de preparar um fluxo de trabalho ou deixe que ele use seu computador para concluir tarefas em diferentes aplicativos para desktop.

## Manter o trabalho em andamento

Peça ao ChatGPT para verificar as fontes que você aprovar e apresentar somente os itens que exigem atenção: solicitações reais, artefatos alterados, repasses de trabalho bloqueados, rascunhos de respostas e decisões.

## Trabalhar com dados

Use o ChatGPT para explorar conjuntos de dados, limpar planilhas, testar hipóteses, responder a perguntas e criar visualizações.

## Criar uma análise reproduzível

Use o Codex para limpar e combinar conjuntos de dados em um repositório, explorar hipóteses com código e organizar os resultados em artefatos que possam ser revisados e executados novamente.

## Organizar a análise em artefatos para revisão

Peça ao ChatGPT para transformar informações aprovadas em resultados que você possa compartilhar: slides, mensagens e outros artefatos prontos para revisão.
