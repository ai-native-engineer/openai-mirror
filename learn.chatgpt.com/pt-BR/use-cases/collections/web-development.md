# Desenvolvimento Web

O Codex funciona muito bem com sistemas de design existentes, levando em conta restrições e referências visuais para criar interfaces responsivas.
Esses casos de uso são úteis quando você desenvolve aplicativos Web e precisa iterar nos designs de frontend.

## Passe da ideia ao protótipo

Use o Codex para transformar uma ideia preliminar em uma direção visual e implementar um primeiro protótipo.

## Desenvolva com base no Figma

Use o Codex para obter do Figma o contexto de design e transformá-lo em código que siga os componentes, os estilos e o sistema de design do repositório.

## Itere na interface

Peça ao Codex que faça alterações pontuais com base em referências visuais ou prompts e verifique o próprio trabalho no navegador.

## Assuma tarefas com escopo delimitado no Slack

Marque o Codex no Slack quando houver uma solicitação de recurso ou um issue reportado, para que ele assuma a tarefa e trabalhe nela em segundo plano.

## Implante uma versão de prévia

Use o Codex para criar ou atualizar um aplicativo Web, implantá-lo na Vercel e receber uma URL ativa para compartilhar.

## Entregue alterações mais rapidamente

Use o Codex no GitHub para garantir que as alterações possam ser mescladas com segurança e acelerar seu ciclo de desenvolvimento.
