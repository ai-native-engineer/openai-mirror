# Sistemas de produção

Os casos de uso desta coleção são úteis quando o Codex trabalha em um repositório que já tem histórico, testes, responsáveis e restrições de produção.
O Codex é especialmente bom em navegar por bases de código complexas, incluindo monorepositórios extensos, com muitos serviços e dependências diferentes.
Se você trabalha em um sistema de produção, familiarize-se com estes casos de uso para entender como o Codex pode ajudar.

## Comece com um tour pela base de código

Use o Codex para se familiarizar com uma base de código complexa, o que é especialmente útil ao começar a trabalhar em um repositório de software usado em produção.

## Modernize a base de código

Use o Codex para planejar migrações da stack de tecnologia, atualizar sua integração para os modelos mais recentes, se aplicável, e refatorar a base de código para melhorar a legibilidade e a facilidade de manutenção.

## Formalize tarefas recorrentes

Peça ao Codex para transformar fluxos de trabalho ou checklists específicos do repositório em uma habilidade, para que todos que contribuem para o repositório possam se beneficiar de um processo padronizado.

## Mantenha a documentação atualizada

Peça ao Codex para comparar as alterações no código-fonte com a documentação existente, atualizar apenas o mínimo necessário da documentação e verificar o resultado.

## Mantenha o sistema saudável

Use o Codex no Slack e conecte-o aos seus sistemas de alertas e rastreamento de issues, bem como às verificações diárias em busca de bugs, para que ele comece a trabalhar automaticamente em solicitações de funcionalidades e correções de bugs.

## Evite gargalos na revisão

Use o Codex para revisar PRs automaticamente e executar rodadas de QA direcionadas aos fluxos críticos, a fim de detectar issues rapidamente e lançar atualizações com confiança.
