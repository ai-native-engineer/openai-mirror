# Ciências da vida

O GPT-Rosalind, nosso modelo de raciocínio de fronteira, foi desenvolvido para apoiar pesquisas em
biologia, descoberta de medicamentos e medicina translacional. Esta série de modelos para ciências da vida
é otimizada para fluxos de trabalho científicos, combinando o uso aprimorado de ferramentas com
uma compreensão mais profunda de química, engenharia de proteínas e genômica. Atualmente,
o GPT-Rosalind está disponível como uma
[prévia de pesquisa](https://openai.com/form/life-sciences-access/) no ChatGPT,
no Codex e na API para usuários qualificados por meio do nosso programa de acesso confiável.

Use o ChatGPT Work ou o Codex em pesquisas e análises científicas. O ChatGPT pode
usar o GPT-Rosalind e plug-ins científicos em fluxos de trabalho de pesquisa compartilhados; use
o Codex quando o trabalho exigir código, um repositório, benchmarks ou experimentos iterativos
de software.

## Pesquisa e análise em ciências da vida

Use o ChatGPT para transformar dados de sequenciamento em insights biológicos acionáveis,
desde análises de bulk RNA-seq e RNA-seq de célula única até a priorização de alvos
com base em várias fontes.

## Pesquisa sobre dobramento de proteínas e busca de arquiteturas

Use o Codex para transformar hipóteses sobre dobramento de proteínas em ciclos experimentais passíveis de revisão
com benchmarks explícitos, artefatos persistentes e limites claros para o que as evidências demonstram.
