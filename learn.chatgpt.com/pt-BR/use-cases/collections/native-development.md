# Desenvolvimento nativo

O Codex funciona muito bem em projetos para plataformas da Apple quando cada iteração inclui um ciclo de compilação, execução ou simulação.
Esses casos de uso são úteis para desenvolver aplicativos novos ou existentes para iOS e macOS quando é preciso iterar na interface e depurar problemas.

## Crie o shell do aplicativo

Peça ao Codex para criar a estrutura inicial de aplicativos para iOS e macOS com ciclos de compilação reproduzíveis. O caso de uso de shell para Mac explora com mais detalhes layouts com barra lateral, área de detalhes e inspetor, comandos, configurações e outras estruturas típicas de aplicativos nativos para desktop.

## Refatore telas SwiftUI do iOS

Use o Codex para dividir views extensas do SwiftUI sem alterar o comportamento e, quando o aplicativo estiver pronto, migrar determinados fluxos do iOS para o Liquid Glass.

## Exponha ações do iOS ao sistema

Use o Codex para identificar as ações e entidades que seu aplicativo deve expor por meio do App Intents, para que os usuários possam acessar funcionalidades do aplicativo pelas interfaces do sistema.

## Depure seu aplicativo

Peça ao Codex para reproduzir bugs no Simulator ou adicionar telemetria ao seu aplicativo para macOS a fim de ajudar você a depurar e corrigir problemas.
