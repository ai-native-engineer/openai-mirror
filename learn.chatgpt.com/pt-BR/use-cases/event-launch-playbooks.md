## Introdução

Quando você gerencia programas de eventos, como nossos [encontros da comunidade do ChatGPT](/community/meetups), o contexto costuma ficar disperso entre várias fontes:

- A página pública do evento
- O plano de suporte ao programa
- Mensagens do Slack
- Planilhas ou documentos
- etc.

Você pode usar o ChatGPT para reunir as fontes de planejamento aprovadas e transformá-las em um plano operacional que separe o texto destinado aos participantes dos detalhes operacionais internos.

## Crie seu primeiro plano operacional

Use o prompt inicial para pedir ao ChatGPT que gere um plano operacional de evento para você. Esse plano deve:

- Indicar as fontes de planejamento (podem ser links, ferramentas internas etc.)
- Listar as informações necessárias
- Definir regras para o texto destinado aos participantes (sem incluir a logística interna)

O resultado deve trazer uma lista do que verificar e executar sempre que um novo evento for planejado.

## Agende no chat uma tarefa para o plano operacional

Depois que a primeira execução do seu novo plano operacional for bem-sucedida, mantenha o mesmo chat aberto e peça ao ChatGPT que [agende uma tarefa para o plano operacional a partir desse chat](/pt-BR/codex/automations#schedule-a-task-inside-a-chat).
