## Defina uma fonte de referência comum

Comece pela apresentação de slides da aula já revisada e pelo plano de unidade. Acrescente as orientações atuais da escola, os materiais de apoio existentes, os requisitos de acessibilidade e as necessidades linguísticas.

Informe ao ChatGPT quais arquivos definem a terminologia, os exemplos, os tempos previstos e as decisões pedagógicas.

## Crie os materiais complementares

Use o prompt inicial para gerar um conjunto coordenado:

1. Um guia do professor com orientações para a preparação e a condução da aula.
2. Um material para os alunos alinhado à sequência da aula.
3. Um gabarito que corresponda exatamente ao material para os alunos.
4. Uma visão geral concisa para as famílias, escrita em linguagem adequada.
5. Uma lista de verificação de materiais e preparação.

Peça ao ChatGPT que, depois de criar os rascunhos, compare os arquivos e aponte inconsistências no vocabulário, nos exemplos, nas instruções ou nas respostas.

## Revise separadamente os materiais de cada público

Os professores devem avaliar se o conteúdo está correto do ponto de vista pedagógico e se os materiais são fáceis de usar. Verifique se os materiais para os alunos são claros e acessíveis, se os gabaritos correspondem exatamente a esses materiais e se a comunicação com as famílias está de acordo com as políticas e os requisitos de idioma.

Mantenha todos os arquivos editáveis e claramente identificados como rascunhos até que o educador responsável aprove o pacote completo.
