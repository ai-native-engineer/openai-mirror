## Como usar

1. Instale o aplicativo do Slack, conecte os repositórios e ambientes corretos e adicione `@Codex` ao canal.
2. Em uma thread, mencione `@Codex` e descreva claramente a solicitação, as restrições e o resultado desejado.
3. Abra o link do chat, revise o resultado e, se a tarefa precisar de outra rodada, continue o acompanhamento no Slack.

Para saber mais sobre como usar o Codex no Slack, consulte o [guia específico](/pt-BR/codex/third-party/slack).

## Dicas

- Se a thread ainda não incluir contexto suficiente nem uma sugestão de correção, inclua algumas orientações no prompt
- Mencione no prompt o nome do projeto ou do ambiente para garantir que o repositório e o ambiente estejam mapeados corretamente
- Delimite o escopo da solicitação para que o Codex possa concluí-la sem precisar de uma segunda rodada de planejamento
- Se o projeto tiver uma base de código grande, oriente o Codex mencionando quais arquivos ou pastas são relevantes para a tarefa
