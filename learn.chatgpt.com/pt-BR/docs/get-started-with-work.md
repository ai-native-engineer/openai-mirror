## Apresentamos o ChatGPT Work

O ChatGPT Work permite delegar trabalho de verdade ao ChatGPT.

Use o Chat quando quiser uma resposta, uma explicação, ideias ou um rascunho curto.
Use o ChatGPT Work quando quiser que o ChatGPT conclua uma tarefa com um resultado claro, como
um briefing, uma apresentação, uma análise, uma atualização recorrente, um fluxo de trabalho ou um arquivo que você possa revisar e
usar. Saiba mais sobre [como usar o Chat e o ChatGPT Work em conjunto](/pt-BR/codex/use-chatgpt).

O ChatGPT Work pode usar seus arquivos, plug-ins e ferramentas aprovadas para obter informações,
criar arquivos finalizados, executar fluxos de trabalho e concluir tarefas, deixando-as prontas para sua
revisão. Você pode acompanhar o progresso, responder a perguntas, mudar de rumo e
aprovar ações importantes.

No [aplicativo para desktop](/pt-BR/codex/app), o ChatGPT Work também pode usar arquivos locais, aplicativos e o
navegador quando essas ferramentas estiverem disponíveis.

Se você já usou o Codex para trabalhos não relacionados à programação, pode continuar no Codex ou usar
o ChatGPT Work. O ChatGPT Work oferece os mesmos recursos essenciais em
uma experiência criada para o trabalho do dia a dia.

## O que experimentar primeiro

Primeiro, mude para **Work**. Depois, escolha sua primeira tarefa.
Boas tarefas têm um resultado claro, alguns materiais de referência e uma entrega que você possa
revisar.

### Escolha a execução local ou na nuvem

No aplicativo para desktop, abra o controle do editor chamado **Trabalhar localmente**. Se
**Nuvem** aparecer como opção, selecione-a quando quiser que o ChatGPT Work continue
em execução após fechar o aplicativo ou desligar o computador, ou quando quiser
continuar o chat pela Web ou pelo aplicativo móvel. Mantenha **Trabalhar localmente** selecionado quando
a tarefa precisar de arquivos ou aplicativos do seu computador.

A Nuvem também é útil para tarefas agendadas que fazem pesquisas ou verificam sites ao longo
do tempo, pois suas execuções não dependem de o computador permanecer ativo.

Veja três casos de uso comuns para começar:

### Crie uma apresentação

Use o ChatGPT Work para transformar anotações, documentos, pesquisas ou materiais de reuniões em uma
apresentação estruturada.

  
    
  

### Crie uma planilha comparativa

Use o ChatGPT Work para transformar anotações, arquivos ou pesquisas em uma planilha que compare
opções e ajude você a tomar uma decisão.

  
    
  

### Configure uma atualização recorrente

Use tarefas agendadas quando quiser que o ChatGPT Work repita, monitore ou atualize algo
ao longo do tempo.

  
    
  

Saiba mais sobre [tarefas agendadas](/pt-BR/codex/automations?surface=app).

## Práticas recomendadas para usar o ChatGPT Work

Use o ChatGPT Work quando quiser que o ChatGPT conclua uma tarefa, crie um arquivo ou gerencie atividades
ao longo do tempo. É uma boa opção para tarefas que:

- Usam várias fontes, plug-ins, ferramentas ou etapas.
- Levariam um tempo considerável para serem concluídas manualmente.
- Produzem um resultado que você vai revisar, editar ou reutilizar.
- Precisam ser repetidas, monitoradas ou atualizadas ao longo do tempo.

Para obter um resultado melhor, informe ao ChatGPT o resultado desejado, quais fontes ou plug-ins
usar, quais restrições seguir, o que caracteriza um bom resultado e quando parar para
revisão ou aprovação.

**Em vez de:** Faça uma apresentação sobre nossa pesquisa com clientes.

Saiba mais sobre [criação de prompts para o ChatGPT Work](/pt-BR/codex/prompting#prompting-for-work).

## Adicione plug-ins para ampliar o contexto e melhorar os resultados

  
    
  

Os plug-ins conectam o ChatGPT Work às ferramentas que sua equipe usa, como Slack, Google Drive,
SharePoint, e-mail, calendários, sistemas de gestão de relacionamento com clientes e
ferramentas de acompanhamento de projetos.

- Selecione **Plug-ins** na barra lateral esquerda para ver a biblioteca de plug-ins.
- Instale os plug-ins mais relevantes para o seu trabalho.
- Para indicar uma ferramenta específica ao ChatGPT, digite `@` seguido do nome do plug-in no prompt.

Saiba mais sobre [plug-ins](/pt-BR/codex/plugins).

## Use o ChatGPT Work com eficiência

Escolha [GPT-6 Astra](/pt-BR/codex/models#gpt-6-astra) para trabalhos exigentes que precisem de
raciocínio cuidadoso, avaliação visual ou um arquivo final bem-acabado. Para tarefas mais simples,
considere Sol, Terra ou Luna. Escolha entre os modelos
disponíveis no seletor de modelos e confira o [uso do plano](/pt-BR/codex/pricing)
antes de iniciar uma tarefa de grande porte.

O ChatGPT Work é ideal para tarefas de maior porte que envolvem várias etapas, fontes ou
ferramentas, ou que exigem uma entrega finalizada. Tarefas mais longas ou complexas podem usar
mais créditos porque o ChatGPT realiza mais trabalho por você. Concentre-se no valor
do resultado final, em vez do número de prompts.

Mantenha o foco da tarefa definindo limites úteis. Por exemplo: “use apenas
estas fontes”, “compare as cinco principais opções” ou “pare antes de enviar
qualquer coisa”.

Prefira o Chat para perguntas rápidas, reescritas curtas e decisões em que você
só precisa de orientação.

Saiba mais sobre [como trabalhar com eficiência](/pt-BR/codex/prompting#prompting-for-work).

Se uma tarefa for pausada para uma revisão de segurança, siga o aviso e analise os
resultados disponíveis antes de continuar. Consulte [monitoramento de segurança e tarefas pausadas](/pt-BR/codex/agent-approvals-security#safety-monitoring-and-paused-tasks).
