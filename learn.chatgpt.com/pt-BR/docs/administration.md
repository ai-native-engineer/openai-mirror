# Administração

Defina limites de acesso e o escopo das políticas para o ChatGPT, as ferramentas do Codex para desenvolvedores, APIs, plug-ins e sistemas conectados

Defina limites de acesso e o escopo das políticas para o ChatGPT, as ferramentas do Codex para desenvolvedores, APIs, plug-ins e sistemas conectados.

A administração abrange seis áreas de controle relacionadas: acesso ao workspace do ChatGPT; política do ambiente de execução local para os recursos abrangidos no aplicativo do ChatGPT para desktop, no Codex CLI e na extensão para IDE; elegibilidade para o Codex Cloud; acesso à API da plataforma; disponibilidade de plug-ins e permissões de conectores; e permissões em sistemas conectados. Comece pela identidade e pelo acesso ao workspace e depois aplique os controles do ambiente de execução e dos sistemas de origem necessários para cada implantação.
