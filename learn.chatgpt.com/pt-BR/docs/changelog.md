  As tarefas agendadas do ChatGPT agora podem ser executadas quando ocorrem eventos compatíveis no Gmail, no Slack
  ou no GitHub. Filtre mensagens do Gmail por remetente ou assunto, monitore canais selecionados do Slack
  ou responda a atividades em pull requests, como revisões, comentários, atualizações de commits
  e mesclagens.

  As tarefas acionadas por eventos estão disponíveis no ChatGPT na Web e em dispositivos móveis para
  planos elegíveis. Conecte o aplicativo correspondente e aprove o acesso solicitado por ele antes
  de criar uma tarefa.

  aplicativo conectado do GitHub deve ter acesso a cada repositório monitorado.

  que atendem aos critérios são recebidos em um curto intervalo, o ChatGPT pode agrupá-los em uma única execução.
  Abra **Agendadas** para revisar eventos pendentes ou escolha **Executar agora**.

  versão prévia para distribuições de desktop compatíveis de Ubuntu, Debian e Fedora em processadores x64
  e ARM64. Baixe o pacote `.deb` ou `.rpm` para sua
  distribuição e faça login para trabalhar com projetos, arquivos locais e o Codex.

  ### Importe a configuração e o trabalho recente de outros agentes

  O aplicativo para desktop é compatível com **Claude Code**, **Claude Cowork** e
  **Cursor**. [Importe instruções, configurações, habilidades, plug-ins, projetos e
  trabalho recente](/codex/import) e ative as atualizações automáticas em
  **Configurações > Importar** para manter o trabalho importado sincronizado.

  O Codex CLI também pode importar configurações compatíveis e chats recentes do Claude Code
  e do Cursor com `/import`.

  ### Apresentamos o Daybreak Blue e o Daybreak Red

  O Daybreak agora oferece dois níveis de acesso a defensores aprovados: Daybreak Blue e
  Daybreak Red. Use-os para passar de descobertas de segurança a correções validadas em
  atividades com autorização explícita.

  Comece pelo Daybreak Blue na maioria dos trabalhos de segurança defensiva. Ele oferece acesso
  a modelos de uso geral, como o GPT-5.6 Sol, para descoberta de vulnerabilidades,
  revisão segura de código, engenharia de detecção, resposta a incidentes, análise de malware
  e validação de patches.

  O Daybreak Red oferece, mediante aprovação separada, acesso a modelos treinados para fins específicos,
  como o GPT-5.6 Cyber, para reprodução autorizada de vulnerabilidades, validação de exploits,
  testes de invasão, red teaming e análise de sistemas complexos.

  O acesso exige aprovação por meio do
  [Trusted Access for Cyber](/codex/cyber-safety#trusted-access-for-cyber) e
  se aplica apenas à identidade, ao workspace ou à organização da API e
  ao respectivo projeto, ao modelo e à interface do produto indicados na aprovação. O Daybreak Red exige aprovação
  e provisionamento separados; o acesso ao Daybreak Blue não dá acesso ao Daybreak Red.

  Trabalhe em um ambiente isolado, defina o escopo do trabalho, use
  [perfis de permissão](/codex/permissions) com o mínimo de privilégios e configure a
  [Revisão automática](/codex/sandboxing/auto-review) para ações elegíveis antes que elas
  ultrapassem o limite do sandbox.

  Saiba mais sobre [Segurança cibernética](/codex/cyber-safety),
  [taxas de créditos do Codex](/codex/pricing#credits-overview) e
  [preços de tokens da API](/api/docs/pricing).

  ### A Pesquisa na Web agora está ativada por padrão

  O Codex agora habilita a Pesquisa na Web para tarefas locais no Codex CLI e na Extensão para IDE.
  Por padrão, o Codex usa um cache da Pesquisa na Web, que é um índice de resultados da Web mantido pela OpenAI. O modo em cache retorna resultados pré-indexados em vez de buscar páginas em tempo real, enquanto o modo em tempo real busca os dados mais recentes da Web. Se você estiver usando `--yolo` ou outra [configuração de Sandbox com Acesso completo](/codex/agent-approvals-security), a Pesquisa na Web usa resultados em tempo real por padrão. Para desativar esse comportamento ou alternar entre os modos, use a opção de configuração `web_search`:

  + `web_search = "cached"` (padrão; fornece resultados do cache da Pesquisa na Web)
  + `web_search = "live"` (busca os dados mais recentes da Web; equivalente a `--search`)
  + `web_search = "disabled"` para remover a ferramenta

  Para saber mais, consulte a [documentação de configuração](/codex/config-file/config-basic).
