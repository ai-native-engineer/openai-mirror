# ChatGPT na Web

Use o ChatGPT na Web para pesquisar, analisar e criar arquivos.

Pesquise, analise e crie no navegador

Faça uma pergunta, pesquise um tema ou descreva uma tarefa com várias etapas. O ChatGPT pode usar seus arquivos e as ferramentas conectadas para criar documentos, apresentações, planilhas e outros resultados.

Comece com uma tarefa clara

Defina um objetivo para o ChatGPT e forneça o contexto necessário. Depois, refine o resultado com mensagens adicionais.

Escolha entre Chat e Work

Use o Chat para explorar uma questão ou desenvolver uma ideia. Mude para o modo Work quando tiver um resultado claro em mente e quiser que o ChatGPT planeje, reúna contexto e conduza uma tarefa maior até produzir um resultado pronto para revisão.

ChatGPT na Web com Chat e Work

Escolha o modelo e o nível de raciocínio adequados

Selecione um modelo e um nível de raciocínio no campo de mensagem. Comece com o nível de esforço padrão e aumente-o quando a tarefa exigir um planejamento ou uma análise mais aprofundados, ou uma execução multiagente em maior escala.

O campo de mensagem do ChatGPT Work com controles de modelo e raciocínio

Adicione ferramentas e fluxos de trabalho repetíveis

Instale plug-ins para conectar serviços como Google Drive, GitHub ou Slack. Adicione habilidades quando o ChatGPT precisar seguir um fluxo de trabalho específico, usar as orientações da equipe ou produzir materiais de forma consistente.

A barra lateral do ChatGPT com a opção Plug-ins ao lado de chats e projetos

Crie e refine arquivos prontos para uso

Use o ChatGPT Work para criar um documento, uma apresentação, uma planilha ou um PDF a partir do seu material de origem. Revise o resultado no chat, peça revisões pontuais e baixe o arquivo final quando estiver pronto.

Use o ChatGPT na Web quando…

Você precisa concluir uma tarefa com várias etapas

O ChatGPT Work pode planejar a tarefa, reunir contexto e conduzir várias etapas rumo a um resultado claro.

A tarefa exige um raciocínio mais aprofundado

Escolha um modelo mais avançado ou aumente o esforço de raciocínio para planejamentos e análises complexos.

O trabalho depende das suas ferramentas e do seu contexto

Use plug-ins e habilidades para acessar fontes conectadas, realizar ações e seguir fluxos de trabalho repetíveis.

Você precisa de um arquivo que possa revisar e compartilhar

Transforme o material de origem em um documento, uma apresentação, uma planilha ou um PDF e refine-o com base no feedback.

Comece pela tarefa e depois adicione o contexto

Descreva o resultado desejado, escolha o modelo e o nível de raciocínio e, depois, conecte as ferramentas que o ChatGPT deve usar para elaborar o plano inicial.
