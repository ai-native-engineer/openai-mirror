Alguns recursos do ChatGPT e do Codex são lançados com um rótulo de maturidade para que você entenda o nível de confiabilidade de cada um, o que pode mudar e qual nível de suporte esperar.

| Maturidade          | O que significa                                                                                                 | Orientação                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Em desenvolvimento | Ainda não está pronto para uso.                                                                                            | Não use.                                                                    |
| Experimental      | Instável; a OpenAI pode remover ou alterar o recurso.                                                                  | Use por sua conta e risco.                                                         |
| Beta              | Pronto para testes abrangentes; completo na maioria dos aspectos, mas alguns podem mudar com base no feedback dos usuários.       | Adequado para a maioria das avaliações e dos projetos-piloto; espere pequenas mudanças.                      |
| Estável            | Com suporte completo, documentado e pronto para uso amplo; o comportamento e a configuração permanecem consistentes ao longo do tempo. | Seguro para uso em produção; as remoções normalmente passam por um processo de descontinuação. |
| Obsoleto        | Ainda disponível por questões de compatibilidade, mas não é mais recomendado; a OpenAI pode remover o recurso em uma versão futura.       | Evite novos usos e planeje a migração.                                            |
