Crie um fluxo de trabalho com o Codex no terminal

Conheça os recursos da CLI que permitem retomar sessões, adicionar contexto visual e da Web, dividir trabalhos complexos e conectar o Codex às suas ferramentas de desenvolvimento.

Volte a um chat salvo

Reabra um chat recente do repositório atual ou pesquise nos chats locais quando precisar retomar um trabalho antigo.

Adicione contexto visual ao prompt

Inclua uma captura de tela de erro, um diagrama de arquitetura ou uma referência de design no primeiro prompt; ou cole uma imagem no editor interativo.

Divida uma investigação mais ampla

Peça ao Codex que delegue partes específicas do trabalho a agentes especializados e depois incorpore as descobertas deles à sessão principal do terminal.

Busque contexto atualizado

Ative a Pesquisa na Web em tempo real quando uma tarefa depender de versões, documentação ou comportamento externo atuais. A atividade de pesquisa continua visível na transcrição.

Transfira o trabalho para o Codex Cloud

Navegue pelos chats ativos e concluídos, envie o trabalho a um ambiente configurado e aplique o resultado ao repositório local pelo terminal.

Conecte ferramentas externas com o MCP

Adicione servidores MCP locais ou remotos, autentique-se quando necessário e inspecione as ferramentas disponíveis para a sessão atual antes que o Codex as utilize.

Defina os limites de cada execução

Escolha quando o Codex pode editar arquivos ou executar comandos sem pedir aprovação e, antes de continuar, inspecione o Sandbox ativo e as raízes com permissão de gravação.

Adapte o Codex ao seu terminal

Gere scripts de preenchimento automático para o shell, escolha um tema de sintaxe e abra prompts mais longos no editor configurado por VISUAL ou EDITOR.
