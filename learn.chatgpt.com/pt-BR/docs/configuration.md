# Configuração

Configure o ChatGPT e as ferramentas do Codex para desenvolvedores, além de fluxos de trabalho reutilizáveis e ferramentas externas

Defina valores padrão, adicione contexto persistente e personalize o funcionamento do ChatGPT e das ferramentas do Codex para desenvolvedores.

A configuração determina o comportamento do ChatGPT e das ferramentas do Codex para desenvolvedores em chats, repositórios e máquinas. O contexto persistente, os arquivos de configuração, as orientações do repositório, os subagentes, as conexões externas e a configuração no Linux e no Windows funcionam em conjunto para manter esses fluxos de trabalho consistentes para usuários individuais e equipes.
