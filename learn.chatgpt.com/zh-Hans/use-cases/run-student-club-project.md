## 建立项目中心

收集项目简介、当前文件夹、会议记录、预算、成员可参与时间、校方要求和截止日期。明确日期、审批和支出规则的权威信息来源。

在重新整理文件或分配工作之前，让 ChatGPT 盘点当前状态。

## 规划工作

运营中心应将以下内容关联起来：

- 里程碑和截止日期
- 拟定的负责人和依赖关系
- 预算类别和审批
- 决策和未解决的问题
- 风险和应急措施
- 会议议程和后续事项
- 沟通文案草稿

将私密的规划笔记与拟发送给成员、合作伙伴或参与者的消息分开存放。

## 与团队共同审查

在团队会议上确认负责人、日期和预算假设。ChatGPT 可以起草建议，但未经审批，不应指定负责人、发送消息或作出资金支出承诺。

每次会议结束后，添加会议记录，并让 ChatGPT 根据已确认的决策更新项目中心。保留决策日志，以便后续组织者能够理解各项变更。
