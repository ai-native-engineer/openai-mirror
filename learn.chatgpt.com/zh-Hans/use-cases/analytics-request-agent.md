## 将需求转化为分析约定

利益相关者的请求通常会把业务问题、偏好的图表形式和预设的指标定义混在一起。向 ChatGPT 提供原始请求和相关背景信息，然后让它在分析前梳理出业务问题、相关定义、数据源、联接关系以及需要做出的决策。

1. 附上请求讨论串、指标术语表、仪表板、导出文件和相关背景信息。
2. 让 ChatGPT 分别列出已知、存在歧义、缺失或超出范围的内容。
3. 确认指标定义、联接逻辑、时间范围和目标受众。
4. 运行起始提示，以开展初步分析并生成可供利益相关者使用的答复。
5. 让分析师审查计算结果、图表、限制说明和待确认问题。

不要让语气笃定的答复掩盖未定义的指标或未经验证的联接关系。分析计划也是交付成果的一部分，因为它可以加快对下一轮迭代结果的审查。

## 与请求方完成闭环

分析经过审查后，让 ChatGPT 把待确认问题整理成一份简短的确认说明，但不要发送。
