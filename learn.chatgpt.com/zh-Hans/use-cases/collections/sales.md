# 销售

使用 ChatGPT Work 或 Codex 汇集客户档案、客户
对话、销售管道信号和尚未解决的风险。ChatGPT 可将已获批准的
上下文整理成简报、跟进材料、销售预测审查和客户计划，同时
将有来源依据的事实与推断出的商机或风险区分开来。

## 确定销售管道优先级并进行预测

对需要关注的客户进行优先级排序，然后审查哪些商机应继续留在
“提交”类别、转入“乐观预期”类别，或移出预测。

## 做好会议准备和会后跟进

汇集客户会议所需的上下文，然后将已获批准的笔记或
文字记录整理为跟进草稿、内部总结以及可供审查的后续步骤。

## 制定客户计划并扫清商机障碍

根据近期客户信号更新客户策略，或分析商机停滞背后的
阻碍因素和升级处理路径。
