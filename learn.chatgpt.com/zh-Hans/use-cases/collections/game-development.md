# 游戏开发

Codex 结合图像生成，尤其擅长创建浏览器游戏和其他类型的游戏。
这些使用场景将帮助您把创意变成可玩的游戏。

## 构建首个可玩的游戏循环

让 Codex 将游戏需求简述转化为可在浏览器中运行的版本，其中包含素材、操控功能和可测试的游戏循环。

## 优化 UI 和操控

游戏运行后，使用 Codex 调整 HUD 细节、菜单和操控，并处理细微的交互问题。

## 攻克复杂的游戏逻辑

让 Codex 通过运行自我评估循环，迭代改进复杂的游戏算法。

## 根据真实信号划分 bug 优先级

让 Codex 在修补游戏前，把 bug 报告、未通过的检查、日志和复现说明汇总为按优先级排序的列表。

## 合并前进行审查

让 Codex 在 GitHub 中自动审查 PR，发现回归问题和缺失的测试，从而加快部署。
