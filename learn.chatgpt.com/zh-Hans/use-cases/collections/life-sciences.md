# 生命科学

GPT-Rosalind 是我们的前沿推理模型，旨在支持
生物学、药物发现和转化医学领域的研究。此生命科学模型
系列针对科学工作流进行了优化，将更出色的工具使用能力与
对化学、蛋白质工程和基因组学的深入理解相结合。
目前，GPT-Rosalind 正以
[研究预览版](https://openai.com/form/life-sciences-access/)形式在 ChatGPT、
Codex 和 API 中面向通过可信访问计划获得资格的用户开放。

使用 ChatGPT Work 或 Codex 进行科学研究和分析。ChatGPT 可以
将 GPT-Rosalind 和科学插件应用于共享研究工作流；当工作
需要代码、代码仓库、基准测试或迭代式
软件实验时，请使用 Codex。

## 生命科学研究与分析

使用 ChatGPT 将测序数据转化为可指导实践的生物学洞见，
涵盖从 bulk RNA-seq 和单细胞 RNA-seq 分析到多来源靶点
优先级排序。

## 蛋白质折叠研究与架构搜索

使用 Codex 将蛋白质折叠假设转化为可审查的实验循环，
其中包含明确的基准测试、可长期保留的产物以及清晰的证据边界。
