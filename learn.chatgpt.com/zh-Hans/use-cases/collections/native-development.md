# 原生开发

当每轮迭代都有相应的构建、运行或模拟器循环时，Codex 非常适合处理 Apple 平台项目。
这些使用场景可帮助您构建全新或现有的 iOS 和 macOS 应用、迭代优化 UI 并调试问题。

## 构建应用外壳

让 Codex 搭建 iOS 和 macOS 应用的基础框架，并建立可重复的构建循环。Mac 应用外壳使用场景深入介绍了侧边栏—详情—检查器布局、命令、设置以及其他桌面端原生结构。

## 重构 iOS SwiftUI 界面

让 Codex 在不改变行为的前提下拆分大型 SwiftUI 视图，然后在应用准备就绪时，将选定的 iOS 流程迁移到 Liquid Glass。

## 向系统公开 iOS 操作

让 Codex 识别您的应用应通过 App Intents 公开的操作和实体，以便用户从系统界面调用应用功能。

## 调试您的应用

让 Codex 在 Simulator 中复现错误，或为您的 macOS 应用添加遥测，以帮助您调试并修复问题。
