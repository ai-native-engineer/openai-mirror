# 生产力与协作

使用 ChatGPT Work 或 Codex 协调涉及插件、文件和团队的工作。
ChatGPT 可以从文件、消息、文档和电子表格中收集上下文，再将这些内容转化为可共享的成果。
对于依赖代码仓库、可复现脚本或工作树的数据项目，请使用 Codex。

## 学习新概念

让 ChatGPT 将内容艰深的论文、规范或技术指南整理为定义、示例和可供您复习的问题。

## 委派多步骤工作流

让 ChatGPT 从多个插件中收集经批准的输入内容以准备工作流，或让它使用您的计算机，跨多个桌面应用完成任务。

## 让工作持续推进

让 ChatGPT 检查您批准的信息源，仅返回需要关注的事项：实际请求、有变更的成果、受阻的工作交接、回复草稿，以及需要做出的决策。

## 处理数据

使用 ChatGPT 探索数据集、清理电子表格、检验假设、回答问题并创建可视化。

## 构建可复现的分析

使用 Codex 清理并合并代码仓库中的数据集，通过代码探索假设，并将结果打包为可供审查、可重新运行的成果。

## 将分析整理成可供审查的成果

让 ChatGPT 将经批准的输入内容转化为可共享的输出：幻灯片、消息，以及其他可供审查的成果。
