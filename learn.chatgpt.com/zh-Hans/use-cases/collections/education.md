# 教育

使用 ChatGPT Work 或 Codex，将分散存放的课程材料、学术
要求、日程安排、反馈和项目上下文转化为可编辑、
可供审查的成果。ChatGPT 可以保留来源证据，让不确定性
清晰可见，并确保高校教师、中小学教师、学生和学校团队仍需对
学术和教学决策负责。

## 高校教师

更新课程、校准评估、比较不同教学班并审查参与情况，
综合研究证据，并为教师委员会做出决策做好准备。

## 高校学生

规划整个学期、准备考试、协调学生项目、兼顾
时间与开支、构建网站，以及管理求职或实习申请。

## K–12 教师

整理教学文件，规划教学单元，制作课程演示文稿和配套
材料，以一致的方式采纳反馈，并构建交互式教学资源。
