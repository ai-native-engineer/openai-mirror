# 生产系统

当 Codex 处理已有开发历史、测试、负责人和生产环境约束的代码仓库时，此合集中的使用场景会很有帮助。
Codex 尤其擅长探索复杂代码库，包括规模庞大、包含众多不同服务和依赖项的单体代码仓库。
如果您正在开发或维护生产系统，请熟悉这些使用场景，以了解 Codex 能如何为您提供帮助。

## 先从代码库导览开始

使用 Codex 熟悉复杂代码库；当您刚开始接手生产软件的代码仓库时，这一点尤其有用。

## 对代码库进行现代化改造

使用 Codex 规划技术栈迁移，在适用时将您的集成升级为使用最新模型，并重构代码库以提升可读性和可维护性。

## 固化可重复执行的工作

让 Codex 将代码仓库特有的工作流或核对清单转化为一项技能，从而让该代码仓库的所有贡献者都能受益于标准化流程。

## 让文档保持最新

让 Codex 将源代码变更与现有文档进行对比，以最小的有效范围更新文档，并验证这些变更。

## 维护系统健康状态

在 Slack 中使用 Codex，并将其接入您的告警系统、问题跟踪系统和每日缺陷排查流程，让 Codex 自动处理功能请求和缺陷修复任务。

## 避免审查瓶颈

使用 Codex 自动审查 PR，并对关键流程执行有针对性的 QA 检查，从而快速发现问题并放心发布更新。
