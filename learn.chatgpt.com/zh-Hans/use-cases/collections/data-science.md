# 数据科学

使用 ChatGPT Work 或 Codex，将仪表板、指标定义、导出数据、
实验记录和利益相关方提供的上下文信息转化为可供他人审查
并据此采取行动的分析成果。ChatGPT 可让计算过程、来源、限制条件和待解决问题
始终清晰可见，以便分析师在分享前验证相关证据。

## 明确问题范围并展开调查

将模糊需求转化为清晰的分析计划，或从关键细分维度和相关上下文入手，调查
KPI 的异常波动。

## 衡量并解读业务表现

评估实验或上线带来的影响，并将定期汇总的 KPI 和
业务信息转化为有来源支撑的业务表现解读。

## 设计仪表板和监控方案

定义支撑决策的仪表板所需的 KPI 层级、图表规范、质量检查、负责人和
监控计划。
