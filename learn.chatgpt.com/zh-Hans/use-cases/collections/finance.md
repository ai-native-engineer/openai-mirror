# 财务

使用 ChatGPT Work 或 Codex，将获批的工作簿、仪表板、模型和
负责人提供的上下文转化为可供审查的分析和报告材料。ChatGPT 可以
清晰呈现公式、来源、假设和待解决问题，让财务
负责人能在共享任何内容前作出判断。

## 解读业绩

将关账数据转化为面向管理层的业绩解读，将实际结果与计划进行比较，并
对重大变动背后的驱动因素进行排序。

## 审查模型和计划

构建或检查财务模型、更新预测并比较不同情景，
且不隐藏任何假设或源数据缺口。

## 编制管理层报告

基于获批的
进度跟踪表、指标、评述和负责人提供的信息，定期编制面向公司、管理层、CFO 或董事会的材料包。
