## 使用方法

1. 安装 Slack App，连接正确的代码仓库和环境，并将 `@Codex` 添加到频道。
2. 在话题串中提及 `@Codex` 时，请明确说明您的请求、约束条件和期望结果。
3. 打开聊天链接并审查结果；如果任务需要再处理一轮，请继续在 Slack 中跟进。

如需进一步了解如何在 Slack 中使用 Codex，您可以参阅 [专题指南](/zh-Hans/codex/third-party/slack)。

## 提示

- 如果话题串尚未包含足够的上下文或建议的修复方案，请在提示中提供一些指导信息
- 请在提示中提及项目或环境的名称，以确保代码仓库与环境之间的映射正确
- 明确界定请求范围，使 Codex 无需再进行一轮规划即可完成任务
- 如果您的项目代码库规模较大，请提及与任务相关的文件或文件夹，以便引导 Codex
