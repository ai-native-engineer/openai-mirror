## 简介

如果任务需要跨桌面应用、窗口或本地文件执行，请使用 [计算机使用](/zh-Hans/docs/computer-use)。ChatGPT 可以在您允许的应用中执行点击、输入和导航操作，然后返回结果供您审查。如果任务涉及网站或已登录的浏览器会话，请使用 `@Chrome` 单独启动一项浏览器任务。

**计算机使用功能需要 ChatGPT 桌面应用。** 在支持的地区，macOS 和 Windows 上的 ChatGPT Work 与 Codex 均提供计算机使用功能。Web 端或移动端上的云端 Work 任务无法直接访问您的本地应用、文件或已登录的桌面浏览器会话。连接 Mac 或 Windows 主机后，您可以通过 [移动端上的远程功能](/zh-Hans/codex/remote-connections) 启动或操控桌面任务。

合适的用例包括：将笔记转存到权威记录系统；在起草回复前跨多个应用核对上下文；或在没有专用插件的工具之间复制已获批准的信息。

## 使用方法

1. 打开 ChatGPT 桌面应用并安装 [计算机使用插件](/zh-Hans/docs/computer-use)。
2. 如需操作桌面应用，请在请求开头使用 `@Computer`；如需执行浏览器任务，则使用 `@Chrome`。
3. 说明任务、涉及的应用或文件，以及您想要的结果。
4. 仔细查看访问权限提示，并在执行发送、提交或更改重要数据的操作前先暂停确认。
5. 在 Windows 上运行计算机使用功能时，请让目标应用保持可见。

如果某个应用有对应插件，ChatGPT 可能会使用该插件执行结构化操作。如果任务依赖应用界面，或没有可用的插件，计算机使用功能会很有用。

## 实用提示

### 了解任务在不同计算机上的运行方式

在 macOS 上，您使用其他应用时，计算机使用可以在后台运行。画中画预览会显示当前活动的应用；您可以打开预览查看任务进展，也可以将其移开。如果您使用宠物，可以将预览移到宠物处。

在 Windows 上，计算机使用会在当前活动的桌面上运行并接管前台。任务运行期间，您会看到指针移动和键盘输入。请保持设备解锁并联网；如果您需要继续使用主桌面，可以在 Windows 虚拟机中运行桌面应用。

### 选择合适的浏览器

浏览器任务通常是计算机使用的一部分。请选择包含您所需上下文的浏览器：

- **[Chrome 扩展程序](/zh-Hans/codex/chrome-extension)：** 使用 `@Chrome` 执行浏览器任务，包括搜索房源、访问网站，以及使用您现有的已登录 Chrome 配置方案、标签页或扩展程序。
- **[内置浏览器](/zh-Hans/codex/browser?surface=app)：** 当您需要使用独立的浏览器会话访问 localhost 或公共站点时，可以使用此浏览器。它具有独立的浏览器状态，并可等待您完成登录。
- **ChatGPT Work 网页端或移动端的云端浏览器：** 用于访问受支持的公共站点，且仅限未登录状态。它无法访问本地文件、已打开的标签页、扩展程序或已保存的密码，也无法登录站点或完成付款。

需要指定浏览器时，请在提示中写明浏览器名称；对于经常使用的桌面偏好，请使用[自定义](/zh-Hans/docs/customization/overview)功能。

### 避免在同一应用中并行运行任务

不要同时针对同一应用运行两个计算机使用任务。相互冲突的操作可能改变当前窗口或状态，导致结果不可靠。

### 做好应用登录与锁定状态下使用的准备

开始桌面任务前，请登录任务所需的应用和服务。在 macOS 上，如果任务需要在 Mac 锁定后继续运行，您可以启用[锁定状态下使用](/zh-Hans/docs/computer-use#locked-use)。Windows 上的计算机使用不支持锁定状态下使用。
