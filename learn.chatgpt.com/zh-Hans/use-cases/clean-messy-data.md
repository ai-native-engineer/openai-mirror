## 简介

ChatGPT 非常擅长系统化地清理表格数据。
如果 CSV 或电子表格中存在日期格式混杂、重复行、货币字符串、空白单元格、别名或粘贴的汇总行，请让 ChatGPT 清理文件副本，并保持原始文件不变。

## 如何使用

1. 将文件拖入 ChatGPT，或在提示中提及该文件，例如 `@customer-export.csv`。
2. 描述您已经发现的问题。
3. 告诉 ChatGPT 清理后的版本应采用哪种形式：CSV、电子表格标签页或可直接上传的文件。
4. 使用前先审查清理后的副本。

使用本页的入门提示进行第一轮清理。将文件名和列表项替换为您自己的内容。需要提供的关键信息包括您已经发现的问题，以及接下来需要哪种文件：清理后的 CSV、已清理的电子表格标签页或可直接上传的文件。ChatGPT 生成清理后的副本后，请打开清理后的文件和聊天中提供的数据质量说明，再将这些数据用于下游流程。
