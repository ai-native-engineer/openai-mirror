## 重新整理前先清点

从现有的课时或单元文件夹开始。告诉 ChatGPT 哪些文件是正式版本、哪些是工作草稿，以及哪些绝不能移动。

请 ChatGPT 生成一份清单，按可能的用途对文件分组，并标出重复文件、名称不明确的文件和旧版本。

## 审查建议的结构

一种实用的结构可以将以下内容分开存放：

- 源材料和参考资料
- 教案
- 演示文稿
- 学生讲义
- 测评材料和答案
- 无障碍版本或不同语言的版本
- 已归档的草稿

具体应设置哪些文件夹，应取决于教师或团队的实际工作方式。在审批任何更改前，请审查文件夹名称和建议的文件移动操作。

## 核验结果

整理完成后，确认链接仍然有效、当前使用的文件仍然易于查找，并且没有删除任何内容。请 ChatGPT 提供 README 和变更摘要，列出已重命名、移动和归档的文件。

当教学单元发生较大变化时，请重新清点文件，确保文件夹保持易用，避免再积累一批重复文件。
