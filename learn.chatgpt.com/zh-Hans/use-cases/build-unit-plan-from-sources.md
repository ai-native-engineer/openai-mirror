## 依据经批准的资料规划教学单元

收集课程标准、课程指南或教学进度指南、校历、以往教案、评估指导以及相关的学习者需求。确定哪些文档当前有效，哪些仅供示例。

要求 ChatGPT 为每项重要的规划决策标明对应的经批准资料。

## 拟定课程顺序

使用入门提示创建一份包含以下内容的计划：

1. 学习目标和课程标准。
2. 符合可用校历安排的课程顺序。
3. 所需材料和来源链接。
4. 形成性检查以及与评估的衔接。
5. 可能出现的错误观念或先备知识缺口。
6. 需要教师审查的决策及缺失的指导信息。

草稿不应只列出活动，还应说明每节课为何要按这一顺序安排。

## 审查教学方面的判断

检查课程标准对齐情况、教学进度、评估负担、无障碍性和年龄适宜性。确认 ChatGPT 未编造学区要求或学习者信息。

在同一聊天中修订计划，然后明确标记获批版本，再使用该版本生成幻灯片或课堂材料。
