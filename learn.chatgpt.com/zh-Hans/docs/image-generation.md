请 ChatGPT 生成或编辑图像。使用图像生成功能创建 UI 素材，
包括横幅、背景、插图、精灵图集和占位图；这些内容既可以
与代码一并创建，也可以在 ChatGPT 聊天中创建。

从 App 消息输入框请求生成图像。如果您希望
ChatGPT 转换现有素材或将其用作视觉参考，请添加参考图像。

### 审查和编辑生成的图像

选择一张生成的图像，即可打开其大图查看器。您可以在
**聚焦视图** 和 **画布视图** 之间切换；前者用于查看单张图像，后者显示同一聊天中
生成的图像。

在 **画布视图** 中，使用 **评论** 为一张或多张
图像添加精准反馈。选择 **多选** 来选取要纳入的图像，然后
在同一聊天中发送您的评论和其他编辑指令。
说明哪些内容应更改，哪些应保持不变。

在 ChatGPT 网页聊天中请求生成图像。如果您希望 ChatGPT 编辑参考图像或将其用作视觉参考，请在
消息输入框中附加该图像。

在交互式会话中描述所需图像，或加入 `$imagegen` 以明确调用
图像生成技能。如果要让现有图像指导生成结果，请使用 `-i` 或
`--image` 将其作为附件。

在扩展程序聊天中请求生成图像。将参考图像拖入
消息输入框时按住 <kbd>Shift</kbd> 键，以便 Codex 编辑或基于
现有素材继续创作。

## 生成或编辑图像

用自然语言描述图像。如果您希望
ChatGPT 转换或扩展现有素材，请添加参考图像。

在提示中加入 `$imagegen`，以明确调用图像生成
技能。

内置图像生成功能使用 `gpt-image-2`，并计入您的常规
Codex 使用限额。生成图像平均会以
未使用图像生成的类似轮次 3–5 倍的速度消耗套餐内用量，具体取决于图像质量
和尺寸。如需批量生成更多图像，请在环境中设置 `OPENAI_API_KEY`，并让
ChatGPT 通过 API 生成图像，这样将按 API 定价计费。

ChatGPT 网页版中图像生成功能的可用性和使用限额取决于您的订阅方案及
工作空间设置。若要以编程方式生成图像，请使用 [图像生成
API](/api/docs/guides/image-generation)。

## 编写有效的图像提示

实用的图像提示通常只需一至三句清晰的话。请描述
决定生成结果是否成功的细节：

- 说明图像的用途或目标受众。
- 指出主要主体以及正在发生的事情。
- 描述场景、构图和视觉风格。
- 如果取景、尺寸、光照、颜色或材质很重要，请加以说明。
- 说明约束条件，包括图像中绝不能出现的任何内容。

优先使用具体的视觉描述，避免只表达宽泛的感受。例如，应描述
光线来自哪个方向，而不是要求“漂亮的光线效果”。对于任何
必须保持不变的要求，请重复说明。

## 优化结果

先从核心构思开始，然后进行小幅、有针对性的修改。每次只调整一个
元素，以免构图和其他重要细节意外变化。
您也可以选择图像中的特定区域，并说明该
区域要如何更改。

编辑现有图像时，请准确说明应更改的内容以及必须
保持不变的内容。

对于范围更大的修改，请确保反馈直接且可执行：提高图像
亮度、降低色彩饱和度、简化背景，或在保持
构图不变的同时改变风格。

## 使用多张参考图像

当一张图像用于确定内容，而另一张用于确定风格、布局或其他视觉
方向时，请只使用少量参考图像。按顺序标明每张
图像，并说明它们之间的关系。组合元素时，请使用
前景、背景、左侧和右侧等空间方位词。

## 为图像添加文字

图像内的文字应保持简短，并明确指定具体内容。请将确切文字放在
引号中，保留您需要的大小写格式，并说明其字体
风格、字号、颜色和位置。对于不常见的名称，请逐个拼出字母，
尤其是在准确性很重要时。还要说明是否允许出现其他文字。

## 创建信息图和信息密集型布局

图像生成功能可帮助您草拟说明图、海报、带标签的示意图、
时间线及其他信息丰富的视觉内容。请描述信息
层级和布局，保持标签简洁，并要求清晰呈现文字。
对于文案密集或排版对成品至关重要的内容，请逐字检查，并在
必要时使用设计工具完成素材。

## 其他注意事项

- **谨慎使用人物肖像。** 描绘真实人物时，请酌情提供
  参考照片，并确认您已获得使用
  其肖像的许可。
- **要求采用原创表现方式。** 请采用通用或原创设计，
  不要模仿特定品牌、产品、艺术家或艺术作品。
- **可选择是否署名。** 您无需在生成的图像上标注 OpenAI 署名，
  但如果相关背景信息有帮助，可以说明素材的制作方式。
- **遵守适用政策。** 使用图像时，请遵守您所在组织的
  准则和 [OpenAI 使用
  政策](https://openai.com/policies/usage-policies/)。
