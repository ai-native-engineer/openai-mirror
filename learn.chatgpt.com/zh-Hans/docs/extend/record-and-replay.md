“录制与重放”适用于 macOS。计算机使用功能也必须可用并已启用。

通过“录制与重放”，您可以在 Mac 上演示工作流程，并将其转化为可复用的技能。如果工作流程需要重复执行、取决于您的偏好，或者演示起来比通过提示描述更容易，请使用此功能。

例如，您可以录制如何申请费用报销、预订停车位、创建配置正确的议题、发布视频或下载定期报告。ChatGPT 或 Codex 可以将这种操作模式封装为一项技能，供您结合计算机使用、浏览器操作、已连接的插件，或这些方式的组合重复使用。

## 开始前

选择您已经知道如何完成的工作流程。当操作步骤稳定、成功标准明确时，“录制与重放”的效果最佳。

## 开始录制

1. 在 ChatGPT 桌面应用中，选择 ChatGPT 并在切换器中启用 Work，或选择 Codex。然后打开 **插件**。
2. 打开 **+** 菜单。
3. 选择 **录制技能**。
4. 审查建议的提示，补充任何有用的上下文，然后提交。
5. 当聊天请求录制您操作的权限时，请在准备好演示工作流程后批准该请求。
6. 在 Mac 上执行工作流程。
7. 完成后，通过菜单栏或浮层停止录制，或者在聊天中说明您已完成。

录制期间，ChatGPT 或 Codex 会观察学习工作流程所需的操作和窗口内容。录制会持续到您将其停止。请确保录制内容聚焦于您希望技能传授的任务。

停止录制后，ChatGPT 或 Codex 会检查录制的工作流程，并生成技能草案。该技能会说明工作流程的适用时机、所需输入、操作步骤及结果验证方法。您还可以要求进一步完善。

## 重放工作流程

在 ChatGPT 或 Codex 中开始新对话，并要求其使用生成的技能。提供本次不同的输入值，例如要上传的文件、要创建的议题或报告的日期范围。

该产品会将技能作为任务的可复用上下文，然后使用当前环境中的可用工具完成工作流程，包括计算机使用、浏览器操作和已安装的插件。

## 提升录制效果的技巧

- 确保演示简短且完整。
- 开始录制前，请说明您的目标，以及每次使用技能时可能有所不同的具体输入。
- 使用贴近实际的输入，但避免使用机密信息和敏感数据。
- 录制后完善技能，明确说明隐含但重要的偏好，例如命名约定、字段默认值或需要做出决策的环节。
- 工作流程完成后停止录制，不要继续录制无关的清理操作。

## 何时需要另外构建插件

“录制与重放”可根据演示的工作流程快速创建技能。
如果您希望在团队中分发独立且稳定的软件包、捆绑
多项技能、包含连接器、添加 MCP 服务器，或管理安装
元数据，请将该工作流程打包成独立插件。请参阅
[构建插件](https://developers.openai.com/plugins/build/plugins)。

## 故障排除

### 我看不到“录制与重放”

如果您的组织使用 `requirements.toml` 管理 Codex，
`[features].computer_use` 要求也会控制“录制与重放”。设置
`computer_use = false` 会导致这两项功能都不可用。
