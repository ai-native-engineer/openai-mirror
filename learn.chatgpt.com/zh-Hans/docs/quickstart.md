## 在哪里使用 ChatGPT

您可以通过不同平台使用 ChatGPT，包括
[ChatGPT 桌面应用](/zh-Hans/codex/app)和[网页版 ChatGPT](/zh-Hans/codex/web)。请选择
适合您工作需求的方式。

  

  如果您是开发者，希望在终端或代码编辑器中使用 Codex，
  请试用 [Codex CLI](/zh-Hans/codex/cli) 或 [Codex IDE 扩展](/zh-Hans/codex/ide)。
