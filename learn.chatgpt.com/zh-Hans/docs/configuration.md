# 配置

配置 ChatGPT 和 Codex 开发者工具、可复用工作流及外部工具

设置默认值、添加持久上下文，并自定义 ChatGPT 和 Codex 开发者工具的工作方式。

配置决定了 ChatGPT 和 Codex 开发者工具在不同聊天、代码仓库和计算机中的行为。持久上下文、配置文件、代码仓库指导信息、子智能体、外部连接以及 Linux 和 Windows 设置相互配合，确保个人和团队的这些工作流保持一致。
