# Codex 远程

通过手机启动、指导、审批和审查已连接计算机上的 Codex 任务。

远程

通过手机启动、指导和审查编程任务

通过手机跟踪进度、审批操作并发送指令。Codex 会在您已连接的计算机上运行每项任务。

设置远程功能

远程连接指南

将 ChatGPT 移动应用与已连接的 Mac 或 Windows PC 搭配使用。功能是否可用取决于发布进度和您的工作空间设置。

Codex 远程交互式预览

交互式 Codex 远程移动应用，展示已连接的计算机、任务、对话、审批和已更改的文件

Codex 远程的优势

通过手机启动任务

选择一台已连接的计算机和一个项目，描述任务，然后让 Codex 开始工作。

在任务进行过程中提供指导

打开任务、跟踪进度并发送新指令，无需回到电脑前。

审批所请求的操作

在 Codex 继续在您已连接的计算机上执行任务之前，审查请求执行的命令和操作。

审查结果

检查回复、已更改的文件、差异和测试结果，然后决定下一步操作。
