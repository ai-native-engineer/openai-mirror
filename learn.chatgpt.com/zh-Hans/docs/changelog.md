  ### 通过 Gmail、Slack 和 GitHub 事件触发计划任务

  现在，当 Gmail、Slack 或 GitHub 中发生受支持的事件时，ChatGPT 计划任务即可运行。您可以按发件人或主题筛选 Gmail 邮件、监控选定的 Slack 频道，或响应 Pull Request 的审查、评论、提交更新和合并等活动。

  使用符合条件套餐的用户可在网页版 ChatGPT 和移动端使用事件触发任务。创建任务前，请先连接相关应用，并批准其访问请求。ChatGPT Slack 应用必须是每个受监控频道的成员，已连接的 GitHub 应用必须拥有每个受监控代码仓库的访问权限。

  事件触发任务不能同时使用定时计划。当符合条件的
  事件在短时间内接连到达时，ChatGPT 可能会将这些事件合并到一次运行中处理。
  打开 **计划任务** 以审查待处理事件，或选择 **立即运行**。

  事件触发计划任务](/codex/automations?surface=web#web-trigger-tasks-from-app-events)。

  ### 网页搜索现已默认启用

  Codex 现已在 Codex CLI 和 IDE 扩展中为本地任务启用网页搜索。
  默认情况下，Codex 使用网页搜索缓存，即由 OpenAI 维护的网页结果索引。缓存模式会返回预先编制索引的结果，而不是实时获取网页；实时模式则会从网络获取最新数据。如果您使用 `--yolo` 或其他 [完全访问权限沙盒设置](/codex/agent-approvals-security)，网页搜索将默认使用实时结果。如要禁用此行为或切换模式，请使用 `web_search` 配置选项：

  + `web_search = "cached"`（默认值；提供网页搜索缓存中的结果）
  + `web_search = "live"`（从网络获取最新数据；等同于 `--search`）
  + `web_search = "disabled"` 可移除此工具

  如需了解详情，请参阅 [配置文档](/codex/config-file/config-basic)。

  管理员仍可使用 `requirements.toml` 强制实施约束；无论该文件位于何处，它都会覆盖默认设置。
