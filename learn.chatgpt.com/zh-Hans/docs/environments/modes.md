在 ChatGPT 桌面应用中，打开 ChatGPT 下拉菜单并选择 **Codex**。
开始 Codex 聊天时，请选择其运行位置：

- **本地**：直接在您当前的项目目录中工作。
- **工作树**：在 Git 工作树中隔离更改。[了解更多](/zh-Hans/codex/environments/git-worktrees)。
- **云端**：在已配置的云端环境中远程运行。

在 **本地** 和 **工作树** 环境中进行的聊天都在您的计算机上运行。

如需查看完整术语表和相关概念，请浏览[概念部分](/zh-Hans/codex/prompting)。
