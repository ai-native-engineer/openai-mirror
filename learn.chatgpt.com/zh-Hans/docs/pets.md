宠物是可选的动画伙伴，可帮助您跟踪任务进展。宠物出现在哪里，
以及显示什么内容，取决于您使用的界面。选择宠物只会改变它的
外观，不会影响 ChatGPT 完成任务的方式。

## 使用悬浮宠物

在 ChatGPT 桌面应用中，宠物可以悬浮在其他应用窗口上方，帮助
您跟踪各个聊天中的动态。

### 选择并唤醒宠物

1. 打开应用底部的个人资料菜单，然后选择**宠物**。您也可以
   打开[**设置**](codex://settings)，然后前往**宠物**。
2. 选择内置宠物或自定义宠物。
3. 输入 `/pet`，或打开命令菜单并选择**唤醒宠物**。

在**设置 \> 宠物**或命令菜单中选择**收起宠物**，或再次输入
`/pet`，即可隐藏宠物。您的选择和宠物位置会保留，
重新打开应用后依然如此。

选择自定义宠物后，它也会显示在您的**个人资料**视图中。

### 了解宠物状态

| 状态          | 含义                                                  |
| --------------- | -------------------------------------------------------- |
| **运行中**     | 聊天正在执行任务。                              |
| **需要输入** | 聊天需要您进行审批、给出回答或做出其他决定。 |
| **就绪**       | 聊天已完成，并有未读动态。            |
| **受阻**     | 聊天失败或遇到系统错误。             |

当多个聊天都有动态时，宠物会优先显示需要输入的聊天，
然后依次显示受阻、就绪和运行中的聊天。打开活动托盘以
选择一个聊天。

点击宠物可返回 ChatGPT，点击某项活动则可打开相应聊天。
活动托盘与[系统
通知](/zh-Hans/codex/notifications?surface=app)相互独立。

### 跟踪计算机使用活动

在 macOS 上，[计算机使用](/zh-Hans/codex/computer-use)的画中画窗口可以
吸附到已唤醒的宠物上。移动宠物时，该窗口会随之移动。

### 创建自定义宠物

1. 打开**设置 \> 宠物**，然后选择**创建自己的宠物**。
2. 应用会安装随附的 `hatch-pet` 技能，重新加载技能，然后打开一个
   新聊天。
3. 描述您想要的宠物，然后发送提示。
4. 任务完成后，返回**设置 \> 宠物**，选择**刷新**，
   然后选择您的新宠物。

在桌面应用中创建的自定义宠物会存储在您的计算机本地。
它们不会自动同步到 ChatGPT 网页版。

### 减少动画

宠物会遵循操作系统的“减少动态效果”设置。启用“减少
动态效果”后，宠物会使用静态帧，而不是精灵动画。

## 在网页端选择宠物

如果宠物功能可用于您的账户和工作空间，请打开**设置 \>
个性化 \> 宠物 \> 选择宠物**。选择内置宠物，或选择
**默认**，即可在不使用宠物的情况下使用 ChatGPT。

网页端宠物会显示在受支持的 ChatGPT Work 聊天中。它不提供
桌面应用中的悬浮层、活动托盘或 `/pet` 命令。

### 上传自定义宠物

选择**上传宠物**以添加自定义精灵图集。文件必须是
带透明背景的 PNG 或 WebP 图像，尺寸须恰好为 1536 × 1872 像素，且不得超过 20 MiB。
您可以在同一设置中编辑、下载、刷新或删除已上传的宠物。

## 选择终端宠物

在交互式 Codex CLI 会话中：

- 输入 `/pets` 或 `/pet` 可打开宠物选择器。
- 输入 `/pets <name>` 可直接选择宠物。
- 输入 `/pets off` 可禁用终端宠物。

选择器包含内置宠物，以及安装在您
计算机上的兼容自定义宠物。终端宠物会显示当前 CLI 会话的活动状态。它使用
**运行中**、**需要输入**、**就绪**和**受阻**状态，但不
提供桌面应用中用于多个聊天的活动托盘。

终端宠物需要 iTerm2 3.6 或更高版本，或者需要支持 Kitty 图形或
Sixel 的终端。它们在 tmux 和 Zellij 中不可用。

## IDE 扩展中的宠物

Codex IDE 扩展不提供宠物选择器或宠物悬浮层。
要使用自己的宠物时，请使用 ChatGPT 桌面应用或 Codex CLI。
