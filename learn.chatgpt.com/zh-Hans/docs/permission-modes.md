## 权限模式

权限决定桌面 App 中的 ChatGPT 与 CLI 或 IDE 中的 Codex 如何处理本地操作，例如编辑文件、运行命令和使用互联网。您选择的模式会划定边界，
规定 ChatGPT 可以自行执行哪些操作，以及哪些操作需要审查。

对于大多数任务，请先选择**请求审批**。在此模式下，ChatGPT 可在
当前工作空间内执行操作；要越过该边界时，它会先暂停。

选择下方的不同模式，了解每种模式的工作方式。

## 启用模式

首次使用 ChatGPT 桌面 App 时，您需要在应用设置中启用这些模式。

**请求审批**始终可用。要将**替我审批**（在设置中称为
**自动审查**）或**完全访问权限**添加到权限菜单，请在 ChatGPT 桌面 App 中打开
**设置 \> 通用**，然后在
**权限**下启用相应模式。启用后，该模式会显示在菜单中，但不会
自动选中该模式，也不会更改现有聊天。

  

  可用模式可能会因您的本地配置和
您所在组织的要求而异。不允许使用的模式会显示为禁用状态。

## 权限的工作原理

以下两项控制相互配合：

- **沙盒**规定 ChatGPT 可以访问哪些文件和网络资源。
- **审批**决定 ChatGPT 何时在执行操作前暂停，或何时将
  请求交由自动审查。

更改请求的审查方不会扩大沙盒范围。例如，
**替我审批**模式的工作空间边界与**请求审批**相同；
该模式会将需要越过该边界的请求交由自动审查。

请在 ChatGPT 桌面 App 或
IDE 扩展中使用编辑器下方的权限控件。

在 CLI 中，输入 `/permissions`。有关技术详情，请参阅
[沙盒](/zh-Hans/codex/sandboxing)、[自动审查](/zh-Hans/codex/sandboxing/auto-review)或
[权限配置文件](/zh-Hans/codex/permissions)。
