## 在以下情况下使用 Codex 云端……

### 工作需要在后台运行

委派耗时较长的任务，待任务就绪后再回来查看。

### 您想比较多次尝试的结果

并行运行任务，无需占用您的本地计算机。

### 从 GitHub、GitLab、Linear 或 Slack 发起工作

通过集成移交工作，无需离开 Pull Request、合并请求、议题、频道或会话串。

### 您不在开发计算机旁

通过网页或 Codex CLI 启动并审查任务。
