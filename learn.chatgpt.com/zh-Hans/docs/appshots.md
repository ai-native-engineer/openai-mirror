应用快照可让您将当前位于前台的应用窗口发送到 ChatGPT 聊天中。当您
正在计算机上的另一个应用中处理任务，并希望向 ChatGPT 提供
当前上下文以便它协助您完成任务时，可使用应用快照。

  应用快照可在适用于 macOS 的 ChatGPT 桌面应用中使用。同时按下两个 Command
键，或按下您自定义的应用快照快捷键，即可拍摄应用快照。

## 应用快照会捕获哪些内容

应用快照仅捕获当前位于前台的窗口。它可以包含以下内容：

- 可见窗口的图像。
- 该窗口中的可用文本，包括可见文本，以及应用在
可见滚动区域之外提供的文本。

将应用快照添加到聊天后，它会作为附件处理。ChatGPT
会将应用快照存储在本地会话文件中，就像存储您手动附加的文件或图像
一样。

## 何时使用应用快照

当 ChatGPT 必须先获得 Mac 应用中的上下文才能执行操作时，请使用应用快照。

示例：

- 分享 API 参考页面，并让 ChatGPT 编写使用该 API 的脚本。
- 分享电子邮件或日历视图，并让 ChatGPT 拟定下一步操作。
- 分享图像编辑器、设计稿或预览窗口，并让 ChatGPT 修改
相关资源或代码。
- 分享错误信息、设置面板或应用状态；这些内容展示起来比
描述起来更容易。

## 拍摄应用快照

1. 将您要分享的应用窗口置于前台。
2. 同时按下两个 Command 键，或按下您在 ChatGPT
设置中配置的自定义快捷键。
3. 如果 ChatGPT 请求 macOS 权限，请授予这些权限。
4. 让 ChatGPT 使用该应用快照执行任务。

  

默认情况下，ChatGPT 会为应用快照新建聊天。如果您在过去 60 秒内曾与某个
聊天互动，ChatGPT 会改为将应用快照添加到最近使用的
聊天中。连续拍摄的应用快照会添加到同一聊天中。

您可以在应用设置中更改应用快照快捷键。

## 权限与安全性

ChatGPT 可能会在拍摄应用快照前请求以下权限：

- **屏幕与系统音频录制** 权限允许 ChatGPT 捕获
  当前位于前台的应用窗口图像。
- **辅助功能** 权限允许 ChatGPT 读取当前位于前台的应用窗口中的可用文本。

拍摄应用快照会与 ChatGPT 分享所捕获的图像和可用文本。
除非任务需要这些敏感
内容，否则请避免拍摄包含这些内容的应用快照。

请像审查是否要与 ChatGPT 分享屏幕截图和文档
一样，审查应用快照。

## 限制与故障排除

应用快照可在适用于 macOS 的 ChatGPT 桌面应用中使用。如果您在 CLI 中继续某个
已包含应用快照的聊天，该附件会成为聊天
历史记录的一部分，但 CLI 无法创建新的应用快照。

对于某些应用和网站，包括 Google Docs、Gmail、Google Sheets 和
Google Slides，ChatGPT 可能只能收到可见的屏幕截图，也可能无法收到
完整文档或屏幕外文本。在 ChatGPT Work 或 Codex 中，ChatGPT 可以使用
已安装的对应插件访问相关应用内容，并协助处理您的
请求。

如果应用快照无法正常使用：

1. 打开 **系统设置 \> 隐私与安全性**。
2. 检查 **屏幕与系统音频录制** 和 **辅助功能** 中 Codex
   计算机使用的权限。
3. 重新启动该应用，然后重试。
