部分 ChatGPT 和 Codex 功能在发布时会带有成熟度标签，帮助您了解各项功能的可靠性、哪些方面可能发生变化，以及可以获得何种级别的支持。

| 成熟度          | 含义                                                                                                 | 使用建议                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 开发中 | 尚不具备使用条件。                                                                                            | 请勿使用。                                                                    |
| 实验性      | 功能尚不稳定，OpenAI 可能会将其移除或更改。                                                                  | 请自行承担使用风险。                                                         |
| 测试版              | 已基本完善，可供广泛测试，但有些方面可能会根据用户反馈调整。       | 可用于大多数评估和试点；预计会有小幅调整。                      |
| 稳定            | 已获得全面支持，文档齐备，可供广泛使用；其行为和配置会长期保持一致。 | 可安全用于生产环境；如需移除，通常会先经过弃用流程。 |
| 已弃用        | 为保持兼容性而继续提供，但已不再推荐使用；OpenAI 可能会在未来版本中将其移除。       | 避免新增使用，并制定迁移计划。                                            |
