## ChatGPT Work 简介

ChatGPT Work 让您可以将实际工作委托给 ChatGPT。

需要答案、解释、头脑风暴或简短草稿时，请使用聊天。
当您希望 ChatGPT 完成成果明确的任务时，请使用 ChatGPT Work，例如生成
简报、演示文稿、分析报告、定期更新、工作流程，或可供您审查并使用的文件。
详细了解[如何结合使用聊天和 ChatGPT Work](/zh-Hans/codex/use-chatgpt)。

ChatGPT Work 可以使用您的文件、插件和已获批准的工具来检索信息、制作成品文件、运行工作流，并完成工作以供您审查。您可以跟踪进度、回答问题、调整方向，并审批重要操作。

在[桌面应用](/zh-Hans/codex/app)中，如果相关工具可用，ChatGPT Work 还可以使用本地文件、应用和
浏览器。

如果您曾使用 Codex 处理非编程工作，可以继续使用 Codex，也可以改用 ChatGPT Work。ChatGPT Work 提供相同的核心能力，并带来专为日常工作设计的体验。

## 首先可以尝试什么

首先，切换到 **Work**。然后选择您的第一项任务。
合适的任务应有明确的成果、几份原始资料，
以及可供您审查的结果。

### 选择在本地或云端工作

在桌面应用中，打开编辑器中标有 **在本地使用 Work** 的控件。
如果有**云端** 选项，且您希望 ChatGPT Work 在关闭应用或计算机后
继续运行，或希望通过网页端或移动应用继续聊天，
请选择该选项。如果任务需要使用您计算机上的文件或应用，
请保持选中 **在本地使用 Work** 。

云端也适合运行需要持续研究或检查网站的计划任务，因为这些任务的运行不要求您的计算机保持唤醒状态。

以下是三个适合入门的常见使用场景：

### 创建演示文稿

使用 ChatGPT Work 将笔记、文档、研究资料或会议材料整理成结构清晰的演示文稿。

  
    
  

### 创建对比电子表格

使用 ChatGPT Work 将笔记、文件或研究资料整理成电子表格，以比较各个选项并帮助您做出决策。

  
    
  

### 设置定期更新

如果您希望 ChatGPT Work 定期重复执行任务、持续监控或更新内容，请使用计划任务。

  
    
  

详细了解[计划任务](/zh-Hans/codex/automations?surface=app)。

## 使用 ChatGPT Work 的最佳实践

当您希望 ChatGPT 完成任务、创建文件或持续管理工作时，请使用 ChatGPT Work。它适合具备以下特点的任务：

- 涉及多个来源、插件、工具或步骤。
- 手动完成需要花费较多时间。
- 生成可供您审查、编辑或复用的结果。
- 需要持续重复执行、监控或更新。

为了获得更好的结果，请告诉 ChatGPT 您需要的成果、应使用的来源或插件、需要遵守的限制条件、理想结果的标准，以及何时应暂停以进行审查或审批。

**避免这样写：** 为我制作一份关于我们客户研究的演示文稿。

详细了解[如何为 ChatGPT Work 编写提示词](/zh-Hans/codex/prompting#prompting-for-work)。

## 添加插件，丰富上下文并提升输出质量

  
    
  

插件可将 ChatGPT Work 连接到您的团队使用的工具，例如 Slack、Google Drive、SharePoint、电子邮件、日历、客户关系管理系统和项目跟踪工具。

- 在左侧边栏中选择 **插件** ，即可查看插件库。
- 安装与您的工作最相关的插件。
- 要让 ChatGPT 使用特定工具，请在提示中输入 `@` 和插件名称。

详细了解[插件](/zh-Hans/codex/plugins)。

## 高效使用 ChatGPT Work

对于需要仔细推理、视觉判断或精心制作最终文件的复杂工作，
请选择 [GPT-6 Astra](/zh-Hans/codex/models#gpt-6-astra)。对于较简单的任务，
可以考虑 Sol、Terra 或 Luna。请从模型选择器中
可用的模型里进行选择，并在开始大型任务前
查看[套餐用量](/zh-Hans/codex/pricing)。

ChatGPT Work 最适合处理工作量较大的任务，这些任务涉及多个步骤、来源或工具，或需要交付完整成果。耗时更长或更复杂的任务可能消耗更多额度，因为 ChatGPT 需要代您完成更多工作。请重点关注最终成果的价值，而非提示的数量。

通过设定合理的边界，让任务保持聚焦。例如：“仅使用这些来源”“比较排名前五的选项”或“在发送任何内容前先停止”。

如果您只是快速提问、进行简短改写，或在做出决策时只需要建议，请改用聊天。

详细了解[如何高效工作](/zh-Hans/codex/prompting#prompting-for-work)。

如果任务因安全审查而暂停，请按照通知中的指示操作，
并在继续前查看所有可用的审查结果。请参阅[安全监控与暂停的任务](/zh-Hans/codex/agent-approvals-security#safety-monitoring-and-paused-tasks)。
