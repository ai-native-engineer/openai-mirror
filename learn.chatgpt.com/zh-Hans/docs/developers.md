# 开发者

配置开发工作流、环境、扩展程序和集成

将 Codex 与代码库、开发环境、自动化流程和您团队的工具结合使用。

Codex 支持日常编码工作，也支持跨本地和云端环境的深度集成。其开发工作流涵盖代码审查、集成终端、可复用的技能和插件、通过 SDK 和 App Server 实现的自动化、团队工具，以及各个界面的参考资料。
