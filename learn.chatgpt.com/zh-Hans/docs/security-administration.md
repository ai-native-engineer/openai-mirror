# 安全

管理 ChatGPT 和 Codex 开发者工具的权限、安全控制和防护措施

控制 ChatGPT 和 Codex 开发者工具可以访问的资源，了解工作如何进行隔离，并对安全敏感型任务采取防护措施。

安全控制措施规定 ChatGPT 和 Codex 开发者工具可以访问哪些资源，以及如何审查敏感操作。权限、沙盒、审批和网络访问共同划定信任边界。Codex Security 可帮助发现并修复漏洞，网络安全指南则说明安全敏感型工作的处理方式。
