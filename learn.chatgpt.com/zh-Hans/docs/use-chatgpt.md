## 将想法转化为实用成果

ChatGPT 是一个 AI 智能体，您可以用自然语言与它交流：

1. 从一个问题、一个想法、一些零散笔记、一份文件，或一项您需要完成的任务开始。

2. 让 ChatGPT 解释信息、拓展思路、起草内容、研究某个主题、分析材料，或创作新内容。

3. 提供它所需的上下文和工具，例如文件、网页搜索、项目或插件。

4. 审查结果、调整方向，并提出修改要求。您不必一开始就写出完美的提示，也不需要使用特殊命令。

## 选择您的工作方式

使用聊天功能提出问题或来回交流。如果您希望 ChatGPT 完成规模较大的任务并交付可供审查的成果，请在切换器中启用 Work。如果您需要开发者视图或更多技术细节，尤其是在进行软件开发时，请选择 Codex。

| 选择       | 适用场景                              | 示例                                                                     |
| ------------ | --------------------------------------------- | ---------------------------------------------------------------------------- |
| 聊天         | 与 ChatGPT 一起处理任务           | 提出问题、搜索网页、集思广益、起草消息、比较选项 |
| ChatGPT Work | 明确预期成果，并获得可供审查的结果 | 创建演示文稿、分析文件、起草报告、制定项目计划           |
| Codex        | 使用开发者工具并查看技术细节 | 调试代码、运行测试、审查 PR、实现功能                      |

使用聊天功能提出问题、集思广益、起草或修改文本、总结文件、
比较选项，或理清规模较大的任务。在 Codex 中，将指针移至 **新建聊天**，然后
在该选项可用时选择 **快速对话** 。

如果您需要完整且可供审查的成果，请切换到 **Work** ，并说明
成果应包含哪些内容。请参阅[开始使用
ChatGPT Work](/zh-Hans/codex/get-started-with-work)，了解任务示例、提示和
最佳实践。

### ChatGPT Work 的功能

ChatGPT Work 可以规划任务、收集上下文、使用工具，并持续推进工作，直至生成可供您审查的成果。

  

您可以让它：

- **研究和分析信息。** 搜索网页、浏览网站、
  比较信息来源、阅读文件、分析数据，并总结研究结果。
- **使用您的文件和工具。** 添加已上传的文件、
[项目](/zh-Hans/codex/projects)、记忆、ChatGPT 资料库和已安装的
[插件](/zh-Hans/codex/plugins)。插件可提供来自已连接服务的信息、可复用的
  工作流和受支持的操作。
- **制作成品文件。** 起草并完善[文档、演示文稿、
  电子表格和 PDF 文件](/zh-Hans/codex/artifacts-viewer)。审查结果，提出
  具体的修改要求，然后下载完成的文件。
- **创作视觉和交互式内容。** 生成或编辑
[图像](/zh-Hans/codex/image-generation)，制作交互式
[可视化](/zh-Hans/codex/visualizations)，并使用
  [站点](/zh-Hans/codex/sites)构建或分享网站和应用。
- **跨网站和应用开展工作。** 使用[浏览器](/zh-Hans/codex/browser)
  开展研究并与网站交互。在桌面应用中，当相关功能可用时，您可以使用
[浏览器扩展程序](/zh-Hans/codex/chrome-extension)、
[计算机使用](/zh-Hans/codex/computer-use)和[应用快照](/zh-Hans/codex/appshots)
  功能。
- **运行代码并审查技术工作。** 运行代码和 shell 命令、
  分析数据、检查文件、[审查代码](/zh-Hans/codex/code-review)，并处理
  您所选环境可以访问的代码仓库。
- **委派并持续推进耗时较长的任务。** 将相互独立的工作分配给
[子智能体](/zh-Hans/codex/agent-configuration/subagents)，跟踪其进度，并
  让[长时间运行的工作](/zh-Hans/codex/long-running-work)持续进行。
- **重复执行实用工作流。** 为周期性工作设置[计划
  任务](/zh-Hans/codex/automations)，并使用
[技能](/zh-Hans/codex/skills-and-plugins)复用工作流程。
- **通过语音交流推进任务。** 如果您的套餐支持，您可以在桌面应用中使用
[ChatGPT 语音](/zh-Hans/codex/features/voice)开始工作、查看进度或
  调整方向。

  功能是否可用取决于您的套餐、平台、地区、发布进度和工作空间设置。
  您的工作空间管理员可以控制 ChatGPT Work、
  插件、浏览器和网络的访问权限。ChatGPT Work 与 Codex 共享[用量
  限制](/zh-Hans/codex/pricing)。

### 选择在云端或本地工作

在网页版中，ChatGPT Work 在托管式云端环境中运行。在桌面应用中，您可能还可以选择任务的运行位置：

- **云端：** 在隔离的托管环境中运行任务。关闭桌面应用后，任务仍可继续运行，
  您也可以通过网页版或移动应用继续处理。
  云端工作可以使用已上传的文件、已连接的工具和经批准的网站。
- **在本地工作：** 使用您计算机上的文件、应用或浏览器。
  当您的账户或工作空间已启用本地工作时，您可以在
  桌面应用中使用此功能。

ChatGPT 会显示进度，并在需要信息或审批时暂停。请先审查可能产生重大影响的操作，再予以批准；在使用或分享最终结果之前，也请先进行检查。

### 比较桌面应用中的 ChatGPT Work 与 Codex

ChatGPT Work 与 Codex 的功能有所重叠。如果您更喜欢 Codex，仍可继续使用它开展研究、处理文档、制作演示文稿，以及完成其他知识工作。当两者均可供您使用时，桌面应用会根据您的选择调整界面以及智能体呈现工作内容的方式。

| 差异          | 桌面应用中的 ChatGPT                                                 | 桌面应用中的 Codex                                              |
| ------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 从哪里开始      | 选择 **ChatGPT**，然后切换到 **Work**                            | 在产品选择器中选择 **Codex**                          |
| 可查看的聊天       | 查看在网页版和移动端通过聊天功能发起的对话，以及 ChatGPT Work 对话 | 专注于 Codex 聊天和开发项目                     |
| 快速对话          | 不可用                                                          | 功能可用时，您可以在 Codex 中访问来自网页版和移动端的 ChatGPT 聊天 |
| 技术细节    | 隐藏 Git 或 shell 命令等技术细节                      | 查看面向开发者的详细信息，包括差异视图和审查视图            |
| 智能体沟通方式 | 倾向于使用非技术性语言，并提供完整成果                     | 可包含技术和实现细节                  |
| Pull Request 窗格  | 使用 ChatGPT Work 时不可用                                  | 启用后可用                                            |

### 自然地与 ChatGPT 对话

像向一位乐于助人的同事说明需求一样写下请求。说明您想达成的目标，
补充会影响回答的细节，并描述所需的格式。
第一条提示只是起点，您可以通过后续消息补充上下文，
或完善结果。

您可以继续给出简单的指令，例如：

- “把它改得更简短。”
- “给我三种不同的方案。”
- “您做了哪些假设？”
- “继续之前，请先向我提问。”

详细了解[提示词](/zh-Hans/codex/prompting)，或参加
[AI 基础课程](https://academy.openai.com/home/courses/ai-foundations-juzjs)，
在指导下进行练习。

## 为 ChatGPT 提供合适的上下文

向 ChatGPT 提供与任务相关的信息、工具和指令。
您不必提供所有内容，只需补充会影响
结果要求的上下文。

### 将相关工作集中在一个项目中

项目可帮助您围绕某个主题、目标或持续进行的工作，
整理 ChatGPT 中的相关内容。如果工作会持续一段时间或依赖相同的上下文，
请将相关聊天、文件和指令集中到一个项目中。[详细了解
项目。](/zh-Hans/codex/projects)

### 附加文件

您可以上传或附加文档、演示文稿、电子表格、PDF 文件、图像和数据导出文件。
如果您希望 ChatGPT 执行以下操作，请使用这些文件：

- 总结或比较这些文件。
- 查找其中的规律或不一致之处。
- 提取、清理或重新整理信息。
- 将这些文件用作创建新文件的原始资料。

ChatGPT 创建文件后，请打开预览并检查其内容。
然后，您可以要求修改，而无需从头开始。详细了解
[如何处理文件](/zh-Hans/codex/artifacts-viewer)。

### 使用插件连接工具

插件可以将 ChatGPT 与您工作中使用的工具和信息连接起来，
例如 Google Drive、SharePoint、Salesforce 或 Gong。
当任务需要聊天之外的信息、在其他系统中执行操作，
或使用可重复的工作流程时，请使用插件。

  

插件能否使用取决于您的套餐、工作空间设置和插件本身。
详细了解[技能和插件](/zh-Hans/codex/skills-and-plugins)。

## 分享 Codex 线程的只读快照

无论使用哪种 Codex 套餐，您都可以在 macOS 版 ChatGPT 桌面应用中
为本地 Codex 线程创建只读快照。
该快照不会让其他人获得访问您的项目或计算机的权限。

分享之前，请检查哪些人可以打开链接：

- **个人账户：** 任何拥有链接的人都可以打开该快照。
- **工作空间账户：** 只有创建该快照的工作空间中已通过身份验证的成员才能打开快照。
  您可以允许该工作空间中的所有成员访问，
  也可以将访问权限限制为受邀人员和群组。
  工作空间管理员可以关闭工作空间共享链接。

1. 打开线程并选择 **分享**。
   在支持斜杠命令的界面中，您也可以使用 `/share`。
2. 对于工作空间账户，请在 **谁有访问权限** 中选择工作空间内的所有成员，
   或选择 **仅限受邀的人员和群组**。如果仅允许受邀者访问，
   请通过电子邮件地址添加现有工作空间成员，或选择工作空间群组。
3. 等待快照上传完成后，选择 **复制链接**。
   打开对话框即会开始上传，但 Codex 只有在您选择 **复制链接**后，
   才会按照您选定的共享范围和接收者发布快照。
4. 在将链接发送给任何人之前，请先打开已复制的链接并检查共享视图。

快照会记录您分享时可用且受支持的线程内容。
之后的消息和更改不会更新现有快照。

共享快照可以包含用户可见的消息、推理摘要、图像附件、
智能体查看或生成的图像，以及文件更改，包括路径和差异。
快照不包含原始线程中的工具调用、
Shell 命令或工具的输入及输出。

Codex 会在上传快照前对符合已知模式的机密信息进行脱敏。
发送链接前，请先检查共享视图，因为文件路径等敏感内容
可能仍会保留在消息、图像或差异中。

您无法从共享快照创建原始线程的派生线程。
您可以将快照作为附件导入，并在新的线程中引用。

如需查看或撤销共享链接，请打开[ChatGPT 数据
控制](https://chatgpt.com/#settings/DataControls)，然后选择 **共享链接**。

## 让结果可直接使用

将最初的结果视为草稿，供您检查、质疑和改进。
即使回答看起来已经很完善，也可能不完整或存在错误，
因此在使用或分享前，请检查重要细节。

**检查结果：**

- 核实重要的数字、名称、日期、引文和说法。
- 打开生成的文件，检查每个部分、标签页、幻灯片或页面。
- 确认 ChatGPT 使用了正确且最新的资料。
- 检查是否有遗漏的信息和缺乏依据的假设。
- 如果结果未达到目标，请要求进行有针对性的修改。

然后，请 ChatGPT 对结果进行严格检验：

- “你使用了哪些资料来源？”
- “请为每项主要论断注明来源。”
- “你做出了哪些假设？”
- “有哪些信息是你无法获取的？”
- “在什么情况下你会改变自己的建议？”
- “请对照原始文件核查这个结果。”

如果 ChatGPT 无法访问某项资料来源或完成任务的某个部分，请要求它明确说明。明确指出不足，比自信地猜测更便于补救。

  法律、财务、医疗、安全及其他事关重大的决策，都需要经过相关专家的审查。请使用 ChatGPT 辅助您做出有依据的判断，而不是让它替代您的判断。
