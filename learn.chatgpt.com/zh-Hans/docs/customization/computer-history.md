在 macOS 上的 ChatGPT 桌面应用中，计算机使用记录对 ChatGPT Pro、Business 和企业用户 **默认关闭** 。
  Pro 用户可以选择
  启用。对于 Business 和企业工作空间，管理员必须
  先明确授予访问权限，各成员才能选择启用。
  计算机使用记录还需要启用[记忆](/zh-Hans/codex/customization/memories)，且不支持
  通过 API 密钥或 Amazon Bedrock 使用。该功能适用于受支持的
  地区，包括欧洲经济区（EEA）、瑞士和
  英国。

计算机使用记录会将您在各应用和网站中的活动转化为记忆与时间线，供 ChatGPT 和 Codex 参考。您可以自然地询问近期工作情况、继续之前的工作、了解自己的工作规律，并将重复的工作流转化为技能或自动化。

只有在您选择启用后，系统才会开始生成使用记录。您可以控制哪些应用和网站纳入记录，通过 macOS 菜单栏查看和暂停收集，并随时检查或删除使用记录。

计算机使用记录取代了此前的 Chronicle 研究预览版，但这是重新构建的系统，而非简单更名。它会利用交互事件，以及通过 macOS 辅助功能获取的文本和其他上下文，生成可供您查看和删除的摘要。使用记录中不包含屏幕截图，也不会录制音频，且绝不会包含隐私浏览模式下的网页浏览活动。

  

## 计算机使用记录能提供哪些帮助

计算机使用记录会提供近期活动作为上下文。当文件、Slack 对话、Google Doc 或其他来源更适合当前任务时，ChatGPT 和 Codex 可以通过使用记录找到该来源，然后直接读取。

## 计算机使用记录的工作原理

计算机使用记录会根据获准的应用和网站创建交互事件流。事件可能包括点击、输入、键盘快捷键、应用切换，以及 macOS 通过辅助功能系统提供的上下文。计算机使用记录会定期将这些事件转换为文字摘要和本地记忆文件。

计算机使用记录不会将屏幕截图纳入您的历史记录，也不会录制麦克风输入或系统音频。私密模式下的网页浏览活动绝不会被纳入。

在 **设置 \> 计算机使用记录 \> 历史记录**中，时间线按
日期和时间对摘要进行分组。每个条目可以显示：

- 活动的标题和文字摘要。
- 提供摘要内容的应用。
- ChatGPT 识别出可重复执行的工作时推荐的技能或自动化。
- 在 Finder 中显示记忆文件或删除条目的操作。

选择 **询问您的历史记录** ，即可开始围绕计算机使用记录进行聊天；也可以使用
以下提示：

- “我上次休息前在处理什么工作？”
- “我在哪里可以找到今天早些时候找过的提案文档？”
- “请列出我今天处理过的任务及其状态。”
- “请总结我昨天做的工作，供站会汇报。”

## 权限和访问

计算机使用记录分别针对工作空间访问权限、个人主动启用、记忆，以及纳入历史记录的应用或网站提供独立的控制选项：

- **工作空间访问权限：** 计算机使用记录在 Business 和
  企业工作空间中默认关闭，只有管理员
  明确授予访问权限后才能使用。企业管理员可使用 **启用计算机
  使用记录** 选项，在[**工作空间设置 \> 权限和角色**](https://chatgpt.com/admin/settings)中
  为相应的工作空间角色授予访问权限。
- **个人主动启用：** 授予工作空间访问权限只是允许成员选择是否
  开启计算机使用记录，并不会为任何人开启此功能。每个
  用户都必须自行主动启用，包括 ChatGPT Pro 用户。
- **记忆：** 计算机使用记录还需要启用[记忆](/zh-Hans/codex/customization/memories)功能。
  使用 `/memories` 可控制单个聊天是否能够使用本地记忆，
  或为后续记忆提供内容。
- **应用和网站：** 您的应用和网站权限决定哪些
  来源可以提供交互事件。您可以仅允许特定
  来源，或排除不希望纳入的应用及网站 URL。

如果您的工作空间角色没有访问权限，则无法通过更改本地设置启用计算机使用记录。

## 开启计算机使用记录

计算机使用记录默认关闭。如果您使用 Business 或企业工作空间，请在开启前让管理员授予您访问权限。管理员的审批并不代表您已主动启用此功能。

1. 在 macOS 上打开 ChatGPT 桌面应用。
2. 在设置的 **集成**下，选择 **计算机使用记录**。
3. 选择 **开启** ，并查看隐私、权限和本地存储
   相关信息。
4. 如果收到提示，请开启 **记忆**。计算机使用记录需要记忆功能，
   才能跨聊天和任务使用活动上下文。
5. 选择哪些应用和网站可以纳入您的历史记录，然后按照 macOS 的权限提示操作。

计算机使用记录无需屏幕录制权限。如果未显示该设置，请确认您的套餐支持计算机使用记录；如适用，还需确认您的工作空间管理员已启用该功能。

## 控制纳入的内容

您可以控制哪些应用和网站会纳入后续历史记录，以及计算机使用记录是否正在收集交互事件。

### 选择应用和网站

在 **设置 \> 计算机使用记录 \> 权限**中，选择计算机使用记录可纳入的应用和
网站：

- **排除这些应用** 和 **排除这些网站** 会屏蔽您指定的应用或 URL，
  同时允许其他受支持的来源。
- **仅包含这些应用** 和 **仅包含这些网站** 只允许您明确选择的
  来源。

您也可以选择历史记录时间线条目中的应用图标，将该应用排除在后续历史记录之外。之后可以再次将其纳入。

私密模式下的网页浏览活动绝不会被纳入。更改应用或网站权限会影响后续历史记录。要移除已有条目，请将其删除或清除。

### 暂停、恢复或停止收集

使用计算机使用记录设置或 macOS 菜单栏，控制该功能何时收集活动：

- 选择 macOS 菜单栏中的 ChatGPT 图标，然后展开计算机使用记录菜单，查看该功能收集哪些活动并访问相关控制选项。
- 选择 **暂停** 可停止收集新的交互事件；准备重新开始时，
选择**恢复** 。
- 关闭计算机使用记录，即可停止收集后续活动。

计算机使用记录可能包含来自通信应用和网站的交互事件。除非事先获得对方明确同意，否则请在与他人交流时关闭该功能。对于包含敏感健康、财务或个人信息的应用，请考虑暂停该功能或排除这些应用。

## 审查并清除历史记录

打开 **设置 \> 计算机使用记录 \> 历史记录** ，查看计算机使用记录
汇总的内容。您可以在 Finder 中显示摘要对应的本地记忆文件，
删除单个时间线条目，或清除最近 10 分钟、最近一小时、最近一天
或全部历史记录。您还可以通过 macOS 菜单栏清除某个
最近使用的应用的上一次会话。

清除历史记录会删除相关的交互事件，以及根据这些事件创建的所有记忆。此操作无法撤销。

## 隐私和本地存储

计算机使用记录会将交互事件流临时存储在您的 Mac 上，以便 ChatGPT 和 Codex 生成记忆并创建建议的工作流。该事件流可能包含点击、输入等活动，以及通过 macOS 辅助功能获取的文本和其他上下文。计算机使用记录不会将屏幕截图纳入您的历史记录，也不会录制麦克风输入或系统音频。私密模式下的网页浏览活动绝不会被纳入。

临时事件文件最多保留 48 小时。生成的记忆文件会一直保留在您的文件系统中，直到您删除或清除这些文件；您可以通过历史记录时间线显示这些文件。

### 计算机使用记录会将我的数据存储在哪里？

计算机使用记录会将交互事件临时保存在您的 Mac 上。这些事件
文件会被隔离存放在 ChatGPT
[App Group](https://developer.apple.com/documentation/xcode/protecting-local-app-data-using-containers) 中，
未经明确许可，其他应用无法访问这些文件。
ChatGPT 和 Codex 会在 48 小时后删除这些事件文件。

计算机使用记录生成的本地记忆与 Codex 相同，即您可以读取和修改的纯文本
Markdown 文件。这些文件存储
在 `$CODEX_HOME/memories/extensions/skysight/` 下，该路径通常解析为
`~/.codex/memories/extensions/skysight/`。

### 哪些数据会与 OpenAI 共享？

计算机使用记录会在本地采集交互事件，然后定期启动一个可访问交互事件流的临时 Codex 会话，将您的活动汇总成记忆。

OpenAI 会在其服务器上处理临时事件文件以生成记忆，随后将这些记忆存储在您的 Mac 本地。除非法律要求，否则 OpenAI 在处理完成后不会保留这些事件文件。OpenAI 不会将这些事件文件用于训练。

当 ChatGPT 或 Codex 在后续聊天中使用记忆时，相关记忆内容
和交互事件可能被纳入上下文。这些聊天内容可能会
用于改进 OpenAI 模型，但前提是您的
[ChatGPT 数据控制设置](https://help.openai.com/en/articles/7730893-data-controls-faq)允许。
这些记忆同样遵循
[与其他 Codex 记忆相同的聊天级别控制](/zh-Hans/codex/customization/memories#control-memories-per-chat)。

### 提示注入风险

计算机使用记录会增加应用和网站内容引发提示注入的风险。例如，如果您访问的网站含有恶意指令，ChatGPT 或 Codex 可能会遵循这些指令。

## Token 使用量

计算机使用记录在汇总活动和创建记忆时会消耗 Token。

## 故障排除

如果计算机使用记录可用但无法启动：

1. 确认 **记忆** 已开启。
2. 打开 **设置 \> 计算机使用记录** ，然后根据显示的状态选择 **完成设置**、 **恢复**
   或 **重试**。
3. 如果该设置仍不可用，请退出并重新打开 ChatGPT 桌面应用。
