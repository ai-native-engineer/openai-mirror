## 在浏览器中使用侧边聊天

Chrome、Edge、Brave 和 Vivaldi 支持侧边聊天。

在您正在浏览的页面旁打开 ChatGPT，即可询问页面相关问题，或进一步让它结合页面上下文、本地文件和已连接应用执行任务。任务需要时，ChatGPT 可以使用您已打开标签页中的上下文。

1. 打开您要使用的页面。
2. 从浏览器工具栏或 **扩展程序** 菜单中选择 ChatGPT。在 macOS 上，
   您也可以按 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>.</kbd>。
3. 询问页面相关问题，或向 ChatGPT 分配任务。

面板会保留在您打开它的标签页旁。在侧边聊天中发起的聊天也可以在 ChatGPT 应用中访问，您还可以在侧边聊天中打开最近的 ChatGPT 聊天，因此能在任一位置继续处理任务。

  

## 将标签页和所选文本添加到聊天中

如果您希望 ChatGPT 将某个页面用作上下文，请在桌面应用中提及已打开的相应浏览器标签页。在支持侧边聊天的浏览器中，您也可以在侧边聊天中提及标签页，或选中页面上的文本并将其添加到聊天中，无需复制整个页面即可询问特定段落的相关问题。

在支持侧边聊天的浏览器中，您还可以右键单击页面并选择
**询问 ChatGPT**。侧边聊天会随即打开并带入相关页面上下文，以便您
在浏览器中继续提出请求。

### 询问 YouTube 视频相关问题

打开 YouTube 视频，然后在支持此功能的侧边聊天中询问相关问题。如果视频有字幕，ChatGPT 可以使用带时间戳的视频文字稿来解释、总结内容或回答相关问题。

请将网页内容、所选文本和视频文字稿视为不可信的上下文。在让 ChatGPT 使用这些信息或据此执行操作前，请先检查页面以及请求的所有权限。

## 设置浏览器

在计算机上安装浏览器，然后在 ChatGPT 桌面应用中打开 **设置 \> 计算机使用** 。
如果您的浏览器未显示在主列表中，
请展开 **更多浏览器** 。

1. 选择您的浏览器，并按照提示安装所需插件。
2. 选择浏览器旁的 **安装** ，打开其扩展程序商店页面。
   安装 ChatGPT 扩展程序，并检查浏览器的权限提示。
3. 返回 **计算机使用** ，确认浏览器旁显示 **管理**。
4. 开始 ChatGPT Work 或 Codex 聊天，然后通过
`@` 提及功能选择您的浏览器。请使用安装了扩展程序的浏览器配置方案。

**计算机使用** 中浏览器的开关控制该浏览器是否显示在
`@` 提及菜单中。如需更改网站权限，请选择 **管理** 。

## 控制网站访问权限

默认情况下，ChatGPT 在与每个新网站交互前都会询问。
ChatGPT 会根据网站主机（例如 `example.com`）显示相应提示。

当 ChatGPT 请求使用网站时，您可以根据任务需求和自己的风险承受能力选择相应选项：

- **允许一次** ：让 ChatGPT 仅使用该网站一次。
- **允许此网站** ：让 ChatGPT 再次使用该网站时无需询问。
- **允许所有网站** ：让 ChatGPT 无需询问即可使用网站。
- **拒绝** ：阻止 ChatGPT 使用该网站。

### 管理允许和阻止的网站

在 ChatGPT 桌面应用中，前往 **设置** \> **计算机使用**，然后选择浏览器旁的
**管理** ，以管理域名的允许列表和阻止列表。
允许列表包含 ChatGPT 无需再次询问即可使用的域名。
阻止列表包含 ChatGPT 不应使用的域名。受支持的浏览器
共用这些网站权限。

从允许列表中移除域名后，ChatGPT 使用该域名前会再次询问。从阻止列表中移除域名后，ChatGPT 可以再次询问，而不再将该域名视为已阻止。

#### 允许所有网站 

如果您选择 **允许所有网站**，ChatGPT 在使用网站前将不再请求确认。
仅当您放心让 ChatGPT 使用浏览器中打开的
任何网站时，才选择此选项。

#### 浏览记录 

浏览记录可能包含敏感的遥测数据、内部 URL、搜索词，以及已登录设备上浏览器会话中的活动。如果您允许 ChatGPT 访问浏览记录，相关记录可能成为 ChatGPT 执行任务时所用上下文的一部分。恶意或误导性的页面内容可能增加 ChatGPT 将这些数据复制到非预期位置的风险。

ChatGPT 需要使用浏览记录时会先询问。ChatGPT 会将浏览记录的访问范围限定为当前请求，且浏览记录没有“始终允许”选项。

## 数据和安全

<a id="chrome-extension-permissions"></a>

### 浏览器扩展程序权限

安装扩展程序时，浏览器会要求您接受权限请求。例如，Chrome 的权限提示可能包括：

- 访问页面调试器
- 读取和更改您在所有网站上的所有数据
- 读取和更改您在所有已登录设备上的浏览记录
- 显示通知
- 读取和更改您的书签
- 管理您的下载内容
- 与配套的本机应用通信
- 查看和管理您的标签页组

这些权限让扩展程序能够执行浏览器工作流。ChatGPT 在任务中使用网站或浏览历史记录前，仍会应用自身的确认机制、设置、允许列表和阻止列表。

### 记忆

计算机使用遵循您的记忆设置。如果开启了记忆，ChatGPT 在您的浏览器中执行任务时可以使用相关的已保存记忆。如果关闭了记忆，浏览器控制就不会使用记忆。

### OpenAI 会存储哪些浏览数据

OpenAI 不会单独存储来自扩展程序的完整浏览器操作记录。OpenAI 只会存储纳入 ChatGPT 上下文的浏览器活动，例如 ChatGPT 从页面读取的文本、屏幕截图、工具调用、摘要、消息或聊天中包含的其他内容。

您的 ChatGPT 数据控制设置适用于在上下文中处理的内容。除非确有需要，且您在场审查每个提示，否则请避免通过浏览器任务发送机密信息或高度敏感的数据。

## 故障排除

如果 ChatGPT 无法连接到您的浏览器，请先确认它尝试访问的网站不在“设置”的阻止列表中。如果网站未被阻止，请依次进行以下检查：

1. 更新 ChatGPT 桌面应用。如果您安装了多个 ChatGPT 或 Codex 桌面应用，请逐一更新，或移除不再使用的副本。
2. 重启浏览器。在 Chrome、Edge、Brave 或 Vivaldi 中，
   从工具栏或 **扩展程序** 菜单重新打开 ChatGPT，并确认侧边聊天能够加载。
   Opera 没有侧边聊天功能，请在桌面应用中检查其连接。
3. 在 **设置 \> 计算机使用**中，确认列表中有您的浏览器，且显示
**管理**。如果仍显示 **安装**，请重新完成设置流程。
   如果浏览器未出现在 `@` 提及菜单中，请开启它的开关。
4. 确保您使用的是已安装扩展程序的浏览器配置方案。如果您使用多个配置方案，请在当前使用的配置方案中安装并启用扩展程序。
5. 新建 ChatGPT Work 或 Codex 聊天，然后再次尝试浏览器任务。这可以清除与该聊天关联的连接状态。
6. 重启 ChatGPT 桌面应用，然后重试。如果扩展程序仍无法连接，
   请通过 **设置 \> 计算机使用**重新安装。
7. 如果 ChatGPT 仍无法使用浏览器，请在应用中运行 `/feedback`，
   并在联系支持团队时提供聊天 ID。

### 上传文件

如果 Chrome 任务需要从您的计算机上传文件，请在 Chrome 中允许 Chrome 扩展程序访问文件 URL：

1. 在 Chrome 中，点击工具栏中的扩展程序图标，然后点击 **管理
   扩展程序**。
2. 在扩展程序卡片上，点击 **详细信息**。
3. 开启 **允许访问文件网址**。

更改设置后，重新启动 Chrome 任务。
