技能和插件可通过适当的
指令、资源和工具，帮助 ChatGPT 和 Codex 完成可重复执行的工作。这样一来，您无需在每次聊天中粘贴
相同的提示、模板、要求或流程。

- 一项 **技能** 会将特定
  任务或工作流所需的指令和配套资源打包在一起。
- 一个 **插件** 是可安装的套件，可包含技能、连接器或
  二者。连接器由模型上下文协议（MCP）服务器提供支持，也可
  选择包含自定义 ChatGPT 界面。

## 使用技能完成重复性工作

技能是一种可复用的工作流，可为 ChatGPT 或 Codex 提供针对特定任务的
指导。它可以记录您目前处理周期性工作的方式，使任一
产品每次遇到该任务时都遵循相同流程。

技能可以包含：

- 名称和说明，帮助 ChatGPT 和 Codex 判断该技能何时
适用。
- 定义流程和预期结果的工作流指令。
- 配套资源，例如模板、示例、品牌指南、模式，
或已连接的工具。

当良好结果有赖于可重复执行的方法时，技能最为实用。
例如，技能可以编写每日简报、审查文档、制作
演示文稿、应用团队写作规范，或每周从相同的
已连接工具中收集信息。

使用技能可提高一致性、将团队最佳实践融入
工作流，并共享标准流程，而不必依赖未记录的
知识。

当您的请求与某项技能的用途相符时，ChatGPT 和 Codex 可以选择该技能。您
也可以明确选择技能。ChatGPT 支持使用 `@` 提及技能，而 Codex
支持使用 `$` 提及技能。

## 构建技能

您可以先把一项经常重复的任务整理为适用于
ChatGPT 和 Codex 的专用操作手册。适合首次构建的技能包括每周更新、营销活动简报、
会议跟进，或任何需要让步骤和格式保持
一致的任务。

要构建实用的技能：

1. **选择一项具体任务。** 记下您通常会从哪些内容入手，例如
   文件、链接或笔记，以及最终结果应是什么样子。
2. **描述工作流。** 在 ChatGPT 中，先使用 `@skill-creator`；在 Codex 中，
   使用 `$skill-creator`。说明目标、要遵循的步骤、预期
   格式，以及该技能应始终包含的内容或应避免的事项。如果您有模板
   或合适的示例，也请添加。
3. **审查并试用草稿。** 检查指令，并使用贴近实际的请求测试技能；
   如果结果遗漏某个步骤或偏离您希望的格式，
   请进一步完善技能。
4. **安装并复用该技能。** 技能启用后，ChatGPT 或 Codex 即可针对
   相关请求使用该技能，您也可以明确选择它。如果工作空间设置允许，您还可以
   将其分享给团队成员。

## 使用插件集成工具并共享工作流

插件让可复用功能更易于安装和共享。插件可以
将技能与 GitHub、Google Drive 或
Slack 等服务的连接器结合起来，还可包含 MCP 服务器，以提供更多工具和上下文。

ChatGPT 和 Codex 共用一个通用插件目录。如果您希望添加
现有工作流而不是自行构建，可浏览该目录。安装
插件后，您可以直接描述任务，也可以使用当前界面的调用语法，明确选择插件或其中包含的
技能。

[了解如何安装和使用插件](/zh-Hans/codex/plugins)。

## 选择技能还是插件

当您需要针对一项具体任务的可复用指令时，请使用技能。当您希望使用
一种可安装的套件，将指令与已连接的服务或
其他工具组合起来时，请使用插件。

您还可以使用
[录制与重放](/zh-Hans/codex/extend/record-and-replay)，借此演示工作流；该功能会将录制内容转化为
可复用的技能。要打包并分发您自己的套件，请参阅
[构建插件](https://developers.openai.com/plugins/build/plugins)。

如果您的插件需要连接服务或对外提供 MCP 工具，请参阅
[构建 MCP 服务器](https://developers.openai.com/plugins/build/mcp-server)。当您的插件准备好接受公开审查时，
请参阅 [提交插件](https://developers.openai.com/plugins/deploy/submission)。

有关可复用工作流的更多示例，请参阅 [在 OpenAI
Academy 中使用技能](https://openai.com/academy/skills/)。
