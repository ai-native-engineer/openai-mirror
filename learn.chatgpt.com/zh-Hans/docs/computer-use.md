在受支持的地区，您可以在 macOS 和 Windows 的 ChatGPT 桌面应用中，通过 ChatGPT Work 和 Codex 使用计算机使用功能。请安装计算机使用插件。在 macOS 上，请在系统提示时授予“屏幕录制”和“辅助功能”权限。

通过计算机使用，ChatGPT 可以查看和操作 macOS 或 Windows 上的图形用户界面。当命令行工具或结构化集成不足以完成任务时，可使用此功能，例如检查桌面应用、使用浏览器、更改应用设置、处理无法通过插件访问的数据源，或重现仅在图形用户界面中出现的错误。

计算机使用可能影响您项目工作空间之外的应用和系统状态，因此请将其用于范围明确的任务，并在继续操作前审查权限提示。

## 设置计算机使用

在 ChatGPT 桌面应用中，选择 ChatGPT 并在切换器中切换到 Work，或选择
Codex。打开 **插件 \> 计算机
使用** ，并在出现提示时选择 **安装插件** 。如果 ChatGPT 显示 **启用**，
请选择该选项。打开计算机使用服务器和技能的开关，然后选择 **立即
试用** 以开始使用。

  

然后打开 **设置 \> 计算机使用** ，查看应用访问权限。已连接浏览器的控件
会显示 **管理** 操作。您批准供后续任务使用的应用会显示在
 **始终允许的应用** 部分。

  

在 Windows 上，请确保目标应用在任务运行期间始终显示在活动桌面上。在 macOS 上，请在系统提示时授予“屏幕录制”和“辅助功能”权限，以便 ChatGPT 查看目标应用并与之交互。

在 macOS 上，请授予以下权限：

- **屏幕录制** 权限，让 ChatGPT 能够查看目标应用。
- **辅助功能** 权限，让 ChatGPT 能够点击、输入和导航。

## 计算机使用的适用场景

对于依赖屏幕截图或视觉判断的复杂任务，
如果您的模型选择器中提供了 [GPT-6 Astra](/zh-Hans/codex/models#gpt-6-astra)，
请选择该模型。同样的插件设置、操作系统权限和应用访问
控制仍然适用。

如果任务依赖图形用户界面，且仅凭文件或命令输出难以验证，请选择计算机使用。

适用场景包括：

- 测试 macOS 应用、Windows 应用、iOS 模拟器流程，或 ChatGPT 正在构建的其他桌面应用。
- 执行需要使用您网页浏览器的任务。
- 重现仅在图形界面中出现的错误。
- 更改需要通过点击用户界面来调整的应用设置。
- 查看无法通过插件访问的应用或数据源中的信息。
- 在 macOS 上，在后台运行范围明确的任务，同时继续处理其他工作。
- 执行跨多个应用的工作流程。

对于您在本地构建的 Web 应用，请优先使用
[内置浏览器](/zh-Hans/codex/browser?surface=app)。

### 在 Windows 前台使用

在 Windows 上，计算机使用在活动桌面运行。您无法在它于后台运行的同时继续使用同一 Windows 会话，因此请注意，任务运行期间，ChatGPT 会移动指针、输入内容并接管前台操作。

如果 Windows 任务需要在您离开时继续运行，请让 Windows
设备保持解锁并连接互联网。您可以通过手机使用
[远程控制](/zh-Hans/codex/remote-connections)查看进度
或发送后续指令，也可以在 Windows 虚拟机中运行 ChatGPT 桌面应用，
让计算机使用接管虚拟机而不是您的主桌面。

## 权限与审批

工作空间管理员可以限制计算机使用能访问哪些应用，
以及是否可以保存审批决定。请参阅
[浏览器和计算机使用的托管控制](/zh-Hans/codex/enterprise/managed-configuration#control-browser-and-computer-use)。

计算机使用所需的系统权限与 ChatGPT 中的应用审批相互独立。在 macOS 上，“屏幕录制”和“辅助功能”权限让 ChatGPT 能够查看和操作应用。应用审批决定您允许 ChatGPT 使用哪些应用。文件读取、文件编辑和 Shell 命令仍须遵循任务的沙盒与审批设置。

通过计算机使用，ChatGPT 只能查看并操作您允许的应用。
任务执行期间，ChatGPT 必须先征得您的许可，才能使用您电脑上的应用。
您可以选择 **始终允许** ，让 ChatGPT 今后使用该应用时
无需再次询问。您可以从 **始终允许** 列表中移除应用；该列表位于 ChatGPT 桌面应用设置的
**计算机使用** 部分。

  
    
  

ChatGPT 也可能在执行敏感或可能造成干扰的操作前请求您的许可。

如果 ChatGPT 无法查看或控制应用，请在 macOS 上打开 **系统设置 \> 隐私与
安全性** ，检查 **屏幕录制** 和 **辅助功能** 中 **Codex
计算机使用** 的权限。在 Windows 上，请确保目标应用在
活动桌面会话中可见。

在 Windows 上，计算机使用会将长期有效的应用权限决定保存在
`$CODEX_HOME/config.toml` 中。请列出计算机使用无需询问
即可打开的应用：

```toml
[computer_use.windows]
always_allowed_app_ids = ["mspaint.exe"]

请使用 Windows 计算机使用功能报告的应用标识符，例如桌面应用的可执行文件名，
或打包应用的应用用户模型 ID。
对于不在列表中的应用，ChatGPT 会请求您的许可。要撤销已保存的决定，请从
 **设置 \> 计算机使用 \> 始终允许**中移除该应用。

此表存储本地计算机使用权限决定。它与管理员强制执行的
`requirements.toml` 相互独立；管理员可以在该文件中
通过 `[features].computer_use = false` 禁用计算机使用。旧版
`$CODEX_HOME/computer-use/config.toml` 中的允许列表条目会迁移到
当前设置；其中的 `denied` 列表不属于当前策略模式。

## 锁定状态下使用

  锁定状态下使用适用于 macOS。在 Windows 上，计算机使用在前台运行。

只有启用锁定状态下使用后，ChatGPT 才能在您的 Mac 锁定后调用计算机使用功能。如果 ChatGPT 任务需要在 Mac 锁定后通过已连接的设备使用桌面应用，请使用此功能。

启用锁定状态下使用后，ChatGPT 会安装 Apple
[授权插件](https://developer.apple.com/documentation/security/authorization-plug-ins)，
该插件会参与 macOS 解锁流程。

锁定状态下使用的适用范围在设计上受到严格限制。它不是 Mac 的通用远程解锁方式，也不会让其他应用或本地进程解锁电脑。

锁定状态下使用的操作步骤：

1. 在应用中打开 **设置 \> 计算机使用** 。
2. 启用锁定状态下使用。
3. Mac 屏幕锁定后，请从已连接的设备启动一项使用计算机使用功能的任务。

Mac 锁定后，当 ChatGPT 任务通过计算机使用访问应用时，ChatGPT 会临时解锁 Mac，同时阻止本地操作并维持锁屏保护。解锁前，ChatGPT 会检查此次解锁尝试是否用于正在进行且受信任的计算机使用轮次。在该短暂授权窗口之外，ChatGPT 会拒绝解锁，并在需要时要求您手动解锁。

锁定状态下使用包含以下安全措施：

- 授权窗口持续时间很短，且仅适用于当前的解锁尝试。
- 自动解锁仅供 ChatGPT 在正在进行的计算机使用轮次中使用。
- 桌面暂时解锁期间，ChatGPT 会遮蔽所有显示器的画面。
- 如果 ChatGPT 检测到本地键盘或指针输入，会重新锁定 Mac，并暂停自动解锁，直到您手动解锁。

## 安全指南

通过计算机使用，ChatGPT 可以查看屏幕内容、截取屏幕截图，并与目标应用中的窗口、菜单、键盘输入和剪贴板状态交互。请将可见的应用内容、浏览器页面、屏幕截图以及在目标应用中打开的文件，视为 ChatGPT 在任务运行期间可能处理的上下文。

请限制任务范围，并在涉及敏感操作的流程中全程在场：

- 每次只为 ChatGPT 指定一个明确的目标应用或操作流程。
- 您可以随时停止任务或接管计算机。
- 除非任务需要，否则请关闭敏感应用。
- 在 Windows 上，ChatGPT 工作时会接管前台输入；请使用另一台设备或虚拟机，或者在您亲自使用该桌面前停止任务。
- 除非您在场并且能够审批每个步骤，否则请避免执行需要机密信息的任务。
- 在允许 ChatGPT 使用应用之前，请审查应用权限提示。
- 仅当您放心让 ChatGPT 在后续任务中自动使用某个应用时，
  才选择 **始终允许** 。
- 涉及账户、安全、隐私、网络、付款或凭据相关设置时，请全程在场。
- 如果 ChatGPT 开始与非目标窗口交互，请取消任务。

如果 ChatGPT 使用您的浏览器，它可以与您已登录的页面交互。请像亲自操作时一样审查网站操作：网页可能包含恶意或误导性内容，而网站可能会将已获批准的点击操作、表单提交以及登录状态下的操作视为由您的账户发起。若要在 ChatGPT 工作期间继续使用您的浏览器，请让 ChatGPT 使用其他浏览器。

此功能无法自动操作终端应用或 ChatGPT 本身，因为自动操作它们可能会绕过 ChatGPT 的安全策略。它也无法以管理员身份进行身份验证，或批准您计算机上的安全和隐私权限请求。

在适用的情况下，文件编辑和 shell 命令仍须遵循 ChatGPT 的审批和沙盒设置。通过桌面应用所做的更改，在保存到磁盘并纳入项目跟踪之前，可能不会显示在审查窗格中。您的 ChatGPT 数据控制适用于通过 ChatGPT 处理的内容，包括由计算机使用功能截取的屏幕截图。
