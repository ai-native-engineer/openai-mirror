ChatGPT 工作空间的使用限额和支出控制适用于该工作空间方案下符合条件的活动。根据方案不同，可能涵盖部分 Codex 活动。这些控制措施并非通用的 Codex 限额体系，也不管控 OpenAI API 平台的计费。

如需了解完整的管理模式，请参阅
[角色与工作空间权限](/zh-Hans/codex/enterprise/roles-and-workspace-permissions)。

## 了解这些控制措施的适用情形

在以下情况下，请审查 ChatGPT 工作空间的用量控制措施：

- 组织依据协议使用共享或购买的 ChatGPT 工作空间额度。
- 符合条件的 Codex 活动可能会消耗这些额度。
- 管理员需要当前方案支持的用户使用限制、工作空间级支出控制或用量通知。

用量控制不用于配置功能使用资格或权限，但用量达到上限时，可能会暂停对符合条件的功能的访问。这些控制措施不会影响源系统的权限，也不管控平台 API 的使用或计费。
