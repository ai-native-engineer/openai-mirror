ChatGPT Work 帮助员工完成多步骤任务，例如研究某个主题、分析信息，或制作完整的文档或演示文稿。完成这些任务可能需要更多推理、工具使用和处理工作，因此可能消耗额度。这些用量是否影响您的发票金额，取决于您的剩余额度、合约费率和工作空间超额使用设置。

通过本指南，您可以了解 Work 如何影响用量、规划向员工推广使用，并采用您所在组织可用的支出控制措施。

## 用量与费用概览

- 对于符合条件的额度制协议，Work 活动会消耗工作空间的共享额度。
- 消耗合约承诺额度并不等同于产生新的开票费用。
- 员工可以同时使用聊天和 Work；估算推广后的用量时，请综合评估两者符合条件的用量。
- 按岗位进行的估算可辅助规划，但并非固定的每用户价格，也不保证实际计费金额。
- 用户用量限额和工作空间超额使用限额是两项独立的控制措施。提醒只会发出通知，不会阻止支出。
- 请根据您所在组织观测到的用量和可衡量的工作流程成果，评估推广情况。

## 为什么 Work 会消耗额度

对于签订了额度制协议的组织，符合条件的 Work 活动会消耗分配给工作空间的共享额度。其他符合条件的 ChatGPT 功能也可以使用同一份额度，因此 Work 不一定有单独的额度余额。

额度消耗量会随以下因素而变化：

- 模型、执行环境，以及适用的推理或速度设置。
- 任务的复杂程度，以及使用了哪些符合条件的工具或功能。例如，使用经批准且员工获准访问的应用和系统中的 CRM 记录、文档或消息，编制季度业务回顾。
- 员工运行任务的频率。

员工开始使用 Work 后，无需停止使用聊天。要了解总消耗量的变化，请将同一批员工此前的聊天用量，与可比时间段内聊天和 Work 的合计用量进行比较。

您的协议和适用价目表决定每项符合条件的活动消耗多少额度。现有的订阅费或席位费与额度消耗估算分开计算。

### 了解 Token 和额度

**Token** 用于衡量模型读取和写入的信息，包括输入、
缓存输入和输出。在额度制协议下， **额度** 从工作空间的共享配额中扣除，
用于支付符合条件的用量。有关额度定价，请参阅
[Token 费率](/zh-Hans/codex/pricing#token-rates)。

如果您的企业协议规定按用量以美元计费，请以 <a href="https://help.openai.com/en/articles/20001415-chatgpt-rate-card-enterprise-token-based-pricing" target="_blank" rel="noopener noreferrer">企业美元价目表</a>和您的协议为准。请勿将额度计算方式用于以美元计费的工作空间，也不要将已消耗的额度视为发票上的额外费用。

## 用量何时会影响您的账单

符合条件的 Work 用量是否产生额外费用，取决于您的协议、剩余额度和适用的计费设置。使用合约承诺额度会减少可用余额，但这一行为本身不会产生新的开票费用：

- **仍有合约承诺额度：** 符合条件的活动会消耗已分配的可用额度。
  使用这些额度本身不会
  产生现有协议之外的新费用。
- **额度已用尽，且您的账户允许超额使用：** 符合条件的使用可以
  在已配置的工作空间超额使用限额内继续，
  并可能按合约规定的超额使用费率计费。
- **额度已用尽，且您的账户不允许超额使用：** 符合条件的功能
  可能暂停，直到有可用额度
  或适用限额发生变化。

超额使用的处理方式取决于账户是否符合条件，以及已配置的
工作空间限额。如果您的协议不允许超额使用，
则符合条件的使用会在可用额度耗尽时停止。如果您的账户允许超额使用，
未设置限额可能会允许符合条件的用量超出额度余额。在支持此设置的情况下，
将超额使用限额设为零可阻止工作空间继续超额使用，
而 **无限制** 并不意味着将支出限制为零。

用量报告和美元金额估算是规划或监控工具，并非已开具的发票。部分显示的估算值采用合约规定的超额使用费率，该费率可能与合约承诺额度的费率不同。请对照发票、计费周期和您所在组织的协议条款，核实实际费用。

## 估算岗位或团队的用量

按岗位进行的估算有助于为职责相近的员工规划推广使用，例如财务、市场营销或销售人员。请先确定您所在组织计划支持的员工和工作流程。

请按以下步骤进行估算：

1. 确定拟使用的用户群体，并选取一段可供比较的现有聊天使用期。
2. 根据观测到的试点用量，或经批准且相关的岗位基准，估算聊天和 Work 的合计消耗量。
3. 查看剩余的合约承诺额度。对合约承诺额度和任何超额用量，分别采用适用的合约费率。
4. 判断预计用量是否在可用额度范围内，或是否可能触发合约中的超额使用条款。
5. 根据实际推广使用情况、任务构成和观测到的消耗量，更新估算。

经批准的基准可能反映企业客户的实际观测用量和实际使用的模型组合。其参考价值取决于比较时段、岗位分类、工作流程和账户相关假设。宽泛的岗位估算不能作为特定行业或特定任务的基准。

**额度消耗金额的年化估算值** 是根据观测到的用量金额推算出的全年数值。
它不是单独的 Work 许可价格或标准的按用户收费金额，
不是 OpenAI 的基础设施成本，也不表示预计您的发票金额
会增加同等数额。实际新增费用取决于剩余的合约承诺额度、
合约定价、允许的超额使用情况和计费周期。

### 市场营销岗位规划示例

一项针对首次使用 Work 的企业市场营销员工的实际用量分析显示，额度消耗金额的年化值出现了以下变化：

- **中位数：** 约为 **每位员工每年 $53**。
- **第 90 百分位数：** 约为 **每位员工每年 $1,154**。
- **平均值：** 约为 **每位员工每年 $309**。

中位数表示观测到的个人用量的中间水平。少数员工消耗的额度较多，因此平均值更高。第 90 百分位数表示观测到的较高用量阈值，并非支出上限或最大值。

对于用量构成类似的 **100 名员工** ，按 **每位员工平均
$309** 计算，约为 **每年 $30,900**，或
**折合每月 $2,575，供规划参考**。

这些参考性估算反映了观测到的企业客户用量及其实际模型组合，由推广使用期间一周的用量年化推算而来。它们不是对节省金额的保证、固定的每用户价格或自动产生的账单，也不表示您的发票金额一定会相应增加。实际费用取决于剩余的合约承诺额度、合约费率和允许的超额使用情况。

负责您账户的团队可以结合您所在组织的协议，帮助解读经批准的估算。

## 管理员控制措施与报告

工作空间所有者和管理员可以使用受支持的设置，管理访问权限和符合条件的额度制用量：

- **Work 访问权限：** 通过工作空间可用的权限设置，
  选择哪些人员或群组可以访问 Work。
- **模型和速度设置：** 如果支持相关设置，可在“工作空间设置 \> 模型”中配置 Work &
  Codex 的初始模型、推理级别、速度，以及快速模式是否可用。
  对于受支持的模型，快速模式可能会消耗更多额度。
- **用户用量限额：** 使用受支持的设置，配置工作空间每月默认限额、
  群组限额或个人覆盖设置，以管理每位用户符合条件的用量。
- **工作空间超额使用限额：** 控制共享额度耗尽后，
  还可以继续产生多少符合条件的用量。
- **用量提醒：** 在支持相关设置的情况下，在“账单”中配置可用的用量阈值和
  接收人。提醒只会发出通知，不会阻止支出。
- **额度余额与报告：** 在“账单”中查看剩余额度，
  并下载您的角色有权访问的用量报告。如果您的协议包含
  合约承诺额度，请将观测到的用量与合约分配额度及
  计费周期进行对照，以评估额度消耗进度。
- **发票：** 如果您的工作空间角色具有发票访问权限，
  请查看已开具的发票及其对应的计费周期。

个人用户的覆盖设置优先于群组和工作空间的默认设置。当用户属于多个群组时，以适用的群组限额中最高的为准。群组未配置限额，并不意味着将额度上限设为零。请检查每位试点参与者实际生效的限额。

用量限额不会增加额度，也不决定谁可以访问 Work。模型默认设置或员工使用指导可以影响额度消耗，但都不能替代强制执行的用量限额或工作空间超额使用设置。

控制项的可用性、报告的详细程度、发票访问权限和计费方式
取决于您的套餐、工作空间配置和协议。报告可能不会
立即反映使用活动；在将用量与发票进行核对之前，
请先核对报告时间戳和计费周期。有关跨产品适用范围和
当前的设置步骤，请参阅
[ChatGPT 用量限额与支出控制](/zh-Hans/codex/enterprise/usage-limits)。

## 结合成果衡量用量

选择一个已有明确基线、需要反复执行的工作流程，例如客户调研、会议准备或财务报告。请采用适合该工作的访问权限、工具和模型能力，不要假定每项任务都需要最先进的选项。

试点期间，请比较引入 Work 前后同一工作流程的表现。根据具体任务，您所在组织可以衡量以下指标：

- 完成工作所需的时间。
- 输出的质量、完整性或一致性。
- 返工、人工协调或错误率。
- 团队是否完成了预期的交付成果。

结合观察到的额度消耗和对账单的实际影响，评估这些由客户衡量的成效。仅凭用量无法证明节省了成本，预计的时间效率提升也不保证带来财务回报。

## 先在可控范围内推广

扩大开放范围前：

1. 核实您的协议条款、剩余额度、适用费率和超额使用设置。
2. 选择一小组用户和一个您所在组织能够评估的工作流程。
3. 配置受支持的访问权限、用户用量上限、提醒和工作空间超额使用上限。
4. 将聊天和 Work 的额度消耗总量与该用户群体的现有基线进行比较。
5. 在扩大推广范围之前，评估观察到的成效以及对账单的实际影响。

有关访问权限、数据、治理和推广的更全面指导，请参阅
[ChatGPT Work 管理员常见问题](/zh-Hans/codex/enterprise/work-admin-faq)。有关
您合同所涉及的定价、可用额度和发票开具问题，
请联系您的客户团队。
