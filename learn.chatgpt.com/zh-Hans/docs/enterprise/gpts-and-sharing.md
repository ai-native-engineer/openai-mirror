## 共享

控制哪些人可以创建 GPTs，以及这些 GPTs 是否可以与特定人员、群组或整个工作空间共享。

  GPT 创建者可以使用已连接的应用或自定义操作，但不能在同一个 GPT 中同时使用两者。

## 已连接应用与操作

允许 GPT 创建者使用经批准的工作空间应用，或配置与获准的第三方 API 交互的操作。访问仍受工作空间策略、用户权限及已批准域名的限制。

## 域名

将 GPT 操作限制在经批准的外部域名范围内，以控制工作空间中创建的 GPTs 可以访问哪些第三方 API。如果没有允许访问的域名，自定义 GPT 操作将无法执行。

  域名审批不能替代 API 身份验证或用户授权。

## 管理 GPTs

审查工作空间中创建的 GPTs，管理共享与所有权，并在适当时删除 GPTs。管理视图根据是否已分配所有者对 GPTs 进行分类，并包含以下信息：

- 名称
- 创建者
- 自定义操作
- 可访问人员
- 聊天
- 创建时间
- 更新时间
