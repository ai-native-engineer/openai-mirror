## 设置 Codex Micro

1. 打开 ChatGPT 桌面应用。
2. 按一下背面的按钮，开启 Codex Micro。
3. 用 USB-C 线缆连接它，或 [通过蓝牙进行配对](#pair-with-bluetooth)，
   然后按照 ChatGPT 检测到设备时显示的设置流程操作。
4. 在 macOS 上，系统提示时请允许 **输入监控**，以便 ChatGPT 响应
   按键操作。
5. 打开 **设置 \> Codex Micro**，选择 Agent 键要跟踪的聊天或
   要触发的操作，自定义命令键、模拟摇杆和旋钮，并调整
   灯光和语音控制项。

默认情况下，按住旋钮片刻即可打开这些设置。您
也可以选择 ChatGPT 底部您账户名称旁边的 Micro 图标。
为旋钮分配自定义操作后，该操作可以取代长按快捷方式。

ChatGPT 首次检测到受支持的 Micro 后，
设备设置仍然可用。ChatGPT 集成无需 Work Louder Input。
您可以使用它自定义其他应用的控制项或配置更多层。

## 通过蓝牙配对

Codex Micro 提供三个蓝牙通道。

1. 按一下背面的按钮，开启 Micro。
2. 按住左下边缘的触控区三秒钟。
蓝牙模式启用时，Micro 下方的灯光会变为蓝色。
3. 轻触触控区，选择蓝牙通道 1、2 或 3。通道指示灯快速闪烁
表示 Micro 已准备好配对。
4. 打开您电脑上的蓝牙设置，并在 Micro
出现时连接它。
5. 等到通道指示灯常亮，即表示配对完成。

如果五秒内没有操作，连接选择器会关闭。要切换到
另一个已配对的通道，请再次打开选择器，选择该通道并等待
选择器关闭。要重新配对该通道，请按住触控区
三秒钟，直到该通道的指示灯开始闪烁。

如要改用 USB-C，请打开连接选择器并轻触触控区，
直到 Micro 下方的灯光变为白色。如果在 Micro 仍处于蓝牙模式时
连接 USB-C 线缆，只会为其充电，并不会将其切换到
有线连接。

如需查看硬件图示，请参阅 [Work Louder Codex Micro 设置
指南](https://worklouder.cc/openai-micro-setup)。

## 使用 Agent 键查看和切换聊天

六个磨砂材质的 Agent 键均可跟踪一个聊天，并亮起以显示其
当前状态。按一下 Agent 键即可切换到相应聊天，而不会将
ChatGPT 窗口移至前台。在 350 毫秒内连按两下该键，可切换聊天并
将 ChatGPT 窗口移至前台。如果希望按一下就让 ChatGPT 获得焦点，请在设备设置中开启
**轻触一次即可聚焦 ChatGPT**。

| 灯光 | 状态           | 含义                                   |
| ----- | ---------------- | ----------------------------------------- |
| 白色 | 空闲             | 聊天处于空闲状态。                         |
| 蓝色  | 思考中         | ChatGPT 正在工作。                       |
| 绿色 | 已完成         | 聊天已完成，并有未读更新。 |
| 琥珀色 | 需要输入   | ChatGPT 需要您的审批或回复。  |
| 红色   | 错误            | 出现了问题。                     |
| 熄灭   | 未分配聊天 | 该按键未跟踪任何聊天。            |

所选聊天对应按键的状态灯会脉动闪烁。

默认情况下，这些按键会跟踪最近更新的六个聊天，无论
它们是否已固定。在设备设置中更改 **Agent 键**，即可使用
其他排列方式：

- **最近的聊天**：跟踪最近更新的六个聊天，包括已固定和
  未固定的聊天。
- **固定的聊天**：跟踪 **已固定** 中的前六个聊天。
- **优先聊天**：将等待输入的聊天、未读聊天和活跃
  聊天排在前面。
- **自定义分配**：为每个 Agent 键分配聊天、快捷方式、物理按键操作或已启用的
  技能。按下未分配的 Agent 键可打开新聊天。
  开始聊天后，ChatGPT 会将其分配给该按键。

跟踪聊天的按键仍使用相同的状态颜色。使用 **自定义
分配** 时，Agent 键可以改为触发操作。

|     | 开启或关闭快速模式。                |
|  | 批准当前请求。             |
|   | 拒绝当前请求。             |
|    | 在新聊天中继续当前聊天。 |
|       | 启动按住说话。                      |
|   | 发送编辑器中的消息。        |

  <div class="min-w-0 md:order-1">

麦克风键使用您计算机的麦克风。Codex Micro 本身没有
麦克风。默认采用**按住说话**：说话时按住该键，
松开即可停止。如需在不持续按住按键的情况下录音，请在 350 毫秒内连续按两次该键，
录音便会持续进行。再次按下该键即可停止。

录音时，青绿色灯光会环绕键盘移动。ChatGPT 处理您的语音时，灯光会变为
移动的白光；提示准备就绪后，则变为常亮白光。
按 Codex 键即可发送该提示。

如果**语音聊天**可在**麦克风键**下使用，请选择该选项，以便使用
麦克风键启动语音聊天或切换麦克风状态；按住该键可
结束聊天。开启**使用单独的麦克风键**，可分别映射宽麦克风键
下方的两个开关。

在设备设置中，从**布局**预览中选择一个命令键，然后
选择其键帽和操作。您可以打开浏览器或终端、管理
聊天、审查更改、执行 Git 和 Pull Request 操作、附加文件或照片、
打开插件或计划任务、更改推理力度、运行已启用的技能，
或分配其他快捷键。如果您选择的键帽已在
其他位置使用，ChatGPT 会对调两个键的键帽，而不会重复使用同一键帽。

重新映射按键后，请更换实体键帽，使其与新操作相符。
选择**重置布局**可恢复命令键和模拟摇杆的默认
分配，而不更改 Agent 键模式或自定义聊天分配。

## 使用模拟摇杆和旋钮

<div class="grid gap-6 md:grid-cols-[minmax(0,1fr)_minmax(16rem,42%)] md:items-start">
  <div class="min-w-0">

模拟摇杆可向任意方向自由移动。当您将它推离中心足够远时，
ChatGPT 会将这一移动转换为四种方向操作之一。
Codex Micro 初始采用如下映射。

在设备设置中，您可以为每个方向选择任一可用的 ChatGPT 桌面版命令，
也可以选择已启用的技能。

  </div>
  <div class="min-w-0 [&_table]:!mt-0">

| 方向 | 默认操作             |
| --------- | -------------------------- |
| 上        | 开启或关闭计划模式。  |
| 右     | 在应用历史记录中前进。 |
| 下      | 显示或隐藏侧边栏。  |
| 左      | 在应用历史记录中后退。    |

  </div>
</div>

旋钮默认使用**编辑器导航**。转动旋钮可依次浏览
编辑器控件和选项，再按下旋钮即可打开或选择当前聚焦的
控件。当编辑器控件或菜单处于打开状态时，旋钮右侧紧邻的 Agent 键会
亮起红灯。按下该键即可取消。

在设备设置中选择以下四种旋钮模式之一：

| 模式                       | 行为                                                                       |
| -------------------------- | ------------------------------------------------------------------------------ |
| **编辑器导航**    | 依次浏览编辑器控件，并选择当前聚焦的控件。                 |
| **仅推理**         | 调整推理力度，并打开对应的滑块或高级选项。               |
| **对话滚动** | 滚动当前聊天；按下旋钮可跳转至最新消息。          |
| **自定义分配**     | 为向左转动、向右转动、按下和长按分别分配操作或技能。 |

在所有模式下，按住旋钮都会打开设备设置，但
**自定义分配**模式除外；在该模式下，长按会执行分配给长按的操作。

## 调整灯光

在设备设置中调整**亮度**，并将**自动调暗**的
间隔设为 30 秒至一小时，或关闭自动调暗。当您操作 Micro，或 Agent 键的
状态发生变化时，灯光会重新亮起。默认情况下，
灯光会在三分钟后熄灭。

以及侧边栏的 Micro 图标旁查看该状态。

## 排查 Codex Micro 问题

### 修复 macOS 上的输入监控问题

如果设备设置显示输入监控尚未设置，请选择**打开
系统设置**，然后执行以下步骤：

1. 打开**系统设置 \> 隐私与安全性 \> 输入监控**。
2. 如果列表中已有 ChatGPT，请开启它的访问权限。如果没有，请将
**ChatGPT** 从“应用程序”拖入列表，或选择**添加 (+)**，然后选择
**ChatGPT**。
3. 退出并重新打开 ChatGPT，然后确认 ChatGPT 能在第 1 层检测到 Micro。

有关这项 macOS 权限的更多信息，请参阅 [Apple 的输入监控
指南](https://support.apple.com/guide/mac-help/mchl4cedafb6/mac)。

### 解决连接干扰问题

ChatGPT 检测到 Micro 但无法连接或通信中断时，会自动重试。
如果问题仍然存在，请重新连接 Micro，并检查是否有
键盘工具或安全工具阻止访问 Micro。

{/* vale Vale.Spelling = NO */}

Work Louder 指出，在 macOS 上，拥有输入监控权限的 Karabiner 和 Logitech Options+ 可能会干扰
Micro 通信。若要
测试是否存在干扰，请退出键盘工具或暂时关闭其
输入监控权限，然后重新连接 Micro。如果您的组织负责管理
您的计算机，请让 IT 管理员检查设备规则。
