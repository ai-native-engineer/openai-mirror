ChatGPT 语音由 GPT-Live 提供支持，让您可以在 ChatGPT 桌面应用的聊天、Work 和 Codex 中通过对话梳理想法并协调任务。无需切换回键盘输入，您就能开始工作、查看进度或改变方向。

ChatGPT Plus、
Pro、Business、Edu 和企业套餐用户可以在 ChatGPT 桌面应用中使用 ChatGPT 语音。企业套餐和 Edu 套餐将先开放
为期两周的抢先体验，之后此功能才会
默认可用。您也可以通过
[iOS 上的远程功能](/zh-Hans/codex/remote-connections#set-up-mobile-access)使用 ChatGPT 语音，前提是已将
手机与桌面主机配对。是否可用还取决于功能推出状态和
工作空间设置。请参阅[功能可用性](/zh-Hans/codex/pricing#feature-availability)。

  

## 开始交谈

1. 在 ChatGPT 桌面应用中打开您想讨论的 Codex 任务，或新建聊天或任务。
2. 在现有任务中选择 **开始语音聊天** ，或在新的聊天或任务中
   选择 **开始新的语音聊天**。
3. 首次开始语音聊天时，请允许访问麦克风、选择一种声音，并在 macOS 上查看屏幕上下文设置。
4. 开始交谈。结束时，选择 **停止语音聊天** 。

在现有 Codex 任务中使用语音的功能正在逐步推出。功能可用后，您可以在以文字消息开始的任务中开启语音交谈。语音功能会使用该任务的对话内容和所选模型来处理您的请求，因此您无需另建任务，就能讨论任务进展或改变方向。

如果现有任务中没有 **开始语音聊天** 选项，请更新桌面应用
以及运行该任务的 Codex 主机。是否可用还取决于您的
账户和工作空间。在支持的情况下，您仍可开始新的语音聊天，
或使用[语音听写](/zh-Hans/codex/prompting#use-voice-dictation)输入提示文本。
要恢复之前的语音聊天，请将其打开并选择 **开始语音聊天**。

您可以在 **设置 \> 语音 \> 语音聊天快捷键**中设置快捷键。

## 进行对话

ChatGPT 语音支持自然地轮流交谈。您可以在 ChatGPT 回答过程中打断它、继续追问或改变方向。如果 ChatGPT 开始工作，您可以继续交谈，以查看进度或引导任务。

## 委派和协调工作

ChatGPT 语音可以为耗时较长的工作启动单独的任务、查看现有任务，并发送后续指令。它会在您的语音对话中反馈进度、遇到的阻碍和结果，让您能在工作继续进行的同时保持交谈。

例如：

- “审查今天的发布简报，并汇总需要审批的决策事项。”
- “启动一项 Codex 任务来运行测试，并调查所有未通过的测试项。”
- “检查正在进行的任务，并汇总所有阻碍进展的问题。”

您也可以要求与另一项 Codex 任务交谈，然后再要求返回上一项任务。例如，先说“让我和正在审查测试的任务聊聊”，然后说“带我回到上一项任务”。目标任务必须支持语音，并且在已连接的主机上可用。

ChatGPT 语音遵循的[权限](/zh-Hans/codex/permission-modes)与
其在 ChatGPT 桌面应用的聊天、Work 和 Codex 中所协调任务的权限相同。

## 向 ChatGPT 展示您看到的内容

在 macOS 上，请在 **设置 \> 语音**中开启 **屏幕上下文** ，然后说：
“看看这个。”ChatGPT 可以获取您
[当前位于前台的应用窗口快照](/zh-Hans/codex/appshots#permissions-and-safety)，并将其
用作上下文。您的组织可以禁用此功能。

应用快照可能包含窗口图像以及可供辅助功能访问的文本，包括
可见滚动区域之外的内容。macOS 可能会请求 **屏幕与系统音频
录制** 和 **辅助功能** 权限。请避免共享
包含敏感信息的窗口，包括可见滚动区域之外的文本。

## ChatGPT 语音与语音听写

使用 ChatGPT 语音与 ChatGPT 实时对话。[语音
听写](/zh-Hans/codex/prompting#use-voice-dictation)则适用于您只想先将
语音转换为提示文本再发送的情况。

## 限制与故障排除

整个 ChatGPT 桌面应用中，同一时间只能进行一个语音聊天。
语音对话有单独的使用额度，额度因套餐而异，并按滚动的
五小时窗口计量。通过语音功能启动的任务仍会消耗您的 Codex 使用额度。
达到任一限额时，ChatGPT 都会通知您。请参阅[语音功能的定价与
限制](/zh-Hans/codex/pricing#chatgpt-voice-in-desktop)。

如果无法开始语音聊天，请确认您的
套餐、功能推出状态和工作空间是否均满足 ChatGPT 语音的可用条件。然后检查麦克风权限，并确认
其他应用窗口中是否已有正在进行的语音聊天。如果屏幕上下文
不可用，请检查 **设置 \> 语音**、应用快照权限以及
您所在组织的限制。
