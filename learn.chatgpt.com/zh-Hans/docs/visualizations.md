可视化可将问题、想法和信息转化为图表、地图、
示意图、计算器、模拟和交互式说明，供您
在 ChatGPT 聊天中探索。当调整输入或观察某种
关系能让答案更易于理解、比较、练习或
付诸行动时，请使用可视化。

  可视化预览版正在逐步推出。可用性可能取决于您的
套餐、平台、账户和工作空间设置。

ChatGPT 桌面应用中的可视化预览版正在逐步推出。当
**可视化** 可用时，请在消息输入框中键入 `@`，开始输入
`Visualize`，然后在 **插件** 下选择 **可视化**。消息输入框会在您的请求前添加
**可视化** 标签。

如果 **可视化** 未显示，请使用网页版 ChatGPT，或等到
预览版向您的账户开放后再重试。

在受支持的聊天或 ChatGPT Work 聊天中，请在消息输入框中键入 `@`，
开始输入 `Visualize`，然后在 **插件** 下选择 **可视化**。其
说明为 **创建可视化和交互式工具**。消息输入框
会在您的请求前添加 **可视化** 标签。

您也可以键入 `@Visualize`，然后选择匹配的建议。

Codex CLI 不会渲染可视化。请在
网页版 ChatGPT 或 ChatGPT 桌面应用中打开相同的源材料，然后在那里添加 `@Visualize` 标签。

Codex IDE 扩展不会渲染可视化。请在网页版 ChatGPT
或 ChatGPT 桌面应用中使用此工作流。

出现 **可视化** 建议，是确认您的账户已启用
预览版的可靠标志。在逐步推出期间，即使套餐相同，不同账户、
工作空间和应用版本的可用性也可能不同。

## 选择适合使用可视化的场景

如果可视化形式能显著改善答案，ChatGPT 可以选择这种形式。您
也可以在明确需要交互式结果时添加 `@Visualize` 标签。

请选择满足任务需求的最简形式：

- 对于带标签的关系或流程，请使用示意图。
- 对于明确的数值数据和比较，请使用图表或绘图。
- 对于地理信息，请使用地图。
- 当输入、时间、运动或空间
关系需要发生变化时，请使用交互式可视化。
- 需要可长期使用的托管应用时，请使用 [站点](/zh-Hans/codex/sites)；它可提供
  可共享的 URL、权限或持久数据。

## 优化并继续

请在同一聊天中继续，并描述您想要的更改。以下是一些实用的
后续请求：

- 添加或移除控件、筛选器、比较项或注释。
- 更正源数据、单位、标签或假设。
- 通过汇总、分箱或采样数据来简化运行缓慢的结果。
- 添加简明的文本摘要和数据表。
- 让每个控件都可通过键盘操作，并添加可见的焦点状态。
- 除颜色外，还应使用标签或图案，并移除循环动画。
- 当结果需要托管并供日后再次访问时，请将其转换为站点。

后续请求可能会创建替代可视化，而不是直接修改
原始结果。将新版本作为依据前，请先进行审查。

## 分享或复用结果

请在可用时使用聊天的标准 **分享** 操作。请先审查
要分享的整个聊天，包括其中的源数据和之前的
消息。可视化通常只是信息快照，反映的是
ChatGPT 创建它时可用的信息，而不是会与
已连接的数据源保持同步的实时仪表板。

生成的下载控件和导出格式可能因结果而异。如果导出
无法正常工作，请让 ChatGPT 以更简单的格式提供底层数据，或者让它
将可视化转换为站点。

## 提升无障碍性

生成的可视化旨在使用语义化控件、清晰可见的焦点状态和便于阅读的
对比度，并减少动态效果，但实际结果可能有所不同。分享前请检查可视化
效果。请让 ChatGPT 添加文本摘要和数据表，为坐标轴
和单位添加标签，避免仅依赖颜色，并确保控件可通过键盘操作。

## 处理生成失败

生成可视化可能需要一分钟或更长时间。如果结果为空
或未显示，请等待响应完成，重新加载一次聊天，然后
重试。如果仍然失败：

- 请求生成规模更小或更简单的可视化。
- 聚合数据或对数据进行分箱，减少采样点数量，或降低大型数据集的精度。
- 移除已生成但无法正常工作的控件，或移除无法正常工作的库。
- 核实重要数值、地理边界，以及对源数据所作的假设。
- 改为请求生成图表、示意图、表格或站点。

请像处理任何 ChatGPT 聊天一样，审慎判断如何处理数据。只有
在您的组织允许时，才可添加敏感信息；分享前，请查看
完整聊天。
