任务生成文件时，请向 ChatGPT 提供源数据、预期文件类型、
文件结构以及与任务相关的审查标准。可用的预览和审查工具
取决于您使用的产品界面。

ChatGPT 桌面应用会在聊天界面旁预览生成的文档、演示文稿、
电子表格和 PDF 文件。启用自动预览后，该应用可以在
任务完成后打开生成的文件。

当 HTML 预览功能可用时，生成的 `.html` 和 `.htm` 文件也可以
作为交互式预览打开。您可以在渲染预览和源代码
视图之间切换，查看输出结果或底层 HTML。

在受支持的预览中，使用标注指出具体部分，并请求
有针对性的修改。

在网页版 ChatGPT Work 中，您可以附加源文件，或让 ChatGPT 创建
文档、演示文稿、电子表格或 PDF 文件。在聊天中审查生成的文件，
根据需要下载，并为下一版本提供有针对性的反馈。

Codex CLI 可以在工作目录中创建和编辑文件，但不提供
可视化的文件预览或标注界面。请让 Codex 报告各个输出路径
以及执行过的检查。

IDE 扩展可以在工作空间中创建和编辑文件。
请在编辑器中审查文本和代码文件，并使用兼容的查看器
打开文档、演示文稿、电子表格或 PDF 文件。

对于电子表格和演示文稿，请说明您需要的工作表、列、图表、

以及结果的检查方式。

## 使用标注完善文件

通过标注，您可以指出文件中的特定部分，并告知 ChatGPT
需要更改哪些内容。适用于代码、Markdown 文件和网站的
标注工作流程也同样适用于文档、电子表格
和演示文稿。

例如，您可以：

- 选择网站上的导航栏，并让 ChatGPT 更改其字体。
- 突出显示投资论述中的一项主张，并询问其来源。
- 标注幻灯片上的图表，并要求使用更清晰的标签。

ChatGPT 会将选定区域作为您请求的上下文，因此您无需从头开始，
也不必更改已经满意的部分，就能完善文件。
初稿完成后，如果内容需要
审查和迭代，标注就尤其有用。

## 在网页端审查和完善文件

打开或下载生成的文件，并在相应的查看器中审查。
请求修改时，请指明需要处理的页面、幻灯片、工作表、表格或段落，
并说明哪些内容应保持不变。在下载下一版本之前，
请让 ChatGPT 说明新的文件名
以及已执行的检查。

## 审查和完善文件

任务运行期间，您可以使用聊天侧边栏。侧边栏可以显示智能体的计划、
来源、生成的文件和聊天摘要，方便您引导工作方向、
检查生成的文件，并要求再处理一轮。

请让 ChatGPT 说明每个文件的保存位置，以及如何验证结果。
通过预览检查输出，然后针对需要再次处理的结构、数据、布局
或验证环节，提供有针对性的反馈。
