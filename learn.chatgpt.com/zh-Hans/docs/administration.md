# 管理

为 ChatGPT、Codex 开发者工具、API、插件和已连接系统设置访问权限与策略边界

为 ChatGPT、Codex 开发者工具、API、插件和已连接系统设置访问权限与策略边界。

管理涵盖六个相互关联的边界：ChatGPT 工作空间访问权限；针对 ChatGPT 桌面应用、Codex CLI 和 IDE 扩展中纳入管理范围的功能实施的本地运行时策略；Codex 云端使用资格；平台 API 访问权限；插件可用性和连接器权限；以及已连接系统中的权限。请先配置工作空间身份和访问权限，再针对每项部署实施所需的运行时控制措施和源系统控制措施。
