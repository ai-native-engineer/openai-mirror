Quickstart

## Get started with the desktop app

Install ChatGPT, sign in, choose where to work, and send your first message.

1. 1 

   ### Install the ChatGPT desktop app

   Download ChatGPT for Windows or macOS.

   [Download ChatGPT](https://persistent.oaistatic.com/codex-app-prod/Codex.dmg)
2. 2 

   ### Open ChatGPT and sign in

   Open the app, then sign in with your ChatGPT account.
3. 3 

   ### Choose where to work

   Start a chat, create a project, or open a folder. ChatGPT can use the
   files and context in the location you choose.

   [Learn about chats and projects](/codex/projects)
4. 4 

   ### Send your first message

   Choose ChatGPT or Codex. In ChatGPT, use the toggle above the composer to
   select Chat or Work. In Codex, start with New chat. For a quick question,
   point to New chat and select the Quick chat icon on its right. Then
   describe the result you want and add any files or context ChatGPT needs.

   [Learn how to use ChatGPT](/codex/use-chatgpt)
