ChatGPT 語音由 GPT-Live 提供支援，讓你能在 ChatGPT 桌面版應用程式的對話、Work 和 Codex 中，透過語音梳理想法並協調任務。你無須切換回打字，就能開始工作、查看進度或改變方向。

ChatGPT 語音可在 ChatGPT 桌面版應用程式中使用，適用於 ChatGPT Plus、
Pro、Business、Edu 和企業方案。企業與 Edu 方案
會先提供為期兩週的搶先體驗，之後此功能
才會預設開放。你也可以在手機與桌面主機配對後，
透過 [iOS 上的遠端功能](/zh-Hant/codex/remote-connections#set-up-mobile-access)
使用 ChatGPT 語音。是否可用也取決於推出狀態和
工作區設定。請參閱[功能可用性](/zh-Hant/codex/pricing#feature-availability)。

  

## 開始說話

1. 在 ChatGPT 桌面版應用程式中開啟你想討論的 Codex 任務，或開始新的對話或任務。
2. 在現有任務中選取 **開始語音對話** ，或在新的對話或任務中
   選取 **開始新的語音對話**。
3. 第一次開始語音對話時，請允許存取麥克風、選擇一種語音，並在 macOS 上檢視螢幕上下文。
4. 開始說話。完成後，請選取 **停止語音對話** 。

現有 Codex 任務的語音功能正在逐步推出。功能開放後，即使任務是以文字訊息開始，你也可以在其中使用語音交談。語音功能會運用該任務的對話內容和所選模型來執行你的要求，讓你無須另開任務，就能討論進度或改變方向。

如果現有任務中無法使用 **開始語音對話** ，請更新桌面 App
和執行該任務的 Codex 主機。是否可用也取決於你的
帳戶和工作區。在支援的情況下，你仍可開始新的語音對話，
或使用[語音聽寫](/zh-Hant/codex/prompting#use-voice-dictation)輸入提示詞文字。
若要繼續先前的語音對話，請開啟該對話並選取 **開始語音對話**。

你可以在 **設定 \> 語音 \> 語音對話快速鍵** 中設定快速鍵。

## 進行對話

ChatGPT 語音讓你能自然地輪流交談。你可以在 ChatGPT 回應時打斷它、追問或改變方向。如果 ChatGPT 開始處理工作，你可以繼續交談，以查看進度或引導任務方向。

## 委派與協調工作

ChatGPT 語音可以為較耗時的工作另開任務、查看現有任務，並傳送後續指示。它會在語音對話中回報進度、阻礙事項和結果，讓你在工作持續進行時也能繼續交談。

例如：

- 「審查今天的發布簡報，並彙整需要核准的決策。」
- 「啟動一項 Codex 任務來執行測試，並調查所有未通過的項目。」
- 「查看進行中的任務，並彙整所有阻礙進度的事項。」

你也可以要求切換到另一個 Codex 任務交談，再要求返回上一個任務。例如，先說：「讓我和正在審查測試的任務交談。」接著再說：「帶我回到上一個任務。」目標任務必須支援語音，且可在已連線的主機上使用。

ChatGPT 語音遵循的[權限](/zh-Hant/codex/permission-modes)，與
其在 ChatGPT 桌面版應用程式的對話、Work 和 Codex 中所指揮的任務相同。

## 讓 ChatGPT 查看你看到的內容

在 macOS 上，請在 **設定 \> 語音** 中開啟 **螢幕上下文** ，然後說：
「看看這個。」ChatGPT 可以擷取最前方視窗的
[應用程式快照](/zh-Hant/codex/appshots#permissions-and-safety)，並
將其用作上下文。你的組織可以停用此功能。

應用程式快照可能包含視窗影像和可供輔助使用功能存取的文字，包括
可見捲動區域之外的內容。macOS 可能會要求 **螢幕與系統音訊
錄製** 和 **輔助使用** 權限。請避免分享
含有敏感資訊的視窗，包括可見捲動區域之外的文字。

## ChatGPT 語音與語音聽寫

使用 ChatGPT 語音與 ChatGPT 進行即時對話。如果你只想先將語音轉成提示詞文字，
再傳送出去，請使用[語音
聽寫](/zh-Hant/codex/prompting#use-voice-dictation)。

## 限制與疑難排解

在 ChatGPT 桌面版應用程式中，一次只能進行一個語音對話。
語音對話採用依方案而定的獨立額度，並以滾動式
五小時區間計算。透過語音功能啟動的任務仍會計入你的 Codex 使用額度。
達到任一上限時，ChatGPT 會通知你。請參閱[語音定價與
限制](/zh-Hant/codex/pricing#chatgpt-voice-in-desktop)。

如果無法開始語音對話，請依你的
方案、推出狀態和工作區，確認 ChatGPT 語音是否可用。接著，請檢查麥克風權限，並確認
另一個應用程式視窗中是否已有語音對話正在進行。如果螢幕上下文無法使用，
請檢查 **設定 \> 語音**、應用程式快照權限，以及
你所屬組織的限制。
