## 設定 Codex Micro

1. 開啟 ChatGPT 桌面 App。
2. 按一下背面的按鈕，開啟 Codex Micro。
3. 使用 USB-C 連接線連接，或 [透過 Bluetooth 配對](#pair-with-bluetooth)，
   接著依照 ChatGPT 偵測到裝置時顯示的設定流程操作。
4. 在 macOS 上，系統提示時，請允許 **輸入監控**，讓 ChatGPT 能回應
   按鍵操作。
5. 開啟 **設定 \> Codex Micro**，選擇智慧體鍵要追蹤的對話或
   觸發的動作、自訂指令鍵、類比搖桿和旋鈕，以及調整
   燈光和語音控制項。

依預設，按住旋鈕片刻即可開啟這些設定。
你也可以選取 ChatGPT 底部帳戶名稱旁的 Micro 圖示。
旋鈕的自訂指派可以取代長按捷徑。

ChatGPT 首次偵測到支援的 Micro 後，裝置設定仍可使用。
與 ChatGPT 整合時，不需要 Work Louder Input。
你可用它自訂其他 App 的控制項，或設定更多圖層。

## 透過 Bluetooth 配對

Codex Micro 提供三個 Bluetooth 通道。

1. 按一下背面的按鈕，開啟 Micro。
2. 按住左下方邊緣的觸控控制區三秒。
Bluetooth 模式啟用時，Micro 下方的燈光會變成藍色。
3. 輕觸觸控控制區，以選擇 Bluetooth 通道 1、2 或 3。
通道指示燈快速閃爍，表示 Micro 已準備好配對。
4. 開啟電腦的 Bluetooth 設定，待 Micro 出現後，
連線至 Micro。
5. 等待通道指示燈持續亮起，這表示配對已完成。

若五秒內沒有操作，連線選擇器就會關閉。若要切換至
另一個已配對的通道，請再次開啟選擇器、選擇通道，並等待
選擇器關閉。若要重新配對該通道，請按住觸控控制區
三秒，直到通道指示燈開始閃爍。

若要改用 USB-C，請開啟連線選擇器並輕觸觸控控制區，
直到 Micro 下方的燈光變成白色。如果 Micro 仍處於 Bluetooth 模式，
接上 USB-C 連接線只會為裝置充電，不會將其切換成
有線連線。

如需硬體圖解，請參閱 [Work Louder Codex Micro
設定指南](https://worklouder.cc/openai-micro-setup)。

## 使用智慧體鍵查看及切換對話

六個磨砂智慧體鍵都能追蹤一則對話，並以燈光顯示其
目前狀態。按一下智慧體鍵，即可切換至該對話，而不會將
ChatGPT 視窗移到最前方。在 350 毫秒內按兩下該鍵，即可切換對話並
將 ChatGPT 視窗移到最前方。若要在第一次按下時就聚焦 ChatGPT，請在裝置設定中開啟
**按一下即可聚焦 ChatGPT**。

| 燈號 | 狀態           | 說明                                   |
| ----- | ---------------- | ----------------------------------------- |
| 白色 | 閒置             | 對話處於閒置狀態。                         |
| 藍色  | 思考中         | ChatGPT 正在處理。                       |
| 綠色 | 完成         | 對話已完成，並有未讀更新。 |
| 琥珀色 | 需要輸入   | ChatGPT 需要你核准或回覆。  |
| 紅色   | 錯誤            | 發生錯誤。                     |
| 熄滅   | 未指派對話 | 此按鍵未追蹤任何對話。            |

所選對話對應按鍵的狀態燈會緩慢明滅。

依預設，這些按鍵會追蹤最近更新的六則對話，不論是否
已釘選。你可以在裝置設定中變更 **智慧體鍵** 設定，以使用
其他配置方式：

- **最近的對話**：追蹤最近更新的六則對話，無論已釘選或
  未釘選。
- **已釘選的對話**：追蹤 **已釘選** 中的前六則對話。
- **優先對話**：將等待輸入、未讀和進行中的
  對話排在最前面。
- **自訂指派**：為每個智慧體鍵指派對話、快速鍵、實體按鍵動作或已啟用的
  技能。按下尚未指派的智慧體鍵即可開啟新對話。
  開始該對話時，ChatGPT 會將該對話指派給該按鍵。

追蹤對話時，按鍵仍會使用相同的狀態色彩。使用 **自訂
指派** 時，智慧體鍵可改為觸發動作。

## 使用及自訂指令鍵

Codex Micro 的預設配置包含六個動作：

  <div class="min-w-0 [&_table]:!mt-0 [&_td:first-child]:!px-2 [&_th:first-child]:!px-2 md:order-2">

|                            按鍵                            | 預設動作                           |
| :-------------------------------------------------------: | ---------------------------------------- |
|     | 開啟或關閉快速模式。                |
|  | 核准目前的請求。             |
|   | 拒絕目前的請求。             |
|    | 在新對話中繼續目前的對話。 |
|       | 啟動按住說話功能。                      |
|   | 傳送撰寫工具中的訊息。        |

  </div>
  <div class="min-w-0 md:order-1">

麥克風鍵使用電腦的麥克風。Codex Micro 本身沒有
麥克風。預設使用 **按住說話**：說話時按住按鍵，
放開即可停止。若要免持錄音，請在 350 毫秒內按兩下，
即可持續錄音。再按一次即可停止。

錄音時，海綠色燈光會在鍵盤四周流動。ChatGPT 處理你的語音時，燈光會變成
流動的白光；提示詞準備就緒後，則轉為恆亮白光。
按下 Codex 鍵即可傳送。

如果 **語音對話** 可在 **麥克風鍵** 下使用，請選取該選項，讓
麥克風鍵可用來開始語音對話或切換麥克風；按住該鍵即可
結束對話。開啟 **使用獨立的麥克風鍵**，即可分別設定寬版麥克風鍵
下方兩個開關的對應功能。

在裝置設定中，於 **配置** 預覽中選取一個指令鍵，然後
選擇其鍵帽和動作。你可以開啟瀏覽器或終端、管理
對話、審查變更、執行 Git 和 Pull Request 操作、附加檔案或照片、
開啟外掛程式或排程任務、變更推理強度、執行已啟用的技能，
或指派其他快速鍵。若選擇的鍵帽已用於
其他位置，ChatGPT 會將兩者互換，而不會重複使用同一個鍵帽。

重新對應按鍵後，請更換實體鍵帽，使其與新動作相符。
選取 **重設配置**，可還原預設的指令鍵與類比搖桿
指派，而不變更智慧體鍵模式或自訂對話指派。

## 使用類比搖桿和旋鈕

<div class="grid gap-6 md:grid-cols-[minmax(0,1fr)_minmax(16rem,42%)] md:items-start">
  <div class="min-w-0">

類比搖桿可朝任何方向自由移動。從中心向外推到足夠距離時，
ChatGPT 會將這項移動轉換為四個方向動作之一。Codex Micro 一開始採用
以下對應設定。

在裝置設定中，為每個方向選擇 ChatGPT 桌面應用程式中任何可用的指令或
已啟用的技能。

  </div>
  <div class="min-w-0 [&_table]:!mt-0">

| 方向 | 預設動作             |
| --------- | -------------------------- |
| 上        | 開啟或關閉規劃模式。  |
| 右     | 在應用程式的瀏覽記錄中前進。 |
| 下      | 顯示或隱藏側邊欄。  |
| 左      | 在應用程式的瀏覽記錄中返回。    |

  </div>
</div>

旋鈕預設使用 **撰寫工具導覽**。轉動旋鈕可依序切換
撰寫工具的控制項和選項，再按下旋鈕即可開啟或選取焦點所在的
控制項。開啟撰寫工具控制項或選單時，緊鄰旋鈕
右側的智慧體鍵會亮紅燈。按下該鍵即可取消。

在裝置設定中選擇四種旋鈕模式之一：

| 模式                       | 操作方式                                                                       |
| -------------------------- | ------------------------------------------------------------------------------ |
| **撰寫工具導覽**    | 在撰寫工具控制項之間移動，並選取焦點所在的控制項。                 |
| **僅限推理**         | 調整推理強度，並開啟對應的滑桿或進階選項。               |
| **對話捲動** | 捲動目前的對話；按下旋鈕可跳至最新訊息。          |
| **自訂指派**     | 為向左旋轉、向右旋轉、按下和長按各指派一個動作或技能。 |

在所有模式中，按住旋鈕都會開啟裝置設定，但
**自訂指派** 模式除外；在此模式中，會執行指派給長按操作的動作。

## 調整燈光

## Codex Micro 疑難排解

### 修正 macOS 上的輸入監控設定

如果裝置設定顯示尚未設定輸入監控，請選取 **開啟
系統設定**，然後按照下列步驟操作：

1. 開啟 **系統設定 \> 隱私權與安全性 \> 輸入監控**。
2. 如果清單中已有 ChatGPT，請開啟其存取權。若沒有列出，請將
**ChatGPT** 從「應用程式」拖入清單，或選取 **加入 (+)**，再選擇
**ChatGPT**。
3. 結束並重新開啟 ChatGPT，然後確認 ChatGPT 能在第 1 層偵測到 Micro。

如需進一步瞭解這項 macOS 權限，請參閱 [Apple 的輸入監控
指南](https://support.apple.com/guide/mac-help/mchl4cedafb6/mac)。

### 排除連線干擾

ChatGPT 偵測到 Micro 卻無法連線或通訊中斷時，會自動重試。
如果問題持續發生，請重新連接 Micro，並檢查
是否有鍵盤公用程式或安全性工具封鎖對 Micro 的存取。

{/* vale Vale.Spelling = NO */}

Work Louder 指出，在 macOS 上，若 Karabiner 和 Logitech Options+ 具有輸入監控權限，可能會干擾
Micro 通訊。若要測試是否受到干擾，請
結束鍵盤公用程式，或暫時關閉其
輸入監控權限，再重新連接 Micro。如果你的電腦由組織
管理，請要求 IT 管理員檢查裝置規則。
