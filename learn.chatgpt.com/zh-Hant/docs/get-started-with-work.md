## ChatGPT Work 簡介

ChatGPT Work 可讓您將實際工作交給 ChatGPT 處理。

需要答案、說明、腦力激盪或簡短草稿時，請使用對話。
若希望 ChatGPT 完成成果明確的任務，請使用 ChatGPT Work，例如製作
摘要文件、簡報、分析報告、定期更新、工作流程，或可供您
審查和使用的檔案。進一步瞭解[如何搭配使用對話與 ChatGPT Work](/zh-Hant/codex/use-chatgpt)。

ChatGPT Work 可使用您的檔案、外掛程式和已核准的工具擷取資訊，
製作完整的檔案、執行工作流程，並完成工作，供您審查。
您可以追蹤進度、回答問題、調整方向，
以及核准重要操作。

在[桌面 App](/zh-Hant/codex/app) 中，當相關工具可供使用時，ChatGPT Work 也能使用本機檔案、應用程式和
瀏覽器。

如果您曾使用 Codex 處理非程式設計工作，可以繼續使用 Codex，也可以改用
ChatGPT Work。ChatGPT Work 提供相同的核心能力，並帶來
專為日常工作設計的體驗。

## 從哪些任務開始

首先，切換至 **Work**，接著選擇第一項任務。
合適的任務應有明確成果、幾份來源資料，
以及可供您審查的輸出。

### 選擇在本機或雲端執行工作

在桌面 App 中，開啟撰寫工具中標示為「 **在本機使用 Work**」的控制項。
如果出現「**雲端** 」選項，而您希望 ChatGPT Work 在關閉應用程式或電腦後
繼續執行，或希望從網頁版或行動應用程式
繼續對話，請選擇該選項。如果任務需要使用電腦上的檔案或應用程式，
請保持選取「 **在本機使用 Work** 」。

雲端也適合用於需要持續研究或檢查網站的排程任務，因為這些任務
不需要您的電腦保持喚醒狀態就能執行。

以下是三個常見的入門使用案例：

### 建立簡報

使用 ChatGPT Work 將筆記、文件、研究資料或會議資料整理成一份
結構清晰的簡報。

  
    
  

### 建立比較試算表

使用 ChatGPT Work 將筆記、檔案或研究資料整理成比較各種選項的試算表，
協助您做出決策。

  
    
  

### 設定定期更新

如要讓 ChatGPT Work 持續重複執行、監控或更新某項內容，
請使用排程任務。

  
    
  

進一步瞭解[排程任務](/zh-Hant/codex/automations?surface=app)。

## 使用 ChatGPT Work 的最佳實務

若要讓 ChatGPT 完成任務、建立檔案，或持續管理工作，
請使用 ChatGPT Work。它很適合符合以下條件的任務：

- 涉及多個來源、外掛程式、工具或步驟。
- 手動完成時會耗費相當多時間。
- 產生供您審查、編輯或重複使用的輸出。
- 需要持續重複執行、監控或更新。

為了獲得更好的結果，請告訴 ChatGPT 您需要的成果、要使用的來源或外掛程式、
必須遵守的限制、理想成果應符合的標準，
以及何時應暫停以進行審查或取得核准。

**不要只說：** 幫我製作一份關於我們客戶研究的簡報。

進一步瞭解[如何為 ChatGPT Work 撰寫提示詞](/zh-Hant/codex/prompting#prompting-for-work)。

## 新增外掛程式，取得更多上下文並提升輸出品質

  
    
  

外掛程式可將 ChatGPT Work 連接至團隊使用的工具，例如 Slack、Google Drive、
SharePoint、電子郵件、行事曆、客戶關係管理系統，
以及專案追蹤工具。

- 在左側邊欄中選取「 **外掛程式** 」，即可查看外掛程式庫。
- 安裝與您的工作最相關的外掛程式。
- 若要指定 ChatGPT 使用特定工具，請在提示詞中輸入 `@` 和外掛程式名稱。

進一步瞭解[外掛程式](/zh-Hant/codex/plugins)。

## 有效率地使用 ChatGPT Work

對於需要縝密推理、視覺判斷或精心製作最終檔案的高難度工作，
請選擇 [GPT-6 Astra](/zh-Hant/codex/models#gpt-6-astra)。較簡單的任務則可
考慮 Sol、Terra 或 Luna。請從模型選擇器中
可用的模型進行選擇，並在開始大型任務前
查看[方案用量](/zh-Hant/codex/pricing)。

ChatGPT Work 最適合處理具一定規模、涉及多個步驟、來源或工具，
或需要完整交付成果的任務。較耗時或較複雜的任務可能會耗用
更多點數，因為 ChatGPT 會代您完成更多工作。請著重於
最終成果的價值，而不是提示詞的數量。

設定適當的範圍，讓任務保持聚焦。例如：「僅使用這些來源」、
「比較前五個選項」，或
「在傳送任何內容前先停下來」。

如果只是要快速提問、簡短改寫，或在做決策時
只需要建議，請改用對話。

進一步瞭解[如何提升工作效率](/zh-Hant/codex/prompting#prompting-for-work)。

如果任務因安全審查而暫停，請先依照通知操作，並檢視所有可用的審查結果，
再繼續執行。請參閱[安全監控與暫停的任務](/zh-Hant/codex/agent-approvals-security#safety-monitoring-and-paused-tasks)。
