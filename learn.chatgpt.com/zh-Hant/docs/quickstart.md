## 在哪裡使用 ChatGPT

你可以透過不同介面使用 ChatGPT，包括
[ChatGPT 桌面版應用程式](/zh-Hant/codex/app)和[網頁版 ChatGPT](/zh-Hant/codex/web)。請選擇
符合你工作需求的選項。

  

  如果你是開發人員，想在終端或程式碼編輯器中使用 Codex，
  請試用 [Codex CLI](/zh-Hant/codex/cli) 或 [Codex IDE 擴充功能](/zh-Hant/codex/ide)。
