# ChatGPT 桌面版應用程式

使用 ChatGPT 桌面版應用程式處理專案、檔案及長時間執行的工作。

掌控複雜工作的指揮中心

在單一桌面工作區中並行執行多個專案、處理檔案、操作電腦，並持續推進長時間執行的工作。

優勢

讓所有對話一目瞭然

在各個專案與長時間執行的工作之間切換，不會遺失上下文。

建立並檢視實際成果

在同一個工作區中開啟文件、試算表、圖像及其他檔案。

靈活運用各項工具

使用瀏覽器、桌面應用程式和外掛程式，或在對話中排程任務。
