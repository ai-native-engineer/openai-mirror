# 開發人員

設定開發工作流程、環境、擴充功能與整合

將 Codex 用於程式碼庫、開發環境和自動化，並搭配團隊使用的工具。

Codex 支援日常程式碼作業，也能跨本機與雲端環境進行更深入的整合。其開發工作流程涵蓋程式碼審查、整合式終端、可重複使用的技能與外掛程式、透過 SDK 與 App Server 進行的自動化、團隊工具，以及各介面的參考資料。

Codex 為工程師帶來的最新動態
