在 ChatGPT 桌面版應用程式中，開啟 ChatGPT 下拉式選單，然後選取 **Codex**。
開始 Codex 對話時，請選擇執行位置：

- **本機**：直接在目前的專案目錄中作業。
- **工作樹**：在 Git 工作樹中隔離變更。[深入瞭解](/zh-Hant/codex/environments/git-worktrees)。
- **雲端**：在已設定的雲端環境中遠端執行。

**本機** 和 **工作樹** 對話都會在你的電腦上執行。

如需完整的術語表和概念說明，請瀏覽[概念章節](/zh-Hant/codex/prompting)。
