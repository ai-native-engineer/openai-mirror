當任務會產生檔案時，請向 ChatGPT 提供來源資料、預期的檔案類型、
結構，以及對該任務而言重要的審查標準。預覽與審查
工具會因您使用的介面而異。

ChatGPT 桌面版應用程式會在對話旁預覽產生的文件、簡報、
試算表和 PDF 檔案。啟用自動預覽後，應用程式
可在任務完成後開啟產生的檔案。

可使用 HTML 預覽時，產生的 `.html` 和 `.htm` 檔案也能
以互動式預覽形式開啟。您可以在呈現後的預覽與原始碼
檢視之間切換，以檢查輸出或其底層 HTML。

使用標註指出受支援預覽中的特定部分，並要求
針對該處進行修改。

在網頁版 ChatGPT Work 中，附加來源檔案，或請 ChatGPT 建立
文件、簡報、試算表或 PDF 檔案。在對話中審查產生的檔案，
需要時下載檔案，並針對下一版本提供具體意見。

Codex CLI 可在工作目錄中建立及編輯檔案，但
不提供視覺化檔案預覽或標註介面。請 Codex 回報每個
輸出路徑，以及所執行的檢查。

IDE 擴充功能可在工作區中建立及編輯檔案。請在編輯器中審查文字和
程式碼檔案，並使用相容的檢視器開啟文件、簡報、試算表或
PDF 檔案。

  
    
  

## 建立供審查的檔案

對於試算表與簡報，請說明您預期的工作表、欄位、圖表、
投影片區段和檢查項目。請 ChatGPT 說明輸出的儲存
位置，以及如何檢查結果。

## 透過標註完善檔案

標註可讓您指出檔案中的特定部分，並告訴 ChatGPT
要變更哪些內容。適用於程式碼、Markdown
檔案和網站的標註工作流程，同樣也適用於文件、試算表和
簡報。

例如，您可以：

- 選取網站上的導覽列，並請 ChatGPT 變更其字型。
- 醒目標示投資論述中的一項主張，並要求提供其來源。
- 標記投影片中的圖表，並要求改用更清楚的標籤。

ChatGPT 會將選取區域作為您請求的上下文，讓您能完善
檔案，無須從頭開始，也不必變更已滿意的部分。
標註在初稿完成後特別實用，此時內容需要
審查及反覆修訂。

## 在網頁上審查及完善檔案

開啟或下載產生的檔案，並在適當的檢視器中審查。
要求修改時，請指出需要處理的頁面、投影片、工作表、表格或
段落，並說明哪些內容應維持不變。下載下一版
之前，請 ChatGPT 回報新的檔案名稱，以及
執行過哪些檢查。

## 審查及完善檔案

任務執行期間，請使用對話側邊欄。其中可顯示智慧體的計畫、
來源、產生的檔案和對話摘要，讓您能調整工作方向、
檢查產生的檔案，並要求再次處理。

請 ChatGPT 說明每個檔案的儲存位置，以及如何驗證
結果。使用預覽檢查輸出，再針對需要再次處理的
結構、資料、版面配置或驗證提供具體意見。
