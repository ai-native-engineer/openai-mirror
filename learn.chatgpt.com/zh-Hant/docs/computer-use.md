在支援的地區，ChatGPT 桌面版應用程式中的「電腦」功能可在 macOS 和 Windows 上搭配 ChatGPT Work 與 Codex 使用。請安裝「電腦」外掛程式。在 macOS 上，請依照提示授予「螢幕錄製」和「輔助使用」權限。

透過「電腦」，ChatGPT 可以查看及操作 macOS 或 Windows 上的圖形使用者介面。當指令列工具或結構化整合不足以完成任務時，即可使用此功能，例如檢查桌面應用程式、使用瀏覽器、變更應用程式設定、使用無法透過外掛程式存取的資料來源，或重現僅在圖形使用者介面中發生的錯誤。

由於「電腦」可能影響專案工作區以外的應用程式和系統狀態，請將其用於範圍明確的任務，並在繼續前審查權限提示。

## 設定「電腦」

在 ChatGPT 桌面版應用程式中，選取 ChatGPT 並在切換器中切換至 Work，或選取
Codex。開啟 **外掛程式 \>
電腦** ，如出現提示，請選取 **安裝外掛程式** 。如果 ChatGPT 顯示 **啟用**，
請選取該選項。開啟「電腦」伺服器和技能的切換開關，然後選取 **立即
試用** 即可開始。

  

接著開啟 **設定 \> 電腦** ，審查應用程式存取權。
已連線瀏覽器的控制項會顯示 **管理** 選項。你核准供日後任務使用的應用程式會顯示於
 **一律允許的應用程式** 區段。

  

在 Windows 上，任務執行期間請讓目標應用程式在使用中的桌面上保持可見。在 macOS 上，請依照提示授予「螢幕錄製」和「輔助使用」權限，讓 ChatGPT 能查看目標應用程式並與其互動。

在 macOS 上，請授予：

- **螢幕錄製** 權限，讓 ChatGPT 能查看目標應用程式。
- **輔助使用** 權限，讓 ChatGPT 能點按、輸入及導覽。

## 何時使用「電腦」

對於需要依賴螢幕擷取畫面或視覺判斷的困難任務，
如果模型選擇器中提供 [GPT-6 Astra](/zh-Hant/codex/models#gpt-6-astra)，請選用此模型。
相同的外掛程式設定、作業系統權限及應用程式存取控制
同樣適用。

若任務仰賴圖形使用者介面，且難以僅透過檔案或指令輸出進行驗證，請使用「電腦」。

適用情境包括：

- 測試 ChatGPT 正在建置的 macOS 應用程式、Windows 應用程式、iOS 模擬器流程或其他桌面應用程式。
- 執行需要使用你的網頁瀏覽器的任務。
- 重現只會在圖形介面中出現的錯誤。
- 變更必須透過 UI 逐步點選才能調整的應用程式設定。
- 查看無法透過外掛程式取得的應用程式或資料來源中的資訊。
- 在 macOS 上，讓範圍明確的任務在背景執行，同時繼續處理其他工作。
- 執行橫跨多個應用程式的工作流程。

對於你在本機建置的網頁應用程式，請優先使用
[內建瀏覽器](/zh-Hant/codex/browser?surface=app)。

### Windows 前景操作

在 Windows 上，「電腦」會在使用中的桌面執行。當你繼續使用同一個 Windows 工作階段時，它無法在背景運作，因此在任務執行期間，ChatGPT 會移動指標、輸入文字並接管前景操作。

若你離開後仍需讓 Windows 任務繼續執行，
請讓 Windows 裝置保持解鎖並連線至網際網路。透過手機使用
[遠端控制](/zh-Hant/codex/remote-connections)查看進度
或傳送後續指示；你也可以在 Windows 虛擬機器內執行 ChatGPT 桌面版應用程式，
讓「電腦」接管 VM，而非你的主要桌面。

## 權限與核准

工作區管理員可以限制「電腦」能存取哪些應用程式，
以及是否允許儲存核准決定。請參閱
[受管理的瀏覽器與「電腦」控制措施](/zh-Hant/codex/enterprise/managed-configuration#control-browser-and-computer-use)。

「電腦」的系統權限與 ChatGPT 中的應用程式核准彼此獨立。在 macOS 上，「螢幕錄製」和「輔助使用」權限可讓 ChatGPT 查看及操作應用程式。應用程式核准決定你允許 ChatGPT 使用哪些應用程式。檔案讀取、檔案編輯和 Shell 指令仍會遵循該任務的沙盒與核准設定。

透過「電腦」，ChatGPT 只能查看及操作你允許的應用程式。
任務執行期間，ChatGPT 必須先取得你的許可，才能使用你電腦上的應用程式。
你可以選擇 **一律允許** ，讓 ChatGPT 日後使用該應用程式時
無須再次詢問。你可以從 **一律允許** 清單移除應用程式；
該清單位於 ChatGPT 桌面版應用程式設定的**電腦** 區段。

  
    
  

ChatGPT 在執行敏感或可能造成干擾的動作前，也可能會要求你的許可。

如果 ChatGPT 無法查看或控制應用程式，請在 macOS 上開啟 **系統設定 \> 隱私權與
安全性** ，並檢查 **螢幕錄製** 和 **輔助使用** 中 **Codex
電腦** 的設定。在 Windows 上，請確認目標應用程式顯示於
使用中的桌面工作階段。

在 Windows 上，「電腦」會將應用程式的持續有效存取決定儲存在
`$CODEX_HOME/config.toml`。請列出「電腦」無須詢問
即可開啟的應用程式：

```toml
[computer_use.windows]
always_allowed_app_ids = ["mspaint.exe"]

請使用 Windows 上「電腦」功能回報的應用程式識別碼，
例如桌面應用程式的執行檔名稱，或封裝應用程式的應用程式使用者模型識別碼。
ChatGPT 會針對不在清單中的應用程式顯示提示。若要撤銷已儲存的決定，
請從 **設定 \> 電腦 \> 一律允許**移除該應用程式。

此表格儲存本機的「電腦」存取決定，與管理員強制套用的
`requirements.toml` 彼此獨立。管理員可在該檔案中
透過 `[features].computer_use = false` 停用「電腦」。舊版
`$CODEX_HOME/computer-use/config.toml` 中的允許清單項目會移轉至
目前的設定；其中的 `denied` 清單不屬於目前的原則結構描述。

## 鎖定時使用

  「鎖定時使用」適用於 macOS。在 Windows 上，「電腦」會在前景運作。

「鎖定時使用」可讓 ChatGPT 在 Mac 鎖定後使用「電腦」，但必須先啟用此功能。若 ChatGPT 任務需要在 Mac 鎖定後，從已連線的裝置使用桌面應用程式，請使用此功能。

啟用「鎖定時使用」時，ChatGPT 會安裝 Apple
[授權外掛程式](https://developer.apple.com/documentation/security/authorization-plug-ins)，
讓此外掛程式參與 macOS 解鎖流程。

「鎖定時使用」的適用範圍刻意受到限制。它不是用來遠端解鎖 Mac 的通用管道，也不允許其他應用程式或本機程序解鎖電腦。

如要使用「鎖定時使用」：

1. 在應用程式中開啟 **設定 \> 電腦** 。
2. 啟用「鎖定時使用」。
3. Mac 螢幕鎖定後，從已連線的裝置啟動使用「電腦」的任務。

Mac 鎖定後，若 ChatGPT 任務透過「電腦」存取應用程式，ChatGPT 會暫時解鎖 Mac，同時阻止本機操作並維持鎖定畫面的保護措施。解鎖前，ChatGPT 會檢查這次解鎖嘗試是否用於進行中且受信任的「電腦」操作回合。如果不在這段短暫的有效期間內，ChatGPT 會拒絕解鎖，並在需要時要求你手動解鎖。

「鎖定時使用」包含以下安全防護措施：

- 授權有效期間很短，且僅限目前這次解鎖嘗試。
- 自動解鎖僅供 ChatGPT 在進行中的「電腦」操作回合期間使用。
- 桌面暫時解鎖時，ChatGPT 會遮蔽所有顯示器畫面。
- 如果 ChatGPT 偵測到本機鍵盤或指標輸入，便會重新鎖定 Mac，並暫停自動解鎖，直到你手動解鎖為止。

## 安全性指引

透過「電腦」，ChatGPT 可以查看螢幕內容、擷取螢幕畫面，並與目標應用程式中的視窗、選單、鍵盤輸入和剪貼簿狀態互動。請將可見的應用程式內容、瀏覽器頁面、螢幕擷取畫面，以及在目標應用程式中開啟的檔案，視為 ChatGPT 在任務執行期間可能處理的上下文。

請限縮任務範圍，並在執行敏感流程時全程在場：

- 每次只向 ChatGPT 明確指定一個目標應用程式或流程。
- 您隨時可以停止任務或接手操作電腦。
- 除非任務需要，否則請關閉涉及敏感資訊的應用程式。
- 在 Windows 上，ChatGPT 執行任務時會接管前景輸入；請使用另一部裝置或 VM，或先停止任務，再自行使用該桌面。
- 除非您在場且能核准每個步驟，否則請避免執行需要機密資訊的任務。
- 允許 ChatGPT 使用應用程式前，請先審查該應用程式的權限提示。
- 只有在您信任 ChatGPT 可於未來任務中自動使用某個應用程式時，
  才對該應用程式選用 **一律允許** 。
- 處理帳戶、安全性、隱私權、網路、付款或憑證相關設定時，請全程在場。
- 如果 ChatGPT 開始操作錯誤的視窗，請取消任務。

如果 ChatGPT 使用您的瀏覽器，它就能與您已登入的頁面互動。請將網站上的操作視同由您親自執行，並加以審查：網頁可能包含惡意或誤導性內容，而網站可能將已核准的點按、表單提交及登入後的操作視為來自您的帳戶。若要在 ChatGPT 執行任務時繼續使用您的瀏覽器，請要求 ChatGPT 改用其他瀏覽器。

此功能無法自動操作終端應用程式或 ChatGPT 本身，因為這類自動化操作可能繞過 ChatGPT 的安全性政策。它也無法以管理員身分通過驗證，或核准您電腦上與安全性和隱私權相關的權限提示。

檔案編輯和 Shell 指令仍須在適用時遵循 ChatGPT 的核准與沙盒設定。透過桌面 App 進行的變更，可能要等到儲存至磁碟並由專案追蹤後，才會顯示在審查窗格中。您的 ChatGPT 資料控制設定適用於經 ChatGPT 處理的內容，包括「電腦」功能擷取的螢幕截圖。
