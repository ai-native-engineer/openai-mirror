# 安全性

管理 ChatGPT 與 Codex 開發者工具的權限、安全性與防護控制措施

控制 ChatGPT 與 Codex 開發者工具可存取的內容、瞭解工作如何隔離，並對安全敏感任務採取防護措施。

安全性控制措施規範 ChatGPT 與 Codex 開發者工具可存取哪些內容，以及如何審查敏感操作。權限、沙盒、核准及網路存取可建立信任邊界。Codex Security 協助找出並修補漏洞，而網路安全指南則說明如何處理安全敏感工作。
