## 以下情況適合使用 Codex 雲端…

### 工作需要在背景執行

委派耗時較長的任務，待就緒後再回來查看。

### 您想比較多次嘗試的結果

平行執行任務，不會占用您的本機電腦。

### 工作從 GitHub、GitLab、Linear 或 Slack 開始

透過整合委派工作，無須離開 Pull Request、合併請求、議題、頻道或討論串。

### 您不在開發用電腦旁

透過網頁或 Codex CLI 開始工作並審查成果。
