部分 ChatGPT 和 Codex 功能在推出時會標示成熟度等級，讓你瞭解各項功能的可靠程度、可能有哪些變更，以及可預期獲得何種程度的支援。

| 成熟度          | 意義                                                                                                 | 使用指引                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 開發中 | 尚未準備好供使用。                                                                                            | 請勿使用。                                                                    |
| 實驗性      | 尚不穩定，OpenAI 可能會移除或變更此功能。                                                                  | 請自行承擔使用風險。                                                         |
| 測試版              | 已可進行廣泛測試；多數方面已完備，但部分內容可能會依使用者回饋調整。       | 適用於大多數評估與試行；預期會有小幅變更。                      |
| 穩定            | 提供完整支援與文件，且已可廣泛使用；其行為與組態會長期維持一致。 | 可安全用於生產環境；移除功能前通常會先經過棄用程序。 |
| 已棄用        | 為維持相容性而繼續提供，但已不再建議使用；OpenAI 可能會在未來的版本中移除此功能。       | 避免在新用途上採用此功能，並規劃遷移。                                            |
