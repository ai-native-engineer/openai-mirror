ChatGPT 工作區的使用量限制與支出控制適用於符合資格的活動，涵蓋範圍以該工作區的方案為準。視方案而定，這可能包括部分 Codex 活動。這些控制並非通用的 Codex 限制系統，也不控管 OpenAI API 平台的計費。

如需瞭解完整的管理架構，請參閱
[角色與工作區權限](/zh-Hant/codex/enterprise/roles-and-workspace-permissions)。

## 瞭解這些控制的適用時機

在下列情況下，請審查 ChatGPT 工作區的使用量控制：

- 組織依協議使用共用或已購買的 ChatGPT 工作區點數。
- 符合資格的 Codex 活動可能會耗用這些點數。
- 管理員需要使用者防護措施、工作區層級的支出控制，或目前方案支援的使用量通知。

使用量控制不會設定功能的使用資格或權限，但可用額度用盡時，可能會暫停使用符合資格的功能。這些控制不會影響來源系統的權限，也不會控管 API 平台的使用量或計費。
