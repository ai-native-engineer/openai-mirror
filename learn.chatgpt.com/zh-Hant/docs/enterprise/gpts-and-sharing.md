## 分享

控管誰可以建立 GPTs，以及這些 GPTs 是否可以與特定人員、群組或整個工作區分享。

  GPT 建立者可以使用已連接的應用程式或自訂動作，但不能在同一個 GPT 中同時使用兩者。

## 已連接的應用程式和動作

允許 GPT 建立者使用經核准的工作區應用程式，或設定與獲准使用的第三方 API 互動的動作。存取仍受工作區政策、使用者權限和已核准網域的限制。

## 網域

將 GPT 動作限制在已核准的外部網域，以控管工作區中建立的 GPTs 可以存取哪些第三方 API。如果未允許任何網域，自訂 GPT 動作便無法執行。

  網域核准不能取代 API 身分驗證或使用者授權。

## 管理 GPTs

審查在工作區中建立的 GPTs、管理分享與擁有權，並在適當時刪除 GPTs。管理檢視會依是否已指派擁有者將 GPTs 分類，並列出下列資訊：

- 名稱
- 建立者
- 自訂動作
- 可存取的對象
- 對話
- 建立時間
- 更新時間
