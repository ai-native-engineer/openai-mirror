ChatGPT Work 協助員工完成多步驟任務，例如研究主題、分析資訊，或製作完整的文件或簡報。完成這些任務可能需要額外的推理、工具和處理作業，因而可能消耗點數。這些用量是否會影響發票金額，取決於你的剩餘點數、合約費率及工作區超額使用設定。

透過本指南瞭解 Work 如何影響用量、規劃員工導入，並運用組織可用的支出控管功能。

## 用量與費用概覽

- 對於採點數計費且符合條件的合約，Work 的使用活動會消耗工作區的共用點數。
- 消耗承諾購買的點數，與在發票上新增費用並不相同。
- 員工可以同時使用對話與 Work；估算導入後的用量時，請合併評估兩者符合條件的用量。
- 依職務估算有助於規劃，但估算值不是每位使用者的固定價格，也不是保證的帳單金額。
- 使用者用量限制與工作區超額用量上限是兩項獨立的控管措施。警示會提供通知，但不會停止支出。
- 根據組織觀察到的用量與可衡量的工作流程成效，評估導入情況。

## Work 為何使用點數

對於採點數計費合約的組織，符合條件的 Work 使用活動會消耗工作區共用額度中的點數。其他符合條件的 ChatGPT 功能也可以使用同一額度，因此 Work 不一定有獨立的點數餘額。

點數消耗量會因下列因素而異：

- 模型、執行環境，以及適用的推理或速度設定。
- 任務的複雜度，以及使用的任何符合條件的工具或功能。例如，使用已核准且員工獲授權存取的應用程式與系統中的 CRM 記錄、文件或訊息，準備季度業務回顧。
- 員工執行任務的頻率。

員工開始使用 Work 時，不需要停止使用對話。若要瞭解總消耗量的變化，請選用可比較的期間，對照同一批員工先前的對話用量，以及導入後對話與 Work 的合計用量。

你的合約與適用的費率表決定每項符合條件的使用活動會消耗多少點數。現有的訂閱費或席位費與點數消耗估算分開計算。

### 瞭解 Token 與點數

**Token** 用來衡量模型讀取與寫入的資訊量，包括輸入、
快取輸入及輸出。採點數計費的合約會從工作區共用額度中扣除 **點數** ，
支付符合條件的用量。如需瞭解點數定價，請參閱
[Token 費率](/zh-Hant/codex/pricing#token-rates)。

如果你的企業合約改以美元按用量計費，請依據 <a href="https://help.openai.com/en/articles/20001415-chatgpt-rate-card-enterprise-token-based-pricing" target="_blank" rel="noopener noreferrer">企業美元費率表</a> 及你的合約計算。請勿將點數計算方式套用至以美元計費的工作區，也不要將已消耗的點數視為發票上的額外費用。

## 用量何時會影響帳單

符合條件的 Work 用量是否會產生額外費用，取決於你的合約、剩餘點數及適用的計費設定。使用承諾購買的點數會減少可用餘額，但本身不會在發票上新增費用：

- **承諾購買的點數仍有剩餘：** 符合條件的使用活動會消耗
  可用點數額度。使用這些點數本身，並不會產生
  現有合約以外的新費用。
- **點數已用完，且帳戶允許超額使用：** 符合條件的使用活動可以
  在設定的工作區超額用量上限內繼續進行，並可能
  按合約約定的超額用量費率收費。
- **點數已用完，且帳戶不允許超額使用：** 符合條件的功能
  可能會暫停，直到有可用點數，
  或適用的上限有所變更。

超額使用的處理方式取決於帳戶資格
及設定的工作區上限。如果合約不允許超額使用，
當可用點數耗盡時，符合條件的使用活動就會停止。如果帳戶允許超額使用，
未設定上限可能會讓符合條件的用量超出點數餘額。在支援此設定的情況下，
將超額用量上限設為零，可防止工作區繼續產生超額用量；
而 **無上限** 並不表示支出上限為零。

用量報告與美元金額估算是規劃或監控工具，並非已開立的發票。部分顯示的估算採用合約約定的超額用量費率，可能與承諾購買的點數費率不同。請對照發票、計費期間及組織合約條款，確認實際費用。

## 估算職務或團隊的用量

依職務估算，有助於為職責相近的員工規劃導入，例如財務、行銷或業務人員。請先從組織預計支援的員工與工作流程著手。

請依下列步驟進行估算：

1. 確定預計導入的使用者群組，並選定既有對話使用活動中可供比較的一段期間。
2. 根據試行期間觀察到的用量，或經核准且適用的職務基準，估算對話與 Work 的合計消耗量。
3. 檢視承諾購買的點數餘額。分別為這些點數與任何超額用量套用適用的合約費率。
4. 判斷可用點數是否足以涵蓋預估用量，或用量是否可能進入合約約定的超額使用範圍。
5. 依實際導入情況、任務組合及觀察到的消耗量更新估算。

經核准的基準可能反映觀察到的企業客戶用量，以及實際使用的模型組合。基準是否有參考價值，取決於比較期間、職務分類、工作流程及帳戶相關假設。概括性的職務估算並不構成特定產業或特定任務的基準。

**年化點數消耗估算** 會將觀察到的用量所對應的金額推算為
全年數值。這不是 Work 的獨立授權價格、每位使用者的標準費用、
OpenAI 的基礎架構成本，也不代表預測發票金額將
增加相同數額。實際新增費用取決於承諾購買的點數餘額、
合約定價、允許的超額用量，以及計費期間。

### 行銷團隊規劃示例

針對企業中首次導入 Work 的行銷人員所做的觀察分析，顯示年化點數消耗金額有以下變化：

- **中位數：** 約為 **每位員工每年 $53**。
- **第 90 百分位數：** 約為 **每位員工每年 $1,154**。
- **平均值：** 約為 **每位員工每年 $309**。

中位數代表觀察到的個人用量的中間值。平均值較高，是因為少數員工消耗了較多點數。第 90 百分位數表示觀察到的較高用量門檻，而不是支出上限或最大值。

若 **100 位員工** 的用量組合相近，套用 **每位員工
平均 $309** 的數值，約為 **每年 $30,900**，或
**換算為每月 $2,575，供規劃參考**。

這些僅供方向參考的估算，是將企業客戶導入期間一週的觀察用量年化計算，反映其用量與實際使用的模型組合。這些數值不是保證可節省的金額或每位使用者的固定價格，不會自動成為帳單金額，也不代表發票金額必然增加。實際費用取決於承諾購買的點數餘額、合約費率及允許的超額用量。

負責你帳戶的團隊可協助對照組織合約，解讀經核准的估算。

## 管理員控管與報告

工作區擁有者與管理員可使用支援的設定，管理存取權及符合條件的點數計費用量：

- **Work 存取權：** 透過工作區提供的權限設定，
  選擇哪些人員或群組可以存取 Work。
- **模型與速度設定：** 若有提供這些選項，可在「工作區設定 \> 模型」中
  設定 Work & Codex 的起始模型、推理等級、速度，以及是否開放快速模式。
  對於支援的模型，快速模式可能會消耗更多點數。
- **使用者用量限制：** 設定支援的工作區每月預設上限、群組上限
  或個別使用者覆寫值，以管理每位使用者符合條件的用量。
- **工作區超額用量上限：** 控制共用點數額度耗盡後，
  還能繼續使用多少符合條件的用量。
- **用量警示：** 在支援的情況下，於「帳單」設定可用的用量門檻
  及通知對象。警示僅提供通知，不會停止支出。
- **點數餘額與報告：** 在「帳單」檢視剩餘點數，並
  下載你的角色可存取的用量報告。如果合約包含
  承諾購買的點數，請將觀察到的用量與合約約定的額度及
  計費期間比較，以評估消耗進度。
- **發票：** 如果你的工作區角色具備發票存取權，
  請檢視已開立的發票及對應的計費期間。

個別使用者的覆寫設定優先於群組與工作區的預設值。當使用者隸屬多個群組時，會套用適用群組上限中的最高值。群組未設定上限，並不表示點數上限為零。請確認每位試行參與者實際生效的上限。

用量限制不會增加點數，也不會決定誰可以存取 Work。模型預設值或提供給員工的使用指引可能影響消耗量，但兩者都不能取代強制執行的用量限制或工作區超額使用設定。

控管功能的可用性、報告詳細程度、發票存取權與計費方式
取決於你的方案、工作區組態及合約。報告可能不會即時反映使用活動；
將用量與發票核對前，請先比對報告的時間戳記與計費期間。
如需瞭解跨產品的適用範圍
與目前的設定程序，請參閱
[ChatGPT 用量限制與支出控管](/zh-Hant/codex/enterprise/usage-limits)。

## 同時衡量用量與成效

選擇一項已有明確比較基準的例行工作流程，例如客戶研究、會議準備或財務報告。請使用適合該工作的存取權、工具與模型能力，而非假設每項任務都需要最進階的選項。

試行期間，請比較導入 Work 前後的同一工作流程。視任務而定，你的組織可以衡量：

- 完成工作所需的時間。
- 產出品質、完整性或一致性。
- 重做情況、人工協調或錯誤率。
- 團隊是否完成預定的交付成果。

請一併檢視這些由客戶衡量的成果、觀察到的點數消耗量，以及對帳單的任何實際影響。僅憑用量無法證明節省了成本，預估可節省的時間也不保證能帶來財務收益。

## 先在可控範圍內導入

擴大存取範圍前：

1. 確認合約內容、剩餘點數、適用費率及超額使用設定。
2. 選定一個小規模群組，以及組織能夠評估的工作流程。
3. 設定所支援的存取權限、使用者用量限制、警示及工作區超額使用上限。
4. 將對話與 Work 的合計消耗量與該群組的既有基準比較。
5. 擴大導入範圍前，請檢視觀察到的成果及對帳單的任何實際影響。

如需更完整的存取權限、資料、治理及導入指引，請參閱
[ChatGPT Work 管理員常見問題](/zh-Hant/codex/enterprise/work-admin-faq)。如有
個別合約的定價、可用點數及帳單開立問題，
請聯絡負責你帳戶的團隊。
