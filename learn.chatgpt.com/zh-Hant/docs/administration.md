# 管理

設定 ChatGPT、Codex 開發工具、API、外掛程式及已連線系統的存取權與政策界線

設定 ChatGPT、Codex 開發工具、API、外掛程式及已連線系統的存取權與政策界線。

管理涵蓋六項相互關聯的管控界線：ChatGPT 工作區存取權；ChatGPT 桌面版應用程式、Codex CLI 和 IDE 擴充功能中納入管控範圍的功能所適用的本機執行階段政策；Codex 雲端使用資格；Platform API 存取權；外掛程式可用性與連接器權限；以及已連線系統的權限。請先從工作區身分識別與存取權著手，再套用各項部署所需的執行階段與來源系統控制措施。
