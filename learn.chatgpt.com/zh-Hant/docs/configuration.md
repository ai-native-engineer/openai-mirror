# 組態

設定 ChatGPT 與 Codex 開發工具、可重複使用的工作流程及外部工具

設定預設值、加入可長期保留的上下文，並自訂 ChatGPT 與 Codex 開發工具的運作方式。

組態會影響 ChatGPT 與 Codex 開發工具在不同對話、程式碼庫及電腦上的運作方式。可長期保留的上下文、設定檔、程式碼庫指引、子代理程式、外部連線，以及 Linux 和 Windows 設定彼此配合，讓個人與團隊都能維持一致的工作流程。
