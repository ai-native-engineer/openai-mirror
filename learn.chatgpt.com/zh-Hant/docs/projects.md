使用專案整理相關對話，並為 ChatGPT 提供所需的上下文。
ChatGPT 桌面版應用程式的 **專案** 檢視包含 ChatGPT 專案，以及
連接至您電腦資料夾的本機專案。

## 選擇專案，或不使用專案直接開始

若工作會持續一段時間、產出多項成果，
或需使用相同的檔案和來源，請建立專案。若工作可獨立完成，
且不需要共用專案上下文，則可不使用專案直接開始對話。

使用專案集中管理相關對話、檔案、指示和來源。
同一個專案可包含使用「對話」或 ChatGPT Work 開始的對話。

## 選擇專案，或不使用專案開始對話

若工作會持續一段時間、產出多項成果，
或需使用相同的檔案和來源，請建立專案。若工作可獨立完成，
且不需要共用專案上下文，則可不使用專案直接開始對話。

每個專案都設有 **對話** 區段，用來列出專案對話；另有 **來源**
區段，用來存放已上傳的檔案和已連接的上下文。專案指示適用於
專案內的所有對話。ChatGPT 專案不提供您電腦上
資料夾的直接存取權，因此請上傳或連接您希望 ChatGPT 使用的來源。

無論選擇哪種方式，都請從專案開始新對話，以使用其共用檔案和
指示，之後可從 **對話** 區段回到該對話。

Codex CLI 會將啟動時所在的目錄視為該對話的專案。
請在您希望 Codex 運作的目錄中執行 `codex`，或傳入
`--cd <directory>`（`-C`）來明確指定。CLI 不會顯示
ChatGPT 的「專案」檢視。

IDE 擴充功能會將您在 IDE 中開啟的資料夾或工作區視為本機
專案。在多根目錄工作區中，請為對話選取工作區根目錄。此
擴充功能不會顯示 Web 或桌面 App 中的 ChatGPT「專案」檢視。

<a id="work-in-a-project"></a>

## 在專案中工作

**專案** 檢視可集中顯示 ChatGPT 專案和本機專案。
ChatGPT 專案可讓相關對話共用專案檔案和上下文。本機
專案則可讓對話存取您電腦上的一或多個資料夾，例如
一組原始碼檔案或程式碼庫。

為每項不同的成果分別開始對話，使各對話的訊息和結果保持
聚焦，同時透過專案整理相關工作。

  
    
  

## 在專案中工作

ChatGPT 專案可讓其中的對話存取相同的已上傳檔案、專案
指示和已連接的來源。快速交談時可使用「對話」，處理規模較大的交付成果時則使用
ChatGPT Work；兩者都會以對話形式顯示在專案的
**對話** 區段中。為每項不同的成果分別開始對話，讓各對話的
訊息和結果保持聚焦，同時由專案保留共用上下文。

## 在專案目錄中工作

從可提供對話檔案上下文的目錄啟動 Codex。使用
`/new` 為每項不同的成果分別開始對話。當 Codex 開啟時，可使用 `/resume`，
或執行 `codex resume`，以繼續已儲存的對話。

對話會保留對話記錄和已記錄的工作目錄，而 Codex 會從目前的工作樹
讀取檔案。請將長期適用的專案指引放在
`AGENTS.md` 或已納入版本控制的文件中，讓日後的對話也能使用。

## 在工作區中工作

開啟可提供對話檔案上下文的資料夾或工作區。為每項不同的成果
分別開始新對話，之後可從 **最近的對話** 選取該對話，
繼續處理。同一專案中的對話可以使用相同的檔案，而每個
對話都會保留各自的對話記錄。

目前選取的內容和已開啟的檔案會為目前回合提供上下文。請將
長期適用的專案指引放在 `AGENTS.md` 或已納入版本控制的文件中，讓
日後的對話也能使用。

## 整理專案和對話

讓進行中的工作保持可見，並將已完成的工作移到一旁：

- **釘選專案** ，使其顯示在側邊欄頂端附近。您也可以
  從「專案」檢視釘選專案。
- **釘選對話** ，以便經常返回該對話，即使專案中出現
  更新的對話也不受影響。
- **重新命名對話** ，使用能描述成果的簡短標題，例如「Q3
  發布摘要」或「結帳流程無障礙審查」。
- **搜尋專案** 時，請使用「專案」檢視。從側邊欄開啟 **搜尋對話** ，
  即使只記得某個詞句或分支名稱、不記得標題，也能找出過往
  對話。「搜尋對話」沒有預設快速鍵，但您可以
  在 **設定 \> 鍵盤快速鍵** 中自行指定。
- 工作完成後，請 **封存對話** 。從專案選單中選取
**封存對話** ，即可一併封存該專案中的所有對話。

釘選不會新增上下文，也不會變更 ChatGPT 可存取的內容；只會改變
專案或對話在側邊欄中的顯示位置。

前往 **設定 \> 已封存的對話**，即可還原已封存的對話。

## 整理專案和對話

讓進行中的工作保持可見，並將已完成的工作移到一旁：

- **釘選專案** ，使其顯示在側邊欄頂端附近。您也可以
  從「專案」檢視釘選專案。
- **釘選對話** ，以便經常返回該對話，即使專案中出現
  更新的對話也不受影響。
- **重新命名對話** ，使用能描述成果的簡短標題，例如「Q3
  發布摘要」或「結帳流程無障礙審查」。
- **搜尋專案** 時，請使用「專案」檢視。若只記得某個詞句或分支名稱，卻不記得標題，請按下
<kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>K</kbd>，
  即可搜尋過往對話。
- 工作完成後，請 **封存對話** 。

釘選不會新增上下文，也不會變更 ChatGPT 可存取的內容；只會改變
專案或對話在側邊欄中的顯示位置。

前往 **設定 \> 資料控制 \> 已封存的對話**，即可還原已封存的對話。

<a id="use-local-projects-for-folders-and-codebases"></a>

## 使用本機專案管理資料夾和程式碼庫

當 ChatGPT 需要讀取或變更您電腦上的檔案時，請新增本機專案。
專案不一定需要資料夾，但您可以視需要附加資料夾。

若要新增或變更資料夾，請開啟專案選單並選取 **編輯專案**。
選取 **新增資料夾** ，即可附加多個資料夾。ChatGPT 可讀取及變更
每個已附加資料夾中的檔案。若要變更預設工作目錄，請將游標移到
資料夾上，然後選取 **設為主要**。

新對話會從主要資料夾開始。Codex 也會將該資料夾設為
Git 操作的預設位置，並自動在其中探索 `AGENTS.md`、技能和
`config.toml`。次要資料夾仍可用於搜尋、讀取和
編輯檔案，但 Codex 不會自動從
次要資料夾探索這些專案檔案。

當相關工作分散在不同位置時，請使用多個資料夾，例如應用程式和
其文件，或網站和其後端。如果工作彼此無關，或每段對話只應存取
程式碼庫的其中一部分，請建立個別專案。
如此可讓工作上下文保持聚焦。遠端專案目前只支援一個
資料夾。

使用 [本機環境](/zh-Hant/codex/environments/local-environment)，為專案定義設定
動作和常用指令。[審查
窗格](/zh-Hant/codex/code-review?surface=app) 可顯示附加至同一專案的各個程式碼庫
中的變更。Pull Request 和
[工作樹](/zh-Hant/codex/environments/git-worktrees) 操作會以主要
程式碼庫為目標。在工作樹中開始對話時，其他資料夾仍會
維持附加狀態。

專案和工作樹負責整理工作，而 [沙盒](/zh-Hant/codex/sandboxing)
則會強制限制本機指令可讀取、變更或透過網路存取的內容。

## 不使用專案開始對話

當工作可獨立完成時，請選取 **新增對話** ；這適用於不需要共用
專案檔案、指示或資料夾存取權的情況。如果有
多段對話會使用相同的上下文，請先建立專案。

<a id="start-a-task-without-a-project-1"></a>

## 不使用專案開始對話

如果對話不需要共用專案檔案、
指示或來源，請從 ChatGPT 首頁開始對話。您可以使用「對話」或 ChatGPT Work；在 Web 上，
兩者都會建立對話。

如果工作範圍擴大，請將其移入專案，並為每項成果使用清楚的
對話名稱。專案可同時容納研究、草擬、審查和後續工作的對話，
不必將所有訊息混在同一個上下文中。

## 使用快速聊天快速提問

快速聊天會開啟一般的 ChatGPT 對話。ChatGPT 對話不會顯示在
Codex 側邊欄中；該側邊欄顯示的是您的 Codex 對話和專案。

將游標移到 **新增對話**，再選取右側的 **快速聊天** 圖示。您也可以
按下

<kbd>Cmd+Option+N</kbd>（macOS），或 <kbd>Ctrl+Alt+N</kbd>（Windows 和 Linux）。
在 **新增對話** 中，您可以開啟現有的 ChatGPT 對話，並將其加入 Codex
對話。

## 引入其他工具和上下文

- 當檔案或 [圖像輸入](/zh-Hant/codex/image-inputs) 只適用於該次請求時，
  請直接將其附加至對話。
- 安裝 [外掛程式](/zh-Hant/codex/plugins)，以引入其他
  服務的上下文和動作。
- 請設定 [MCP](/zh-Hant/codex/extend/mcp) 伺服器，以使用您的組織或開發環境
  透過 Model Context Protocol 提供的工具。
- 若可使用 [記憶](/zh-Hant/codex/customization/memories) 功能，即可將過往工作的實用上下文
  延續至日後的對話。

- 若視覺上下文僅適用於該請求，請將 [圖像輸入](/zh-Hant/codex/image-inputs)
  傳送至對話。
- 安裝 [外掛程式](/zh-Hant/codex/plugins)，以引入其他服務的上下文和
  操作。
- 若您的組織或開發環境
  透過 Model Context Protocol 提供工具，請設定 [MCP](/zh-Hant/codex/extend/mcp) 伺服器。
- 如有提供，請使用 [記憶](/zh-Hant/codex/customization/memories)，將過往工作中的實用上下文
  帶入日後的對話。

- 在編輯器中引用已開啟的檔案或選取程式碼，為
目前這一輪補充上下文。
- 若您的組織或開發環境
  透過 Model Context Protocol 提供工具，請設定 [MCP](/zh-Hant/codex/extend/mcp) 伺服器。
- 如有提供，請使用已連線的 Codex 主機所提供的 [記憶](/zh-Hant/codex/customization/memories)，
  將實用上下文帶入日後的對話。

- 若檔案和已連線的來源需要提供給專案內的所有對話使用，
  請將其加入專案的 **來源** 區段。
- 若檔案或 [圖像輸入](/zh-Hant/codex/image-inputs) 僅適用於某個對話，
  請直接將其附加至該對話。
- 在 ChatGPT Work 中安裝 [外掛程式](/zh-Hant/codex/plugins)，以引入其他服務的上下文和
  操作。
- 如有提供，請使用 [記憶](/zh-Hant/codex/customization/memories)，將過往工作中的實用上下文
  帶入日後的對話。
