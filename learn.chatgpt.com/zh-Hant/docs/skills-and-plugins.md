技能和外掛程式能協助 ChatGPT 和 Codex 完成重複性工作，並提供
適當的指示、資源和工具。如此一來，就不必在每次對話中都貼上
相同的提示詞、範本、需求或流程。

- **技能** 會將特定
  任務或工作流程所需的指示與支援資源封裝在一起。
- **外掛程式** 是一種可安裝的套件，可包含技能、連接器或
  兩者。連接器由 Model Context Protocol (MCP) 伺服器提供支援，並可
  選擇加入自訂 ChatGPT UI。

## 使用技能處理可重複執行的工作

技能是一種可重複使用的工作流程，可為 ChatGPT 或 Codex 提供特定任務的
指引。它能記錄您處理週期性工作的既有方式，讓任一
產品每當該任務出現時都遵循相同流程。

技能可以結合以下內容：

- 名稱與說明，可協助 ChatGPT 和 Codex 判斷技能何時
適用。
- 定義流程與預期結果的工作流程指示。
- 支援資源，例如範本、範例、品牌指引、結構描述，
或已連線工具。

當良好成果仰賴可重複執行的方法時，技能最能發揮效用。舉例
來說，技能可以準備每日摘要、審查文件、製作
簡報、套用團隊寫作標準，或每週從
相同的已連線工具收集資訊。

使用技能可提升一致性，並讓團隊的最佳實務可直接用於
工作流程；您也可以共享標準流程，不必依賴未記錄成文件的
知識。

ChatGPT 和 Codex 可在您的要求符合某項技能的用途時選用該技能。您
也可以明確選取技能。ChatGPT 支援以 `@` 提及技能，而 Codex
則支援以 `$` 提及技能。

## 建置技能

您可以先將經常重複執行的任務整理成一份專用操作手冊，供
ChatGPT 和 Codex 使用。適合先建立的技能包括每週更新、行銷活動摘要、
會議後續追蹤，或任何步驟與格式應保持
一致的任務。

建置實用技能的步驟如下：

1. **選擇一項範圍明確的任務。** 記下您通常會使用哪些起始資料，例如
   檔案、連結或筆記，以及完成後的成果應有什麼樣貌。
2. **描述工作流程。** 在 ChatGPT 中，先使用 `@skill-creator`；在 Codex 中，
   使用 `$skill-creator`。說明目標、要遵循的步驟、預期
   格式，以及技能一律應納入或避免的內容。如果有範本
   或優良範例，也請一併加入。
3. **審查並試用草稿。** 檢查指示，並使用一項
   符合實際情境的要求測試技能。如果結果遺漏步驟或偏離
   您期望的格式，請進一步調整。
4. **安裝並重複使用技能。** 啟用技能後，ChatGPT 或 Codex 可以使用
   技能處理相關要求，您也可以明確選取。若工作區設定允許，您也可以
   與團隊成員分享技能。

## 使用外掛程式整合工具及共享工作流程

外掛程式讓可重複使用的功能更容易安裝和分享。外掛程式可以
結合技能與 GitHub、Google Drive 或
Slack 等服務的連接器，也能納入 MCP 伺服器，以提供額外的工具和上下文。

ChatGPT 和 Codex 共用一個通用外掛程式目錄。當您想要
新增現有工作流程而非自行建置時，請瀏覽該目錄。安裝
外掛程式後，請直接描述任務，或明確選擇外掛程式或套件內含的
技能；明確選擇時，請使用所用介面的叫用語法。

[瞭解如何安裝及使用外掛程式](/zh-Hant/codex/plugins)。

## 選擇技能或外掛程式

當特定任務需要可重複使用的指示時，請使用技能。如果您需要
可安裝的套件，以將指示與
已連線的服務或其他工具結合，請使用外掛程式。

您也可以透過
[錄製與重播](/zh-Hant/codex/extend/record-and-replay)，示範工作流程；錄製內容會轉換成
可重複使用的技能。若要封裝及發布自己的套件，請參閱
[建置外掛程式](https://developers.openai.com/plugins/build/plugins)。

若外掛程式需要連線至服務或對外提供 MCP 工具，請參閱
[建置 MCP 伺服器](https://developers.openai.com/plugins/build/mcp-server)。外掛程式準備好接受公開審查後，
請參閱 [提交外掛程式](https://developers.openai.com/plugins/deploy/submission)。

如需更多可重複使用工作流程的範例，請參閱 [在 OpenAI
Academy 中使用技能](https://openai.com/academy/skills/)。
