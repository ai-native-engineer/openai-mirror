在 macOS 上的 ChatGPT 桌面版應用程式中，電腦使用紀錄 **預設為關閉** ，適用於 ChatGPT Pro、Business 和
  Enterprise 使用者。Pro 使用者可以自行選擇
  開啟。在 Business 和 Enterprise 工作區，管理員必須
  先明確授予存取權，各成員才能自行選擇開啟。
  電腦使用紀錄也需要[記憶](/zh-Hant/codex/customization/memories)功能，且
  無法搭配 API 金鑰或 Amazon Bedrock 使用。此功能適用於支援的
  地區，包括歐洲經濟區 (EEA)、瑞士和
  英國。

電腦使用紀錄會將你在各種應用程式和網站上的活動轉換成記憶與時間軸，供 ChatGPT 和 Codex 參考。你可以用自然語言詢問近期工作、接續先前的進度、了解自己的工作模式，並將重複的工作流程轉化為技能或自動化。

只有在你選擇開啟後，才會開始建立使用紀錄。你可以控制哪些應用程式和網站提供活動資料，透過 macOS 選單列查看及暫停資料收集，並隨時檢視或刪除使用紀錄。

電腦使用紀錄取代了先前的 Chronicle 研究預覽版，但這是一套重新打造的系統，而非單純更名。它會利用互動事件，以及透過 macOS 輔助使用功能取得的文字和其他上下文，建立可供你審查與刪除的摘要。使用紀錄中不會包含螢幕截圖，也不會錄製音訊；私密瀏覽模式下的網頁瀏覽活動一律不會納入。

  

## 電腦使用紀錄如何提供協助

電腦使用紀錄會提供近期活動作為上下文。如果某項任務更適合參考檔案、Slack 對話、Google 文件或其他來源，ChatGPT 和 Codex 可以透過使用紀錄找出該來源，再直接讀取。

## 電腦使用紀錄的運作方式

電腦使用紀錄會根據允許的應用程式和網站建立互動事件串流。事件可能包括點按、文字輸入、鍵盤快速鍵、切換應用程式，以及 macOS 透過輔助使用系統提供的上下文。電腦使用紀錄會定期將這些事件轉換成文字摘要和本機記憶檔案。

電腦使用紀錄不會將螢幕截圖納入使用紀錄，也不會錄製麥克風輸入或系統音訊。私密瀏覽模式的網頁瀏覽活動一律不會納入。

在 **設定 \> 電腦使用紀錄 \> 使用紀錄**中，時間軸會依日期
和時間將摘要分組。每個項目可顯示：

- 活動的標題和文字摘要。
- 提供摘要內容的應用程式。
- ChatGPT 辨識出可重複執行的工作時，所建議的技能或自動化。
- 在 Finder 中顯示記憶檔案或刪除項目的操作。

選取 **詢問你的使用紀錄** ，即可透過電腦使用紀錄開始對話，或使用
以下提示詞：

- 「我上次休息前在處理什麼工作？」
- 「我今天稍早在找的提案文件在哪裡？」
- 「請列出我今天處理過的任務及其狀態。」
- 「請為站立會議準備我昨天的工作摘要。」

## 權限與存取

電腦使用紀錄會分別管理工作區存取、個人是否選擇啟用、記憶，以及納入使用紀錄的應用程式或網站：

- **工作區存取權：** 電腦使用紀錄在 Business 和
  企業工作區中預設為關閉，必須由管理員
  明確授予存取權後才能使用。企業管理員可使用 **啟用電腦
  使用紀錄** 功能，在[**工作區設定 \> 權限與角色**](https://chatgpt.com/admin/settings)
  中為適當的工作區角色授予存取權。
- **個人自行啟用：** 授予工作區存取權，只是讓成員可以選擇
  開啟電腦使用紀錄，不會替任何人開啟此功能。每位
  使用者都必須自行選擇啟用，包括 ChatGPT Pro 使用者。
- **記憶：** 電腦使用紀錄也必須啟用[記憶](/zh-Hant/codex/customization/memories)。
  使用 `/memories` 控制個別對話是否可以使用本機記憶，
  或為後續記憶提供內容。
- **應用程式與網站：** 應用程式和網站權限決定哪些
  來源可提供互動事件。你可以只允許特定
  來源，或排除不想納入的應用程式和網站 URL。

如果你的工作區角色沒有存取權，即使變更本機設定，也無法啟用電腦使用紀錄。

## 開啟電腦使用紀錄

電腦使用紀錄預設為關閉。如果你使用 Business 或企業工作區，請先要求管理員授予你存取權，再啟用此功能。管理員核准不代表你已自行選擇啟用。

1. 在 macOS 上開啟 ChatGPT 桌面版應用程式。
2. 在「設定」中的 **整合**區段，選取 **電腦使用紀錄**。
3. 選取 **開啟** ，並詳閱隱私權、權限及本機儲存
   資訊。
4. 如有提示，請開啟 **記憶**。電腦使用紀錄必須啟用記憶功能，
   才能跨對話和任務使用活動上下文。
5. 選擇可納入使用紀錄的應用程式和網站，再依照 macOS 顯示的權限提示操作。

電腦使用紀錄不需要螢幕錄製權限。如果未顯示這項設定，請確認你的方案支援電腦使用紀錄；如適用，也請確認工作區管理員已啟用該功能。

## 控制納入的內容

你可以決定哪些應用程式和網站會納入日後的使用紀錄，以及電腦使用紀錄是否正在收集互動事件。

### 選擇應用程式與網站

在 **設定 \> 電腦使用紀錄 \> 權限**中，選擇電腦使用紀錄可納入的應用程式
與網站：

- **排除這些應用程式** 和 **排除這些網站** 會封鎖你指定的應用程式或 URL，
  同時允許其他支援的來源。
- **只納入這些應用程式** 和 **只納入這些網站** 只會允許
  你明確選擇的來源。

你也可以選取使用紀錄時間軸項目中的應用程式圖示，將該應用程式排除在日後的使用紀錄之外；之後仍可重新納入。

私密瀏覽模式的網頁瀏覽活動一律不會納入。變更應用程式或網站權限，只會影響日後的使用紀錄。若要移除既有項目，請將其刪除或清除。

### 暫停、繼續或停止收集

透過電腦使用紀錄設定或 macOS 選單列，控制此功能何時收集活動：

- 選取 macOS 選單列中的 ChatGPT 圖示，展開「電腦使用紀錄」選單，即可查看擷取了哪些活動，並存取相關控制項。
- 選取 **暫停** 可停止收集新的互動事件；準備再次開始時，
請選取**繼續** 。
- 關閉電腦使用紀錄，即可停止收集日後的活動。

電腦使用紀錄可能納入通訊應用程式和網站中的互動事件。與他人通訊時，除非事先取得對方明確同意，否則請關閉此功能。若應用程式含有敏感的健康、財務或個人資訊，請考慮暫停此功能，或將這些應用程式排除。

## 審查並清除使用紀錄

開啟 **設定 \> 電腦使用紀錄 \> 使用紀錄** ，即可查看電腦使用紀錄
彙整的內容。你可以在 Finder 中顯示摘要對應的本機記憶檔案、
刪除個別時間軸項目，或清除最近 10 分鐘、最近 1 小時、最近 1 天
或全部的使用紀錄。你也可以透過 macOS 選單列，清除最近使用的
應用程式的上一個工作階段。

清除使用紀錄時，系統會刪除相關互動事件及據此建立的所有記憶。此操作無法復原。

## 隱私權與本機儲存

電腦使用紀錄會將互動事件串流暫時儲存在你的 Mac 上，讓 ChatGPT 和 Codex 能夠產生記憶並建立建議的工作流程。此串流可能包含點按、文字輸入等活動，以及透過 macOS 輔助使用功能取得的文字和其他上下文。電腦使用紀錄不會將螢幕截圖納入使用紀錄，也不會錄製麥克風輸入或系統音訊。私密瀏覽模式的網頁瀏覽活動一律不會納入。

暫存事件檔案最多保留 48 小時。產生的記憶檔案會留在你的檔案系統中，直到你刪除或清除為止；你可以透過「使用紀錄」時間軸顯示這些檔案。

### 電腦使用紀錄會將我的資料儲存在哪裡？

電腦使用紀錄會將互動事件暫存在你的 Mac 上。事件
檔案會隔離於 ChatGPT 的
[App Group](https://developer.apple.com/documentation/xcode/protecting-local-app-data-using-containers)中，
因此其他應用程式未經明確授權便無法存取這些檔案。
ChatGPT 和 Codex 會在 48 小時後刪除這些事件檔案。

電腦使用紀錄會產生與 Codex 相同類型的本機記憶，也就是可供讀取和修改的純文字
Markdown 檔案。這些檔案
儲存在 `$CODEX_HOME/memories/extensions/skysight/` 中，該路徑通常會解析為
`~/.codex/memories/extensions/skysight/`。

### 哪些資料會與 OpenAI 分享？

電腦使用紀錄會在本機擷取互動事件，並定期啟動短暫的 Codex 工作階段，存取互動事件串流，將你的活動彙整成記憶。

OpenAI 會在其伺服器上處理暫存事件檔案以產生記憶，並將這些記憶儲存在你的 Mac 本機。除非法律另有要求，否則 OpenAI 不會在處理後保留這些事件檔案。OpenAI 也不會將其用於訓練。

當 ChatGPT 或 Codex 在後續對話中使用記憶時，相關記憶內容
和互動事件可能會納入上下文。這些對話內容可能
用於改善 OpenAI 模型，但前提是你的
[ChatGPT 資料控制設定](https://help.openai.com/en/articles/7730893-data-controls-faq)允許。
這些記憶也遵循
[與其他 Codex 記憶相同的對話層級控制](/zh-Hant/codex/customization/memories#control-memories-per-chat)。

### 提示注入風險

電腦使用紀錄會增加應用程式和網站內容造成提示注入的風險。舉例來說，如果你造訪含有惡意指示的網站，ChatGPT 或 Codex 可能會遵循這些指示。

## Token 用量

電腦使用紀錄在彙整活動並建立記憶時，會耗用 Token。

## 疑難排解

如果電腦使用紀錄可用但無法啟動：

1. 確認已開啟 **記憶** 。
2. 開啟 **設定 \> 電腦使用紀錄** ，並依照顯示的狀態選取 **完成設定**、 **繼續**
   或 **再試一次**。
3. 如果該設定仍無法使用，請結束並重新開啟 ChatGPT 桌面版應用程式。
