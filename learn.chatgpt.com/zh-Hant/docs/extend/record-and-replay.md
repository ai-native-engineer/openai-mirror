錄製與重播適用於 macOS。電腦功能也必須可供使用並已啟用。

錄製與重播可讓你在 Mac 上示範工作流程，並將其轉換成可重複使用的技能。若工作流程具有重複性、取決於你的偏好，或直接示範比在提示詞中描述更容易，就適合使用此功能。

例如，你可以錄下如何申報費用、預訂停車位、建立設定正確的議題、發布影片，或下載定期報告。ChatGPT 或 Codex 可以將這種操作模式封裝成技能，供你日後搭配電腦功能、瀏覽器操作、已連線的外掛程式，或結合這些方式再次使用。

## 開始之前

選擇一個你已經知道如何完成的工作流程。錄製與重播在步驟穩定且成功標準明確時效果最佳。

## 開始錄製

1. 在 ChatGPT 桌面版應用程式中，選取 ChatGPT 並在切換器中開啟 Work，或選取 Codex。接著開啟 **外掛程式**。
2. 開啟 **+** 選單。
3. 選取 **錄製技能**。
4. 審查建議的提示詞，補充任何有用的上下文，然後送出。
5. 當對話要求取得錄製你操作的權限時，請在準備好示範工作流程後核准要求。
6. 在 Mac 上執行該工作流程。
7. 完成後，請從選單列或浮動介面停止錄製，或在對話中表示你已完成。

錄製期間，ChatGPT 或 Codex 會觀察學習工作流程所需的操作和視窗內容。錄製會持續進行，直到你停止錄製。請讓錄製內容聚焦於你希望透過技能傳授的任務。

停止錄製後，ChatGPT 或 Codex 會檢查所擷取的工作流程，並建立技能草稿。技能會說明應在何時使用此工作流程、需要哪些輸入、應遵循哪些步驟，以及如何驗證結果。你也可以要求進一步調整。

## 重播工作流程

開始新的 ChatGPT 或 Codex 對話，並要求它使用所產生的技能。請提供本次不同的值，例如要上傳的檔案、要建立的議題，或報告的日期範圍。

此產品會將技能作為該任務可重複使用的上下文。接著，它可以使用目前環境中可用的工具完成工作流程，包括電腦功能、瀏覽器操作和已安裝的外掛程式。

## 提升錄製品質的技巧

- 示範內容應簡短且完整。
- 開始錄製前，請先說明你的目標，以及每次使用技能時可能不同的特定輸入。
- 使用符合實際情境的輸入，但請避免機密資訊和敏感資料。
- 錄製後，請完善技能，明確指出重要但未直接呈現的偏好，例如命名慣例、欄位預設值或決策點。
- 工作流程完成時就停止錄製，不要繼續錄下無關的清理工作。

## 何時該另行建置外掛程式

錄製與重播可讓你快速根據示範的工作流程建立技能。
如果你想在團隊中發布獨立且穩定的套件、綑綁
多項技能、納入連接器、新增 MCP 伺服器，或管理安裝
中繼資料，請將該工作流程封裝成獨立的外掛程式。請參閱
[建置外掛程式](https://developers.openai.com/plugins/build/plugins)。

## 疑難排解

### 我看不到錄製與重播

如果你的組織使用 `requirements.toml` 管理 Codex，其中的
`[features].computer_use` 要求也會控制錄製與重播。設定
`computer_use = false` 會讓這兩項功能都無法使用。
