## 權限模式

權限會控制 ChatGPT（在桌面應用程式中）和 Codex（在 CLI 或 IDE 中）處理本機操作的方式，例如編輯檔案、執行指令及使用網際網路。您選擇的模式會劃定
ChatGPT 可以自行執行的操作與需要審查的操作之間的界線。

對大多數工作而言，建議先使用 **要求核准**。這可讓 ChatGPT 在
目前的工作區內運作，並在超出該界線前暫停。

選取下方的不同模式，以瞭解各模式如何運作。

## 啟用模式

首次使用 ChatGPT 桌面應用程式時，需要在應用程式設定中啟用各模式。

**要求核准** 一律可用。若要將 **代我核准**（在設定中稱為
**自動審查**）或 **完整存取權** 加入權限選單，請在 ChatGPT 桌面應用程式中開啟
**設定 \> 一般**，然後在
**權限** 下開啟該模式。啟用模式後，該模式便會出現在選單中；這項操作不會
選取該模式，也不會變更現有對話。

  

  可用模式可能會依您的本機組態及您所屬
組織的要求而異。不允許使用的模式會顯示為停用狀態。

## 權限的運作方式

兩項控制機制會搭配運作：

- **沙盒** 會界定 ChatGPT 可存取哪些檔案與網路資源。
- **核准** 會決定 ChatGPT 何時在執行操作前暫停，或將
  要求送交自動審查。

變更要求的審查者並不會擴大沙盒範圍。例如，
**代我核准** 的工作區界線與 **要求核准** 相同；
它會將超出該界線的要求送交自動審查。

在 ChatGPT 桌面應用程式或
IDE 擴充功能中，請使用撰寫工具下方的權限控制項。

在 CLI 中輸入 `/permissions`。如需技術詳細資訊，請參閱
[沙盒](/zh-Hant/codex/sandboxing)、[自動審查](/zh-Hant/codex/sandboxing/auto-review)，或
[權限設定檔](/zh-Hant/codex/permissions)。
