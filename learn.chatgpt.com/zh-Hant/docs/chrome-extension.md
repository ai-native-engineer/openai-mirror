透過 ChatGPT 瀏覽器擴充功能，您可以從 ChatGPT 桌面版應用程式操作 Google Chrome、Microsoft Edge、Brave、Opera 或 Vivaldi。ChatGPT 可以讀取您已登入的網站內容，或在網站上執行操作，例如 LinkedIn、Salesforce、Gmail 或內部工具。

這五款瀏覽器都支援在桌面版應用程式中
提及分頁及控制瀏覽器。Chrome、Edge、Brave 和 Vivaldi 也支援側邊對話。 **Opera 不支援
側邊對話**；請改從桌面版應用程式啟動 Opera 任務。

設定其他瀏覽器前，請先更新 ChatGPT 桌面版應用程式。瀏覽器是否可用，可能取決於功能推出進度和您的工作區設定。

若要改讓 ChatGPT 控制其內建瀏覽器，請使用 `@Browser`。
[內建瀏覽器](https://help.openai.com/en/articles/20001277-using-the-built-in-browser-in-the-chatgpt-desktop-app)
支援登入，讓您在 ChatGPT 內完成瀏覽工作，且不會使用
您平常的瀏覽器設定檔。

ChatGPT 也能依任務需求切換工具：有專用整合可用時使用外掛程式，需要已登入瀏覽器的上下文時使用您的瀏覽器，而存取 localhost 時則使用內建瀏覽器。

## 在瀏覽器中使用側邊對話

Chrome、Edge、Brave 和 Vivaldi 均可使用側邊對話。

在您目前檢視的頁面旁開啟 ChatGPT，即可針對該頁面提問，或接著執行可同時運用頁面上下文、本機檔案和已連線應用程式的任務。任務需要時，ChatGPT 可以使用您已開啟分頁中的上下文。

1. 開啟您要使用的頁面。
2. 從瀏覽器工具列或 **擴充功能** 選單選取 ChatGPT。在 macOS 上，您
   也可以按下 <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>.</kbd>。
3. 針對該頁面提問，或指派任務給 ChatGPT。

此面板會留在您開啟它的分頁中。您在側邊對話中開始的對話也可在 ChatGPT 應用程式中使用，而且您可以在側邊對話中開啟最近的 ChatGPT 對話，因此可從任一處繼續工作。

  

## 將分頁和選取的文字加入對話

在桌面版應用程式中提及已開啟的瀏覽器分頁，即可讓 ChatGPT 將該頁面用作上下文。在支援側邊對話的瀏覽器中，您也可以在側邊對話中提及分頁，或選取頁面上的文字並將所選內容加入對話，針對特定段落提問，而不必複製整個頁面。

在支援側邊對話的瀏覽器中，您也可以在頁面上按一下滑鼠右鍵，然後選取
**詢問 ChatGPT**。側邊對話會連同相關頁面上下文一起開啟，讓您可以
在瀏覽器中繼續處理該要求。

### 針對 YouTube 影片提問

開啟 YouTube 影片，接著在瀏覽器支援的側邊對話中針對影片提問。如果影片有字幕，ChatGPT 可以使用影片中帶有時間戳記的轉錄稿，說明或摘要內容，或回答相關問題。

請將網頁內容、選取的文字和影片轉錄稿視為不受信任的上下文。要求 ChatGPT 使用這些資訊或據此執行操作前，請先審查頁面和所有要求的權限。

## 設定您的瀏覽器

在電腦上安裝瀏覽器，然後在 ChatGPT 桌面版應用程式中開啟 **設定 \> 電腦** 。
如果主清單中未顯示您的瀏覽器，
請展開 **更多瀏覽器** 。

1. 選取您的瀏覽器，並依照畫面上的提示安裝所需的外掛程式。
2. 選取瀏覽器旁的 **安裝** ，以開啟其擴充功能商店頁面。
   安裝 ChatGPT 擴充功能，並審查瀏覽器顯示的權限提示。
3. 返回 **電腦** ，確認瀏覽器旁顯示 **管理**。
4. 開始 ChatGPT Work 或 Codex 對話，並使用
`@` 提及功能選取您的瀏覽器。請使用已安裝擴充功能的瀏覽器設定檔。

在 **電腦** 中，瀏覽器的切換開關會控制該瀏覽器是否出現在
`@` 提及選單中。如要變更網站權限，請改為選取 **管理** 。

## 控制網站存取權

預設情況下，ChatGPT 與每個新網站互動前都會先詢問。
ChatGPT 會以網站主機為單位顯示提示，例如 `example.com`。

當 ChatGPT 要求使用網站時，您可以依任務和您的風險承受程度選擇合適的選項：

- **允許一次** ，讓 ChatGPT 使用該網站一次。
- **允許此網站** ，讓 ChatGPT 日後無須詢問即可再次使用該網站。
- **允許所有網站** ，讓 ChatGPT 無須詢問即可使用網站。
- **拒絕** ，阻止 ChatGPT 使用該網站。

### 管理允許和封鎖的網站

在 ChatGPT 桌面版應用程式中，前往 **設定** \> **電腦**，然後選取瀏覽器旁的
**管理** ，以管理網域的允許清單和封鎖清單。
允許清單列出 ChatGPT 無須再次詢問即可使用的網域。
封鎖清單列出 ChatGPT 不應使用的網域。受支援的瀏覽器
共用這些網站權限。

從允許清單移除某個網域後，ChatGPT 使用該網域前會再次詢問。從封鎖清單移除某個網域後，ChatGPT 就可以再次詢問是否允許使用該網域，而不再將其視為已封鎖。

#### 允許所有網站 

如果您選取 **允許所有網站**，ChatGPT 在使用網站前
將不再要求確認。只有在您放心讓 ChatGPT 使用瀏覽器中開啟的任何網站時，
才應選擇此選項。

#### 瀏覽記錄 

瀏覽記錄可能包含敏感的遙測資料、內部 URL、搜尋字詞，以及已登入裝置上瀏覽器工作階段中的活動。如果您允許 ChatGPT 存取瀏覽記錄，相關記錄項目可能會成為 ChatGPT 執行任務時所用上下文的一部分。惡意或誤導性的頁面內容可能增加 ChatGPT 將這些資料複製到非預期位置的風險。

ChatGPT 想使用瀏覽記錄時會先詢問。ChatGPT 會將瀏覽記錄的存取範圍限制於當次要求，且瀏覽記錄不提供一律允許的選項。

## 資料與安全性

<a id="chrome-extension-permissions"></a>

### 瀏覽器擴充功能權限

安裝擴充功能時，瀏覽器會要求您同意授予權限。例如，Chrome 的權限提示可能包括：

- 存取網頁偵錯工具
- 讀取及變更您在所有網站上的所有資料
- 讀取及變更您所有已登入裝置上的瀏覽記錄
- 顯示通知
- 讀取及變更您的書籤
- 管理您的下載項目
- 與搭配使用的原生應用程式通訊
- 檢視及管理您的分頁群組

這些擴充功能權限讓擴充功能能夠執行瀏覽器工作流程。ChatGPT 在任務期間使用網站或瀏覽記錄之前，仍會透過自身的確認機制、設定、允許清單和封鎖清單進行控管。

### 記憶

「電腦」功能會遵循您的「記憶」設定。若已開啟記憶，ChatGPT 在您的瀏覽器中工作時，可以使用已儲存的相關記憶。若已關閉記憶，瀏覽器控制就不會使用記憶。

### OpenAI 會儲存哪些瀏覽資料

OpenAI 不會另外儲存您透過擴充功能操作瀏覽器的完整記錄。只有當瀏覽器活動成為 ChatGPT 上下文的一部分時，OpenAI 才會儲存這些活動，例如 ChatGPT 從網頁讀取的文字、螢幕擷取畫面、工具呼叫、摘要、訊息，或對話中包含的其他內容。

您的 ChatGPT 資料控制設定適用於在上下文中處理的內容。除非任務確實需要機密資訊或高度敏感的資料，且您會在場審查每則提示詞，否則請避免透過瀏覽器任務傳送這些內容。

## 疑難排解

如果 ChatGPT 無法連線至您的瀏覽器，請先在「設定」中確認 ChatGPT 嘗試存取的網站不在封鎖清單內。如果網站未遭封鎖，請依序進行以下檢查：

1. 請更新 ChatGPT 桌面版應用程式。如果您安裝了多個 ChatGPT 或 Codex 桌面版應用程式，請逐一更新，或移除不再使用的副本。
2. 重新啟動瀏覽器。在 Chrome、Edge、Brave 或 Vivaldi 中，從
   工具列或 **擴充功能** 選單重新開啟 ChatGPT，並確認側邊對話能夠載入。Opera 不提供側邊對話；
   請從桌面 App 檢查其連線狀態。
3. 在 **設定 \> 電腦**中，確認您的瀏覽器已列出，且顯示
**管理**。如果仍顯示 **安裝**，請再次依照設定流程操作。
   如果瀏覽器未出現在 `@` 提及選單中，請開啟該瀏覽器的開關。
4. 請確認您使用的是已安裝擴充功能的瀏覽器設定檔。如果您使用多個設定檔，請在目前使用的設定檔中安裝並啟用擴充功能。
5. 開始新的 ChatGPT Work 或 Codex 對話，然後再次嘗試瀏覽器任務。這樣可以清除該對話專屬的連線狀態。
6. 重新啟動 ChatGPT 桌面版應用程式，然後再試一次。如果擴充功能仍無法連線，
   請透過 **設定 \> 電腦**重新安裝。
7. 如果 ChatGPT 仍無法使用瀏覽器，請在應用程式中執行 `/feedback`，
   並在聯絡支援團隊時附上對話 ID。

### 上傳檔案

如果 Chrome 任務需要從您的電腦上傳檔案，請在 Chrome 中允許 Chrome 擴充功能存取檔案網址：

1. 在 Chrome 中，點選工具列上的擴充功能圖示，然後按一下 **管理
   擴充功能**。
2. 在擴充功能資訊卡上，按一下 **詳細資料**。
3. 開啟 **允許存取檔案網址**。

變更設定後，請再次啟動 Chrome 任務。
