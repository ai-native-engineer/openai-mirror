使用 Codex 建立終端工作流程

瞭解如何運用 CLI 功能，繼續先前的工作階段、加入視覺或網頁上下文、拆分複雜工作，以及將 Codex 連接至開發工具。

返回已儲存的對話

重新開啟目前程式碼庫中最近的對話；若要回到較早的工作，也可以搜尋所有本機對話。

在提示詞中加入視覺上下文

在第一個提示詞中附上錯誤螢幕截圖、架構圖或設計參考，或將圖片貼到互動式撰寫工具中。

拆分大型調查工作

請 Codex 將範圍明確的工作委派給專門的智慧體，再將其調查結果帶回主要終端工作階段。

搜尋最新資訊

若任務依賴最新版本、文件或外部行為，可將該次執行切換為即時網頁搜尋。搜尋活動仍會顯示在對話記錄中。

將工作移至 Codex 雲端

瀏覽進行中和已完成的對話、將工作提交至已設定的環境，並從終端把結果套用至本機程式碼庫。

使用 MCP 連接外部工具

加入本機或遠端 MCP 伺服器，視需要進行身分驗證，並在 Codex 使用工具前，檢查目前工作階段有哪些可用工具。

為每次執行設定界限

設定 Codex 何時無須詢問即可編輯檔案或執行指令，並在繼續前檢查目前使用的沙盒與可寫入根目錄。

讓 Codex 配合你的終端環境

產生 Shell 自動完成項目、選擇語法主題，並使用由 VISUAL 或 EDITOR 設定的編輯器開啟較長的提示詞。

瞭解 Codex CLI 能做什麼

在同一套專注的終端工作循環中，完成互動式工作、自動化、審查與委派。

深入瞭解

讓整個程式碼編寫循環都在終端中完成

在程式碼庫中啟動 Codex，探索不熟悉的程式碼、規劃變更、編輯檔案，並執行本機開發工具。引導目前的回合，在指令與差異出現時逐一檢查，並將後續工作留在同一工作階段中。

Codex CLI 在終端中檢查程式碼庫、編輯程式碼並執行測試

使用技能與外掛程式

將可重複使用的指示封裝為技能，再加入外掛程式；如此一來，無須離開 CLI，即可讓 Codex 連接團隊的工具與資料。

Codex CLI 中可用的技能、外掛程式和已連接的開發工具

在變更發布前進行審查

針對未提交的變更、某次提交或基底分支執行專門審查。Codex 會按優先順序回報發現的問題，且不會修改工作樹，讓你能在提交或開啟 Pull Request 前處理風險。

Codex CLI 回報本機程式碼審查中按優先順序排列的發現

你在終端中工作

在一套專注的工作循環中，探索及編輯程式碼庫並執行其中的程式碼。

你需要使用指令碼或 CI

在可重複執行的工作流程中執行非互動式指令。

你想進行本機程式碼審查

在提交或開啟 Pull Request 前檢查變更。

你想將工作交給雲端處理

啟動雲端對話，稍後再返回終端。

試用終端工作循環

從一項具體任務開始，審查建議的工作，並在同一工作階段中繼續後續作業。
