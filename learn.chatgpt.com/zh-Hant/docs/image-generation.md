請 ChatGPT 生成或編輯圖像。使用圖像生成功能，製作 UI 素材、
橫幅、背景、插圖、精靈圖集和預留位置；這些內容可與程式碼一併
建立，也可在 ChatGPT 對話中建立。

透過 App 撰寫工具要求生成圖像。若希望
ChatGPT 轉換現有素材或將其用作視覺參考，請加入參考圖像。

### 審查和編輯生成的圖像

選取生成的圖像以開啟展開檢視器。你可以在
**聚焦檢視** 和 **畫布檢視** 之間切換：前者可檢查單張圖像，後者可查看同一對話中
生成的圖像。

在 **畫布檢視** 中，使用 **留言** 對一或多張
圖像提供精確意見。選取 **多選** 以選擇要納入的圖像，然後
在同一個對話中送出留言及任何其他編輯指示。
請說明哪些部分應變更、哪些部分應維持不變。

在 ChatGPT Web 對話中要求生成圖像。若希望 ChatGPT 編輯參考圖像或將其用作視覺指引，請將圖像附加到
撰寫工具。

在互動式工作階段中描述圖像，或加入 `$imagegen`，以明確叫用
圖像生成技能。若要讓現有圖像作為結果的視覺參考，請使用 `-i` 或
`--image` 附加該圖像。

從擴充功能對話要求生成圖像。將參考圖像拖入
撰寫工具時按住 <kbd>Shift</kbd>，即可讓 Codex 編輯或延伸
現有素材。

## 生成或編輯圖像

使用自然語言描述圖像。若希望
ChatGPT 轉換或延伸現有素材，請加入參考圖像。

在提示詞中加入 `$imagegen`，以明確叫用
圖像生成技能。

內建圖像生成功能使用 `gpt-image-2`，並計入你的一般
Codex 用量限制。視圖像品質和尺寸而定，圖像生成消耗方案內含額度的速度，平均是
不使用圖像生成的類似對話回合的 3–5 倍。
若要處理較大的批次，請在環境中設定 `OPENAI_API_KEY`，並要求
ChatGPT 透過 API 生成圖像，此時將採用 API 定價。

ChatGPT Web 中的圖像可用性與用量限制，取決於你的方案和
工作區設定。若要以程式方式生成圖像，請使用 [圖像
生成 API](/api/docs/guides/image-generation)。

## 撰寫有效的圖像提示詞

有效的圖像提示詞通常只需一至三句清楚的說明。請描述
決定結果成敗的細節：

- 說明圖像的用途或目標受眾。
- 指出主要主體及正在發生的事情。
- 描述場景、構圖和視覺風格。
- 若取景方式、尺寸、光線、色彩或材質很重要，請一併說明。
- 說明限制條件，包括圖像不得包含的任何內容。

與其描述籠統感受，不如使用具體的視覺語言。例如，請說明
光線來自何處，而不是要求「漂亮的光線」。任何
必須固定不變的要求，都請重複說明。

## 精修結果

先從核心構想開始，再進行小幅且有針對性的修改。每次只調整一個
元素，以免構圖和其他重要細節偏移。
你也可以選取圖像中的特定區域，並說明要對該
區域進行的變更。

編輯現有圖像時，請明確說明哪些部分要變更、哪些部分必須
保持不變。

若要進行範圍較廣的修改，意見應直接且可據以執行：調亮圖像、
降低色彩飽和度、簡化背景，或在保留
構圖的同時變更風格。

## 使用多張參考圖像

當一張圖像用來界定內容，另一張用來界定風格、版面配置或其他視覺方向時，
請使用少量參考圖像。依序標示每張
圖像並解釋它們之間的關係。合併元素時，請使用
前景、背景、左側和右側等空間方位詞。

## 在圖像中加入文字

圖像內的文字應簡短，並精確指定。將確切文字置於
引號內，保留所需的大小寫，並描述字型
風格、大小、顏色和位置。若名稱不常見，請逐一拼出字母，
尤其在準確性很重要時。請說明是否允許任何其他文字。

## 建立資訊圖表和內容密集的版面配置

圖像生成可協助草擬解說圖、海報、加上標籤的圖解、
時間軸和其他資訊豐富的視覺內容。請描述資訊
層級和版面配置、保持標籤簡潔，並要求清晰呈現文字。
若文案密集或排版對正式成品至關重要，請逐字檢查，並視需要
在設計工具中完成素材製作。

## 其他注意事項

- **謹慎使用肖像。** 描繪真人時，請視情況提供
  參考照片，並確認已取得使用
  其肖像的許可。
- **要求採用原創手法。** 請要求一般性或原創設計，
  不要模仿特定品牌、產品、藝術家或藝術作品。
- **是否註明來源由你決定。** 生成的圖像不必標註 OpenAI，
  但若有助於交代背景，你可以說明素材的製作方式。
- **遵守適用政策。** 使用圖像時，請遵循你所屬
  組織的準則和 [OpenAI 的使用
  政策](https://openai.com/policies/usage-policies/)。
