寵物是可選用的動畫夥伴，可協助你掌握工作進度。寵物出現的位置
及其顯示內容取決於你使用的介面。選擇寵物只會改變它的
外觀，不會影響 ChatGPT 完成任務的方式。

## 使用浮動寵物

在 ChatGPT 桌面版應用程式中，寵物可浮在其他應用程式視窗上方，協助
你掌握各個對話的活動。

### 選擇並喚醒寵物

1. 開啟應用程式底部的個人檔案選單，然後選取 **寵物**。你也可以
   開啟 [**設定**](codex://settings)，然後前往 **寵物**。
2. 選擇內建或自訂寵物。
3. 輸入 `/pet`，或開啟指令選單並選取 **喚醒寵物**。

選取 **收起寵物**（可在 **設定 \> 寵物** 或指令選單中找到），或再次輸入
`/pet` 即可隱藏寵物。你的選擇和寵物位置會持續保留，
重新開啟應用程式後也是如此。

選擇自訂寵物後，該寵物也會出現在你的 **個人檔案** 畫面中。

### 瞭解寵物狀態

| 狀態          | 說明                                                  |
| --------------- | -------------------------------------------------------- |
| **執行中**     | 對話正在執行任務。                              |
| **需要輸入** | 對話需要你的核准、答覆或其他決定。 |
| **已就緒**       | 對話已執行完畢，且有未讀活動。            |
| **受阻**     | 對話執行失敗或發生系統錯誤。             |

當多個對話都有活動時，寵物會優先顯示需要
輸入的對話，接著依序顯示受阻、已就緒和執行中的對話。開啟活動匣以
選擇對話。

選取寵物以返回 ChatGPT，或選取活動以開啟對應的對話。
活動匣獨立於 [系統
通知](/zh-Hant/codex/notifications?surface=app)。

### 掌握電腦活動

在 macOS 上，[電腦](/zh-Hant/codex/computer-use) 的子母畫面視窗可以
貼附在已喚醒的寵物旁。移動寵物時，視窗也會跟著移動。

### 建立自訂寵物

1. 開啟 **設定 \> 寵物**，然後選取 **建立自己的寵物**。
2. 應用程式會安裝隨附的 `hatch-pet` 技能、重新載入技能，並開啟
   新對話。
3. 描述你想要的寵物，然後送出提示詞。
4. 任務完成後，回到 **設定 \> 寵物**，選取 **重新整理**，
   然後選擇你的新寵物。

在桌面版應用程式中建立的自訂寵物會儲存在本機電腦上。
這些寵物不會自動同步至 ChatGPT 網頁版。

### 減少動態效果

寵物會遵循作業系統的減少動態效果設定。啟用減少
動態效果後，寵物會改用靜止影格，而非精靈圖動畫。

## 在網頁版中選擇寵物

如果你的帳戶和工作區可使用寵物，請開啟 **設定 \>
個人化 \> 寵物 \> 選擇寵物**。選擇內建寵物，或選擇
**預設**，即可在不使用寵物的情況下使用 ChatGPT。

網頁版寵物會顯示在支援此功能的 ChatGPT Work 對話中，但不提供
桌面版應用程式的浮動覆疊層、活動匣或 `/pet` 指令。

### 上傳自訂寵物

選取 **上傳寵物**，以新增自訂精靈圖集。檔案必須是
具透明背景的 PNG 或 WebP，尺寸必須正好為 1536 × 1872 像素，且不得大於 20 MiB。
你可以在同一項設定中編輯、下載、重新整理或刪除已上傳的寵物。

## 選擇終端寵物

在互動式 Codex CLI 工作階段中：

- 輸入 `/pets` 或 `/pet` 以開啟寵物選擇器。
- 輸入 `/pets <name>` 即可直接選擇寵物。
- 輸入 `/pets off` 即可停用終端寵物。

選擇器包含內建寵物，以及安裝在你電腦上的
相容自訂寵物。終端寵物會呈現目前 CLI 工作階段的活動狀態。它使用
**執行中**、**需要輸入**、**已就緒** 和 **受阻** 等狀態，但不會
提供桌面版應用程式的多對話活動匣。

終端寵物必須搭配 iTerm2 3.6 或更新版本，或支援 Kitty 圖形或
Sixel 的終端使用。在 tmux 和 Zellij 中無法使用終端寵物。

## IDE 擴充功能中的寵物

Codex IDE 擴充功能不提供寵物選擇器或浮動寵物覆疊層。
若要使用自己的寵物，請使用 ChatGPT 桌面版應用程式或 Codex CLI。
