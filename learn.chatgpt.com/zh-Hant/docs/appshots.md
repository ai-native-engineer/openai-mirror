應用程式快照可讓你將最前方的應用程式視窗傳送至 ChatGPT 對話。若你正在
電腦上使用另一個應用程式，並想將目前的上下文提供給
ChatGPT，讓它協助你完成任務，便可使用應用程式快照。

  應用程式快照可在 macOS 版 ChatGPT 桌面應用程式中使用。同時按下兩個 Command
鍵，或你自訂的應用程式快照快速鍵，即可擷取應用程式快照。

## 應用程式快照擷取的內容

應用程式快照只會擷取最前方的視窗，內容可能包括：

- 可見視窗的圖像。
- 該視窗中可取得的文字，包括可見文字，以及應用程式所提供、位於
可見捲動範圍之外的文字。

將應用程式快照加入對話後，它會如附件般運作。ChatGPT
會將應用程式快照儲存在本機的工作階段檔案中，就像你手動附加的檔案或圖像
一樣。

## 使用應用程式快照的時機

當 ChatGPT 必須先取得 Mac 應用程式的上下文才能執行操作時，請使用應用程式快照。

範例：

- 分享 API 參考頁面，並要求 ChatGPT 撰寫使用該 API 的指令碼。
- 分享電子郵件或行事曆檢視畫面，並要求 ChatGPT 草擬後續步驟。
- 分享圖像編輯器、設計稿或預覽視窗，並要求 ChatGPT 修改
相關資產或程式碼。
- 分享錯誤、設定面板或應用程式狀態；這類內容直接展示會比文字
描述更容易。

## 擷取應用程式快照

1. 將你要分享的應用程式視窗移到最前方。
2. 同時按下兩個 Command 鍵，或你在 ChatGPT
設定中指定的自訂快速鍵。
3. 如果 ChatGPT 要求，請授予所需的 macOS 權限。
4. 要求 ChatGPT 使用該應用程式快照執行任務。

  

根據預設，ChatGPT 會為應用程式快照建立新對話。如果你在過去 60 秒內曾與某個
對話互動，ChatGPT 會改為將應用程式快照加入最近互動的
對話。連續擷取的應用程式快照會加入同一個對話。

你可以在應用程式設定中變更應用程式快照的快速鍵。

## 權限與安全性

ChatGPT 可能會先要求下列權限，才能擷取應用程式快照：

- **螢幕與系統音訊錄製** 可讓 ChatGPT 擷取
  最前方視窗的圖像。
- **輔助使用** 可讓 ChatGPT 讀取最前方視窗中可取得的文字。

擷取應用程式快照會將擷取到的圖像和可取得的文字分享給 ChatGPT。
除非任務需要使用敏感內容，否則請避免擷取含有這類
內容的應用程式快照。

審查應用程式快照時，請採用與審查是否要將螢幕截圖和文件
分享給 ChatGPT 相同的方式。

## 限制與疑難排解

應用程式快照可在 macOS 版 ChatGPT 桌面應用程式中使用。如果你在 CLI 中繼續某個
已包含應用程式快照的對話，該附件仍會是對話
記錄的一部分，但 CLI 無法建立新的應用程式快照。

對於某些應用程式和網站，包括 Google Docs、Gmail、Google Sheets 和
Google Slides，ChatGPT 可能只會收到可見的螢幕截圖，並且可能無法取得
完整文件或畫面外的文字。在 ChatGPT Work 或 Codex 中，ChatGPT 可以使用
已安裝的對應外掛程式來存取相關應用程式內容，並協助處理你的
要求。

若應用程式快照無法運作：

1. 開啟 **系統設定 \> 隱私權與安全性**。
2. 在 **螢幕與系統音訊錄製** 和 **輔助使用** 中，檢查 Codex
   電腦的權限。
3. 重新啟動應用程式，然後再試一次。
