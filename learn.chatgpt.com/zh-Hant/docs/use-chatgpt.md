## 將想法化為實用成果

ChatGPT 是一個 AI 智慧體，你可以用自然語言與它溝通：

1. 從問題、想法、初步筆記、檔案，或你需要完成的任務開始。

2. 請 ChatGPT 解釋資訊、拓展想法、草擬內容、研究主題、分析資料，或創作新內容。

3. 提供它所需的上下文和工具，例如檔案、網頁搜尋、專案或外掛程式。

4. 審查結果、調整方向，並要求修改。你不需要一開始就寫出完美的提示詞，也不需要特殊指令。

## 選擇工作方式

使用「對話」提問或來回討論。想讓 ChatGPT 完成較大型的任務並產出可供審查的結果時，請在切換器中開啟 Work。需要開發者檢視畫面或更詳盡的技術細節時，尤其是進行軟體開發時，請選擇 Codex。

| 選擇       | 使用時機                              | 範例                                                                     |
| ------------ | --------------------------------------------- | ---------------------------------------------------------------------------- |
| 對話         | 與 ChatGPT 一起逐步處理事情           | 提出問題、搜尋網頁、腦力激盪、草擬訊息、比較選項 |
| ChatGPT Work | 設定預期成果，取得可供審查的結果 | 製作簡報、分析檔案、草擬報告、擬定專案計畫           |
| Codex        | 使用開發工具並查看技術細節 | 偵錯程式碼、執行測試、審查 PR、實作功能                      |

使用「對話」提問、腦力激盪、草擬或修改文字、摘要檔案內容、
比較選項，或釐清較大型的任務。在 Codex 中，將游標指向「 **新增對話**」，再
於選項可用時選取「 **快速聊天** 」。

需要已完成且可供審查的成果時，請切換至 **Work** ，並說明
成果應包含哪些內容。請參閱[開始使用 ChatGPT
Work](/zh-Hant/codex/get-started-with-work)，了解任務範例、提示詞和
最佳做法。

### ChatGPT Work 可以做什麼

ChatGPT Work 可以規劃任務、蒐集上下文、使用工具，並持續執行工作，直到產出可供你審查的成果。

  

你可以要求它：

- **研究並分析資訊。** 搜尋網頁、瀏覽網站、
  比較資訊來源、讀取檔案、分析資料，並總結研究結果。
- **使用你的檔案與工具。** 加入已上傳的檔案、
[專案](/zh-Hant/codex/projects)、記憶、ChatGPT Library，以及已安裝的
[外掛程式](/zh-Hant/codex/plugins)。外掛程式可提供透過連線取得的資訊、可重複使用的
  工作流程，以及支援的操作。
- **產出完整檔案。** 草擬並完善[文件、簡報、
  試算表和 PDF 檔案](/zh-Hant/codex/artifacts-viewer)。審查結果、提出
  具體修改需求，並下載完成的檔案。
- **建立視覺與互動式作品。** 生成或編輯
[圖像](/zh-Hant/codex/image-generation)，製作互動式
[視覺化](/zh-Hant/codex/visualizations)，並透過
  [Sites](/zh-Hant/codex/sites) 建立或分享網站和應用程式。
- **跨網站與應用程式完成工作。** 使用[瀏覽器](/zh-Hant/codex/browser)進行
  研究並與網站互動。在桌面 App 中，也可以使用
[瀏覽器擴充功能](/zh-Hant/codex/chrome-extension)、
[電腦](/zh-Hant/codex/computer-use)和[應用程式快照](/zh-Hant/codex/appshots)，
  前提是這些功能可用。
- **執行程式碼並審查技術工作。** 執行程式碼與 shell 指令、分析
  資料、檢查檔案、[審查程式碼](/zh-Hant/codex/code-review)，並使用
  所選環境可存取的程式碼庫。
- **委派並持續處理耗時較長的任務。** 將彼此獨立的工作分派給
[子代理程式](/zh-Hant/codex/agent-configuration/subagents)，追蹤其進度，並
  讓[長時間執行的工作](/zh-Hant/codex/long-running-work)持續進行。
- **重複執行實用的工作流程。** 設定[排程
  任務](/zh-Hant/codex/automations)來處理重複性工作，並使用
[技能](/zh-Hant/codex/skills-and-plugins)來重複使用工作流程。
- **透過語音處理任務。** 若你的方案支援，即可在桌面 App 中使用
[ChatGPT 語音](/zh-Hant/codex/features/voice)開始工作、查看進度或
  調整方向。

  功能的可用性取決於你的方案、平台、地區、推出進度及工作區
  設定。工作區管理員可以控制 ChatGPT Work、
  外掛程式與瀏覽器的使用權限，以及網路存取權限。ChatGPT Work 和 Codex 共用[用量
  限制](/zh-Hant/codex/pricing)。

### 選擇在雲端或本機工作

在網頁版中，ChatGPT Work 會在受管理的雲端環境中執行。在桌面 App 中，你可能也能選擇任務的執行位置：

- **雲端：** 在隔離的託管環境中執行工作。關閉桌面 App 後，任務仍可持續執行，
  你也能從網頁版或行動 App 接續處理。雲端工作
  可以使用已上傳的檔案、已連線的工具和已核准的網站。
- **在本機工作：** 使用電腦上的檔案、應用程式或瀏覽器。
  當你的帳戶或工作區已啟用本機工作時，
  就可以在桌面 App 中使用。

ChatGPT 會顯示進度，並在需要資訊或核准時暫停。針對影響重大的操作，請先審查再核准；使用或分享最終結果之前，也請先檢查內容。

### 比較桌面 App 中的 ChatGPT Work 與 Codex

ChatGPT Work 與 Codex 的功能有部分重疊。如果你偏好 Codex，仍可繼續使用它進行研究、製作文件與簡報，以及處理其他知識工作。當兩者都可供你使用時，桌面 App 會調整介面與智慧體呈現工作成果的方式。

| 差異          | 桌面 App 中的 ChatGPT                                                 | 桌面 App 中的 Codex                                              |
| ------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 如何開始      | 選取 **ChatGPT**，然後切換至 **Work**                            | 在產品選取器中選取 **Codex**                          |
| 可查看的對話       | 查看在網頁版和行動裝置上透過「對話」開始的對話，以及 ChatGPT Work 對話 | 以 Codex 對話和開發專案為主                     |
| 快速聊天          | 無法使用                                                          | 此功能可用時，可在 Codex 中存取來自網頁版和行動裝置的 ChatGPT 對話 |
| 技術細節    | 隱藏 Git 或 shell 指令等技術細節                      | 查看開發相關細節，包括差異比對與審查畫面            |
| 智慧體的溝通方式 | 偏好使用非技術性語言，並呈現已完成的成果                     | 可包含技術與實作細節                  |
| Pull Request 窗格  | 使用 ChatGPT Work 時無法使用                                  | 啟用後即可使用                                            |

### 自然地與 ChatGPT 對話

撰寫需求時，就像在向樂於協助的同事說明一樣。
說明你想達成的目標，補充會影響答案的細節，並描述需要的格式。
第一個提示詞只是起點；你可以透過後續訊息補充上下文，
或進一步調整結果。

你可以用簡單的指示繼續，例如：

- 「請再簡短一些。」
- 「請提供三種不同的做法。」
- 「你做了哪些假設？」
- 「繼續之前，請先問我一些問題。」

進一步了解[提示詞](/zh-Hant/codex/prompting)，或參加
[AI 基礎課程](https://academy.openai.com/home/courses/ai-foundations-juzjs)，
在引導下進行練習。

## 為 ChatGPT 提供適當的上下文

向 ChatGPT 提供與任務相關的資訊、工具和指示。
你不必提供所有資訊，
只需補充會影響成果是否符合需求的上下文。

### 將相關工作集中在專案中

專案可協助你按照主題、目標或持續進行的工作，
整理 ChatGPT 中的內容。若工作會持續一段時間或需要相同的上下文，
請將相關對話、檔案和指示集中在同一個專案中。[進一步了解
專案。](/zh-Hant/codex/projects)

### 附加檔案

你可以上傳或附加文件、簡報、試算表、PDF 檔案、圖片，以及匯出的資料。
需要 ChatGPT 執行以下工作時，就可以使用這些內容：

- 摘要或比較這些內容。
- 找出模式或不一致之處。
- 擷取、清理或重新整理資訊。
- 將這些內容作為建立新檔案的來源資料。

ChatGPT 建立檔案後，請開啟預覽並檢查內容。
接著可以要求修改，不必從頭開始。進一步了解
[如何處理檔案](/zh-Hant/codex/artifacts-viewer)。

### 使用外掛程式連接工具

外掛程式可將 ChatGPT 連接至你工作時使用的工具和資訊，
例如 Google Drive、SharePoint、Salesforce 或 Gong。
如果任務仰賴對話之外的資訊、需要在其他系統中執行操作，
或涉及可重複使用的工作流程，即可使用外掛程式。

  

外掛程式能否使用，取決於你的方案、工作區設定及外掛程式本身。
進一步了解[技能和外掛程式](/zh-Hant/codex/skills-and-plugins)。

## 分享 Codex 對話串的唯讀快照

無論使用哪一種 Codex 方案，你都可以在 macOS 的 ChatGPT 桌面版應用程式中，
建立本機 Codex 對話串的唯讀快照。
快照不會讓其他人存取你的專案或電腦。

分享前，請確認哪些人可以開啟連結：

- **個人帳戶：** 任何擁有連結的人都可以開啟快照。
- **工作區帳戶：** 只有建立快照的工作區中已通過身分驗證的成員，
  才能開啟快照。你可以允許該工作區的所有成員存取，
  或僅允許受邀的人員和群組存取。
  工作區管理員可以停用工作區分享連結。

1. 開啟對話串並選取 **分享**。
   在支援斜線指令的介面中，也可以使用 `/share`。
2. 若使用工作區帳戶，請在 **誰可以存取** 中，選擇工作區的所有成員
   或 **僅限受邀的人員和群組**。若設定為僅限受邀者存取，
   請透過電子郵件地址新增現有的工作區成員，或選擇工作區群組。
3. 等待快照上傳完成，然後選取 **複製連結**。
   開啟對話方塊就會開始上傳，但只有在你
   選取 **複製連結**後，Codex 才會依照你選擇的存取對象和收件人發布快照。
4. 將連結傳送給任何人之前，請先開啟已複製的連結，檢查分享畫面。

快照會擷取分享當下已有且受支援的對話串內容。
後續新增的訊息和變更不會更新既有快照。

分享的快照可能包含使用者可見的訊息、推理摘要、圖片附件、
智慧體查看或產生的圖片，以及檔案變更，包括路徑和差異內容。
快照不包含原始對話串的工具呼叫、shell 指令，
或工具的輸入與輸出。

Codex 會在上傳快照前，遮蔽可透過已知模式辨識的機密資訊。
在傳送連結前，請先檢查分享畫面，因為訊息、圖片或差異內容中
仍可能留有敏感內容，包括檔案路徑。

你無法從分享的快照為原始對話串建立分支。
你可以將快照以附件形式匯入，並在新的對話串中參考快照內容。

若要檢視或撤銷分享連結，請開啟[ChatGPT
資料控制項](https://chatgpt.com/#settings/DataControls)，然後選取 **已分享的連結**。

## 讓結果可直接使用

將第一版結果視為草稿，你可以檢查、質疑並改進它。
即使回覆看似完善，仍可能不完整或有誤，
因此在使用或分享前，請先檢查重要細節。

**檢查成果：**

- 核對重要的數字、名稱、日期、引文和主張。
- 開啟產生的檔案，逐一檢查每個區段、分頁、投影片或頁面。
- 確認 ChatGPT 使用的來源資料正確且為最新。
- 找出缺漏的資訊與缺乏根據的假設。
- 如果結果未達目標，請要求針對不足之處進行修改。

接著請 ChatGPT 嚴格檢驗結果：

- 「你使用了哪些資料來源？」
- 「請為每項主要主張標註來源。」
- 「你做了哪些假設？」
- 「有哪些資訊是你無法存取的？」
- 「哪些因素會讓你改變建議？」
- 「請對照原始檔案，檢查這項結果。」

如果 ChatGPT 無法存取某項資料來源，或無法完成部分任務，請要求它直接說明。明確指出的缺漏，比言之鑿鑿的猜測更容易補救。

  法律、財務、醫療、安全性及其他影響重大的決策，都需要由相關領域的專家審查。請用 ChatGPT 協助你在掌握充分資訊後做出判斷，而非讓它代替你判斷。
