# 功能

探索 ChatGPT 中的工作流程、能力、指令和設定

探索使用 ChatGPT 工作時可用的工作流程、能力、指令和設定。

ChatGPT 將專案、長時間進行的對話、網頁瀏覽、檔案、圖像及外掛程式整合在一起。指令、設定和疑難排解參考資料則讓這些工作流程更加完整，無論是選擇合適的工作流程，還是為每段對話提供所需的上下文和工具，都有所涵蓋。

探索專案和對話

Codex 側邊欄和「新增」選單，提供對話、外掛程式與內容工具

工作流程

組織、委派及審查工作的方式。

專案和對話

集中管理相關的對話、上下文和工作。

Codex 遠端

從手機啟動任務、核准動作並審查工作。

Sites

在 ChatGPT 中建立、儲存及發布互動式網站和應用程式。

視覺化

將想法和資訊轉換為互動式視覺解說。

排程任務

為週期性工作設定排程，並審查完成後的結果。

長時間執行的工作

你離開時，讓 ChatGPT 繼續工作。

通知

選擇工作需要你留意時，ChatGPT 通知你的方式。

寵物

選擇一個動畫夥伴，追蹤對話動態。

Codex Micro

使用 Work Louder 鍵盤監控及控制 ChatGPT 對話。

能力

供 ChatGPT 理解、創作及採取行動的工具。

瀏覽器

讓 ChatGPT 瀏覽網站並採取行動，同時由你掌握控制權。

電腦

讓 ChatGPT 透過視覺介面與應用程式互動。

ChatGPT 語音

在 ChatGPT 桌面版應用程式的對話、Work 和 Codex 中試用語音。

外掛程式

安裝可重複使用的工作流程、已連結的工具和共用上下文。

網頁搜尋

尋找最新資訊，並將資料來源納入任務。

圖像生成

在工作中建立及編輯圖像。

圖像輸入

將螢幕截圖和圖像用作 ChatGPT 的上下文。

應用程式快照

擷取應用程式狀態，以進行視覺檢查和偵錯。

瀏覽器擴充功能

搭配 ChatGPT 使用 Chrome、Edge、Brave、Opera 或 Vivaldi。

處理檔案

建立、預覽及改進文件和其他生成的檔案。

參考資料

尋找 ChatGPT 桌面版應用程式的指令和設定。

指令

使用應用程式指令、鍵盤快速鍵和深層連結。

斜線指令

使用捷徑執行常見的互動操作。

設定

調整 ChatGPT 桌面版應用程式的偏好設定。

疑難排解

解決 ChatGPT 桌面版應用程式中的常見問題。
