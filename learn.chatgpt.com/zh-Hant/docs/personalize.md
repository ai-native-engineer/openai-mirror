將 ChatGPT 個人化，讓回覆和工作方式更符合您的偏好。您可以自行決定要啟用哪些個人化功能，並隨時在 ChatGPT 桌面版應用程式的設定中變更。

## 選擇個性

選擇 **友善**、 **務實**或 **無** 作為預設個性；此設定位於
**設定 \> 個人化**。個性會改變 ChatGPT 的溝通方式，
但不會改變模型的能力。

## 新增自訂指示

透過自訂指示設定您希望 ChatGPT 在各個
對話中遵循的偏好，例如您偏好的回覆風格。在 Codex 中，這些個人
指示會儲存在您的全域 `AGENTS.md` 檔案中。專案和
程式碼庫也可以提供各自的指示。

[瞭解 `AGENTS.md` 指示的運作方式](/zh-Hant/codex/agent-configuration/agents-md)。

## 運用記憶延續上下文

[記憶](/zh-Hant/codex/customization/memories)可讓 ChatGPT 將先前對話中的實用上下文
帶入後續工作。記憶內容可以包括一貫的偏好、經常採用的工作流程、
專案慣例，以及其他原本需要反覆說明的上下文。

記憶與必要的專案指引彼此獨立。請將
必須一律適用的指示寫在 `AGENTS.md` 或已納入版本控制的專案文件中。

## 透過電腦使用紀錄新增近期活動

[電腦使用紀錄](/zh-Hant/codex/customization/computer-history)是一項可自行選擇啟用的 macOS
桌面功能，可將已獲允許的應用程式和網站中的活動轉化為
記憶與時間軸。此功能會使用互動事件，以及透過 macOS 輔助使用功能取得的文字與其他
上下文。此功能不會在您的使用紀錄中加入
螢幕擷圖，也不會錄製音訊。

啟用前，請先審查電腦使用紀錄涵蓋的內容。您可以隨時暫停這項功能、排除應用程式和網站、檢視或刪除個別時間軸項目，以及清除近期或所有使用紀錄。

## 管理個人化設定

開啟[**設定**](codex://settings)，即可更新您的個性、自訂
指示、記憶，以及其他可用的個人化控制項。請參閱
[ChatGPT 桌面版應用程式設定](/codex/reference/settings)，查看
日常偏好設定概覽。
