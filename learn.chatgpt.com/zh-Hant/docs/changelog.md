## 0.152.0

## 新功能

- Vim 模式支援在草稿中使用 `/` 和 `?` 搜尋、醒目顯示符合項目，以及使用 `n` 和 `N` 重複跳至符合項目。(#41586)
- 速率限制橫幅提供查看用量、管理點數、重設限制及管理方案的操作選項。(#41742)
- 終端介面和 `codex exec` 會顯示憑證更新進度，包括 Amazon Bedrock 的重新身分驗證進度。(#41239)
- MCP 伺服器名稱可包含 `:`、`@`、`/` 和 `.`，讓 CLI 指令與身分驗證流程都能使用套件風格的名稱。(#41700)
- 個別 MCP 工具支援 `output_token_limit` 設定，且在恢復工作階段後仍維持一致的截斷行為。(#41421)
- App Server 用戶端可設定 `thread/shellCommand` 的逾時時間，也支援超過一小時的期限。(#41384)

## 錯誤修正

- 啟用 Vim 的撰寫工具現在會以插入模式開始新草稿，包括送出訊息或發送斜線指令之後。(#41921)
- 自動審查核准請求時，可保留更長的訊息及更多對話記錄。(#41931)

- 核准請求的自動審查會在歷程壓縮後，繼續保留使用者的指示、回答及有效授權。(#41660, #41846, #41852)
- 恢復對話串時，若未提供工作目錄，就會還原已儲存的工作目錄；更新用戶端中繼資料時，也會保留檔案系統權限。(#41567, #41464)
- 更新快取及變更遠端外掛程式時，MCP 工具仍可使用；重試身分驗證時，會使用輔助程式提供的最新標頭。(#41336, #41344, #41396, #41400)
- 開啟模型選擇器時會更新可用模型，同時保留目前醒目顯示的選項。(#41467)
- 修正搭配 Microsoft Store 版 PowerShell 執行 Windows 沙盒時的問題、子程序在終端查詢時停滯的問題，以及舊版 JediTerm 終端中與游標相關的顯示錯亂。(#41227, #41436, #41673)
- 雲端任務請求會拒絕不受信任的後端 URL，並停用重新導向，以保護已儲存的憑證。(#41403)

## 維護作業

- 規劃工具預設為停用；可使用 `tools.update_plan.enabled = true` 啟用。(#41744)
- 啟動時便開始載入外掛程式推薦內容，縮短第一輪互動前的等待時間。(#41375)

## 新功能

- 遠端外掛程式現已預設啟用，目錄列內容更豐富，並支援 npm 市集來源及顯示遠端與本機版本。 (#30297, #26705, #29375, #30981)

## 0.142.2

## 新功能

- 若支援工具搜尋，MCP 工具現在會預設使用此功能，提升工具探索能力，同時維持與較舊模型及供應商的相容性。 (#29486)
- 啟用 `respect_system_proxy` 時，macOS 身分驗證用戶端可遵循系統 Proxy、PAC 與 WPAD 設定。 (#26709)
- 外掛程式可透過本機資訊清單與遠端目錄提供專用的深色模式標誌。 (#29488)
- 應用程式可利用伺服器提供的可見性與較快模型的中繼資料，顯示資訊更豐富的安全緩衝 UI。 (#29473)

## 錯誤修正

- 遠端外掛程式目錄現在會傳回經過編選的特色外掛程式排名。 (#29485)
- Amazon Bedrock 憑證過期時，現在會顯示具體的復原指引，而非籠統的授權錯誤。 (#28992)
- 遠端 stdio MCP 伺服器現在可接受以遠端平台路徑格式表示的絕對工作目錄。 (#29493)
- 遠端 HTTP(S) 圖像輸入現在會傳回清楚且模型可見的驗證錯誤；仍支援內嵌 data URL 與本機圖像。 (#29417, #29419)
- PowerShell 指令若包含安全分類器無法檢查的可執行 AST 區域，現在便需要核准。 (#24092)
- 所選模型缺少必要的中繼資料時，程式碼模式現在會發出警告。 (#29490)

## 例行維護

- 隨附的 OpenSSL 與 esbuild 相依套件已更新至修補後的版本。 (#29487, #29489)
- 格式化工具執行成功時現在不再輸出訊息，失敗時則仍會顯示診斷資訊。 (#29467)
