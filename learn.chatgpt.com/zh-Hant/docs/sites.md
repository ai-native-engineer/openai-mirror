   返回 **Sites** 以重新開啟或調整網站。準備就緒後，選擇哪些人

 **新增檔案及更多內容** 。

## 新增「使用 ChatGPT 登入」功能

公開網站可持續對所有人開放，同時提供選用的「使用 ChatGPT 登入」功能，以支援需要識別身分的功能，例如儲存進度、個人化檢視畫面，或屬於特定個人的記錄。僅限工作區存取的網站已使用 ChatGPT 身分來落實分享設定。

要求 Sites 新增登入體驗：

```text
Add Sign in with ChatGPT to this public Site. Keep the Site available to signed-out visitors. Show a Sign in with ChatGPT action when someone is signed out. After they sign in, greet them with their full name when available, or their email address otherwise. Add a Sign out action, and keep authorization decisions in server-side code.

Sites 會透過平台提供的路徑處理登入和登出流程，然後將訪客帶回你的網站：

```html
<a href="/signin-with-chatgpt">Sign in with ChatGPT</a>
<a href="/signout-with-chatgpt">Sign out</a>

訪客登入後，Sites 會透過下列要求標頭，將其身分轉送至伺服器：

- `oai-authenticated-user-email` 包含已通過身分驗證的電子郵件地址。
- `oai-authenticated-user-full-name` 可能包含非空白的個人資料名稱。請將其視為選用欄位，
  若沒有名稱，則改用電子郵件地址。

請在伺服器端程式碼中進行授權判斷，不要依賴分別提供姓名各部分的標頭。

## 瞭解專案、版本及部署

網站是持續保留的託管成果。你可以在 ChatGPT 的 **Sites** 中重新開啟、調整、設定
及分享網站。

Sites 專案會將本機原始碼專案連結到由 Sites 管理的託管服務。
Sites 會將這項關聯和選用的儲存空間繫結名稱儲存在
`.openai/hosting.json`。新建立的本機起始專案可以先不含
`project_id`；Sites 會在佈建託管專案後新增這個欄位。

例如，已佈建且使用關聯式資料庫繫結、但不使用檔案儲存空間的網站，可包含以下內容：

```json
{
  "project_id": "<project-id>",
  "d1": "DB",
  "r2": null
}

即使建立網站的 ChatGPT Work 對話已結束，網站仍會顯示在你的 Sites 清單中。你不需要本機專案或資訊清單，就能在網頁上開始建立網站。網站與 ChatGPT 專案彼此獨立。

Sites 的發佈流程分為兩個獨立階段：

1. **儲存版本。** ChatGPT 會建置可部署的版本。若是本機原始碼專案，
   ChatGPT 會將該版本與建置時使用的 Git 提交建立關聯。
   若需要可供審查的部署候選版本，請使用此階段。
2. **部署版本。** ChatGPT 會發佈已儲存的版本，並在
   部署成功時回報正式環境 URL。只有在你確實要讓
   選定的對象存取網站時，才使用此階段。

需要找出先前的部署候選版本時，請要求 ChatGPT 列出或檢查已儲存的版本。

## 選擇受支援的網站類型

建立新專案時，可以從 Sites 工作流程建議的網站起始範本開始。若使用現有專案，請先要求 ChatGPT 確認專案能產生相容的部署成品，再要求部署。

向 ChatGPT 說明你需要的產品行為，讓它選擇合適的網站類型：

| 網站需求                                                      | 可向 Sites 提出的要求                                                         |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 以內容為主的網站或到達網頁                            | 網站不持久保存應用程式狀態，除非使用體驗有此需求 |
| 已儲存的記錄、使用者進度或遊戲分數                   | D1，用於持久保存結構化資料的關聯式資料庫                         |
| 圖像、文件、音訊、影片或其他上傳內容              | R2，用於儲存檔案的物件儲存空間                                                  |
| 具有可搜尋中繼資料的上傳檔案                        | 以 D1 儲存中繼資料，並以 R2 儲存檔案內容                                      |
| 需要目前工作區使用者身分的內部網站 | 經工作區驗證的使用者身分                                         |
| 公開登入或外部身分提供者                | 已啟用身分驗證的網站                                                |

請勿為暫時性的顯示狀態要求持久性儲存空間，例如佈景主題選擇或已關閉的橫幅。對於使用者預期代管網站會保留的產品資料，則應要求持久性儲存空間。

## 控管存取權和機密資料

在您變更存取權之前，新網站僅限其擁有者和工作區管理員存取。審查內容、資料處理方式和預期受眾期間，請維持存取限制。

視您的帳戶和工作區設定而定，分享選項可能包括：

- **擁有者和工作區管理員**
- **所選的有效使用者或群組**（若支援此選項）
- **受邀的外部檢視者**（若提供外部邀請功能）
- **工作區中的任何人**（若支援此選項）
- **網際網路上的任何人**（僅在啟用公開發布時提供）

訪客存取權可讓他人開啟網站，但不會授予編輯權限。在企業工作區中，公開發布預設為停用，必須由管理員啟用。

若分享範圍受到限制，受邀訪客必須使用獲授存取權的帳戶登入。公開網站無須具備 ChatGPT 工作區存取權即可造訪。網站的受眾設定與網站內建的任何登入功能，是彼此獨立的控制設定。

例如：

```text
Change this Site's access to everyone in my workspace after showing me the
current Site and confirming its URL.

### 邀請工作區以外的人員

外部邀請可讓您授予特定人員網站存取權，無須公開網站。您可以邀請工作區以外的檢視者，也可以透過個人帳戶分享私人網站。此功能正陸續向使用 Plus、Pro、Business 和企業方案的 Sites 使用者推出。

1. 開啟您擁有的網站，然後選取 **分享**。
2. 若要保持網站私密，請將 **誰可以存取** 設為 **僅限受邀者**。
3. 在 **搜尋人員或群組** 欄位輸入檢視者的電子郵件地址；若是個人網站，則使用
**輸入電子郵件地址** 欄位，然後選取收件人。
4. 審查受眾和收件人的 **檢視者** 存取權，然後選取
**邀請**。
5. 確認該檢視者已列在儲存的存取權清單中。分享網站連結，並請對方使用獲授存取權的帳戶登入。

外部檢視者可以開啟及使用網站。他們不會成為工作區成員或網站編輯者，也無法編輯或發布網站。邀請會授予此網站的存取權；分享前，請先審查網站內容及其連接的資料。

在企業方案中，管理員可在 **工作區設定 \> 權限與角色** 中管理 **允許成員邀請外部訪客造訪
網站** 。此權限
與公開發布網站的權限彼此獨立。
Business 工作區沒有獨立的外部邀請權限
開關；必須先啟用 Sites，且帳戶必須已可使用此功能。
若未顯示邀請選項，請檢查所選帳戶、網站
擁有權、工作區權限，以及此功能是否已向您開放。

若要移除檢視者，請開啟網站的分享控制項並移除其存取權。同時也要檢查其餘受眾設定：移除一項邀請，不會移除對方透過公開、工作區或群組分享取得的存取權。

### 協作編輯網站

網站協作需要有工作區。當此功能可用時，網站擁有者可以邀請同一工作區的有效成員擔任編輯者。

編輯者可以讀取網站實際使用的資料庫資料。請只邀請您信任、可放心讓其存取網站程式碼和資料的人。

1. 開啟網站，然後選取 **分享**。
2. 在 **新增人員或群組** 下方，找到並選取一名工作區成員。系統會
   將對方新增為訪客。
3. 開啟該成員旁的 **可檢視** 選單，然後選取 **可編輯**。存取權設定會
   自動儲存。在該成員的 Sites 檢視畫面中，
   網站會列在 **與您分享** 區段下。
4. 編輯者可以開啟網站、進行修改、儲存版本，並在擁有者首次發布網站後發布更新。

網站擁有者負責管理編輯權限，可將現有訪客升級為
編輯者、將編輯者的權限改為 **可檢視**，或移除其存取權。共同編輯功能
不會新增獨立的工作區權限開關。

編輯者無法變更網站受眾、邀請或移除其他人、管理設定或分析資料、還原先前版本，或轉移擁有權。編輯者也不能首次發布網站；必須由擁有者先發布網站，編輯者才能發布後續更新。

編輯權限與訪客存取權彼此獨立。上述步驟會先將人員新增為訪客，再授予編輯權限。將訪客升級為編輯者，不會變更網站的受眾設定。

環境變數和機密資料。請勿在提示詞、附加檔案

請勿將這些值儲存在 `.openai/hosting.json` 中。請確保本機 `.env` 和

## 變更網站 URL

在支援編輯 URL 的情況下，網站擁有者可以變更現有網站由 ChatGPT 代管的 URL，無須建立新的部署。

1. 開啟 **Sites**，找到該網站，然後開啟其設定。
2. 找到網站 URL，然後選取 **變更 URL**。
3. 輸入可用的名稱。名稱至少須包含五個字元、以小寫英文字母開頭，且僅能使用小寫英文字母、數字與單獨出現的連字號。名稱不得以連字號結尾，也不得包含連續的連字號。
4. 確認變更，並等候 Sites 更新網址。

變更 URL 不會建立新的部署。舊網址會重新導向至新網址，並保留路由和查詢參數。

變更由 ChatGPT 代管的 URL，不會新增、移除或變更自訂網域。自訂網域是既有且獨立的功能；當此功能可用時，請使用自訂網域設定。

## 連接自訂網域

在支援自訂網域的情況下，您可以連接自己擁有的根網域或子網域。Sites 不會代您註冊網域，因此您必須能夠修改該網域的 DNS 記錄。推出初期，企業工作區不支援自訂網域。

若要連接網域：

1. 開啟網站設定，然後選取 **新增網域**。
2. 輸入您要使用的根網域或子網域。
3. 複製 Sites 提供的 DNS 記錄與對應值，再透過您的網域供應商新增這些記錄。
4. 等候幾分鐘，然後返回網站設定並重新整理網域狀態。

您也可以請 ChatGPT 協助將網域指向您的網站。如果已啟用瀏覽或電腦功能，ChatGPT 可在您登入後協助您操作網域供應商的介面。

## 分享前先審查

分享網站前：

- 審查網站的內容、生成的文字和圖像、連結、上傳的檔案、表單，以及互動行為。
- 確認網站不會揭露機密或敏感資訊、機密值，或您無權分享的第三方內容。
- 從預期訪客的角度測試網站，包括存取和登入行為。
- 審查會收集個人資訊或訪客提供的其他內容的功能。決定網站是否應收集、分享或發布這些資訊。
- 如果網站採用「使用 ChatGPT 登入」功能，請說明網站會收到哪些訪客資訊，以及如何使用這些資訊。
- 若網站收集或處理個人資料，請遵守
[適用的隱私權和資料保護法律](https://help.openai.com/en/articles/20001340)。
- 選擇符合預期對象需求、分享範圍最小的選項。
- 開啟已分享的網站，確認預期對象可以造訪。

如果網站是從本機專案建置的，也請在 Codex 的[審查窗格](/zh-Hant/codex/code-review?surface=app)中檢查原始碼變更
及任何資料庫遷移。

## 下架或刪除網站

若要取消存取權但不刪除網站，請開啟分享設定，將存取對象限制為自己或指定人士。確認先前的對象已無法開啟網站。

若要永久刪除網站：

1. 開啟 **Sites** ，並找到該網站。
2. 選取 **刪除網站** ，然後依照提示中的指示操作。
3. 輸入網站的 Slug，然後選取 **永久刪除**。

刪除網站會將其永久移除。已刪除的網站無法還原。

## 瞭解限制與不支援的用途

Sites 可託管在其支援的執行環境中運作的網頁體驗。部分框架、私有網路、資料庫、背景服務和託管模式不受支援。

支援 HTTP、HTTPS 和 WebSockets，但不支援原始 TCP 傳入與傳出連線。

每個網站的儲存空間限制如下：

| 資源            | 限制                  |
| ------------------- | ---------------------- |
| D1 資料庫儲存空間 | 10 GB                  |
| R2 物件儲存空間   | 無固定儲存空間上限 |

Sites 在推出時不支援資料駐留或推論駐留。此限制涵蓋已部署的網站、網站程式碼、D1 和 R2 的資料與檔案儲存空間、產生的構件，以及紀錄。

請勿使用 Sites 處理受保護的健康資訊或支付卡資料；
以未滿 13 歲或未達適用數位同意年齡的兒童為對象；
提供金融交易功能；散布惡意軟體；協助進行網路釣魚；冒充個人
或組織；或以其他方式違反 OpenAI 政策。請參閱
[建立及管理 ChatGPT Sites](https://help.openai.com/en/articles/20001339)，
瞭解目前的限制和相關政策連結。
