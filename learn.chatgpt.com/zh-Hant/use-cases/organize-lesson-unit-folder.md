## 重新整理前先清點

先從現有的課程或單元資料夾著手。告訴 ChatGPT 哪些檔案應作為正式依據、哪些是編輯中的草稿，以及哪些檔案絕對不能移動。

要求 ChatGPT 建立檔案清單，依可能的用途分組，並標示重複檔案、名稱不清楚的檔案和較舊版本。

## 審查建議的結構

實用的結構可將以下內容分開存放：

- 來源與參考資料
- 教案
- 簡報
- 學生講義
- 評量與解答
- 無障礙或不同語言版本
- 已封存的草稿

具體的資料夾配置應反映教師或團隊實際的工作方式。在核准任何變更前，請先審查名稱和建議的移動項目。

## 驗證結果

整理後，確認連結仍然有效、目前版本的檔案依然容易找到，而且沒有任何檔案遭到刪除。請 ChatGPT 提供 README 和變更摘要，列出已重新命名、移動及封存的檔案。

單元大幅變更時，請再次清點，以維持資料夾的實用性，避免再累積一批重複檔案。
