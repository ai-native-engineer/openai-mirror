## 以經核准的來源作為單元規劃依據

蒐集課程標準、課程指南或教學進度指南、校曆、過往課程、評量指引，以及相關的學習者需求。確認哪些文件是現行版本，哪些僅為範例。

要求 ChatGPT 將每項重要的規劃決策對應至經核准的來源。

## 草擬課程順序

使用入門提示詞，建立包含以下內容的計畫：

1. 學習目標與課程標準。
2. 配合校曆可用時程的課程順序。
3. 所需教材與來源連結。
4. 形成性檢核與評量的對應關係。
5. 可能的迷思概念或先備知識缺口。
6. 需由教師審查的決策與缺漏指引。

草稿不應只列出活動，還應說明為何每一堂課都應安排在該順序中。

## 審查教學判斷

檢查課程標準的對齊情況、教學進度、評量負荷、無障礙性和年齡適切性。確認 ChatGPT 未虛構學區要求或學習者資訊。

在同一個對話中修訂計畫，接著清楚標示已核准的版本，再用它生成簡報或課堂教材。
