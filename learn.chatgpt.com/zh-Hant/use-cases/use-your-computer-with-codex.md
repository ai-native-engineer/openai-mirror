## 簡介

當任務需要跨桌面應用程式、視窗或本機檔案進行時，請使用 [電腦](/zh-Hant/docs/computer-use)。ChatGPT 可在你允許的應用程式中點按、輸入及操作，然後傳回結果供你審查。若要處理網站或已登入的瀏覽器工作階段，請使用 `@Chrome` 另行啟動瀏覽器任務。

**使用「電腦」需要 ChatGPT 桌面版應用程式。** 在支援的地區，ChatGPT Work 與 Codex 的「電腦」功能可於 macOS 和 Windows 上使用。網頁版或行動裝置上的 Work 雲端任務無法直接存取你的本機應用程式、檔案或已登入的桌面瀏覽器工作階段。連接 Mac 或 Windows 主機後，你可以透過 [行動裝置上的遠端功能](/zh-Hant/codex/remote-connections) 啟動或引導桌面任務。

適合的使用情境包括：將筆記移入正式紀錄系統、起草回覆前先透過幾個應用程式確認上下文，或在沒有專用外掛程式的工具之間複製已核准的詳細資料。

## 使用方式

1. 開啟 ChatGPT 桌面版應用程式，並安裝 [「電腦」外掛程式](/zh-Hant/docs/computer-use)。
2. 若要使用桌面應用程式，請以 `@Computer` 開始提出要求；若要執行瀏覽器任務，則以 `@Chrome` 開始。
3. 說明任務、涉及的應用程式或檔案，以及你想要的結果。
4. 審查存取權提示，並在執行會傳送、提交或變更重要資料的動作前暫停。
5. 在 Windows 上使用「電腦」時，請在執行期間讓目標應用程式保持可見。

如果某個應用程式有外掛程式，ChatGPT 可能會使用該外掛程式執行結構化動作。當任務需要透過應用程式介面操作，或沒有可用的外掛程式時，「電腦」便很實用。

先從一項工具開始：若要處理桌面應用程式和本機檔案，請使用 `@Computer`；若要操作瀏覽器，請使用 `@Chrome`。ChatGPT 可視需要選擇其他工具。

**尋找住宿**

**掌握專案最新進度**

在 macOS 上，使用 [應用程式快照](/zh-Hant/codex/appshots) 分享目前位於最前方的應用程式視窗。應用程式快照可提供視覺上下文；若你允許，「電腦」便可接著開啟、檢查並操作該應用程式。

## 實用技巧

### 瞭解任務在不同電腦上的執行方式

在 macOS 上，即使你正在使用其他應用程式，電腦任務仍可在背景執行。子母畫面預覽會顯示目前作用中的應用程式；開啟預覽即可查看任務進度，也可將它移到不礙事的位置。如果你使用寵物，也可將預覽移到寵物上。

在 Windows 上，電腦任務會在作用中的桌面執行並接管前景操作。任務執行期間，指標會移動，鍵盤也會自動輸入內容。請讓裝置保持解鎖和連線狀態；如果你需要繼續使用主要桌面，也可在 Windows 虛擬機器中執行桌面應用程式。

### 選擇合適的瀏覽器

電腦任務經常也包含瀏覽器任務。請根據所需的上下文選擇瀏覽器：

- **[Chrome 擴充功能](/zh-Hant/codex/chrome-extension)：** 使用 `@Chrome` 執行瀏覽器任務，包括搜尋刊登項目、瀏覽網站，以及存取你現有且已登入的 Chrome 設定檔、分頁或擴充功能。
- **[內建瀏覽器](/zh-Hant/codex/browser?surface=app)：** 需要以獨立的瀏覽器工作階段存取 localhost 或公開網站時使用。它有自己的瀏覽器狀態，並可在你登入期間等候。
- **網頁版或行動版 ChatGPT Work 中的雲端瀏覽器：** 適用於受支援、可在未登入狀態下使用的公開網站。它無法存取本機檔案、已開啟的分頁、擴充功能或已儲存的密碼，也無法登入網站或完成付款。

如果使用哪個瀏覽器很重要，請在提示詞中指明瀏覽器；如要持續套用某項桌面偏好設定，請使用 [自訂](/zh-Hant/docs/customization/overview)。

### 避免同時對同一應用程式執行多項任務

請勿讓兩項電腦任務同時操作同一個應用程式。兩項任務的操作可能互相干擾，改變目前的視窗或狀態，導致結果不可靠。

### 準備應用程式登入狀態與鎖定時使用設定

開始桌面任務前，請先登入任務所需的應用程式和服務。Windows 上的電腦功能不支援鎖定時使用。在 macOS 上，若 [鎖定時使用](/zh-Hant/docs/computer-use#locked-use) 未啟用，電腦任務會在 Mac 鎖定時停止；啟用後，支援的任務可在 Mac 鎖定後繼續執行。
