## 確立共同依循的資料來源

先以經審查的課程簡報和單元教學計畫為基礎，再加入現行校方指引、現有講義、無障礙要求和語言需求。

告訴 ChatGPT 應以哪些檔案作為術語、範例、時間安排和教學決策的依據。

## 建立配套教材

使用起始提示詞產生一套相互配合的教材：

1. 一份包含準備事項與課堂引導說明的教師指南。
2. 一份依照課程順序編排的學生講義。
3. 一份與講義內容完全相符的解答。
4. 一份用語適切、內容精簡的家庭說明。
5. 一份教材與準備事項檢查清單。

完成草稿後，請 ChatGPT 比對各檔案，並回報不一致的用詞、範例、指示或答案。

## 依受眾分別審查

教師應審查教學內容是否正確且易於使用。檢查學生教材是否清楚且符合無障礙要求、解答是否與講義完全一致，以及家庭溝通內容是否符合政策和語言要求。

在負責的教育工作者核准整套教材前，請確保每個檔案都可編輯，並清楚標示為草稿。
