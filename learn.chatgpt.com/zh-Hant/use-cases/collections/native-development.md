# 原生開發

若每一輪作業都搭配建置、執行或模擬器迭代流程，Codex 便很適合用於 Apple 平台專案。
無論是建置全新或既有的 iOS 與 macOS 應用程式，若需要持續調整 UI 並偵錯問題，這些使用案例都很實用。

## 建立應用程式殼層

請 Codex 為 iOS 與 macOS 應用程式建立骨架，並搭配可重複執行的建置迭代流程。Mac 殼層使用案例會深入介紹側邊欄、詳細資料與檢查器的版面配置、指令、設定，以及其他桌面平台原生結構。

## 重構 iOS SwiftUI 畫面

使用 Codex 拆分大型 SwiftUI 檢視而不改變其行為，接著在應用程式準備就緒時，讓選定的 iOS 流程改用 Liquid Glass。

## 向系統公開 iOS 動作

運用 Codex 找出應用程式應透過 App Intents 公開的動作與實體，讓使用者能從系統介面存取應用程式功能。

## 偵錯應用程式

讓 Codex 在 Simulator 中重現錯誤，或在 macOS 應用程式中加入遙測功能，以協助你偵錯並修正問題。
