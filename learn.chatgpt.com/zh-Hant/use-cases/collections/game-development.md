# 遊戲開發

Codex 搭配圖像生成，在打造瀏覽器遊戲及其他類型的遊戲方面尤其強大。
這些使用案例將協助你把構想化為可直接遊玩的遊戲。

## 打造第一個可玩的遊戲循環

請 Codex 根據遊戲簡介，打造可在瀏覽器執行的版本，其中包含素材、操控機制與可供測試的遊戲循環。

## 微調 UI 與操控機制

遊戲開始執行後，使用 Codex 調整 HUD 細節、選單與操控機制，並修正細微的互動問題。

## 處理棘手的遊戲邏輯

運用 Codex 執行自我評估循環，持續迭代複雜的遊戲演算法。

## 根據真實訊號分級處理錯誤

在 Codex 修補遊戲前，先使用 Codex 彙整錯誤報告、未通過的檢查、紀錄與重現說明，並產生依優先順序排列的清單。

## 合併前審查

讓 GitHub 中的 Codex 自動審查 PR，找出迴歸問題與遺漏的測試，進而加快部署速度。
