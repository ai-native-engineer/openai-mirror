# 生產系統

當 Codex 處理已有歷史紀錄、測試、負責人及生產環境限制的程式碼庫時，這個合輯中的使用案例便很實用。
Codex 尤其擅長探索複雜的程式碼庫，包括擁有許多不同服務和相依項目的龐大 monorepo。
如果您負責生產系統，請熟悉這些使用案例，以瞭解 Codex 能如何協助您。

## 從程式碼庫導覽開始

使用 Codex 熟悉複雜的程式碼庫，在接手生產軟體的程式碼庫時尤其有用。

## 現代化程式碼庫

運用 Codex 規劃技術堆疊移轉、在適用時將現有整合升級至最新模型，並重構程式碼庫，以改善可讀性和可維護性。

## 將重複性工作標準化

請 Codex 將程式碼庫專用的工作流程或檢查清單轉化為一項技能，讓該程式碼庫的所有貢獻者都能受益於標準化流程。

## 讓文件保持最新

請 Codex 比對原始碼變更與現有文件，僅更新足以涵蓋變更的最小文件範圍，再驗證這些變更。

## 維持系統健康狀態

透過 Slack 使用 Codex，並將它與您的警示系統、議題追蹤流程及每日錯誤巡檢整合，讓 Codex 自動處理功能請求和錯誤修正。

## 避免審查瓶頸

運用 Codex 自動審查 PR，並針對關鍵流程執行重點品質檢查，以便迅速發現問題，安心發布更新。
