# 生產力與協作

使用 ChatGPT Work 或 Codex，協調涉及外掛程式、檔案與團隊的工作。
ChatGPT 可彙整檔案、訊息、文件與試算表中的上下文，再將其轉化為可分享的產出物。
若資料專案需依賴程式碼庫、可重現的指令碼或工作樹，請使用 Codex。

## 學習新概念

請 ChatGPT 將艱深的論文、規格或技術指南整理成定義、範例和問題，方便你複習。

## 委派多步驟工作流程

讓 ChatGPT 從多個外掛程式收集經你核准的輸入內容來準備工作流程，或讓它操作你的電腦，跨桌面應用程式完成任務。

## 讓工作持續推進

讓 ChatGPT 檢查你核准的來源，並只回傳需要留意的項目：實際請求、已變更的產出物、受阻的交接、回覆草稿與決策事項。

## 處理資料

使用 ChatGPT 探索資料集、清理試算表、檢驗假設、回答問題並建立視覺化。

## 建立可重現的分析

使用 Codex 在程式碼庫中清理及合併資料集、透過程式碼探索假設，並將結果整理成可供審查且可重新執行的產出物。

## 將分析整理成可供審查的產出物

讓 ChatGPT 將經你核准的輸入內容轉化為可分享的成果：投影片、訊息，以及其他可供審查的產出物。
