# 銷售

使用 ChatGPT Work 或 Codex，整合客戶紀錄、客戶
對話、銷售管道訊號和尚待處理的風險。ChatGPT 可將經核准的
上下文轉化為摘要、後續聯絡內容、預測審查和客戶計畫，同時
清楚區分有來源依據的事實與推論出的商機或風險。

## 排定銷售管道優先順序並審查預測

先將需要關注的客戶依優先順序排列，再檢視哪些商機應繼續列為
預期成交、改列為有望成交，或從預測中移除。

## 準備會議並進行會後追蹤

彙整客戶會議所需的上下文，再將經核准的筆記或
逐字稿轉化為後續聯絡草稿、內部摘要和可供審查的後續步驟。

## 制定客戶計畫並排除商機障礙

根據近期的客戶訊號更新客戶策略，或釐清商機停滯背後的
阻礙因素與升級處理路徑。
