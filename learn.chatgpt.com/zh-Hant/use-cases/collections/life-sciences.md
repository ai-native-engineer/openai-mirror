# 生命科學

GPT-Rosalind 是我們的前沿推理模型，旨在支援
生物學、藥物發現與轉譯醫學各領域的研究。這個生命科學模型
系列已針對科學工作流程最佳化，結合更強的工具運用能力與
對化學、蛋白質工程和基因體學更深入的理解。目前，
GPT-Rosalind 以
[研究預覽版](https://openai.com/form/life-sciences-access/)形式在 ChatGPT、
Codex 與 API 中提供，符合資格的使用者可透過我們的可信任存取計畫使用。

使用 ChatGPT Work 或 Codex 進行科學研究與分析。ChatGPT 可
將 GPT-Rosalind 與科學外掛程式應用於共用研究工作流程；若
工作需要程式碼、程式碼庫、基準測試，或反覆進行
軟體實驗，請使用 Codex。

## 生命科學研究與分析

使用 ChatGPT 將定序資料轉化為可實際應用的生物學洞察，
涵蓋 bulk RNA-seq 與單細胞 RNA-seq 分析，以及多來源標的
優先排序。

## 蛋白質折疊研究與架構搜尋

使用 Codex 將蛋白質折疊假設轉化為可供審查的實驗迭代流程，
並搭配明確的基準測試、可長期留存的成果物，以及清楚界定的證據範圍。
