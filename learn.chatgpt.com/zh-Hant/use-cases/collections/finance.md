# 財務

使用 ChatGPT Work 或 Codex，將經核准的活頁簿、儀表板、模型和
負責人提供的上下文轉化為可供審查的分析與報告成果。ChatGPT 可以
讓公式、來源、假設及待釐清問題保持清楚可見，讓財務
負責人在分享任何內容前先作出判斷。

## 說明營運表現

將關帳資料整理成供管理層參考的說明，比較結果與計畫，並
排序造成重大變動的因素。

## 審查模型與計畫

建立或檢查財務模型、更新預測並比較各種情境，
且不隱藏任何假設或來源缺漏。

## 製作管理層報告

進度追蹤表、指標、說明及負責人提供的資訊，製作供公司、管理層、CFO 或董事會使用的定期報告資料包。
