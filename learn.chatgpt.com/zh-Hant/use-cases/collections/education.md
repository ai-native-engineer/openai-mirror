# 教育

使用 ChatGPT Work 或 Codex，將分散各處的課程教材、學術
要求、時程、意見回饋與專案上下文，轉化為可編輯、
可供審查的成果。ChatGPT 可保留來源證據，讓不確定性
清楚可見，並確保大專院校教師、中小學教師、學生與校方團隊仍須為
學術與教學決策負責。

## 大專院校教師

更新課程、校準評量、比較各班別、檢視參與情況、
彙整研究證據，並準備教師委員會決策所需資料。

## 大專院校學生

規劃學期安排、準備考試、協調學生專案、妥善分配
時間與金錢、建立網站，並管理求職或實習申請。

## K–12 教師

整理教學檔案、規劃單元、製作課程簡報與配套
教材、以一致方式採納意見回饋，並建立互動式課程資源。
