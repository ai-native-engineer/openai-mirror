# 資料科學

使用 ChatGPT Work 或 Codex，將儀表板、指標定義、匯出資料、
實驗筆記和利害關係人的背景資訊轉化為可供他人審查
並據以採取行動的分析。ChatGPT 可讓計算、來源、注意事項和待釐清問題
保持清楚可見，讓分析師能在分享前驗證依據。

## 界定問題範圍並深入調查

將模糊的需求轉化為明確的分析計畫，或調查
重要區隔與相關背景下的非預期 KPI 變動。

## 衡量並解釋成效

評估實驗或產品推出的影響，並將持續更新的 KPI 和
業務資料轉化為有來源佐證的績效說明。

## 設計儀表板與監控機制

為可直接支援決策的儀表板，定義 KPI 階層、圖表規格、品質檢查、負責人，以及
監控計畫。
