## 簡介

ChatGPT 很擅長有系統地清理表格資料。
如果 CSV 或試算表中有日期格式混用、資料列重複、貨幣字串、空白儲存格、別名或貼上的摘要列，請 ChatGPT 清理一份副本，並維持原始檔案不變。

## 使用方式

1. 將檔案拖入 ChatGPT，或在提示詞中提及檔案，例如 `@customer-export.csv`。
2. 描述你已發現的問題。
3. 告訴 ChatGPT 清理後的版本應採用何種形式：CSV、試算表分頁或可直接上傳的檔案。
4. 使用前先審查清理後的副本。

使用本頁的起始提示詞進行第一輪清理。請將檔名和條列項目換成你自己的內容。最有用的資訊是你已發現的問題，以及接下來所需的檔案：清理後的 CSV、乾淨的試算表分頁或可直接上傳的檔案。ChatGPT 建立清理後的副本後，請先從對話中開啟已清理的檔案與資料品質說明，再將資料用於後續流程。
