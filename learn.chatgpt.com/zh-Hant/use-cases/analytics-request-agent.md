## 把需求整理成明確的分析約定

利害關係人的需求往往混合了業務問題、偏好的圖表，以及未經確認便預設的指標定義。將原始需求和相關背景資訊提供給 ChatGPT，再請它於分析前先找出要回答的問題、所需定義、資料來源、資料聯結及待決事項。

1. 附上需求討論串、指標詞彙表、儀表板、資料匯出檔及相關背景資訊。
2. 請 ChatGPT 列出哪些資訊已知、仍不明確、有缺漏或超出範圍。
3. 確認指標定義、聯結邏輯、時間範圍和目標對象。
4. 使用起始提示詞，產出初步分析及可直接提供給利害關係人的答覆。
5. 請分析師審查計算結果、圖表、注意事項和待釐清問題。

不要讓語氣篤定的答案掩蓋尚未定義的指標或未經驗證的資料聯結。分析計畫本身也是交付成果的一部分，因為它能讓下一次迭代的審查更快完成。

## 與需求提出者完成確認

分析經過審查後，請 ChatGPT 將待釐清問題整理成簡短的確認說明，但先不要傳送。
