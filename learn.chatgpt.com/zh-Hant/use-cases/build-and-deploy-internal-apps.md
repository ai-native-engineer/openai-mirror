## 透過單一任務完成建立與部署

Sites 是 ChatGPT 中由平台管理的託管服務。要求 ChatGPT 建立應用程式後，它就能建置專案、執行專案以進行測試、完成部署，並傳回可分享的 URL。

Sites 目前處於公開測試階段，適用於符合資格的付費方案。推出初期，免費版或 Go 無法使用，歐洲經濟區 (EEA)、瑞士或英國也不提供；推出進度或工作區設定可能影響存取。

涵蓋範圍從靜態網站到全端 JavaScript 或 TypeScript 網頁應用程式。因此，Sites 很適合用來打造聚焦特定用途的內部工具，例如新人到職儀表板、培訓中心、可搜尋的資源庫、輕量工作流程應用程式和報表檢視畫面。

請參閱 [Sites 文件](/zh-Hant/codex/sites)，瞭解設定、儲存、部署和存取相關指引。

先從一個實用的工作流程著手。比起籠統要求重建整個內部系統，目標明確的初版更容易審查、部署和改進。

## 向 ChatGPT 提供工作流程上下文

告訴 ChatGPT 這個應用程式的使用對象、使用者應完成的操作、應查閱哪些來源資料，以及哪些內容應在工作階段之間保留。請明確說明預定的分享範圍，並要求 ChatGPT 在部署前測試主要流程。

使用 [外掛程式](/zh-Hant/codex/plugins)，從已連線的內部來源擷取或重新整理資料。你可以在 Web 版 Work 中，或在桌面版 Work 或 Codex 中，啟動使用已連線應用程式或雲端檔案的 Sites 任務。若要使用本機檔案，請使用桌面 App；若要使用已登入的網站，請使用內建瀏覽器；若要使用現有的 Chrome 工作階段，請使用 Codex Chrome 擴充功能。

  若需要即時擷取資料，可以使用在網站設定中組態的
  API 金鑰連線至第三方工具。請勿在提示詞
  和檔案中加入機密值。若要使用外掛程式連線，可以 [從
  目前的任務排程工作](/zh-Hant/codex/automations#schedule-work-from-a-task)；該工作會依固定排程使用外掛程式擷取資料，
  接著更新應用程式，並儲存一個版本以供審查。
  只有在核准後，才能部署經過審查的版本。

## 為應用程式選擇儲存方案

許多內部應用程式都需要持久保存資料。Sites 支援兩種基本儲存機制：

- 使用與 SQLite 相容的資料庫 D1 來儲存結構化資料，例如檢查清單狀態、書籤、篩選器、註解、組態和檔案中繼資料。
- 使用 R2 物件儲存空間來保存需要持久保留的檔案位元組，例如上傳的文件、圖像或其他資產。

將結構化中繼資料保存在 D1，較大的檔案物件則保存在 R2。唯讀資源頁面或小型靜態網站可能兩者都不需要。

Sites 不支援資料駐留或推論駐留。請勿用它處理受保護的健康資訊或支付卡資料，也不要透過它進行金融交易。在儲存敏感資訊前，請先查看 [Sites 的資料與使用限制](https://help.openai.com/en/articles/20001339-creating-and-managing-chatgpt-sites)。

## 管理及分享專案

你可以管理哪些人能造訪已部署的專案。

審查新專案的內容、資料處理方式和預定對象時，請將專案維持為私人。

視帳戶與工作區設定而定，你可以與下列對象分享專案：

- 你邀請的人。
- 工作區中的所有人。
- 網際網路上的任何人。

分享只會讓其他人造訪專案，並不允許他們編輯。若要變更存取權，請開啟 [ChatGPT 中的 Sites](https://chatgpt.com/sites)，或直接要求 ChatGPT：

輕量活動指南、社團資源頁面或其他供工作區外人士使用的網站，也適合公開分享。在企業工作區中，公開發佈預設為關閉，必須由管理員啟用。即使可以使用公開連結，也要將內部資料保持為私人。

- **[新人到職中心](/showcase/onboarding-hub)** 整合首週檢查清單、資源、筆記和上傳的文件。它使用 D1 儲存使用者狀態和檔案中繼資料，並使用 R2 儲存上傳檔案的位元組。
- **[培訓中心](/showcase/enablement-hub)** 提供由 D1 支援的可搜尋培訓資源庫，並具備篩選器和已儲存的書籤。
- **[Pulse 儀表板](/showcase/pulse-dashboard)** 顯示指標、趨勢和資料沿襲詳細資訊，並使用 D1 儲存組態和快取快照。
- **[Sparkboard](/showcase/idea-intake)** 將員工構想徵集轉化為工作流程，包含經身分驗證的提案提交功能、投票、留言、狀態看板和貢獻者排名。
- **[上線日曆](/showcase/launch-cal)** 將即將推出的產品整理成按月顯示的日曆，並提供篩選器、風險訊號、檢查清單和已連線來源的參考資料。
- **[活動規劃中心](/showcase/event-planning-hub)** 整合活動請求、核准、範本、里程碑、政策準備度，以及已連線的規劃資源。
