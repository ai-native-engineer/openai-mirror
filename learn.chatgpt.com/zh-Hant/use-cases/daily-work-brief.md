## 預期成果

讓 ChatGPT Work 持續負責協助您掌握工作。在同一個對話串中，它可以每小時檢查您已連線的工作工具、彙整優先事項、協助您準備會議，並標出需要您留意的訊息、決策或承諾事項。在桌面版 App 中，您提出要求時，它也可以協助您為專案建立或協調獨立任務。

使用適合您工作的來源，例如 Slack 或 Teams、Gmail 或 Outlook、您的行事曆、文件及專案追蹤工具。如果 ChatGPT 無法存取某個來源，應該告訴您，而不是猜測其中的內容。

選擇最符合您希望幕僚長工作方式的介面：

- **ChatGPT Web 版：** 使用已連線的工作工具，並執行每小時一次的 [排程檢查](/zh-Hant/codex/automations?surface=web)，即使筆電關機也能繼續。若您希望無論身在何處都能收到最新資訊，這是不錯的預設選擇。
- **ChatGPT 桌面版 App：** 使用相同的已連線來源，並搭配本機檔案和應用程式。您提出要求時，幕僚長也能建立彼此獨立的專案隊友、向其提供工作簡報並協調其工作。若 [排程檢查](/zh-Hant/codex/automations?surface=app) 需要使用本機檔案或桌面工具，請讓電腦保持開機，並讓 App 持續執行。

## 依需求自訂

1. 使用起始提示詞開始新的對話串。
2. 連接與工作相關的訊息、電子郵件、行事曆及文件來源。
3. 檢視首次更新，並指出任何重要、已解決或遺漏的事項。
4. 持續在同一個對話串中處理後續事項、準備會議及草擬回覆。
5. 在桌面版中，如果某個專案需要專屬隊友，請要求它建立或繼續執行獨立任務。
6. 檢視每小時定期檢查的執行情況，並視需要調整排程。

起始提示詞會授權每小時執行一次檢查。ChatGPT 在建立另一項任務、傳送訊息、更新文件、變更排程或做出承諾前，都應先徵詢您的同意。
