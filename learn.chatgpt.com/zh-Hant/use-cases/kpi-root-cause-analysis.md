## 先定義指標，再說明變動原因

根本原因分析應先確立穩定的指標定義與比較期間，並取得可作為事實依據的資料。在請 ChatGPT 說明變動原因之前，先提供 KPI 定義、儀表板、匯出資料，以及產品發布或行銷活動的相關上下文。

1. 說明 KPI、比較期間、預期方向，以及這項分析應支援的決策。
2. 附上儀表板、指標定義、匯出資料、區隔切分結果與相關上下文。
3. 請 ChatGPT 檢查資料品質，並提出最實用的拆解方式。
4. 執行起始提示詞，並分開審查已確認的驅動因素與假設。
5. 變更儀表板或流程前，先與指標負責人確認建議行動。

使用圖表呈現這項變動，以便檢視，但不要將某個區隔內的相關性視為因果關係的證明。在摘要報告中一併保留來源連結、注意事項和未解問題。

## 檢驗根本原因

在將摘要報告提交給管理階層之前，請 ChatGPT 尋找反證和其他可能的解釋。
