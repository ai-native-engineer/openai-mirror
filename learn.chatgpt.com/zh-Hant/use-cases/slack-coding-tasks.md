## 如何使用

1. 安裝 Slack 應用程式、連線至正確的程式碼庫與環境，並將 `@Codex` 加入頻道。
2. 在討論串中提及 `@Codex`，並清楚說明要求、限制條件與期望的結果。
3. 開啟對話連結並審查結果；如果任務需要再處理一輪，請回到 Slack 繼續討論。

如要進一步瞭解如何在 Slack 中使用 Codex，請參閱 [專屬指南](/zh-Hant/codex/third-party/slack)。

## 提示

- 如果討論串尚未包含足夠的上下文或建議的修正方案，請在提示詞中補充一些指引
- 在提示詞中提及專案或環境名稱，確保程式碼庫與環境的對應關係正確
- 明確界定要求範圍，讓 Codex 不必再進行一輪規劃即可完成任務
- 如果專案的程式碼庫很龐大，請提及與任務相關的檔案或資料夾，以引導 Codex
