## 建立專案中樞

彙整專案簡介、現有資料夾、會議記錄、預算、成員可參與時間、校方要求和截止日期。確認日期、核准事項及支出規則分別以哪項資料為準。

重新整理檔案或指派工作前，先要求 ChatGPT 盤點現況。

## 規劃工作

營運中樞應串聯以下項目：

- 里程碑和截止日期
- 建議的負責人和相依關係
- 預算類別和核准事項
- 決策和待解問題
- 風險和應變措施
- 會議議程和後續事項
- 溝通內容草稿

將私密規劃筆記與準備傳送給成員、合作夥伴或參與者的訊息分開保存。

## 與團隊一起審查

在團隊會議中確認負責人、日期和預算假設。ChatGPT 可以草擬建議，但未經核准，不應指派人員、傳送訊息或做出資金承諾。

每次會議後，加入會議記錄，並要求 ChatGPT 依據已確認的決策更新中樞。保留決策記錄，讓日後的籌辦人能理解各項變更。
