## 사용 방법

1. Slack 앱을 설치하고 올바른 레포지토리와 환경을 연결한 다음 채널에 `@Codex`를 추가하세요.
2. 스레드에서 `@Codex`를 멘션하고 명확한 요청 사항, 제약 조건, 원하는 결과를 전달하세요.
3. 채팅 링크를 열어 결과를 검토하고, 작업을 한 차례 더 진행해야 한다면 Slack에서 후속 논의를 이어가세요.

Slack에서 Codex를 사용하는 방법은 [전용 가이드](/ko-KR/codex/third-party/slack)에서 자세히 알아볼 수 있습니다.

## 팁

- 스레드에 충분한 컨텍스트나 제안된 수정안이 아직 없다면 프롬프트에 작업 방향을 안내하는 내용을 추가하세요
- 프롬프트에 프로젝트 또는 환경 이름을 명시해 레포지토리와 환경이 올바르게 매핑되었는지 확인하세요
- Codex가 계획을 다시 세우지 않고도 작업을 완료할 수 있도록 요청 범위를 명확히 정하세요
- 프로젝트의 코드베이스가 크다면 Codex가 참고할 수 있도록 작업과 관련된 파일이나 폴더를 명시하세요
