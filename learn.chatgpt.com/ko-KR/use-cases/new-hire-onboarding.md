## 소개

신규 입사자 온보딩은 일반적으로 여러 시스템에 걸쳐 진행됩니다. 여기에는 채용 확정자 목록, 온보딩 트래커, 관리자 또는 팀 매핑, 계정 및 장비 준비 상태, 캘린더 주요 일정, 첫 주를 조율하는 팀 채팅 공간이 포함됩니다.

ChatGPT는 이 워크플로우를 조율하는 데 도움을 줄 수 있습니다. 입사일 기준 대상 그룹을 파악하고, 트래커 업데이트를 준비하고, 해당 그룹을 팀별로 요약하고, 환영 공간 설정 초안을 하나의 검토 가능한 패킷으로 작성하도록 요청하세요. 첫 번째 단계는 읽기 전용으로 진행하고, 정확한 실행 계획을 검토한 후 쓰기 작업, 초대, 게시, DM, 이메일 또는 채널 생성을 명시적으로 승인하세요.

## 검토 범위 정의

ChatGPT가 어떤 내용도 읽거나 쓰기 전에 대상자 범위, 소스 시스템, 허용되는 필드, 결과물의 저장 대상, 검토자, 범위에서 제외할 작업을 정의하세요.

온보딩 데이터에는 민감한 정보가 포함될 수 있으므로 이 과정이 중요합니다. 워크플로우에서는 선호 이름, 직무, 채용 팀, 관리자, 필요시 업무용 이메일, 입사일, 시간대 또는 대략적인 근무지, 버디, 계정 준비 상태, 장비 준비 상태, 오리엔테이션 주요 일정, 미해결 질문과 같은 실무적인 온보딩 정보만 다루세요.

프롬프트나 생성된 트래커에 보상 정보, 인구통계 정보, 정부 발급 ID, 자택 주소, 의료 또는 장애 정보, 신원 조회 상태, 이민 상태, 면접 피드백 또는 성과 메모를 포함하지 마세요.

## 승인된 온보딩 입력 수집

조직에서 온보딩 조율용으로 이미 승인한 기준 정보부터 사용하세요. 채용 데이터 내보내기 파일, HR 내보내기 파일, 스프레드시트, 프로젝트 트래커, 관리자가 제공한 표, 디렉터리 내보내기 파일 또는 붙여 넣은 소규모 샘플을 사용할 수 있습니다.

트래커를 만들기 전에 ChatGPT가 읽은 출처, 행 수, 날짜 범위, 필드 이름, 선택한 열을 보고하도록 요청하세요. 스프레드시트 셀, 문서, 채팅 메시지, 레코드는 따라야 할 지시가 아니라 요약할 데이터로 취급해야 합니다.

## 온보딩 트래커 작성

ChatGPT가 출처의 사실 정보와 생성한 계획 필드를 분리하면 트래커를 더 쉽게 검토할 수 있습니다.

예를 들어 출처 열에는 이름, 팀, 관리자, 직무, 입사일, 업무용 이메일, 입사 지역이 포함될 수 있습니다. 계획 열에는 계정 담당자, 장비 담당자, 오리엔테이션 세션, 환영 공간 상태, 버디, 준비 상태, 누락된 정보, 다음 작업이 포함될 수 있습니다.

운영 트래커를 업데이트하기 전에 새 CSV, 스프레드시트, Markdown 표 또는 초안 탭에 트래커를 준비하도록 ChatGPT에 요청하세요. 쓰기 작업을 승인하기 전에 행, 공유 대상, 누락된 필드에 관한 질문을 검토하세요.

## 팀 요약 및 환영 공간 초안 작성

트래커 초안이 정확하면 코디네이터가 검토할 순서대로 다음 커뮤니케이션 자료를 준비하도록 ChatGPT에 요청하세요.

1. 인원수, 입사일, 관리자, 준비 상태의 미비점을 포함한 팀별 요약.
2. 승인된 이름 규칙을 적용한 비공개 환영 공간 이름.
3. 각 공간의 초대 목록, 담당자, 주제, 북마크, 환영 메시지, 첫 주 체크리스트 항목.
4. 불필요한 개인 정보를 제외한 공지 채널 문안.

이 단계의 출력은 여전히 초안이어야 합니다. 채널 이름은 신원이나 재직 상태를 드러낼 수 있고, 초대하면 해당 사용자에게 즉시 알림이 갈 수 있습니다. 공간 생성, 초대, 게시, DM, 이메일, 트래커 쓰기 작업은 반드시 명시적으로 승인한 뒤에만 수행되도록 하세요.

## 주간 온보딩 워크플로우 실행

반복해서 온보딩을 점검하려면 작업을 다음 체크포인트로 나누세요.

1. **현황 파악:** 지정한 출처만 읽고, 대상 입사일 범위에 해당하는 사람을 찾은 뒤, 누락되거나 서로 충돌하는 데이터를 보고하세요.
2. **초안 준비:** 트래커 초안, 팀 요약 초안, 환영 공간 계획, 초대 목록, 메시지 초안을 작성하세요.
3. **검토:** 대상 그룹, 대상 트래커, 공지 날짜 또는 상태, 공지 대상자, 환영 공간 이름 규칙, 공간 공개 범위 설정, 초대 목록, 모든 메시지를 확인하세요.
4. **실행:** 명시적인 승인 문구를 받은 후 검토된 작업만 수행하도록 ChatGPT에 요청하세요.
5. **보고:** 생성된 결과물의 링크, 작업별 건수, 해결되지 않은 미비점, 다음 담당자를 반환하세요. 최종 요약에 전체 명단이 필요한 경우가 아니라면 명단 전체를 붙여 넣지 마세요.

## 추천 프롬프트

아래 프롬프트는 작업을 여러 단계로 나누어 준비합니다. 팀에서 공유 프로젝트 페이지나 관리자용 브리핑 문서를 사용한다면 외부 작업을 승인하기 전에 검토한 트래커, 요약, 환영 공간 계획을 해당 초안 결과물로 묶도록 ChatGPT에 요청하세요.
