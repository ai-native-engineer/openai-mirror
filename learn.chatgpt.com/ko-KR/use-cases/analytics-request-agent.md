## 요청을 분석 명세로 구체화하기

이해관계자의 요청에는 비즈니스 질문, 선호하는 차트, 가정한 지표 정의가 뒤섞여 있는 경우가 많습니다. ChatGPT에 원래 요청과 관련 컨텍스트를 제공한 다음, 분석을 시작하기 전에 질문, 지표 정의, 데이터 소스, 조인, 의사결정 사항을 파악하도록 요청하세요.

1. 요청 스레드, 지표 용어집, 대시보드, 내보낸 데이터, 관련 컨텍스트를 첨부하세요.
2. ChatGPT에 확인된 사항, 모호한 사항, 누락된 사항, 범위 밖의 사항을 나열하도록 요청하세요.
3. 지표 정의, 조인 로직, 분석 기간, 공유 대상을 확인하세요.
4. 스타터 프롬프트를 실행해 1차 분석을 수행하고 이해관계자에게 바로 공유할 수 있는 답변을 준비하세요.
5. 분석가에게 계산 결과, 차트, 유의 사항, 미해결 질문을 검토하도록 요청하세요.

답변이 자신 있게 제시되더라도 정의되지 않은 지표나 검증되지 않은 조인을 간과하지 마세요. 분석 계획도 결과물에 포함해야 합니다. 그래야 다음번 분석 결과를 더 빠르게 검토할 수 있습니다.

## 요청자와 최종 확인하기

분석 검토가 끝나면 미해결 질문을 짧은 확인 메모로 정리하되, 전송하지는 않도록 ChatGPT에 요청하세요.
