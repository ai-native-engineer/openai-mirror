## 공식 수업 자료 수집

각 과목의 강의계획서, 과제 안내문, 읽기 목록, 수업 일정표와 현재 사용 중인 폴더를 수집하세요. 공식 수업 자료를 개인 노트 및 제출물과 구분하세요.

정리를 시작하기 전에 ChatGPT에 파일 목록을 작성하고, 중복 파일을 찾아내고, 제안하는 폴더 구조를 보여 달라고 요청하세요.

## 워크스페이스 구성

유용한 학기 워크스페이스에는 다음이 포함되어야 합니다:

- 과목별 폴더 하나
- 공식 자료, 읽기 자료, 노트, 과제, 제출물을 위한 별도 위치
- 일관되고 검색하기 쉬운 파일 이름
- 중요한 파일 링크가 포함된 과목별 인덱스
- 모든 날짜의 출처가 포함된 마감일 추적표

원본 파일은 보존하고, 오래된 중복 파일은 삭제하지 말고 보관하세요.

## 마감일 및 충돌 확인

각 마감일을 강의계획서나 과제 안내문과 대조하세요. 하나를 임의로 선택하지 말고 날짜가 서로 다르거나 시간대가 누락되었거나 제출 지침이 불분명한 경우를 표시하세요.

제안된 구조를 검토한 후 파일 변경 사항을 소규모로 나누어 승인하세요. 새 공식 자료가 추가될 때마다 인덱스와 마감일 추적표를 다시 확인하세요.
