## 소개

ChatGPT를 사용하면 직접 검토하고 수정할 수 있는 완전한 기능의 DCF 워크북을 만들 수 있습니다.

과거 재무 데이터, 가치평가 가정, 모델링 메모를 비롯한 여러 파일을 컨텍스트로 활용할 수 있습니다.
이 파일들을 직접 제공하거나, 입력 자료가 Google Drive 또는 다른 연결된 소스에 있다면 파일 참조를 사용할 수 있습니다. 이 경우 ChatGPT가 모든 파일을 검색하도록 요청하는 것보다 정확한 파일 참조를 제공하는 편이 더 효과적입니다.

## 워크북 만들기

1. 과거 재무 데이터, 가치평가 가정, 모델링 메모를 첨부하거나, 해당 소스와 함께 정확한 파일 참조를 제공하세요.
2. 스타터 프롬프트를 실행하고 편집 가능한 `.xlsx` 워크북을 요청하세요.
3. 생성된 워크북을 ChatGPT에서 여세요. 모델 탭, 수식, 가정, 가치평가 요약을 검토할 수 있도록 전체 화면 보기로 확대하세요.
4. 같은 채팅에서 계속 수식의 연결 관계를 확인하고, 가정을 변경하고, 시나리오를 추가하거나 모델을 더 정교하게 다듬으세요.

워크북이 채팅에 나타나면 열어 전체 화면으로 확대하세요. 소스 입력 자료, 예측 동인, 가치평가 결과, 민감도 분석표를 검토한 다음, 그 상태에서 ChatGPT에 같은 워크북을 수정해 달라고 요청하세요.

## 가치평가 검토하기

워크북을 사용하기 전에 재무팀 동료가 하듯 다음 항목을 검토해 달라고 ChatGPT에 요청하세요: 소스 파일과의 수치 일치 여부, 수식, 하드코딩된 가정, 가치평가 결과.

## 가정 하나 수정하기

워크북을 검토한 후 같은 채팅에서 수정할 부분을 구체적으로 요청하세요. 영향을 쉽게 확인할 수 있도록 한 번에 하나의 동인만 변경하세요.
