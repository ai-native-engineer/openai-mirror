## 차트가 아니라 의사결정을 중심으로 설계하기

대시보드 명세를 작성하기 전에 대시보드가 뒷받침해야 할 의사결정과 신호에 따라 조치할 담당자를 정의하세요. 명세가 실제 데이터에 기반하도록 ChatGPT에 지표 정의, 원본 데이터 내보내기 파일, 기존 예시, 워크플로우 컨텍스트, 이해관계자 피드백을 제공하세요.

1. 워크플로우, 대상 사용자, 의사결정, 검토 주기를 명시하세요.
2. 지표 용어집, 원본 데이터 내보내기 파일, 대시보드 예시, 이해관계자 피드백을 첨부하세요.
3. ChatGPT에 데이터 소스의 미비점과 품질 검사 항목을 파악하고, 담당자가 필요한 부분을 정리해 달라고 요청하세요.
4. 스타터 프롬프트를 실행해 KPI 계층 구조, 차트 명세, 필터, 모니터링 방안의 초안을 작성하세요.
5. 게시 위험 요소를 검토하고 제안된 지표를 원본 데이터와 대조해 검증하세요.

대시보드 명세를 분석가, 데이터 소유자, 사용자 간의 계약으로 간주하세요. 각 차트의 의미와 언제 신뢰할 수 있는지, 어떤 조치로 이어져야 하는지를 정의하세요.

## 모니터링을 실제 조치로 연결하기

명세 검토가 끝나면 ChatGPT에 가장 중요한 검사 항목을 명확한 에스컬레이션 기준이 포함된 모니터링 체크리스트로 정리해 달라고 요청하세요.
