## 소개

현금 흐름 예측을 만들 때는 예측이 정확하고 실제 비즈니스 상황을 반영하는지 확인해야 합니다. ChatGPT를 사용하면 ChatGPT에서 직접 검토하고 수정할 수 있는 예측 워크북을 만들 수 있습니다. 현금 흐름 입력값, 운영 가정, 모델 제약 조건을 첨부하세요. 입력값이 Google Drive 또는 연결된 다른 소스에 있다면 파일 참조를 사용할 수도 있습니다.

## 예측 만들기

1. 현금 흐름 입력값, 운영 가정, 모델 제약 조건을 첨부하세요.
2. 시작 프롬프트를 실행해 편집 가능한 `.xlsx` 형식의 워크북을 요청하세요.
3. ChatGPT에서 워크북을 여세요. 전체 화면으로 확장해 가정, 수식, 시나리오, 요약 탭을 검토하세요.
4. 같은 채팅에서 수금, 급여, 공급업체 지급, 성장률 또는 안전 현금 기준액에 관한 가정을 변경하세요.

워크북이 채팅에 표시되면 열어서 전체 화면으로 확장하세요. 시점 가정, 수식, 시나리오, 요약 탭을 검토한 다음, 이어서 ChatGPT에 같은 워크북을 수정해 달라고 요청하세요.

## 현금 압박 검토하기

예측을 사용하기 전에 ChatGPT에 유동성 최저점을 파악하고, 워크북을 원본 입력값과 대조하며, 검토가 필요한 가정을 나열해 달라고 요청하세요.

## 시나리오 실행하기

ChatGPT에서 워크북을 검토한 후 후속 프롬프트를 사용해 한 번에 하나의 시나리오 변수만 변경하세요.
