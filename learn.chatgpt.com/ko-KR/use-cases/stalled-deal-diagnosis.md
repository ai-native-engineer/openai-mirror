## 전체 딜 이력에서 정체 원인 추적하기

현재 표시된 단계만으로는 장애 요인을 온전히 파악하기 어렵습니다. ChatGPT가 고객 측, 기술, 법무, 내부 프로세스 문제를 구분할 수 있도록 단계 변경 이력, 완료된 활동 내역, 통화 기록, 이메일, 딜 관련 스레드, 보안 또는 조달 메모, 계정 컨텍스트를 제공하세요.

1. 진단할 딜과 기간, 진단 결과를 바탕으로 내려야 할 의사 결정을 정의하세요.
2. 단계 변경 이력, 활동 내역, 녹취록, 이메일, 관련 스레드, 보안 또는 조달 메모, 계정 컨텍스트를 첨부하세요.
3. 근본 원인을 지목하기 전에 타임라인부터 구성하도록 ChatGPT에 요청하세요.
4. 스타터 프롬프트를 실행하고 근거, 이전 시도, 종속성, 에스컬레이션 경로, 다음 조치를 검토하세요.
5. 고객에게 후속 연락을 보내기 전에 딜 담당자가 내용을 승인하도록 하세요.

진단은 사실에 근거하고 기간 범위를 명확히 한정하세요. 장애 요인이 불분명하다면 여러 가능성을 가려내는 데 필요한 최소한의 고객 측 또는 내부 확인 사항을 나열하세요.

## 진단을 복구 계획으로 전환하기

장애 요인에 합의한 후에는 담당자와 종속성, 각 단계의 이행을 입증할 기준을 포함해 핵심 조치에 집중한 복구 계획을 만들도록 ChatGPT에 요청하세요.
