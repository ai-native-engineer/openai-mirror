## 프로젝트 허브 구축하기

프로젝트 개요, 현재 폴더, 회의록, 예산, 구성원별 가능 일정, 학교 측 요구 사항, 마감일을 모으세요. 일정, 승인, 지출 규칙에 관해 어떤 자료가 기준 정보인지 파악하세요.

파일을 재정리하거나 업무를 배정하기 전에 ChatGPT에 현재 상태를 파악해 목록으로 정리해 달라고 요청하세요.

## 업무 계획 세우기

운영 허브에서는 다음 항목이 서로 연결되어야 합니다:

- 마일스톤과 마감일
- 담당자 후보와 종속성
- 예산 항목과 승인
- 결정 사항과 미해결 질문
- 리스크와 비상 대응 조치
- 회의 안건과 후속 조치
- 커뮤니케이션 초안

비공개 기획 메모는 구성원, 파트너 또는 참석자에게 보낼 메시지와 분리해 관리하세요.

## 팀과 함께 검토하기

담당자, 일정, 예산 관련 가정을 팀 회의에서 확인하세요. ChatGPT는 제안 초안을 작성할 수 있지만, 승인 없이 담당자를 지정하거나 메시지를 보내거나 자금 지출을 약정해서는 안 됩니다.

각 회의가 끝나면 회의록을 추가하고, 확정된 결정 사항을 반영해 허브를 업데이트하도록 ChatGPT에 요청하세요. 향후 운영진도 변경 사항을 이해할 수 있도록 의사 결정 로그를 유지하세요.
