## 감사 가능한 운영 작업 실행

사용자에게 액세스 권한을 부여하거나, 일괄 업데이트를 적용하거나, 서로 다른 매개변수로 스크립트를 호출하는 등 정기적으로 실행해야 하는 반복 가능한 운영 작업이 있다면 ChatGPT로 자동화하고 감사 가능한 출력을 받을 수 있습니다.

ChatGPT가 반복 가능한 운영 작업을 실행한 뒤 검증 근거가 되는 아티팩트로 실행 결과를 보여 줘야 할 때 이 워크플로우를 사용하세요.

## 작업 및 입력 설명

1. ChatGPT에 프로세스를 일괄 실행할 대상이 담긴 입력 테이블, 파일, 티켓 또는 기타 목록을 제공하세요.
2. 해당하는 경우 허용 범위를 정의하는 승인 출처 또는 정책을 ChatGPT에 알려 주세요.
3. 작업을 수행할 스크립트, API, 스킬, CLI 또는 앱 워크플로우를 ChatGPT에 알려 주세요.
4. 워크플로우가 드라이 런을 지원한다면 필요에 따라 드라이 런을 요청하세요.
5. ChatGPT에 일괄 작업을 실행하고 항목마다 성공 또는 실패 결과를 한 행씩 기록하도록 요청하세요.

작업 범위를 좁게 유지하고, 필수 입력이 모두 제공된 경우에만 작업을 실행하도록 ChatGPT에 지시하세요.
행에 필수 필드가 누락되어 있다면 ChatGPT가 추측하는 대신 해당 행을 표시해야 합니다.

티켓 시스템이나 목록 항목이 담긴 스프레드시트 등 작업 실행에 사용하는 도구를 [플러그인](/ko-KR/codex/plugins)으로 연결하세요.

## 결과 검증을 위한 근거 요구

유용한 운영 작업 실행에는 본인이나 팀원이 확인할 수 있는 결과가 포함되어야 합니다. 예를 들어 CSV, 로그 파일, 대시보드 링크, 스크린샷, PR 검사 또는 작업 성공을 보여 주는 기타 근거가 있습니다. ChatGPT 데스크톱 앱에서는 실행 후 [생성된 파일을 열어 살펴보고](/ko-KR/codex/artifacts-viewer) 결과를 검증할 수 있습니다.

## 실행을 재사용 가능한 워크플로우로 전환

첫 실행에 성공하면 반복 가능한 부분을 정리하도록 ChatGPT에 요청하세요. 일반적인 워크플로우라면 이를 [스킬](/ko-KR/codex/build-skills)이나 [예약 작업](/ko-KR/codex/automations)으로 만들 수 있습니다.

예약 운영 작업의 경우 수동 실행에서 신뢰할 수 있는 출력이 생성된 뒤에만 예약 작업을 만드세요. ChatGPT가 직접 수행하도록 명시적으로 요청하지 않는 한, 액세스 권한이나 데이터에 영구적인 영향을 줄 수 있는 민감한 작업은 초안 상태로만 유지하세요.
