## 재정리 전에 파일 목록 만들기

기존 수업 또는 단원 폴더에서 시작하세요. ChatGPT에 기준 파일, 작업 중인 초안, 절대 이동해서는 안 되는 파일이 각각 무엇인지 알려 주세요.

예상 용도별로 파일을 분류한 목록을 만들고 중복 파일, 불명확한 이름, 이전 버전을 표시해 달라고 요청하세요.

## 제안된 구조 검토하기

실용적인 폴더 구조는 다음과 같이 나눌 수 있습니다:

- 원본 자료 및 참고 자료
- 수업 계획안
- 프레젠테이션
- 학생용 배포 자료
- 평가 자료 및 정답지
- 접근성 지원 또는 언어별 버전
- 보관된 초안

세부 폴더 구성은 교사나 팀의 실제 업무 방식을 반영해야 합니다. 폴더 이름과 제안된 파일 이동을 검토한 후에 변경을 승인하세요.

## 결과 검증하기

정리가 끝나면 링크가 여전히 작동하는지, 현재 사용하는 파일을 계속 쉽게 찾을 수 있는지, 삭제된 항목은 없는지 확인하세요. ChatGPT에 README와 변경 사항 요약을 요청하되, 요약에는 이름이 변경되거나 이동 또는 보관된 파일이 표시되도록 하세요.

단원 내용이 크게 바뀔 때마다 파일 목록을 다시 만들어, 중복 파일이 또 쌓이는 일을 막고 폴더를 계속 편리하게 사용할 수 있도록 하세요.
