## 소개

예산을 편성하면서 차이를 검토하거나 문제를 확인하려는 경우, ChatGPT를 사용해 필요한 기능을 모두 갖춘 검토용 워크북을 만들어 활용할 수 있습니다.

예산 계획, 실적 내보내기 파일, 결산 메모를 첨부한 다음 ChatGPT에 편집 가능한 검토용 워크북을 요청하세요. ChatGPT는 원본 입력 데이터를 보존하고, 실적을 계획에 매핑해 차이를 계산하며, 채팅에서 확인할 수 있는 요약 보기를 만들 수 있습니다.

## 검토용 워크북 만들기

1. 예산 계획, 실적 내보내기 파일, 결산 메모를 첨부하거나, 출처 정보와 함께 정확한 파일 참조를 제공하세요.
2. 시작 프롬프트를 실행하고 편집 가능한 `.xlsx` 워크북을 요청하세요.
3. ChatGPT에서 워크북을 여세요. 원본 입력 데이터, 매핑, 차이 계산 수식, 요약 탭을 확인할 수 있도록 전체 화면 보기로 확장하세요.
4. 같은 채팅에서 계속해서 카테고리 매핑을 수정하고, 부서별 분석을 추가하거나, 재무 요약 초안을 작성하세요.

연결된 플러그인에 원본 파일이 있다면 정확한 파일이나 폴더를 지정하세요. 검토에 특정 재무 자료를 사용해야 한다면 ChatGPT에 Drive나 워크스페이스 전체를 검색하도록 요청하지 마세요. 채팅에 워크북이 나타나면 이를 열고 전체 화면으로 확장한 뒤, 수정을 요청하기 전에 원본 입력 데이터, 매핑, 차이 계산 수식, 요약 탭을 검토하세요.

## 차이 확인

워크북을 공유하기 전에 ChatGPT에 카테고리, 수식, 차이 설명을 점검하도록 요청하세요.
