## 시험 범위 정하기

공식 학습 목표, 강사의 안내 사항, 강의 노트, 읽기 자료, 문제 세트, 이전 퀴즈를 먼저 준비하세요. 학습에 쓸 수 있는 시간과 이미 보완이 필요하다고 판단한 주제도 추가하세요.

계획한 주제마다 근거가 되는 강의 자료를 연결해 달라고 ChatGPT에 요청하세요. 범위가 불분명한 주제는 시험 내용으로 간주하지 말고 확인할 질문으로 남겨 두세요.

## 여러 학습 방식 만들기

시작 프롬프트를 사용해 서로 보완되는 다음 자료를 만드세요:

1. 개념 간 관계를 보여 주는 개념도.
2. 복습용 간결한 학습 가이드.
3. 간격 반복 학습 일정표.
4. 회상, 설명, 응용 유형을 아우르는 문제 은행.
5. 강의 자료를 근거로 한 정답 해설.
6. 주제별 진도와 연습 결과를 기록하는 추적기.

하나의 요약을 반복해서 읽는 것보다 여러 형식을 함께 활용하면 부족한 부분을 더 쉽게 파악할 수 있습니다.

## 검토하고 조정하기

문제와 해설을 공식 자료와 대조해 확인하세요. 지어낸 주제, 명확하지 않은 정답, 근거 없는 주장을 제거하세요.

각 학습 세션이 끝나면 진도 추적기를 업데이트하고, 파악된 부족한 부분에 맞춰 다음 세션을 조정해 달라고 ChatGPT에 요청하세요. 채점 대상 평가와 이용이 제한된 강의 자료는 강사가 정한 규칙에 따라 다루세요.
