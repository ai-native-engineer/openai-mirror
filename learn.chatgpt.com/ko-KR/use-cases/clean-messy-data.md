## 소개

ChatGPT는 표 형식 데이터를 체계적으로 정제하는 데 탁월합니다.
CSV나 스프레드시트에 여러 형식의 날짜, 중복 행, 통화 문자열, 빈 셀, 별칭 또는 붙여 넣은 요약 행이 있다면, 원본 파일은 변경하지 않고 사본을 정제해 달라고 ChatGPT에 요청하세요.

## 사용 방법

1. ChatGPT에 파일을 드래그해 넣거나 프롬프트에서 `@customer-export.csv`처럼 멘션하세요.
2. 이미 확인한 문제를 설명하세요.
3. 정제된 버전을 CSV, 스프레드시트 탭 또는 바로 업로드할 수 있는 파일 중 어떤 형식으로 만들지 ChatGPT에 알려 주세요.
4. 정제된 사본은 사용하기 전에 검토하세요.

1차 정제에는 이 페이지의 시작 프롬프트를 사용하세요. 파일 이름과 글머리 기호 항목을 상황에 맞게 바꾸세요. 중요한 정보는 이미 파악한 문제와 다음 단계에 필요한 파일 형식입니다. 파일 형식은 정제된 CSV, 정제된 스프레드시트 탭 또는 바로 업로드할 수 있는 파일일 수 있습니다. ChatGPT가 정제된 사본을 만들면 해당 데이터를 후속 작업에 사용하기 전에 채팅에서 정제된 파일과 데이터 품질 메모를 열어 확인하세요.
