## 승인된 교육 콘텐츠로 시작하기

검토된 수업 패키지, 연습 문제, 피드백 규칙, 접근성 요구사항, 디자인 선호 사항을 활용하세요. 학습 목표와 학생이 해당 연습을 완료했는지 판단할 근거를 파악하세요.

누락된 교육 정책이나 학습자 데이터를 임의로 만들어 내지 마세요.

## 학습 플로우 만들기

핵심에 집중한 첫 버전에는 다음이 포함되어야 합니다:

- 명확한 소개
- 단계별 예시
- 몇 가지 대화형 연습 활동
- 제공된 규칙에 따른 피드백
- 최종 자가 점검
- 교사용 메모

Sites에서 자료를 만들고 미리 보세요. 철저하게 테스트할 수 있을 만큼 인터랙션 모델을 단순하게 유지하세요.

## 공유하기 전에 테스트하기

주요 경로, 키보드 조작, 레이블, 색상 대비, 반응형 동작, 피드백 로직, 콘텐츠 정확성을 확인하세요. 정답과 오답을 모두 테스트하세요.

ChatGPT에 제한 사항과 접근성이나 수업에 관해 아직 해결되지 않은 질문을 문서화하도록 요청하세요. 검토된 자료는 게시하거나 학생들과 공유하기 전에 교육자의 승인을 받아야 합니다.
