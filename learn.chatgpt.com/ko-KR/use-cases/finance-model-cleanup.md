## 소개

금융 모델에는 눈에 잘 띄지 않는 하드코딩 값, 오래된 링크, 일관성 없는 기간, 검증 결과가 더 이상 일치하지 않는 항목이 쌓이기 쉽습니다. ChatGPT는 워크북을 체계적으로 점검하고 수정 범위를 엄격히 제한해 필요한 부분만 고친 뒤, 어느 지점에서 재무 책임자의 판단이 필요한지 알려 주는 QA 메모를 작성할 수 있습니다.

## 검토 범위 정의

모델과 대사 기준이 되는 원본 파일을 첨부하세요. 결과물을 확인할 대상, 우선 확인할 탭, 예상 결과물, ChatGPT가 변경하지 않아야 할 가정을 명시하세요. 모든 수정 사항을 비교할 수 있도록 원본 워크북도 보관하세요.

1. 모델과 이를 뒷받침하는 원본 파일을 첨부하세요.
2. 우선 확인할 탭, 예상 검증 항목, 변경하지 않을 가정을 지정하세요.
3. 스타터 프롬프트를 실행해 정리된 사본과 QA 메모를 요청하세요.
4. ChatGPT에서 워크북을 열고 변경된 수식, 링크, 출력 탭을 점검하세요.
5. 재무 책임자의 확인이 필요한 질문을 해결한 뒤 가정 변경을 수락하세요.

## 정리 결과 확인

QA 메모에는 문제를 심각도순으로 정리하고 정확한 셀이나 탭을 명시해야 합니다. 안전한 서식·레이블 수정과 수정 방법이 명확한 수식 오류는 바로 반영할 수 있지만, 모호한 비즈니스 로직은 계속 검토 대상으로 표시해야 합니다.
