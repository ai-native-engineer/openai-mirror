## 소개

데스크톱 앱, 창 또는 로컬 파일을 오가는 작업에는 [컴퓨터 사용](/ko-KR/docs/computer-use)을 활용하세요. ChatGPT가 허용된 앱에서 클릭하고 입력하며 탐색한 다음, 검토할 수 있도록 결과를 반환합니다. 웹사이트나 로그인된 브라우저 세션에서 작업하려면 `@Chrome`으로 별도의 브라우저 작업을 시작하세요.

**컴퓨터 사용에는 ChatGPT 데스크톱 앱이 필요합니다.** 지원되는 지역에서는 macOS와 Windows에서 ChatGPT Work와 Codex를 통해 컴퓨터 사용을 이용할 수 있습니다. 웹이나 모바일에서 실행하는 클라우드 Work 작업은 로컬 앱, 파일 또는 로그인된 데스크톱 브라우저 세션에 직접 접근할 수 없습니다. Mac 또는 Windows 호스트를 연결하면 [모바일 원격 기능](/ko-KR/codex/remote-connections)으로 데스크톱 작업을 시작하거나 진행 방향을 조정할 수 있습니다.

대표적인 활용 사례로는 메모를 기록 시스템으로 옮기기, 답장 초안을 작성하기 전에 여러 앱에서 컨텍스트 확인하기, 전용 플러그인이 없는 도구 사이에서 승인된 세부 정보 복사하기 등이 있습니다.

Messages와 Notes에 주말 오두막 여행 계획이 있다면 다음과 같이 안전하게 데스크톱 작업을 맡길 수 있습니다:

<div data-use-case-export-only>

**데스크톱 작업:** Messages에서 주말 오두막 여행 아이디어를 모으고 Notes의 후보 목록을 확인한 뒤 로컬 메모를 만들고 답장 초안을 작성합니다.

**결과:** Pine Lodge는 계단 없이 출입할 수 있고 2시간 이내 거리에 있으며 총비용은 $690입니다. Lake House도 가능하지만 이동 시간과 접근성을 확인해야 합니다. Cedar Ridge는 계단이 있어 제외되었습니다. 그룹 인원을 알 수 없어 1인당 요금은 아직 확정할 수 없습니다.

로컬 메모와 답장 초안을 검토할 준비가 되었습니다. 예약하거나 전송한 내용은 없습니다.

## 사용 방법

1. ChatGPT 데스크톱 앱을 열고 [컴퓨터 사용 플러그인](/ko-KR/docs/computer-use)을 설치하세요.
2. 데스크톱 앱 작업은 `@Computer`로, 브라우저 작업은 `@Chrome`으로 요청을 시작하세요.
3. 작업 내용, 관련 앱이나 파일, 원하는 결과를 설명하세요.
4. 접근 권한 요청을 검토하고 중요한 데이터를 전송하거나 제출하거나 변경하는 작업을 하기 전에 잠시 멈추세요.
5. Windows에서는 컴퓨터 사용이 실행되는 동안 대상 앱이 화면에 보이도록 유지하세요.

앱에 사용할 수 있는 플러그인이 있다면 ChatGPT가 구조화된 작업에 해당 플러그인을 사용할 수 있습니다. 작업에 앱 인터페이스가 필요하거나 사용할 수 있는 플러그인이 없다면 컴퓨터 사용이 유용합니다.

## 시도해 볼 작업

도구 하나로 시작하세요. 데스크톱 앱과 로컬 파일에는 `@Computer`를, 브라우저에는 `@Chrome`을 사용하세요. 필요에 따라 ChatGPT가 다른 도구를 선택할 수 있습니다.

**메시지를 바탕으로 계획 세우기**

**숙소 찾기**

**프로젝트 진행 상황 파악하기**

**회의 메모를 바탕으로 트래커 업데이트하기**

**로그인된 브라우저에서 작업하기**

**웹사이트 테스트하기**

**로컬 파일 정리하기**

**현재 보고 있는 화면 보여 주기**

macOS에서는 [앱샷](/ko-KR/codex/appshots)으로 현재 보고 있는 앱 창을 공유하세요. 앱샷은 시각적 컨텍스트를 제공하며, 사용자가 허용하면 컴퓨터 사용으로 해당 앱을 열고 살펴보거나 조작할 수 있습니다.

## 실용적인 팁

### 컴퓨터별 작업 실행 방식 이해하기

macOS에서는 다른 앱을 사용하는 동안 컴퓨터 사용이 백그라운드에서 작업을 실행할 수 있습니다. 화면 속 화면 미리보기에는 활성 앱이 표시됩니다. 미리보기를 열어 작업 과정을 확인하거나 방해되지 않는 곳으로 옮기세요. 펫을 사용하는 경우 미리보기를 펫으로 옮길 수 있습니다.

Windows에서는 컴퓨터 사용이 활성 데스크톱에서 실행되며 포그라운드를 제어합니다. 작업이 실행되는 동안 마우스 포인터가 움직이고 키보드 입력이 이루어집니다. 기기를 잠그지 말고 연결 상태를 유지하세요. 기본 데스크톱을 계속 사용해야 한다면 데스크톱 앱을 Windows 가상 머신에서 실행하세요.

### 적합한 브라우저 선택하기

컴퓨터 사용에는 브라우저 작업이 포함되는 경우가 많습니다. 필요한 컨텍스트가 있는 브라우저를 선택하세요.

- **[Chrome 확장 프로그램](/ko-KR/codex/chrome-extension):** 매물 검색, 웹사이트 탐색, 기존에 로그인된 Chrome 프로필이나 탭 또는 확장 프로그램 사용 등의 브라우저 작업에는 `@Chrome`을 사용하세요.
- **[내장 브라우저](/ko-KR/codex/browser?surface=app):** 로컬호스트나 공개 사이트에 사용할 별도의 브라우저 세션이 필요할 때 사용하세요. 자체 브라우저 상태를 유지하며 사용자가 로그인하는 동안 기다릴 수 있습니다.
- **웹 또는 모바일의 ChatGPT Work 클라우드 브라우저:** 로그인하지 않은 상태로 이용할 수 있는 지원 대상 공개 사이트에 사용하세요. 로컬 파일, 열린 탭, 확장 프로그램 또는 저장된 비밀번호에 접근할 수 없으며, 사이트에 로그인하거나 결제를 완료할 수도 없습니다.

필요한 경우 프롬프트에 브라우저를 명시하고, 반복해서 적용할 데스크톱 기본 설정은 [맞춤 설정](/ko-KR/docs/customization/overview)에서 지정하세요.

### 같은 앱에서 동시 실행 피하기

같은 앱에서 두 개의 컴퓨터 사용 작업을 동시에 실행하지 마세요. 작업 간 동작이 충돌하면 현재 창이나 상태가 변경되어 결과를 신뢰하기 어려울 수 있습니다.

### 앱 로그인 및 잠긴 상태 사용 준비하기

데스크톱 작업을 시작하기 전에 필요한 앱과 서비스에 로그인하세요. macOS에서 Mac이 잠긴 후에도 작업을 계속해야 한다면 [잠긴 상태 사용](/ko-KR/docs/computer-use#locked-use)을 활성화할 수 있습니다. Windows의 컴퓨터 사용에서는 잠긴 상태 사용을 이용할 수 없습니다.
