# 생산성 및 협업

ChatGPT Work 또는 Codex를 사용해 플러그인, 파일, 팀 전반의 작업을 조율하세요.
ChatGPT는 파일, 메시지, 문서, 스프레드시트에서 컨텍스트를 수집해 공유 가능한 결과물로 만들 수 있습니다.
레포지토리, 재현 가능한 스크립트 또는 작업 트리에 의존하는 데이터 프로젝트에는 Codex를 사용하세요.

## 새로운 개념 학습하기

난해한 논문, 사양서 또는 기술 가이드를 나중에 검토할 수 있는 정의, 예시, 질문으로 정리하도록 ChatGPT에 요청하세요.

## 여러 단계로 구성된 워크플로우 위임하기

ChatGPT가 여러 플러그인에서 승인된 입력을 수집해 워크플로우를 준비하거나, 사용자의 컴퓨터를 이용해 여러 데스크톱 앱에서 작업을 완료하도록 하세요.

## 업무 흐름 유지하기

ChatGPT가 사용자가 승인한 소스를 확인하고 실제 요청, 변경된 결과물, 진행이 막힌 인계, 답변 초안, 결정 사항 등 확인이 필요한 항목만 알려 주도록 하세요.

## 데이터 다루기

ChatGPT를 사용해 데이터 세트를 탐색하고, 스프레드시트를 정리하고, 가설을 검증하고, 질문에 답하고, 시각화를 만드세요.

## 재현 가능한 분석 구축하기

Codex를 사용해 레포지토리에서 데이터 세트를 정제하고 결합하며, 코드로 가설을 탐색하고, 결과를 검토와 재실행이 가능한 결과물로 구성하세요.

## 분석을 검토 가능한 결과물로 구성하기

ChatGPT가 승인된 입력을 공유할 수 있고 검토 준비가 완료된 슬라이드, 메시지 및 기타 결과물로 변환하도록 하세요.
