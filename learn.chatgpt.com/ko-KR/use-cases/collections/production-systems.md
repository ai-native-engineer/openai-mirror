# 프로덕션 시스템

이 컬렉션의 사용 사례는 Codex가 변경 이력, 테스트, 담당자, 프로덕션 제약 조건이 이미 있는 레포지토리에서 작업할 때 유용합니다.
Codex는 다양한 서비스와 종속성이 얽혀 있는 방대한 모노레포지토리를 비롯해 복잡한 코드베이스를 탐색하는 데 특히 뛰어납니다.
프로덕션 시스템을 다루고 있다면 이러한 사용 사례를 살펴보고 Codex를 어떻게 활용할 수 있는지 알아보세요.

## 코드베이스 둘러보기부터 시작하기

Codex를 활용하면 복잡한 코드베이스를 파악할 수 있으며, 특히 프로덕션 소프트웨어 레포지토리에 처음 합류할 때 유용합니다.

## 코드베이스 현대화하기

Codex를 활용해 기술 스택 마이그레이션을 계획하고, 해당되는 경우 최신 모델을 사용하도록 통합을 업그레이드하며, 가독성과 유지보수성을 높이도록 코드베이스를 리팩터링하세요.

## 반복 작업 체계화하기

레포지토리에 특화된 워크플로우나 체크리스트를 스킬로 전환하도록 Codex에 요청해, 해당 레포지토리의 모든 기여자가 표준화된 프로세스를 활용할 수 있게 하세요.

## 문서를 최신 상태로 유지하기

Codex에 소스 변경 사항을 기존 문서와 비교하고, 문서 중 필요한 최소 범위만 업데이트한 뒤 변경 사항을 검증하도록 요청하세요.

## 시스템 상태 유지하기

Slack에서 Codex를 사용하고 알림 시스템, 이슈 추적 도구, 일일 버그 점검 프로세스에 연결해 기능 요청과 버그 수정 작업을 자동으로 맡아 처리하게 하세요.

## 검토 병목 방지하기

Codex를 활용해 PR을 자동으로 검토하고 핵심 플로우를 대상으로 집중적인 QA를 수행하면 문제를 빠르게 발견하고 안심하고 업데이트를 배포할 수 있습니다.
