# 재무

ChatGPT Work 또는 Codex를 사용해 승인된 워크북, 대시보드, 모델, 담당자
컨텍스트를 검토 가능한 분석 및 보고 자료로 전환하세요. ChatGPT는
수식, 출처, 가정, 미해결 질문을 계속 확인할 수 있게 하므로 재무
담당자가 어떤 내용이든 공유하기 전에 직접 판단할 수 있습니다.

## 실적을 설명하세요

결산 데이터를 경영진용 설명 자료로 구성하고, 실적을 계획과 비교한 뒤,
중요한 변동을 일으킨 요인을 순위별로 정리하세요.

## 모델과 계획을 검토하세요

가정이나 출처 정보의 누락을 숨기지 않고 재무 모델을 작성하거나 점검하고,
예측을 업데이트하며 시나리오를 비교하세요.
