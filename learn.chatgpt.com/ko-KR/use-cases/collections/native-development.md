# 네이티브 개발

각 반복 작업에 빌드, 실행 또는 시뮬레이터 루프를 연계하면 Apple 플랫폼 프로젝트에서 Codex를 매우 효과적으로 활용할 수 있습니다.
이 사용 사례는 신규 또는 기존 iOS 및 macOS 앱을 개발하면서 UI를 반복 개선하고 이슈를 디버깅해야 할 때 유용합니다.

## 앱 셸 빌드하기

Codex에 반복 가능한 빌드 루프를 갖춘 iOS 및 macOS 앱의 기본 구조를 생성하도록 요청하세요. Mac 셸 사용 사례에서는 사이드바-상세 보기-인스펙터 레이아웃, 명령, 설정 등 데스크톱 네이티브 구조를 더 자세히 다룹니다.

## iOS SwiftUI 화면 리팩터링하기

Codex를 사용해 동작을 변경하지 않고 대규모 SwiftUI 뷰를 분할한 다음, 앱이 준비되면 선택한 iOS 플로우를 Liquid Glass로 전환하세요.

## iOS 액션을 시스템에 노출하기

사용자가 시스템의 여러 화면에서 앱 기능에 접근할 수 있도록 Codex를 활용해 앱이 App Intents를 통해 노출해야 하는 액션과 엔티티를 파악하세요.

## 앱 디버깅하기

Codex를 사용해 Simulator에서 버그를 재현하거나 macOS 앱에 텔레메트리를 추가하여 이슈를 디버깅하고 수정하세요.
