# 게임 개발

Codex는 이미지 생성 기능과 함께 사용하면 브라우저 기반 게임을 비롯한 다양한 유형의 게임을 만드는 데 특히 강력합니다.
이 사용 사례를 통해 아이디어를 실제로 플레이할 수 있는 게임으로 구현할 수 있습니다.

## 플레이 가능한 첫 게임 루프 만들기

Codex에 게임 개요를 에셋, 조작 체계, 테스트 가능한 게임 루프를 갖춘 브라우저 빌드로 구현해 달라고 요청하세요.

## UI와 조작 체계 다듬기

게임이 실행된 후 Codex를 사용해 HUD 세부 요소와 메뉴, 조작 체계를 조정하고 사소한 상호작용 문제를 해결하세요.

## 까다로운 게임 로직 해결하기

Codex로 자체 평가 루프를 실행하여 복잡한 게임 알고리즘을 반복 개선하세요.

## 실제 신호를 바탕으로 버그 분류하기

Codex가 게임을 패치하기 전에 버그 보고서, 실패한 검사, 로그, 재현 메모를 모아 우선순위가 지정된 목록으로 정리하도록 하세요.

## 병합 전에 검토하기

GitHub에서 Codex가 PR을 자동으로 검토해 회귀 문제와 누락된 테스트를 찾아내도록 하여 배포 속도를 높이세요.
