## 피드백을 변경 계획으로 전환하기

현재 수업 자료 폴더, 피드백, 승인된 파일 목록, 명시적인 확인이 필요한 변경 사항을 준비하세요. 요청된 변경 사항과 제안 또는 미해결 질문을 구분하세요.

각 피드백 항목을 영향을 받는 파일 및 섹션에 매핑해 달라고 ChatGPT에 요청하세요.

## 범위 승인하기

수정을 허용하기 전에 파일별 계획을 검토하세요. 어떤 이전 버전을 보존해야 하는지, 용어·예시·정답 같은 공통 콘텐츠는 어떤 소스 파일을 기준으로 관리하는지 확인하세요.

승인 후에는 연결된 파일을 한 번의 통합 작업으로 수정하세요.

## 파일 간 일관성 확인하기

업데이트된 수업용 슬라이드, 교사용 가이드, 학생용 유인물, 정답지를 비교하여 다음을 확인하세요:

- 예시와 정답이 여전히 일치하는지
- 지침에서 일관된 용어를 사용하는지
- 시간 배정 변경 사항이 필요한 모든 곳에 반영되었는지
- 출처 링크가 그대로 유지되는지
- 이전 버전이 아카이브에 보관되었는지
- 미해결 질문이 계속 표시되는지

변경 로그를 활용하여 교육자의 최종 검토를 지원하세요. 담당 검토자의 확인 없이는 요청된 수정 사항을 승인된 수업 관련 결정이나 정책 결정으로 간주하지 마세요.
