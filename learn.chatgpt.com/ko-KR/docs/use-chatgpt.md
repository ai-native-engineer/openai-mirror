## 아이디어를 유용한 결과물로 만들기

ChatGPT는 자연어로 소통할 수 있는 AI 에이전트입니다.

1. 질문, 아이디어, 정리되지 않은 메모, 파일 또는 완료해야 할 작업으로 시작하세요.

2. ChatGPT에 정보 설명, 아이디어 구체화, 콘텐츠 초안 작성, 주제 조사, 자료 분석 또는 새로운 결과물 생성을 요청하세요.

3. 파일, 웹 검색, 프로젝트, 플러그인 등 필요한 컨텍스트와 도구를 추가하세요.

4. 결과를 검토하고 방향을 바로잡은 다음 변경을 요청하세요. 처음부터 완벽한 프롬프트를 작성하거나 특별한 명령어를 사용할 필요는 없습니다.

## 작업 방식 선택하기

질문하거나 대화를 주고받을 때는 채팅을 사용하세요. ChatGPT에 더 큰 작업을 맡겨 검토할 수 있는 결과물까지 완성하게 하려면 전환 메뉴에서 Work를 켜세요. 개발자용 화면이나 더 자세한 기술 정보가 필요할 때, 특히 소프트웨어 개발 작업에는 Codex를 선택하세요.

| 선택       | 사용 목적                              | 예시                                                                     |
| ------------ | --------------------------------------------- | ---------------------------------------------------------------------------- |
| 채팅         | ChatGPT와 함께 작업하기           | 질문, 웹 검색, 브레인스토밍, 메시지 초안 작성, 옵션 비교 |
| ChatGPT Work | 원하는 결과를 정하고 검토 가능한 결과물 받기 | 프레젠테이션 제작, 파일 분석, 보고서 초안 작성, 프로젝트 계획 수립           |
| Codex        | 개발자 도구를 사용하고 기술 세부정보 확인하기 | 코드 디버깅, 테스트 실행, PR 검토, 기능 구현                      |

질문, 브레인스토밍, 글의 초안 작성이나 수정, 파일 요약,
옵션 비교, 더 큰 작업의 구체화에는 채팅을 사용하세요. Codex에서는 **새 채팅에** 마우스 포인터를 올린 다음,
 **빠른 채팅** 옵션이 있으면 선택하세요.

검토할 수 있는 완성된 결과물이 필요하면 **Work로** 전환하고
결과물에 포함할 내용을 설명하세요. [ChatGPT
Work 시작하기](/ko-KR/codex/get-started-with-work)에서 작업 예시, 프롬프트,
권장사항을 확인하세요.

### ChatGPT Work로 할 수 있는 작업

ChatGPT Work는 작업을 계획하고, 컨텍스트를 수집하고, 도구를 사용해 검토할 수 있는 결과물이 나올 때까지 작업을 진행할 수 있습니다.

  

다음과 같은 작업을 요청하세요:

- **정보를 조사하고 분석하세요.** 웹을 검색하고, 웹사이트를 탐색하며,
  출처를 비교하고, 파일을 읽고, 데이터를 분석해 조사 결과를 요약하세요.
- **파일과 도구를 활용하세요.** 업로드한 파일,
[프로젝트](/ko-KR/codex/projects), 메모리, ChatGPT Library, 설치된
[플러그인](/ko-KR/codex/plugins)을 불러오세요. 플러그인은 연결된 정보, 재사용 가능한
  워크플로우, 지원되는 작업을 제공할 수 있습니다.
- **완성된 파일을 만드세요.** [문서, 프레젠테이션,
  스프레드시트, PDF 파일](/ko-KR/codex/artifacts-viewer)의 초안을 작성하고 다듬으세요. 결과를 검토하고
  구체적인 변경을 요청한 다음 완성된 파일을 다운로드하세요.
- **시각적이고 인터랙티브한 결과물을 만드세요.** 
[이미지](/ko-KR/codex/image-generation)를 생성하거나 편집하고, 인터랙티브한
[시각화](/ko-KR/codex/visualizations)를 만들고,
  [Sites](/ko-KR/codex/sites)로 웹사이트와 앱을 제작하거나 공유하세요.
- **웹사이트와 앱을 넘나들며 작업하세요.** [브라우저](/ko-KR/codex/browser)를 사용해
  웹사이트에서 정보를 조사하고 필요한 작업을 수행하세요. 데스크톱 앱에서는
[브라우저 확장 프로그램](/ko-KR/codex/chrome-extension),
[컴퓨터 사용](/ko-KR/codex/computer-use), [앱샷](/ko-KR/codex/appshots)이 제공되는 경우
  이 기능들을 사용하세요.
- **코드를 실행하고 기술 작업을 검토하세요.** 코드와 셸 명령어를 실행하고, 데이터를
  분석하고, 파일을 살펴보며, [코드를 검토](/ko-KR/codex/code-review)하고 선택한 환경에서
  접근할 수 있는 레포지토리에서 작업하세요.
- **작업을 위임하고 장시간 작업을 이어가세요.** 독립적으로 진행할 수 있는 작업을 여러
[하위 에이전트](/ko-KR/codex/agent-configuration/subagents)에게 나누어 맡기고 진행 상황을 확인하며
  [장시간 작업](/ko-KR/codex/long-running-work)을 계속 실행하세요.
- **유용한 워크플로우를 반복해서 사용하세요.** 반복 작업을 처리할 [예약
  작업](/ko-KR/codex/automations)을 설정하고
[스킬](/ko-KR/codex/skills-and-plugins)을 활용해 워크플로우를 재사용하세요.
- **대화로 작업을 진행하세요.** 지원되는 플랜에서는 데스크톱 앱의
[ChatGPT 음성 대화](/ko-KR/codex/features/voice)로 작업을 시작하거나, 진행 상황을 확인하거나,
  작업 방향을 바꾸세요.

  기능 제공 여부는 플랜, 플랫폼, 지역, 배포 상황, 워크스페이스
  설정에 따라 달라집니다. 워크스페이스 관리자는 ChatGPT Work와
  플러그인, 브라우저의 사용 권한 및 네트워크 접근을 제어할 수 있습니다. ChatGPT Work와 Codex는 [사용량
  한도](/ko-KR/codex/pricing)를 공유합니다.

### 클라우드 또는 로컬 작업 선택하기

웹에서는 ChatGPT Work가 관리형 클라우드 환경에서 실행됩니다. 데스크톱 앱에서는 작업을 실행할 위치를 선택할 수도 있습니다:

- **클라우드:** 격리된 호스팅 환경에서 작업을 실행합니다. 데스크톱 앱을 닫은 뒤에도
  작업이 계속 진행될 수 있으며, 웹이나 모바일 앱에서 이어서 진행할 수 있습니다.
  클라우드 작업에서는 업로드한 파일, 연결된 도구, 승인된 웹사이트를 사용할 수 있습니다.
- **로컬 작업:** 컴퓨터의 파일, 앱 또는 브라우저를 사용합니다.
  계정이나 워크스페이스에서 이 기능이 활성화되어 있으면
  데스크톱 앱에서 로컬 작업을 이용할 수 있습니다.

ChatGPT는 진행 상황을 표시하며 정보나 승인이 필요하면 일시 중지합니다. 중대한 영향을 줄 수 있는 작업은 승인 전에 검토하고, 최종 결과는 사용하거나 공유하기 전에 확인하세요.

### 데스크톱에서 ChatGPT Work와 Codex 비교하기

ChatGPT Work와 Codex는 일부 기능이 겹칩니다. Codex를 선호한다면 조사, 문서, 프레젠테이션 및 기타 지식 업무에 계속 사용할 수 있습니다. 두 제품을 모두 이용할 수 있다면, 데스크톱 앱에서는 선택한 제품에 따라 인터페이스와 에이전트가 작업을 보여주는 방식이 달라집니다.

| 차이점          | 데스크톱 앱의 ChatGPT                                                 | 데스크톱 앱의 Codex                                              |
| ------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 시작 방법      | **ChatGPT를** 선택한 다음 **Work로** 전환                            | 제품 선택 메뉴에서 **Codex를** 선택                          |
| 표시되는 채팅       | 웹과 모바일의 채팅 모드에서 시작한 대화와 ChatGPT Work 대화 표시 | Codex 채팅과 개발 프로젝트를 중심으로 표시                     |
| 빠른 채팅          | 제공되지 않음                                                          | 기능이 제공되는 경우 웹과 모바일의 ChatGPT 채팅을 Codex에서 이용 |
| 기술 세부정보    | Git이나 셸 명령어와 같은 기술 세부정보 숨김                      | diff 화면과 검토 화면 등 개발자용 세부정보 표시            |
| 에이전트의 소통 방식 | 기술 전문 용어를 쓰지 않는 표현과 완성된 결과물을 선호                     | 기술 및 구현 세부 사항을 포함할 수 있음                  |
| Pull Request 패널  | ChatGPT Work 사용 시 이용 불가                                  | 활성화된 경우 이용 가능                                            |

### ChatGPT와 자연스럽게 대화하기

도움을 주는 동료에게 요청을 설명하듯 작성하세요. 이루려는 목표를 밝히고,
답변에 영향을 주는 세부 정보를 더한 뒤 원하는 형식을 설명하세요.
첫 프롬프트는 시작점일 뿐입니다. 후속 메시지로 컨텍스트를 추가하거나
결과를 다듬을 수 있습니다.

다음과 같은 간단한 요청으로 대화를 이어갈 수 있습니다:

- “이 내용을 더 짧게 줄여 주세요.”
- “서로 다른 접근 방식 세 가지를 제시해 주세요.”
- “어떤 가정을 하고 있나요?”
- “계속하기 전에 제게 질문해 주세요.”

[프롬프팅](/ko-KR/codex/prompting)에 대해 자세히 알아보거나
[AI 기초 과정](https://academy.openai.com/home/courses/ai-foundations-juzjs)을 수강하며
안내에 따라 실습해 보세요.

## ChatGPT에 적절한 컨텍스트 제공하기

작업에 중요한 정보, 도구, 지침을 ChatGPT에 제공하세요.
모든 정보를 제공할 필요는 없습니다. 좋은 결과의 기준에 영향을 미치는
컨텍스트를 포함하세요.

### 관련 작업을 프로젝트에 모아 두기

프로젝트를 사용하면 ChatGPT에서 주제, 목표 또는 지속적으로 진행하는 작업별로
내용을 정리할 수 있습니다. 작업이 계속 이어지거나 같은 컨텍스트가 필요하다면
관련 채팅, 파일, 지침을 하나의 프로젝트에 모아 두세요. [프로젝트에 대해
자세히 알아보세요.](/ko-KR/codex/projects)

### 파일 첨부하기

문서, 프레젠테이션, 스프레드시트, PDF 파일, 이미지,
내보낸 데이터를 업로드하거나 첨부할 수 있습니다. ChatGPT에 다음 작업을 요청할 때 활용하세요:

- 내용을 요약하거나 비교하기
- 패턴이나 불일치 찾기
- 정보를 추출, 정제 또는 재구성하기
- 새 파일을 만들 때 원본 자료로 사용하기

ChatGPT가 파일을 만들면 미리 보기를 열어 내용을 확인하세요.
처음부터 다시 시작하지 않고도 변경을 요청할 수 있습니다. 자세한 내용은
[파일로 작업하는 방법](/ko-KR/codex/artifacts-viewer)에서 확인하세요.

### 플러그인으로 도구 연결하기

플러그인을 사용하면 Google Drive, SharePoint, Salesforce, Gong 등 업무에 사용하는
도구와 정보를 ChatGPT에 연결할 수 있습니다. 채팅 외부의 정보, 다른 시스템에서의 작업 또는
반복 가능한 워크플로우가 필요한 경우
플러그인을 사용하세요.

  

플러그인 사용 가능 여부는 사용 중인 플랜, 워크스페이스 설정, 해당 플러그인에
따라 달라집니다. [스킬과 플러그인](/ko-KR/codex/skills-and-plugins)에 대해 자세히 알아보세요.

## Codex 스레드의 읽기 전용 스냅샷 공유하기

모든 Codex 플랜에서 macOS용 ChatGPT 데스크톱 앱으로 로컬 Codex 스레드의
읽기 전용 스냅샷을 만들 수 있습니다. 스냅샷을 공유해도 다른 사람에게 사용자의 프로젝트나
컴퓨터에 대한 접근 권한이 부여되지는 않습니다.

공유하기 전에 누가 링크를 열 수 있는지 확인하세요:

- **개인 계정:** 링크가 있는 사람은 누구나 스냅샷을 열 수 있습니다.
- **워크스페이스 계정:** 스냅샷을 만든 워크스페이스의 인증된 구성원만
  스냅샷을 열 수 있습니다. 해당 워크스페이스의 모든 구성원에게 접근을 허용하거나
  초대받은 사람과 그룹으로 접근 대상을 제한할 수 있습니다. 워크스페이스 관리자는
  워크스페이스 공유 링크를 비활성화할 수 있습니다.

1. 스레드를 열고 **공유를** 선택하세요. 슬래시 명령어를 지원하는 환경에서는 `/share`도
   사용할 수 있습니다.
2. 워크스페이스 계정이라면 **접근 권한이 있는 사용자** 설정에서 워크스페이스의 모든 구성원 또는
    **초대된 사람과 그룹만을** 선택하세요. 초대받은 대상만 접근하도록 하려면
   기존 워크스페이스 구성원을 이메일로 추가하거나 워크스페이스 그룹을 선택하세요.
3. 스냅샷 업로드가 완료될 때까지 기다린 후 **링크 복사를** 선택하세요.
   대화 상자를 열면 업로드가 시작되지만, Codex는 **링크 복사를** 선택할 때만
   사용자가 선택한 공개 범위와 수신자에 맞춰 스냅샷을 게시합니다.
4. 다른 사람에게 보내기 전에 복사한 링크를 열어 공유 화면을 검토하세요.

스냅샷에는 공유 시점의 스레드 콘텐츠 중 지원되는 항목이 담깁니다.
이후에 추가된 메시지나 변경 사항은 기존 스냅샷에 반영되지 않습니다.

공유된 스냅샷에는 사용자에게 표시되는 메시지, 추론 요약, 첨부 이미지,
에이전트가 확인하거나 생성한 이미지, 경로와 diff를 포함한 파일 변경 사항이 담길 수 있습니다.
원본 스레드의 도구 호출, 셸 명령어,
도구 입력 또는 출력은 포함되지 않습니다.

Codex는 스냅샷을 업로드하기 전에 알려진 패턴과 일치하는 비밀 정보를 가립니다. 파일 경로를 비롯한
민감한 내용이 메시지, 이미지 또는 diff에 남아 있을 수 있으므로 링크를 보내기 전에
공유 화면을 검토하세요.

공유 스냅샷에서 원본 스레드를 포크할 수는 없습니다. 스냅샷을 첨부 파일로 가져와
새 스레드에서 참조할 수 있습니다.

공유 링크를 확인하거나 공유를 취소하려면 [ChatGPT 데이터
제어](https://chatgpt.com/#settings/DataControls)를 열고 **공유 링크를** 선택하세요.

## 결과를 바로 사용할 수 있도록 다듬기

첫 결과는 검토하고 의문을 제기하며 개선할 수 있는 초안으로 여기세요.
잘 다듬어진 답변도 불완전하거나 틀릴 수 있으므로 사용하거나 공유하기 전에 중요한
세부 사항을 검토하세요.

**작업 결과 확인:**

- 중요한 수치, 이름, 날짜, 인용문, 주장을 검증하세요.
- 생성된 파일을 열어 모든 섹션, 탭, 슬라이드 또는 페이지를 확인하세요.
- ChatGPT가 올바른 최신 원본 자료를 사용했는지 확인하세요.
- 누락된 정보나 근거 없는 가정이 있는지 확인하세요.
- 결과물이 목표에 부합하지 않으면 필요한 부분을 중심으로 수정해 달라고 요청하세요.

그런 다음 ChatGPT에 결과물을 철저히 검증해 달라고 요청하세요:

- “이 작업에 어떤 자료를 참고했나요?”
- “주요 주장마다 출처를 밝혀 주세요.”
- “어떤 가정을 했나요?”
- “접근하지 못한 정보는 무엇인가요?”
- “무엇이 달라지면 추천 내용이 바뀌나요?”
- “이 결과를 원본 파일과 대조해 확인해 주세요.”

ChatGPT가 자료에 접근하지 못했거나 작업의 일부를 완료하지 못했다면 그 사실을 분명히 밝히도록 요청하세요. 자신 있게 내놓은 추측보다는 명확히 드러난 부족한 부분을 보완하기가 더 쉽습니다.

  법률, 금융, 의료, 보안 등 중대한 사안에 관한 결정에는 적절한 전문가 검토가 필요합니다. ChatGPT는 충분한 정보에 근거한 판단을 돕는 용도로 사용하고, 판단을 대신하게 해서는 안 됩니다.
