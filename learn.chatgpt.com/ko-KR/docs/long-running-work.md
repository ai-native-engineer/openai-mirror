여러 단계가 필요할 수 있는 작업을 맡길 때는 ChatGPT에 명확한 결과와 제약 조건,
완료 기준을 알려주세요. 관련 작업은 같은 채팅에서 이어가세요. 그러면
ChatGPT가 같은 컨텍스트를 바탕으로 다음 단계를 선택하고 작업의
완료 여부를 판단할 수 있습니다.

ChatGPT 데스크톱 앱에서 `/goal`을 입력해 목표 모드를 시작하세요. ChatGPT가 작업하는 동안 진행 상태 표시줄에서
목표를 일시 중지하거나 재개하고, 편집하거나 지울 수 있습니다.

ChatGPT 웹에서 호스팅되는 장시간 작업을 진행하려면 ChatGPT Work를 사용하고
결과, 제약 조건, 검토 기준을 프롬프트에 직접 입력하세요.

같은 웹 채팅에서 계속 진행하며 컨텍스트를 추가하거나 제약 조건을 변경하고,
상태 업데이트를 요청하세요. 서로 독립적인 작업을 병렬로 실행할 수 있다면 별도의
채팅을 사용하고, 같은 연결 소스에 대한 쓰기 권한을 두 작업에 모두 부여하지 마세요.
관련 작업의 채팅과 소스 파일은 하나의
[프로젝트](/ko-KR/codex/projects)에 함께 보관하세요.

대화형 Codex CLI 세션에서 `/goal`을 입력해 목표 모드를 시작하세요. 같은 세션을
계속 사용해 작업 방향을 조정하거나 상태 업데이트를 요청하세요.

IDE 확장 채팅에서 `/goal`을 입력해 현재 열려 있는 워크스페이스에서 목표 모드를 시작하세요.
작업이 실행되는 동안 같은 채팅에서 작업 방향을 조정하세요.

## 목표 시작하기

ChatGPT 데스크톱 앱, Codex CLI 또는 IDE 확장에서 `/goal`을 입력하세요.
목표 텍스트는 작업의 첫 번째 프롬프트이자
완료 기준이 됩니다.

원하는 결과가 아직 명확하지 않다면 `/plan`으로 시작하세요. ChatGPT가 질문을 통해 요구 사항을 파악하고,
제약 조건을 식별한 뒤 그 결과를 측정 가능한 성공 기준이 포함된 목표로
정리하도록 요청하세요. 그런 다음 다듬은 목표를 `/goal`로 시작하세요.

## 완료 기준 정의하기

ChatGPT가 스스로 진행 상황을 확인할 수 있도록 목표를 작성하세요. 해당하는 경우
다음 세 가지를 포함하세요:

| 목표 요소     | 포함할 내용                                                               |
| ---------------- | ----------------------------------------------------------------------------- |
| **결과**      | ChatGPT가 수행해야 하는 작업만 설명하지 말고, 원하는 결과를 설명하세요.   |
| **제약 조건**  | 필요한 도구, 작업 범위, 호환성 요구 사항, 피해야 할 접근 방식을 명시하세요. |
| **검증** | 작업이 완료되었음을 입증할 테스트, 측정 항목 또는 검토 기준을 추가하세요.  |

예:

```text
Migrate this codebase from JavaScript to TypeScript. Preserve existing behavior,
compile in strict mode without explicit `any` types, and make the full test suite pass.

## 실행 중인 목표 조정하기

ChatGPT 데스크톱 앱에서는 목표 진행 상태 표시줄이 메시지 입력창 위에 표시됩니다. 이 표시줄에서
작업을 일시 중지하거나 재개하고, 목표를 편집하거나 지울 수 있습니다. 목표가 실행되는 동안
후속 메시지를 보내 컨텍스트를 추가하거나 제약 조건을 조정할 수도 있습니다.

메인 채팅을 중단하지 않고 상태 요약이나 설명을 확인하려면 사이드 채팅을
사용하세요. 연결이 끊길 것으로 예상되면 미리 목표를 일시 중지하고,
ChatGPT가 작업을 계속해도 되는 시점에 재개하세요.

## 실행 중인 작업 조정하기

같은 채팅에서 계속 진행하며 컨텍스트를 추가하거나 제약 조건을 조정하고
상태 요약을 요청하세요. 다른 작업을 독립적으로 실행할 수 있다면 별도의 채팅을
시작하세요.

## 실행 중인 목표 조정하기

같은 대화형 세션에서 후속 메시지를 보내 컨텍스트를 추가하거나
제약 조건을 조정하세요. Codex가 계속 진행하기 전에 진행 상황을 요약하도록 하려면
상태 요약을 요청하세요.

## 실행 중인 목표 조정하기

같은 IDE 채팅에서 계속 진행하며 컨텍스트를 추가하거나 제약 조건을 조정하고
상태 요약을 요청하세요. 목표가 실행되는 동안 워크스페이스를 사용할 수 있는 상태로 유지하세요.

목표를 시작해도 ChatGPT에 더 넓은 접근 권한이 부여되지는 않습니다. 기존
[샌드박스 및 승인 정책](/ko-KR/codex/sandboxing)이 그대로 적용되며, 결정이 필요하면
작업이 일시 중지됩니다. [자동 승인
검토](/ko-KR/codex/sandboxing/auto-review)를 사용하면 해당 범위를 확대하지 않고도 별도의 검토자가
요건에 맞는 요청을 평가할 수 있습니다.

## 목표를 병렬로 실행하기

각 채팅은 고유한 컨텍스트, 메시지, 결과, 목표를 유지합니다. 채팅을
동시에 실행할 수 있지만, 두 채팅에서 같은 파일을 변경하지 않도록 하세요.
[작업 트리](/ko-KR/codex/environments/git-worktrees)를 사용해 병렬 코딩 채팅마다 별도의
체크아웃을 제공하세요.

로컬 작업 시 설정의 **실행 중 잠자기 방지** 옵션을 켜 Mac이
잠자기 상태로 전환되지 않도록 하세요. [펫](/ko-KR/codex/pets?surface=app)이나 [시스템
알림](/ko-KR/codex/notifications?surface=app)을 사용해 채팅에 입력이 필요한 시점이나
검토 가능한 상태가 된 시점을 확인하세요.
