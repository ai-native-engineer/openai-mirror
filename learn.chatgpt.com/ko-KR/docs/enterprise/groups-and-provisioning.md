그룹을 사용하면 ChatGPT 워크스페이스의 구성원을 체계적으로 관리하고 그룹에 사용자 지정 역할을 부여할 수 있습니다. 그룹 멤버십은 시트 할당을 대체하지 않으며, 그 자체로 워크스페이스 기능에 대한 권한을 부여하거나 로컬 런타임 정책보다 우선하거나 Platform API 또는 연결된 시스템에 대한 접근 권한을 제공하지 않습니다.

전체 제어 모델은
[역할 및 워크스페이스 권한](/ko-KR/codex/enterprise/roles-and-workspace-permissions)에서 확인하세요.

## 멤버십 소스 비교하기

파일럿 참여자나 워크스페이스 운영자, 지원되는 동일한 기능을 사용해야 하는 구성원처럼 필요한 접근 권한이 같은 사람들을 그룹으로 관리하세요.

### 공통된 접근 권한이 필요한 구성원을 위한 그룹 만들기

워크스페이스 소유자와 관리자는 그룹을 만들고 관리할 수 있습니다. 소규모이거나 임시로 운영할 그룹은 수동 관리 방식으로 만들고, 멤버십을 디렉터리에 맞춰야 하는 경우에는 ID 공급자의 기존 그룹을 동기화하세요.

각 그룹에는 멤버십 관리의 기준이 되는 소스가 하나씩 있습니다:

| 그룹 유형                | 멤버십 소스                   | 적용 조건                                                                  |
| ------------------------- | ----------------------------------- | -------------------------------------------------------------------------------- |
| 수동 관리          | ChatGPT 워크스페이스 관리    | 그룹 규모가 작거나 임시로 운영되거나 디렉터리 동기화로 관리되지 않는 경우             |
| ID 공급자 관리 | SCIM을 통해 연동된 ID 공급자 | 멤버십이 조직의 디렉터리와 구성원 제거 절차를 따라야 하는 경우 |

수동 관리 그룹과 ID 공급자가 관리하는 그룹을 함께 사용할 수 있습니다. 동기화된 그룹의 멤버십 소스는 ID 공급자이며, 이후 프로비저닝 업데이트로 워크스페이스에서 변경한 내용이 덮어써질 수 있습니다. 현재 SCIM 동작, 지원되는 속성, 설정 절차는 도움말 센터의 안내를 기준으로 합니다.

## 접근 권한의 범위 이해하기

그룹에 속해 있다는 사실만으로는 워크스페이스 기능을 사용할 권한이 부여되지 않습니다.

### 그룹에 적절한 권한 연결하기

워크스페이스 소유자는 그룹에 사용자 지정 역할을 할당하거나, 지원되는 경우
구성원에게 직접 할당할 수 있습니다. 적용되는 모든 역할을 확인하세요. 어느 역할에든 명시적인 **꺼짐** 설정이 있으면
다른 역할에서 허용하더라도 해당 권한이 거부됩니다. 구성원의 시트 유형과
제품 이용 자격도 여전히 적용됩니다.

SCIM은 워크스페이스 멤버십과 그룹 할당을 프로비저닝합니다. GitHub, Google Drive, Slack 또는 연결된 다른 시스템의 권한을 부여하지는 않습니다. 또한 로컬 런타임 요구 사항이나 Platform API 조직 접근 권한을 대체하지 않습니다.

워크스페이스 RBAC와 로컬 런타임 요구 사항은 서로 다른 제어 시스템입니다.
하나의 그룹이 두 시스템 모두와 관련될 수 있지만, 워크스페이스 그룹 순서만으로
관리형 요구 사항의 매칭 규칙이나 우선순위 규칙을 추론해서는 안 됩니다.
[관리형 구성](/ko-KR/codex/enterprise/managed-configuration)에서 문서에 명시된 전달 방식과
로컬 우선순위 규칙을 확인하세요.

## 최신 설정 절차 따르기

워크스페이스 관리에 관한 세부 사항은 변경될 수 있습니다. 최신 UI 절차와 이용 가능 여부, 제한 사항은 다음 자료에서 확인하세요:

- [구성원, 시트 유형, 역할 및 접근 권한 관리](https://help.openai.com/en/articles/8266401-managing-members-seat-types-roles-and-access-in-chatgpt-enterprise)
- [그룹 관리](https://help.openai.com/en/articles/9083985-group-permissions-in-gpts)
- [SCIM 연동 관련 자주 묻는 질문](https://help.openai.com/en/articles/10011769-openai-platform-scim-integration-faq)
- [워크스페이스 설정 관리](https://help.openai.com/en/articles/8411955)

### 신규 가입자, 소속 변경자, 탈퇴자 확인하기

- **신규 가입자:** 구성원이 대기 중인 워크스페이스 초대를 수락하고
  지정된 시트, 그룹 멤버십, 권한 및 지원되는 기능을
  제공받았는지 확인하세요.
- **소속 변경자:** 멤버십 관리의 기준이 되는 소스를 업데이트하고
  적용되는 모든 역할을 고려해 구성원의 실질적인 권한을 확인하세요.
- **탈퇴자:** ID 공급자를 통해 SCIM으로 관리되는 구성원의 접근 권한을 제거하고
  해당 구성원이 더 이상 워크스페이스에 접근할 수 없는지 확인하세요.
  워크스페이스에서만 구성원을 제거하면 이후 동기화로 접근 권한이
  복원될 수 있습니다.
