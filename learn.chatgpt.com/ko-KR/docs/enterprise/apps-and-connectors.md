플러그인은 재사용 가능한 워크플로우를 하나로 묶어 제공하며, 스킬과 다른 도구에 연결되는
앱을 포함할 수 있습니다. ChatGPT와 Codex는 지원되는 환경에서
동일한 공개 플러그인 디렉터리를 사용하며, 관리자는 워크스페이스에서 사용할 수 있는 플러그인을 결정합니다.
[플러그인](/ko-KR/codex/plugins),
[스킬](/ko-KR/codex/skills-and-plugins),
[앱과 커넥터](https://help.openai.com/en/articles/11487775)에 대해 자세히 알아보세요.

구성원은 자신의 역할에 플러그인과 앱 사용이 허용되고
연결된 서비스에도 접근할 수 있는 경우에만 커넥터 기반 기능을 사용할 수 있습니다.

웹, 데스크톱, 모바일에서 제공되는 ChatGPT의 채팅과 Work,
ChatGPT 데스크톱 앱의 Codex, Codex CLI 플러그인 브라우저에서 플러그인을 사용할 수 있습니다.
IDE 확장에서는 사용할 수 없습니다.

이러한 제어 기능과 워크스페이스 역할 및 권한의 관계는
[역할 및 워크스페이스 권한](/ko-KR/codex/enterprise/roles-and-workspace-permissions)을 참조하세요.

## 기능 제어 체계 이해하기

플러그인에는 다음과 같은 제어 계층이 적용될 수 있습니다:

| 계층                   | 결정 사항                                                           | 관리 위치                                                                                                              |
| ----------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 사용 가능 여부            | 사용자의 플러그인 번들 사용 가능 여부                           | 지원되는 웹 및 데스크톱 환경에서는 [워크스페이스 설정](https://chatgpt.com/admin/settings), CLI에서는 CLI 플러그인 브라우저 |
| 포함된 스킬         | 설치된 플러그인이 제공하는 재사용 가능한 지침                 | 플러그인 패키지 및 [스킬 제어](/ko-KR/codex/enterprise/skills)                                                               |
| App 접근 권한              | 사용자의 커넥터 기반 기능 사용 가능 여부                          | [워크스페이스 앱](https://chatgpt.com/admin/ca)과 [권한 및 역할](https://chatgpt.com/admin/settings)                    |
| 작업 및 권한 | 사용자가 실행할 수 있는 작업과 ChatGPT가 커넥터 사용 전에 확인을 요청하는 조건 | [워크스페이스 앱](https://chatgpt.com/admin/ca)의 커넥터별 작업 제어 및 App 권한                            |
| 서비스 권한 부여   | 인증된 주체가 접근할 수 있는 외부 데이터와 작업        | 연결된 서비스 및 해당 ID 공급자                                                                                 |
| 런타임 권한     | 에이전트가 데이터나 도구를 제공받은 후 수행할 수 있는 작업                        | 현재 사용 중인 환경의 런타임, 샌드박스 및 승인 제어                                                              |

이러한 계층을 바탕으로 두 단계에 걸쳐 도입하세요. 먼저 적절한 플러그인을 사용할 수 있도록 설정한 다음,
각 워크플로우에 필요한 기능과 권한을 구성하세요.

## 1단계: 플러그인 사용 설정

지원되는 웹 및 데스크톱 환경에서는 워크스페이스의 플러그인 제어로
플러그인을 사용하거나 설치할 수 있는 역할을 결정합니다. Codex CLI에서는 자체 플러그인
브라우저를 사용하여 설치합니다. 패키징 및 배포 방법은
[플러그인 빌드](https://developers.openai.com/plugins/build/plugins)에서
확인하세요.

GitHub에서 워크스페이스 플러그인을 가져오고 최신 상태로 유지하는 방법은
[플러그인 관리](/ko-KR/codex/enterprise/plugin-management)를 참조하세요.

### 검토를 위한 공개 카탈로그 내보내기

자격 요건을 충족하는 ChatGPT Enterprise 워크스페이스 소유자와 관리자는
워크스페이스에서 사용할 수 있는 공개 플러그인 목록을 CSV로 다운로드할 수 있습니다. 플러그인 사용 설정을 변경하기 전에
내보낸 파일에서 플러그인, 앱, 스킬 메타데이터를 검토하세요.

1. [관리자 \> 플러그인](https://chatgpt.com/admin/plugins)을 여세요.
2. **공개를** 선택하세요.
3. 페이지 헤더에서 다운로드 아이콘(**CSV 내보내기**)을 선택하세요.

다운로드되는 파일의 이름은 `public-plugins-security-review.csv`이며, 다음 정보가 포함됩니다:

- 플러그인 메타데이터: `Plugin Name`, `Plugin Description`, `Date Added (UTC)`,
`OpenAI Verified`, `Developer Name` 및 `Version`.
- App 메타데이터: `App Name(s)` 및 `App Description(s)`.
- 채팅 스킬 메타데이터: `Skill Name(s)` 및 `Skill Description(s)`.

플러그인에 앱이나 스킬이 두 개 이상 포함되면 해당 값은 세미콜론으로 구분됩니다.
내보내기에는 최대 48시간 전의 공개 카탈로그 스냅샷이 사용됩니다.
현재 워크스페이스에 표시되는 공개 플러그인만 포함되며, 해당 워크스페이스용으로 생성된 플러그인은 포함되지 않습니다.
FedRAMP 워크스페이스에서는 내보내기를 사용할 수 없습니다.

## 2단계: 기능 관리

  ChatGPT에서 앱이나 플러그인을 사용할 수 있도록 설정해도 연결된 서비스의 파일,
레코드 또는 작업에 대한 접근 권한이 부여되지는 않습니다. 문제를 해결하거나
접근 권한을 확대하기 전에 구성원의 워크스페이스 역할과 승인된 작업 설정을
확인하세요. 그런 다음 인증된 계정이나 공유 연결에 연결된 서비스의 권한이
예상대로 부여되어 있는지 확인하세요.

ChatGPT와 Codex의 플러그인에는 외부 시스템에서 데이터를 검색, 조회, 동기화하거나
작업을 수행하는 커넥터가 포함될 수 있습니다. 플러그인 사용 가능 여부는 각 커넥터에 부여하는 접근 권한 및 허용하는 작업과
별도로 제어합니다.

커넥터 기반 기능은
[워크스페이스 앱](https://chatgpt.com/admin/ca)과
[권한 및 역할](https://chatgpt.com/admin/settings)에서 관리하세요. 관리자는 제공되는 제어 기능을 통해
다음 작업을 수행할 수 있습니다:

- 앱이나 커넥터를 활성화하고 워크스페이스 역할별로 접근 권한을 할당합니다.
- 작업 제어를 지원하는 커넥터에서는 읽기 전용 작업이나 승인된 사용자 지정 작업 세트를
허용하고, 새로 추가되는 작업을 워크스페이스에서 처리하는 방식도 설정합니다.
- App 권한을 설정하여 ChatGPT가 앱 사용 전에 언제 확인을 요청할지 결정합니다.
- 각 연결된 서비스와 인증된 사용자가 부여한 범위 및 권한 내에서만
접근하도록 제한합니다.

현재 사용 가능 여부와 절차는
[앱의 관리자 제어, 보안 및 컴플라이언스](https://help.openai.com/en/articles/11509118)를 참조하세요.

## 초기에 도입할 핵심 플러그인 선정

명확한 업무상 필요를 충족하는 플러그인부터 시작하세요. 각 플러그인을 모든 구성원에게
허용할지, 특정 역할이나 시범 운영 그룹으로 제한할지, 추가 검토를 거칠지
결정하세요.

연결된 서비스마다 업무 책임자, 허용된 데이터, 승인된 읽기 또는 쓰기 작업,
인증 방법, 지원 또는 제거 문의처를 기록하세요.

쓰기 작업을 활성화하거나 새로운 연동 기능을 게시하기 전에 해당 기능을 사용할 수 있는 역할 범위를
확인하고, 연결된 서비스에서 의도한 권한만 보유한 계정으로
테스트하세요.

폭넓게 도입하려면 이메일,
캘린더, 파일 또는 문서 시스템처럼 팀이 매일 사용하는 범주부터 시작하세요.
[플러그인 디렉터리](https://chatgpt.com/apps)에서 지원되는 ChatGPT 및 Codex 환경별로
현재 사용 가능 여부와 기능을 확인하세요.

초기 도입 대상이 무엇이든 읽기 작업부터 시작하세요. 쓰기 작업을 활성화하기 전에
플러그인 소유자를 파악하고, 커넥터의 범위와 서비스 권한을 검토하며,
데이터 접근 권한을 확인하고, 외부에 미치는 영향과 복구 방안을
문서화하세요.

## 데이터 플로우와 보안 이해하기

ChatGPT가 플러그인에 포함된 앱이나 커넥터를 사용하면 연결된 서비스에 요청을 보내고,
해당 서비스에서 인증된 사용자의 권한 범위 내에서 데이터나 작업 결과를
반환합니다.

ChatGPT는 연결된 앱의 데이터를 다음 두 가지 방식으로 처리합니다:

- **동기화하지 않음:** ChatGPT는 채팅과 심층 리서치의 데이터를 일시적으로 처리하며
  색인을 생성하지 않습니다.
- **동기화:** ChatGPT는 연결된 콘텐츠 중 선택한 항목의 색인을 미리 생성합니다. 앱의 동기화 지원 여부는
  해당 플러그인 페이지에서 확인할 수 있습니다.

이 모드는 ChatGPT가 연결된 콘텐츠의 색인을 생성하는 방식을 변경하며,
일반적인 채팅 보존 설정을 대체하지 않습니다. 앱을 사용하는 ChatGPT 대화는
Compliance API를 통해 계속 조회할 수 있습니다.

OpenAI의 앱 안내 문서는 전송 중 및 저장 시 암호화, 사용자별 권한 부여, 역할 및 작업 제어, 앱을 사용하는 대화에 적용되는 네트워크 액세스 제한을 설명합니다. 또한 Business, Enterprise, Edu 고객의 경우 앱을 통해 액세스한 정보를 모델 학습에 사용하지 않는다고 명시합니다. 요청이 연결된 서비스에 도달하면 해당 서비스의 권한 범위, 데이터 보존, 데이터 레지던시 및 기타 정책도 적용됩니다.

데이터 처리에 관한 최신 정보는 [앱 보안 및 컴플라이언스](https://help.openai.com/en/articles/11509118)와
[동기화 지원 앱](https://help.openai.com/en/articles/10847137)을
참고하세요. ChatGPT 데스크톱 앱, Codex CLI 또는 IDE 확장에서
로컬로 구성한 MCP 서버에 대해서는
[Codex MCP 구성](/ko-KR/codex/extend/mcp)을 참고하세요.
