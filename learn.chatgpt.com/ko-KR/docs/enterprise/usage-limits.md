ChatGPT 워크스페이스의 사용 한도와 지출 관리 기능은 워크스페이스 플랜에서 정한 대상 활동에 적용됩니다. 플랜에 따라 일부 Codex 활동도 대상에 포함될 수 있습니다. 이러한 관리 기능은 Codex 전반에 적용되는 공통 한도 체계가 아니며, OpenAI API 플랫폼의 요금 청구를 관리하지 않습니다.

전체 관리 체계에 대해서는
[역할 및 워크스페이스 권한](/ko-KR/codex/enterprise/roles-and-workspace-permissions)을 참조하세요.

## 관리 기능이 적용되는 경우

다음과 같은 경우 ChatGPT 워크스페이스의 사용량 관리 기능을 검토하세요:

- 조직의 계약에 따라 ChatGPT 워크스페이스의 공유 크레딧이나 구매한 크레딧을 사용하는 경우.
- 적용 대상 Codex 활동으로 해당 크레딧이 소모될 수 있는 경우.
- 관리자에게 현재 플랜에서 지원하는 사용자별 보호 장치, 워크스페이스 수준의 지출 관리 기능 또는 사용량 알림이 필요한 경우.

사용량 관리 기능은 기능 이용 자격이나 권한을 설정하지 않습니다. 다만 한도가 소진되면 적용 대상 기능에 대한 접근이 일시 중지될 수 있습니다. 소스 시스템의 권한에 영향을 주지 않으며, 플랫폼 API의 사용이나 요금 청구도 관리하지 않습니다.
