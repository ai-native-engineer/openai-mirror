## 공유

GPT를 만들 수 있는 사용자를 지정하고 특정 사용자, 그룹 또는 워크스페이스 전체에 GPT를 공유할 수 있는지를 설정하세요.

  GPT 제작자는 연결된 앱 또는 맞춤 액션 중 하나를 사용할 수 있지만, 하나의 GPT에서 두 가지를 함께 사용할 수는 없습니다.

## 연결된 앱 및 액션

GPT 제작자가 승인된 워크스페이스 앱을 사용하거나 허용된 타사 API와 상호작용하는 액션을 구성할 수 있도록 허용하세요. 접근에는 워크스페이스 정책, 사용자 권한 및 승인된 도메인 제한이 계속 적용됩니다.

## 도메인

워크스페이스에서 만든 GPT가 접근할 수 있는 타사 API를 제어하려면 GPT 액션을 승인된 외부 도메인으로 제한하세요. 허용된 도메인이 없으면 GPT의 맞춤 액션을 실행할 수 없습니다.

  도메인 승인이 API 인증이나 사용자 권한 부여를 대신하지는 않습니다.

## GPT 관리

워크스페이스에서 만든 GPT를 검토하고, 공유 및 소유권을 관리하며, 필요한 경우 GPT를 삭제하세요. 관리 화면에서는 소유자 지정 여부에 따라 GPT를 분류하며 다음 정보를 표시합니다.

- 이름
- 제작자
- 맞춤 액션
- 접근 가능한 사용자
- 채팅
- 생성일
- 업데이트일
