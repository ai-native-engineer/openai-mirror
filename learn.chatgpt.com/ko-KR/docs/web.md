질문하거나 주제를 조사하거나 여러 단계의 작업을 설명하세요. ChatGPT는 파일과 연결된 도구를 활용해 문서, 프레젠테이션, 스프레드시트와 기타 결과물을 만들 수 있습니다.

파일과 도구 활용하기

파일, 프로젝트, 플러그인을 활용해 작업에 필요한 정보와 도구를 ChatGPT에 제공하세요.

Work 선택 상태로 프롬프트 Composer와 연결 가능한 플러그인이 표시되고 사이드바에 프로젝트가 있는 웹용 ChatGPT 화면

웹에서 할 수 있는 작업 알아보기

빠른 답변에는 채팅 모드를 사용하고, 파일, 플러그인, 추론 설정을 활용하는 여러 단계의 작업에는 Work 모드를 사용하세요.

자세히 알아보기

채팅 모드 또는 Work 모드 선택하기

질문을 살펴보거나 아이디어를 구체화할 때는 채팅 모드를 사용하세요. 원하는 결과가 명확하고 ChatGPT가 계획을 세우고 컨텍스트를 수집해 더 큰 작업을 검토 가능한 결과물로 완성하도록 하려면 Work 모드로 전환하세요.

채팅 모드와 Work 모드가 표시된 웹용 ChatGPT 화면

알맞은 모델과 추론 수준 선택하기

Composer에서 모델과 추론 수준을 선택하세요. 기본 설정으로 시작한 뒤, 작업에 더 심층적인 계획이나 분석 또는 더 큰 규모의 멀티 에이전트 실행이 필요할 때 추론 수준을 높이세요.

모델 및 추론 제어 옵션이 있는 ChatGPT Work Composer

도구와 반복 가능한 워크플로우 활용하기

플러그인을 설치해 Google Drive, GitHub, Slack 등의 서비스에 연결하세요. ChatGPT가 특정 워크플로우를 따르거나 팀 지침을 활용하거나 일관된 방식으로 결과물을 만들어야 할 때는 스킬을 추가하세요.

채팅 및 프로젝트와 함께 플러그인 항목이 표시된 ChatGPT 사이드바

완성된 파일 만들고 다듬기

ChatGPT Work를 사용해 원본 자료로 문서, 프레젠테이션, 스프레드시트 또는 PDF를 만드세요. 채팅에서 결과를 검토하고 필요한 부분만 수정하도록 요청한 다음, 완성된 파일이 준비되면 다운로드하세요.

개요, 출처, 검토 항목이 포함된 ChatGPT Work를 사용해 만든 프레젠테이션

웹에서 ChatGPT를 사용하면 좋은 경우…

여러 단계의 작업을 완료해야 할 때

ChatGPT Work를 사용하면 작업을 계획하고 컨텍스트를 수집하며, 여러 단계를 차례로 진행해 명확한 결과를 도출할 수 있습니다.

작업에 더 심층적인 추론이 필요할 때

복잡한 계획과 분석이 필요하면 더 강력한 모델을 선택하거나 추론 수준을 높이세요.

작업에 사용 중인 도구와 컨텍스트가 필요할 때

플러그인과 스킬을 사용해 연결된 소스에서 정보를 가져오고, 필요한 작업을 실행하고, 반복 가능한 워크플로우를 따르세요.

검토하고 공유할 수 있는 파일이 필요할 때

원본 자료를 문서, 프레젠테이션, 스프레드시트 또는 PDF로 만든 다음 피드백을 반영해 다듬으세요.

작업을 먼저 설명한 다음 컨텍스트 추가하기

원하는 결과를 설명하고 모델과 추론 수준을 선택한 다음, ChatGPT가 초기 계획을 세우는 데 사용할 도구를 연결하세요.
