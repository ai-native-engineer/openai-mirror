펫은 작업 진행 상황을 확인할 때 선택적으로 사용할 수 있는 애니메이션 동반자입니다. 펫이 나타나는 위치와
표시하는 내용은 사용하는 인터페이스에 따라 다릅니다. 펫을 선택해도 ChatGPT의 작업 수행 방식은 바뀌지 않고
외형만 달라집니다.

## 플로팅 펫 사용하기

ChatGPT 데스크톱 앱에서는 펫을 다른 앱 창 위에 띄워
여러 채팅의 활동을 확인할 수 있습니다.

### 펫 선택하고 깨우기

1. 앱 하단의 프로필 메뉴를 열고 **펫** 항목을 선택하세요. 또는
   [**설정**](codex://settings)을 열어 **펫** 항목으로 이동할 수도 있습니다.
2. 기본 제공 펫이나 맞춤형 펫을 선택하세요.
3. `/pet`을 입력하거나 명령어 메뉴를 열고 **펫 깨우기** 항목을 선택하세요.

펫을 숨기려면 **설정 \> 펫** 화면이나 명령어 메뉴에서 **펫 숨기기** 항목을 선택하거나
`/pet`을 다시 입력하세요.
선택한 펫과 펫의 위치는 앱을 다시 열어도 유지됩니다.

맞춤형 펫을 선택하면 **프로필** 화면에도 해당 펫이 표시됩니다.

### 펫 상태 알아보기

| 상태          | 의미                                                  |
| --------------- | -------------------------------------------------------- |
| **실행 중**     | 채팅에서 작업이 진행 중입니다.                              |
| **입력 필요** | 채팅에 사용자의 승인, 답변 또는 다른 결정이 필요합니다. |
| **준비됨**       | 채팅 작업이 완료되었으며 읽지 않은 활동이 있습니다.            |
| **차단됨**     | 채팅 작업이 실패했거나 시스템 오류가 발생했습니다.             |

둘 이상의 채팅에서 활동이 발생하면 펫은 입력 필요, 차단됨, 준비됨,
실행 중 순으로 채팅을 우선 표시합니다. 활동 트레이를 열어
채팅을 선택하세요.

펫을 선택하면 ChatGPT로 돌아가고, 활동을 선택하면 해당 채팅이 열립니다.
활동 트레이는 [시스템
알림](/ko-KR/codex/notifications?surface=app)과 별개입니다.

### 컴퓨터 사용 진행 상황 확인하기

macOS에서는 [컴퓨터 사용](/ko-KR/codex/computer-use) 화면 속 화면 창을
깨어 있는 펫에 붙일 수 있습니다. 펫을 움직이면 창도 따라 움직입니다.

### 맞춤형 펫 만들기

1. **설정 \> 펫** 화면을 열고 **나만의 펫 만들기** 항목을 선택하세요.
2. 앱은 함께 제공되는 `hatch-pet` 스킬을 설치하고 스킬을 다시 로드한 다음
   새 채팅을 엽니다.
3. 원하는 펫을 설명한 뒤 프롬프트를 보내세요.
4. 작업이 완료되면 **설정 \> 펫** 화면으로 돌아가 **새로 고침** 항목을 선택한 다음
   새 펫을 선택하세요.

데스크톱 앱에서 만든 맞춤형 펫은 컴퓨터에 로컬로 저장됩니다.
ChatGPT 웹과 자동으로 동기화되지는 않습니다.

### 애니메이션 줄이기

펫은 운영 체제의 동작 줄이기 설정을 따릅니다. 동작 줄이기를
사용하면 펫에 스프라이트 애니메이션 대신 정지 프레임이 표시됩니다.

## 웹에서 펫 선택하기

계정과 워크스페이스에서 펫을 사용할 수 있다면 **설정 \>
개인 맞춤 설정 \> 펫 \> 펫 선택** 화면을 여세요. 기본 제공 펫을 선택하거나
펫 없이 ChatGPT를 사용하려면 **기본값** 항목을 선택하세요.

웹 펫은 지원되는 ChatGPT Work 채팅에 표시됩니다. 데스크톱 앱의
플로팅 오버레이, 활동 트레이, `/pet` 명령어는 제공하지 않습니다.

### 맞춤형 펫 업로드하기

**펫 업로드** 항목을 선택해 맞춤형 스프라이트 시트를 추가하세요. 파일은
정확히 1536 × 1872픽셀인 투명 PNG 또는 WebP 형식이어야 하며 크기는 20 MiB 이하여야 합니다.
같은 설정 화면에서 업로드한 펫을 편집, 다운로드, 새로 고침 또는 삭제할 수 있습니다.

## 터미널 펫 선택하기

대화형 Codex CLI 세션에서 다음을 수행하세요:

- `/pets` 또는 `/pet`을 입력하여 펫 선택기를 여세요.
- `/pets <name>`을 입력하여 펫을 바로 선택하세요.
- `/pets off`을 입력하여 터미널 펫을 비활성화하세요.

선택기에는 기본 제공 펫과 컴퓨터에 설치된 호환되는 맞춤형 펫이
표시됩니다. 터미널 펫은 현재 CLI 세션의 활동을 보여 주며
**실행 중**, **입력 필요**, **준비됨**, **차단됨** 상태를 사용합니다. 다만
데스크톱 앱의 여러 채팅용 활동 트레이는 제공하지 않습니다.

터미널 펫을 사용하려면 iTerm2 3.6 이상 또는 Kitty 그래픽이나
Sixel을 지원하는 터미널이 필요합니다. tmux와 Zellij에서는 사용할 수 없습니다.

## IDE 확장의 펫

Codex IDE 확장은 펫 선택기나 플로팅 펫 오버레이를 제공하지 않습니다.
나만의 펫을 사용하려면 ChatGPT 데스크톱 앱이나 Codex CLI를 사용하세요.
