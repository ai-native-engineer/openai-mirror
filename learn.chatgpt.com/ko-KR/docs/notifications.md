알림은 작업을 확인해야 하는 시점을 알려 줍니다. 알림의 제어 옵션과
전달 채널은 사용 환경에 따라 다릅니다.

## 데스크톱 알림 구성

[**설정**](codex://settings)을 열어 턴 완료 알림을 표시하지 않을지,
ChatGPT가 백그라운드에 있을 때만 표시할지, 항상 표시할지 선택하세요.
별도의 제어 옵션으로 권한 요청 및 질문 알림을 켜거나 끌 수 있습니다.
운영 체제에서 ChatGPT 데스크톱 앱에 알림 권한을 부여하라는
메시지가 표시될 수 있습니다.

### 활동 보기에서 채팅 확인

**활동** 기능을 사용할 수 있으면 사이드바에서 종 아이콘을 선택해
읽지 않은 채팅, 실행 중인 채팅 또는 응답을 기다리는 채팅을 확인할 수 있습니다.
macOS에서는 <kbd>Cmd</kbd>+<kbd>Option</kbd>+<kbd>U</kbd>로, Windows에서는
<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>U</kbd>로 활동 보기를 열거나 닫을 수도 있습니다.

보기의 옵션을 사용해 표시할 채팅을 선택하세요. 사용 중인 환경에 따라
옵션에는 **Work**, **채팅**, **고정됨**, **예약됨** 등이 포함될 수 있습니다.
읽지 않은 항목을 지우려면 **모두 읽음으로 표시** 옵션을 선택할 수도 있습니다.

<a id="follow-task-activity-with-a-pet"></a>

### 펫으로 채팅 활동 확인

ChatGPT 데스크톱 앱에서는 다른 앱에서 작업하는 동안 화면에 떠 있는 펫으로
채팅 활동을 확인할 수도 있습니다. 채팅이 **실행 중**,
**입력 필요**, **준비됨**, **차단됨** 중 어떤 상태인지 표시할 수 있습니다.

펫 선택 방법, 상태의 의미, 나만의 펫을 만드는 방법은
[펫](/ko-KR/codex/pets?surface=app)에서 확인하세요.

## 웹 알림 구성

계정에서 사용할 수 있는 알림 카테고리와 채널을 관리하려면
**설정 \> 알림** 페이지를 여세요. 카테고리와 계정에 따라 사용 가능한
채널에는 푸시, 이메일 또는 SMS가 포함될 수 있습니다. 작업 알림 설정의
**작업 관리** 옵션을 사용해 **예약됨** 화면을 여세요.

## CLI 알림 구성

터미널 및 외부 알림에 관한 자세한 내용은 고급 구성 가이드의
[알림](/ko-KR/codex/config-file/config-advanced#notifications)에서 확인하세요.
TUI에서 알림을 보내는 시점과 턴이 완료될 때 Codex가 외부 프로그램을
실행할지 여부를 선택할 수 있습니다.

<a id="follow-task-activity-in-the-ide"></a>

## IDE에서 채팅 활동 확인

IDE 확장은 별도의 알림 제어 옵션을 제공하지 않습니다. 채팅 활동을
확인하려면 채팅을 열어 두세요. 턴이 완료될 때 외부 프로그램을
실행하려면 연결된 Codex 호스트에서 `notify`를 구성하세요. 자세한 내용은
고급 구성 가이드의 [알림](/ko-KR/codex/config-file/config-advanced#notifications)에서
확인하세요.
