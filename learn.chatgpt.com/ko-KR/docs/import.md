가져오기 플로우를 사용하면 다른 에이전트의 지침, 설정, 스킬, 플러그인, 프로젝트
및 최근 작업을 ChatGPT 데스크톱 앱이나 Codex CLI로 가져올 수 있습니다.
데스크톱 앱은 **Claude Code**, <strong>Claude Cowork</strong>,
 **Cursor** 가져오기를 지원합니다. Codex CLI는 **Claude Code** 또는 **Cursor** 가져오기를 지원합니다.

데스크톱 앱은 지원되는 항목을 직접 가져오며, 권한 부여가 필요한 플러그인이나
연결을 가져온 경우 설정을 완료할 수 있습니다. 자동 업데이트로 가져온 작업을
계속 동기화할 수도 있습니다.

가져오기를 실행해도 기존 에이전트 설정이 변경되거나 삭제되지 않습니다.

  

## 가져오기 시작하기

### 데스크톱 앱에서 가져오기

1. ChatGPT 데스크톱 앱에서 **설정 \> 가져오기** 메뉴를 여세요. **가져오기** 섹션이
   아직 설정에 표시되지 않으면 **일반** 메뉴를 열고 **다른 에이전트
   설정 가져오기** 항목을 찾으세요.
2. **가져오기를** 선택하세요.
3. 가져올 에이전트를 선택한 다음 **계속을** 선택하세요.
4. **가져올 항목 선택** 화면에서 가져올 항목을 고른 다음 **계속을** 선택하세요.
5. 가져오기가 완료되면 가져온 프로젝트나 채팅을 열어 작업을 계속하세요.

### 가져온 작업 동기화 유지하기

ChatGPT 데스크톱 앱에서 **설정 \> 가져오기** 메뉴를 열고 자동
업데이트를 켜서 가져온 작업을 원본 에이전트와 계속 동기화하세요.
같은 설정 섹션에서 가져오기 기록도 검토할 수 있습니다.

### Codex CLI에서 가져오기

1. 로컬 Codex CLI 세션을 시작하고 `/import`를 입력하세요.
2. **Claude Code** 또는 **Cursor** 중 하나를 선택하세요.
3. 지원되는 설정, 프로젝트 파일, 최근 채팅 중에서 가져올 항목을
선택하세요.
4. 가져온 구성을 검토하고 Codex에서 작업을 계속하세요.

Codex CLI는 최근 30일 동안의 채팅을 최대 50개까지 가져옵니다. `/import` 명령어는
작업 실행 중이거나 원격 세션에 있는 경우, 또는 로컬 app-server 데몬에
연결된 상태에서는 사용할 수 없습니다. 자세한 내용은 [CLI 슬래시
명령어](/codex/developer-commands?surface=cli#cli-import-claude-code-or-cursor-setup-with-import) 문서를 참조하세요.

  

## 가져오기 작동 방식

가져오기 플로우는 사용자 수준 설정과 기존 프로젝트를 모두 확인합니다.
사용자 수준 설정은 사용자 기기의 파일에서 가져오며, 프로젝트 수준 설정은
선택한 레포지토리와 폴더의 파일에서 가져옵니다.

가져오기를 실행하면 ChatGPT는 다음 작업을 수행합니다:

1. 지원되는 설정과 최근 작업을 감지합니다.
2. 선택한 항목을 가져옵니다.
3. 기존 에이전트 설정을 변경하지 않습니다.
4. 가져온 플러그인이나 연결에 추가 설정이 필요한지 확인합니다.
5. 설정을 완료해야 하는 경우 상태 카드를 표시합니다.

## 가져온 후 설정 완료하기

가져오기가 완료되면 앱의 왼쪽 하단에 상태 카드가 표시됩니다.
가져온 플러그인이나 연결에 추가 설정이 필요하면 해당 카드에 표시됩니다.

앱에서 확인이 필요한 항목을 표시하면 **완료를** 선택하고
안내에 따라 설정을 완료하세요.

## 가져온 후 검토할 항목

가져온 설정을 사용하기 전에 검토하고, 특히 다음 항목을 확인하세요:

- 가져온 스킬과 에이전트의 도구 제한 또는 권한.
- 사용자 지정 인증, 헤더, 환경 변수 또는 전송 방식을 사용하는
MCP 서버 설정. 다시 로그인해야 할 수 있습니다.
- 가져온 후 동작이 달라질 수 있는 훅.
- 직접 추가 조치가 필요한 플러그인, 마켓플레이스 또는 기타 설정.
- 인수, 셸
보간 또는 파일 경로 자리표시자에 의존하는 프롬프트 템플릿이나 명령어 형식의 프롬프트.

## 가져온 후

가져오기가 완료되면 가져온 프로젝트 중 하나를 열고
작업을 이어가세요. 다음 작업을 시작하는 방법은 [ChatGPT 사용하기](/ko-KR/codex/use-chatgpt)에서
확인하세요.
