시각화는 질문, 아이디어, 정보를 차트, 지도,
다이어그램, 계산기, 시뮬레이션, 그리고 ChatGPT 채팅에서 탐색할 수 있는 대화형 설명으로
전환합니다. 입력값을 조정하거나 관계를 살펴보는 것이 답변을 더 쉽게 이해하고 비교하거나,
내용을 연습하고 실제로 활용하는 데 도움이 될 때
시각화를 사용하세요.

  시각화 프리뷰가 순차적으로 출시되고 있습니다. 사용 가능 여부는 이용 중인
요금제, 플랫폼, 계정 및 워크스페이스 설정에 따라 달라질 수 있습니다.

ChatGPT 데스크톱 앱에서 시각화 프리뷰가 순차적으로 출시되고 있습니다.
**Visualize** 항목을 사용할 수 있으면 메시지 입력창에 `@`를 입력하고,
`Visualize`를 입력하기 시작한 다음 **플러그인에서** **Visualize를** 선택하세요. 그러면 요청 앞에
**Visualize** 태그가 추가됩니다.

**Visualize** 항목이 표시되지 않으면 웹용 ChatGPT를 사용하거나,
프리뷰가 계정에 제공된 후 다시 시도하세요.

지원되는 채팅 또는 ChatGPT Work 채팅의 메시지 입력창에 `@`를 입력하고,
`Visualize`를 입력하기 시작한 다음 **플러그인에서** **Visualize를** 선택하세요. 설명 문구는
**시각화 및 대화형 도구 만들기**입니다. 그러면 요청 앞에
**Visualize** 태그가 추가됩니다.

`@Visualize`를 입력하고 일치하는 제안을 선택할 수도 있습니다.

Codex CLI에서는 시각화를 렌더링하지 않습니다. 같은 원본 자료를
웹용 ChatGPT 또는 ChatGPT 데스크톱 앱에서 연 다음, 그곳에서 `@Visualize` 태그를 추가하세요.

Codex IDE 확장에서는 시각화를 렌더링하지 않습니다. 이 워크플로우는 웹용 ChatGPT
또는 ChatGPT 데스크톱 앱에서 진행하세요.

## 사용 가능 여부 확인

| 사용 환경                     | 현재 사용 가능 여부                                                          |
| --------------------------- | ----------------------------------------------------------------------------- |
| 웹용 ChatGPT          | 지원 대상 계정의 채팅 및 ChatGPT Work에서 사용 가능                      |
| ChatGPT 데스크톱 앱         | 프리뷰로 순차 출시 중                                                        |
| ChatGPT 모바일 앱         | 대상 계정에 순차 출시 중; 메시지 입력창의 컨트롤은 앱 버전에 따라 다를 수 있음 |
| Codex CLI 및 IDE 확장 | 시각화 렌더링은 지원되지 않음                                       |

**Visualize** 제안이 표시되는 것은 계정에서 프리뷰가 활성화되었다는 확실한 신호입니다.
출시 기간에는 같은 요금제를 사용하더라도 계정,
워크스페이스 및 앱 버전에 따라 사용 가능 여부가 다를 수 있습니다.

## 시각화 사용 시점 선택하기

ChatGPT는 답변의 질을 실질적으로 높일 수 있을 때 시각적 형식을 선택할 수 있습니다.
대화형 결과를 구체적으로 원할 때는 `@Visualize` 태그를 직접 추가할 수도 있습니다.

요구 사항을 충족하는 가장 간단한 형식을 요청하세요:

- 레이블이 지정된 관계 또는 프로세스에는 다이어그램을 사용하세요.
- 항목별 수치 데이터와 비교에는 차트나 플롯을 사용하세요.
- 지리 정보에는 지도를 사용하세요.
- 입력값, 시간, 움직임 또는 공간 관계를 변경해야 한다면 대화형 시각화를
사용하세요.
- 공유 가능한 URL, 권한 또는 영구 데이터를 갖추고 지속해서 사용할 수 있는 호스팅 애플리케이션이 필요하면
  [Site](/ko-KR/codex/sites)를 사용하세요.

효과적인 요청을 작성하려면 원하는 결과, 원본 자료, 질문, 유용한 상호작용을
명시하세요. 다음 예시를 사용해 보세요:

ChatGPT에 사용할 정보를 알려 주세요. 예를 들어 채팅의 기존 콘텐츠, 붙여 넣은 데이터,
첨부 파일 또는 사용 가능한 연결된 소스를 지정할 수 있습니다.
복잡한 요청에는 선택 가능한 경우 더 높은 추론 수준을 사용하세요.

## 수정하고 계속하기

같은 채팅에서 계속 진행하며 원하는 변경 사항을 설명하세요. 유용한
후속 요청의 예시는 다음과 같습니다:

- 컨트롤, 필터, 비교 또는 주석을 추가하거나 제거하세요.
- 원본 데이터, 단위, 레이블 또는 가정을 수정하세요.
- 데이터를 집계, 구간화 또는 샘플링하여 느린 결과를 단순화하세요.
- 간결한 텍스트 요약과 데이터 표를 추가하세요.
- 모든 컨트롤을 키보드로 사용할 수 있게 하고 포커스 상태가 눈에 띄게 표시되도록 하세요.
- 색상 외에도 레이블이나 패턴을 사용하고 반복되는 움직임을 제거하세요.
- 결과를 호스팅하고 나중에 다시 확인해야 한다면 Site로 전환하세요.

후속 요청으로 원래 결과를 그 자리에서 수정하는 대신 대체 시각화가
생성될 수 있습니다. 사용하기 전에 새 버전을 검토하세요.

## 결과 공유 또는 재사용

사용할 수 있다면 채팅의 기본 **공유** 기능을 사용하세요. 공유하기 전에
원본 데이터와 이전 메시지를 포함해 채팅 전체를 먼저 검토하세요.
시각화는 일반적으로 ChatGPT가 만들 당시 사용 가능했던 정보의
스냅샷이며, 연결된 소스와 계속 동기화되는
라이브 대시보드가 아닙니다.

생성된 다운로드 컨트롤과 내보내기 형식은 결과에 따라 다를 수 있습니다. 내보내기가
작동하지 않으면 ChatGPT에 바탕이 된 데이터를 더 간단한 형식으로 제공하거나 시각화를
Site로 전환해 달라고 요청하세요.

## 접근성 개선

생성된 시각화는 시맨틱 컨트롤, 명확한 포커스 표시, 읽기 쉬운 명암 대비,
움직임 최소화를 적용하는 것을 목표로 하지만 결과는 달라질 수 있습니다. 공유하기 전에 시각화를
확인하세요. ChatGPT에 텍스트 요약과 데이터 표를 추가하고, 축과 단위에 레이블을 지정하며,
색상에만 의존하지 않고 키보드로 컨트롤을 조작할 수 있게 해 달라고 요청하세요.

## 결과 생성 실패 시 복구하기

시각화를 생성하는 데 1분 이상 걸릴 수 있습니다. 결과가 비어 있거나
표시되지 않으면 응답 생성이 완료될 때까지 기다리고, 채팅을 한 번 새로고침한
다음 다시 시도하세요. 그래도 실패하면:

- 더 작거나 단순한 시각화를 요청하세요.
- 대규모 데이터 세트에서는 데이터를 집계 또는 구간화하거나, 샘플링할 데이터 포인트 수를 줄이거나, 정밀도를 낮추세요.
- 생성된 컨트롤이나 라이브러리 중 작동하지 않는 항목을 제거하세요.
- 중요한 값, 지리적 경계, 소스 데이터에 관한 가정을 검증하세요.
- 대신 차트, 다이어그램, 표 또는 Site를 요청하세요.

다른 ChatGPT 채팅에서와 같은 판단 기준으로 데이터를 처리하세요. 조직에서
허용하는 경우에만 민감한 정보를 포함하고, 공유하기 전에 전체 채팅을
검토하세요.
