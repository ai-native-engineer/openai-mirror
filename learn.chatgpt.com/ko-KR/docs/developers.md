# 개발자

개발 워크플로우, 환경, 확장 프로그램, 통합을 설정하세요

코드베이스, 개발 환경, 자동화, 팀에서 사용하는 도구와 Codex를 함께 활용하세요.

Codex는 로컬과 클라우드 환경 전반에서 일상적인 코드 작업과 더 긴밀한 통합을 지원합니다. Codex 개발 워크플로우에는 코드 검토, 통합 터미널, 재사용 가능한 스킬과 플러그인, SDK와 App Server를 활용한 자동화, 팀 도구, 각 인터페이스별 참조 자료가 포함됩니다.

엔지니어를 위한 Codex의 새로운 기능

워크플로우 살펴보기

웹 애플리케이션을 위한 Codex 출력, 통합 터미널 및 코드 검토

개발 워크플로우

ChatGPT에서 변경 사항을 검토하고 개발 도구를 사용하세요.

코드 검토

배포 전에 변경 사항을 검토하고 피드백을 반영하세요.

통합 터미널

ChatGPT 데스크톱 앱에서 명령어를 실행하고 출력을 확인하세요.

기능 확장 및 자동화

개발 워크플로우를 패키징하고 결정론적 자동화를 실행하세요.

스킬 빌드하기

ChatGPT와 Codex에서 반복해서 수행할 작업에 필요한 지침과 리소스를 패키징하세요.

플러그인 빌드

ChatGPT와 Codex에서 사용할 스킬과 MCP 서버를 패키징하세요.

사이트 도구(WebMCP)

WebMCP를 사용해 AI 에이전트가 웹사이트에서 직접 작업할 수 있도록 하세요.

훅

Codex가 라이프사이클 이벤트를 내보낼 때 사용자 지정 명령어를 실행하세요.

환경

개발 작업을 실행할 위치와 격리 방식을 선택하세요.

로컬, 클라우드 등 작업을 실행하는 여러 방식을 비교하세요.

로컬 환경

프로젝트와 작업 트리에서 사용할 설정 스크립트와 액션을 구성하세요.

클라우드 환경

설정된 클라우드 환경에 작업을 위임하세요.

Git 작업 트리

동시에 진행하는 변경 사항을 각각 별도의 작업 트리에 격리하세요.

Codex로 빌드하기

제품, 시스템, 자동화된 워크플로우에 Codex를 추가하세요.

Codex SDK

애플리케이션에서 프로그래밍 방식으로 Codex를 제어하세요.

App Server

Codex 클라이언트를 구동하는 프로토콜과 연동하세요.

MCP 서버

Model Context Protocol을 통해 Codex 기능을 제공하세요.

GitHub Action

GitHub Actions 워크플로우에서 Codex를 실행하세요.

비대화형 모드

스크립트와 기타 자동화 시스템에서 Codex를 실행하세요.

타사 통합

팀에서 이미 사용하는 도구에서 작업을 위임하고 진행 상황을 추적하세요.

GitHub

작업을 할당하고 변경 사항을 검토하며 Pull Request를 준비하세요.

GitLab(베타)

프로젝트를 연결하고 작업을 위임한 다음 병합 요청을 검토하세요.

Slack

외부 대화에서 Codex 채팅을 시작하고 결과를 다시 전달하세요.

Linear

이슈를 Codex에 할당하고 작업이 완료될 때까지 진행 상황을 추적하세요.

참조 자료

개발자 인터페이스별 명령어, 설정, 플러그인 제출 오류를 찾아보세요.

CLI 맞춤 설정

구문 강조, 테마, 셸 동작을 조정하세요.

개발자 명령

데스크톱 앱, Codex CLI, IDE 확장에서 명령어와 슬래시 명령어를 사용하세요.

개발자 설정

개발 작업에 맞게 데스크톱 앱, Codex CLI, IDE 확장을 설정하세요.
