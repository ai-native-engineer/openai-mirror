# 기능

ChatGPT의 워크플로우, 기능, 명령, 설정을 살펴보세요

ChatGPT에서 작업할 때 사용할 수 있는 워크플로우, 기능, 명령, 설정을 살펴보세요.

ChatGPT에서는 프로젝트와 장시간 이어지는 채팅을 웹 브라우징, 파일, 이미지, 플러그인과 함께 활용할 수 있습니다. 적합한 워크플로우를 선택하는 단계부터 각 채팅에 필요한 컨텍스트와 도구를 제공하는 단계까지, 명령, 설정, 문제 해결 참조 자료가 이러한 워크플로우를 뒷받침합니다.

프로젝트 및 채팅 살펴보기

채팅, 플러그인, 콘텐츠 도구가 표시된 Codex 사이드바와 추가 메뉴

워크플로우

작업을 정리하고 위임하고 검토하는 방법입니다.

프로젝트 및 채팅

관련 채팅, 컨텍스트, 작업을 한곳에서 관리하세요.

Codex 원격

휴대폰에서 작업을 시작하고, 동작을 승인하고, 작업 내용을 검토하세요.

Sites

ChatGPT에서 인터랙티브 웹사이트와 앱을 만들고 저장하고 게시하세요.

시각화

아이디어와 정보를 인터랙티브 시각 자료로 설명하세요.

예약 작업

반복 작업을 예약하고 완료된 작업 결과를 검토하세요.

장시간 작업

자리를 비운 동안에도 ChatGPT가 작업을 계속하도록 하세요.

알림

작업을 확인해야 할 때 ChatGPT가 알리는 방식을 선택하세요.

펫

움직이는 동반자를 선택하고 채팅 활동을 확인하세요.

Codex Micro

Work Louder 키보드로 ChatGPT 채팅을 모니터링하고 제어하세요.

ChatGPT가 정보를 이해하고 콘텐츠를 만들며 작업을 수행하는 데 사용할 수 있는 도구입니다.

브라우저

제어권을 유지하면서 ChatGPT에 웹사이트 탐색과 작업 수행을 맡기세요.

컴퓨터 사용

ChatGPT가 시각적 인터페이스를 통해 앱을 조작하도록 하세요.

ChatGPT 음성 대화

ChatGPT 데스크톱 앱의 채팅, Work, Codex에서 음성을 사용해 보세요.

플러그인

재사용 가능한 워크플로우, 연결된 도구, 공유 컨텍스트를 설치하세요.

웹 검색

최신 정보를 찾고 출처를 작업에 추가하세요.

이미지 생성

작업 과정에서 이미지를 만들고 편집하세요.

이미지 입력

스크린샷과 이미지를 ChatGPT의 컨텍스트로 활용하세요.

앱샷

시각적으로 검사하고 디버깅할 수 있도록 앱 상태를 캡처하세요.

브라우저 확장 프로그램

Chrome, Edge, Brave, Opera 또는 Vivaldi를 ChatGPT와 함께 사용하세요.

파일 작업하기

문서와 기타 파일을 생성하고 미리 보고 다듬으세요.

참조 자료

ChatGPT 데스크톱 앱의 명령과 설정을 찾아보세요.

명령

앱 명령, 키보드 단축키, 딥 링크를 사용하세요.

슬래시 명령어

자주 사용하는 대화형 작업을 단축 명령으로 실행하세요.

설정

ChatGPT 데스크톱 앱의 환경설정을 구성하세요.

문제 해결

ChatGPT 데스크톱 앱에서 자주 발생하는 문제를 해결하세요.
