원격 연결을 사용하면 다른 기기나 컴퓨터에서 실행 중인 작업에 액세스할 수 있습니다.
ChatGPT 모바일 앱에서 **원격을** 열면 연결된 Mac 또는 Windows 기기에서
ChatGPT나 Codex 채팅으로 작업할 수 있습니다. ChatGPT 데스크톱 앱을 실행하는
다른 지원 기기에서 작업을 이어가거나 앱을 SSH 호스트의 프로젝트에
연결할 수도 있습니다.

원격 액세스에는 연결된 호스트의 프로젝트, 채팅, 파일, 자격 증명,
권한, 플러그인, 컴퓨터 사용, 브라우저 설정, 로컬 도구가 사용됩니다.

## 원격으로 할 수 있는 작업

- 호스트의 프로젝트에서 새 채팅을 시작하거나 기존 채팅을 이어갑니다.
- 후속 지침을 보내고 질문에 답하며 진행 중인 작업의 방향을 조정합니다.
- 명령과 기타 작업을 승인합니다.
- 출력 결과, diff, 테스트 결과, 터미널 출력 및 스크린샷을 검토합니다.
- ChatGPT가 작업을 완료하거나 사용자의 확인이 필요할 때 알림을 받습니다.
- 연결된 호스트와 채팅 사이를 전환합니다.

다음 섹션에서는 ChatGPT 모바일 앱에서 **원격을** 열어
데스크톱 호스트에 액세스하는 방법을 설명합니다. Codex를 SSH 호스트의 프로젝트에 연결하려면
[SSH 호스트에 연결](#connect-to-an-ssh-host)을 참고하세요.

## 원격 설정 전 확인 사항

  원격 기능은 macOS 및 Windows에서 ChatGPT 데스크톱 앱을 실행하는 호스트를 지원합니다.
  iOS 또는 Android의 ChatGPT에서 호스트를 제어할 수 있으며, 다른 Mac 또는
  Windows 기기에서 **다른 기기 제어** 기능을 사용할 수 있으면 해당 기기에서도 제어할 수 있습니다. 이용 가능 여부는
  배포 단계에 따라 달라질 수 있습니다.

다음을 준비하세요:

- 사용하려는 ChatGPT 계정과 워크스페이스의 Codex 액세스 권한.
- iOS 또는 Android 기기에 설치된 최신 ChatGPT 모바일 앱. **원격이**
  앱에 표시되지 않으면 먼저 ChatGPT를 업데이트하세요.
- 절전 상태가 아니고 온라인에 연결되어 있으며 동일한 계정과 워크스페이스에 로그인한 호스트에서
실행 중인 macOS 또는 Windows용 최신 ChatGPT 데스크톱 앱. 모바일 설정은
앱에서 시작해야 하며 Codex CLI나 IDE 확장에서는 설정할 수 없습니다.
- 해당 계정 또는 워크스페이스에 필요한 다중 인증, SSO 또는 패스키
구성.

ChatGPT 워크스페이스를 통해 Codex를 사용하는 경우 휴대폰으로 연결하려면 관리자가
먼저 원격 제어 액세스를 활성화해야 할 수 있습니다.

## 원격 설정

연결하려는 호스트의 ChatGPT 데스크톱 앱에서 시작하세요. 설정 플로우에서
해당 호스트의 원격 액세스를 활성화하면 휴대폰으로 스캔할 수 있는 QR 코드가
표시됩니다.
이 QR 코드를 사용하면 휴대폰과 호스트가 페어링됩니다. 각 휴대폰과 지원되는
데스크톱 앱 기기를 제어하려는 모든 호스트와 각각 페어링하세요.

  2026년 6월 8일 이후 사용한 기존 연결은 페어링 상태가 유지됩니다. 2026년 6월 8일 이후
기존 연결을 사용하지 않았다면 두 앱을 모두 업데이트하고 기기를 다시
페어링하세요.

1. 원격 설정을 시작합니다.

   호스트에서 ChatGPT 데스크톱 앱을 여세요. **설정** \>
**연결** \> **이 Mac 또는 PC 제어로** 이동한 다음 **설정** 또는
**추가를** 선택하세요. 원격 액세스를 승인하고 요청된 확인 절차를 완료하세요.

2. QR 코드를 스캔합니다.

   휴대폰으로 앱에 표시된 QR 코드를 스캔하세요. 그러면 ChatGPT가 열리고
모바일 앱과 호스트의 연결을 완료할 수 있습니다.

3. ChatGPT에서 설정을 완료합니다.

   ChatGPT에서 원격 설정 플로우가 열립니다. 동일한 ChatGPT 계정과
워크스페이스를 사용하는지 확인한 다음 필요한 다중 인증, SSO 또는
패스키 단계를 완료하세요. 설정이 완료되면 휴대폰의 원격 화면에
호스트가 표시됩니다.

4. 호스트 설정을 검토합니다.

   호스트의 앱에서 **설정** \> **연결로** 이동해 연결된
   기기를 관리하세요. 컴퓨터가 절전 모드로 전환되지 않도록 할지, 컴퓨터 사용을 활성화할지,
   Chrome 확장 프로그램을 설치할지도 선택할 수 있습니다.

  

## 연결 대상 선택

현재 ChatGPT를 사용하는 노트북이나 데스크톱부터 연결하세요. 지속적으로
액세스하거나 다른 환경이 필요하면 상시 가동 컴퓨터 또는 SSH 호스트를 추가하세요.

### <span class="not-prose inline-flex items-center gap-3 align-middle"><span class="inline-flex h-7 w-7 shrink-0 items-center justify-center rounded-md bg-surface-secondary text-secondary"></span><span>노트북 또는 데스크톱</span></span>

데스크톱 앱이 이미 설치된 Mac 또는 Windows PC를 연결하세요. 그러면 현재 사용하는
프로젝트, 채팅, 자격 증명, 플러그인 및 로컬 설정에 그대로 원격으로
액세스할 수 있습니다.

컴퓨터가 절전 모드로 전환되거나 네트워크 연결이 끊기거나 앱이 닫히면 다시 사용할 수 있을 때까지
원격 액세스가 중지됩니다. 이 컴퓨터를 호스트 기기로 사용하는 경우
전원에 연결해 두고, 가능한 경우 호스트의 연결 설정에서 절전 모드로
전환되지 않도록 설정하세요.

Mac 노트북은 덮개를 열고 전원을 연결하면 원격 액세스를 계속 사용할 수 있습니다.
덮개를 닫은 상태라면 외부 디스플레이도 연결하세요. 다만
**잠자기를** 선택하면 원격 액세스가 중지됩니다.

Windows 호스트에서
[컴퓨터 사용](/ko-KR/codex/computer-use) 기능이 필요한 작업을 수행하려면 세션을 잠금 해제하고 계속 사용할 수 있는 상태로 유지하세요. Windows의 컴퓨터 사용은
포그라운드에서 실행되므로 호스트 데스크톱을 해당 작업에 전용으로 사용하면서
원격 제어로 작업을 시작하거나 확인하는 것이 가장 적합합니다.

### <span class="not-prose inline-flex items-center gap-3 align-middle"><span class="inline-flex h-7 w-7 shrink-0 items-center justify-center rounded-md bg-surface-secondary text-secondary"></span><span>전용 상시 가동 컴퓨터</span></span>

장시간 실행되는 작업 중에도 ChatGPT에 계속 연결하려면 전용 상시 가동
Mac 또는 Windows PC를 사용하세요.

해당 컴퓨터에 ChatGPT 또는 Codex가 사용할 프로젝트, 자격 증명, MCP 서버, 스킬 및 도구를
설치하세요.

### <span class="not-prose inline-flex items-center gap-3 align-middle"><span class="inline-flex h-7 w-7 shrink-0 items-center justify-center rounded-md bg-surface-secondary text-secondary"></span><span>원격 개발 환경</span></span>

프로젝트가 이미 원격 환경에 있다면 SSH 호스트나 관리형 원격 개발 환경을
사용하세요. 먼저 데스크톱 앱 호스트를 해당 환경에 연결하세요.
휴대폰은 계속 같은 호스트에 연결되며 ChatGPT는 원격 환경에서 해당 환경의 종속성,
보안 정책 및 컴퓨팅 리소스를 사용해
작업합니다.

SSH 설정에 관한 자세한 내용은 [SSH 호스트에 연결](#connect-to-an-ssh-host)을 참고하세요.

  상시 가동 컴퓨터나 원격 호스트에서 브라우저 또는 데스크톱 작업을 수행하려면
해당 호스트에서 컴퓨터 사용을 활성화하고 Chrome 확장 프로그램을 설치하세요.

## 연결된 호스트에서 제공되는 항목

휴대폰은 프롬프트, 승인 및 후속 메시지를 ChatGPT로 보냅니다. ChatGPT가 사용하는
환경은 연결된 호스트에서 제공합니다.

구체적으로 다음과 같습니다:

- 레포지토리 파일과 로컬 문서는 연결된 호스트에서 제공됩니다.
- 셸 명령은 해당 호스트 또는 원격 환경에서 실행됩니다.
- MCP 서버, 스킬, 브라우저 액세스 및 컴퓨터 사용은 해당 호스트의
구성에 따라 제공됩니다.
- 로그인된 웹사이트와 데스크톱 앱은 호스트에서 액세스할 수 있는 경우에만
사용할 수 있습니다.
- 샌드박스 설정, 보안 제어 및 작업 승인은 연결된 세션에도 계속
적용됩니다.

보안 릴레이 계층을 통해 신뢰할 수 있는 컴퓨터를 공개 인터넷에 직접 노출하지 않고도
사용자가 승인한 ChatGPT 기기에서 해당 컴퓨터에 액세스할 수 있습니다.

## 다른 기기에서 작업 이어가기

원격 제어를 지원하며 ChatGPT 데스크톱 앱에 로그인한 다른 기기에서
작업을 이어갈 수 있습니다. 예를 들어 노트북을 사용할 수 없다면 휴대폰으로
상시 가동 호스트에서 채팅을 시작한 다음, 나중에 노트북에서 앱을 열어
같은 채팅을 계속할 수 있습니다.

이 기능을 사용할 수 있는 Mac 또는 Windows 기기에서는 **설정 \>
연결 \> 다른 기기 제어로** 이동해 다른 호스트를 추가하세요. 한 기기에서
원격 액세스를 허용하는 동시에 다른 기기를 제어할 수 있습니다.

  

## SSH 호스트에 연결

ChatGPT 데스크톱 앱에서 SSH 호스트의 원격 프로젝트를 추가하고 원격 파일 시스템과
셸을 사용하는 채팅을 실행하세요. 원격 프로젝트의 채팅은 원격 호스트에서 명령어를
실행하고 파일을 읽으며 변경 사항을 저장합니다.

일반 SSH 접속과 동일한 보안 기준을 원격 호스트에도 적용하세요. 신뢰할 수 있는 키와
최소 권한 계정을 사용하고 인증 없이 접근할 수 있는 공개 리스너를 실행하지 마세요.

1. Codex가 호스트를 자동으로 검색할 수 있도록 SSH 설정에 호스트를 추가하세요.

   ```text
   Host devbox
     HostName devbox.example.com
     User you
     IdentityFile ~/.ssh/id_ed25519

   Codex는 `~/.ssh/config`에서 명시적으로 지정된 호스트 별칭을 읽고
   OpenSSH로 해석하며, 패턴만으로 지정된 호스트는 무시합니다.

2. 앱을 실행하는 컴퓨터에서 SSH로 해당 호스트에 접속할 수 있는지 확인하세요.

   ```bash
   ssh devbox

3. 원격 호스트에 Codex를 설치하고 인증하세요.

   앱은 원격 사용자의 로그인 셸을 사용해 SSH로 원격 Codex App Server를
   시작합니다. 해당 셸에서 `codex` 명령어를 실행할 수 있도록 원격 호스트의
   `PATH`에 경로가 포함되어 있는지 확인하세요.

4. 앱에서 **설정 \> 연결을** 열고 SSH 호스트를 추가하거나 활성화한 다음,
   원격 프로젝트 폴더를 선택하세요.

## 호스트 간 채팅 인계

채팅 인계 기능을 사용하면 기존 채팅과 Git 상태를 로컬 컴퓨터와 연결된 원격 호스트
사이에서 이동할 수 있습니다. 로컬에서 작업을 시작해 원격 컴퓨터의 작업 트리에서
계속 진행한 뒤, 나중에 채팅을 다시 가져오세요.

채팅을 인계하기 전에 대상 호스트를 연결하고 해당 호스트에 동일한 Git 레포지토리의
프로젝트를 저장하세요. 프로젝트가 레포지토리의 하위 디렉터리에 있다면 두 호스트에
동일한 하위 디렉터리를 저장하세요. Codex는 저장된 프로젝트가 일치하는 대상만 표시합니다.

채팅을 인계하려면 다음 단계를 따르세요:

1. 데스크톱 앱에서 채팅을 여세요.
2. 채팅 하단에서 현재 실행 위치를 선택한 다음
   대상 호스트를 선택하세요. 원격 채팅을 로컬 컴퓨터로 다시 인계할 때는 **이 컴퓨터를** 
   선택하세요.
3. 대상과 브랜치를 검토한 다음 **인계를** 선택하세요.

Codex는 대상 호스트에 작업 트리를 만들거나 기존 작업 트리를 재사용하고 채팅과
Git 상태를 전송한 다음, 채팅을 해당 호스트로 전환합니다. 채팅이 실행 중이면
인계 과정에서 전송하기 전에 현재 응답을 중단합니다.

다른 채팅에서 Codex에 채팅 이름을 지정해 해당 채팅을 연결된 호스트로 인계하도록
요청할 수도 있습니다. Codex는 요청을 보낸 채팅 자체를 인계할 수 없으며,
Codex 클라우드 환경으로의 인계는 지원되지 않습니다.

## 인증 및 네트워크 노출

원격 연결은 SSH로 원격 Codex App Server를 시작하고 관리합니다.
App Server 트랜스포트를 공유 네트워크나 공용 네트워크에 직접 노출하지 마세요.

현재 네트워크 외부에 있는 원격 컴퓨터에 접속해야 한다면 App Server를
인터넷에 직접 노출하는 대신 VPN 또는 메시 네트워킹 도구를 사용하세요.

## 문제 해결

### 휴대폰에 호스트가 표시되지 않음

호스트에서 데스크톱 앱이 실행 중이고 **다른 기기의
연결 허용** 옵션이 활성화되어 있으며, 두 기기가 동일한 ChatGPT 계정과
워크스페이스를 사용하는지 확인하세요. 2026년 6월 8일 이후 연결을 사용하지 않았다면
두 앱을 모두 업데이트하고 기기를 다시 페어링하세요.

### 다시 로그인한 후 원격 제어가 꺼져 있음

ChatGPT에서 로그아웃하면 **원격 제어가** 꺼지지만
기존 기기 페어링은 삭제되지 않습니다. 다시 로그인한 후 **원격 제어를** 
켜서 이전 연결 상태를 복원하세요.

**원격 제어를** 켜고 **추가를** 선택한 후 오류가 표시되면,
호스트에서 ChatGPT 데스크톱 앱을 다시 시작한 다음 다시 시도하세요.

### 승인 요청이 표시되지 않음

ChatGPT 모바일 앱에서 **원격을** 여세요. 휴대폰과 호스트가
동일한 ChatGPT 계정과 워크스페이스를 사용하는지 확인한 다음, QR 코드를 다시 스캔하거나
호스트에서 설정을 다시 시작하세요. ChatGPT 워크스페이스를 사용한다면 관리자에게
원격 제어 액세스를 활성화했는지 확인해 달라고 요청하세요.

### 원격 세션 연결이 끊어짐

호스트가 절전 모드로 전환되었거나 네트워크 연결이 끊겼거나 앱이 종료되었는지 확인하세요.
ChatGPT가 작업하는 동안 호스트가 절전 모드로 전환되지 않도록 하고 연결 상태를 유지하세요.

### 인증으로 인해 설정이 차단됨

설정 중 표시되는 프롬프트에 따라 계정 또는 워크스페이스 인증을 완료하세요. 조직에서
SSO, 다중 인증 또는 패스키를 요구한다면 해당 인증 절차를 마친 후 다시 시도하세요.
그래도 설정에 실패하면 워크스페이스 관리자에게 원격 제어 액세스를 활성화했는지
확인해 달라고 요청하세요.
