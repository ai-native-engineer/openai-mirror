선택기 예시 이미지에는 GPT-5.6 컨트롤이 표시되어 있습니다. Astra가 출시되면서 대상 Pro, Business
($100), Enterprise 계정의 파워 옵션은 Terra 낮음, Sol 낮음, Sol Medium,
Astra 낮음, Astra Medium, Astra Extra High로 업데이트됩니다.
옵션은 플랜과 출시 단계에 따라 다를 수 있습니다.

### 실험적 컨텍스트 관리

지원되는 Codex 클라이언트에서 ChatGPT Plus 또는 Pro로 로그인한 사용자는
실험적 컨텍스트 관리를 활성화할 수 있습니다. Astra는 컨텍스트 윈도우가 바뀌어도 메모를 유지하며,
같은 작업의 이전 메시지와 도구 결과를 검색할 수 있습니다.
이 실험 기능은 기본적으로 꺼져 있으며, 출시 시점에는 Business, Enterprise 또는
API 키로 로그인하는 경우 사용할 수 없습니다.

이 기능을 사용하려면 `config.toml`에 `features.context_management.experimental_mode = true`로 설정한 뒤
새 작업을 시작하세요. 설정에 관한 내용은 [구성 참조 자료](/ko-KR/codex/config-file/config-reference)를,
파일 위치는 [구성 기본 사항](/ko-KR/codex/config-file/config-basic)을 참고하세요.
워크스페이스 요구 사항은 계속 적용됩니다.

## Astra, Sol, Terra, Luna 선택 가이드

여러 단계와 도구를 아우르는 작업에 가장 강력한 성능이 필요하다면
 **Astra를** 선택하세요. **Sol은** 깊이 있고 완성도 높은 결과를 제공하며, **Terra는** 일상 업무에,
 **Luna는** 명확하고 반복 가능한 작업에 적합합니다.

### 각 모델에 적합한 작업

- **Astra: 가장 어려운 작업을 처음부터 끝까지 처리할 때.** 지속적인 추론과 판단이 필요한
  코드, 앱, 연구 전반의 워크플로우를 완수하려면 Astra를 선택하세요.
  유용한 결과를 얻는 데 필요한 자료, 템플릿, 제약 조건,
  검증 기준을 제공하세요. Astra는 핵심을 짚는 질문을 하고 사용자의 지침을 반영하면서도
  원래 목표와 제약 조건을 놓치지 않는 능력이 더 뛰어납니다.
- **Sol: 복잡하고 정답이 정해지지 않은 작업에 적합.** 추가 분석이나 판단, 세심한 마무리가 필요한 모호한 작업, 어려운 작업, 가치가 높은 작업에는
  Sol을 선택하세요. 복잡한 코드 변경, 심층 리서치,
  완성도 높은 문서 작성이 그 예입니다. 범위가 좁은 작업에서는
  완료 기준을 명확히 정해 작업의 초점을 유지하세요.
- **Terra: 실용적인 만능 모델.** Sol만큼 깊이 있는 분석까지는 필요 없지만
  강력한 추론과 도구 사용이 필요한 일상 업무에는 Terra를 선택하세요.
  이전에 GPT-5.5에 맡기던 작업이라면 Terra부터 시작하면 좋습니다.
- **Luna: 명확하고 반복 가능한 작업에 적합.** 좋은 결과의 기준이 분명한 구체적인 대량 작업에는
  Luna를 선택하세요. 예를 들면 추출, 분류,
  변환, 구조화된 요약 등이 있습니다.

### 추론 수준 선택

필요한 결과를 얻을 수 있는 가장 낮은 추론 수준을 사용하세요. 계획, 분석 또는
검토가 더 필요한 작업에서는 추론 수준을 높이세요.

- ChatGPT 데스크톱 앱, 웹의 ChatGPT Work, IDE 확장의 **낮음** 또는 CLI의 **Low** 설정은
  빠르게 처리할 수 있고 범위가 명확한 작업에 적합합니다.
- **Medium은** 더 많은 계획이 필요한 작업에서 속도와 깊이의 균형을 맞춥니다.
- **High와** **Extra High는** 여러 단계나 자료,
  상충하는 조건을 고려해야 하는 어려운 작업에 적합합니다.

GPT-5.5와 GPT-5.6의 추론 수준은 정확히 대응하지 않습니다. 익숙한 작업을 더 낮은
설정으로 시도한 후 결과에 따라 조정하세요.

### Max 또는 Ultra 사용 시점

**Max** 설정은 선택한 모델이 단일 작업을 더 오래 추론할 수 있게 합니다.
속도나 사용량보다 깊이가 중요한 가장 어려운 문제에 사용하세요.
옵션에 Max 항목이 표시되지 않으면 앱 설정에서 활성화해야 합니다.

**Ultra** 설정은 [하위 에이전트](/ko-KR/codex/agent-configuration/subagents)를 사용해
복잡한 작업의 각 부분을 병렬로 처리합니다. 작업을 의미 있는 부분으로 나눌 수 있을 때 선택하세요.
대부분의 작업에는 Max 또는 Ultra 설정이 필요하지 않습니다.

데스크톱 앱의 모델 슬라이더에 Ultra 옵션이 표시되지 않으면
**설정** \> **구성으로** 이동한 다음 **모델 선택기 슬라이더에 Ultra 표시를** 켜세요.

## 지원 중단 예정인 Codex 모델

ChatGPT로 로그인한 Codex에서는 `gpt-5.4`와 `gpt-5.4-mini` 모델의 지원이
2026년 8월 31일에 종료됩니다. 워크스페이스 기본값, 저장된 모델 설정,
관리형 구성, 사용자 지정 에이전트, 예약 작업에서
`gpt-5.4`를 `gpt-5.6-terra`로, `gpt-5.4-mini`를 `gpt-5.6-luna`로 바꾸세요.

ChatGPT로 로그인한 Codex에서는 `gpt-5.2`와 `gpt-5.3-codex` 모델이
이미 사용 중단 예정(deprecated) 상태입니다. 이 모델들을 아직 참조하는 스크립트, 구성 파일,
`codex exec --model` 명령어를 업데이트하세요.

OpenAI API와 본인의 API 키로 인증한 Codex는
GPT-5.4 지원 종료의 영향을 받지 않습니다. 현재 API에서 사용할 수 있는 모델은
[API 모델 페이지](/api/docs/models)를 참고하세요.

## 기본 로컬 모델 구성하기

ChatGPT 데스크톱 앱, Codex CLI, IDE 확장은 동일한 `config.toml`
[구성 파일](/ko-KR/codex/config-file/config-basic)을 사용합니다. 모델을 지정하려면 구성 파일에
`model` 항목을 추가하세요. 모델을 지정하지 않으면
ChatGPT 데스크톱 앱, Codex CLI 또는 IDE 확장에서 권장 모델을 사용합니다.
