앱샷을 사용하면 가장 앞에 있는 앱 창을 ChatGPT 채팅으로 보낼 수 있습니다. 컴퓨터에서 다른 앱으로
작업하는 동안 현재 컨텍스트를 ChatGPT에 제공해 해당 작업에 도움을
받고 싶을 때 앱샷을 사용하세요.

  앱샷은 macOS용 ChatGPT 데스크톱 앱에서 사용할 수 있습니다. 양쪽 Command
키를 동시에 누르거나 사용자 지정 앱샷 단축키를 눌러 캡처하세요.

## 앱샷으로 캡처되는 내용

앱샷은 가장 앞에 있는 창만 캡처합니다. 포함될 수 있는 내용은 다음과 같습니다:

- 화면에 보이는 창의 이미지.
- 해당 창에서 가져올 수 있는 텍스트. 여기에는 화면에 보이는 텍스트와 앱이
현재 보이는 스크롤 영역 밖에서 제공하는 텍스트가 포함됩니다.

채팅에 앱샷을 추가하면 첨부 파일처럼 작동합니다. ChatGPT는 직접 첨부한 파일이나
이미지와 마찬가지로 앱샷을 세션 파일에 로컬로
저장합니다.

## 앱샷을 사용하는 경우

ChatGPT가 작업을 수행하기 전에 Mac 앱의 컨텍스트가 필요할 때 앱샷을 사용하세요.

예:

- API 참조 페이지를 공유하고, 이를 사용하는 스크립트를 작성해 달라고 ChatGPT에 요청하세요.
- 이메일 또는 캘린더 화면을 공유하고, 후속 조치의 초안을 작성해 달라고 ChatGPT에 요청하세요.
- 이미지 편집기나 디자인 또는 미리보기 창을 공유하고, 관련 애셋이나
코드를 수정해 달라고 ChatGPT에 요청하세요.
- 설명하기보다 보여 주는 편이 쉬운 오류, 설정 패널 또는 앱 상태를
공유하세요.

## 앱샷 캡처하기

1. 공유하려는 앱 창을 맨 앞으로 가져오세요.
2. 양쪽 Command 키를 동시에 누르거나 ChatGPT 설정에서 지정한 사용자 지정
단축키를 누르세요.
3. ChatGPT가 요청하면 macOS 권한을 허용하세요.
4. 앱샷을 사용해 작업을 수행하도록 ChatGPT에 요청하세요.

  

기본적으로 ChatGPT는 앱샷을 위한 새 채팅을 시작합니다. 지난 60초 이내에 사용한
채팅이 있다면 대신 해당 최근 채팅에 앱샷을 추가합니다. 앱샷을 연속으로
캡처하면 모두 같은 채팅에 추가됩니다.

앱 설정에서 앱샷 단축키를 변경할 수 있습니다.

## 권한 및 안전

ChatGPT는 앱샷을 캡처하기 전에 다음 권한을 요청할 수 있습니다:

- **화면 및 시스템 오디오 녹음을** 허용하면 ChatGPT가
  가장 앞에 있는 창의 이미지를 캡처할 수 있습니다.
- **손쉬운 사용을** 허용하면 ChatGPT가 가장 앞에 있는 창에서 가져올 수 있는 텍스트를 읽을 수 있습니다.

앱샷을 캡처하면 캡처된 이미지와 가져올 수 있는 텍스트가 ChatGPT와
공유됩니다. 작업에 민감한 콘텐츠가 꼭 필요한 경우가 아니라면 해당 콘텐츠의
앱샷을 캡처하지 마세요.

스크린샷이나 문서를 ChatGPT와 공유할 때와 같은 기준으로 앱샷도
검토하세요.

## 제한 사항 및 문제 해결

앱샷은 macOS용 ChatGPT 데스크톱 앱에서 사용할 수 있습니다. 앱샷이 이미 포함된 채팅을
CLI에서 재개하면 해당 첨부 파일은 채팅 기록의 일부로 유지되지만,
CLI에서는 새 앱샷을 캡처할 수 없습니다.

Google Docs, Gmail, Google Sheets, Google Slides를 비롯한 일부 앱과
웹사이트에서는 ChatGPT가 화면에 보이는 스크린샷만 받을 수 있고
전체 문서나 화면 밖의 텍스트는 받지 못할 수 있습니다. ChatGPT Work 또는 Codex에서 ChatGPT는
설치된 해당 앱용 플러그인을 사용해 관련 앱 콘텐츠에 액세스하고 요청을
처리하는 데 도움을 줄 수 있습니다.

앱샷이 작동하지 않는 경우:

1. **시스템 설정 \> 개인정보 보호 및 보안을** 여세요.
2. Codex
   컴퓨터 사용에 **화면 및 시스템 오디오 녹음** 권한과 **손쉬운 사용** 권한이 허용되어 있는지 확인하세요.
3. 앱을 다시 시작한 후 다시 시도하세요.
