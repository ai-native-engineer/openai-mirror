일부 ChatGPT 및 Codex 기능은 성숙도 라벨과 함께 출시됩니다. 이 라벨을 통해 각 기능의 신뢰성, 변경될 수 있는 부분, 기대할 수 있는 지원 수준을 파악할 수 있습니다.

| 성숙도          | 의미                                                                                                 | 사용 지침                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 개발 중 | 아직 사용할 준비가 되지 않았습니다.                                                                                            | 사용하지 마세요.                                                                    |
| 실험적      | 불안정하며 OpenAI가 제거하거나 변경할 수 있습니다.                                                                  | 사용에 따른 위험은 사용자가 감수해야 합니다.                                                         |
| 베타              | 광범위한 테스트에 사용할 준비가 되었으며 대부분 완성된 상태입니다. 다만 일부 사항은 사용자 피드백에 따라 변경될 수 있습니다.       | 대부분의 평가와 시범 운영에 사용할 수 있습니다. 소폭 변경될 수 있다는 점을 고려하세요.                      |
| 안정적            | 지원과 문서화가 완비되어 광범위하게 사용할 수 있으며, 동작과 구성은 시간이 지나도 일관되게 유지됩니다. | 프로덕션 환경에서 안전하게 사용할 수 있으며, 기능 제거 시에는 일반적으로 사용 중단 예고 절차를 거칩니다. |
| 사용 중단 예정(deprecated)        | 호환성을 위해 계속 제공되지만 더 이상 사용을 권장하지 않습니다. OpenAI가 향후 릴리스에서 제거할 수 있습니다.       | 신규 도입을 피하고 마이그레이션을 계획하세요.                                            |
