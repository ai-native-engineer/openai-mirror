Codex 기반 터미널 워크플로우 구축

세션을 재개하고 시각적 컨텍스트와 웹 컨텍스트를 추가하며, 복잡한 작업을 나누고 Codex를 개발 도구에 연결하는 데 사용할 수 있는 CLI 기능을 알아보세요.

저장된 채팅으로 돌아가기

현재 레포지토리의 최근 채팅을 다시 열거나, 이전 작업으로 돌아가야 할 때 로컬 채팅 전체를 검색하세요.

프롬프트에 시각적 컨텍스트 추가

첫 프롬프트에 오류 스크린샷, 아키텍처 다이어그램 또는 디자인 참고 자료를 첨부하거나 대화형 Composer에 이미지를 붙여 넣으세요.

큰 조사 작업 나누기

Codex에 특정 작업을 전문 에이전트에게 위임하도록 요청한 다음, 결과를 기본 터미널 세션으로 가져오세요.

최신 정보 검색

작업에 최신 릴리스, 문서 또는 외부 동작 정보가 필요하면 실행 중에 실시간 웹 검색으로 전환하세요. 검색 활동은 대화 기록에 계속 표시됩니다.

Codex 클라우드로 작업 이동

진행 중이거나 완료된 채팅을 살펴보고, 구성된 환경에 작업을 제출한 다음, 터미널에서 결과를 로컬 레포지토리에 적용하세요.

MCP로 외부 도구 연결

로컬 또는 원격 MCP 서버를 추가하고, 필요한 경우 인증한 다음, Codex가 도구를 사용하기 전에 현재 세션에서 사용할 수 있는 도구를 확인하세요.

실행별 작업 범위 설정

Codex가 묻지 않고 파일을 편집하거나 명령어를 실행할 수 있는 시점을 정하고, 계속하기 전에 활성 샌드박스와 쓰기 가능한 루트를 확인하세요.

터미널에 맞게 Codex 설정

셸 자동 완성을 생성하고, 구문 테마를 선택하고, 긴 프롬프트는 VISUAL 또는 EDITOR로 설정한 에디터에서 여세요.

Codex CLI로 할 수 있는 작업

대화형 작업, 자동화, 검토 및 위임을 하나의 집중된 터미널 루프에서 수행하세요.

코딩 루프를 터미널 안에서 유지

레포지토리에서 Codex를 시작해 익숙하지 않은 코드를 탐색하고 변경을 계획하며 파일을 편집하고 로컬 개발 도구를 실행하세요. 진행 중인 턴에 추가 지시를 내리고, 표시되는 명령어와 diff를 확인하며, 후속 작업도 같은 세션에서 계속하세요.

레포지토리를 검사하고 코드를 편집하며 터미널에서 테스트를 실행하는 Codex CLI

스킬 및 플러그인 사용

반복 가능한 지침을 스킬로 패키징한 다음, CLI를 벗어나지 않고 Codex를 팀의 도구 및 데이터에 연결할 수 있도록 플러그인을 추가하세요.

Codex CLI에서 사용할 수 있는 스킬, 플러그인 및 연결된 개발자 도구

배포 전에 변경 사항 검토

커밋되지 않은 변경 사항, 커밋 또는 베이스 브랜치를 대상으로 전용 검토를 실행하세요. Codex는 작업 트리를 수정하지 않고 우선순위별 검토 결과를 보고하므로, 커밋하거나 Pull Request를 열기 전에 리스크를 해결할 수 있습니다.
