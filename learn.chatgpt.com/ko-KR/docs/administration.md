# 관리

ChatGPT, Codex 개발자 도구, API, 플러그인 및 연결된 시스템의 액세스 범위와 정책 적용 범위를 설정하세요

ChatGPT, Codex 개발자 도구, API, 플러그인 및 연결된 시스템의 액세스 범위와 정책 적용 범위를 설정하세요.

관리에서는 서로 연관된 여섯 가지 제어 영역을 다룹니다. ChatGPT 워크스페이스 액세스, ChatGPT 데스크톱 앱·Codex CLI·IDE 확장의 적용 대상 기능에 대한 로컬 런타임 정책, Codex 클라우드 사용 자격, Platform API 액세스, 플러그인 사용 가능 여부와 커넥터 권한, 연결된 시스템의 권한입니다. 워크스페이스 ID와 액세스 설정부터 시작한 다음, 각 배포에 필요한 런타임 및 소스 시스템 제어를 적용하세요.

ChatGPT Work 클라우드 보안

호스팅 환경의 실행 방식, 연결된 계정, 액세스 제어, 데이터 보존, 감사 시 확인할 수 있는 정보를 검토하세요.

ChatGPT Work 로컬 보안

로컬 실행, 기기 및 브라우저 액세스, 관리형 정책, 데이터 처리 및 감사의 제약 사항을 검토하세요.

ChatGPT Work 관리자용 자주 묻는 질문

ChatGPT Work의 액세스, 데이터, 거버넌스, 사용량 및 인시던트 관련 제어를 검토하세요.

ChatGPT Work: 사용량 및 비용

공유 크레딧, 청구에 미치는 영향, 지출 제어 및 도입 계획을 알아보세요.

ID 및 인증

사용자의 로그인 방식을 선택하고 프로그램으로 실행하는 워크플로우에 사용할 자격 증명을 발급하세요.

인증 개요

로그인 방식, 자격 증명 저장 방식 및 정책 강제 적용 기능을 비교하세요.

워크로드 ID

신뢰할 수 있는 워크로드가 장기간 유효한 자격 증명 없이 Codex를 사용할 수 있도록 하세요.

개인 액세스 토큰

프로그램에서 액세스할 때 사용할 토큰을 생성하고 관리하세요.

서비스 계정

자동화된 워크플로우에 사용할 워크스페이스 ID를 생성하고 관리하세요.

워크스페이스 액세스, 정책 및 모델

ChatGPT 워크스페이스 액세스 권한을 부여하고, 이를 로컬 런타임 정책, Codex 클라우드 액세스 및 Platform API 액세스와 별도로 관리하세요.

그룹 및 프로비저닝

수동 관리 그룹과 SCIM 그룹, 프로비저닝 및 도입 대상 그룹을 관리하세요.

사용자 수명 주기 관리

직원 계정을 프로비저닝하고 그룹 액세스 권한을 업데이트하며, 퇴사하는 사용자의 자격 증명을 무효화하세요.

역할 및 워크스페이스 권한

워크스페이스, 런타임, API, 플러그인 및 소스 시스템의 제어 항목을 정리한 기준 자료를 활용하세요.

GPT와 공유

워크스페이스 전반에서 GPT 공유, 소유권, 연결된 앱 및 타사 액션을 관리하세요.

관리형 구성

지원되는 환경에서 관리형 설정을 배포하고, ChatGPT 데스크톱 앱, Codex CLI 및 IDE 확장의 적용 대상 기능에 런타임 요구사항을 강제 적용하세요.

Prisma AIRS

Codex 프롬프트에 워크스페이스 전반의 보안 정책을 적용하세요.

HIPAA 구성

보호 대상 건강 정보를 처리할 가능성이 있는 워크플로우의 로컬 런타임 보호 조치를 구성하세요.

워크스페이스 모델 가용성

ChatGPT, ChatGPT 데스크톱 앱의 Codex, Codex CLI, IDE 확장, Codex 클라우드 및 Platform API의 모델 액세스를 각각 구분하세요.

플러그인 및 커넥터 제어

플러그인 설치, 번들로 제공되는 스킬, 커넥터 기반 기능 및 연결된 서비스에 대한 액세스를 제어하세요.

플러그인 제어

플러그인 사용 가능 여부, 커넥터 액세스와 액션, 소스 시스템의 권한을 관리하세요.

플러그인 관리

GitHub에서 워크스페이스 플러그인을 가져와 동기화하세요.

스킬 제어

ChatGPT 워크스페이스, 로컬 파일 시스템 및 플러그인의 스킬 제어 기능을 비교하세요.

사용량, 거버넌스 및 컴플라이언스

도입 현황을 측정하고 보고 또는 감사 데이터를 담당 시스템으로 전달하세요.

거버넌스

확인하려는 내용에 맞는 분석, 지출 및 감사 인터페이스를 선택하세요.

관리자 플러그인

권한, 승인, 지원되는 관리 워크플로우에 관리자 플러그인을 사용하세요.

워크스페이스 분석

워크스페이스의 ChatGPT 도입 현황과 Codex 사용량을 확인하세요.

분석 API

Codex 분석 API로 개발자 활동 및 코드 검토 보고를 자동화하세요.

Compliance API 및 감사 이벤트

감사 및 조사 워크플로우에 사용할 활동 기록을 내보내세요.

배포 및 모델 제공업체

데스크톱 앱을 배포하고 업데이트하거나, 관리 대상 호스트를 연결하거나, 지원되는 외부 모델 제공업체를 설정하세요.

앱 업데이트 관리

데스크톱 앱 업데이트를 제어하고 기기 관리 플랫폼을 통해 승인된 버전을 배포하세요.

Windows 앱 배포

관리 대상 Windows 기기에 사용할 설치 및 업데이트 방식을 선택하세요.

원격 연결

연결된 컴퓨터에서 작업을 시작하고 제어하세요.

Amazon Bedrock
