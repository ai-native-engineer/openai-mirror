# Codex 원격

연결된 컴퓨터에서 실행되는 Codex 작업을 휴대폰으로 시작하고, 진행 방향을 안내하고, 승인하고, 검토하세요.

원격

휴대폰으로 코딩 작업을 시작하고, 진행 방향을 안내하고, 검토하세요

휴대폰에서 진행 상황을 확인하고 동작을 승인하며 지침을 보내세요. Codex는 연결된 컴퓨터에서 각 작업을 실행합니다.

원격 설정

원격 연결 가이드

ChatGPT 모바일 앱을 연결된 Mac 또는 Windows PC와 함께 사용하세요. 사용 가능 여부는 기능 배포 상황과 워크스페이스 설정에 따라 달라집니다.

대화형 Codex 원격 미리보기

연결된 컴퓨터, 작업, 대화, 승인, 변경된 파일을 보여주는 대화형 Codex 원격 모바일 앱

Codex 원격의 장점

휴대폰에서 작업 시작하기

연결된 컴퓨터와 프로젝트를 선택하고 작업을 설명한 다음 Codex가 작업을 시작하도록 하세요.

진행 중인 작업 안내

자리에 돌아가지 않고도 작업을 열어 진행 상황을 확인하고 새 지침을 보내세요.

요청된 동작 승인

Codex가 연결된 컴퓨터에서 작업을 계속하기 전에 요청된 명령과 동작을 검토하세요.

결과 검토

응답, 변경된 파일, diff, 테스트 결과를 확인한 후 다음 단계를 결정하세요.

빠른 시작

원격 시작하기

컴퓨터를 연결하고 접근 권한을 승인한 후 첫 작업을 시작하세요.

QR 코드 스캔

휴대폰으로 코드를 스캔한 후 동일한 ChatGPT 계정과 워크스페이스에 로그인하고 연결을 승인하세요. 본인이 소유하고 신뢰하는 기기만 연결하세요.

열기

ChatGPT 모바일 앱에서 연결된 컴퓨터를 선택하고 새 작업을 시작하거나 기존 작업을 계속하세요. 컴퓨터가 절전 모드로 전환되지 않도록 하고 온라인 상태를 유지하세요.

어디서나 작업 이어가기

휴대폰에서 작업을 시작하고, 승인하고, 검토하세요. 연결된 컴퓨터는 조직의 보안 정책에 따라 작업을 실행합니다.

컴퓨터에서 실행 중인 작업 보기

연결된 여러 컴퓨터에서 진행 중인 작업을 확인하고, 기존 대화를 이어가며, 사용자 입력이 필요한 시점을 파악하세요.
