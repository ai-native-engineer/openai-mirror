ChatGPT 데스크톱 앱에서 ChatGPT 드롭다운을 열고 **Codex를** 선택하세요.
Codex 채팅을 시작할 때 실행할 위치를 선택하세요:

- **로컬**: 현재 프로젝트 디렉터리에서 직접 작업합니다.
- **작업 트리**: Git 작업 트리에서 변경 사항을 격리합니다. [자세히 알아보기](/ko-KR/codex/environments/git-worktrees).
- **클라우드**: 구성된 클라우드 환경에서 원격으로 실행합니다.

**로컬** 채팅과 **작업 트리** 채팅은 모두 사용자의 컴퓨터에서 실행됩니다.

전체 용어집과 개념은 [개념 섹션](/ko-KR/codex/prompting)에서 확인하세요.
