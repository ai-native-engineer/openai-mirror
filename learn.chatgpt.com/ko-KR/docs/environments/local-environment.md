로컬 환경에서는 작업 트리의 설정 단계와 프로젝트의 공통 액션을 구성할 수 있습니다.

  ChatGPT 데스크톱 앱의 Codex에서만 로컬 환경을 사용할 수 있습니다.
  로컬 환경을 구성하거나 사용하기 전에 **Codex를** 선택하세요.

[ChatGPT 데스크톱 앱 설정](codex://settings) 창에서 로컬 환경을 구성합니다. 생성된 파일을 프로젝트의 Git 레포지토리에 체크인하면 다른 사용자와 공유할 수 있습니다.

Codex는 이 구성을 프로젝트 루트의 `.codex` 폴더에 저장합니다.
레포지토리에 프로젝트가 두 개 이상 있다면,
공유 `.codex` 폴더가 있는 프로젝트 디렉터리를 여세요.

## 설정 스크립트

작업 트리는 로컬 채팅과 다른 디렉터리에서 실행되므로 프로젝트가 완전히 설정되지 않았거나, 종속성 또는 레포지토리에 체크인되지 않은 파일이 누락되었을 수 있습니다. 새 채팅을 시작하면서 Codex가 새 작업 트리를 만들면 설정 스크립트가 자동으로 실행됩니다.

이 스크립트를 사용해 종속성 설치나 빌드 프로세스 실행 등 환경을 구성하는 데 필요한 명령어를 실행하세요.

예를 들어 TypeScript 프로젝트에서는 설정 스크립트로 종속성을 설치하고 초기 빌드를 실행할 수 있습니다:

```bash
npm install
npm run build

설정이 플랫폼별로 다르다면 macOS, Windows 또는 Linux용 설정 스크립트를 정의해 기본 스크립트를 재정의하세요.

## 액션

액션을 설정해 두면 프로젝트 빌드 실행이나 개발 서버 시작처럼 자주 쓰는 명령어를 매번 입력하지 않아도 됩니다. 일회성으로 빠르게 디버깅할 때는 통합 터미널을 직접 사용할 수 있습니다.

</section>

예를 들어 Node.js 프로젝트에서는 다음 스크립트가 포함된 "실행" 액션을 만들 수 있습니다:

```bash
npm start

액션의 명령어가 플랫폼마다 다르다면 macOS, Windows 및 Linux용 스크립트를 각각 정의하세요.

각 액션을 구분할 수 있도록 액션마다 아이콘을 선택하세요.

## 내장 Git 도구 사용

<div class="my-8 grid gap-6 md:grid-cols-[minmax(0,1fr)_minmax(16rem,42%)] md:items-center">

<div>

Codex에서 ChatGPT 데스크톱 앱은 각 로컬 프로젝트와 작업 트리에 자주 쓰는
Git 컨트롤을 제공합니다. diff 창에는 현재 체크아웃의 변경 사항이 표시되며
Codex가 처리할 인라인 댓글을 추가할 수 있습니다. 앱을 벗어나지 않고 개별
청크를 스테이징하거나 되돌리고, 파일 전체를 스테이징하거나 되돌리며, 변경 사항을 커밋하고, 브랜치를 푸시하고,
Pull Request를 만들 수 있습니다.

앱에서 제공하지 않는 Git 작업에는 [통합 터미널](/ko-KR/codex/integrated-terminal)을 사용하세요.
동시에 진행되는 변경 사항을 로컬 체크아웃과 분리하려면
[작업 트리](/ko-KR/codex/environments/git-worktrees)에서 작업을 시작하세요.
