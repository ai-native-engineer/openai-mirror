## 개요

플러그인은 ChatGPT와 Codex의 기능을 재사용 가능한 워크플로우로 묶습니다.
스킬, 커넥터 또는 둘 다 포함할 수 있습니다. 두 제품은 하나의 통합 플러그인
디렉터리를 사용하므로 각 제품이 지원하는 환경에서 동일한 공개
플러그인을 찾을 수 있습니다.

플러그인은 웹, 데스크톱, 모바일용 ChatGPT의 채팅과 Work에서 사용할 수 있으며,
ChatGPT 데스크톱 앱의 Codex에서도 사용할 수 있습니다. Codex CLI에도 Codex 환경용
플러그인 브라우저가 있습니다. IDE 확장은 플러그인을 지원하지 않습니다.

모바일에서는 채팅이나 Work에서 계정에 제공되는 플러그인을 사용할 수 있습니다.

**플러그인** 탭을 열어 플러그인을 찾아보고 설치하세요. 설치한 후에는
ChatGPT의 채팅이나 Work 또는 Codex에서 플러그인을 사용할 수 있습니다. 설치된 플러그인은
새 채팅에 스킬, 커넥터, MCP 도구를 추가할 수 있습니다.

**플러그인** 탭을 열어 플러그인을 찾아보고 설치하세요. 설치한 후에는
채팅이나 Work에서 플러그인을 사용할 수 있습니다. 플러그인 도구를 사용하려면 먼저 외부
서비스에 연결하라는 요청이 표시될 수 있습니다.

Codex CLI에서 `/plugins`를 입력해 플러그인 브라우저를 여세요. 설정된 마켓플레이스에서
플러그인을 설치한 후, 포함된 스킬이나 도구를 사용하기 전에
새 세션을 시작하세요.

### 지원되는 환경에서 플러그인 사용

IDE 확장에서는 플러그인을 사용할 수 없습니다. Codex용 플러그인을 찾아보고 설치하려면
ChatGPT 데스크톱 앱 또는 Codex CLI를 사용하세요.

예를 들어 다음과 같이 ChatGPT와 Codex의 기능을 확장할 수 있습니다:

- Codex Security 플러그인을 설치해 검사 권한이 있는 코드를 스캔하고
발견된 잠재적 보안 이슈가 실제 취약점인지 확인하세요.
- Gmail 플러그인을 설치해 Gmail에서 작업하세요.
- Google Drive 플러그인을 설치해 Drive, 문서, 스프레드시트,
프레젠테이션에서 작업하세요.
- Slack 플러그인을 설치해 채널을 요약하거나 답글 초안을 작성하세요.

플러그인에는 다음 구성 요소 중 하나 이상이 포함될 수 있습니다:

- **스킬:** 특정 유형의 작업에 재사용할 수 있는 지침입니다. ChatGPT와
  Codex는 필요할 때 스킬을 불러와 작업에 맞는 절차를 따르고
  적절한 참조 자료나 보조 스크립트를 사용할 수 있습니다.
- **커넥터:** GitHub, Slack, Google Drive 같은 도구와의 연결입니다. 이를 통해
  ChatGPT와 Codex는 해당 도구의 정보를 읽고 도구에서 작업을 수행할 수 있습니다.
  커넥터는 도구를 제공하며 선택적으로 맞춤형 UI를 포함할 수 있습니다.
- **MCP 서버:** ChatGPT와 Codex가 추가 도구나 공유 정보에 접근할 수 있게 하는 서비스입니다.
  이러한 도구와 정보는 주로 로컬 프로젝트 외부 시스템에서 제공됩니다. MCP 서버는
  커넥터의 기반 서비스이기도 합니다. 도구를 정의하고 인증을 적용하며,
  구조화된 데이터를 반환하고 외부 시스템에서 작업을 수행합니다.
- **브라우저 확장 프로그램:** 플러그인의 워크플로우에 필요한
  브라우저 기능입니다.
- **훅:** 수명 주기의 지정된 시점에 실행되는 명령어입니다. 활성화하기 전에
  플러그인 훅을 검토하고 신뢰할 수 있는지 확인하세요.
- **예약 작업 템플릿:** 예약 작업을 사용할 수 있는 환경에서
  반복 작업을 설정할 때 재사용하는 기본 틀입니다.

프로젝트나 팀을 위한 레포지토리 마켓플레이스 같은 마켓플레이스 소스를 통해
플러그인을 게시하고 공유할 수 있습니다. [플러그인 빌드](https://developers.openai.com/plugins/build/plugins)에서
마켓플레이스 설정, 패키징, 배포 지침을 확인하세요.

통합 기능을 개발한다면
[MCP 서버 빌드](https://developers.openai.com/plugins/build/mcp-server)부터 시작하세요.
플러그인에 맞춤형 UI가 필요하다면
[선택적 UI 가이드](https://developers.openai.com/plugins/build/chatgpt-ui)를 참조하세요.

## 플러그인 사용 및 설치

### 통합 플러그인 디렉터리

ChatGPT와 Codex는 동일한 공개 플러그인 카탈로그를 사용합니다. 웹 또는
ChatGPT 데스크톱 앱에서 **플러그인** 탭을 열어 플러그인을 찾아보고 설치하세요.

  
    
  

플러그인 디렉터리는 플러그인을 다음 탭으로 분류합니다:

- **OpenAI:** OpenAI가 개발한 플러그인입니다.
- **워크스페이스 이름:** 워크스페이스에서 제공하는 플러그인입니다.
- **개인:** 개인 마켓플레이스의 플러그인입니다. 해당하는 플러그인이 있으면 **내가 만든 항목** 및
**나와 공유된 항목** 섹션이 표시됩니다.

별도의 **설치됨** 행에서 이미 설치한 플러그인을 검토하세요.

워크스페이스 관리자는 팀을 위한 GitHub 마켓플레이스를 가져와 동기화할 수 있습니다.
설정 및 접근 요구 사항은 [플러그인 관리](/ko-KR/codex/enterprise/plugin-management)에서
확인하세요.

### 플러그인 설치 및 사용

플러그인 디렉터리를 연 후 다음 단계를 따르세요:

1. 플러그인을 검색하거나 둘러본 다음 세부 정보를 여세요.
2. 더하기 버튼을 선택해 플러그인을 설치하세요.
3. 플러그인에 커넥터가 필요하면 연결 요청이 표시될 때 연결하세요. 일부 플러그인은
설치 중에 인증을 요청하고, 다른 플러그인은 처음 사용할 때
인증을 요청합니다.
4. 설치한 후 새 채팅을 시작하고 ChatGPT 또는 Codex에 플러그인을 사용하도록
요청하세요.

순차 제공되고 있습니다. 지원 대상에는 Airtable, GitLab, HubSpot, Notion, Supabase,

### Codex에서 Apple Messages 사용

Apple Messages 플러그인은 macOS용 ChatGPT 데스크톱 앱에서 모든 요금제로 사용할 수 있습니다.
Codex와 ChatGPT Work에서는 Mac에 있는 iMessage, SMS, RCS 채팅을 읽고 검색하며
Messages 앱을 통해 사용자를 대신해 메시지를 보낼 수 있습니다.
Messages를 통해 ChatGPT와 원격으로 대화하는 기능은 제공하지 않으며,
일반 ChatGPT 채팅에서는 작동하지 않습니다.

이번 릴리스에서 Messages 플러그인은 ChatGPT 데스크톱 앱의 Apple Silicon
(arm64) 빌드에만 포함됩니다.

1. **플러그인** 메뉴를 열고 Apple Messages 플러그인을 찾아 설치하세요.
2. Codex 또는 ChatGPT Work에서 새 채팅을 시작하고 메시지 찾기, 요약, 초안 작성
또는 전송을 요청하세요.
3. ChatGPT가 Messages 내용을 읽기 전에 요청된 macOS 권한을 부여하세요.
4. 전송을 허용하기 전에 메시지와 수신자를 검토하세요.

기본적으로 ChatGPT는 사용자가 메시지와 수신자를 승인한 후에만
메시지를 전송합니다. 해당 전송만 승인하려면 **한 번 허용** 옵션을 선택하세요.
**이 채팅에 항상 전송 허용** 옵션을 선택하면 ChatGPT가 이후 해당
Messages 채팅에 별도의 전송 승인 없이 메시지를 보낼 수 있습니다.

신뢰할 수 없거나 오해를 유발하는 지침이 포함될 수 있는 채팅에서는 전송할 때마다 승인하도록
설정하세요. 전송을 항상 허용하면 ChatGPT가 사용자 명의로 메시지를 보내기 전에 내용을 검토할
마지막 기회가 사라집니다. 이 위험을 감수할 수 있을 때만 사용하세요.

전송할 때마다 승인하도록 다시 설정하려면 **설정** \> **컴퓨터 사용** 메뉴를 열고
 **Messages** 옆의 **관리** 옵션을 선택하세요. **항상 전송 허용** 항목에서
해당 채팅 옆의 휴지통 아이콘을 선택한 후 **제거** 옵션을 선택해 확인하세요. ChatGPT는
다음부터 해당 채팅에 메시지를 보내기 전에 승인을 요청합니다.

**알려진 문제:** 작업에 **전체 권한** 설정을 사용하거나 다른 방식으로
승인 요청을 비활성화하면 Apple Messages가 메시지 전송에 필요한
확인 요청을 표시하지 못할 수 있습니다. **승인 요청** 또는 **대신 승인** 설정으로 전환하고 다시 시도하세요.

Apple Messages는 사용자의 Mac에서 실행됩니다. 웹이나 모바일의 ChatGPT,
Codex CLI 또는 IDE 확장에서는 직접 사용할 수 없습니다.

관리형 워크스페이스에서는 관리자가 기존 컴퓨터 사용 제어 기능으로
Apple Messages를 비활성화할 수 있습니다.

### API 키 인증 시 사용 가능 여부

[OpenAI API 키로
Codex에 로그인](/ko-KR/codex/auth#sign-in-with-an-api-key)하면 Codex CLI와 ChatGPT 데스크톱 앱의 Codex에서
OpenAI가 선별한 지원 대상 플러그인을 둘러보고 설치하거나 관리할 수 있습니다.
일부 플러그인은 연결 플로우에 지원되지 않는 OAuth 기능이 필요하므로
API 키 인증으로는 사용할 수 없습니다. 플러그인 사용량은
[플랫폼 사용량 페이지](https://platform.openai.com/usage)에서 확인하세요.

### 권한 및 데이터 공유 방식

웹에서 ChatGPT를 사용할 때 채팅과 Work는 해당 채팅에서 사용할 수 있는 워크스페이스 권한과
도구를 사용합니다. 커넥터에는 여전히 별도의 로그인과 접근 권한이 필요합니다.

플러그인 기능이 Codex 호스트를 통해 실행되면 해당 호스트의 [샌드박스 및
승인 정책](/ko-KR/codex/agent-approvals-security)이 적용됩니다.
외부 서비스에 연결할 때는 해당 서비스 자체의 인증 및
접근 제어가 적용됩니다.

- 플러그인에 포함된 스킬은 설치 후 새 채팅이나 CLI 세션을
시작하면 사용할 수 있습니다.
- 플러그인에 커넥터가 포함되어 있으면 설정 중이나 해당 커넥터를
처음 사용할 때 사용 중인 제품에서 커넥터 설치 또는 로그인을 요청할 수 있습니다.
- 플러그인에 MCP 서버가 포함되어 있으면 사용하기 전에 추가 설정이나
인증이 필요할 수 있습니다.
- ChatGPT가 플러그인에 포함된 커넥터를 통해 데이터를 전송할 때는 해당 서비스의
이용약관과 개인정보 보호 정책이 적용됩니다.

### 플러그인 제거

플러그인을 제거하려면 지원되는 플러그인 브라우저에서 해당 플러그인을 연 다음,
해당 옵션이 있으면 **플러그인 제거를** 선택하세요. 워크스페이스에서 설치한 플러그인이나
기본 플러그인에는 이 옵션이 없을 수 있습니다. 이 경우 워크스페이스
관리자가 해당 플러그인을 관리합니다.

플러그인을 제거하면 해당 ChatGPT 또는 Codex 환경에서 플러그인
번들이 제거되지만, 번들에 포함된 커넥터는 ChatGPT에서 별도로 관리할 때까지
연결된 상태로 유지됩니다.

## 자체 플러그인 빌드

플러그인을 직접 만들거나 테스트 또는 배포하려면
[플러그인 빌드](https://developers.openai.com/plugins/build/plugins)를 참고하세요. 이 페이지에서는 로컬 스캐폴딩,
마켓플레이스 수동 설정, 워크스페이스 공유, 플러그인 매니페스트와
패키징 지침을 다룹니다.

플러그인에 서버 기반 기능이 포함되어 있다면
[MCP 서버 빌드](https://developers.openai.com/plugins/build/mcp-server)를 참고하세요.
MCP 도구는 맞춤형 UI 없이 작동할 수 있으며, 시각적 인터페이스가 워크플로우에 도움이 될 때는
UI를 반환할 수도 있습니다.

플러그인을 검토받을 준비가 되면
[플러그인 제출](https://developers.openai.com/plugins/deploy/submission)에서 OpenAI 플랫폼의 제출
플로우, 필수 권한, 검토 자료, MCP 검사와
테스트 케이스 요건을 확인하세요.
