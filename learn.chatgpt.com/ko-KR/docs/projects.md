프로젝트를 사용해 관련 채팅을 정리하고 ChatGPT에 필요한 컨텍스트를 제공하세요.
ChatGPT 데스크톱 앱의 **프로젝트** 보기에는 ChatGPT 프로젝트와
컴퓨터의 폴더에 연결된 로컬 프로젝트가 표시됩니다.

## 프로젝트를 선택하거나 프로젝트 없이 시작하기

작업이 장기간 계속되거나, 결과물이 둘 이상이거나, 동일한 파일과 소스를
사용해야 하는 경우 프로젝트를 만드세요. 작업이 독립적이고 공유 프로젝트 컨텍스트가
필요하지 않으면 프로젝트 없이 채팅을 시작하세요.

관련 채팅, 파일, 지침, 소스를 한곳에 모아 관리하려면 프로젝트를 사용하세요.
한 프로젝트에 채팅 또는 ChatGPT Work로 시작한 채팅을 모두 포함할 수 있습니다.

## 프로젝트를 선택하거나 프로젝트 없이 채팅하기

작업이 장기간 계속되거나, 결과물이 둘 이상이거나, 동일한 파일과 소스를
사용해야 하는 경우 프로젝트를 만드세요. 작업이 독립적이고 공유 프로젝트 컨텍스트가
필요하지 않으면 프로젝트 없이 채팅을 시작하세요.

각 프로젝트에는 프로젝트 채팅 목록이 표시되는 **채팅** 섹션과 업로드한 파일 및 연결된 컨텍스트를 관리하는 **소스**
섹션이 있습니다. 프로젝트 지침은 해당 프로젝트의
모든 채팅에 적용됩니다. ChatGPT 프로젝트에서는 컴퓨터의
폴더에 직접 접근할 수 없으므로 ChatGPT에서 사용할 소스를 업로드하거나 연결하세요.

어느 옵션을 선택하든 공유 파일과
지침을 사용하려면 프로젝트에서 새 채팅을 시작하고 **채팅** 섹션에서 해당 채팅으로 돌아가세요.

Codex CLI는 실행한 디렉터리를 해당 채팅의 프로젝트로 간주합니다.
Codex가 작업할 디렉터리에서 `codex` 명령을 실행하거나
`--cd <directory>` (`-C`)를 전달해 디렉터리를 명시적으로 지정하세요. CLI에서는
ChatGPT 프로젝트 보기를 사용할 수 없습니다.

IDE 확장 프로그램은 IDE에서 연 폴더나 워크스페이스를 로컬
프로젝트로 간주합니다. 다중 루트 워크스페이스에서는 채팅에 사용할 워크스페이스 루트를 선택하세요.
이 확장 프로그램에서는 웹이나 데스크톱 앱의 ChatGPT 프로젝트 보기를 사용할 수 없습니다.

## 프로젝트에서 작업하기

**프로젝트** 보기에서는 ChatGPT 프로젝트와 로컬 프로젝트를 한곳에서 관리할 수 있습니다.
ChatGPT 프로젝트에서는 관련 채팅끼리 프로젝트 파일과 컨텍스트를 공유합니다.
로컬 프로젝트에서는 채팅이 컴퓨터의 소스 파일 모음이나 코드베이스 등
하나 이상의 폴더에 접근할 수 있습니다.

결과물마다 별도의 채팅을 시작하세요. 그러면 프로젝트에서 관련 작업은 함께 정리하면서도
각 채팅의 메시지와 결과에 집중할 수 있습니다.

  
    
  

## 프로젝트에서 작업하기

ChatGPT 프로젝트의 모든 채팅에서는 동일하게 업로드한 파일, 프로젝트
지침, 연결된 소스에 접근할 수 있습니다. 간단히 대화하려면 채팅을 사용하고
규모가 큰 결과물을 만들려면 ChatGPT Work를 사용하세요. 두 방식 모두 프로젝트의
**채팅** 섹션에 채팅으로 표시됩니다. 결과물마다 별도의 채팅을 시작하면
프로젝트의 공유 컨텍스트를 유지하면서 각 채팅의 메시지와 결과에 집중할 수 있습니다.

## 프로젝트 디렉터리에서 작업하기

채팅에 파일 컨텍스트를 제공할 디렉터리에서 Codex를 시작하세요.
`/new` 명령으로 결과물마다 별도의 채팅을 시작하세요. Codex가 실행 중일 때 `/resume` 명령을 사용하거나
`codex resume` 명령을 실행하면 저장된 채팅을 이어갈 수 있습니다.

채팅에는 대화 기록과 기록된 작업 디렉터리가 유지되며 Codex는
현재 작업 트리에서 파일을 읽습니다. 향후 채팅에서도 참조할 수 있도록 지속적으로 사용할 프로젝트 지침을
`AGENTS.md` 또는 버전 관리에 포함된 문서에 보관하세요.

## 워크스페이스에서 작업하기

채팅에 파일 컨텍스트를 제공할 폴더나 워크스페이스를 여세요. 결과물마다
새 채팅을 시작하고 **최근 채팅** 목록에서 해당 채팅을 선택해
계속하세요. 같은 프로젝트에 속한 채팅은 동일한 파일을 사용할 수 있지만
대화 기록은 채팅마다 별도로 유지됩니다.

현재 선택한 항목과 열려 있는 파일은 현재 턴의 컨텍스트로 사용됩니다.
향후 채팅에서도 참조할 수 있도록 지속적으로 사용할 프로젝트 지침을 `AGENTS.md` 또는 버전 관리에 포함된 문서에
보관하세요.

## 프로젝트 및 채팅 정리하기

진행 중인 작업은 잘 보이게 두고 완료한 작업은 정리하세요:

- 사이드바 상단에 계속 표시하려면 **프로젝트를 고정하세요** .
  프로젝트 보기에서도 고정할 수 있습니다.
- 자주 다시 여는 **채팅을 고정하세요** . 프로젝트에 새로운 채팅이
  추가되어도 쉽게 찾을 수 있습니다.
- **채팅 이름을 변경하세요** . “Q3
  출시 개요”나 “결제 접근성 검토”처럼 결과물을 설명하는 짧은 제목을 사용하세요.
- 프로젝트 보기에서 **프로젝트를 검색하세요** . 사이드바에서 **채팅 검색을** 
  열면 제목이 기억나지 않더라도 기억나는 문구나 브랜치 이름으로
  이전 채팅을 찾을 수 있습니다. 채팅 검색에는 기본 단축키가 없지만
   **설정 \> 키보드 단축키에서** 직접 지정할 수 있습니다.
- 작업을 마치면 **채팅을 보관하세요** . 프로젝트 메뉴에서
**채팅 보관을** 선택하면 프로젝트의 채팅을 함께 보관할 수 있습니다.

고정해도 컨텍스트가 추가되거나 ChatGPT의 접근 범위가 달라지지 않습니다.
사이드바에서 프로젝트나 채팅이 표시되는 위치만 바뀝니다.

보관된 채팅은 **설정 \> 보관된 채팅에서** 복원할 수 있습니다.

## 폴더와 코드베이스에 로컬 프로젝트 사용하기

ChatGPT가 컴퓨터의 파일을 읽거나 변경해야 한다면 로컬 프로젝트를 추가하세요.
프로젝트에 폴더가 꼭 필요한 것은 아니지만 필요에 따라 연결할 수 있습니다.

폴더를 추가하거나 변경하려면 프로젝트 메뉴를 열고 **프로젝트 편집을** 선택하세요.
여러 폴더를 연결하려면 **폴더 추가를** 선택하세요. ChatGPT는 연결된 모든 폴더의 파일을
읽고 변경할 수 있습니다. 기본 작업 디렉터리를 변경하려면 폴더에
마우스 포인터를 올리고 **기본으로 설정을** 선택하세요.

새 채팅은 기본 폴더에서 시작됩니다. Codex는 이 폴더를 Git 작업과
`AGENTS.md`, 스킬,
`config.toml` 자동 검색의 기본 위치로도 사용합니다. 보조 폴더에서도 파일 검색,
읽기, 편집이 가능하지만 Codex는 보조 폴더에 있는 이러한 프로젝트 파일을
자동으로 찾지 않습니다.

앱과 관련 문서, 웹사이트와 백엔드처럼 관련 작업이 서로 다른 위치에 있다면
여러 폴더를 사용하세요. 작업 간에 관련이 없거나 채팅별로 레포지토리의
특정 부분에만 접근해야 한다면 프로젝트를 별도로 만드세요.
이렇게 하면 작업 컨텍스트를 집중적으로 관리할 수 있습니다. 원격 프로젝트는 현재
폴더 하나만 지원합니다.

[로컬 환경](/ko-KR/codex/environments/local-environment)에서 프로젝트의 설정
작업과 자주 사용하는 명령어를 정의하세요. [검토
창](/ko-KR/codex/code-review?surface=app)에서는 같은 프로젝트에 연결된 여러 레포지토리의 변경 사항을
확인할 수 있습니다. Pull Request 및
[작업 트리](/ko-KR/codex/environments/git-worktrees) 작업은 기본
레포지토리를 대상으로 합니다. 작업 트리에서 채팅을 시작해도 다른 폴더는
연결된 상태로 유지됩니다.

프로젝트와 작업 트리는 작업을 정리하는 데 사용되지만 [샌드박스](/ko-KR/codex/sandboxing)는
로컬 명령어가 읽거나 변경할 수 있는 항목과 네트워크 접근 범위를 제한합니다.

후속 작업을 위한 채팅을 병렬로 진행할 수 있습니다.

## 간단한 질문에는 빠른 채팅 사용하기

빠른 채팅을 열면 일반 ChatGPT 채팅이 시작됩니다. ChatGPT 채팅은
Codex 채팅과 프로젝트가 표시되는 Codex 사이드바에는 나타나지 않습니다.

**새 채팅에** 마우스 포인터를 올린 다음 오른쪽에 있는 **빠른 채팅** 아이콘을 선택하세요. 또는
다음 단축키를 사용할 수 있습니다.

macOS에서는 <kbd>Cmd+Option+N</kbd>, Windows와 Linux에서는 <kbd>Ctrl+Alt+N</kbd>을 누르세요.
 **새 채팅에서** 기존 ChatGPT 채팅을 열어 Codex
채팅에 추가할 수도 있습니다.

## 다른 도구와 컨텍스트 가져오기

- 특정 요청에만 필요한 파일이나 [이미지 입력](/ko-KR/codex/image-inputs)은 해당 채팅에
  직접 첨부하세요.
- 다른 서비스의 컨텍스트와 작업 기능을 가져오려면 [플러그인](/ko-KR/codex/plugins)을

- 조직이나 개발 환경에서 Model Context Protocol을 통해 도구를 제공한다면 [MCP](/ko-KR/codex/extend/mcp) 서버를
  구성하세요.
- [메모리](/ko-KR/codex/customization/memories)를 사용할 수 있다면 이전 작업의 유용한 컨텍스트를

- 해당 요청에만 시각적 컨텍스트가 필요한 경우 [이미지 입력](/ko-KR/codex/image-inputs)을
  채팅에 전달하세요.
- 다른 서비스의 컨텍스트와 작업을 가져오려면 [플러그인](/ko-KR/codex/plugins)을
  설치하세요.
- 조직이나 개발 환경에서 Model Context Protocol을 통해 도구를 제공하는 경우
  [MCP](/ko-KR/codex/extend/mcp) 서버를 구성하세요.
- 사용 가능한 경우 [메모리](/ko-KR/codex/customization/memories)를 사용해 이전 작업의 유용한 컨텍스트를
  향후 채팅에서도 활용하세요.

- 열려 있는 파일을 참조하거나 에디터에서 코드를 선택해
현재 턴에 컨텍스트를 추가하세요.
- 조직이나 개발 환경에서 Model Context Protocol을 통해 도구를 제공하는 경우
  [MCP](/ko-KR/codex/extend/mcp) 서버를 구성하세요.
- 사용 가능한 경우 연결된 Codex 호스트의 [메모리](/ko-KR/codex/customization/memories)를 사용해
  유용한 컨텍스트를 향후 채팅에서도 활용하세요.

- 프로젝트의 모든 채팅에서 사용할 파일과 연결된 소스를 **소스** 섹션에
  추가하세요.
- 해당 채팅에만 필요한 파일이나 [이미지 입력](/ko-KR/codex/image-inputs)을
  채팅에 직접 첨부하세요.
- ChatGPT Work에서 다른 서비스의 컨텍스트와 작업을 가져오려면 [플러그인](/ko-KR/codex/plugins)을
  설치하세요.
- 사용 가능한 경우 [메모리](/ko-KR/codex/customization/memories)를 사용해 이전 작업의 유용한 컨텍스트를
  향후 채팅에서도 활용하세요.
