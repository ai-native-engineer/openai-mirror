## 친구 및 동료 초대

자격 요건을 충족하는 사용자는 앱 왼쪽 하단의
프로필 메뉴에서 Codex 초대장을 보낼 수 있습니다. 대상 개인 플랜에서는 **친구 초대를** 선택하고,
대상 Business 워크스페이스에서는 **동료 초대를** 선택하세요.
수신자의 이메일 주소를 입력한 다음 초대장을 보내세요.

초대 대화상자에는 플랜이나 프로모션에 따른 현재 보상, 수신자 요건, 초대 한도, 보상 만료 시점이 표시됩니다. 개인 및 Business 추천 프로그램에는 각각 별도의 보상과 자격 요건이 적용됩니다. 현재 ChatGPT Enterprise에서는 추천 프로그램을 이용할 수 없습니다.

2026년 6월 11일부터 6월 24일까지 자격 요건을 충족하는 Plus 및 Pro 사용자는
친구를 최대 3명까지 초대할 수 있습니다. 초대받은 사람이 자격 요건을 충족하고 첫 Codex 메시지를 보내면
두 사람 모두에게 요청 한도 초기화 1회가 적립됩니다. 적립된 요청 한도 초기화는
지급 후 30일 동안 사용할 수 있습니다. Business 추천에는 별도의
공유 워크스페이스 크레딧 보상이 적용됩니다.
초대장을 보내기 전에 [현재 약관](https://help.openai.com/en/articles/20001271)을
확인하세요.

## 자주 묻는 질문

### Sites 요금은 얼마인가요?

공개 베타 기간 동안 [Sites](/ko-KR/codex/sites)는 대상 ChatGPT 플랜에 포함됩니다.
이용 가능 여부는 플랜, 지역, 워크스페이스 설정에 따라 달라집니다.

### 내 플랜의 사용량 한도는 어떻게 되나요?

보낼 수 있는 메시지 수는 사용하는 모델, 작업의 규모와 복잡성, 로컬 또는 클라우드 실행 여부에 따라 달라집니다. 작은 스크립트나 일반적인 함수 작업은 할당된 사용량의 일부만 소모할 수 있지만, 규모가 큰 프로젝트나 장시간 실행 작업, 에이전트가 더 많은 컨텍스트를 유지해야 하는 긴 세션에서는 메시지당 사용량이 훨씬 많습니다.

비슷해 보이는 작업도 사용량은 다를 수 있습니다. 모델 선택, 컨텍스트, 추론, 도구 사용, 검색, 캐싱이 모두 사용량에 영향을 미치므로 프롬프트 길이만으로는 사용량을 정확히 예측하기 어렵습니다.

작업에 가장 적합한 GPT-5.6 모델을 선택하세요:

- **Sol은** 복잡한 추론, 모호한 문제, 고급 코딩,
  중대한 의사 결정 등 가장 어려운 작업을 위해 설계되었습니다.
- **Terra는** 프로덕션 작업, 보고서 작성, 문서 분석,
  코딩, 합리적인 판단이 필요한 업무에 일상적으로 활용할 수 있는 주력 모델입니다.
- **Luna는** 라우팅, 분류, 추출, 지원,
  백그라운드 자동화, 범위가 명확한 코딩 작업처럼
  빠른 대량 처리가 필요한 작업에 최적화되어 있습니다.

### 데스크톱의 ChatGPT 음성 대화

데스크톱의 ChatGPT 음성 대화에는 플랜에 따라 별도의 사용량 한도가 적용되며, 최근 5시간을 기준으로 사용량을 계산합니다. 음성으로 시작한 작업은 기존 Codex 사용량 한도에서 차감됩니다. 어느 한도에든 도달하면 ChatGPT가 알려줍니다.

GPT-Live는 실시간 대화를 담당합니다. 기존 Codex 작업에서 음성을 사용하면
해당 작업에서 선택한 모델이 작업을 처리합니다. 이용 가능 여부와 설정 방법은
[ChatGPT 음성 대화](/ko-KR/codex/features/voice#start-talking)를 참고하세요.

- **Plus:** 약 15~30분
- **Pro 5x(월 $100):** 약 1~2.5시간
- **Pro 20x(월 $200):** 음성 무제한 이용
- **Business:** 약 45분
- **Enterprise / Edu(레거시):** 약 45분

음성을 무제한으로 이용할 수 있어도 Codex 작업까지 무제한이 되는 것은 아닙니다. ChatGPT 음성 대화로 시작한 작업은 계속해서 기존 Codex 사용량 한도에서 차감됩니다.

크레딧 기반 과금 또는 종량제 과금을 사용하는 Business, Edu, Enterprise 워크스페이스에서는 데스크톱 음성 사용에 분당 약 6크레딧이 부과됩니다. 현재 API 키로는 데스크톱의 ChatGPT 음성 대화를 이용할 수 없습니다.

### 사용량 한도에 도달하면 어떻게 되나요?

이미 진행 중인 작업은 마무리할 수 있도록 지원하고자 합니다. 턴이 진행되는 도중 사용량 한도에 도달하더라도 에이전트는 공정 사용 한도 내에서 해당 턴의 작업을 계속할 수 있습니다.

사용량 한도에 도달한 ChatGPT Plus 및 Pro 사용자는 기존 플랜을 업그레이드하지 않고도 크레딧을 추가로 구매해 작업을 계속할 수 있습니다.

[유연한
요금제](https://help.openai.com/en/articles/11487671-flexible-pricing-for-the-enterprise-edu-and-business-plans)를 사용하는 Business, Edu 및 엔터프라이즈 플랜에서는
워크스페이스 크레딧을 추가로 구매해 작업을 계속할 수 있습니다.

사용량 한도에 가까워지면 더 작은 모델로 전환해
남은 한도 내에서 더 오래 작업할 수도 있습니다.

모든 사용자는 API 키로 로컬 채팅을 추가로 실행할 수도 있으며,
이때 사용량에는 [표준 API 요금](https://platform.openai.com/docs/pricing)이 적용됩니다.

### 이미지 생성은 사용량 한도에 어떻게 반영되나요?

이미지 생성은 로컬 메시지 및 클라우드 채팅과
동일한 일반 사용량 한도에 포함됩니다. 이미지 생성 시 이미지 품질과 크기에 따라
이미지를 생성하지 않는 유사한 턴보다 기본 제공 한도가
평균 3~5배 더 빠르게 소진됩니다. 기본 제공 한도에 도달한 후에는
이미지 생성에도 [크레딧](#credits-overview)이 사용됩니다.

Free 플랜에서는 이미지 생성을 사용할 수 없습니다. API 키로 Codex를 사용하면
이미지 생성에는 ChatGPT 기본 제공 사용량 한도 대신 API 요금이
적용됩니다.

### 현재 사용량 한도는 어디에서 확인할 수 있나요?

현재 사용량 한도는 [사용량
대시보드](https://chatgpt.com/codex/settings/usage)에서 확인할 수 있습니다. 진행 중인 Codex CLI 세션에서
남은 한도를 확인하려면 `/status`를 사용할 수 있습니다.

대시보드를 1~2주마다 확인해 사용 속도와 남은 사용 가능량을 파악하세요.
사용량이 예상보다 많다면 더 작은 모델을 사용하거나 작업 범위를 좁혀도
유용한 결과를 얻을 수 있는지 검토해 보세요.

### 토큰과 크레딧이란 무엇인가요?

토큰은 ChatGPT가 읽고 쓰는 정보의 작은 단위입니다.
프롬프트, 파일, 채팅 기록, 도구 결과, ChatGPT의 응답에는 모두
토큰이 사용됩니다.

크레딧은 크레딧 기반 플랜에서 과금 대상 사용량의 비용을 지불하는 단위입니다.
기본 제공 한도에 도달한 후에도 보유한 크레딧으로 작업을
계속할 수 있습니다. 크레딧 구매 가격과 적용 가능한 할인은 플랜이나
계약에 따라 달라집니다.

자세히 알아보세요](https://help.openai.com/en/articles/4936856-what-are-tokens-and-how-to-count-them).

기존 요율표를 계속 사용해야 합니다. 자세한 내용은
[OpenAI 영업팀에

### 코드 검토 사용량에는 무엇이 포함되나요?

코드 검토 사용량은 Codex가 GitHub에서 검토를 수행하는 경우에만 적용됩니다.
예를 들어 Pull Request에서 `@Codex`를 태그해 검토를 요청하거나 레포지토리에서
자동 검토를 활성화한 경우가 여기에 해당합니다. 로컬 또는 GitHub 외부에서 실행한
검토는 일반 사용량 한도에 포함됩니다.

### 사용량 한도 내에서 더 오래 작업하려면 어떻게 해야 하나요?

위에 제시된 사용량 한도와 크레딧은 평균값입니다.
다음 방법으로 사용량 한도를 최대한 활용해 보세요:

- **프롬프트 분량을 조절하세요.** 에이전트에게 전달하는 지시 사항은 구체적으로 작성하되,
  불필요한 컨텍스트는 제거하세요.
- **참고 자료의 범위를 제한하세요.** 관련 파일만 제공하고 가능하면
  출처나 날짜 범위를 좁히세요.
- **필요에 맞게 출력을 지정하세요.** 대상 독자, 형식, 분량을 정하고
  필수 작업과 선택적인 개선 사항을 구분하세요.
- **AGENTS.md의 분량을 줄이세요.** 규모가 큰 프로젝트에서는
  AGENTS.md 파일을 [레포지토리 내 하위
  디렉터리에 배치](/ko-KR/codex/agent-configuration/agents-md#layer-project-instructions)하여 이 파일들로 전달하는 컨텍스트의 양을 조절할 수 있습니다.
- **사용하는 MCP 서버 수를 제한하세요.** 각
[MCP](/ko-KR/codex/extend/mcp) 서버는 메시지에 컨텍스트를 추가하므로
  사용량 한도를 더 많이 소모합니다. 필요하지 않은 MCP 서버는 비활성화하세요.
- **일상적인 작업에는 더 작은 모델을 사용하세요.** GPT-5.6 Terra 또는
  GPT-5.6 Luna를 사용하면 이전에 사용하던 모델에 따라
  로컬 메시지 사용량 한도 내에서 더 오래 작업할 수 있습니다.

작업을 선택하고 범위를 정하는 방법은 [Work를
효율적으로 사용하기](/ko-KR/codex/prompting#use-work-efficiently)를 참조하세요.
