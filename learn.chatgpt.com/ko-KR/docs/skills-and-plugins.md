스킬과 플러그인은 ChatGPT와 Codex가 적절한 지침, 리소스, 도구를 활용해
반복 작업을 완료하도록 도와줍니다. 따라서 채팅할 때마다 같은
프롬프트, 템플릿, 요구 사항 또는 프로세스를 붙여 넣을 필요가 줄어듭니다.

- **스킬은** 특정
  작업이나 워크플로우에 필요한 지침과 지원 리소스를 하나로 묶습니다.
- **플러그인은** 스킬, 커넥터 또는 둘 다를 포함할 수 있는 설치형 번들입니다.
  커넥터는 Model Context Protocol (MCP) 서버를 기반으로 하며 선택적으로
  맞춤형 ChatGPT UI를 포함할 수 있습니다.

## 반복 작업에 스킬 활용하기

스킬은 ChatGPT나 Codex에 작업별 지침을 제공하는 재사용 가능한 워크플로우입니다.
기존에 반복 작업을 수행하던 방식을 담아 ChatGPT나 Codex가
그 작업을 처리할 때마다 동일한 프로세스를 따르도록 할 수 있습니다.

스킬을 구성할 때 다음 요소를 결합할 수 있습니다:

- 스킬이 적용되는 상황을 ChatGPT와 Codex가 파악하는 데 도움이 되는 이름과
설명.
- 프로세스와 예상 결과를 정의하는 워크플로우 지침.
- 템플릿, 예시, 브랜드 가이드라인, 스키마 또는 연결된 도구와 같은 지원
리소스.

좋은 결과가 반복 가능한 방식에 달려 있을 때 스킬이 가장 유용합니다. 예를
들어 스킬을 사용해 일일 브리핑을 준비하고, 문서를 검토하고, 프레젠테이션을 만들고,
팀의 글쓰기 표준을 적용하거나 매주 같은 도구에 연결해 정보를 수집할 수
있습니다.

스킬로 일관성을 높이고, 팀의 모범 사례를 워크플로우에서 활용할 수
있도록 하며, 문서화되지 않은 지식에 의존하는 대신 표준 프로세스를
공유하세요.

요청이 스킬의 용도와 일치하면 ChatGPT와 Codex가 적절한 스킬을 선택할 수 있습니다.
사용자가 직접 선택할 수도 있습니다.
스킬 멘션의 경우 ChatGPT에서는 `@` 멘션을 지원하고, Codex에서는 `$` 멘션을 지원합니다.

## 스킬 빌드

이미 반복하고 있는 작업 하나를 ChatGPT와 Codex용 플레이북으로
정리하는 것부터 시작하세요. 첫 스킬로는 주간 업데이트, 캠페인 브리핑,
회의 후속 조치나 단계와 형식을 일관되게 유지해야 하는
작업이 적합합니다.

유용한 스킬을 빌드하려면:

1. **범위가 명확한 작업 하나를 선택하세요.**
   평소 파일, 링크, 메모 등 어떤 자료로 작업을 시작하는지와 완성된 결과가 어떤 모습이어야 하는지 적어 두세요.
2. **워크플로우를 설명하세요.**
   ChatGPT에서는 `@skill-creator`로 시작하고 Codex에서는 `$skill-creator`를 사용하세요.
   목표, 따라야 할 단계, 예상 형식, 스킬에 항상 포함할 내용과 피해야 할 사항을 설명하세요.
   템플릿이나 좋은 예시가 있다면 추가하세요.
3. **초안을 검토하고 시험해 보세요.**
   지침을 확인하고 실제 상황에 가까운 요청으로 스킬을 테스트하세요.
   결과에서 단계가 누락되거나 원하는 형식에서 벗어나면 스킬을 다듬으세요.
4. **스킬을 설치하고 재사용하세요.**
   스킬이 활성화되면 ChatGPT나 Codex가 관련 요청에 사용할 수 있으며, 사용자가 직접 선택할 수도 있습니다.
   워크스페이스 설정에서 허용하는 경우 팀원과 공유할 수도 있습니다.

스킬 빌드에 관한 자세한 내용은 아래 전용 가이드를 참고하세요.

    </span>
    ChatGPT와 Codex에서 재사용 가능한 스킬을 만들고, 테스트하고, 공유하세요.
  

## 도구와 공유 워크플로우에 플러그인 활용하기

플러그인을 사용하면 재사용 가능한 기능을 더 쉽게 설치하고 공유할 수 있습니다. 또한
스킬을 GitHub, Google Drive, Slack 같은 서비스용 커넥터와 결합할 수
있으며, 추가 도구와 컨텍스트를 위한 MCP 서버를 포함할 수도 있습니다.

ChatGPT와 Codex는 하나의 통합 플러그인 디렉터리를 공유합니다. 워크플로우를 직접
만드는 대신 기존 워크플로우를 추가하려면 이 디렉터리를 살펴보세요. 플러그인을
설치한 후에는 작업을 바로 설명하거나, 사용 중인 환경에 맞는 호출 구문으로
플러그인 또는 번들에 포함된 스킬을 명시적으로 선택하세요.

[플러그인을 설치하고 사용하는 방법을 알아보세요](/ko-KR/codex/plugins).

## 스킬과 플러그인 중 선택하기

특정 작업을 위한 재사용 가능한 지침이 필요하면 스킬을 사용하세요. 지침을
연결된 서비스나 다른 도구와 결합할 수 있는 설치형 패키지가 필요하면
플러그인을 사용하세요.

[Record & Replay](/ko-KR/codex/extend/record-and-replay)로
워크플로우를 시연할 수도 있습니다. 이 기능은 녹화 내용을
재사용 가능한 스킬로 변환합니다. 자체 번들을 패키징하고 배포하는 방법은
[플러그인 빌드](https://developers.openai.com/plugins/build/plugins)를 참고하세요.

플러그인이 서비스에 연결하거나 MCP 도구를 노출해야 한다면
[MCP 서버 빌드](https://developers.openai.com/plugins/build/mcp-server)를 참고하세요. 플러그인이 공개 검토를 받을 준비가 되면
[플러그인 제출](https://developers.openai.com/plugins/deploy/submission)을 참고하세요.

재사용 가능한 워크플로우의 더 많은 예시는 [OpenAI
아카데미에서 스킬 사용하기](https://openai.com/academy/skills/)를 참고하세요.
