# 구성

ChatGPT와 Codex 개발자 도구, 재사용 가능한 워크플로우 및 외부 도구를 구성하세요

기본값을 설정하고 지속적으로 유지되는 컨텍스트를 추가하여 ChatGPT와 Codex 개발자 도구의 작동 방식을 맞춤 설정하세요.

구성에 따라 채팅, 레포지토리, 기기 전반에서 ChatGPT와 Codex 개발자 도구의 작동 방식이 달라집니다. 지속적으로 유지되는 컨텍스트, 구성 파일, 레포지토리 지침, 하위 에이전트, 외부 연결, Linux 및 Windows 설정을 함께 사용하면 개인과 팀 모두 워크플로우를 일관되게 유지할 수 있습니다.

맞춤 설정 살펴보기

ChatGPT 설정 탐색 메뉴, 구성 파일 옵션 및 성격 설정

맞춤 설정

사용 환경을 맞춤 설정하고 채팅 간에 유용한 컨텍스트를 이어서 활용하세요.

맞춤 설정 개요

지침, 스킬, MCP, 하위 에이전트를 활용해 ChatGPT와 Codex를 맞춤 설정하세요.

메모리

ChatGPT가 채팅이 바뀌어도 유용한 컨텍스트를 유지하도록 하세요.

컴퓨터 사용 기록

최근 컴퓨터 활동을 컨텍스트로 활용하고 포함할 내용을 관리하세요.

구성 파일

구성 파일과 변수를 사용해 모델, 도구, 환경, 기본값을 제어하세요.

기본 구성

구성 계층을 이해하고 구성 파일을 만드세요.

고급 구성

프로필, 공급자, 정책 및 고급 옵션을 사용하세요.

구성 참조

지원되는 모든 구성 키를 확인하세요.

환경 변수

시스템과 세션에 따라 달라지는 값을 설정하세요.

구성 예시

주석이 포함된 전체 구성 예시로 시작하세요.

에이전트 구성

에이전트가 서로 협업하고 프로젝트 지침을 따르도록 구성하세요.

AGENTS.md

Codex에 레포지토리에서 지속적으로 적용할 지침을 제공하세요.

하위 에이전트

특정 작업을 전문 에이전트에 위임하세요.

속도

Codex의 작업 속도와 깊이를 조절하세요.

규칙

Codex가 자동으로 실행할 수 있는 명령어를 정의하세요.

ChatGPT와 Codex 확장

지식을 패키징하고 서비스를 연결하며 기능을 추가하세요.

기록 및 재생

ChatGPT 또는 Codex에 워크플로우를 보여 주고 재사용 가능한 스킬로 만드세요.

MCP

Codex 개발자 도구를 외부 도구 및 컨텍스트에 연결하세요.

Linux

지원되는 Linux 데스크톱에서 ChatGPT를 설치하고 업데이트하세요.

ChatGPT 데스크톱 앱

Ubuntu, Debian 또는 Fedora에 Linux 프리뷰를 설치하세요.

Windows

Codex를 Windows에서 네이티브로 실행하거나 WSL에서 실행하세요.

PowerShell 또는 WSL 워크플로우에서 ChatGPT 데스크톱 앱을 사용하세요.

Windows 샌드박스

네이티브 파일 시스템 및 명령어 격리 기능을 사용해 Codex를 실행하세요.

WSL

Windows가 관리하는 Linux 환경에서 Codex를 사용하세요.
