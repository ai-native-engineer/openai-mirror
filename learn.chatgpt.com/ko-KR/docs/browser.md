## 주소 표시줄에서 검색

내장 브라우저의 주소 표시줄에 입력하면 방문 기록에서 페이지를 찾을 수 있습니다.

입력해 Google에서 검색하세요.

내장 브라우저는 별도의 프로필과 방문 기록을 유지합니다. 검색 결과에는 평소 사용하는
Chrome 프로필이나 다른 브라우저의 페이지가 자동으로 포함되지 않습니다.

## 방문 기록 관리

**설정 \> 브라우저를** 열면 내장 브라우저의 방문 기록을 검색하거나 방문한
페이지를 다시 열 수 있으며, 조직에서 허용하는 경우 방문 기록 항목을 삭제할 수 있습니다.
**인터넷 사용 기록 삭제에서** 삭제할 기간과 브라우저 데이터
유형을 선택하세요.

이 기능을 사용할 수 있는 경우 ChatGPT는 현재 작업과 관련된 페이지를 찾기 위해 방문 기록
검색을 요청할 수 있습니다. 액세스를 허용하기 전에 요청을 검토하세요. 방문 기록에는
내부 URL, 검색어 및 기타 민감한 정보가 포함될 수 있으므로 작업에 해당 컨텍스트가
필요한 경우에만 허용하세요.

## 개발자 모드

개발자 모드는 Chrome과 내장 브라우저에서 컴퓨터 사용 기능과 함께 사용할 수 있습니다.
이 모드를 사용하면 ChatGPT가 Chrome DevTools Protocol (CDP)에 통제된 방식으로 액세스할 수 있습니다.
JavaScript를 프로파일링하고, 콘솔 출력과 네트워크 트래픽을 검사하고, DOM과 적용된 스타일을
확인하거나 실행 중인 브라우저에서 문제를 진단할 때 사용하세요.

이 기능을 사용하려면 [**설정 \> 브라우저를**](codex://settings/browser-use) 열고,
 **개발자 모드에서** **전체 CDP 액세스 사용을** 켜세요. 조직에서
이 설정을 비활성화한 경우 로컬에서 활성화할 수 없습니다. 관리자는
[`requirements.toml`](/ko-KR/codex/enterprise/managed-configuration#pin-feature-flags)의 `[features]` 섹션에
`browser_use_full_cdp_access = false`로 설정하여 전체 CDP 액세스를 비활성화하고,
사용자가 ChatGPT 데스크톱 앱에서 해당 설정을 활성화하지 못하도록
할 수 있습니다.

전체 CDP 액세스는 민감한 브라우저 내부 정보를 노출할 수 있습니다. ChatGPT는 전체
CDP를 사용해 웹사이트를 검사하기 전에 명시적인 승인을 요청합니다. 승인하기 전에
사이트, 작업 및 요청된 액세스 권한을 검토하세요.

예:

```text

network traffic, then identify the bottleneck.

## ChatGPT Work로 웹 작업 처리하기

ChatGPT Work는 로그인이 필요한 사이트를 포함해 여러 웹사이트에서 작업을 완료할 수 있습니다.

Work는 휴대폰이나 노트북의 브라우저가 아니라 클라우드의 별도 컴퓨터에서 실행되는 자체 브라우저를 사용합니다.

웹이나 모바일의 ChatGPT Work에서 작업을 시작하면 컴퓨터를 덮고 자리를 비워도 ChatGPT가 작업을 계속할 수 있습니다. Work는 자체 컴퓨터로 웹페이지를 읽고, 클릭하고, 내용을 입력하며 인터넷에서 다양한 작업을 수행할 수 있습니다. 요청에 따라 플러그인이나 브라우저를 사용하거나 둘 다 사용할 수 있습니다.

예를 들어 ChatGPT는 다음과 같은 작업을 도와줄 수 있습니다:

- DMV 방문 일정을 찾아 예약하기
- 공공요금 서비스 계정에 로그인해 요금제 비교하기
- 조건에 맞는 아파트를 찾아 저장하기
- 소셜 미디어에서 경쟁사 조사하기
- 회계 소프트웨어에서 장부 마감하기

ChatGPT가 어떤 웹사이트에 접속할 수 있는지는 사용자가 결정합니다. ChatGPT는 예약이나 결제를 완료하는 등 중요한 영향을 미치는 작업을 수행하기 전에 확인을 요청하도록 학습되었습니다. 어떤 이유로든 ChatGPT가 진행하지 못하면 모바일과 데스크톱에서 ChatGPT의 컴퓨터 제어권을 넘겨받아 직접 사용할 수 있습니다.

ChatGPT Work가 인증이 필요한 웹사이트에 접속하는 기능은 Plus와 Pro 요금제의 웹 및 모바일 환경에서 사용할 수 있습니다.

사용 가능 여부는 단계적 출시 상황에 따라 달라집니다. 엔터프라이즈 또는 Edu 워크스페이스에서는 웹사이트 로그인 기능을 사용할 수 없습니다.

## ChatGPT Work의 컴퓨터 작동 방식

작업에 웹사이트가 필요하면 ChatGPT는 자체 브라우저로 페이지를 탐색하고, 정보를 수집하고, 온라인에서 필요한 단계를 수행합니다.

기본적으로 ChatGPT는 새 웹사이트에 접속하기 전에 승인을 요청합니다. 요청을 개별적으로 승인하거나, ChatGPT가 작업과 관련된 웹사이트 접속을 자동으로 승인하도록 설정을 변경할 수 있습니다. ChatGPT Work는 예약을 위해 사용자 정보를 제출하거나 결제를 완료하는 등 중요한 영향을 미치는 작업을 수행하기 전에 항상 확인을 요청합니다.

## 웹사이트에 로그인하기

로그인이 필요한 웹사이트에서는 ChatGPT Work가 사용자에게 로그인을 요청합니다. 인증을 마치면 로그인된 웹사이트에서 작업을 계속합니다. 세션은 이후 작업에서도 유지되므로 매번 로그인할 필요가 없습니다.

### 보안 로그인 양식 사용하기

ChatGPT는 사용자 이름이나 비밀번호를 볼 수 없습니다. 이 정보는 모델에 전혀 노출되지 않으며 모델 학습에도 사용되지 않습니다. ChatGPT는 사용자 이름이나 비밀번호를 저장하지 않습니다. **설정** \> **클라우드 브라우저** \> **브라우저 데이터에서** 언제든 모든 사이트 또는 개별 사이트의 방문 기록을 삭제할 수 있으며, 삭제하면 해당 사이트에서 로그아웃됩니다.

ChatGPT는 로그인 화면이 나타나면 작업을 일시 중지하고 로그인 정보와 필요한 경우 2단계 인증 코드를 입력하도록 요청합니다. iOS에서는 지원되는 비밀번호 관리자를 사용해 간편하게 로그인할 수 있습니다.

ChatGPT에서 제공하는 로그인 양식을 사용하세요. 채팅으로 비밀번호를 보내지 마세요.

![DMV 작업을 일시 중지하고 웹사이트 주소와 가려진 비밀번호가 있는 보안 로그인 양식을 표시하는 iOS의 ChatGPT Work.](/images/codex/cloud-browser-auth/sign-in.webp)

### 웹페이지에서 로그인하기

해당 옵션이 표시되면 **대신 웹페이지에서 로그인** 옵션을 선택해 클라우드 브라우저에서 직접 로그인하세요. 로그인하는 동안 작업은 일시 중지됩니다. **완료를** 선택해 ChatGPT에 제어권을 돌려주거나, 요청을 건너뛰거나 취소하세요.

## ChatGPT Work에서 작업 시작하기

1. 웹이나 모바일에서 ChatGPT를 열고 Work에서 작업을 시작하세요.
2. ChatGPT가 수행할 작업을 설명하세요.
3. 웹사이트 접속 승인 요청이 표시되면 승인하세요.
4. 웹사이트에서 로그인을 요구하면 직접 로그인하세요.
5. 대화에서 작업 진행 상황을 확인하세요.
6. 결과를 검토하고 중요한 영향을 미치는 작업을 승인하세요.

브라우저를 별도로 선택할 필요는 없습니다. ChatGPT가 요청에 따라 브라우저를 언제 사용할지 결정합니다.

일부 웹사이트는 접속을 차단합니다. 이런 경우 ChatGPT가 이를 알리고, 가능하면 다른 방법으로 작업을 완료하려고 시도합니다.

## 보안 및 사용자 제어

ChatGPT 설정에서 **클라우드 브라우저를** 열어 웹사이트 권한을 관리하세요. 다음과 같은 옵션을 사용할 수 있습니다:

- **항상 묻기**: 모든 웹사이트 접속 요청을 직접 검토합니다.
- **자동 승인**: ChatGPT가 웹사이트와 작업의 관련성을 확인한 후 접속을 자동으로 승인하도록 합니다.
- **항상 허용**: 추가 검토 단계 없이 웹사이트 접속을 허용합니다. 번거로움을 최소화하기 위해 제공하는 옵션이지만, 사용을 권장하지는 않습니다.

![항상 묻기, 자동 승인, 항상 허용 웹사이트 권한 옵션이 표시된 클라우드 브라우저 설정.](/images/codex/cloud-browser-auth/website-permissions.webp)

개별 웹사이트를 허용하거나 차단해 기본 권한 설정보다 우선 적용할 수도 있습니다.

ChatGPT가 웹사이트 로그인을 요청하기 전에 별도의 검토 모델이 로그인 요청과 사용자 정보가 입력될 곳을 확인해 피싱이나 기만의 징후가 있는지 검사합니다. OpenAI는 프롬프트 인젝션, 피싱, 의도하지 않은 동작 등의 위험에 대해 에이전트를 테스트합니다.

사용자가 모든 정보를 투명하게 확인할 수 있도록 웹사이트 주소와 로그인 양식 미리보기가 표시되며, 계속 진행하기 전에 실제 웹사이트를 살펴볼 수 있습니다. 보안 로그인 양식에 입력한 로그인 정보는 브라우저로 직접 전달되며 모델에는 보이지 않습니다.

## 개인정보 보호 및 브라우저 데이터

ChatGPT Work의 컴퓨터는 사용자 기기의 브라우저와 별도로 작동합니다. 자체 쿠키, 브라우저 데이터, 로그인 세션을 유지합니다. ChatGPT가 작업을 수행하는 동안 사용하는 정보에는 사용자가 선택한 ChatGPT 데이터 제어 설정이 적용됩니다. 이 설정은 웹 및 모바일 ChatGPT의 **설정** \> **데이터 제어에서** 확인할 수 있습니다.

사용자 개인 브라우저의 열린 탭, 방문 기록, 저장된 비밀번호, 쿠키, 확장 프로그램 또는 기존 로그인 세션은 사용하지 않습니다.

브라우저 데이터를 지우려면 **설정** \> **클라우드 브라우저** \> **브라우저 데이터** \> **모두 지우기로** 이동하세요. 이렇게 하면 ChatGPT Work의 브라우저로 로그인한 웹사이트에서 로그아웃되므로 이후 작업에서는 다시 로그인해야 합니다.

![브라우저 데이터 섹션과 클라우드 브라우저에 저장된 쿠키를 관리하는 쿠키 설정이 있는 클라우드 브라우저 설정 화면.](/images/codex/cloud-browser-auth/browser-data.webp)

## 제한 사항

- 웹사이트 로그인 기능은 워크스페이스와 단계적 출시 상황에 따라 제공되지 않을 수 있습니다. 작업에 지원되지 않는 로그인 방식이 필요하면 해당 단계를 직접 완료하거나 다른 사용 가능한 도구를 사용하세요.
- 일부 사이트는 자동화된 브라우저를 차단하거나 CAPTCHA를 요구합니다. 이러한 사이트에서는 ChatGPT가 작업을 완료하지 못할 수 있습니다.
- 클라우드 브라우징 사용 가능 여부는 요금제, 워크스페이스 설정 및 단계적 출시 상황에 따라 달라질 수 있습니다. Free와 Go를 제외한 유료 요금제에서는 모든 지역에서 클라우드 브라우징을 사용할 수 있습니다. 엔터프라이즈 관리자는 워크스페이스에서 클라우드 브라우징을 활성화해야 합니다.

단계적 출시 중에는 요금제에서 지원하더라도 브라우저가 즉시 표시되지 않을 수 있습니다.
