## Codex Micro 설정하기

1. ChatGPT 데스크톱 앱을 여세요.
2. 후면 버튼을 한 번 눌러 Codex Micro를 켜세요.
3. USB-C 케이블로 연결하거나 [Bluetooth로 페어링](#pair-with-bluetooth)한 다음,
   ChatGPT가 기기를 감지하면 표시되는 설정 절차를 따르세요.
4. macOS에서 메시지가 표시되면 ChatGPT가 키 입력에
   반응할 수 있도록 **입력 모니터링을** 허용하세요.
5. **설정 \> Codex Micro를** 열어 에이전트 키로 추적할 채팅 또는
   실행할 동작을 선택하고, 명령어 키, 아날로그 스틱, 다이얼을 사용자 지정하며,
   조명과 음성 컨트롤을 조정하세요.

기본적으로 다이얼을 잠시 길게 누르면 이 설정이 열립니다. ChatGPT 화면 하단에서
계정 이름 옆의 Micro 아이콘을 선택할 수도 있습니다.
다이얼에 사용자 지정 동작을 할당하면 길게 누르기 단축키를 대체할 수 있습니다.

ChatGPT가 지원되는 Micro를 처음 감지한 후에도 기기 설정을 계속 사용할 수
있습니다. ChatGPT 연동에는 Work Louder Input이 필요하지 않습니다.
다른 앱의 컨트롤을 사용자 지정하거나 레이어를 더 구성할 때 사용하세요.

## Bluetooth로 페어링하기

Codex Micro에는 Bluetooth 채널이 3개 있습니다.

1. 후면 버튼을 한 번 눌러 Micro를 켜세요.
2. 왼쪽 아래 가장자리의 터치 컨트롤을 3초 동안 길게 누르세요.
Bluetooth 모드가 활성화되면 Micro 아래쪽 조명이 파란색으로 바뀝니다.
3. 터치 컨트롤을 탭해 Bluetooth 채널 1, 2 또는 3을 선택하세요. 채널 표시등이 빠르게
깜박이면 Micro를 페어링할 준비가 된 것입니다.
4. 컴퓨터의 Bluetooth 설정을 열고 Micro가
표시되면 연결하세요.
5. 채널 표시등이 깜박이지 않고 계속 켜질 때까지 기다리세요. 그러면 페어링이 완료됩니다.

5초 동안 아무 입력이 없으면 연결 선택기가 닫힙니다. 페어링된 다른 채널로
전환하려면 선택기를 다시 열고 채널을 선택한 후 닫힐 때까지 기다리세요. 해당
채널을 다시 페어링하려면 표시등이 깜박이기 시작할 때까지 터치 컨트롤을
3초 동안 길게 누르세요.

USB-C를 대신 사용하려면 연결 선택기를 열고 Micro 아래쪽 조명이 흰색으로
바뀔 때까지 터치 컨트롤을 탭하세요. Micro가 아직 Bluetooth 모드일 때
USB-C 케이블을 연결하면 충전은 되지만 유선 연결로
전환되지는 않습니다.

하드웨어 다이어그램은 [Work Louder Codex Micro 설정
가이드](https://worklouder.cc/openai-micro-setup)를 참조하세요.

## 에이전트 키로 채팅 확인 및 전환하기

반투명 에이전트 키 6개는 각각 채팅 하나를 추적하며, 조명으로 현재
상태를 표시합니다. 에이전트 키를 한 번 누르면 ChatGPT 창을 전면으로 가져오지 않고
해당 채팅으로 전환합니다. 350밀리초 이내에 두 번 누르면 채팅으로 전환되고
ChatGPT 창도 전면으로 이동합니다. 한 번만 눌러도 ChatGPT에 포커스를 맞추려면 기기 설정에서
**한 번 탭하여 ChatGPT에 포커스 맞추기** 옵션을 켜세요.

| 조명 | 상태           | 의미                                   |
| ----- | ---------------- | ----------------------------------------- |
| 흰색 | 대기             | 채팅이 대기 상태입니다.                         |
| 파란색  | 생각 중         | ChatGPT가 작업 중입니다.                       |
| 초록색 | 완료         | 채팅이 완료되었으며 읽지 않은 업데이트가 있습니다. |
| 황색 | 입력 필요   | ChatGPT에 사용자의 승인이나 응답이 필요합니다.  |
| 빨간색   | 오류            | 문제가 발생했습니다.                     |
| 꺼짐   | 할당된 채팅 없음 | 키가 채팅을 추적하지 않습니다.            |

선택한 채팅의 키는 상태 표시등 색상으로 서서히 깜박입니다.

기본적으로 키는 고정 여부와 관계없이 가장 최근에 업데이트된 채팅 6개를
추적합니다. 다른 구성을 사용하려면 기기 설정에서 **에이전트 키** 항목을
변경하세요:

- **최근 채팅**: 고정 여부와 관계없이 가장 최근에 업데이트된 채팅 6개를
  추적합니다.
- **고정된 채팅**: **고정됨** 목록에서 처음 6개 채팅을 추적합니다.
- **우선 채팅**: 입력을 기다리는 채팅, 읽지 않은 채팅, 활성
  채팅을 먼저 배치합니다.
- **사용자 지정 할당**: 각 에이전트 키에 채팅, 단축키, 물리적 키 동작 또는 활성화된
  스킬을 할당합니다. 할당되지 않은 에이전트 키를 누르면 새 채팅이 열립니다.
  채팅을 시작하면 ChatGPT가 해당 키에 채팅을 할당합니다.

채팅을 추적하는 키의 상태 색상은 그대로 유지됩니다. **사용자 지정
할당을** 사용하면 에이전트 키가 대신 동작을 실행할 수 있습니다.

## 명령어 키 사용 및 사용자 지정

Codex Micro의 기본 레이아웃에는 다음 6가지 동작이 있습니다:

|                            키                            | 기본 동작                           |
| :-------------------------------------------------------: | ---------------------------------------- |
|     | 패스트 모드를 켜거나 끕니다.                |
|  | 현재 요청을 승인합니다.             |
|   | 현재 요청을 거부합니다.             |
|    | 현재 채팅을 새 채팅에서 이어갑니다. |
|       | 눌러서 말하기를 시작합니다.                      |
|   | Composer에 입력된 메시지를 전송합니다.        |

마이크 키는 컴퓨터의 마이크를 사용합니다. Codex Micro에는 자체
마이크가 없습니다. 기본적으로 **눌러서 말하기** 기능을 사용합니다. 말하는 동안
키를 누르고 있다가 말을 마치면 놓으세요. 손을 대지 않고 계속 녹음하려면
350밀리초 이내에 키를 두 번 누르세요. 녹음을 중지하려면 다시 누르세요.

녹음하는 동안 청록색 불빛이 키보드 주위를 움직입니다. ChatGPT가 음성을
처리하는 동안에는 움직이는 흰색 불빛으로 바뀌고, 프롬프트가 준비되면 흰색으로
계속 켜집니다. 전송하려면 Codex 키를 누르세요.

**마이크 키** 아래에 **음성 채팅** 옵션이 있다면 선택하세요. 그러면
마이크 키로 음성 채팅을 시작하거나 마이크를 켜고 끌 수 있습니다. 키를
길게 누르면 음성 채팅이 종료됩니다. 넓은 마이크 키 아래의 두 스위치를 각각
매핑하려면 **별도의 마이크 키 사용** 옵션을 켜세요.

기기 설정의 **레이아웃** 미리보기에서 명령어 키를 선택한 다음
키캡과 동작을 선택하세요. 브라우저 또는 터미널 열기, 채팅 관리,
변경 사항 검토, Git 및 Pull Request 작업 실행, 파일 또는 사진 첨부,
플러그인 또는 예약 작업 열기, 추론 노력 수준 변경, 활성화된 스킬 실행,
다른 단축키 할당 등을 선택할 수 있습니다. 이미 다른 곳에서 사용 중인
키캡을 선택하면 ChatGPT는 하나의 키캡을 중복 사용하지 않고 두 키캡을 서로 바꿉니다.

키를 다시 매핑한 후에는 실제 키캡도 새 동작에 맞는 것으로 교체하세요.
에이전트 키 모드나 사용자 지정 채팅 할당을 변경하지 않고 명령어 키와 아날로그 스틱의
기본 할당을 복원하려면 **레이아웃 재설정** 옵션을 선택하세요.

## 아날로그 스틱과 다이얼 사용하기

<div class="grid gap-6 md:grid-cols-[minmax(0,1fr)_minmax(16rem,42%)] md:items-start">
  <div class="min-w-0">

아날로그 스틱은 어느 방향으로든 자유롭게 움직입니다. 중심에서 충분히 멀리
밀면 ChatGPT가 움직임을 네 가지 방향 동작 중 하나로 변환합니다. Codex Micro의
기본 매핑은 다음과 같습니다.

기기 설정에서 각 방향에 사용할 수 있는 ChatGPT 데스크톱 명령어나 활성화된
스킬을 선택하세요.

  </div>
  <div class="min-w-0 [&_table]:!mt-0">

| 방향 | 기본 동작             |
| --------- | -------------------------- |
| 위        | 플랜 모드를 켜거나 끕니다.  |
| 오른쪽     | 앱 탐색 기록에서 앞으로 이동합니다. |
| 아래      | 사이드바를 표시하거나 숨깁니다.  |
| 왼쪽      | 앱 탐색 기록에서 뒤로 이동합니다.    |

  </div>
</div>

다이얼은 기본적으로 **Composer 탐색** 모드를 사용합니다. 다이얼을 돌려
Composer 컨트롤과 옵션 사이를 이동한 다음, 눌러서 포커스된 컨트롤을
열거나 선택하세요. Composer 컨트롤이나 메뉴가 열려 있으면 다이얼 바로 오른쪽의
에이전트 키에 빨간불이 켜집니다. 취소하려면 해당 키를 누르세요.

기기 설정에서 다음 네 가지 다이얼 모드 중 하나를 선택하세요:

| 모드                       | 작동 방식                                                                       |
| -------------------------- | ------------------------------------------------------------------------------ |
| **Composer 탐색**    | Composer 컨트롤 사이를 이동하고 포커스된 컨트롤을 선택합니다.                 |
| **추론 전용**         | 추론 노력 수준을 조정하고 해당 슬라이더나 고급 옵션을 엽니다.               |
| **대화 스크롤** | 활성 채팅을 스크롤합니다. 다이얼을 누르면 최신 메시지로 이동합니다.          |
| **사용자 지정 할당**     | 왼쪽 회전, 오른쪽 회전, 누르기, 길게 누르기에 각각 동작이나 스킬을 할당합니다. |

모든 모드에서 다이얼을 길게 누르면 기기 설정이 열립니다. 단,
**사용자 지정 할당** 모드에서는 길게 누르기에 할당된 동작이 실행됩니다.

## Codex Micro 문제 해결

### macOS에서 입력 모니터링 문제 해결

기기 설정에 입력 모니터링이 설정되지 않은 것으로 표시되면 **시스템 설정
열기** 옵션을 선택하고 다음 단계를 따르세요:

1. **시스템 설정 \> 개인정보 보호 및 보안 \> 입력 모니터링** 화면을 여세요.
2. ChatGPT가 이미 목록에 있으면 접근 권한을 켜세요. 없다면 응용 프로그램 폴더에서
**ChatGPT** 앱을 목록으로 드래그하거나 **추가(+)** 버튼을 선택한 다음
**ChatGPT** 앱을 선택하세요.
3. ChatGPT를 종료했다가 다시 열고, 레이어 1에서 Micro가 감지되는지 확인하세요.

이 macOS 권한에 대한 자세한 내용은 [Apple의 입력 모니터링
가이드](https://support.apple.com/guide/mac-help/mchl4cedafb6/mac)를 참조하세요.

### 연결 간섭 문제 해결

ChatGPT는 Micro를 감지했지만 연결할 수 없거나 통신이 끊어지면 자동으로
다시 시도합니다. 문제가 계속되면 Micro를 다시 연결하고 키보드 유틸리티나
보안 도구가 Micro에 대한 접근을 차단하는지 확인하세요.

{/* vale Vale.Spelling = NO */}

Work Louder에 따르면 macOS에서 Karabiner와 Logitech Options+에 입력 모니터링
권한이 있으면 이러한 앱이 Micro 통신을 방해할 수 있습니다. 간섭 여부를
테스트하려면 키보드 유틸리티를 종료하거나 입력 모니터링 접근 권한을 일시적으로
끈 다음 Micro를 다시 연결하세요. 조직에서 컴퓨터를 관리하는 경우 IT 관리자에게
기기 규칙을 확인해 달라고 요청하세요.

{/* vale Vale.Spelling = YES */}
