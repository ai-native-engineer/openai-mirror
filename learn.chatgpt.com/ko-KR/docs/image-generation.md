ChatGPT에 이미지 생성 또는 편집을 요청하세요. 코드와 함께 또는 ChatGPT 채팅에서 만들고 싶은 UI 에셋,
배너, 배경, 일러스트레이션, 스프라이트 시트, 플레이스홀더에 이미지 생성을
활용하세요.

앱의 Composer에서 이미지를 요청하세요. ChatGPT가 기존 에셋을 변환하거나 시각적
가이드로 활용하게 하려면 참조 이미지를 추가하세요.

### 생성된 이미지 검토 및 편집

생성된 이미지를 선택해 확대 뷰어로 여세요.
이미지 하나를 살펴보려면 **집중 보기로**, 같은 채팅에서 생성된 이미지를 보려면
**캔버스 보기로** 전환하세요.

**캔버스 보기에서** **댓글을** 사용해 하나 이상의 이미지에 구체적인 피드백을
추가하세요. 포함할 이미지를 고르려면 **다중 선택을** 선택한 다음, 같은 채팅에서
댓글과 추가 편집 지침을 보내세요.
변경할 부분과 그대로 유지할 부분을 설명하세요.

ChatGPT 웹 채팅에서 이미지를 요청하세요. ChatGPT가 참조 이미지를 편집하거나
시각적 가이드로 활용하게 하려면 Composer에 참조 이미지를 첨부하세요.

대화형 세션에서 이미지를 설명하거나, 이미지 생성 스킬을 명시적으로 호출하려면
프롬프트에 `$imagegen`을 포함하세요. 결과에 참고할 기존 이미지는 `-i` 또는
`--image`로 첨부하세요.

확장 프로그램 채팅에서 이미지를 요청하세요. Codex가 기존 에셋을 편집하거나
이를 바탕으로 새 이미지를 만들게 하려면 <kbd>Shift</kbd>를 누른 채 Composer로 참조 이미지를
드래그하세요.

## 이미지 생성 또는 편집

이미지를 자연어로 설명하세요. ChatGPT가 기존 에셋을 변환하거나 확장하게 하려면
참조 이미지를 추가하세요.

이미지 생성 스킬을 명시적으로 호출하려면 프롬프트에 `$imagegen`을
포함하세요.

내장 이미지 생성은 `gpt-image-2`를 사용하며 일반 Codex 사용 한도에서
차감됩니다. 이미지 생성은 품질과 크기에 따라 이미지 생성이 없는 유사한 턴보다
기본 제공 한도를 평균 3–5배 더 빠르게 소진합니다.
더 큰 배치를 처리하려면 환경에 `OPENAI_API_KEY`를 설정하고 ChatGPT에 API를 통해
이미지를 생성하도록 요청하세요. 그러면 API 요금이 적용됩니다.

ChatGPT 웹의 이미지 사용 가능 여부와 사용 한도는 플랜 및
워크스페이스 설정에 따라 달라집니다. 프로그래밍 방식으로 이미지를 생성하려면 [이미지
생성 API](/api/docs/guides/image-generation)를 사용하세요.

## 효과적인 이미지 프롬프트 작성

효과적인 이미지 프롬프트는 명확한 문장 1~3개면 충분한 경우가 많습니다. 결과의
성패를 좌우하는 세부 정보를 설명하세요:

- 이미지의 용도나 대상 사용자를 설명하세요.
- 주요 피사체와 무슨 일이 벌어지고 있는지 설명하세요.
- 배경, 구도, 시각적 스타일을 설명하세요.
- 중요한 경우 프레이밍, 크기, 조명, 색상 또는 소재를 추가하세요.
- 이미지에 포함하면 안 되는 요소를 비롯한 제약 조건을 명시하세요.

막연한 표현보다 구체적인 시각 언어를 사용하세요. 예를 들어 “아름다운 조명”을 요청하는
대신 빛이 어디에서 들어오는지 설명하세요. 반드시 유지해야 하는 요구 사항은
반복해서 명시하세요.

## 결과 다듬기

핵심 아이디어로 시작한 다음, 범위를 좀혀 조금씩 수정하세요. 구도와 그 밖의 중요한
세부 정보가 달라지지 않도록 한 번에 한 요소씩 조정하세요. 이미지에서 특정 영역을
선택하고 해당 영역에 적용할 변경 사항을 설명할 수도
있습니다.

기존 이미지를 편집할 때는 변경할 부분과 그대로 유지할 부분을 정확히
설명하세요.

범위가 넓은 수정을 요청할 때는 피드백을 명확하고 바로 적용할 수 있게 작성하세요. 이미지를 더
밝게 만들거나, 색상 채도를 낮추거나, 배경을 단순화하거나, 구도는 유지한 채
스타일을 바꾸라고 요청하세요.

## 여러 참조 이미지 사용

한 이미지가 콘텐츠를 정하고 다른 이미지가 스타일, 레이아웃 또는 기타 시각적 방향을
정하는 경우에는 소수의 참조 이미지를 사용하세요. 각 이미지를 순서대로 구분하고
서로 어떤 관계인지 설명하세요. 요소를 결합할 때는 전경, 배경, 왼쪽, 오른쪽과 같은
공간 용어를 사용하세요.

## 이미지에 텍스트 추가

이미지 속 텍스트는 짧게 유지하고 정확하게 지정하세요. 정확한 문구를 따옴표 안에
넣고, 원하는 대소문자 표기를 유지하며 글꼴 스타일, 크기, 색상, 위치를 설명하세요.
생소한 이름은 정확성이 중요할 때 글자를 하나씩
적으세요. 다른 텍스트를 허용하는지도 명시하세요.

## 인포그래픽과 정보 밀도가 높은 레이아웃 만들기

이미지 생성은 설명 자료, 포스터, 라벨이 포함된 다이어그램,
타임라인 등 정보가 풍부한 시각 자료의 초안을 만드는 데 유용합니다. 정보
계층 구조와 레이아웃을 설명하고, 라벨을 간결하게 유지하며, 텍스트가 선명하게 렌더링되도록 요청하세요.
문구가 빽빽하거나 프로덕션에서 타이포그래피가 중요한 경우, 모든 단어를 검토하고 필요하면
디자인 도구에서 에셋을 완성하세요.

## 추가 고려 사항

- **인물의 초상은 신중하게 사용하세요.** 실제 인물을 묘사할 때는 적절한 경우
  참조 사진을 제공하고, 해당 인물의 초상을 사용할 허가를 받았는지
  확인하세요.
- **독창적인 표현을 요청하세요.** 특정 브랜드, 제품, 아티스트 또는 작품을 모방하지 말고
  일반적이거나 독창적인 디자인을 요청하세요.
- **출처 표기는 선택 사항입니다.** 생성된 이미지에 OpenAI를 출처로 표시할 필요는 없지만,
  해당 정보가 유용하다면 에셋이 어떻게 만들어졌는지 설명할 수 있습니다.
- **적용되는 정책을 준수하세요.** 조직의
  가이드라인과 [OpenAI 사용
  정책](https://openai.com/policies/usage-policies/)에 따라 이미지를 사용하세요.
