## 권한 모드

권한은 ChatGPT(데스크톱 앱)와 Codex(CLI 또는 IDE)가 파일 편집, 명령 실행, 인터넷 사용 같은 로컬 작업을 처리하는 방식을 제어합니다. 선택한 모드는 ChatGPT가 자체적으로 수행할 수 있는 작업과 검토가 필요한 작업의 경계를
설정합니다.

대부분의 작업에서는 먼저 **승인 요청** 모드를 사용하세요. 이 모드에서는 ChatGPT가 현재
워크스페이스 내에서 작업할 수 있으며, 해당 경계를 벗어나기 전에 일시 중지합니다.

아래에서 모드를 선택하여 각각의 작동 방식을 알아보세요.

## 모드 활성화

ChatGPT 데스크톱 앱을 처음 사용하는 경우 애플리케이션 설정에서 모드를 활성화해야 합니다.

**승인 요청은** 항상 사용할 수 있습니다. 권한 메뉴에 **대신 승인**(설정에서는
**자동 검토로** 표시됨) 또는 **전체 권한을** 추가하려면 ChatGPT 데스크톱 앱에서
**설정 \> 일반을** 연 다음 **권한에서**
해당 모드를 켜세요. 모드를 활성화하면 메뉴에서 사용할 수 있게 될 뿐, 해당 모드가
자동으로 선택되거나 기존 채팅에 적용되지는 않습니다.

  

  사용 가능한 모드는 로컬 구성과 조직의 요구사항에 따라 달라질 수
있습니다. 허용되지 않는 모드는 비활성화되어 표시됩니다.

## 권한 작동 방식

다음 두 가지 제어 방식이 함께 작동합니다:

- **샌드박스는** ChatGPT가 액세스할 수 있는 파일과 네트워크 리소스를 결정합니다.
- **승인은** ChatGPT가 작업 전에 일시 중지하거나 요청을
  자동 검토로 보내는 시점을 결정합니다.

요청의 검토 주체를 바꿔도 샌드박스 범위는 확장되지 않습니다. 예를 들어
**대신 승인** 모드는 **승인 요청** 모드와 동일한 워크스페이스 경계를 유지하며,
해당 경계를 벗어나는 작업에 관한 요청을 자동 검토로 보냅니다.

ChatGPT 데스크톱 앱이나
IDE 확장에서 Composer 아래에 있는 권한 제어를 사용하세요.

CLI에서는 `/permissions`을 입력하세요. 자세한 기술 정보는
[샌드박스](/ko-KR/codex/sandboxing), [자동 검토](/ko-KR/codex/sandboxing/auto-review),
[권한 프로필](/ko-KR/codex/permissions) 문서를 참조하세요.
