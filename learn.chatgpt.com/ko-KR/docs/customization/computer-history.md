## 컴퓨터 사용 기록의 작동 방식

컴퓨터 사용 기록은 허용된 앱과 웹사이트의 상호작용 이벤트 스트림을 생성합니다. 이벤트에는 클릭, 키 입력, 키보드 단축키, 앱 전환, 그리고 macOS 접근성 시스템이 제공하는 컨텍스트가 포함될 수 있습니다. 컴퓨터 사용 기록은 이러한 이벤트를 정기적으로 텍스트 요약과 로컬 메모리 파일로 변환합니다.

컴퓨터 사용 기록은 스크린샷을 기록에 포함하지 않으며 마이크 입력이나 시스템 오디오도 녹음하지 않습니다. 비공개 모드의 웹 탐색 활동은 절대 포함되지 않습니다.

**설정 \> 컴퓨터 사용 기록 \> 기록** 화면의 타임라인에서는 요약이
날짜와 시간별로 정리됩니다. 각 항목에는 다음 정보가 표시될 수 있습니다:

- 활동의 제목과 텍스트 요약.
- 요약 생성에 사용된 앱.
- ChatGPT가 반복 가능한 작업을 식별했을 때 제안하는 스킬 또는 자동화.
- Finder에서 메모리 파일을 표시하거나 항목을 삭제하는 작업.

컴퓨터 사용 기록을 활용한 채팅을 시작하려면 **사용 기록에 관해 질문하기** 항목을 선택하거나
다음과 같은 프롬프트를 사용하세요:

- “마지막으로 쉬기 전에는 어떤 작업을 하고 있었나요?”
- “오늘 아까 찾던 제안 문서는 어디에 있나요?”
- “오늘 진행한 작업 목록과 각 작업의 상태를 알려 주세요.”
- “스탠드업 미팅을 위해 어제 한 일을 요약해 주세요.”

## 권한 및 접근

컴퓨터 사용 기록은 워크스페이스 접근 권한, 개인별 사용 동의, 메모리, 그리고 기록에 포함할 앱이나 웹사이트를 각각 별도로 관리합니다:

- **워크스페이스 접근 권한:** 컴퓨터 사용 기록은 Business 및
  엔터프라이즈 워크스페이스에서 기본적으로 꺼져 있으며, 관리자가
  명시적으로 접근 권한을 부여하기 전까지 사용할 수 없습니다. 엔터프라이즈 관리자는 **컴퓨터
  사용 기록 활성화** 옵션을 [**워크스페이스 설정 \> 권한 및 역할**](https://chatgpt.com/admin/settings) 화면에서
  사용해 적절한 워크스페이스 역할에 접근 권한을 부여할 수 있습니다.
- **개인별 사용 동의:** 워크스페이스 접근 권한을 부여하면 구성원이 컴퓨터 사용 기록을
  켤지 선택할 수 있게 될 뿐, 누구에게도 이 기능이 자동으로 활성화되지는 않습니다. ChatGPT Pro 사용자를 포함해
  모든 사용자가 개별적으로 사용에 동의해야 합니다.
- **메모리:** 컴퓨터 사용 기록을 사용하려면 [메모리](/ko-KR/codex/customization/memories) 기능도 필요합니다.
  `/memories` 명령어를 사용해 개별 채팅에서 로컬 메모리를 사용할 수 있는지,
  또는 향후 메모리 생성에 기여할 수 있는지를 제어하세요.
- **앱 및 웹사이트:** 앱과 웹사이트의 권한 설정에 따라 상호작용 이벤트를 제공할 수 있는
  소스가 결정됩니다. 특정 소스만 허용하거나,
  포함하지 않으려는 앱과 웹사이트 URL을 제외할 수 있습니다.

워크스페이스 역할에 접근 권한이 없다면 로컬 설정을 변경해도 컴퓨터 사용 기록을 활성화할 수 없습니다.

## 컴퓨터 사용 기록 켜기

컴퓨터 사용 기록은 기본적으로 꺼져 있습니다. Business 또는 엔터프라이즈 워크스페이스를 사용하는 경우 기능을 켜기 전에 관리자에게 접근 권한을 요청하세요. 관리자 승인이 개인별 사용 동의를 대신하지는 않습니다.

1. macOS에서 ChatGPT 데스크톱 앱을 여세요.
2. 설정의 **통합** 섹션에서 **컴퓨터 사용 기록** 항목을 선택하세요.
3. **켜기** 버튼을 선택하고 개인정보 보호, 권한 및 로컬 저장소
   관련 정보를 검토하세요.
4. 안내가 표시되면 **메모리** 기능을 켜세요. 컴퓨터 사용 기록이 채팅과 작업 전반에서
   활동 컨텍스트를 사용하려면 메모리가 필요합니다.
5. 기록에 포함할 앱과 웹사이트를 선택한 다음 macOS 권한 요청 메시지에 따라 설정하세요.

컴퓨터 사용 기록에는 화면 녹화 권한이 필요하지 않습니다. 설정이 표시되지 않으면 사용 중인 요금제에서 컴퓨터 사용 기록을 지원하는지 확인하고, 해당하는 경우 워크스페이스 관리자가 이 기능을 활성화했는지 확인하세요.

## 포함할 항목 관리

향후 기록에 반영할 앱과 웹사이트, 그리고 컴퓨터 사용 기록의 상호작용 이벤트 수집 여부를 직접 관리할 수 있습니다.

### 앱과 웹사이트 선택

**설정 \> 컴퓨터 사용 기록 \> 권한** 화면에서 기록에 포함할 앱과
웹사이트를 선택하세요:

- **다음 앱 제외** 및 **다음 웹사이트 제외** 옵션은 지정한 앱이나 URL을
  차단하고, 지원되는 다른 소스는 허용합니다.
- **다음 앱만 포함** 및 **다음 웹사이트만 포함** 옵션은
  직접 선택한 소스만 허용합니다.

기록 타임라인 항목에서 앱 아이콘을 선택해 해당 앱을 향후 기록에서 제외할 수도 있습니다. 나중에 다시 포함할 수 있습니다.

비공개 모드의 웹 탐색 활동은 절대 포함되지 않습니다. 앱이나 웹사이트 권한을 변경하면 이후의 기록에만 적용됩니다. 기존 항목을 제거하려면 해당 항목을 삭제하거나 기록을 지우세요.

### 수집 일시 중지, 재개 또는 중단

컴퓨터 사용 기록 설정이나 macOS 메뉴 막대에서 활동 수집 시점을 관리할 수 있습니다:

- macOS 메뉴 막대에서 ChatGPT 아이콘을 선택하고 컴퓨터 사용 기록 메뉴를 펼치면 수집되는 활동을 확인하고 관련 설정을 관리할 수 있습니다.
- **일시 중지** 버튼을 선택하면 새 상호작용 이벤트 수집이 중단됩니다.
다시 시작하려면 **재개** 버튼을 선택하세요.
- 향후 활동 수집을 중단하려면 컴퓨터 사용 기록을 끄세요.

컴퓨터 사용 기록에는 커뮤니케이션 앱과 웹사이트의 상호작용 이벤트가 포함될 수 있습니다. 다른 사람과 소통할 때는 상대방의 명시적인 사전 동의를 받지 않았다면 기능을 끄세요. 민감한 건강 정보, 금융 정보 또는 개인정보가 포함된 앱은 제외하거나 수집을 일시 중지하는 것이 좋습니다.

## 기록 검토 및 삭제

**설정 \> 컴퓨터 사용 기록 \> 기록** 화면을 열어 컴퓨터 사용 기록이 요약한

개별 타임라인 항목을 삭제할 수 있습니다. 최근 10분, 최근 1시간, 최근 하루 또는

마지막 세션을 삭제할 수도 있습니다.

기록을 지우면 관련 상호작용 이벤트와 그 이벤트에서 생성된 모든 메모리가 삭제됩니다. 삭제된 기록은 복구할 수 없습니다.

## 개인정보 보호 및 로컬 저장소

컴퓨터 사용 기록은 ChatGPT와 Codex가 메모리를 생성하고 추천 워크플로우를 만들 수 있도록 상호작용 이벤트 스트림을 Mac에 임시로 저장합니다. 이 스트림에는 클릭이나 키 입력 같은 활동과 macOS 접근성 기능을 통해 제공되는 텍스트 및 기타 컨텍스트가 포함될 수 있습니다. 컴퓨터 사용 기록은 스크린샷을 기록에 포함하지 않으며 마이크 입력이나 시스템 오디오도 녹음하지 않습니다. 비공개 모드의 웹 탐색 활동은 절대 포함되지 않습니다.

임시 이벤트 파일은 최대 48시간 동안 보관됩니다. 생성된 메모리 파일은 직접 삭제하거나 기록을 지우기 전까지 파일 시스템에 남아 있으며, 기록 타임라인에서 해당 파일을 확인할 수 있습니다.

### 컴퓨터 사용 기록의 데이터는 어디에 저장되나요?

컴퓨터 사용 기록은 상호작용 이벤트를 Mac에 임시로 저장합니다.
이벤트 파일은 ChatGPT의
[App Group](https://developer.apple.com/documentation/xcode/protecting-local-app-data-using-containers) 내부에 격리되어 저장되므로,
다른 앱은 명시적인 허가 없이는 해당 파일에 접근할 수 없습니다.
ChatGPT와 Codex는 이 이벤트 파일을 48시간 후에 삭제합니다.

컴퓨터 사용 기록은 Codex와 동일한 유형의 로컬 메모리를 생성합니다. 이는 직접 읽고 수정할 수 있는
일반 텍스트 형식의 Markdown 파일입니다. 파일은
`$CODEX_HOME/memories/extensions/skysight/` 경로에 저장되며, 이 경로는 일반적으로
`~/.codex/memories/extensions/skysight/` 경로를 가리킵니다.

### 어떤 데이터가 OpenAI와 공유되나요?

컴퓨터 사용 기록은 상호작용 이벤트를 로컬에 수집한 후, 주기적으로 상호작용 이벤트 스트림에 접근할 수 있는 임시 Codex 세션을 시작해 활동을 메모리로 요약합니다.

OpenAI는 서버에서 임시 이벤트 파일을 처리해 메모리를 생성하며, 생성된 메모리는 Mac에 로컬로 저장됩니다. OpenAI는 법적으로 요구되는 경우를 제외하고 처리 후 해당 이벤트 파일을 보관하지 않으며, 파일을 학습에 사용하지 않습니다.

ChatGPT나 Codex가 이후 채팅에서 메모리를 사용하면 관련 메모리 내용과
상호작용 이벤트가 컨텍스트에 포함될 수 있습니다. 이러한 채팅 내용은
OpenAI 모델 개선에 사용될 수 있으며, 이는
[ChatGPT 데이터 제어 설정](https://help.openai.com/en/articles/7730893-data-controls-faq)에서 허용한 경우에만 해당합니다.

### 프롬프트 인젝션 위험

컴퓨터 사용 기록을 사용하면 앱과 웹사이트의 콘텐츠를 통한 프롬프트 인젝션 위험이 커집니다. 예를 들어 악의적인 지침이 포함된 웹사이트를 방문하면 ChatGPT나 Codex가 해당 지침을 따를 수 있습니다.

## 토큰 사용량

컴퓨터 사용 기록은 활동을 요약하고 메모리를 생성하는 과정에서 토큰을 사용합니다.

## 문제 해결

컴퓨터 사용 기록을 사용할 수 있지만 실행되지 않는 경우:

1. **메모리** 기능이 켜져 있는지 확인하세요.
2. **설정 \> 컴퓨터 사용 기록** 화면을 열고 표시된 상태에 따라 **설정 완료**, **재개**,
   또는 **다시 시도** 항목을 선택하세요.
3. 설정을 계속 사용할 수 없다면 ChatGPT 데스크톱 앱을 종료했다가 다시 여세요.
