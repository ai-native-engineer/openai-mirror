# 보안

ChatGPT 및 Codex 개발자 도구의 권한, 보안 및 안전 제어를 관리합니다

ChatGPT 및 Codex 개발자 도구의 액세스 대상을 제어하고, 작업이 격리되는 방식을 이해하며, 보안에 민감한 작업에 보호 조치를 적용합니다.

보안 제어는 ChatGPT 및 Codex 개발자 도구의 액세스 대상과 민감한 동작의 검토 방식을 정의합니다. 권한, 샌드박스, 승인 및 네트워크 액세스를 통해 신뢰 경계를 설정합니다. Codex Security는 취약점을 찾아 해결하는 데 도움을 주며, 사이버 안전 지침에서는 보안에 민감한 작업을 처리하는 방식을 설명합니다.

권한 살펴보기

기본, 자동, 전체, 사용자 지정 액세스를 위한 ChatGPT 승인 옵션

권한

파일 시스템, 네트워크, 명령어, 승인 및 검토 동작을 제어합니다.

파일 시스템, 명령어 실행 및 네트워크 액세스에 사용할 프로필을 선택합니다.

샌드박스

Codex가 명령 실행과 파일 변경 사항을 격리하는 방식을 알아봅니다.

자동 검토

구성한 정책에 따라 동작을 자동으로 검토합니다.

에이전트 승인 및 보안

Codex가 동작을 수행하기 전에 승인을 요청해야 하는 시점을 정합니다.

인터넷 액세스

클라우드 채팅에서 액세스할 수 있는 도메인을 제어합니다.

Codex Security

취약점을 찾고 분석하여 해결합니다.

Codex Security 개요

코드를 평가하고 검토된 보안 이슈를 바탕으로 필요한 부분을 정확히 수정합니다.

Codex Security 플러그인

ChatGPT 데스크톱 앱과 Codex CLI에서 보안 워크플로우를 실행합니다.

Codex Security CLI

로컬에서 보안 스캔을 실행하고 레포지토리 검토를 자동화합니다.

Codex Security TypeScript SDK

보안 스캔과 진행 상황 보고를 개발자 도구에 통합합니다.

Codex Security 클라우드 설정

레포지토리를 연결하고 클라우드 보안 스캔을 구성합니다.

보안 검토

GitHub Pull Request에 대해 심층 보안 검토를 실행합니다.

위협 모델

코드베이스의 위협 모델을 검토하고 개선합니다.

Codex Security 클라우드 관련 자주 묻는 질문

클라우드 스캔, 보안 이슈, 개인정보 보호, 액세스에 관한 답변을 확인합니다.

사이버 안전

승인된 모델을 선택하고 보안 작업을 안전하게 수행하도록 구성합니다.

모델 및 신뢰할 수 있는 액세스

사이버 보안 모델을 선택하고 신뢰할 수 있는 액세스를 요청합니다.

권장 구성

환경을 격리하고 정해진 작업 범위를 강제 적용하며 민감한 동작을 검토합니다.
