# ChatGPT 데스크톱 앱

프로젝트, 파일 작업, 장시간 작업에 ChatGPT 데스크톱 앱을 사용하세요.

복잡한 작업을 위한 컨트롤 센터

하나의 데스크톱 워크스페이스에서 프로젝트를 병렬로 진행하고, 파일을 다루고, 컴퓨터를 사용하며, 장시간 작업을 계속 이어가세요.

장점

모든 채팅을 한눈에 보기

컨텍스트를 잃지 않고 프로젝트와 장시간 작업 사이를 오가세요.

실제 결과물 만들고 확인하기

같은 워크스페이스에서 문서, 스프레드시트, 이미지 등 다양한 파일을 여세요.

여러 도구를 활용해 작업하기

브라우저, 데스크톱 앱, 플러그인을 사용하거나 채팅 안에서 작업을 예약하세요.

채팅과 프로젝트 알아보기

첫 메시지 보내기

ChatGPT 또는 Codex를 선택하세요. ChatGPT에서는 Composer 위의 토글로 채팅 또는 Work를 선택하세요. Codex에서는 새 채팅으로 시작하세요. 간단한 질문을 하려면 새 채팅에 마우스 포인터를 올리고 오른쪽에 있는 빠른 채팅 아이콘을 선택하세요. 그런 다음 원하는 결과를 설명하고 ChatGPT에 필요한 파일이나 컨텍스트를 추가하세요.
