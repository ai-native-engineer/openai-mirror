ChatGPT 브라우저 확장 프로그램을 사용하면 ChatGPT 데스크톱 앱에서 Google Chrome, Microsoft Edge,
Brave, Opera 또는 Vivaldi로 작업할 수 있습니다. ChatGPT는 LinkedIn, Salesforce, Gmail,
내부 도구 등 이미 로그인한 사이트의 내용을 읽거나 해당 사이트에서 작업을 수행할 수 있습니다.

다섯 브라우저 모두 데스크톱 앱에서 탭 멘션과
브라우저 제어를 지원합니다. Chrome, Edge, Brave, Vivaldi는 사이드 채팅도 지원합니다. **Opera는 사이드 채팅을
지원하지 않습니다**. Opera 작업은 데스크톱 앱에서 시작하세요.

다른 브라우저를 설정하기 전에 ChatGPT 데스크톱 앱을 업데이트하세요.
브라우저 사용 가능 여부는 기능 출시 상황과 워크스페이스 설정에 따라 달라질 수 있습니다.

대신 ChatGPT가 내장 브라우저를 제어하도록 하려면 `@Browser`를 사용하세요.
[내장 브라우저](https://help.openai.com/en/articles/20001277-using-the-built-in-browser-in-the-chatgpt-desktop-app)는 로그인을 지원하며,
평소 사용하는 브라우저 프로필을 사용하지 않고
ChatGPT 안에서 브라우징 작업을 처리합니다.

ChatGPT는 작업에 따라 도구를 전환할 수도 있습니다. 전용 연동 기능이 제공되면
플러그인을, 로그인된 브라우저의 컨텍스트가 필요하면 사용자의 브라우저를,
로컬호스트에는 내장 브라우저를 사용합니다.

## 브라우저에서 사이드 채팅 사용

사이드 채팅은 Chrome, Edge, Brave, Vivaldi에서 사용할 수 있습니다.

현재 보고 있는 페이지 옆에 ChatGPT를 열어 페이지에 관해 질문하거나,
페이지의 컨텍스트를 로컬 파일 및 연결된 앱과 함께 활용하는 작업으로 이어가세요.
작업에 필요한 경우 ChatGPT가 열려 있는 탭의 컨텍스트를 사용할 수 있습니다.

1. 작업하려는 페이지를 여세요.
2. 브라우저 툴바 또는 **확장 프로그램** 메뉴에서 ChatGPT를 선택하세요. macOS에서는
   <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>.</kbd> 키를 눌러도 됩니다.
3. 페이지에 관해 질문하거나 ChatGPT에 작업을 요청하세요.

패널은 처음 연 탭에 계속 표시됩니다. 사이드 채팅에서 시작한 채팅은
ChatGPT 앱에서도 사용할 수 있고, 최근 ChatGPT 채팅을 사이드 채팅에서 열 수도 있으므로
어느 쪽에서든 작업을 이어갈 수 있습니다.

  

## 탭과 선택한 텍스트를 채팅으로 가져오기

ChatGPT가 특정 페이지를 컨텍스트로 사용하게 하려면 데스크톱 앱에서 해당 페이지가 열린 브라우저 탭을 멘션하세요.
사이드 채팅을 지원하는 브라우저에서는 사이드 채팅에서도 탭을 멘션할 수 있습니다.
또는 페이지에서 텍스트를 선택해 채팅으로 가져오면
페이지 전체를 복사하지 않고도 특정 구절에 관해 질문할 수 있습니다.

사이드 채팅을 지원하는 브라우저에서는 페이지를 마우스 오른쪽 버튼으로 클릭한 다음
**ChatGPT에 질문하기** 항목을 선택할 수도 있습니다. 관련 페이지 컨텍스트와 함께 사이드 채팅이 열리므로
브라우저에서 요청을 이어갈 수 있습니다.

### YouTube 동영상에 관해 질문하기

YouTube 동영상을 연 다음, 지원되는 사이드 채팅에서 동영상에 관해 질문하세요.
자막이 제공되면 ChatGPT가 타임스탬프가 포함된 동영상 스크립트를 사용해
콘텐츠를 설명하거나 요약하고 관련 질문에 답할 수 있습니다.

웹페이지 콘텐츠, 선택한 텍스트, 동영상 스크립트는 신뢰할 수 없는
컨텍스트로 취급하세요. ChatGPT에 해당 정보를 사용하거나 그에 따라 작업하도록 요청하기 전에
페이지와 요청된 권한을 검토하세요.

## 브라우저 설정

컴퓨터에 브라우저를 설치한 다음, ChatGPT 데스크톱 앱에서 **설정 \> 컴퓨터 사용** 항목을 여세요.
기본 목록에 브라우저가 표시되지 않으면 **더 많은 브라우저** 항목을
펼치세요.

1. 브라우저를 선택하고 안내가 표시되면 그에 따라 필요한 플러그인을 설치하세요.
2. 브라우저 옆의 **설치** 버튼을 선택해 해당 브라우저의 확장 프로그램 스토어 페이지를 여세요.
   ChatGPT 확장 프로그램을 설치하고 브라우저에 표시되는 권한 요청을 검토하세요.
3. **컴퓨터 사용** 설정으로 돌아가 브라우저에 **관리** 버튼이 표시되는지 확인하세요.
4. ChatGPT Work 또는 Codex 채팅을 시작하고
`@` 멘션으로 브라우저를 선택하세요. 확장 프로그램을 설치한 브라우저 프로필을 사용하세요.

**컴퓨터 사용** 설정의 브라우저 토글은 해당 브라우저를
`@` 멘션 메뉴에 표시할지 여부를 제어합니다. 웹사이트 권한을 변경하려면 **관리** 버튼을 선택하세요.

지정하세요. 예를 들면 다음과 같습니다:

```text
@Edge open Salesforce and update the account from these call notes.

열려 있는 탭을 멘션해 해당 페이지의 컨텍스트를 ChatGPT에 제공할 수도 있습니다.
Opera는 사이드 채팅이 없어도 이러한 데스크톱 워크플로우를 지원합니다.

## 웹사이트 접근 권한 관리

기본적으로 ChatGPT는 새 웹사이트와 상호작용하기 전에 허용 여부를 묻습니다.
이 요청은 `example.com` 같은 웹사이트 호스트를 기준으로 표시됩니다.

ChatGPT가 웹사이트 사용 권한을 요청하면 작업과 감수할 수 있는 위험 수준에
맞는 옵션을 선택할 수 있습니다:

- ChatGPT가 웹사이트를 한 번만 사용하게 하려면 **한 번 허용** 옵션을 선택하세요.
- ChatGPT가 다시 묻지 않고 해당 웹사이트를 사용할 수 있도록 **이 사이트에 허용** 옵션을 선택하세요.
- ChatGPT가 묻지 않고 웹사이트를 사용할 수 있도록 **모든 사이트에 허용** 옵션을 선택하세요.
- ChatGPT가 웹사이트를 사용하지 못하게 하려면 **거부** 옵션을 선택하세요.

### 허용하거나 차단한 웹사이트 관리

ChatGPT 데스크톱 앱에서 **설정** \> **컴퓨터 사용** 경로로 이동한 다음,
브라우저 옆의 **관리** 버튼을 선택하여 도메인 허용 목록과 차단 목록을 관리하세요.
허용 목록에는 ChatGPT가 다시 묻지 않고 사용할 수 있는 도메인이 포함됩니다.
차단 목록에는 ChatGPT가 사용하면 안 되는 도메인이 포함됩니다.
지원되는 브라우저는 이러한 웹사이트 권한을 공유합니다.

허용 목록에서 도메인을 삭제하면 ChatGPT가 해당 도메인을 사용하기 전에 다시 묻습니다.
차단 목록에서 도메인을 삭제하면 ChatGPT가 더 이상 해당 도메인을 차단된 것으로 취급하지 않고
사용 권한을 다시 요청할 수 있습니다.

#### 모든 사이트에 허용 

**모든 사이트에 허용** 옵션을 선택하면 ChatGPT가 웹사이트를 사용하기 전에 더 이상 확인을 요청하지 않습니다.
브라우저에 열려 있는 어떤 웹사이트든
ChatGPT가 사용하도록 믿고 맡길 수 있는 경우에만 이 옵션을 선택하세요.

#### 브라우저 방문 기록 

브라우저 방문 기록에는 민감한 원격 분석 데이터, 내부 URL, 검색어,
로그인한 기기의 브라우저 세션 활동이 포함될 수 있습니다. ChatGPT에 브라우저 방문 기록
접근을 허용하면 관련 기록 항목이 ChatGPT가 작업에 사용하는 컨텍스트에
포함될 수 있습니다. 악의적이거나 오해를 유도하는 페이지 콘텐츠는 ChatGPT가
이 데이터를 의도하지 않은 곳에 복사할 위험을 높일 수 있습니다.

ChatGPT는 브라우저 방문 기록을 사용하려 할 때 권한을 요청합니다. 방문 기록 접근 범위는
해당 요청으로 제한되며, 방문 기록에는 항상 허용 옵션이 없습니다.

### 브라우저 확장 프로그램 권한

확장 프로그램을 설치할 때 브라우저에서 권한을 허용하라는 메시지가 표시됩니다.
예를 들어 Chrome의 권한 요청에는 다음 항목이 포함될 수 있습니다:

- 페이지 디버거에 액세스
- 모든 웹사이트에서 사용자의 모든 데이터 읽기 및 변경
- 로그인한 모든 기기의 방문 기록 읽기 및 변경
- 알림 표시
- 북마크 읽기 및 변경
- 다운로드 관리
- 연동되는 네이티브 애플리케이션과 통신
- 탭 그룹 보기 및 관리

이러한 권한을 통해 확장 프로그램이 브라우저 워크플로우를 수행할 수 있습니다. ChatGPT는 작업 중 웹사이트나 브라우저 방문 기록을 사용하기 전에 자체 확인 절차, 설정, 허용 목록, 차단 목록을 계속 적용합니다.

### 메모리

컴퓨터 사용은 메모리 설정을 따릅니다. 메모리가 켜져 있으면 ChatGPT는 브라우저에서 작업할 때 저장된 관련 메모리를 사용할 수 있습니다. 메모리가 꺼져 있으면 브라우저 제어에 메모리를 사용하지 않습니다.

### OpenAI가 저장하는 브라우저 활동 정보

OpenAI는 확장 프로그램을 통한 브라우저 동작의 전체 기록을 별도로 저장하지 않습니다. 브라우저 활동이 ChatGPT 컨텍스트의 일부가 되는 경우에만 저장합니다. 여기에는 ChatGPT가 페이지에서 읽은 텍스트, 스크린샷, 도구 호출, 요약, 메시지 및 채팅에 포함된 기타 콘텐츠가 해당합니다.

ChatGPT 데이터 제어 설정은 컨텍스트에서 처리되는 콘텐츠에 적용됩니다. 브라우저 작업에 꼭 필요하고 각 프롬프트를 직접 검토할 수 있도록 자리를 지키는 경우가 아니라면, 비밀 정보나 매우 민감한 데이터를 브라우저 작업을 통해 전송하지 마세요.

## 문제 해결

ChatGPT가 브라우저에 연결할 수 없다면 먼저 ChatGPT가 접근하려는 웹사이트가 설정의 차단 목록에 포함되어 있지 않은지 확인하세요. 웹사이트가 차단되지 않았다면 다음 항목을 차례로 확인하세요:

1. ChatGPT 데스크톱 앱을 업데이트하세요. ChatGPT 또는 Codex 데스크톱 앱이 둘 이상 설치되어 있다면 각각 업데이트하거나 더 이상 사용하지 않는 설치본을 삭제하세요.
2. 브라우저를 다시 시작하세요. Chrome, Edge, Brave 또는 Vivaldi에서는
   툴바나 **확장 프로그램** 메뉴에서 ChatGPT를 다시 열고 사이드 채팅이 로드되는지 확인하세요.
   Opera에는 사이드 채팅이 없으므로 데스크톱 앱에서 연결 상태를 확인하세요.
3. **설정 \> 컴퓨터 사용에서** 브라우저가 나타나고
**관리** 항목이 표시되는지 확인하세요. 여전히 **설치가** 표시되면 설정 플로우를 다시 진행하세요.
   `@` 멘션 메뉴에 브라우저가 없다면 해당 브라우저의 토글을 켜세요.
4. 확장 프로그램이 설치된 브라우저 프로필을 사용 중인지 확인하세요. 프로필을 둘 이상 사용한다면 현재 활성화된 프로필에 확장 프로그램을 설치하고 사용 설정하세요.
5. 새 ChatGPT Work 또는 Codex 채팅을 시작하고 브라우저 작업을 다시 시도하세요. 이렇게 하면 채팅별 연결 상태가 초기화될 수 있습니다.
6. ChatGPT 데스크톱 앱을 다시 시작한 다음 다시 시도하세요. 그래도 확장 프로그램이
   연결되지 않으면 **설정 \> 컴퓨터 사용에서** 다시 설치하세요.
7. 그래도 ChatGPT가 브라우저를 사용할 수 없다면 앱에서 `/feedback`을 실행하고,
   지원팀에 문의할 때 채팅 ID를 함께 보내세요.

### 파일 업로드

Chrome 작업에서 컴퓨터의 파일을 업로드해야 한다면 Chrome에서 Chrome 확장 프로그램의 파일 URL 접근을 허용하세요:

1. Chrome 툴바에서 확장 프로그램 아이콘을 클릭한 다음 **확장 프로그램
   관리를** 클릭하세요.
2. 확장 프로그램 카드에서 **세부정보를** 클릭하세요.
3. **파일 URL에 대한 액세스 허용** 옵션을 켜세요.

설정을 변경한 후 Chrome 작업을 다시 시작하세요.
