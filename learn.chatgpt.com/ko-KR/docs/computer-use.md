지원되는 지역에서는 macOS 및 Windows의 ChatGPT 데스크톱 앱에서 ChatGPT Work와 Codex로 컴퓨터 사용 기능을 이용할 수 있습니다. 컴퓨터 사용 플러그인을 설치하세요. macOS에서는 권한 요청이 표시되면 화면 기록 및 손쉬운 사용 권한을 부여하세요.

컴퓨터 사용을 이용하면 ChatGPT가 macOS 또는 Windows의 그래픽 사용자 인터페이스를 보고 조작할 수 있습니다. 데스크톱 앱 확인, 브라우저 사용, 앱 설정 변경, 플러그인으로 제공되지 않는 데이터 소스 활용, 그래픽 사용자 인터페이스에서만 발생하는 버그 재현처럼 명령줄 도구나 구조화된 통합만으로는 처리하기 어려운 작업에 사용하세요.

컴퓨터 사용은 프로젝트 워크스페이스 외부의 앱과 시스템 상태에 영향을 줄 수 있으므로 범위가 명확한 작업에 사용하고, 계속 진행하기 전에 권한 요청을 검토하세요.

## 컴퓨터 사용 설정

ChatGPT 데스크톱 앱에서 ChatGPT를 선택하고 전환 메뉴에서 Work로 전환하거나
Codex를 선택하세요. **플러그인 \> 컴퓨터
사용** 메뉴를 열고 안내가 표시되면 **플러그인 설치** 옵션을 선택하세요. ChatGPT에 **활성화** 옵션이 표시되면
선택하세요. 컴퓨터 사용 서버와 스킬 토글을 켠 다음 **지금
사용해 보기** 옵션을 선택해 시작하세요.

  

그런 다음 **설정 \> 컴퓨터 사용** 메뉴를 열어 앱 접근 권한을 검토하세요. 연결된 브라우저의
제어 영역에는 **관리** 옵션이 표시됩니다. 향후 작업에서도 사용하도록 승인한 앱은
 **항상 허용된 앱** 섹션에 표시됩니다.

  

Windows에서는 작업이 실행되는 동안 대상 앱이 활성 데스크톱에 보이도록 유지하세요. macOS에서는 권한 요청이 표시되면 화면 기록 및 손쉬운 사용 권한을 부여하여 ChatGPT가 대상 앱을 보고 조작할 수 있도록 하세요.

macOS에서는 다음 권한을 부여하세요:

- ChatGPT가 대상 앱을 볼 수 있도록 하는 **화면 기록** 권한.
- ChatGPT가 클릭하고 입력하며 탐색할 수 있도록 하는 **손쉬운 사용** 권한.

## 컴퓨터 사용이 적합한 경우

스크린샷이나 시각적 판단이 필요한 어려운 작업에는
모델 선택기에 [GPT-6 Astra](/ko-KR/codex/models#gpt-6-astra)가 제공되는 경우
이 모델을 선택하세요. 플러그인 설정, 운영 체제 권한, 앱 접근
제어는 동일하게 적용됩니다.

파일이나 명령어 출력만으로는 확인하기 어려운 그래픽 사용자 인터페이스가 필요한 작업에는 컴퓨터 사용을 선택하세요.

다음과 같은 작업에 적합합니다:

- ChatGPT가 개발 중인 macOS 앱, Windows 앱, iOS 시뮬레이터 플로우 또는 기타 데스크톱 앱 테스트.
- 웹 브라우저가 필요한 작업 수행.
- 그래픽 인터페이스에서만 나타나는 버그 재현.
- UI를 클릭해야 변경할 수 있는 앱 설정 수정.
- 플러그인으로 접근할 수 없는 앱이나 데이터 소스의 정보 확인.
- macOS에서 다른 작업을 계속하면서 범위가 명확한 작업을 백그라운드에서 실행.
- 여러 앱에 걸친 워크플로우 실행.

로컬에서 개발하는 웹 앱이라면 먼저
[내장 브라우저](/ko-KR/codex/browser?surface=app)를 사용하세요.

### Windows 포그라운드 사용

Windows에서 컴퓨터 사용은 활성 데스크톱에서 실행됩니다. 사용자가 동일한 Windows 세션을 계속 사용하는 동안 백그라운드에서 작동할 수는 없습니다. 따라서 작업 중에는 ChatGPT가 마우스 포인터를 움직이고 텍스트를 입력하며 포그라운드 제어권을 가져간다는 점을 염두에 두세요.

자리를 비운 동안에도 Windows 작업을 계속하려면
Windows 기기를 잠금 해제 상태로 유지하고 인터넷에 연결하세요.
휴대폰에서 [원격 제어](/ko-KR/codex/remote-connections)를 사용해 진행 상황을 확인하거나
후속 지침을 보내세요. 또는 Windows 가상 머신에서 ChatGPT 데스크톱 앱을 실행해
컴퓨터 사용이 기본 데스크톱 대신 VM을 제어하도록 하세요.

## 컴퓨터 사용 작업 시작

프롬프트에 `@Computer` 또는 `@AppName`를 입력하거나 ChatGPT에 컴퓨터 사용을 요청하세요.
ChatGPT가 조작할 앱, 창 또는 플로우를 정확하게 설명하세요.

```text
Open the app with Computer Use, reproduce the onboarding bug, and fix the
smallest code path that causes it. After each change, run the same UI flow
again.

```text
Open @Chrome and verify the checkout page still works after the latest changes.

대상 앱이 전용 플러그인이나 MCP 서버를 제공한다면 데이터 접근과 반복 가능한 작업에는 해당 구조화된 통합을 우선 사용하세요. ChatGPT가 앱을 시각적으로 확인하거나 조작해야 할 때는 컴퓨터 사용을 선택하세요.

## 권한 및 승인

워크스페이스 관리자는 컴퓨터 사용이 접근할 수 있는 앱과
승인 저장 여부를 제한할 수 있습니다.
[관리형 브라우저 및 컴퓨터 사용 제어](/ko-KR/codex/enterprise/managed-configuration#control-browser-and-computer-use)를 참고하세요.

컴퓨터 사용에 필요한 시스템 권한은 ChatGPT의 앱 승인과 별개입니다. macOS에서는 화면 기록 및 손쉬운 사용 권한이 있어야 ChatGPT가 앱을 보고 조작할 수 있습니다. 앱 승인은 사용자가 ChatGPT에 사용을 허용하는 앱을 결정합니다. 파일 읽기, 파일 수정, 셸 명령어에는 해당 작업의 샌드박스 및 승인 설정이 계속 적용됩니다.

컴퓨터 사용을 이용하면 ChatGPT는 사용자가 허용한 앱만 보고 조작할 수 있습니다.
작업 중에는 ChatGPT가 컴퓨터의 앱을 사용하기 전에 사용자에게 권한을 요청합니다.
 **항상 허용을** 선택하면 이후에는 해당 앱을 사용할 때
다시 권한을 묻지 않습니다. ChatGPT 데스크톱 앱 설정에서 **컴퓨터 사용** 섹션의
 **항상 허용** 목록에 있는 앱을 제거할 수 있습니다.

  
    
  

ChatGPT는 민감하거나 작업에 지장을 줄 수 있는 동작을 수행하기 전에도 권한을 요청할 수 있습니다.

ChatGPT가 앱을 보거나 제어하지 못한다면 macOS에서 **시스템 설정 \> 개인정보 보호 및
보안** 메뉴를 열고 **화면 기록** 및 **손쉬운 사용** 설정에서 **Codex
컴퓨터 사용** 권한을 확인하세요. Windows에서는 대상 앱이
활성 데스크톱 세션에 보이는지 확인하세요.

Windows에서 컴퓨터 사용은 앱에 대한 결정을
`$CODEX_HOME/config.toml`에 영구 저장합니다. 컴퓨터 사용이 권한 요청 없이 열 수 있는 앱을
나열하세요:

```toml
[computer_use.windows]
always_allowed_app_ids = ["mspaint.exe"]

Windows 컴퓨터 사용에서 보고하는 앱 식별자를 사용하세요. 데스크톱 앱의 실행 파일 이름이나
패키지 앱의 앱 사용자 모델 ID 등이 이에 해당합니다. 목록에 없는 앱을 사용하려 하면
ChatGPT가 권한을 요청합니다. 저장된 결정을 취소하려면
 **설정 \> 컴퓨터 사용 \> 항상 허용** 목록에서 해당 앱을 제거하세요.

이 테이블에는 로컬 컴퓨터 사용에 관한 결정이 저장됩니다. 관리자가 강제 적용하는
`requirements.toml` 파일과는 별개이며, 관리자는 이 파일에서
`[features].computer_use = false` 설정으로 컴퓨터 사용을 비활성화할 수 있습니다. 기존
`$CODEX_HOME/computer-use/config.toml`의 허용 목록 항목은
현재 설정으로 마이그레이션되지만, 해당 파일의 `denied` 목록은 현재 정책 스키마에 포함되지 않습니다.

## 잠금 중 사용

  잠금 중 사용은 macOS용 기능입니다. Windows에서는 컴퓨터 사용이 포그라운드에서 실행됩니다.

잠금 중 사용을 활성화한 경우에만 Mac이 잠긴 후에도 ChatGPT가 컴퓨터 사용 기능을 이용할 수 있습니다. Mac이 잠긴 뒤 연결된 기기에서 ChatGPT 작업을 통해 데스크톱 앱을 사용해야 할 때 이 기능을 사용하세요.

잠금 중 사용을 활성화하면 ChatGPT가
macOS 잠금 해제 플로우에 참여하는 Apple [권한 부여 플러그인](https://developer.apple.com/documentation/security/authorization-plug-ins)을
설치합니다.

잠금 중 사용은 의도적으로 용도가 제한되어 있습니다. Mac을 원격으로 잠금 해제하는 범용 수단이 아니며, 다른 앱이나 로컬 프로세스가 컴퓨터의 잠금을 해제하도록 허용하지도 않습니다.

잠금 중 사용을 이용하려면:

1. 앱에서 **설정 \> 컴퓨터 사용** 메뉴를 여세요.
2. 잠금 중 사용을 활성화하세요.
3. Mac 화면이 잠긴 후 연결된 기기에서 컴퓨터 사용을 이용하는 작업을 시작하세요.

Mac이 잠긴 후 ChatGPT 작업이 컴퓨터 사용으로 앱에 접근하면 ChatGPT는 로컬 사용을 차단하고 잠금 화면의 보호 기능을 유지하면서 Mac의 잠금을 일시적으로 해제합니다. 잠금을 해제하기 전에 해당 시도가 진행 중인 신뢰할 수 있는 컴퓨터 사용 턴을 위한 것인지 확인합니다. 이 짧은 허용 시간 밖에서는 잠금 해제를 거부하며, 필요한 경우 사용자에게 직접 잠금을 해제하도록 요청합니다.

잠금 중 사용에는 다음과 같은 보호 조치가 적용됩니다:

- 잠금 해제 권한의 유효 시간은 짧으며 현재 잠금 해제 시도에만 적용됩니다.
- 자동 잠금 해제는 컴퓨터 사용 턴이 진행되는 동안 ChatGPT만 사용할 수 있습니다.
- 데스크톱의 잠금이 일시적으로 해제되는 동안 ChatGPT가 모든 디스플레이를 가립니다.
- ChatGPT가 로컬 키보드나 마우스 포인터 입력을 감지하면 Mac을 다시 잠그고 사용자가 직접 잠금을 해제할 때까지 자동 잠금 해제를 일시 중지합니다.

## 안전 지침

컴퓨터 사용을 이용하면 ChatGPT가 화면 내용을 확인하고 스크린샷을 촬영하며 대상 앱의 창, 메뉴, 키보드 입력 및 클립보드 상태와 상호 작용할 수 있습니다. 화면에 보이는 앱 콘텐츠, 브라우저 페이지, 스크린샷, 대상 앱에서 연 파일은 작업 중 ChatGPT가 처리할 수 있는 컨텍스트로 간주하세요.

작업 범위를 좁게 유지하고 민감한 플로우가 진행될 때는 자리를 지키세요:

- ChatGPT에 한 번에 하나의 대상 앱이나 플로우를 명확히 지정하세요.
- 언제든지 작업을 중지하거나 컴퓨터를 직접 제어할 수 있습니다.
- 민감한 정보가 있는 앱은 작업에 필요한 경우가 아니라면 닫아 두세요.
- Windows에서는 ChatGPT가 작업하는 동안 포그라운드 입력을 제어합니다. 보조 기기나 VM을 사용하거나, 해당 데스크톱을 직접 사용하기 전에 작업을 중지하세요.
- 직접 지켜보며 각 단계를 승인할 수 없다면 비밀 정보가 필요한 작업은 피하세요.
- ChatGPT가 앱을 사용하도록 허용하기 전에 앱 권한 요청을 검토하세요.
- **항상 허용** 옵션은 향후 작업에서 ChatGPT가 자동으로 사용해도
  괜찮다고 판단한 앱에만 적용하세요.
- 계정, 보안, 개인정보 보호, 네트워크, 결제 또는 자격 증명과 관련된 설정을 다룰 때는 자리를 비우지 마세요.
- ChatGPT가 엉뚱한 창을 조작하기 시작하면 작업을 취소하세요.

ChatGPT가 브라우저를 사용하면 이미 로그인한 페이지에서 작업할 수 있습니다. 웹사이트에서 수행하는 작업은 직접 수행할 때처럼 검토하세요. 웹페이지에는 악성 콘텐츠나 오해를 유발하는 콘텐츠가 포함될 수 있으며, 사이트에서는 승인한 클릭, 양식 제출, 로그인 상태에서 수행한 작업을 사용자 계정에서 수행한 것으로 간주할 수 있습니다. ChatGPT가 작업하는 동안에도 브라우저를 계속 사용하려면 ChatGPT에 다른 브라우저를 사용하도록 요청하세요.

이 기능으로는 터미널 앱이나 ChatGPT 자체를 자동화할 수 없습니다. 이를 자동화하면 ChatGPT 보안 정책을 우회할 수 있기 때문입니다. 또한 컴퓨터에서 관리자로 인증하거나 보안 및 개인정보 보호 권한 요청을 승인할 수도 없습니다.

파일 편집과 셸 명령어에는 해당되는 경우 ChatGPT의 승인 및 샌드박스 설정이 계속 적용됩니다. 데스크톱 앱을 통해 변경한 내용은 디스크에 저장되고 프로젝트에서 추적되기 전까지 검토 창에 표시되지 않을 수 있습니다. 컴퓨터 사용으로 캡처한 스크린샷을 포함하여 ChatGPT를 통해 처리되는 콘텐츠에는 사용자의 ChatGPT 데이터 제어 설정이 적용됩니다.
