Öffne in der ChatGPT-Desktop-App das ChatGPT-Drop-down-Menü und wähle **Codex** aus.
Lege beim Starten eines Codex-Chats fest, wo er ausgeführt wird:

- **Lokal**: Arbeite direkt in deinem aktuellen Projektverzeichnis.
- **Worktree**: Isoliere Änderungen in einem Git-Worktree. [Weitere Informationen](/de-DE/codex/environments/git-worktrees).
- **Cloud**: Führe den Chat remote in einer konfigurierten Cloud-Umgebung aus.

Chats mit den Optionen **Lokal** und **Worktree** werden jeweils auf deinem Computer ausgeführt.

Das vollständige Glossar und alle Konzepte findest du im [Abschnitt „Konzepte“](/de-DE/codex/prompting).
