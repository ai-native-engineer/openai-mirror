# Entwickelnde

Arbeitsabläufe, Umgebungen, Erweiterungen und Integrationen für die Entwicklung konfigurieren

Nutze Codex bei der Arbeit mit Codebasen und Entwicklungsumgebungen, zur Automatisierung und zusammen mit den Tools deines Teams.

Codex unterstützt alltägliche Programmieraufgaben ebenso wie weitergehende Integrationen in lokalen und Cloud-Umgebungen. Die Arbeitsabläufe für die Entwicklung umfassen Code Review, das integrierte Terminal, wiederverwendbare Skills und Plug-ins, Automatisierungen mit dem SDK und dem App Server, Team-Tools sowie Referenzmaterial zu den einzelnen Oberflächen.
