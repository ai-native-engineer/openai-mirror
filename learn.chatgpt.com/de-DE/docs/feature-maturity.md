Einige Funktionen von ChatGPT und Codex werden mit einer Angabe zu ihrem Reifegrad veröffentlicht. So kannst du einschätzen, wie zuverlässig die jeweilige Funktion ist, was sich möglicherweise ändert und welche Unterstützung du erwarten kannst.

| Reifegrad          | Bedeutung                                                                                                 | Empfehlung                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| In Entwicklung | Noch nicht einsatzbereit.                                                                                            | Nicht verwenden.                                                                    |
| Experimentell      | Instabil; OpenAI kann die Funktion entfernen oder ändern.                                                                  | Auf eigenes Risiko verwenden.                                                         |
| Beta              | Bereit für Tests in größerem Umfang. Die Funktion ist weitgehend vollständig, einzelne Aspekte können sich jedoch aufgrund von Rückmeldungen der Nutzenden noch ändern.       | Für die meisten Evaluierungen und Pilotprojekte geeignet; rechne mit kleineren Änderungen.                      |
| Stabil            | Wird vollständig unterstützt, ist dokumentiert und für den breiten Einsatz bereit. Verhalten und Konfiguration bleiben langfristig konsistent. | Kann sicher im Produktivbetrieb eingesetzt werden; eine Entfernung erfolgt in der Regel erst nach einem Abkündigungsprozess. |
| Veraltet        | Aus Kompatibilitätsgründen weiterhin verfügbar, aber nicht mehr empfohlen. OpenAI kann die Funktion in einer zukünftigen Version entfernen.       | Setze die Funktion nicht für neue Vorhaben ein und plane eine Migration.                                            |
