# Codex Remote

Starte, steuere, genehmige und überprüfe Codex-Aufgaben auf einem verbundenen Computer von deinem Smartphone aus.

Remote

Verfolge den Fortschritt, genehmige Aktionen und sende Anweisungen von deinem Smartphone aus. Codex führt jede Aufgabe auf deinem verbundenen Computer aus.
