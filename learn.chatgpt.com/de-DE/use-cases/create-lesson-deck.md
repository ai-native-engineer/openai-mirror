## Mit geprüften Inhalten beginnen

Verwende einen freigegebenen Plan für eine Unterrichtseinheit oder Unterrichtsstunde, aktuelle Quellmaterialien, eine Präsentationsvorlage des Schulbezirks, freigegebene Bilder und Vorgaben zur Barrierefreiheit. Halte Inhalte aus den Quellen und optionale Beispiele getrennt.

Eine klare Quellenhierarchie verhindert, dass veraltete Folien gegenüber dem geprüften Plan Vorrang erhalten.

## Präsentation erstellen

Bitte ChatGPT, eine bearbeitbare Präsentation im nativen Format mit einem schlüssigen Unterrichtsablauf zu erstellen:

- Einstiegsfrage oder Einstiegsphänomen
- knappe Erklärungen
- ausgearbeitete Beispiele
- Verständniskontrollen
- Übungs- oder Diskussionsimpulse
- Exit-Ticket
- Sprechernotizen
- Quellenangaben

Die Präsentation soll den Unterricht unterstützen, statt jedes Detail auf den Folien unterzubringen.

## Präsentation im nativen Format prüfen

Prüfe die eigentliche Präsentation, nicht nur eine Gliederung. Achte auf Lesbarkeit, Tempo, Barrierefreiheit, Nutzungsrechte für Bilder und eine korrekte Wiedergabe der Quellen. Prüfe außerdem, ob die Sprechernotizen alle Details enthalten, die die Lehrkraft benötigt.

Überarbeite die Präsentation in gezielten Durchgängen. Kennzeichne sie so lange als Entwurf, bis eine Lehrkraft bestätigt, dass die Inhalte und der Unterrichtsablauf verwendet werden können.
