## Verwendung

1. Installiere die Slack-App, verknüpfe die richtigen Repositories und Umgebungen und füge `@Codex` zum Kanal hinzu.
2. Erwähne `@Codex` in einem Thread. Formuliere deine Anfrage klar und nenne alle Einschränkungen sowie das gewünschte Ergebnis.
3. Öffne den Chat-Link, überprüfe das Ergebnis und setze die Unterhaltung in Slack fort, falls die Aufgabe noch einmal bearbeitet werden muss.

Weitere Informationen zur Verwendung von Codex in Slack findest du im [entsprechenden Leitfaden](/de-DE/codex/third-party/slack).

## Tipps

- Wenn der Thread noch nicht genügend Kontext oder noch keinen Lösungsvorschlag enthält, ergänze deinen Prompt um entsprechende Hinweise
- Stelle sicher, dass das Repository und die Umgebung richtig zugeordnet sind, indem du den Namen des Projekts oder der Umgebung in deinem Prompt angibst
- Grenze die Anfrage so ein, dass Codex sie ohne eine zweite Planungsrunde abschließen kann
- Wenn dein Projekt eine große Codebasis umfasst, gib Codex Orientierung, indem du die für die Aufgabe relevanten Dateien oder Ordner nennst
