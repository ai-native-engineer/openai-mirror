# API billing and invoice timing

Learn when API invoices are issued and where to find invoices, payment history, and receipts.

Updated: 3 days ago

API billing and the documents you receive depend on your account type and billing arrangement.

# Enterprise API invoices

OpenAI provides API invoices for Enterprise customers.

If you are an Enterprise API customer:

* You are billed at the end of each calendar month for that month’s usage, unless you have a different custom billing arrangement in writing.
* Invoices are typically issued within 2 weeks after the billing cycle ends.
* Your Enterprise contract determines your payment terms.

You can download invoices from the [**Billing** section of the API Platform](https://platform.openai.com/account/billing).

# Other API customers

If you use the API as an individual or team customer:

* Payment is handled through prepaid credits or automatic credit-card charges.
* You can view your payment history and available invoices or receipts in **Billing history**.

For automatic credit-card billing, payments are collected at usage thresholds or monthly, depending on your payment method and country.

For prepaid credit purchases and automatic recharges, see: [Prepaid API billing](https://help.openai.com/articles/8264644).
