# Using the built-in browser in the ChatGPT desktop app

Browse, sign in, download files, and review pages without leaving ChatGPT.

Updated: 2 days ago

Use the built-in browser when a task needs a web page. You and ChatGPT can see the same page, and ChatGPT can work across tabs, download files, or wait while you sign in.  
  
The built-in browser is available in the ChatGPT desktop app on macOS and Windows. It uses its own browser state and supports richer sign-in, autofill, password management, extensions, downloads, and navigation. Available features may depend on your plan and workspace settings.

# Open the browser

1. Open a chat in Work or Codex.
2. Open the browser from the toolbar or press Command (⌘)+Shift+B on macOS or Ctrl+Shift+B on Windows.
3. Ask ChatGPT to use the current page and follow any permission prompt.
4. Check the website and approve access when ChatGPT asks.

# Choose the built-in browser or Chrome

The built-in browser keeps browsing inside the ChatGPT desktop app and uses its own browser state. Use it for local development, public pages, and tasks you want to keep inside the app. Use the Codex Chrome extension when a task needs your existing Chrome profile, signed-in session, open tabs, or Chrome extensions. Review the active account before allowing ChatGPT to continue.  
  
Enter credentials only in the browser, never in the chat. Review the active account before allowing ChatGPT to continue.

# Use tabs and download files

ChatGPT can open and move between several tabs during one task. It can also start downloads and may ask before saving a file.  
  
Open a link outside the app when you want to continue in your regular browser.

# Review a page with annotations

1. Open the page or local development route you want to review.
2. Turn on Annotation mode and select the element or area you want to change.
3. Leave a specific comment, then ask ChatGPT to address it.
4. Review the updated page and related changes before continuing.

# Manage website access safely

ChatGPT asks before using a new website unless you have already allowed that host or have selected a more permissive setting. Manage allowed and blocked websites in the desktop app settings.  
  
Treat website content as untrusted. Keep the task specific, check the site before approving access, and stop the task if ChatGPT opens the wrong account or page.

# FAQ

## Can I sign in to a website in the built-in browser?

Yes. Sign in through the browser when prompted. ChatGPT may suggest Chrome when the Codex Chrome extension can use an existing signed-in session.  
  
You can clear clear cookies and logged-in status, as well as delete browsing history, in the desktop app Settings menu

## Does the built-in browser use my Chrome profile?

No. The built-in browser uses its own browser state. Use the Codex Chrome extension when a task needs your existing Chrome profile, cookies, signed-in session, open tabs, or Chrome extensions.

## How is the built-in browser different from cloud browser?

The built-in browser runs inside the desktop app, where you can follow and annotate the page. Cloud browser runs remotely in ChatGPT and can continue delegated web tasks in the background.  
  
For more information, see the [built-in browser](https://developers.openai.com/codex/app/browser) and [Codex Chrome extension](https://developers.openai.com/codex/app/chrome-extension) guides.
