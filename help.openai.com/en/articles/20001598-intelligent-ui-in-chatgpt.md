# Intelligent UI in ChatGPT

Intelligent UI lets ChatGPT combine text, visuals, and interactive elements in your conversations.

Updated: 17 days ago

Intelligent UI lets ChatGPT shape each answer with the right layout, visuals, and interactivity for what you want to understand or do, directly in the conversation.

## How does Intelligent UI work?

We’ve trained GPT-6 to compose responses using text, visuals, and interactive elements, choosing how they fit together based on your question. Responses can include graphics, tappable buttons, forms, charts, and interactive experiences you can use directly in your conversation.The format depends on what you’re asking. A comparison might work best side by side. An explanation might be easier to understand through an interactive diagram. And when a simple text answer is the most useful response, ChatGPT can give you that.

## What’s the difference between GPT-6 on free and paid plans?

GPT-6 in ChatGPT is based on GPT-6 Sol for Plus, Pro, Business, and Enterprise, and GPT-6 Luna for Free and Go. Both are tuned for everyday conversation and support Intelligent UI.The Pro reasoning option uses GPT-6 Astra and does not support Intelligent UI.

## How does Intelligent UI work across reasoning settings?

Intelligent UI works from Instant through Extra High reasoning levels.

## Can I add preferences for how ChatGPT responds?

Yes. Add your preferences in **Custom Instructions** to tell ChatGPT how you would like it to respond. For example, “keep answers concise” or “use tables when comparing options.”You can also ask for a different style in an individual conversation. These preferences guide the response; the exact layout can vary.

## Can I turn Intelligent UI off?

You can choose a simpler response style in your ChatGPT settings on the web. Select **Personalization → Layout and Visuals → Simple**. This reduces visual and interactive elements, though some may still appear.

## Will my inputs or progress be saved?

That depends on the experience. Some components, such as checklists, can retain their state when you refresh the chat thread. State is not retained across chat threads.

## Can I use Intelligent UI in the Work tab?

No. Intelligent UI is available in Chat, not in the Work tab.

## Does Intelligent UI work with Voice?

No. Intelligent UI is not available in Voice.

## Does Intelligent UI work with plugins?

Plugins you’ve connected, such as Gmail, Health, and Finance, will continue to work in ChatGPT.
