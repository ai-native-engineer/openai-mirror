# Managing billing for ChatGPT and the API platform

Find billing settings and support for your ChatGPT account, workspace, or API organization.

Updated: 3 days ago

ChatGPT and the API platform have separate billing systems. Manage each product’s charges and billing history in its own settings.

# Manage billing for ChatGPT on the web

For Free, Go, Plus, or Pro accounts, open [ChatGPT billing settings](https://chatgpt.com/#settings/Billing), or:

1. Sign in to ChatGPT on the web.
2. Open **Settings**.
3. Select **Billing**.

If you subscribed on the web, use the options in **Billing** to manage your subscription, payment methods, and available billing history.

# Manage ChatGPT Business, Enterprise, or Edu billing

For ChatGPT Business, workspace owners and admins can open [**Workspace settings > Billing**](https://chatgpt.com/admin/billing). Only workspace owners can update billing information and payment methods or view invoices.

For eligible ChatGPT Enterprise and Edu workspaces, authorized workspace owners and admins can select their workspace in the [Global Admin Console](https://admin.openai.com/), then open **Billing**. Available controls depend on your plan and permissions. Only workspace owners can view **Invoices**.

# Manage API billing

API organization owners can view billing details in the [API billing overview](https://platform.openai.com/account/billing/overview).

## Set up API billing separately from ChatGPT

To start paid API usage, add a payment method in your [API account billing settings](https://platform.openai.com/settings/organization/billing/overview). API usage is billed separately from your ChatGPT subscription.

API charges depend on the models and features you use, including token usage and any applicable tool or storage charges. Check the [API pricing page](https://developers.openai.com/api/docs/pricing) for current rates.

For prepaid credit purchases and automatic recharges, see: [Setting up prepaid billing](https://help.openai.com/articles/8264644).

# Check subscriptions on more than one platform

ChatGPT subscriptions can be billed through the web, Apple App Store, or Google Play Store. Subscriptions on more than one platform may result in separate charges.

To identify which platform manages your subscription and avoid duplicate charges, see: [Managing your ChatGPT subscription across devices](https://help.openai.com/articles/20001043).
