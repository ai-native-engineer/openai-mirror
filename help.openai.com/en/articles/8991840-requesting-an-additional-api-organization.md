# Requesting an additional API organization

Learn how to request a new API organization — and why using Projects might be a better option for most users.

Updated: 15 days ago

If you need a second API organization, we can create one on your behalf. Please [contact our support team](https://help.openai.com/articles/6614161) and provide the following details:

* **Desired name of the organization**
* **Email address of the person who should own the organization**

Once we receive your request, we’ll create the new organization for you. You can then invite additional members as needed.

# Important recommendation

Before requesting a new organization, **we recommend considering the use of Projects** instead.

Projects allow you to:

* Manage billing separately across different teams or initiatives.
* Assign and organize API keys, usage, and permissions more flexibly.
* Avoid the complexity of managing multiple organizations.

For most customers, **Projects are the preferred way** to structure separate teams, departments, or initiatives within a single organization.

Learn more about [Projects](https://help.openai.com/articles/9186755) in the Help Center.
