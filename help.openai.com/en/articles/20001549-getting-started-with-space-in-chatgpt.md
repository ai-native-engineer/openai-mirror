# Getting started with Space in ChatGPT

Create and organize pages, work with ChatGPT, and collaborate on documents.

Updated: 1 hour ago

Space is a home for your pages, uploaded files, and other work in ChatGPT. You can create and edit pages with ChatGPT, organize related content in spaces, and share your work to collaborate with other people.

Space replaces Library for accounts with access to Space. Projects remain separate, so you can continue using them for your project chats, files, and instructions.

# Availability

You can create and edit content in Space with ChatGPT Pro, Business, or Enterprise. In managed workspaces, your organization’s sharing settings determine which sharing options you can use. Enterprise administrators may need to enable sharing before members can collaborate.

Use Space on the web or in the ChatGPT desktop app to create and edit pages. On mobile, you can find, read, and share pages and navigate between pages and subpages. Mobile does not support editing pages.

Slides and Sheets are coming soon. Automatic page updates with Keep updated are not available at launch.

Space is coming soon for Enterprise and Business workspaces with data residency in Canada or the United Arab Emirates.

Inference data residency is not currently supported for Space.

# Understand pages and spaces

A **page** is an editable document. For example, you can use a page for a project brief, meeting notes, a research summary, or a team update. You and your collaborators can edit the same page, and each person can ask their own ChatGPT to help with the content.

A **space** groups related content. You have a personal space, and you can use other spaces to organize work on a topic or with a team. Spaces can contain folders and pages. A page can also contain subpages, so you can keep a summary and its supporting material together.

**Projects** continue to organize chats, files, and project instructions. Creating or using a space does not replace your existing Projects. Learn more about [Projects in ChatGPT](/en/articles/10169521-projects-in-chatgpt).

# Create a space

Ask ChatGPT to create a space and give it a name. For example: “Create a space named Website launch.”

When you ask ChatGPT to create a page, specify the space where it should go. For example: “Create a project overview page in Website launch with our goals, timeline, and next steps.”

# Create a page

You can start a page from a conversation, begin writing directly in Space, or use a template from Space home.

To create a page from a conversation:

1. Open the conversation with the material you want to use, or start a new conversation.
2. Ask ChatGPT to create a page. Describe what it should contain and include any files or context it needs.
3. Open the page and review the result. You can edit the text directly or ask ChatGPT to make changes.

For example: “Create a page from this conversation with the project goals, decisions, and next steps.”

# Edit a page with ChatGPT

Open a page to edit it directly or ask ChatGPT for a specific change. You can revise the whole page or focus on one section.

For example:

* “Shorten the introduction and keep the recommendations unchanged.”
* “Add a summary of the attached meeting notes under Decisions.”
* “Compare these two proposals and add the main differences to this page.”

Pages can include charts, trackers, and interactive tools created by ChatGPT. For example, you can ask ChatGPT to add a chart that compares figures in a report.

Use comments to give feedback on a specific passage. Select the text and add a comment describing the change you want. Use the page’s chat for broader questions or changes across the document.

Check names, dates, calculations, and source information before using or sharing the page.

# Organize and find your work

## Organize pages and subpages

Use spaces to group related work. Organize pages by nesting them under a parent page. For example, a project overview page can contain subpages for meeting notes and weekly updates.

Ask ChatGPT to create a subpage and name its parent: “Create a Meeting notes subpage under Project overview.” You can also ask ChatGPT to rename a page.

To move a page under another page in the same space, tell ChatGPT which page to move and where it should go. You need edit access to both pages. Review any change in access before confirming the move.

## Find your content

Use these views in Space to find your work:

* **All > Your items** shows content in your personal space, including pages, files, and folders.
* **All > Shared with you** shows items shared directly with you or with a team you belong to. Items you can access only through a shared space may not appear here; open that space to find them.
* Pages shows pages you own or that have been shared with you. Use **Your items** or **Shared with you** to narrow the list. Open a parent page to find its subpages.
* **Suggested** and **Recents** help you return to recently used content.
* Images separates **Your creations** from **Uploads**.

On mobile, find pages through Space search or global search. Recently viewed pages also appear in **Suggested**.

# Add files and use connected content

File access depends on whether you upload the file into a page or link to a file stored elsewhere:

* **Files uploaded into a page** follow that page’s permissions. People who can access the page can access those uploaded files.
* **Links to separately stored files** do not automatically give readers access to the original file. This includes files stored in Space and files in connected services.
* **Files in connected services** keep the permissions of the original service. Sharing a page does not change who can open the source file.

If you or ChatGPT copy or summarize information from a source onto a shared page, people who can view the page can read that information, even if they cannot open the original source.

# Share and collaborate

You can share an individual page or share a space to work with other people on related pages and files.

Open the page and select **Share**. Choose who to share it with and whether they can view or edit it. People with edit access can make changes together in real time.

Access can come from a direct invitation to a page, a parent page, or the space that contains it. Subpages inherit access from their parent.

To remove someone’s access, check how they received it. Removing a direct invitation does not remove access inherited from a parent page or space. To remove inherited access, change the sharing settings on the parent page or space that grants it. Moving a page can also change who can access it through its new parent.

In Business and Enterprise workspaces, your organization’s sharing settings apply.

Each collaborator works with their own ChatGPT. Sharing a page does not give other people access to your private chats or your ChatGPT Memory. However, information written onto the page is visible to everyone who can view it. Review the content and its permissions before sharing.

# What happens when you delete a page?

Deleting a page moves it and its subpages to Trash, including subpages owned by other people. Check the subpages before deleting the parent page.

# Privacy and data controls

If Memory is enabled, ChatGPT may use personal context when helping you write or update a page. Once that information is written onto the page, people who can view the page can read it.

Each collaborator’s training and Memory settings apply when their ChatGPT uses shared content. If a collaborator has Memory enabled, their ChatGPT may remember information from the shared page even when your Memory is off.

Shared content may be used for training when someone’s ChatGPT reads or creates it, depending on that person’s settings. For example, if you turn off training but a collaborator has it on, your contributions may still be used for training through their interaction. OpenAI does not train on ChatGPT Business or Enterprise data by default.

For more information about training preferences, see [Data controls in ChatGPT](/en/articles/7730893-data-controls-in-chatgpt). The companion article, Space in ChatGPT: sharing, data, and controls, explains page permissions, Memory, and training in more detail.

# Report content

To report content that may violate OpenAI’s policies or the law, use the [Report Content form](https://openai.com/form/report-content/). Include a link to the content and explain what you are reporting.

# Troubleshooting

## Why can’t I edit a page?

You need edit access to change a page. If you already have edit access, open the page on the web or in the desktop app. Mobile supports reading and sharing pages, but not editing.

## Why can’t someone open a file linked from my page?

Readers need access to the original file as well as the page. Sharing the page does not change the file’s permissions.
