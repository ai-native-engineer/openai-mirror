# Moving to the new ChatGPT desktop app

How to move from the Codex app or the previous ChatGPT desktop app.

Updated: 2 days ago

ChatGPT Work is gradually rolling out to eligible accounts over the coming days. If you don't see ChatGPT Work in your account yet, your account may not have access yet. Availability will continue to expand as the rollout progresses.

The new ChatGPT desktop app includes Chat and Work under ChatGPT, alongside Codex, on macOS and Windows. Follow the steps for the app you use today.

# If you already use the Codex app

Update the Codex app as usual. After the update, it becomes the new ChatGPT desktop app with Chat, Work, and Codex.  
  
  
Existing Codex chats and projects should remain after the update. The updated app opens in Codex for existing Codex users. You can keep Codex as the default when the app opens and choose the Codex app icon in settings.

# If you already use the ChatGPT desktop app

Follow the prompt in the app to download the new ChatGPT desktop app. Then sign in with the same ChatGPT account.  
  
The new app may install alongside your current app. If both remain installed, you will see:

* **ChatGPT**: The new app with Chat and Work under ChatGPT, plus Codex.
* **ChatGPT Classic:** The previous ChatGPT desktop app. You can continue using it; no migration is required at launch. It continues to receive model updates, bug fixes, security patches, and support for its existing Enterprise capabilities. New agent features may be available only in the new app.

# If you are installing ChatGPT for the first time

[Download the ChatGPT desktop app](https://chatgpt.com/features/desktop/) for your operating system, open it, and sign in.

# What changes in the new app?

* **Chat:** Ask questions, search, and have conversations.
* **Work:** Research, analyze information, and create documents, spreadsheets, presentations, reports, and Sites.
* **Codex:** Develop software with local files, repositories, terminals, and developer tools.
* On desktop, select ChatGPT or Codex from the top-left menu. In ChatGPT, select Chat or Work from the toggle at the top of the page. Chat and Work chats appear together in Recents, where you can sort, filter, and pin chats. Your existing ChatGPT Projects also appear under Projects. From a project, choose Chat to start a new chat, or choose Work to start a Work chat using the project’s context. Codex remains a separate view; its workflows are unchanged, and its history remains separate from ChatGPT history. This navigation update does not change your workspace’s existing access permissions, security settings, governance controls, or spend model.
* Cloud Work chats sync across web, mobile, and desktop. Work chats started on web or mobile appear in the desktop app, and cloud Work chats started on desktop can be continued on web or mobile.
* Codex is not selectable on web or mobile, but supported desktop Codex chats can be accessed from the Remote tab in the ChatGPT mobile app.

# FAQ

## Why do I see both ChatGPT and ChatGPT Classic?

The new app may install separately from the previous desktop app. ChatGPT is the new app with Chat, Work, and Codex. ChatGPT is the new app with Chat and Work under ChatGPT, plus Codex.  
  
ChatGPT Classic continues to receive model updates, bug fixes, security patches, and support for its existing Enterprise capabilities. Some new agent features are available only in the new ChatGPT app.

## Can I keep using ChatGPT Classic?

Yes. ChatGPT Classic continues to receive model updates, bug fixes, security patches, and support for its existing Enterprise capabilities. ChatGPT is the new app with Chat and Work under ChatGPT, plus Codex.

## Is Codex available on web or mobile?

Codex is not selectable on web or mobile. Chat and Work are available there, and you can access supported desktop Codex chats from the Remote tab in the ChatGPT mobile app.
