# Understanding a temporary $5 API authorization hold

Understand why updating your API payment method can create a temporary $5 authorization hold.

Updated: 3 days ago

The $5 pending charge you see after updating your API payment method is a temporary authorization hold on your credit card. This is part of setting up API pay-as-you-go billing.

The pending charge will be reversed within 7 days.

# Distinguish the hold from API payments

A temporary authorization hold is separate from a payment for API usage or a purchase of prepaid credits. Actual API charges depend on your billing arrangement.

For information about purchasing and using prepaid credits, see: [Prepaid API billing](https://help.openai.com/articles/8264644).

If you have questions about the pending charge, [contact OpenAI Support](/en/articles/6614161) using the chat widget in the Help Center.
