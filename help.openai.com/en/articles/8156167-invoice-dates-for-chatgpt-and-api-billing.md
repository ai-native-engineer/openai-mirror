# Invoice dates for ChatGPT and API billing

Learn how billing and invoicing work for ChatGPT subscriptions and API usage.

Updated: 3 days ago

OpenAI does not support changes to invoice dates. Billing cycles and invoice schedules depend on your subscription type and billing arrangement.

# ChatGPT subscriptions

For a ChatGPT subscription billed monthly:

* Billing recurs on the date you subscribed.
* For example, if you subscribed on the 12th, you are billed again on the 12th of each following month.
* Invoice dates follow that recurring schedule and cannot be modified.

# API billing

API billing is not always postpaid. Accounts can use prepaid credits or automatic card payments, while Enterprise API customers receive invoices.

For Enterprise API customers, invoices cover calendar-month usage unless a different custom billing arrangement is agreed in writing. For example, an invoice covering March usage is issued after March ends.

For invoice availability, timing, and receipts, see: [API billing and invoice timing](https://help.openai.com/articles/6640792).

For prepaid credit purchases, see: [Prepaid API billing](https://help.openai.com/articles/8264644).
