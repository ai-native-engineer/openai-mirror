# Canceling API pay-as-you-go service

Learn how to cancel API pay-as-you-go service and understand access, outstanding charges, and prepaid credits after cancellation.

Updated: 3 days ago

You can cancel your API pay-as-you-go service at any time. Cancellation does not refund charges already accrued during the current billing month.

# Cancel your plan

Before you begin, make sure you have permission to manage billing for the API organization you want to cancel.

1. Go to that organization’s [**Billing overview**](https://platform.openai.com/account/billing/overview).
2. Select **Cancel plan** or **Cancel billing plan**, whichever appears.
3. Review the cancellation details, then select **Cancel plan** to confirm.

# Understand what happens after cancellation

Canceling your API billing plan does not clear unpaid usage charges.

If you pay by card, you may still be charged for outstanding usage after you cancel. If your account receives monthly invoices, you may receive a final invoice for the current billing month.

Other API accounts use prepaid credits or automatic card payments and can view their payment history and receipts in Billing. For the distinction between invoices and receipts, see: [API billing and invoice timing](https://help.openai.com/articles/6640792).

You can still access the API Platform after canceling your billing plan.

For accounts billed after usage, API access continues until the end of the current calendar month. Stop sending API requests if you do not want to incur additional usage charges.

If you use prepaid billing, canceling your plan turns off automatic reloading. You can continue using your remaining credits.

Purchased prepaid credits are non-refundable. For credit-balance and recharge information, see: [Prepaid API billing](https://help.openai.com/articles/8264644).
