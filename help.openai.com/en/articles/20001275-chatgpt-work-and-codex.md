# ChatGPT Work and Codex

Use Chat or Work in ChatGPT, or switch to Codex for software development.

Updated: yesterday

ChatGPT Work is gradually rolling out to eligible accounts over the coming days. If you don't see ChatGPT Work in your account yet, your account may not have access yet. Availability will continue to expand as the rollout progresses.

ChatGPT includes Chat and Work, plus Codex in the desktop app. Chat is for fast, conversational assistance and everyday questions. Work is an agent designed for longer, multi-step work and finished deliverables. Codex remains dedicated to software development and technical work.

Work follows the same usage structure as Codex. The [Codex pricing page](https://developers.openai.com/codex/pricing) explains included usage and additional credits; its examples are based on coding tasks, so Work usage will vary by task.

# Choose an experience

* **Chat:** Ask questions, search, brainstorm, or get quick conversational help.

* **Work:** Research a topic, analyze information, or create a document, spreadsheet, presentation, report, or Site.

* **Codex:** Write or debug code, run tests and commands, review changes, or work with a repository.

# Where Work and Codex are available

Work is available on ChatGPT web and mobile for eligible paid plans. Work is also available in the ChatGPT desktop app when included for your plan and workspace.

Work is available for eligible ChatGPT Enterprise and Edu workspaces with Enterprise Key Management (EKM) enabled. Workspace settings and role-based access controls still determine member access.  
  
Work on web and mobile runs in the cloud. In the desktop app, select ChatGPT from the top-left menu, then select Work from the toggle at the top of the page. Chat and Work chats appear together in Recents, where you can sort, filter, and pin chats. Your existing ChatGPT Projects appear under Projects. From a project, choose Chat to start a new chat, or choose Work to start a Work chat using the project’s context. When allowed by your plan and workspace, Work in the desktop app can also use local files and desktop apps with your permission.

Cloud Work chats sync across web, mobile, and desktop. Work chats started on web or mobile appear in the desktop app, and cloud Work chats started on desktop can be continued on web or mobile. When you start local chats, they stay on your computer.

Codex remains a separate view in the ChatGPT desktop app. Select Codex from the top-left menu. Its workflows are unchanged, and its history remains separate from ChatGPT history. Codex can work with local folders, repositories, terminals, and developer tools. Codex is not selectable on web or mobile. You can access supported desktop Codex chats from the Remote tab in the ChatGPT mobile app, but those chats do not become web or mobile chat history.

# Start on desktop

1. Open the ChatGPT desktop app and sign in.
2. Select ChatGPT or Codex from the top-left menu.
3. If you select ChatGPT, choose Chat or Work from the toggle at the top of the page.
4. Start a new chat or open an existing project. From a project, choose Chat to start a new chat, or choose Work to start a Work chat using project context. In Work or Codex, you can also open a local folder.
5. Describe the outcome you want. Add any files, constraints, and review criteria ChatGPT should use.
6. Review the result, then ask for changes or follow-up work in the same chat.

# Start Work on web or mobile

1. Open ChatGPT on the web or in the mobile app and select Work.
2. Start a new chat or open an existing project.
3. Add any files and context ChatGPT should use, then describe the task or deliverable you want completed

A project keeps related chats, files, and instructions together. Work can also run once, repeat on a schedule or trigger, or monitor for changes through Scheduled Tasks. You can review progress, answer questions, change direction, and approve important actions.

Chats created in Chat sync between ChatGPT web and the desktop app. On desktop, Chat and Work chats appear together in Recents, where you can sort, filter, and pin chats.

Cloud Work chats sync across web, mobile, and desktop. Work chats started on web or mobile appear in the desktop app, and cloud Work chats started on desktop can be continued on web or mobile.

Codex remains a separate view. Its workflows are unchanged, and its history remains separate from ChatGPT history. Codex does not appear on web. Use the Remote tab in the ChatGPT mobile app to access supported remote Codex chats.

# FAQ

## Can Work use files on my computer?

Yes, in the desktop app. Open a local folder or project and grant access only to the files the task needs. Local files and outputs remain on that computer unless you explicitly move or share them. Work on web and mobile cannot directly access files on your computer.

## Is Codex available on web or mobile?

Codex is not selectable on web or mobile. You can access supported desktop Codex chats from the Remote tab in the ChatGPT mobile app. Remote access does not add those chats to your web or mobile chat history.

## Where can I learn more?

See Using Codex with your ChatGPT plan for Codex access and usage. See Projects in ChatGPT for help organizing ongoing work, and Scheduled Tasks in ChatGPT for recurring or trigger-based work.

## How do you switch between Chat, Work, and Codex?

**On desktop:**

Select ChatGPT or Codex from the top-left menu. In ChatGPT, select Chat or Work from the toggle at the top of the page. Chat and Work chats appear together in Recents. Use the filter to show all chats or only Chat or Work, and sort or pin chats as needed. Codex remains a separate view; its workflows are unchanged, and its history remains separate from ChatGPT history.

While you’re in Codex, select New chat to open Quick Chat.

**On mobile:**

Select Chat or Work from the dropdown at the top of the screen. Codex is not selectable on mobile, but you can access supported desktop Codex chats from the Remote tab.

## What’s happening to regular ChatGPT?

The fast, familiar Chat experience is still available.

On desktop, select ChatGPT from the top-left menu, then select Chat from the toggle at the top of the page.

On mobile, select Chat from the dropdown at the top of the screen.
