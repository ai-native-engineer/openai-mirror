# Getting started with fine-tuning

Learn how to prepare examples and find the guides for fine-tuning an OpenAI API model.

Updated: 13 days ago

## Overview

If you're interested in fine-tuning an OpenAI model to better adapt it to a specific task, refer to our [fine-tuning guide](https://platform.openai.com/docs/guides/fine-tuning#use-a-fine-tuned-model). This guide is suitable for developers working with our API. If you're interested in getting better responses from ChatGPT, review our [prompt engineering guide](https://help.openai.com/articles/10032626) for ChatGPT.

## Prepare your training data

Fine-tuning data gives the model examples of how it should respond to a conversation. Match your examples as closely as possible to the input the model will see in production.

For data-format requirements and examples, see the [fine-tuning developer guide](https://platform.openai.com/docs/guides/fine-tuning).

## Check model availability

Check the [model optimization and fine-tuning guide](https://platform.openai.com/docs/guides/model-optimization) and your organization's /v1/fine\_tuning/model\_limits response for current fine-tuning model availability.
