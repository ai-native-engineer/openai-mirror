# Submit an EU AI Act inquiry

For EU AI Act-related matters, you may use this form to request EU AI Act model documentation or submit a complaint if you believe that OpenAI does not comply with its obligations under the Copyright Chapter of the Code of Practice for General-Purpose AI Models.

If you would like to report a security issue or incident, please let us know immediately by submitting an encrypted report as described in OpenAI’s [Coordinated Vulnerability Disclosure⁠](https://openai.com/policies/coordinated-vulnerability-disclosure-policy/) Policy.
