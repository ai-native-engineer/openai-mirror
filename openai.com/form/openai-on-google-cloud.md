# Get access to OpenAI frontier models on Google Cloud

Soon, customers will be able to access OpenAI’s frontier models through Model Garden on the Gemini platform and purchase them through Google Cloud Marketplace—all within their existing Google Cloud environment.

## Available in limited preview

* **OpenAI frontier models through the Responses API on Google Cloud:** Select customers can evaluate OpenAI models for supported development and internal testing use cases.
* Codex through the API in the Codex app, command-line interface (CLI), and supported development environments (IDEs)

The preview is invite-only. Register your interest to be considered for early access.
