# Daybreak Red is now available in AWS GovCloud (US-East)

Building on the availability of Daybreak models on Amazon Bedrock, GPT‑5.6 Cyber is now available to approved customers [in AWS GovCloud (US-East)⁠(opens in a new window)](https://aws.amazon.com/about-aws/whats-new/2026/10/openai-daybreak-red-govcloud-east/) through Daybreak Red. This expansion gives government security teams a new way to apply advanced cybersecurity capabilities within the AWS environments they use to support critical missions.

Daybreak Red provides access to OpenAI’s purpose-trained cybersecurity models for authorized vulnerability research, exploit validation, and security testing. GPT‑5.6 Cyber can help defenders investigate complex software weaknesses, reproduce vulnerabilities in controlled settings, and develop mitigations. Qualified security practitioners should review findings and proposed fixes before implementation.

## Bringing frontier cybersecurity capabilities to government teams

For government organizations, adopting advanced cybersecurity capabilities requires more than model performance. Teams also need to work within established security, governance, and operational requirements.

Availability in AWS GovCloud (US-East) gives eligible teams a path to incorporate GPT‑5.6 Cyber into those workflows through Amazon Bedrock. Defenders can use it to reason through security findings, assess their impact, and evaluate fixes, helping connect vulnerability research to practical improvements in defense.

Daybreak Red gives verified defenders greater latitude for authorized cybersecurity work, with fewer refusals for these tasks alongside stronger identity verification, monitoring, and access controls.

For Daybreak Red on Amazon Bedrock, inference data is not used to train models, and customers do not need to share their Daybreak Red data with OpenAI.

## Get started

Access requires OpenAI Daybreak Red approval and AWS provisioning. To get started, complete the [Daybreak application](/form/enterprise-trusted-access-for-cyber/) or contact your OpenAI or AWS account team about eligibility. Once approved, work with your AWS account team to enable access. Daybreak Red approval does not automatically enable model access on AWS.

Learn more about[Daybreak models on AWS](/index/daybreak-models-are-now-available-on-aws/).
