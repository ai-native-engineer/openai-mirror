##### Build and Operate Production Agents with OpenAI and Amazon Bedrock

12/1 at 1:30PM | MGM

Moving an agent from prototype to production requires more than a capable model. This session examines the architecture patterns needed to build reliable, governable agentic workflows across enterprise systems using OpenAI and Amazon Bedrock. Explore tool use, evaluations, observability, identity, and permissions—and learn how to design agents that can take action while remaining measurable, secure, and aligned with organizational policies.
