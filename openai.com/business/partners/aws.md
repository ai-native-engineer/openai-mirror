### What is the OpenAI and AWS partnership?

OpenAI and AWS are making OpenAI models, Codex, and agent capabilities available within AWS environments, allowing customers to build with OpenAI while using familiar AWS infrastructure, security, governance, and procurement processes. ([OpenAI](/index/openai-on-aws/))

### Which OpenAI capabilities are available through AWS?

Customers can access OpenAI models on Amazon Bedrock, configure Codex to use Bedrock, and build agentic workflows with Amazon Bedrock Managed Agents powered by OpenAI.

### What is Codex on Amazon Bedrock?

Codex is OpenAI’s coding agent. When configured with Bedrock, Codex runs locally in the CLI, desktop app, or IDE extension while inference requests are processed through Amazon Bedrock. ([OpenAI Help Center⁠(opens in a new window)](https://help.openai.com/en/articles/20001252-use-codex-with-amazon-bedrock))
