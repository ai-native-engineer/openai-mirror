## How it works

Use natural language to search your Oracle Analytics Cloud catalog for workbooks, datasets, subject areas, and folders. Inspect dataset and subject-area metadata, and ask questions using Oracle Analytics SQL query results.
The plugin includes tools for creating catalog folders, saving supported workbook or connection content, copying or moving catalog items, updating catalog access controls, and exporting workbooks to PNG or PDF.
A workspace administrator configures an Oracle Analytics Cloud instance using a supported endpoint. Sign in to that instance to use its tools. Available content and operations depend on the instance configuration, connected tools, and account permissions.
