# Aurora

Access data with Consilio

Aurora helps authorized Consilio users search their eDiscovery and legal-services data from ChatGPT. Users can find matters by alpha-code, client name, or free text; list or search workspaces inside accessible matters; and run AI-assisted document searches within a workspace. Results are scoped to the user's existing Consilio access and include source links where applicable.
