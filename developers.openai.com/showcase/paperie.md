A greeting-card canvas where an agent supplies personalized words and artwork while you edit and preview the same design. Choose a template or start from a blank card, then adjust its format, messages, and envelope.

An agent can bring recipient context and generated artwork into a card, then refine the words and design through WebMCP. You can edit the same card and preview each change as it happens.
