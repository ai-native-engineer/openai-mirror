Description

Paper Glider is a 3D flying game built with Codex and GPT-5.6. Players steer a paper airplane through a continuous sequence of warm interiors, collecting rings while avoiding furniture and walls.

## Build notes

### Initial prompt

Copy prompt
 

Build “Paper Glider,” a simple in-browser 3D flying game. The player guides a paper airplane through a continuous sequence of beautifully designed rooms by moving the pointer or dragging on touch. Passing through floating rings increases the score; hitting furniture or walls ends the run. Keep movement forgiving and arcade-like rather than physically realistic.

Use WebGL with a clean, low-poly art direction, warm afternoon light, and subtle paper textures. Animate curtains, dust, and loose pages to convey motion. Include a short start screen, score, best score stored locally, increasing speed, a game-over state, and one-click restart. Generate the rooms procedurally from a small set of reusable obstacles so the game needs no external level data.

Support desktop and mobile controls, maintain smooth performance, run build and lint, and verify starting, scoring, collisions, and restarting in the browser with no console errors.

### Iterations

1. Built a dependency-free WebGL game engine with procedural rooms, furniture, rings, dust, curtains, loose pages, cross-device steering, scoring, collisions, restart, and persistent best score.
2. Added parquet, rugs, wall panels, molding, framed artwork, brass details, richer materials, layered lighting, shadows, color grading, and distance-based rendering limits for a more elevated presentation.
3. Final step

   Finished a polished, responsive gliding game with procedural interiors, forgiving controls, an escalating arcade loop, and verified desktop and mobile play.
