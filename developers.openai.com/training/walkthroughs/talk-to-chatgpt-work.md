# Using voice

Voice lets you talk with ChatGPT while it works in the desktop app, so you can brainstorm ideas, ask for a slide deck, and refine it out loud.

## Create a slide deck with Voice

1. [![](/images/codex/walkthroughs/chatgpt-voice-orb-still.webp)](/images/codex/walkthroughs/chatgpt-voice-orb.mp4)

   Talk through ideas

   Brainstorm a team event.
2. Ask for a slide deck

   Turn the strongest ideas into a pitch.
3. ![](/images/codex/apps/google-slides.svg)

   Open your slides

   Review the deck with ChatGPT.

## Start talking

Start a new chat in the ChatGPT desktop app, select Voice before sending
your first message, and talk through an idea. ChatGPT can ask follow-up
questions, build a presentation from the conversation, and keep working
while you use your computer.

Start new voice chat

In a new desktop chat, select the Voice icon before sending your first
message.

The first time, allow microphone access, choose a voice, and review Screen
context on Mac.

As the task takes shape, its progress and any finished files stay visible
on your screen.

Available in the ChatGPT desktop app with Plus, Pro, Business, Edu, and
Enterprise plans, or through Remote on iOS after pairing your computer.

## Voice or dictation?

Use ChatGPT Voice for a live conversation with ChatGPT. Use voice
dictation when you only want to turn speech into prompt text before
sending it.

Voice
:   Live conversation while work continues.

Dictation
:   Speech becomes prompt text before sending.

## Steer without starting over

Start with an idea, ask ChatGPT to shape it into a presentation, then ask
for changes to the slides. Each follow-up builds on the same context, so
you can keep refining the deck without repeating the original request.

On Mac, open **Settings > Voice**, turn on **Screen context**, then say “Take a look at this” to share the window in front of you.

Open the ChatGPT desktop app, start Voice, and guide one task forward with a
few short follow-ups.

1. Start voice

   In a new desktop chat, select the Voice icon before sending a message.
2. Say

   “Help me brainstorm three activation ideas for a team event.”
3. Steer

   “Turn the strongest two into a five-slide visual pitch deck.”
4. Review

   “Show me the latest version and what still needs my input.”
