# Creating slides and docs

Turn messy source material into a clear document, shape the refined content into a slide deck, and save both formats as templates to reuse.

Messy input

Notes, transcripts, or files

![](/images/codex/apps/google-docs.svg) Doc

A clear, editable record

![](/images/codex/apps/google-slides.svg) Slide deck

A focused visual story

## Start with what you have

Notes, transcripts, documents, and files rarely arrive ready to share.
Attach your source material, describe the result you need, and say what
should be checked before delivery.

In this example we’ll turn a weekly meeting transcript into a concise
visual summary for leadership. We’re using Google Docs and Google Slides
here, but you can also use Word and PowerPoint.

## Turn a messy input into a doc

Start by asking ChatGPT to turn your transcript or notes into a Google
Doc. Ask for the sections you want and for ChatGPT to flag missing
details.

### Choose how it should look

Here, we named the sections we wanted. You can guide the format in either
of two ways.

#### Describe the structure

Name the sections, details, and information to include.

#### Attach an example

Share a document or template whose structure you like.

Review the result against the original source. Once the document is
accurate, it can guide the presentation.

## Turn the document into a deck

Ask ChatGPT to turn the approved document into a concise deck that
follows the same key sections. Attach a reference presentation if you
want it to follow a particular visual style.

The deck should prioritize the story rather than repeat every detail.
Review the document or slides alongside the conversation, then ask for
focused changes to specific sections without starting over.

## Save the formats to use again

Use **@Template Creator**
and attach the finished document, presentation, or both. ChatGPT can save
the structure and visual style as reusable templates.

* ![](/images/codex/apps/google-docs.svg)

  Document format

  Keep the sections and level of detail.
* ![](/images/codex/apps/google-slides.svg)

  Presentation style

  Reuse the slide order and visual direction.

Now you can attach new source material and mention the saved template. The
information changes while the format stays familiar.

Open the first prompt in ChatGPT and attach your notes, transcript, or other
source material. Copy the follow-up prompts into that same conversation.

1. ### Create the document

   Turn [source material] into a clear document for [audience], with a short summary, key details, takeaways, open questions, and next steps.

   [Open this prompt in ChatGPT Work (opens in a new tab)](https://chatgpt.com/?surface=work&prompt=Turn+%5Bsource+material%5D+into+a+clear+document+for+%5Baudience%5D%2C+with+a+short+summary%2C+key+details%2C+takeaways%2C+open+questions%2C+and+next+steps.)
2. ### Create the slide deck

   Use the document you just made to create a slide deck that follows its structure.
3. ### Save with Template Creator

   Use @Template Creator to save the structure of the finished document and/or the style of the finished presentation as reusable templates.
