### Projects and chats

A project keeps related chats, files, and sources together. Use one when several tasks need the same context. Each chat holds a conversation and its results; start a separate chat for each distinct outcome.

[Read the docs](https://learn.chatgpt.com/docs/projects)

### Plugins and connected sources

Plugins add tools and reusable skills to ChatGPT. Google Drive and Gmail connect it to files and email you can access. Browse Plugins, review the requested permissions, and connect your account when prompted. Type @ in chat to choose a plugin.

[Read the docs](https://learn.chatgpt.com/docs/plugins)
