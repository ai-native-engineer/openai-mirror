## Walkthroughs

These walkthroughs show what you can do with ChatGPT Work, and many of the same approaches also apply to Codex.
Follow them in order or jump straight to what you want to learn.

1. [01Walkthrough 1.

   ### Getting started with ChatGPT Work

   Use Work when a task is scattered across the tools you already use and needs to end in a finished result.

   8 min](/training/walkthroughs/getting-started)
2. [02Walkthrough 2.

   ### Plugins and skills

   Plugins give ChatGPT new things it can do. Skills save how you want those things done.

   9 min](/training/walkthroughs/plugins-and-skills)
3. [03Walkthrough 3.

   ### Set up scheduled tasks

   Ask ChatGPT to run useful work later or repeat it on a schedule, then review every run in the Scheduled tab.

   7 min](/training/walkthroughs/scheduled-tasks)
4. [04Walkthrough 4.

   ### Creating slides and docs

   Turn messy source material into a clear document, shape the refined content into a slide deck, and save both formats as templates to reuse.

   8 min](/training/walkthroughs/creating-slides-and-docs)
5. [05Walkthrough 5.

   ### Using your computer and browser

   ChatGPT can read what’s on screen, click, and type in apps and websites you allow it to use. Work through a spreadsheet, research a topic across websites, or fill out a form on a site you’re already signed in to.

   10 min](/training/walkthroughs/using-your-computer-and-browser)
6. [06Walkthrough 6.

   ### Building a shareable site

   Describe what you want, and ChatGPT can build and host a real website, even from ChatGPT Work on your phone. Create a dashboard, shared trip planner, interactive tool, game, or whatever else you can imagine.

   7 min](/training/walkthroughs/building-a-shareable-site)
7. [07Walkthrough 7.

   ### Working on your phone

   Use ChatGPT Work from the mobile app, or use Remote to review, approve, and start tasks on your connected computer.

   7 min](/training/walkthroughs/working-on-your-phone)
8. [08Walkthrough 8.

   ### Using voice

   Voice lets you talk with ChatGPT while it works in the desktop app, so you can brainstorm ideas, ask for a slide deck, and refine it out loud.

   6 min](/training/walkthroughs/using-voice)
